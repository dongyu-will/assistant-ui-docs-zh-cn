# assistant-ui Chinese glossary

## Keep unchanged

Brand, product, protocol, platform, package, API, type, component and code identifiers stay in their official spelling: `assistant-ui`, React, React Native, Next.js, Fumadocs, TypeScript, JavaScript, JSX, MDX, OpenAI, Anthropic, LangGraph, LangChain, MCP, A2UI, Slack, Microsoft Teams, Radix UI, Base UI, shadcn/ui, Assistant Cloud, WebMCP, Xulux, `ThreadPrimitive`, `AssistantRuntimeProvider`, `@assistant-ui/*`, `use*Runtime`, CLI commands, route slugs, and URLs.

## Keep English with a Chinese explanation on first use

Use the official English term in prose, adding a short Chinese explanation when it helps: runtime（运行时）, primitive（原语）, composer（输入框组件）, thread（会话线程）, streaming（流式输出）, generative UI（生成式 UI）, human in the loop（人在回路）, external store（外部状态存储）, adapter（适配器）, transport（传输层）, renderer（渲染器）, and tool call（工具调用）.
