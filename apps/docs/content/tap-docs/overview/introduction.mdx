**tap 是一个基于 React Hooks 的状态管理库。**

它让你能够使用已经熟悉的 React API 和心智模型来构建和管理应用状态，并围绕一个新的原语：**Resource** 组织这些状态。

Resource 对状态所做的事情，就像组件对 UI 所做的事情一样。它将有状态行为转换为可复用、可组合的构建块，但返回的是状态和方法，而不是 JSX。

> **Resource 像组件一样组织，但像 Hooks 一样执行。**

## Resource 是状态组合的基本单元

<TapTutorialSlideshow />

`resource()` 将 Hook 转换为 Resource。使用
[`useResource`](/tap/docs/tap/resources#hosting-a-resource) 组合单个 Resource，
或使用 [`useResources`](/tap/docs/tap/composition#useresources) 组合带键的集合。

嵌套的 Resource 的行为就像其 Hook 逻辑被内联一样，因此副作用遵循声明顺序，而不是组件树顺序。详情请参阅
[与 React 的差异](/tap/docs/tap/differences-from-react)。
