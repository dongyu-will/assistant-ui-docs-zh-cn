title: 动机
description: 基于 React 生命周期构建的可组合配置和状态。

tap 旨在将 React 的两项优势引入应用状态：可组合配置和原生生命周期。

## 可组合配置

资源元素将实现与其配置一起封装。由于它是一个值，因此可以在执行前进行传递、替换和嵌套。

```ts
AuiConfig({
  cloud: AssistantCloud({ apiKey: "..." }),
  threads: CloudThreadList({
    thread: () => AISDKThread({ transport: /* ... */ }),
  }),
});
```

每次调用都会返回一个
[`ResourceElement`](/tap/docs/tap/api-reference#resourceelement)。这些元素共同构成一个类型安全的声明式配置树。应用可以替换其中一部分，而无需改变其余部分的组装方式。

## 使用 React 生命周期管理状态

资源使用 React Hooks 管理状态，并采用与 React 组件相同的两阶段生命周期：

- 在 **render** 阶段，Hooks 推导资源的当前状态，并组合子资源。
- 在 **mount** 阶段，effect 将该状态连接到外部世界。当依赖项发生变化时，effect 会重新运行；当资源卸载时，effect 会进行清理。

这使生命周期本身成为状态模型的一部分。状态与 effect 始终保持在一起，同时资源仍独立于用于呈现它们的组件树。
