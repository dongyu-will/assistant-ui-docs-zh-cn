---
title: 作用域
description: Store 中命名且相互独立的状态单元。
---

**作用域（scope）**是 Store 中一个带名称的插槽。与其把所有内容放在同一个地方，不如将应用状态拆分为相互独立的单元——每个单元都有自己的名称、方法和状态。

一个聊天应用可能包含三个自然嵌套的作用域：

```
App              ← threadList scope
  └ ThreadView   ← thread scope
    └ Message    ← message scope
```

树中的每一层都会添加一个作用域。任意层级的组件都可以访问其上方的作用域。

## 注册作用域

你可以通过扩展 `ScopeRegistry` 来声明有哪些作用域：

```ts title="lib/store/scopes.ts"
import "@assistant-ui/store";

declare module "@assistant-ui/store" {
  interface ScopeRegistry {
    threadList: {
      methods: {
        getState: () => { threadIds: string[] };
      };
    };
    thread: {
      methods: {
        getState: () => { messages: { role: string; content: string }[] };
      };
    };
    message: {
      methods: {
        getState: () => { role: string; content: string };
      };
    };
  }
}
```

这是一个**类型级别**的声明——不包含运行时代码。它会告诉 TypeScript 存在哪些作用域，以及每个作用域的结构。每个 Store hook 都会使用这些信息来提供自动补全和类型检查。

由于 `ScopeRegistry` 使用了 TypeScript 模块扩展，不同的包可以分别注册自己的作用域。`@my-org/chat` 包可以注册 `thread` 和 `message`，而 `@my-org/analytics` 注册 `analytics`——你的应用可以通过同一个 `useAui` hook 访问所有这些作用域。

## 填充作用域

你可以使用一个 `AuiProvider` 来填充作用域，其 `config` 通过 `AuiConfig(...)` 构建：

```tsx
AuiConfig({
  threadList: ThreadListResource(),
});
```

每个键都对应 `ScopeRegistry` 中的一个名称。每个值都是实现该作用域方法的 Tap 资源元素。

在顶层，仅使用 `config` 就可以创建 Store：

```tsx
const App = () => {
  const config = AuiConfig({ threadList: ThreadListResource() });
  return (
    <AuiProvider config={config}>
      <ThreadView />
    </AuiProvider>
  );
};
```

现在，`App` 内的任意组件都可以调用 `useAui()`，获取已填充 `threadList` 作用域的 Store。

你不必一次填充所有作用域。树中的每一层都可以使用自己的作用域扩展 Store——嵌套 provider 传入 `extends={aui}` 以扩展父级作用域（或传入 `extends={null}` 以进行隔离）：

```tsx
const ThreadView = () => {
  // extends the parent store with a thread scope
  const aui = useAui();
  const config = AuiConfig({ thread: ThreadResource() });
  return (
    <AuiProvider extends={aui} config={config}>
      <MessageList />
    </AuiProvider>
  );
};
```

嵌套 provider 会接收已经包含 `threadList` 的父 Store，并使用 `thread` 对其进行扩展。`ThreadView` 内的组件可以访问这两个作用域。
