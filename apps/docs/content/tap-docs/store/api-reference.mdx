## Hooks

### useAui()

```ts
function useAui(): AssistantClient;
```

返回最近的 `AuiProvider` 中的状态存储。客户端是不可变的：状态更新会保持其标识不变，而结构性变更（某个 scope 解析为不同的实例）会生成新的客户端，并触发消费者重新渲染。

### AuiConfig

```ts
function AuiConfig(config: AuiConfig.Input): AuiConfig;

type AuiConfig.Input = {
  [K in ClientNames]?: ClientElement<K> | DerivedElement<K>;
};
```

构建由 `AuiProvider` 的 `config` 属性接受的品牌化配置对象。直接使用对象字面量会产生类型错误。

`useAui(scopes)` 扩展重载已弃用；请提升 `const aui = useAui()` 和 `const config = AuiConfig(scopes)`，并改用 `<AuiProvider extends={aui} config={config}>`。

### useAuiState

```ts
function useAuiState<T>(selector: (state: AssistantState) => T): T;
```

订阅状态的一个切片。仅当选中的值发生变化时才会重新渲染（通过 `Object.is` 进行比较）。选择器必须返回具体值，而不是整个状态对象。可能不可用的 scope 可以通过 `s.optional.<scope>` 读取；它会解析为 `undefined`，而不是抛出异常。

### useAuiEvent

```ts
function useAuiEvent<TEvent extends AssistantEventName>(
  selector: AssistantEventSelector<TEvent>,
  callback: AssistantEventCallback<TEvent>,
): void;
```

订阅事件。选择器可以是字符串（`"scope.event"`）或对象（`{ scope, event }`）。组件卸载时取消订阅。

## 组件

### AuiProvider

```tsx
const aui = useAui();
const config = AuiConfig({ counter: CounterResource() });

// Top-level root
<AuiProvider config={config}>{children}</AuiProvider>

// Nested: extend the parent (or extends={null} to isolate)
<AuiProvider extends={aui} config={config}>{children}</AuiProvider>
```

向 React 树提供一个 `AssistantClient`，该客户端由使用 `AuiConfig(...)` 构建的 `config` 创建。在父级 provider 下嵌套时，`extends` 是必需的：`extends={aui}` 会扩展父级，`extends={null}` 会进行隔离。空配置会创建一个扩展 `extends` 客户端的客户端。挂载后，`ref` 会接收生成的客户端。子组件通过 `useAui()` 访问客户端。

### AuiIf

```tsx
<AuiIf condition={(s) => s.counter.count > 0}>
  <ResetButton />
</AuiIf>
```

仅当条件返回 `true` 时才渲染子项。内部使用 `useAuiState`。

### RenderChildrenWithAccessor

```tsx
<RenderChildrenWithAccessor
  getItemState={(aui) => aui.todoList.todo({ index }).getState()}
>
  {(getItem) =>
    children({
      get todo() {
        return getItem();
      },
    })
  }
</RenderChildrenWithAccessor>
```

为列表渲染设置延迟的项访问器。`getItem` 函数会将状态读取延迟到消费者访问该项时；如果子项渲染函数从未读取该项，则不会创建订阅。当子项返回无 props 组件（例如 `{() => <Todo />}`）时，输出会自动进行 memoization（记忆化）。

| 属性 | 类型 |
|------|------|
| `getItemState` | `(aui: AssistantClient) => T` |
| `children` | `(getItem: () => T) => ReactNode` |

参见[渲染列表](/tap/docs/store/rendering-lists)了解完整模式。

## 资源工具

### Derived

```ts
function Derived<K extends ClientNames>(config: Derived.Props<K>): DerivedElement<K>;
```

创建一个派生 scope，指向父级 scope 中的数据。

```ts
Derived({
  source: "thread",
  query: { index: 0 },
  get: (aui) => aui.thread.message({ index: 0 }),
});
```

`get` 函数接收当前的 `AssistantClient`，并且必须返回通过 `useClientResource`（或 `useClientLookup`/`useClientList`）创建的客户端，通常是调用父级 scope 方法的结果。meta（`source`、`query`）充当标识：当 `query` 在渲染之间发生变化时，会在同一个渲染过程中返回新的访问器；这对于按索引为子消费者（如 `MessageByIndex`）设置 key 很有用。

### attachTransformScopes

```ts
function attachTransformScopes(
  hook: (...args: any[]) => any,
  transform: (scopes: ScopesConfig, parent: AssistantClient) => void,
): void;
```

将转换函数附加到资源 hook 上——传入你提供给 `resource()` 的 hook 函数，而不是资源包装器。当资源通过 `AuiProvider` 挂载时，会运行该转换函数，并可通过修改 `scopes` 来添加或修改同级 scope。转换会迭代应用：新的根 scope 会触发其自身的转换。

每个 hook 只能有一个转换。重复添加时会抛出异常。

### forwardTransformScopes

```ts
function forwardTransformScopes(
  target: (...args: any[]) => any,
  source: (...args: any[]) => any,
): void;
```

将 `source` 的转换复制到 `target`，并与 `target` 已有的任何转换组合。当一个资源 hook 包装另一个资源 hook 时使用。

### ScopesConfig

```ts
type ScopesConfig = {
  [K in ClientNames]?: ClientElement<K> | DerivedElement<K>;
};
```

传递给 `AuiConfig` 并由转换函数修改的 scope 对象。

## 资源 hooks

这些 hook 在 Tap 资源内部使用，用于与 Store 集成。

### useClientResource

```ts
function useClientResource<TMethods extends ClientMethods>(
  element: ResourceElement<TMethods>,
): {
  state: InferClientState<TMethods>;
  methods: TMethods;
  key: string | number | undefined;
};
```

将单个资源元素包装为客户端。将客户端添加到内部客户端栈，以便进行事件作用域限定。

`state` 根据元素的 `getState()` 返回类型推断。如果未定义 `getState`，则 `state` 为 `undefined`。

### useClientLookup

```ts
function useClientLookup<TMethods extends ClientMethods>(
  elements: readonly ResourceElement<TMethods>[],
): {
  state: InferClientState<TMethods>[];
  get: (lookup: { index: number } | { key: string }) => TMethods;
};
```

将资源元素列表包装为客户端。每个元素都必须有 key（通过 `withKey`）。内部会为每个元素使用 `useClientResource`。

`get` 按索引或 key 解析客户端。如果查找不匹配，则抛出异常。

### useClientList

```ts
function useClientList<TData, TMethods extends ClientMethods>(
  props: useClientList.Props<TData, TMethods>,
): {
  state: InferClientState<TMethods>[];
  get: (lookup: { index: number } | { key: string }) => TMethods;
  add: (data: TData) => void;
};
```

管理支持添加和移除的动态客户端列表。基于 `useClientLookup` 构建。

```ts
type useClientList.Props<TData, TMethods> = {
  initialValues: TData[];
  getKey: (data: TData) => string;
  resource: Resource<TMethods, [useClientList.ResourceProps<TData>]>;
};

type useClientList.ResourceProps<TData> = {
  key: string;
  getInitialData: () => TData;
  remove: () => void;
};
```

`getInitialData()` 会在挂载时调用一次。`remove()` 会从列表中移除该项。重复 key 时会抛出异常。

### useAssistantClientRef

```ts
function useAssistantClientRef(): {
  parent: AssistantClient;
  current: AssistantClient | null;
};
```

返回指向正在构建的状态存储的 ref。在资源创建期间，`current` 为 `null`，并在所有同级 scope 挂载后填充。可在 `useEffect` 中使用它，以便在运行时访问同级 scope。

### useAssistantEmit

```ts
function useAssistantEmit(): <TEvent extends Exclude<AssistantEventName, "*">>(
  event: TEvent,
  payload: AssistantEventPayload[TEvent],
) => void;
```

返回稳定的 emit 函数。事件通过 microtask（微任务）传递——监听器会在当前状态更新完成后触发。

### getClientId

```ts
function getClientId(client: object): getClientId.ClientId;
```

返回已绑定客户端实例的不透明标识。在已绑定客户端的整个生命周期内保持稳定，不受访问器包装影响，是按客户端缓存使用的可靠 `WeakMap` key。对不可用 scope 的访问器调用时会抛出异常。

## 类型

### ScopeRegistry

```ts
interface ScopeRegistry {}
```

模块扩展点。扩展此接口以注册 scope：

```ts
declare module "@assistant-ui/store" {
  interface ScopeRegistry {
    counter: {
      methods: {
        getState: () => { count: number };
        increment: () => void;
      };
      meta?: { source: ClientNames; query: Record<string, unknown> };
      events?: { "counter.incremented": { newCount: number } };
    };
  }
}
```

`methods` 是必需的。`meta` 和 `events` 是可选的。

### ClientOutput

```ts
type ClientOutput<K extends ClientNames> = ClientSchemas[K]["methods"] & ClientMethods;
```

实现 scope `K` 的资源的返回类型。将其用作资源函数的返回类型注解。

### ClientNames

```ts
type ClientNames = keyof ClientSchemas;
```

所有已注册 scope 名称的联合类型。

### AssistantClient

```ts
type AssistantClient = {
  [K in ClientNames]: AssistantClientAccessor<K>;
} & {
  readonly optional: {
    readonly [K in ClientNames]: AssistantClientAccessor<K> | undefined;
  };
  subscribe(listener: () => void): Unsubscribe;
  on<TEvent extends AssistantEventName>(
    selector: AssistantEventSelector<TEvent>,
    callback: AssistantEventCallback<TEvent>,
  ): Unsubscribe;
};
```

由 `useAui()` 返回的状态存储对象。每个 scope 都是一个访问器。`optional` 暴露相同的 scope，但会将不可用的 scope 解析为 `undefined`，而不是抛出异常的访问器：`aui.optional.counter?.increment()`。`subscribe` 会在任何状态变化时触发。`on` 订阅类型化事件。

### AssistantClientAccessor

```ts
type AssistantClientAccessor<K extends ClientNames> =
  ClientSchemas[K]["methods"] & {
    /** @deprecated Access the scope as a property instead. */
    (): ClientSchemas[K]["methods"];
  } & (
    | ClientMeta<K>
    | { source: "root"; query: Record<string, never> }
    | { source: null; query: null }
  ) & { name: K };
```

一种 scope 访问器，将 scope 的方法作为属性暴露（`aui.counter.increment()`）。读取 `.source`、`.query` 和 `.name` 获取元数据；通过 `aui.optional.counter` 检查可用性。调用签名（`aui.counter()`）已弃用，并返回相同的访问器。

### AssistantState

```ts
type AssistantState = ScopeStates & {
  readonly optional: {
    readonly [K in keyof ScopeStates]: ScopeStates[K] | undefined;
  };
};

type ScopeStates = {
  [K in ClientNames]: ClientSchemas[K]["methods"] extends {
    getState: () => infer S;
  }
    ? S
    : never;
};
```

传递给 `useAuiState` 选择器的状态对象。每个键都是对应 scope 的 `getState()` 返回类型。`optional` 暴露相同的 scope，但会将不可用的 scope 解析为 `undefined`，而不是抛出异常：`s.optional.counter?.count`。

### ClientMeta

```ts
type ClientMeta<K extends ClientNames> =
  "meta" extends keyof ClientSchemas[K]
    ? Pick<ClientSchemas[K]["meta"], "source" | "query">
    : never;
```

如果在 `ScopeRegistry` 中声明了 `meta`，则这是 scope `K` 的 `source` 和 `query` 形状。

### ClientElement

```ts
type ClientElement<K extends ClientNames> = ResourceElement<ClientOutput<K>>;
```

实现 scope `K` 的资源元素。

### DerivedElement

```ts
type DerivedElement<K extends ClientNames> =
  ResourceElement<ReturnType<AssistantClientAccessor<K>>>;
```

`Derived(...)` 为 scope `K` 返回的元素。

### ClientMethods

```ts
interface ClientMethods {
  [key: string | symbol]: (...args: any[]) => any;
}
```

scope 方法的基础约束。

### ClientSchema

```ts
type ClientSchema<
  TMethods extends ClientMethods = ClientMethods,
  TMeta extends { source: ClientNames; query: Record<string, unknown> } = never,
  TEvents extends Record<string, unknown> = never,
> = {
  methods: TMethods;
  meta?: TMeta;
  events?: TEvents;
};
```

用于声明 `ScopeRegistry` 条目的辅助工具。

### ClientEvents

```ts
type ClientEvents<K extends ClientNames> =
  "events" extends keyof ClientSchemas[K]
    ? ClientSchemas[K]["events"] extends Record<`${K}.${string}`, unknown>
      ? ClientSchemas[K]["events"]
      : never
    : never;
```

由 scope `K` 声明的事件映射（如果有）。

### Unsubscribe

```ts
type Unsubscribe = () => void;
```

## 事件类型

### AssistantEventName

```ts
type AssistantEventName = keyof AssistantEventPayload;
```

所有已注册事件名称与 `"*"` 的联合类型。

### AssistantEventPayload

```ts
type AssistantEventPayload = ClientEventMap & {
  "*": { [K in keyof ClientEventMap]: { event: K; payload: ClientEventMap[K] } }[keyof ClientEventMap];
};
```

将事件名称映射到其负载类型。`"*"` 键接收一个包装后的 `{ event, payload }` 对象。

### AssistantEventSelector

```ts
type AssistantEventSelector<TEvent extends AssistantEventName> =
  | TEvent
  | { scope: AssistantEventScope<TEvent>; event: TEvent };
```

字符串（`"scope.event"`）或对象（`{ scope, event }`）。字符串默认使用与事件来源匹配的 `scope`。

### AssistantEventScope

```ts
type AssistantEventScope<TEvent extends AssistantEventName> =
  | "*"
  | EventSource<TEvent>
  | AncestorsOf<EventSource<TEvent>>;
```

可监听的有效 scope：事件的来源 scope、该 scope 的任意祖先，或用于监听全部事件的 `"*"`。

### AssistantEventCallback

```ts
type AssistantEventCallback<TEvent extends AssistantEventName> = (
  payload: AssistantEventPayload[TEvent],
) => void;
```

### normalizeEventSelector

```ts
function normalizeEventSelector<TEvent extends AssistantEventName>(
  selector: AssistantEventSelector<TEvent>,
): { scope: AssistantEventScope<TEvent>; event: TEvent };
```

将字符串选择器转换为 `{ scope, event }` 形式。类似 `"counter.incremented"` 的字符串会变为 `{ scope: "counter", event: "counter.incremented" }`。
