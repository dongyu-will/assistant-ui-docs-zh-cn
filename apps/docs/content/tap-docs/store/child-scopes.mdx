---
title: 子作用域
description: 使用 Derived、useClientResource 和 useClientLookup 从父级数据派生作用域。
---

到目前为止，每个作用域都是独立的状态单元——创建它、提供它，然后使用它。但当你有一个列表，其中每个项目都需要自己的作用域时，该怎么办？

聊天应用不只有一条消息——而是几十条。待办事项应用不只有一个待办事项——而是一个动态列表。你无法在 `ScopeRegistry` 中为每个项目注册单独的作用域。相反，**父作用域**管理整个集合，而**子作用域**指向其中的单个项目。

## 模式

父作用域暴露一个项目列表。子作用域指向列表中的某个项目。连接方式如下：

1. 父级 resource 使用 `useClientLookup` 管理子 client 的集合
2. 父级返回一个可通过索引或键访问子项的方法
3. `Derived` 作用域调用该方法来解析特定的子项

```
todoList scope (parent)
  └ manages a list of todo clients
  └ exposes: todo({ index }) → methods

todo scope (child, via Derived)
  └ points to one specific todo from the parent
```

## 分步说明

### 1. 注册两个作用域

```ts title="lib/store/todo-scope.ts"
import type { ClientOutput } from "@assistant-ui/store";

declare module "@assistant-ui/store" {
  interface ScopeRegistry {
    todoList: {
      methods: {
        getState: () => { todos: { id: string; text: string; done: boolean }[] };
        todo: (lookup: { index: number }) => ClientOutput<"todo">;
        add: (text: string) => void;
      };
    };
    todo: {
      methods: {
        getState: () => { id: string; text: string; done: boolean };
        toggle: () => void;
        remove: () => void;
      };
      meta: { source: "todoList"; query: { index: number } };
    };
  }
}
```

`todo` 作用域声明 `meta: { source: "todoList"; query: { index: number } }`——这会告知 TypeScript，`todo` 派生自 `todoList`，并通过索引进行查找。

### 2. 使用 useClientLookup 构建父级 resource

`useClientLookup` 会将 resource 元素列表包装为可通过索引或键访问的 client：

```ts title="lib/store/todo-list-resource.ts"
import { resource, withKey } from "@assistant-ui/tap";
import { useClientLookup } from "@assistant-ui/store";
import type { ClientOutput } from "@assistant-ui/store";
import { useState, useMemo } from "react";

const useTodoResource = ({
  id,
  text,
  done,
}: {
  id: string;
  text: string;
  done: boolean;
}): ClientOutput<"todo"> => {
  const [state, setState] = useState({ id, text, done });

  return {
    getState: () => state,
    toggle: () => setState((s) => ({ ...s, done: !s.done })),
    remove: () => {}, // filled in by parent
  };
};

const TodoResource = resource(useTodoResource);

const useTodoListResource = (): ClientOutput<"todoList"> => {
  const [items, setItems] = useState([
    { id: "1", text: "Learn Store", done: false },
  ]);

  const todos = useClientLookup(
    items.map((item) => withKey(item.id, TodoResource(item))),
  );

  const state = useMemo(
    () => ({ todos: todos.state }),
    [todos.state],
  );

  return {
    getState: () => state,
    todo: (lookup) => todos.get(lookup),
    add: (text) =>
      setItems((prev) => [
        ...prev,
        { id: crypto.randomUUID(), text, done: false },
      ]),
  };
};

const TodoListResource = resource(useTodoListResource);
```

`useClientLookup` 返回 `{ state, get }`：
- `state`——每个子项的 `getState()` 结果组成的数组
- `get({ index })` 或 `get({ key })`——解析特定子项的方法

每个元素都必须通过 `withKey` 设置键。键可以让 Store 在重新渲染期间跟踪元素身份。

### 3. 使用 Derived 创建子作用域

`Derived` 会创建一个指向父级中某个项目的作用域：

```tsx title="app/TodoApp.tsx"
import { AuiConfig, AuiProvider, useAui, useAuiState, Derived } from "@assistant-ui/store";

const TodoApp = () => {
  const config = AuiConfig({ todoList: TodoListResource() });
  return (
    <AuiProvider config={config}>
      <TodoList />
    </AuiProvider>
  );
};

const TodoList = () => {
  const todos = useAuiState((s) => s.todoList.todos);
  return (
    <div>
      {todos.map((_, index) => (
        <TodoItem key={index} index={index} />
      ))}
    </div>
  );
};

const TodoItem = ({ index }: { index: number }) => {
  const aui = useAui();
  const config = AuiConfig({
    todo: Derived({
      source: "todoList",
      query: { index },
      get: (aui) => aui.todoList.todo({ index }),
    }),
  });
  return (
    <AuiProvider extends={aui} config={config}>
      <TodoDisplay />
    </AuiProvider>
  );
};
```

`Derived` 接受三个字段：
- `source`——父作用域名称
- `query`——查找参数（传递给 meta，用于调试和事件作用域划分）
- `get`——从父级解析子项方法的函数。它接收当前的 `aui` store，并且必须返回调用父级方法的结果

### 4. 使用子作用域

`AuiProvider` 内的组件现在可以像使用其他作用域一样使用 `todo` 作用域：

```tsx title="app/TodoDisplay.tsx"
const TodoDisplay = () => {
  const { text, done } = useAuiState((s) => s.todo);
  const aui = useAui();

  return (
    <label>
      <input
        type="checkbox"
        checked={done}
        onChange={() => aui.todo.toggle()}
      />
      {text}
    </label>
  );
};
```

`TodoDisplay` 不需要知道或关心 `todo` 是派生作用域——它使用 `useAuiState` 和 `useAui` 的方式与使用其他作用域完全相同。

## useClientResource

如果你的父级只需要暴露一个子项（而不是列表），可以直接使用 `useClientResource`：

```ts
import { useClientResource } from "@assistant-ui/store";

const useThreadResource = (): ClientOutput<"thread"> => {
  const composer = useClientResource(ComposerResource());

  return {
    getState: () => ({ ... }),
    composer: () => composer.methods,
  };
};

const ThreadResource = resource(useThreadResource);
```

`useClientResource` 会包装单个 resource 元素，并返回 `{ state, methods, key }`。`useClientLookup` 正是对每个元素在内部使用的方式。

## useClientList

对于用户可以添加和删除项目的动态列表，请使用 `useClientList`：

```ts
import { useClientList } from "@assistant-ui/store";
import { useState } from "react";

const useTodoItem = ({
  getInitialData,
  remove,
}: {
  getInitialData: () => { id: string; text: string; done: boolean };
  remove: () => void;
}): ClientOutput<"todo"> => {
  const [state, setState] = useState(getInitialData());

  return {
    getState: () => state,
    toggle: () => setState((s) => ({ ...s, done: !s.done })),
    remove,
  };
};

const TodoItemResource = resource(useTodoItem);

const useTodoListResource = (): ClientOutput<"todoList"> => {
  const todos = useClientList({
    initialValues: [{ id: "1", text: "Learn Store", done: false }],
    getKey: (item) => item.id,
    resource: TodoItemResource,
  });

  return {
    getState: () => ({ todos: todos.state }),
    todo: (lookup) => todos.get(lookup),
    add: (text) => todos.add({ id: crypto.randomUUID(), text, done: false }),
  };
};

const TodoListResource = resource(useTodoListResource);
```

`useClientList` 在 `useClientLookup` 的基础上扩展了变更功能：
- `add(data)`——向列表中添加新项目
- 每个子 resource 都会将 `{ key, getInitialData, remove }` 作为 props 接收
- `getInitialData()` 返回项目数据（在挂载时调用一次）
- `remove()` 从列表中移除项目
