Store (`@assistant-ui/store`) 将 Tap 资源连接到 React，并提供带作用域的类型安全状态管理。

## 安装

```sh
npm install @assistant-ui/store @assistant-ui/tap
```

## 定义作用域类型

通过扩展 `ScopeRegistry` 接口来注册作用域。这会为所有 Store hooks 提供类型安全。

```ts title="lib/store/counter-scope.ts"
import "@assistant-ui/store";

declare module "@assistant-ui/store" {
  interface ScopeRegistry {
    counter: {
      methods: {
        getState: () => { count: number };
        increment: () => void;
      };
    };
  }
}
```

## 创建资源

定义一个返回 `ClientOutput<"counter">` 的 Tap 资源。这会将资源的方法连接到你刚刚注册的作用域类型。

```ts title="lib/store/counter-store.ts"
import { resource } from "@assistant-ui/tap";
import { useState, useMemo } from "react";
import type { ClientOutput } from "@assistant-ui/store";

const useCounterResource = ({
  initialCount = 0,
}: {
  initialCount?: number;
}): ClientOutput<"counter"> => {
  const [count, setCount] = useState(initialCount);

  const state = useMemo(() => ({ count }), [count]);

  return {
    getState: () => state,
    increment: () => setCount((c) => c + 1),
  };
};

export const CounterResource = resource(useCounterResource);
```

## 在 React 中使用

使用 `AuiProvider` 创建 store 并将其提供给组件树，使用 `useAuiState` 订阅状态。

```tsx title="app/CounterApp.tsx"
"use client";

import { AuiConfig, AuiProvider } from "@assistant-ui/store";
import { CounterResource } from "@/lib/store/counter-store";
import { CounterDisplay } from "./CounterDisplay";

export const CounterApp = () => {
  const config = AuiConfig({ counter: CounterResource({ initialCount: 0 }) });
  return (
    <AuiProvider config={config}>
      <CounterDisplay />
    </AuiProvider>
  );
};
```

```tsx title="app/CounterDisplay.tsx"
"use client";

import { useAui, useAuiState } from "@assistant-ui/store";

export const CounterDisplay = () => {
  const count = useAuiState((s) => s.counter.count);
  const aui = useAui();

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => aui.counter.increment()}>+</button>
    </div>
  );
};
```

`useAuiState((s) => s.counter.count)` 只订阅 `count` 值，因此只有在该值发生变化时，组件才会重新渲染。

`aui.counter` 会公开作用域的方法，因此 `aui.counter.increment()` 会调用你在资源中定义的 `increment` 方法。
