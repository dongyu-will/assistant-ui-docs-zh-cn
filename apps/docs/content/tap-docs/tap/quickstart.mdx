## 安装

```sh
npm install @assistant-ui/tap
```

## 定义 Resource

使用你已经熟悉的 React Hooks 编写一个带有 `use` 前缀的 Hook，然后使用 `resource()` 将其封装：

```ts
import { resource } from "@assistant-ui/tap";
import { useState } from "react";

const useCounter = () => {
  const [count, setCount] = useState(0);

  return {
    count,
    increment: () => setCount((value) => value + 1),
  };
};

const Counter = resource(useCounter);
```

Resource 返回状态和方法，而不是 JSX。

## 在 React 中使用

`useResource` 会计算 Resource 并返回其当前值：

```tsx
import { useResource } from "@assistant-ui/tap";

function CounterButton() {
  const counter = useResource(Counter());

  return (
    <button onClick={counter.increment}>
      Count: {counter.count}
    </button>
  );
}
```

Resource 发生变化时，组件会重新渲染；组件卸载时，会清理 Resource。
