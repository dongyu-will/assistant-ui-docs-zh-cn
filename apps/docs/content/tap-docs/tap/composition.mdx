---
title: 组合
description: 将 Resource 组合成可复用的状态树。
---

Resource 将小型的有状态行为组合成更大的行为。父 Resource
渲染一个子 Resource，并直接接收其公共 API。它可以读取子 Resource 的状态、调用其方法、将其与其他
Resource 组合，或公开自己的新 API。

最终形成的是由多个职责聚焦的 Resource 组成的树，而不是一个单体式状态存储。

## useResource

Hook 调用会在调用位置固定其实现。`ResourceElement`
使该实现成为输入，因此 Resource 可以接收另一个 Resource 作为配置，并渲染所提供的实现：

```ts
import {
  resource,
  useResource,
  type ResourceElement,
} from "@assistant-ui/tap";

type CounterState = ReturnType<typeof useCounter>;

const useMockCounter = (count: number): CounterState => ({
  count,
  increment: () => undefined,
});

const MockCounter = resource(useMockCounter);

const useLimitedCounter = ({
  counter,
  max,
}: {
  counter: ResourceElement<CounterState>;
  max: number;
}) => {
  const state = useResource(counter);
  const isAtLimit = state.count >= max;

  return {
    count: state.count,
    isAtLimit,
    increment: () => {
      if (!isAtLimit) state.increment();
    },
  };
};

const LimitedCounter = resource(useLimitedCounter);
```

调用方选择计数器实现：

```ts
const counter = isDemo
  ? MockCounter(5)
  : Counter({ initialValue: 0 });

const limitedCounter = LimitedCounter({ counter, max: 10 });
```

`LimitedCounter`负责限制行为，而调用方决定计数的来源。它接受任何返回
`CounterState` 的 Resource。

配置的 Resource 发生变化时，`useResource`会卸载之前的实现并挂载下一个实现。`useResource`
调用本身仍处于相同位置，因此无需让 Hook 调用变为条件调用，即可动态选择实现。

## useResources

当 Resource 拥有动态集合时，请使用`useResources`：

```ts
import { resource, withKey, useResources } from "@assistant-ui/tap";

const useCounterList = (ids: readonly string[]) => {
  const counters = useResources(
    ids.map((id) => withKey(id, Counter({ initialValue: 0 }))),
  );

  return {
    counters,
    total: counters.reduce((sum, counter) => sum + counter.count, 0),
  };
};

const CounterList = resource(useCounterList);
```

集合中的每个元素都需要唯一的 key。`withKey`为每个子 Resource 提供稳定的身份，因此集合重新排序时，状态会跟随 key：

```ts
CounterList(["a", "b", "c"]);
CounterList(["c", "a", "b"]);
```

移除某个 key 会卸载对应的 Resource。使用不同的 Resource 实现复用某个 key，会替换旧的 Resource 及其状态。

## 组合会创建所有权

渲染 Resource 会使其成为当前 Resource 的子 Resource：

```text
LimitedCounter
└── Counter or MockCounter

CounterList
├── Counter key="a"
├── Counter key="b"
└── Counter key="c"
```

子 Resource 会随其父 Resource 一起挂载和卸载。Effects 会按照 Resource 的渲染顺序运行。详情请参阅
[Effect ordering](/tap/docs/tap/differences-from-react#effects-run-in-call-order)。

组合不会创建新的调度器。`useResource`和`useResources`
仍属于当前 Resource 树的一部分，因此更新可以传播到根节点。若要引入独立的调度边界，请使用
[`useTapRoot`](/tap/docs/tap/trees-and-rerenders#separate-scheduling-with-usetaproot)。
