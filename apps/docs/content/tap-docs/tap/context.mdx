---
title: 上下文
description: 在资源边界之间传递值，无需逐层传递 prop。
---

<Callout type="info">
Tap 上下文从 `@assistant-ui/tap` 0.9 版本开始受支持，现已不再弃用。
</Callout>

上下文允许你在资源树中传递值，而无需在每一层之间逐层传递 prop，这与 React 的 `createContext` / `useContext` 思路相同。

## createContext

使用默认值创建上下文。

```ts
import { createContext } from "react";

const ThemeContext = createContext("light");
```

## 读取上下文

在资源中使用从 `"react"` 导入的 `use` 读取上下文的当前值。

```ts
import { use } from "react";

const useButton = () => {
  const theme = use(ThemeContext);
  // ...
};

const Button = resource(useButton);
```

## useContextProvider

向回调函数中渲染的所有资源提供上下文值。

```ts
import { useContextProvider, useResource } from "@assistant-ui/tap";

const useApp = () => {
  const child = useContextProvider(ThemeContext, "dark", () => {
    return useResource(Button());
  });

  return child;
};

const App = resource(useApp);
```

在回调函数中渲染的任何资源（包括深层嵌套的子元素）都可以从 `ThemeContext` 读取 `"dark"`。
