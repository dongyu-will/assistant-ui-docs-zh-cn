---
title: 资源
description: 将有状态行为封装为可复用、可配置的值。
---

**Resource（资源）** 将有状态行为封装在一个 JavaScript 值之后。它使用输入进行渲染，在多次渲染之间保留 Hook 状态，挂载副作用，并在卸载时进行清理。

它的返回值就是其公共 API：无论 Resource 在何处渲染，都可以使用其中的状态和方法。

## 将 Hook 封装为 Resource

从一个普通的 Hook 开始，然后将其传递给 `resource()`：

```ts
import { resource } from "@assistant-ui/tap";
import { useState } from "react";

const useCounter = (props: { initialValue?: number }) => {
  const [count, setCount] = useState(props.initialValue ?? 0);

  return { count, increment: () => setCount((c) => c + 1) };
};

const Counter = resource(useCounter);
```

`useCounter` 包含实现。`Counter` 是可复用的 Resource。
请将实现放在以 `use` 为前缀的 Hook 中，以便 React 的 Hooks 规则能够正常检查它。

调用 Resource 会对其进行配置：

```ts
const counter = Counter({ initialValue: 10 });
```

这不会运行 `useCounter`，也不会创建状态。它会返回一个描述待渲染内容的惰性
`ResourceElement`，这与 React 渲染组件之前，JSX 对组件的描述方式非常相似。

## 配置就是一个值

由于配置后的 Resource 是一个值，应用可以在创建任何状态之前选择、传递并嵌套它：

```tsx
import { useResource, type ResourceElement } from "@assistant-ui/tap";

type CounterState = ReturnType<typeof useCounter>;

function CounterButton({
  counter = Counter({ initialValue: 0 }),
}: {
  counter?: ResourceElement<CounterState>;
}) {
  const state = useResource(counter);

  return <button onClick={state.increment}>{state.count}</button>;
}
```

组件负责决定状态在哪里渲染，但不负责其实现或配置。调用方可以使用默认 Resource，也可以提供任何返回相同 API 的其他 Resource。

## 承载 Resource

使用 `useResource` 渲染单个 Resource，或使用
[`useResources`](/tap/docs/tap/composition#useresources) 渲染 Resource 的带键列表。

```tsx
import { useResource } from "@assistant-ui/tap";

function CounterButton() {
  const { count, increment } = useResource(Counter({ initialValue: 10 }));
  return <button onClick={increment}>Count: {count}</button>;
}
```

渲染会创建 Resource 的状态，并返回其当前的公共 API。在 React 组件中，状态发生变化时组件会重新渲染，而 Resource 会随组件一起卸载。在另一个 Resource 内部，它会成为同一资源树中的子节点。

多次渲染之间可以更改参数，而不会替换 Resource 的状态。副作用会通过其依赖数组作出响应，这与 React 组件中的行为相同。
