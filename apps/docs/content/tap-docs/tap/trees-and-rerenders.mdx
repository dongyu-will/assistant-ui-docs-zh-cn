## 资源树

使用 `useResource` 或 `useResources` 组合的资源会形成一棵树：

```
createTapRoot(function AppRoot() { return useResource(App()); })  <- tree root
  ├─ useResource(Sidebar)
  │    └─ useResource(NavItem)
  └─ useResource(Main)
       ├─ useResource(Header)
       └─ useResources([...Items])
```

## 重新渲染

在 React 中，状态变化会重新渲染拥有该状态的组件及其子组件。
父组件不会受到影响。

在 tap 中，父资源会直接读取资源的返回值。当子资源发生变化时，其父资源必须重新渲染才能接收新值。这个过程会沿着资源树向上继续，因此**整个资源树都会从根节点开始重新渲染**。

`useResource` 和 `useResources` 会将子资源组合到现有树中。它们不会创建调度边界。

## 使用 useTapRoot 分离调度

`useTapRoot` 不会将另一个子资源组合到当前树中，而是创建一个拥有独立 tap 调度器的新资源根：

```ts
import { useResource, useTapRoot } from "@assistant-ui/tap";

const useCounterRoot = () =>
  useTapRoot(function CounterRoot() {
    return useResource(Counter());
  });
```

`CounterRoot` 内部的更新只会调度该根节点。外部树不会重新渲染。由于调用方不再通过渲染接收更新，`useTapRoot` 会返回一个稳定的 `{ getValue, subscribe }` 句柄，而不是渲染值。

| | `useResource` / `useResources` | `useTapRoot` |
| --- | --- | --- |
| 树 | 将子资源添加到当前树 | 启动一棵新树 |
| 调度器 | 继承当前根节点的调度器 | 创建一个 tap 调度器 |
| 更新时 | 当前树重新渲染 | 只有新的根节点重新渲染 |
| 结果 | 子资源的当前值 | 一个稳定的 `{ getValue, subscribe }` 句柄 |

使用 `getValue()` 读取最新的已提交值，并使用 `subscribe()` 观察变化：

```ts
const counter = useCounterRoot();

counter.getValue();

const unsubscribe = counter.subscribe(() => {
  console.log(counter.getValue());
});
```

创建根节点不会让创建它的组件订阅该根节点。React 组件可以使用 `useSyncExternalStore` 渲染根节点的值：

```tsx
import { useSyncExternalStore } from "react";

function CounterView() {
  const counter = useCounterRoot();
  const state = useSyncExternalStore(
    counter.subscribe,
    counter.getValue,
    counter.getValue,
  );

  return <button onClick={state.increment}>{state.count}</button>;
}
```

该根节点仍归调用 `useTapRoot` 的组件或资源所有，并会随所有者一起卸载。

## 树根与调度

每棵树都有一个根节点，用于决定更新的调度和传递方式：

| API | 新建调度器？ | 更新通过何种方式传递 |
| --- | --- | --- |
| `useResource` / `useResources` | 否 | 当前根节点的渲染 |
| `useTapRoot` | 是，一个 tap 调度器 | `subscribe()` |
| `createTapRoot` | 是，一个 tap 调度器 | `subscribe()` |

tap 调度器会在渲染其根节点之前，将多个状态变化批量处理。

### flushTapSync

`flushTapSync` 允许你同步刷新待处理的 tap 调度器更新。

```ts
import { flushTapSync } from "@assistant-ui/tap";

flushTapSync(() => {
  handle.getValue().increment();
});

// state is already updated here
console.log(handle.getValue().count);
```

这适用于由 `createTapRoot` 或 `useTapRoot` 创建的 tap 调度根节点。
对于由 React 调度的树，请使用 `flushSync`（来自 `react-dom`）。
