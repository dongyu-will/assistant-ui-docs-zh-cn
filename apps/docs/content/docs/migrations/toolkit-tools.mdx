---
title: 将工具迁移到工具包
description: 将 makeAssistantTool、useAssistantTool、makeAssistantToolUI 和 useAssistantToolUI 注册迁移到工具包 API。
---

基于组件和 Hook 的工具 API 已弃用：

- `makeAssistantTool`
- `useAssistantTool`
- `makeAssistantToolUI`
- `useAssistantToolUI`

请改用通过 `Tools({ toolkit })` 注册的工具包。工具包将模型契约、浏览器执行逻辑和工具调用渲染集中在一个命名映射中，从而避免重复注册，并明确客户端与后端的分工。

## 之前

```tsx
import { AssistantRuntimeProvider, makeAssistantTool } from "@assistant-ui/react";
import { useChatRuntime } from "@assistant-ui/ai-sdk";
import { z } from "zod";

const WeatherTool = makeAssistantTool({
  toolName: "get_weather",
  description: "Get the current weather for a city.",
  parameters: z.object({
    city: z.string(),
  }),
  execute: async ({ city }) => fetchWeather(city),
  render: ({ args, result }) => (
    <WeatherCard city={args.city} weather={result} />
  ),
});

export function App() {
  const runtime = useChatRuntime();

  return (
    <AssistantRuntimeProvider runtime={runtime}>
      <WeatherTool />
      <Thread />
    </AssistantRuntimeProvider>
  );
}
```

## 之后

```tsx title="app/toolkit.tsx"
"use generative";

import { defineToolkit } from "@assistant-ui/react";
import { z } from "zod";

export default defineToolkit({
  get_weather: {
    description: "Get the current weather for a city.",
    parameters: z.object({
      city: z.string(),
    }),
    execute: async ({ city }) => {
      "use client";
      return fetchWeather(city);
    },
    render: ({ args, result }) => (
      <WeatherCard city={args.city} weather={result} />
    ),
  },
});
```

```tsx title="app/MyRuntimeProvider.tsx"
"use client";

import {
  AssistantRuntimeProvider,
  AuiConfig,
  Tools,
} from "@assistant-ui/react";
import { useChatRuntime } from "@assistant-ui/ai-sdk";
import toolkit from "./toolkit";

export function App() {
  const runtime = useChatRuntime();
  const config = AuiConfig({ tools: Tools({ toolkit }) });

  return (
    <AssistantRuntimeProvider runtime={runtime} config={config}>
      <Thread />
    </AssistantRuntimeProvider>
  );
}
```

`useChatRuntime()` 默认指向 `/api/chat`。如需指向其他端点或自定义请求，请参阅[自定义传输层](/docs/runtimes/ai-sdk/v7#custom-transport)。

## 机械迁移步骤

1. 创建一个 `Toolkit` 对象。
2. 将每个 `toolName` 移入工具包键。
3. 将 `description`、`parameters`、`execute`、`providerOptions`、`render`、`renderText` 和 `display` 移到工具包条目中。
4. 在运行时提供程序上使用 `config={config}` 注册一次工具包，其中 `const config = AuiConfig({ tools: Tools({ toolkit }) })`。
5. 移除 `<Tool />`、`<ToolUI />`、`useAssistantTool(...)` 和 `useAssistantToolUI(...)` 注册。

## 仅限 UI 的工具渲染器

如果你曾使用 `makeAssistantToolUI` 或 `useAssistantToolUI` 来处理后端、MCP 或
LangGraph 工具，则工具会在其他位置执行。建议使用带有 `execute: externalTool()` 的
`"use generative"` 工具包，让编译器省略服务器条目，同时客户端仍将你的渲染器保留为 `type: "backend"`：

```tsx
// app/toolkit.tsx
"use generative";

import { defineToolkit, externalTool } from "@assistant-ui/react";

export default defineToolkit({
  web_search: {
    execute: externalTool(),
    render: ({ args, result }) => (
      <SearchResults query={args.query} results={result?.results ?? []} />
    ),
  },
});
```

像注册其他工具包一样注册它：`config={config}`，其中 `const config = AuiConfig({ tools: Tools({ toolkit }) })`。
仅渲染条目不会上传架构，也不会运行浏览器代码——它们只会为匹配的工具调用消息部分附加
UI。对于 MCP 服务器目录，请在同一个生成式工具包中展开
`defineMcpToolkit({ ... })`。

如果只希望一次性渲染器影响特定的消息界面，请使用 `MessagePrimitive.Parts` 内联工具渲染覆盖，而不是进行全局注册。

## 动态工具

如果工具需要组件状态或 props，请将工具包契约保存在 `"use generative"` 文件中，并使用
`stubTool()` 作为执行器。拥有该状态的组件通过 `useAuiToolOverrides(...)` 提供真正的执行器：

<Callout type="warn">
  `useAuiToolOverrides` 为实验性 API，可能会发生变化。
</Callout>

```tsx title="task-board-toolkit.tsx"
"use generative";

import { defineToolkit, stubTool } from "@assistant-ui/react";
import { z } from "zod";

export type Task = { id: string; title: string };

export default defineToolkit({
  add_task: {
    description: "Add a task to the board.",
    parameters: z.object({ title: z.string() }),
    execute: stubTool(),
    renderText: {
      running: "Adding task",
      complete: "Task added",
    },
  },
});
```

```tsx title="TaskBoard.tsx"
import {
  AuiConfig,
  AuiProvider,
  Tools,
  useAui,
  useAuiToolOverrides,
} from "@assistant-ui/react";
import { useState, type Dispatch, type SetStateAction } from "react";
import type { Task } from "./task-board-toolkit";
import toolkit from "./task-board-toolkit";

function TaskBoard() {
  const [tasks, setTasks] = useState<Task[]>([]);
  const aui = useAui();
  const config = AuiConfig({ tools: Tools({ toolkit }) });

  return (
    <AuiProvider extends={aui} config={config}>
      <TaskBoardToolOverrides setTasks={setTasks} />
      <TaskList tasks={tasks} />
    </AuiProvider>
  );
}

function TaskBoardToolOverrides({
  setTasks,
}: {
  setTasks: Dispatch<SetStateAction<Task[]>>;
}) {
  useAuiToolOverrides({
    add_task: {
      execute: async ({ title }) => {
        setTasks((prev) => [
          ...prev,
          { id: crypto.randomUUID(), title },
        ]);
        return { ok: true };
      },
    },
  });
  return null;
}
```

这样，面向模型的契约会保留在工具包文件中，而组件负责管理有状态的执行器。

## 生成式工具包

对于在 `"use generative"` 文件中编写的工具，请使用 `defineToolkit(...)` 导出工具包。编译器会自动为你拆分后端、前端和人在回路工具。这是文档和复制粘贴示例应采用的默认形式：

```tsx
"use generative";

import { defineToolkit } from "@assistant-ui/react";
import { z } from "zod";

export default defineToolkit({
  create_chart: {
    description: "Create a chart for the user.",
    parameters: z.object({
      title: z.string(),
      values: z.array(z.number()),
    }),
    execute: async ({ title, values }) => {
      "use client";
      return renderChart(title, values);
    },
    render: ChartTool,
  },
});
```

生成式编译器生成的前端工具和人在回路工具已经在后端设置了架构默认值，因此客户端不再重复上传这些架构。
