## 概览

本指南介绍如何使用 assistant-ui 的运行时系统和预构建 UI 组件，将 Assistant Cloud 与 [AI SDK](https://sdk.vercel.ai/) 集成。

## 你将获得的功能

此集成提供：

- **`<Thread />`** — 完整的聊天界面，包含消息、输入框和状态指示器
- **`<ThreadList />`** — 显示所有会话的侧边栏，支持自动生成标题，以及新建、删除和管理操作
- **自动持久化** — 消息会在流式传输过程中保存。首次发送消息时会自动创建线程。
- **运行时集成** — assistant-ui 运行时会在后台处理所有云端同步。

## 工作原理

`@assistant-ui/ai-sdk` 中的 `useChatRuntime` hook（钩子）封装了 AI SDK 的 `useChat`，并通过 `cloud` 参数添加云端持久化功能。`AISDKThreads({ cloud })` 是面向 `AuiConfig` / `createAssistantClient` 宿主的存储条目列表。该宿主只挂载可见的线程，因此切换线程会取消正在进行的运行。运行时会自动：

1. 在用户发送第一条消息时创建云端线程
2. 在消息完成流式传输后持久化消息
3. 在助手首次响应后生成对话标题
4. 通过 `<ThreadList />` 切换线程时加载历史消息

你只需提供云端配置，其余工作都会自动处理。默认的 `AssistantChatTransport` 会自动将请求发送到 `/api/chat`。

<PlatformTabs>

```tsx title="app/chat/page.tsx"
"use client";

import { useMemo } from "react";
import { AssistantCloud, AssistantRuntimeProvider } from "@assistant-ui/react";
import { useChatRuntime } from "@assistant-ui/ai-sdk";
import { ThreadList } from "@/components/assistant-ui/elements/thread-list.aui";
import { Thread } from "@/components/assistant-ui/elements/thread.aui";

export default function ChatPage() {
  const cloud = useMemo(
    () =>
      new AssistantCloud({
        baseUrl: process.env.NEXT_PUBLIC_ASSISTANT_BASE_URL!,
        anonymous: true, // Creates browser-session based user ID
      }),
    [],
  );

  const runtime = useChatRuntime({
    cloud,
  });

  return (
    <AssistantRuntimeProvider runtime={runtime}>
      <div className="grid h-dvh grid-cols-[200px_1fr] gap-x-2 px-4 py-4">
        <ThreadList />
        <Thread />
      </div>
    </AssistantRuntimeProvider>
  );
}
```

## 遥测

`useChatRuntime` Hook 会捕获完整的运行遥测数据，包括时间信息。它与 assistant-ui 运行时集成，可提供：

**自动捕获：**
- `status` — `"completed"`、`"incomplete"` 或 `"error"`
- `duration_ms` — 运行总时长（在客户端测量）
- `steps` — 每个步骤的详细信息，包括时间、使用情况和工具调用
- `tool_calls` — 工具调用，包括名称、参数、结果和来源
- `total_steps` — 推理/工具步骤的数量
- `output_text` — 完整的响应文本（截断至 50K 个字符）

**需要进行路由配置：**
- `model_id` — 使用的模型
- `input_tokens` / `output_tokens` — Token 使用统计

如需捕获模型和使用情况数据，请将 `messageMetadata` 回调添加到 AI SDK 路由中：

```tsx title="app/api/chat/route.ts"
import { streamText } from "ai";
import { openai } from "@ai-sdk/openai";

export async function POST(req: Request) {
  const { messages } = await req.json();

  const result = streamText({
    model: openai("gpt-5.6-luna"),
    messages,
  });

  return result.toUIMessageStreamResponse({
    messageMetadata: ({ part }) => {
      if (part.type === "finish") {
        return {
          usage: part.totalUsage,
        };
      }
      if (part.type === "finish-step") {
        return {
          modelId: part.response.modelId,
        };
      }
      return undefined;
    },
  });
}
```

如果没有此配置，遥测报告中将不会包含模型和 Token 数据。

### 自定义报告

使用 `beforeReport` Hook 添加自定义元数据或过滤报告：

```tsx
const cloud = new AssistantCloud({
  baseUrl: process.env.NEXT_PUBLIC_ASSISTANT_BASE_URL!,
  anonymous: true,
  telemetry: {
    beforeReport: (report) => ({
      ...report,
      metadata: { userTier: "pro", region: "us-east" },
    }),
  },
});
```

从 `beforeReport` 返回 `null`，即可跳过特定运行的报告。要完全禁用遥测，请传入 `telemetry: false`。

### 子代理模型跟踪

当工具调用委托给其他模型时（例如，主运行使用 GPT，但某个工具调用 Gemini），你可以跟踪受委托模型的使用情况。在 API 路由中通过 `messageMetadata.samplingCalls` 传递采样调用数据，遥测报告器会自动将其包含在报告中。

请参阅 [AI SDK 遥测指南](/docs/cloud/ai-sdk#sub-agent-model-tracking)，了解使用 `createSamplingCollector` 和 `wrapSamplingHandler` 的完整配置方法。

上面的 React 示例使用匿名模式，以便快速演示。对于带有用户账户的生产应用，请传入一个显式的云实例，并使用身份验证提供商提供的令牌：

```tsx
import { useMemo } from "react";
import { useAuth } from "@clerk/nextjs";

import { useChatRuntime } from "@assistant-ui/ai-sdk";

function Chat() {
  const { getToken } = useAuth();

  const cloud = useMemo(() => new AssistantCloud({
    baseUrl: process.env.NEXT_PUBLIC_ASSISTANT_BASE_URL!,
    authToken: async () => getToken({ template: "assistant-ui" }),
  }), [getToken]);

  const runtime = useChatRuntime({ cloud });
  // ...
}
```
