Assistant Cloud API 直接从前端访问。除授权用户外，大多数操作都不再需要后端服务器。

本指南介绍如何为 Assistant Cloud 设置用户身份验证和授权。

## 工作区

授权授予给一个**工作区**。工作区是包含线程和消息的作用域。常见用法包括：

- 使用 `userId` 作为个人聊天的工作区
- 使用 `orgId + userId` 处理组织范围内的对话
- 使用 `projectId + userId` 构建基于项目的应用

## 身份验证方式

选择适合你的应用的方式：

| 方式 | 适用场景 | 复杂度 |
|----------|----------|------------|
| **直接集成身份验证提供商** | 受支持的提供商（Clerk、Auth0、Supabase 等） | 低 |
| **后端服务器** | 自定义身份验证、多用户工作区或自托管解决方案 | 中 |
| **匿名模式** | 演示、原型或测试 | 无 |

### 直接集成身份验证提供商

在 Assistant Cloud 控制台中，前往 **Auth Integrations** 并添加你的提供商。这会根据身份验证提供商返回的用户 ID 自动分配工作区。

然后传入一个 `authToken` 函数，使其返回提供商的 ID 令牌：

```ts
import { AssistantCloud } from "@assistant-ui/react";

const cloud = new AssistantCloud({
  baseUrl: process.env.NEXT_PUBLIC_ASSISTANT_BASE_URL!,
  authToken: () => getTokenFromYourProvider(), // Returns JWT
});
```

### 后端服务器方式

当你需要自定义工作区逻辑或使用不受支持的身份验证提供商时，可以采用此方式。

<Steps>
<Step>

#### 创建 API 密钥

在 Assistant Cloud 控制台中，前往 **API Keys** 并创建密钥。将其添加到环境中：

```bash
ASSISTANT_API_KEY=your_key_here
```

</Step>
<Step>

#### 创建令牌端点

```ts title="/app/api/assistant-ui-token/route.ts"
import { AssistantCloud } from "assistant-cloud";
import { auth } from "@clerk/nextjs/server"; // Or your auth provider

export const POST = async (req: Request) => {
  const { userId, orgId } = await auth();

  if (!userId) return new Response("Unauthorized", { status: 401 });

  // Define your workspace ID based on your app's structure
  const workspaceId = orgId ? `${orgId}_${userId}` : userId;

  const assistantCloud = new AssistantCloud({
    apiKey: process.env.ASSISTANT_API_KEY!,
    userId,
    workspaceId,
  });

  const { token } = await assistantCloud.auth.tokens.create();
  return new Response(token);
};
```

</Step>
<Step>

#### 在前端使用令牌

```tsx title="app/chat/page.tsx"
const cloud = new AssistantCloud({
  baseUrl: process.env.NEXT_PUBLIC_ASSISTANT_BASE_URL!,
  authToken: () =>
    fetch("/api/assistant-ui-token", { method: "POST" }).then((r) => r.text()),
});

const runtime = useChatRuntime({
  cloud,
});
```

</Step>
</Steps>

### 匿名模式（无身份验证）

对于演示或测试，可以使用匿名模式创建基于浏览器会话的用户：

```tsx
import { AssistantCloud } from "@assistant-ui/react";

const cloud = new AssistantCloud({
  baseUrl: process.env.NEXT_PUBLIC_ASSISTANT_BASE_URL!,
  anonymous: true,
});
```

<Callout type="warning">
  匿名模式会为每个浏览器会话创建一个新用户。线程不会在不同会话或设备之间保留。仅将此模式用于原型开发。
</Callout>

## 身份验证提供商示例

### Clerk

<Steps>
<Step>

#### 配置 JWT 模板

在 Clerk 控制台中，前往 **Configure → JWT Templates**。创建一个名为“assistant-ui”的新空白模板：

```json
{
  "aud": "assistant-ui"
}
```

<Callout type="info">
  `aud` 声明可确保 JWT 仅对 Assistant Cloud 有效。
</Callout>

记下 **Issuer** 和 **JWKS Endpoint** 的值。

</Step>
<Step>

#### 在 Assistant Cloud 中添加身份验证集成

在 Assistant Cloud 控制台中，前往 **Auth Rules** 并创建新规则：

- **Provider**：Clerk
- **Issuer**：从 Clerk JWT Template 中粘贴
- **JWKS Endpoint**：从 Clerk JWT Template 中粘贴
- **Audience**：`assistant-ui`

</Step>
<Step>

#### 在应用中使用

```tsx
import { useAuth } from "@clerk/nextjs";
import { AssistantCloud } from "@assistant-ui/react";

function Chat() {
  const { getToken } = useAuth();

  const cloud = useMemo(
    () =>
      new AssistantCloud({
        baseUrl: process.env.NEXT_PUBLIC_ASSISTANT_BASE_URL!,
        authToken: () => getToken({ template: "assistant-ui" }),
      }),
    [getToken],
  );

  // Use with your runtime...
}
```

</Step>
</Steps>

### Auth0

```tsx
import { useAuth0 } from "@auth0/auth0-react";
import { AssistantCloud } from "@assistant-ui/react";

function Chat() {
  const { getAccessTokenSilently } = useAuth0();

  const cloud = useMemo(
    () =>
      new AssistantCloud({
        baseUrl: process.env.NEXT_PUBLIC_ASSISTANT_BASE_URL!,
        authToken: () => getAccessTokenSilently(),
      }),
    [getAccessTokenSilently],
  );

  // Use with your runtime...
}
```

在 Assistant Cloud 控制台中，使用你的 Auth0 域名和 audience 配置 Auth0 集成。

### Supabase Auth

```tsx
import { useSupabaseClient } from "@supabase/auth-helpers-react";
import { AssistantCloud } from "@assistant-ui/react";

function Chat() {
  const supabase = useSupabaseClient();

  const cloud = useMemo(
    () =>
      new AssistantCloud({
        baseUrl: process.env.NEXT_PUBLIC_ASSISTANT_BASE_URL!,
        authToken: async () => {
          const { data } = await supabase.auth.getSession();
          return data.session?.access_token ?? "";
        },
      }),
    [supabase],
  );

  // Use with your runtime...
}
```

### Firebase Auth

```tsx
import { getAuth, getIdToken } from "firebase/auth";
import { AssistantCloud } from "@assistant-ui/react";

function Chat() {
  const cloud = useMemo(() => {
    const auth = getAuth();
    return new AssistantCloud({
      baseUrl: process.env.NEXT_PUBLIC_ASSISTANT_BASE_URL!,
      authToken: () => getIdToken(auth.currentUser!, true),
    });
  }, []);

  // Use with your runtime...
}
```
