Assistant Cloud 是一项托管服务，可为 AI 聊天应用添加线程管理、消息持久化和用户授权功能。它适用于任何 React UI——无论你使用 assistant-ui 组件，还是自行构建 UI。

## 你将获得什么

- **线程持久化** — 随着对话进行，消息会自动保存。用户可以随时继续聊天，即使跨越多个会话也不受影响。
- **线程列表** — 提供用于浏览、切换和管理对话的内置 UI 组件（或 hooks）。
- **自动生成标题** — 根据初始消息，为对话生成有意义的标题。
- **用户授权** — 与你的身份验证提供商集成，按用户或工作区限定线程范围。

## 支持的后端

| 后端 | 独立模式 | 与 assistant-ui 配合 |
|---------|----------------|-------------------|
| AI SDK | [`useCloudChat`](/docs/cloud/ai-sdk) | [`useChatRuntime`](/docs/cloud/ai-sdk-assistant-ui) / `AISDKThreads` |
| LangGraph | — | [`useLangGraphRuntime`](/docs/cloud/langgraph) |
| Custom | — | 本地运行时 |

## 开始使用

<Callout type="info">
  你需要一个 Assistant Cloud 账户。[在此注册](https://cloud.assistant-ui.com/) 以创建项目。

  在项目设置中，复制 **Frontend API URL**（`https://proj-[ID].assistant-api.com`）——你将在下面的指南中用到它。
</Callout>

### 选择集成路径

**使用 AI SDK 和你自己的 UI？**
→ 按照 [AI SDK 指南](/docs/cloud/ai-sdk)使用 `useCloudChat` hook。只需一个 hook，即可对现有代码进行最少的修改。

**想要使用 `<Thread />` 和 `<ThreadList />` 这样的预构建组件？**
→ 按照 [AI SDK + assistant-ui 指南](/docs/cloud/ai-sdk-assistant-ui)操作，使用支持云端持久化的完整 UI 组件。

**使用 LangGraph？**
→ 按照 [LangGraph 指南](/docs/cloud/langgraph)操作，集成由云端支持的 LangGraph Cloud。
