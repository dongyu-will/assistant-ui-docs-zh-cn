## 概览

本指南介绍如何使用 assistant-ui 的运行时系统和预构建 UI 组件，将 Assistant Cloud 与 [LangGraph Cloud](https://docs.langchain.com/langsmith/deploy-to-cloud-overview) 集成。

## 前置条件

<Callout type="info">
  你需要一个 Assistant Cloud 账户才能按照本指南操作。[点击此处注册
  ](https://cloud.assistant-ui.com/) 开始使用。
</Callout>

### 创建运行时提供程序

创建一个将 LangGraph 与 assistant-cloud 集成的运行时提供程序。对于演示或原型，可以选择匿名模式；对于生产环境，则应选择经过身份验证的模式：

<PlatformTabs>
<Tab value="React">

<Tabs items={["Anonymous", "Authenticated (Clerk)"]}>

<Tab value="Anonymous">

```tsx title="app/chat/runtime-provider.tsx"
"use client";

import {
  AssistantCloud,
  AssistantRuntimeProvider,
} from "@assistant-ui/react";
import { useLangGraphRuntime } from "@assistant-ui/react-langgraph";
import { createThread, deleteThread, getThreadState, sendMessage } from "@/lib/chatApi";
import { LangChainMessage } from "@assistant-ui/react-langgraph";
import { useMemo } from "react";

export function MyRuntimeProvider({
  children,
}: Readonly<{
  children: React.ReactNode;
}>) {
  const cloud = useMemo(
    () =>
      new AssistantCloud({
        baseUrl: process.env.NEXT_PUBLIC_ASSISTANT_BASE_URL!,
        anonymous: true, // Creates browser session-based user ID
      }),
    [],
  );

  const runtime = useLangGraphRuntime({
    cloud,
    stream: async function* (messages, { initialize }) {
      const { externalId } = await initialize();
      if (!externalId) throw new Error("Thread not found");

      return sendMessage({
        threadId: externalId,
        messages,
      });
    },
    create: async () => {
      const { thread_id } = await createThread();
      return { externalId: thread_id };
    },
    load: async (externalId) => {
      const state = await getThreadState(externalId);
      return {
        messages:
          (state.values as { messages?: LangChainMessage[] }).messages ?? [],
      };
    },
    delete: async (externalId) => {
      await deleteThread(externalId);
    },
  });

  return (
    <AssistantRuntimeProvider runtime={runtime}>
      {children}
    </AssistantRuntimeProvider>
  );
}
```

<Callout type="info">
  `useLangGraphRuntime` 钩子接受 `cloud`、`create`、`load` 和 `delete` 参数，以简化线程管理。运行时会在内部处理线程生命周期。

  - **`create`**：创建新线程时调用。返回包含后端线程 ID 的 `{ externalId }`。
  - **`load`**：切换到现有线程时调用。返回该线程的消息（以及可选的中断）。
  - **`delete`**：删除线程时调用。接收线程的 `externalId`。提供此参数后，用户便可以在线程列表 UI 中删除线程。
</Callout>

## 身份验证

React 运行时提供器标签页展示了两种身份验证模式：

- **匿名**：适用于 React 演示和原型。会创建基于浏览器会话的用户 ID。
- **已验证**：适用于带有用户账户的生产环境。已验证示例使用 [Clerk](https://clerk.com/),

React Native 和 React Ink 标签页使用显式的 `authToken` 回调，这是浏览器会话身份验证演示之外推荐使用的形式。

如需了解其他身份验证提供商或自定义实现，请参阅[云授权](/docs/cloud/authorization)指南。
