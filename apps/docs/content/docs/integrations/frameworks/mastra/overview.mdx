[Mastra](https://mastra.ai/) 是一个开源的 TypeScript 智能体框架。它为 AI 应用提供了多种原语：支持记忆和工具调用的智能体、确定性的 LLM 工作流、RAG、模型路由、工作流图以及自动化评估。

<Callout type="info">
这是一份集成指南，而不是运行时适配器。assistant-ui 不提供 `@assistant-ui/react-mastra` 包。你可以通过标准的 [AI SDK 运行时](/docs/runtimes/ai-sdk/v7)接入 Mastra，让 API 端点通过 Mastra 的智能体流处理请求。
</Callout>

## 选择一种模式

| 模式 | 适用场景 |
| --- | --- |
| [全栈](/docs/integrations/frameworks/mastra/full-stack) | 单个 Next.js 应用：API 路由在进程内调用 Mastra。部署更简单，代码库也更集中。 |
| [独立服务器](/docs/integrations/frameworks/mastra/separate-server) | Mastra 作为独立服务运行；Next.js 前端调用其 API。支持独立扩展，职责分离更清晰。 |

两种模式都使用来自 [`@assistant-ui/ai-sdk`](/docs/runtimes/ai-sdk/v7) 的相同客户端 `useChatRuntime`。唯一的区别在于 Mastra 智能体的运行位置。

## 架构

Mastra 在服务器端的 LLM 客户端层进行集成。assistant-ui 通过 AI SDK 运行时与 API 路由通信；该路由调用 `agent.stream(messages)`，并将结果封装在 UI 消息流中返回。客户端则通过 AI SDK 适配器构建于 [`ExternalStoreRuntime`](/docs/runtimes/custom/external-store) 之上。

共享适配器（附件、语音、反馈、历史记录）的工作方式与 [适配器](/docs/runtimes/concepts/adapters)中所述相同。多线程支持使用 [AssistantCloud](/docs/cloud) 或[自定义线程列表](/docs/runtimes/concepts/threads)。

## 要求

- 一个 Next.js 项目，或其他能够运行 AI SDK 路由处理程序的框架。
- 在环境中配置模型 API 密钥（OpenAI、Anthropic 等）。
- Node 18 或更高版本。
