在 Next.js 应用中以内进程方式运行 Mastra。助手代码、API 路由和 assistant-ui 前端都位于同一个项目中。这是阻力最小的路径：一个部署目标、一组环境变量，无需处理跨源连接。

如需独立扩展，请改为参阅[独立服务器](/docs/integrations/frameworks/mastra/separate-server)。

## 设置

<Steps>
<Step>

### 初始化 assistant-ui

在项目中设置 assistant-ui：

```sh title="New project"
npx assistant-ui@latest create
```

```sh title="Existing project"
npx assistant-ui@latest init
```

这会安装依赖，并在 `app/api/chat/route.ts` 创建默认的聊天 API 路由。如需手动设置，请参阅[入门指南](/docs)。

</Step>
<Step>

### 安装 Mastra 包

`@mastra/core` 提供助手运行时；`@mastra/ai-sdk` 将 Mastra 的流格式转换为 AI SDK 的 UI 消息流；工具 schema 需要使用 `zod`。

<InstallCommand npm={["@mastra/core@latest", "@mastra/ai-sdk@latest", "zod@latest"]} />

</Step>
<Step>

### 配置 Next.js

Mastra 的运行时依赖仅适用于 Node.js 的模块。告知 Next.js 在服务器端将 Mastra 包作为外部依赖进行打包，避免这些包被追踪到 Edge 运行时中。

```js title="next.config.mjs"
/** @type {import('next').NextConfig} */
const nextConfig = {
  serverExternalPackages: ["@mastra/*"],
};

export default nextConfig;
```

如果跳过此步骤，你将在请求时而不是构建时看到难以判断原因的打包错误。

</Step>
<Step>

### 定义助手

在项目根目录创建 `mastra/` 文件夹，并在其中创建两个文件：

```txt title="Project layout"
mastra/
├── agents/
│   └── chefAgent.ts
└── index.ts
```

在 `chefAgent.ts` 中定义助手：

```ts title="mastra/agents/chefAgent.ts"
import { Agent } from "@mastra/core/agent";

export const chefAgent = new Agent({
  name: "chef-agent",
  instructions:
    "You are Michel, a practical and experienced home chef. " +
    "You help people cook with whatever ingredients they have available.",
  model: "openai/gpt-5.6-luna",
});
```

`model: "openai/gpt-5.6-luna"` 使用 Mastra 的模型路由器。在 `.env.local` 中设置提供商密钥，以便 Next.js 自动加载它：

```sh title=".env.local"
OPENAI_API_KEY=sk-...
```

</Step>
<Step>

### 注册助手

使用该助手初始化 Mastra，以便按名称查找它：

```ts title="mastra/index.ts"
import { Mastra } from "@mastra/core";
import { chefAgent } from "./agents/chefAgent";

export const mastra = new Mastra({
  agents: { chefAgent },
});
```

</Step>
<Step>

### 接入 API 路由

将默认路由替换为从 Mastra 助手进行流式传输的路由：

```ts title="app/api/chat/route.ts"
import { createUIMessageStream, createUIMessageStreamResponse } from "ai";
import { toAISdkStream } from "@mastra/ai-sdk";
import { mastra } from "@/mastra";

export const maxDuration = 30;

export async function POST(req: Request) {
  const { messages } = await req.json();

  const agent = mastra.getAgent("chefAgent");
  const stream = await agent.stream(messages);

  const uiMessageStream = createUIMessageStream({
    originalMessages: messages,
    execute: async ({ writer }) => {
      for await (const part of toAISdkStream(stream, { from: "agent" })) {
        await writer.write(part);
      }
    },
  });

  return createUIMessageStreamResponse({ stream: uiMessageStream });
}
```

`agent.stream()` 返回 Mastra 原生流。`toAISdkStream`（来自 `@mastra/ai-sdk`）会将每个部分适配为 AI SDK 的格式；`createUIMessageStream` 将部分循环封装为 `useChatRuntime` 消费的 UI 消息流；`createUIMessageStreamResponse` 将其作为 HTTP 响应返回。

`@/mastra` 的导入假定已在 `tsconfig.json` 中配置 `@/*` 路径别名（assistant-ui starter 会完成此设置）。如果项目使用其他别名，请调整导入路径。

</Step>
<Step>

### 运行并验证

启动开发服务器：

```bash npm2yarn
npm run dev
```

打开 `http://localhost:3000`，发送类似 *“鸡蛋和米饭能做什么？”* 的消息，并确认：

- 响应会逐个 token 进行流式输出。
- 浏览器的网络面板中显示一个 `POST /api/chat`，并返回 `text/event-stream`。
- 控制台中没有关于缺少模块的错误；如果看到 `Cannot find module '@mastra/...'`，请重新检查 `serverExternalPackages` 步骤。

</Step>
</Steps>

## 注意事项

- **路由中的错误会以流错误的形式传递到客户端。** 如果需要在错误到达客户端之前记录结构化错误，请将 `agent.stream()` 包装在 `try/catch` 中。
- **固定兼容的版本。** `@mastra/ai-sdk` 遵循 AI SDK v6 契约。如果将 `ai` 升级到未来的主版本，请根据 Mastra 的发行说明验证 `toAISdkStream` 的格式。
- **Mastra 的高级功能**（内存、工具、工作流、评估）完全位于助手定义中。assistant-ui 只会看到生成的流，因此 Mastra 支持的任何功能都无需进一步修改前端即可使用。请参阅 [Mastra 文档](https://mastra.ai/docs).
