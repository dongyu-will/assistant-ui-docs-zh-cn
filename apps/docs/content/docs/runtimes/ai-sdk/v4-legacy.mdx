<Callout type="warn">
AI SDK v4 是遗留版本。新项目应使用 [AI SDK v7](/docs/runtimes/ai-sdk/v7)。v4 集成使用较旧的 `@assistant-ui/react-data-stream` 包，而不是 `@assistant-ui/ai-sdk`。
</Callout>

## 为什么是遗留版本

Vercel 大约每年发布一个 AI SDK 主版本；v4 比 v7 落后三个主版本。当前的 `@assistant-ui/ai-sdk` 包仅支持当前的 AI SDK 主版本（v7），因此 v4 用户应改用 [`@assistant-ui/react-data-stream`](/docs/runtimes/custom/data-stream)——这与 v4 的 `toDataStreamResponse()` 发出的数据流协议相同。

本页面供现有 v4 项目参考。条件允许时，请计划迁移到 v7。

## 设置

<Steps>
<Step>

### 安装

<InstallCommand npm={["@assistant-ui/react", "@assistant-ui/react-data-stream", "ai@^4"]} />

</Step>
<Step>

### 后端路由

```ts title="@/app/api/chat/route.ts"
import { streamText } from "ai";
import { openai } from "@ai-sdk/openai";

export async function POST(req: Request) {
  const { messages } = await req.json();
  const result = streamText({ model: openai("gpt-5.6-luna"), messages });
  return result.toDataStreamResponse();
}
```

</Step>
<Step>

### 前端

```tsx title="@/app/page.tsx"
"use client";

import { AssistantRuntimeProvider } from "@assistant-ui/react";
import { useDataStreamRuntime } from "@assistant-ui/react-data-stream";
import { Thread } from "@/components/assistant-ui/elements/thread.aui";

export default function Home() {
  const runtime = useDataStreamRuntime({ api: "/api/chat" });
  return (
    <AssistantRuntimeProvider runtime={runtime}>
      <div className="h-full">
        <Thread />
      </div>
    </AssistantRuntimeProvider>
  );
}
```

AI SDK v4 的 `toDataStreamResponse()` 会以
`x-vercel-ai-data-stream: v1` 响应标头发出数据流线格式，因此 `useDataStreamRuntime`
会自动检测该格式。如果自定义代理移除或隐藏了该标头，请显式传入
`protocol: "data-stream"`。

</Step>
</Steps>

`useDataStreamRuntime` 接受 `api`、`initialMessages`、`onFinish`、`onError`、`headers`、`body` 以及标准 `LocalRuntimeOptions`。完整参考请参阅[数据流协议](/docs/runtimes/custom/data-stream)。

## 与 v6 的差异

| 功能 | v4 | v6 |
| --- | --- | --- |
| `ai` 包 | `ai@^4` | `ai@^6` |
| 运行时包 | `@assistant-ui/react-data-stream` | `@assistant-ui/react-ai-sdk@1.3.40` |
| 运行时 Hook | `useDataStreamRuntime` | `useChatRuntime` |
| 响应 | `toDataStreamResponse()` | `toUIMessageStreamResponse()` |
| 工具模式 | `parameters: z.object({...})` | `inputSchema: zodSchema(z.object({...}))` |
| 消息类型 |（无类型） | `UIMessage` |

## 迁移到 v7

准备升级时：

1. 将 `@assistant-ui/react-data-stream` 替换为 `@assistant-ui/ai-sdk`。
2. 将后端更新为当前 AI SDK 的 `streamText`（请参阅 [v7 文档](/docs/runtimes/ai-sdk/v7)）。
3. 将运行时 Hook 从 `useDataStreamRuntime` 切换为 `useChatRuntime`。

AI SDK 在 [ai-sdk.dev/docs/migration-guides](https://ai-sdk.dev/docs/migration-guides) 提供了 codemod，可处理包相关的重写。

## 替代方案：react-ai-sdk@0.10.16

`@assistant-ui/react-ai-sdk` 的较早版本系列直接支持 AI SDK v4；其最后一个版本是 `0.10.16`。该版本系列已不再维护，也没有升级路径；如果你要开始一个新的 v4 项目，请改用 `@assistant-ui/react-data-stream`。
