<Callout type="warn">
AI SDK v5 是旧版。新项目应使用 [AI SDK v7](/docs/runtimes/ai-sdk/v7)。v5 用户应固定使用 `@assistant-ui/react-ai-sdk@1.1.21`（最后一个兼容 v5 的版本）；后续版本面向更新的 AI SDK 主版本。
</Callout>

## 为什么是旧版

AI SDK v6 引入了重大的 API 变更：异步 `convertToModelMessages`、新的工具 schema，以及 `toUIMessageStreamResponse()`。v5 仍然可以使用，但在 `@assistant-ui/react-ai-sdk` 中不再获得新功能。固定使用 `1.1.21` 可确保你继续使用兼容 v5 的 API 表面。

本页面供现有的 v5 项目参考。条件允许时，请计划迁移到 v7。

## 设置

<Steps>
<Step>

### 安装兼容 v5 的版本

<InstallCommand npm={["@assistant-ui/react", "@assistant-ui/react-ai-sdk@1.1.21", "ai@^5", "@ai-sdk/openai@^1", "zod"]} />

</Step>
<Step>

### 后端路由

```ts title="@/app/api/chat/route.ts"
import { openai } from "@ai-sdk/openai";
import { streamText, tool } from "ai";
import type { Message } from "ai";
import { z } from "zod";

export const maxDuration = 30;

export async function POST(req: Request) {
  const { messages }: { messages: Message[] } = await req.json();
  const result = streamText({
    model: openai("gpt-5.6-luna"),
    messages,
    tools: {
      get_current_weather: tool({
        description: "Get the current weather",
        parameters: z.object({ city: z.string() }),
        execute: async ({ city }) => `The weather in ${city} is sunny`,
      }),
    },
  });
  return result.toDataStreamResponse();
}
```

</Step>
<Step>

### 前端

```tsx title="@/app/page.tsx"
"use client";

import { Thread } from "@/components/assistant-ui/elements/thread.aui";
import { AssistantRuntimeProvider } from "@assistant-ui/react";
import { useChatRuntime } from "@assistant-ui/react-ai-sdk";

export default function Home() {
  const runtime = useChatRuntime();
  return (
    <AssistantRuntimeProvider runtime={runtime}>
      <div className="h-full">
        <Thread />
      </div>
    </AssistantRuntimeProvider>
  );
}
```

</Step>
</Steps>

<Callout type="info">
在 `@assistant-ui/react-ai-sdk` 版本低于 0.11.3 时，请改用带有来自 `ai/react` 的 `useChat` 的 `useVercelUseChatRuntime`：

```tsx
import { useChat } from "ai/react";
import { useVercelUseChatRuntime } from "@assistant-ui/react-ai-sdk";

const chat = useChat({ api: "/api/chat" });
const runtime = useVercelUseChatRuntime(chat);
```
</Callout>

## 与 v6 的差异

| 功能 | v5 | v6 |
| --- | --- | --- |
| `ai` 包 | `ai@^5` | `ai@^6` |
| `@assistant-ui/react-ai-sdk` | `@1.1.21` | `@1.3.40` |
| `@ai-sdk/openai` | `^1` | `^3` |
| 消息类型 | `Message` | `UIMessage` |
| `convertToModelMessages` | 同步 | 异步（`await`） |
| 工具 schema | `parameters: z.object({...})` | `inputSchema: zodSchema(z.object({...}))` |
| 响应 | `toDataStreamResponse()` | `toUIMessageStreamResponse()` |

## 迁移到 v6

准备升级时：

1. 将 `ai` 从 `@^5` 更新为 `@^6`，并将 `@assistant-ui/react-ai-sdk` 更新到最新版本线。
2. 在 `convertToModelMessages(...)` 调用中添加 `await`。
3. 转换工具 schema：`parameters: z.object({...})` → `inputSchema: zodSchema(z.object({...}))`。
4. 将 `toDataStreamResponse()` 替换为 `toUIMessageStreamResponse()`。
5. 将 `Message` 类型切换为 `UIMessage`。

AI SDK 在 [ai-sdk.dev/docs/migration-guides/migration-guide-6-0](https://ai-sdk.dev/docs/migration-guides/migration-guide-6-0) 提供了 codemod，可处理大多数包侧重写。
