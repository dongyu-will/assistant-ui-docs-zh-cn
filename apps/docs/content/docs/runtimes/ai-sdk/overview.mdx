`@assistant-ui/ai-sdk` 将 assistant-ui 与 [Vercel AI SDK](https://ai-sdk.dev/). 集成。本文涵盖 `useChat` 流程、自定义传输层、前端工具、附件、引用上下文、多步骤助手、令牌用量和云端持久化。

## 选择版本

| AI SDK | 运行时包 | 文档 |
| --- | --- | --- |
| `ai@^7` + `@ai-sdk/react@^4` | `@assistant-ui/ai-sdk`（最新） | [v7（当前）](/docs/runtimes/ai-sdk/v7) |
| `ai@^6` + `@ai-sdk/react@^3` | `@assistant-ui/react-ai-sdk@1.3.40` | [v6（旧版）](/docs/runtimes/ai-sdk/v6-legacy) |
| `ai@^5` + `@ai-sdk/react@^2` | `@assistant-ui/react-ai-sdk@1.1.21` | [v5（旧版）](/docs/runtimes/ai-sdk/v5-legacy) |
| `ai@^4` | `@assistant-ui/react-data-stream` | [v4（旧版）](/docs/runtimes/ai-sdk/v4-legacy) |

新项目应使用 v7。v6、v5 和 v4 的文档面向尚未迁移的项目；这些版本都存在已知的兼容性缺口，并且不会获得新功能。

## 架构

`@assistant-ui/ai-sdk` 构建于 `ExternalStoreRuntime` 之上（参见[架构](/docs/runtimes/concepts/architecture)）。作为运行时适配器发布的功能，其工作方式与其他场景完全相同；请参见[适配器](/docs/runtimes/concepts/adapters)。

如需支持安全重载的流式传输（持久化正在进行中的响应，以便客户端可以重新连接），请参见[可恢复流](/docs/guides/resumable-streams)。

## 选择 useChatRuntime 还是 useAISDKRuntime

两者都包含在同一个包中。

- **`useChatRuntime`**（推荐）封装了 AI SDK 的 `useChat` hook，并添加了云端会话线程支持、标准适配器插槽以及 `AssistantChatTransport`（默认转发系统消息和前端工具）。除非有特殊原因，否则请使用此方式。
- **`useAISDKRuntime`** 是一个更底层的 hook，接收一个由你直接控制的现有 `useChat` 实例。当你需要将聊天实例与非 assistant-ui 代码共享，或接入一个不继承自 `AssistantChatTransport` 的自定义传输层时，请使用它。
