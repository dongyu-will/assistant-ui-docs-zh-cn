在本教程中，我们将使用 LangChain.js、LangGraph.js 和 assistant-ui 构建一个股票经纪助手。

我们将逐步介绍将 assistant-ui 集成到 LangGraph Cloud 端点所需的步骤。
代码片段主要聚焦于前端设置，但我们也会介绍后端代码中的相关部分。

此代理使用了以下功能：

- 🚄 将消息从 LangGraph 状态流式传输到 assistant-ui
- 💅 使用 Markdown 渲染富文本
- 🛠️ 生成式 UI：将工具调用映射到工具 UI
- 🔁 审批 UI：在执行前确认工具调用（人在回路）

## 前置条件

- Node.js 24 或更高版本

## 最终效果

- 演示：https://assistant-ui-stockbroker.vercel.app/
- 源代码：https://github.com/assistant-ui/assistant-ui-stockbroker

## 开始使用

通过[设置前端](/docs/runtimes/langgraph/tutorial/part-1)开始教程的第 1 部分。
