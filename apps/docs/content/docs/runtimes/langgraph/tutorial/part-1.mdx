## 创建新项目

运行以下命令，使用 LangGraph assistant-ui 模板创建新的 Next.js 项目：

```sh
npx create-assistant-ui@latest -t langchain my-app
cd my-app
```

你应该会在项目中看到以下文件：

### 设置环境变量

在项目中创建 `.env.local` 文件，并添加以下变量：

```sh title="@/.env.local"
LANGGRAPH_API_URL=https://assistant-ui-stockbroker.vercel.app/api
NEXT_PUBLIC_LANGGRAPH_ASSISTANT_ID=stockbroker
```

这会将前端连接到运行于
`https://assistant-ui-stockbroker.vercel.app/api`
下的 LangGraph Cloud 端点。
此端点运行的是[此仓库中定义的](https://github.com/assistant-ui/assistant-ui-stockbroker/blob/main/backend). LangGraph agent。

### 启动服务器

运行以下命令即可启动服务器：

```sh
npm run dev
```

服务器启动后，在浏览器中打开 http://localhost:3000. 即可查看前端。

你应该可以与助手聊天，并实时查看 LLM 流式返回的响应。

## 探索功能

### 流式传输

消息流式传输支持默认已启用。LangGraph 集成包含完善的消息处理机制，可以高效地管理流式响应：

- 使用 `LangGraphMessageAccumulator` 实时累积并更新消息
- 使用 `appendLangChainChunk` 自动合并部分消息块
- 运行时负责处理管理流式状态的所有复杂逻辑

这意味着你会看到 LLM 生成的 token 平滑地逐个出现，同时文本内容和工具调用都能得到正确处理。

### Markdown 支持

使用 Markdown 进行富文本渲染的功能默认已启用。
