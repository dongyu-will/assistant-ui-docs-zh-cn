---
title: Agent 状态
description: 在 LangGraph 中使用 useLangGraphState 和 useLangGraphSetState 读取并乐观更新图状态。
---

`useLangGraphState` 镜像 LangGraph 流式传输到客户端的图 values 对象。代理运行期间（启用 `values` 流式传输模式时），它会实时更新。`useLangGraphSetState` 允许你应用乐观的本地更新，并将其随下一次发送一并提交。

## 启用 `values` 流式传输模式

<Callout type="warn">
默认的流式传输设置**不**包含 `values` 流式传输模式。没有它，`useLangGraphState` 将永远无法接收实时图状态。
</Callout>

如果你自行调用 `client.runs.stream`，请在已有模式的基础上同时请求 `values`：

```ts
client.runs.stream(threadId, assistantId, {
  input,
  streamMode: ["messages", "updates", "custom", "values"],
});
```

如果你使用 `unstable_createLangGraphStream`，其默认流式传输模式也**不**包含 `values`。请显式传入该选项：

```ts
const stream = unstable_createLangGraphStream({
  client,
  assistantId: ASSISTANT_ID,
  streamMode: ["messages", "updates", "custom", "values"],
});
```

## 基本用法

```tsx
import {
  useLangGraphState,
  useLangGraphSetState,
} from "@assistant-ui/react-langgraph";
import { useAuiState } from "@assistant-ui/react";

type GraphState = {
  messages: unknown[];
  filters: { region: string; maxResults: number };
};

const state = useLangGraphState<GraphState>();
// state: GraphState | undefined  (latest agent state; updates live while the agent runs)

const setState = useLangGraphSetState<GraphState>();
// setState(next | (prev) => next)   (optimistic local update; sent with the NEXT run)

const isRunning = useAuiState((s) => s.thread.isRunning);
// isRunning: boolean                (whether the thread is currently running)
```

## 示例

在聊天旁边渲染图状态，并暂存一个乐观的筛选器更新：

```tsx
"use client";

import {
  useLangGraphState,
  useLangGraphSetState,
} from "@assistant-ui/react-langgraph";
import { useAuiState } from "@assistant-ui/react";
import { Thread } from "@/components/assistant-ui/elements/thread.aui";

type GraphState = {
  filters: { region: string; maxResults: number };
  lastQuery?: string;
};

export function CatalogAssistant() {
  const state = useLangGraphState<GraphState>();
  const setState = useLangGraphSetState<GraphState>();
  const isRunning = useAuiState((s) => s.thread.isRunning);

  return (
    <div className="flex h-full">
      <aside className="w-72 border-r p-4">
        <h2>Graph state</h2>
        {state ? (
          <ul>
            <li>Region: {state.filters.region}</li>
            <li>Max results: {state.filters.maxResults}</li>
            {state.lastQuery && <li>Last query: {state.lastQuery}</li>}
          </ul>
        ) : (
          <p>No graph state yet. Ensure streamMode includes "values".</p>
        )}
        <button
          type="button"
          disabled={isRunning}
          onClick={() =>
            setState((prev) => ({
              ...prev,
              filters: {
                region: "eu",
                maxResults: prev?.filters.maxResults ?? 10,
              },
            }))
          }
        >
          Prefer EU region
        </button>
        {isRunning && <p>Agent is running…</p>}
      </aside>
      <main className="flex-1">
        <Thread />
      </main>
    </div>
  );
}
```

该面板会跟踪图发出的最新 `values` 事件。按钮会立即更新本地覆盖层；下一次发送时，该更新对象会合并到运行 `input` 中，以便 LangGraph 通过图的状态 reducer 和输入 schema 应用它。

## 状态同步方式

LangGraph 状态就是图的 values 对象。当 `streamMode` 包含 `"values"` 时，每个 `values` 事件都会更新客户端快照，而 `useLangGraphState` 会对外暴露该快照。

`useLangGraphSetState` 提供的 setter 会在本地覆盖该快照。下一次发送时，运行时会将更新对象合并到运行 `input` 中，因此 LangGraph 会通过图的状态 reducer 和输入 schema 对其进行归约。

如果你提供自定义的 `stream` 回调，暂存的更新可以通过 `config.state` 获取。请自行将它转发到运行输入中：

```ts
const runtime = useLangGraphRuntime({
  stream: async (messages, { initialize, ...config }) => {
    const { externalId } = await initialize();
    if (!externalId) throw new Error("Thread not found");

    const client = createClient();
    return client.runs.stream(externalId, ASSISTANT_ID, {
      input: {
        ...(config.state ?? {}),
        messages,
      },
      streamMode: ["messages", "updates", "custom", "values"],
    });
  },
});
```

使用包辅助函数的内置路径会替你执行此合并。自定义 `stream` 回调必须显式执行合并。

## 写回时机

`useLangGraphSetState` 首先是乐观的本地更新。只有在下一次运行开始时，该值才会到达代理。它不是通往已经在运行中的运行的实时通道。请暂存筛选器、偏好设置或其他图字段，让下一轮通过 reducer 应用；不要期待正在运行的任务观察到运行中途的 setter 调用。

## 与其他状态的关系

请区分以下三个状态层：

- **你的应用状态**仍归你所有（React 状态、URL、状态存储）。assistant-ui 不会管理它。
- **`useAuiState`** 读取 assistant-ui 的客户端状态（消息、输入框、线程状态）。
- **`useLangGraphState` / `useLangGraphSetState`** 镜像由**代理**（你的 LangGraph 图）所拥有的状态，并通过 `values` 事件在线路上传输并同步。

对于位于图状态 schema 中的字段，请使用 `useLangGraphState` 和 `useLangGraphSetState`。对于依赖聊天线程本身的 UI，请使用 `useAuiState`。其他所有内容都使用你自己的状态。
