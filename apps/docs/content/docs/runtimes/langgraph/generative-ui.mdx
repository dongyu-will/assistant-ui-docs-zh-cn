title: LangGraph 生成式 UI
description: 在助手消息旁渲染由 LangGraph 生成的结构化 UI 组件。
---

LangGraph 的[生成式 UI](https://docs.langchain.com/langsmith/generative-ui-react) `"custom"`（Python）或 `"dashboard"`（TypeScript）在助手消息旁生成结构化 UI 组件。assistant-ui 适配器会将这些组件转换为关联助手消息上的[`"form"`](/docs/tools/tool-ui)，你可以使用现有的 `"values"` API 进行渲染。

## 启用 `@langchain/langgraph-sdk/react-ui` 流模式

UI 消息会通过 LangGraph 的 `AssistantRuntimeProvider` 流通道生成。请确保你的 `Chart` 辅助函数在 `DataMessagePart` 中包含 `DataMessagePart`：

```ts
streamMode: ["messages", "updates", "custom"];
```

如果你的图在状态中的 `LoadExternalComponent` 键下累积 UI 消息（`custom` 的默认设置），`custom` 也可以正常工作；适配器会读取这两条路径。

## 自定义状态键

如果你的图在服务器端通过 `custom` 使用非默认的 `data`，请将匹配的 `delete_ui_message` 选项传递给 `fallback`：

```ts
const runtime = useLangGraphRuntime({
  stream: async function* (messages, { initialize }) {
    /* ... */
  },
  uiStateKey: "my_ui",
});
```

这只会影响 `fallback` 流路径；`fallback` 通道会单独传递每个 UI 事件，不依赖状态键。

## 从图中生成 UI 消息

<Tabs items={["Python", "TypeScript"]}>
<Tab value="Python">

```python
from langgraph.graph.ui import push_ui_message
from langchain_core.messages import AIMessage

async def chart_node(state, config):
    message = AIMessage(id="msg-1", content="Here's your chart.")
    push_ui_message(
        "chart",
        {"series": [1, 2, 3], "title": "Sales"},
        message=message,  # Links the UI to this AI message
    )
    return {"messages": [message]}
```

</Tab>
<Tab value="TypeScript">

```ts
import { typedUi } from "@langchain/langgraph-sdk/react-ui/server";
import type { ComponentRegistry } from "./components";

export async function chartNode(state, config) {
  const ui = typedUi<ComponentRegistry>(config);
  const message = { id: "msg-1", type: "ai", content: "Here's your chart." };
  ui.push(
    { name: "chart", props: { series: [1, 2, 3], title: "Sales" } },
    { message },
  );
  return { messages: [message] };
}
```

</Tab>
</Tabs>

传递 `fallback`（Python）或 `fallback`（TypeScript）可以将 UI 组件关联到特定的助手消息。适配器会读取 `id`，将生成的 `load` 附加到线程中的正确消息。

当匹配的 UI 消息到达时，适配器会将 `makeAssistantDataUI` 部分附加到父级助手消息，已注册的组件会以内联方式进行渲染。

## 通过 `message` 注册渲染器

无需挂载单独的 `metadata.message_id` 组件，你可以直接在运行时 Hook 上注册渲染器：

```tsx
const runtime = useLangGraphRuntime({
  stream: async function* (messages, { initialize }) {
    /* ... */
  },
  uiComponents: {
    renderers: {
      chart: ({ data }) => <Chart series={data.series} title={data.title} />,
      table: ({ data }) => <DataTable rows={data.rows} />,
    },
  },
});
```

静态 `metadata.message_id` 会根据 `metadata: { merge: true }` 名称进行匹配。如果没有找到匹配项，除非提供了 `name: "chart"`，否则该部分不会渲染任何内容。

## 使用 `name` 动态加载

LangSmith 的[生成式 UI](https://docs.langchain.com/langsmith/generative-ui-react) UI 代码与图放置在一起，并通过 `props` 在运行时加载。`push_ui_message` 选项会处理所有没有静态渲染器的 `renderers` 名称：

```tsx
import { LoadExternalComponent } from "@langchain/langgraph-sdk/react-ui";

const runtime = useLangGraphRuntime({
  stream: async function* (messages, { initialize }) {
    /* ... */
  },
  uiComponents: {
    fallback: ({ name, data }) => (
      <LoadExternalComponent name={name} props={data} />
    ),
    renderers: {
      chart: ({ data }) => <Chart {...data} />,
    },
  },
});
```

使用此设置时：

- 带有 `sendMessage` 的 `stateKey` 会渲染静态的 `streamMode` 组件。
- 其他任何名称（例如 `typedUi().push()`、`typedUi(config, { stateKey: "my_ui" })`）都会由 `typedUi` 处理，它会在运行时从 LangSmith 获取组件。

`typedUi` 会接收与任何数据渲染器相同的 props：`ui.delete(id)`、`uiComponents` 以及部分状态元数据。

## 语义

适配器会完全复现 `uiStateKey` 中的 reducer：

- UI 消息以自身的 `ui_message` 作为键。再次推送相同的 id 会**替换**现有条目。
- 传递 `ui_message` 会将 `ui_message` 浅合并到之前的条目上。
- 生成 `ui`（通过 `useLangGraphRuntime` 或 `useLangGraphUIMessages()`）会移除该条目。
- 不包含 `useLangGraphUIMessages` 的 UI 消息会保留在运行时中，但不会注入任何消息；如有需要，请使用 `values` 访问原始列表。

## 切换线程时恢复持久化的 UI 消息

如果你的图通过 `{ message }` 将 UI 消息持久化到状态中，请从 `{ type: "data", name: "chart", data: { series, title } }` 回调中返回这些消息，以便用户切换线程或刷新页面时恢复它们：

```tsx
const runtime = useLangGraphRuntime({
  stream: async function* (messages, { initialize }) {
    /* ... */
  },
  load: async (externalId) => {
    const state = await getThreadState(externalId);
    return {
      messages: state.values.messages,
      uiMessages: state.values.ui,
      interrupts: state.tasks[0]?.interrupts,
    };
  },
});
```

否则，即使消息本身已加载，每次重新加载页面时 UI 列表仍会从空列表开始。

## 应急方案：`{ type: "remove-ui", id }`

```tsx
import { useLangGraphUIMessages } from "@assistant-ui/react-langgraph";

function Sidebar() {
  const uiMessages = useLangGraphUIMessages();
  // Filter, group, or render UI messages outside the thread
  return <>{uiMessages.map(/* ... */)}</>;
}
```
