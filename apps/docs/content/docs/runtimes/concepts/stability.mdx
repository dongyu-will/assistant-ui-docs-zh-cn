assistant-ui 为部分 API 添加了 `unstable_` 前缀。

## `unstable_` 的含义 [#what-unstable_-means]

`unstable_` 前缀表示该 API 已公开暴露，你可以基于它进行构建；但其接口（签名、命名、语义、返回结构）可能在任何版本中发生变化，包括补丁版本。

如果你依赖不稳定 API：

- **固定依赖范围**，避免自动的次版本或补丁版本更新在你不知情的情况下改写契约。
- **隔离调用位置**，在代码中通过一个小型包装器封装调用，以便在上游发生变更时集中适配。
- **预期名称变更或移除**，API 稳定后可能会发生这些变化；稳定版本会移除该前缀。

## 在编辑器中查看 [#in-your-editor]

每个实验性 API 都带有如下形式的 `@deprecated` 标记，因此编辑器会为它显示删除线：

```ts
/** @deprecated Experimental since 2026-06-23. Not scheduled for removal; the API may change in any release. */
```

将鼠标悬停在带删除线的 API 上，可以查看其标记类型。实验性 API 会显示 `Experimental since <date>`；计划移除的 API 则会指出替代项。

typescript-eslint 的 `@typescript-eslint/no-deprecated` 规则也会报告实验性 API，该规则由 `strict-type-checked` 配置启用。请将你使用的实验性 API 列入该规则的 `allow` 选项。

## 为什么会提供这些 API [#why-we-ship-them]

某项功能保持 `unstable_` 状态通常有三个原因：

1. **设计仍在变化**，我们希望在最终确定之前收集对当前形态的反馈。
2. **API 依赖仍在调整的内部实现**，因此其接口会随之变化。
3. **使用场景当前确实存在**，但尚未满足稳定 API 的要求（语义化版本规范、全面覆盖和文档）。

## 当前不稳定的 API [#currently-unstable-apis]

以下是在运行时文档中列出的 `unstable_` 导出项，列表并不完整。

| API | 包 | 说明 |
| --- | --- | --- |
| `unstable_createMessageConverter` | `@assistant-ui/react` | AssistantTransport 和 DataStream 使用的消息格式转换器。 |
| `unstable_humanToolNames` | `@assistant-ui/react` | 会暂停运行、直到通过 `addResult` 添加结果的工具名称。仅适用于 LocalRuntime；DataStream 不支持。 |
| `unstable_threadListAdapter` | `@assistant-ui/react-langgraph` | `useLangGraphRuntime` 上的 LangGraph 线程列表适配器插槽。 |
| `unstable_createLangGraphStream` | `@assistant-ui/react-langgraph` | 端到端取消原语。 |
| `unstable_Provider` | 各种适配器 | 已弃用，将在未来的次版本中移除。`RemoteThreadListAdapter` 的 React 组件形式。必须同步渲染子元素。`useRemoteThreadListRuntime` 仅在挂载时的适配器提供它时才会渲染它；`RemoteThreadList` 存储条目会忽略它。请优先使用 `unstable_useAdapters`。 |
| `unstable_useAdapters` | 各种适配器 | `RemoteThreadListAdapter` 的 Hook 形式。`RemoteThreadList` 存储条目会调用它。`useRemoteThreadListRuntime` 也会调用它，但在渲染 `unstable_Provider` 时除外。 |
| `unstable_capabilities` | `ExternalStoreRuntime` | 控制复制功能及其他线程能力的启用状态。 |
| `unstable_state`、`unstable_annotations`、`unstable_data` | 消息元数据 | 为高级使用场景暴露的运行时内部字段。 |
| `unstable_assistantMessageId`、`unstable_threadId`、`unstable_parentId`、`unstable_getMessage` | `ChatModelRunOptions` | 传递给你的 `ChatModelAdapter.run` 的标识符和访问器。 |

框架适配器会在相应的适配器页面中列出各自不稳定的接口。

## API 何时变得稳定 [#when-something-stabilizes]

稳定化通常会移除前缀。如果 `unstable_foo` 变得稳定，新的导出项将是 `foo`；旧名称会作为已弃用的别名至少保留一个次版本周期，并且变更日志会明确说明此次变化。

请关注[发布说明](https://github.com/assistant-ui/assistant-ui/releases) 和[迁移指南](/docs/migrations)，了解相关过渡安排。
