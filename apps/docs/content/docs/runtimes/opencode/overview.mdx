`@assistant-ui/react-opencode` 是用于 [OpenCode](https://opencode.ai/), 的运行时适配器。OpenCode 是一个开源 AI 编程代理。它将 OpenCode 服务器的会话和事件 API 接入 assistant-ui 线程，包括工具权限、交互式问题和会话状态。

<Callout type="warn">
此适配器当前版本为 v0.0.3，属于实验性功能。运行时 API 和导出的 hooks 可能会随时变更，恕不另行通知。
</Callout>

## 适用场景

在以下情况下选择 OpenCode 运行时：

- 你正在基于 OpenCode 代理服务器构建 UI。
- 你需要原生支持 OpenCode 的权限和提问流程。
- 你希望使用与会话相关的功能：fork、revert、unrevert、refresh。

如果你的后端不是基于 OpenCode 构建的，请参阅[选择运行时](/docs/runtimes/pick-a-runtime)了解其他方案。

## 架构

`@assistant-ui/react-opencode` 基于 `ExternalStoreRuntime` 构建，并额外使用 `RemoteThreadList` 管理由会话支持的线程（参见[架构](/docs/runtimes/concepts/architecture)）。OpenCode 会话会映射到 assistant-ui 线程；运行时订阅服务器发送事件流，并将消息投影到线程中。

## 要求

- 正在运行的 [OpenCode](https://opencode.ai/) 服务器（默认使用 `http://localhost:4096`）。
- React 18 或 19。

## 子代理对话

OpenCode `task` 工具调用会通过工具元数据公开其子会话。运行时会加载这些子会话，通过同一个 OpenCode 事件流使它们保持同步，并将其会话记录投影到 `ToolCallMessagePart.messages` 中。支持并行任务和递归嵌套任务。

加载采用主动加载方式，而不是根据渲染器显示的内容按需加载。线程订阅后，其会话记录中的每个 `task` part 都会获取对应的子会话；每个子会话也会对其自身的嵌套任务执行相同操作。因此，一个包含许多任务调用的长会话会获取所有子代理的会话记录，无论这些会话是否处于展开状态。每个子会话只会获取一次，之后通过事件流保持最新状态，因此重新订阅线程不会再次获取它。

只有在子会话加载完成后，`task` part 才会携带 `messages`。子会话仍在加载时，该 part 会被投影为普通工具调用，因此空的 `messages` 数组始终表示子代理没有产生任何内容，而不是表示其会话记录仍在传输中。

在 `task` 工具渲染器中使用 assistant-ui 的 [`MessagePartPrimitive.Messages`](/docs/tools/multi-agent) 来显示子对话。嵌套对话为只读，并继承父线程的工具渲染器。
