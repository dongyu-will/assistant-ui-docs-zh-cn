---
title: 快速开始
description: 针对本地 OpenCode 服务器的最小化 useOpenCodeRuntime 设置。
---

只需三步，即可与本地 OpenCode 服务器建立可用的聊天。假设你已经运行了 OpenCode；如果还没有，请先按照 [opencode.ai](https://opencode.ai/) 安装并启动服务器。

<Steps>
<Step>

### 接入运行时提供程序

```tsx title="app/MyRuntimeProvider.tsx"
"use client";

import { AssistantRuntimeProvider } from "@assistant-ui/react";
import { useOpenCodeRuntime } from "@assistant-ui/react-opencode";

export function MyRuntimeProvider({
  children,
}: {
  children: React.ReactNode;
}) {
  const runtime = useOpenCodeRuntime({
    baseUrl: "http://localhost:4096",
  });

  return (
    <AssistantRuntimeProvider runtime={runtime}>
      {children}
    </AssistantRuntimeProvider>
  );
}
```

如果省略 `baseUrl`，其默认值为 `http://localhost:4096`。

</Step>
<Step>

### 渲染线程

```tsx title="app/page.tsx"
import { Thread } from "@/components/assistant-ui/elements/thread.aui";
import { MyRuntimeProvider } from "./MyRuntimeProvider";

export default function Page() {
  return (
    <MyRuntimeProvider>
      <Thread />
    </MyRuntimeProvider>
  );
}
```

</Step>
<Step>

### 设置 UI 组件

按照 [UI 组件指南](/elements/thread) 接入 Thread、输入框和支持性的原语。

</Step>
</Steps>

运行时会与 OpenCode 服务器建立 SSE 事件流，监听会话和消息事件，并将它们映射到线程中。每个 OpenCode 会话对应一个线程；线程列表反映服务器上的会话。

## 默认模型和 agent

启动新会话时固定默认模型或 agent：

```tsx
const runtime = useOpenCodeRuntime({
  baseUrl: "http://localhost:4096",
  defaultModel: { providerID: "anthropic", modelID: "claude-sonnet-4-6" },
  defaultAgent: "coder",
});
```

## 使用自己的客户端

如果你需要预先配置好的 `OpencodeClient`（例如用于身份验证请求头），可以直接传入：

```tsx
import { createOpencodeClient } from "@assistant-ui/react-opencode";

const client = createOpencodeClient({
  baseUrl: "http://localhost:4096",
  // additional client config...
});

const runtime = useOpenCodeRuntime({ client });
```

## 恢复会话

传入 `initialSessionId`，即可在首次加载时针对现有会话打开运行时：

```tsx
const runtime = useOpenCodeRuntime({
  baseUrl: "http://localhost:4096",
  initialSessionId: "ses_abc123",
});
```
