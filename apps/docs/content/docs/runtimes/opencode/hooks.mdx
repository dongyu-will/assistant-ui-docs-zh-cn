用于与运行中会话交互的 OpenCode 专用 React hooks。所有 hooks 都必须在运行时上下文中使用（即在 `useOpenCodeRuntime` 设置中的树由 `AssistantRuntimeProvider` 包裹）。

## 权限

OpenCode 会暂停工具执行，以请求用户许可（例如运行 shell 命令、写入文件）。与工具调用关联的权限会映射到 assistant-ui 的标准工具审批契约，因此默认的 `ToolFallback` 无需自定义权限组件，即可渲染可用的 **允许**、**始终允许** 和 **拒绝** 操作。只有当 OpenCode 提供了可持久化的匹配模式时，才会显示始终允许选项。

`useOpenCodePermissions` 仍可用于自定义工具渲染器，以及未与工具调用关联的权限请求。它会返回待处理的权限请求和一个回复函数：

```tsx
import { useOpenCodePermissions } from "@assistant-ui/react-opencode";

function PermissionPrompt() {
  const { pending, reply } = useOpenCodePermissions();

  return pending.map((req) => (
    <div key={req.id}>
      <p>
        Allow <code>{req.toolName}</code>: {req.title ?? req.permission}?
      </p>
      <button onClick={() => reply(req.id, "once")}>Allow once</button>
      <button onClick={() => reply(req.id, "always")}>Always allow</button>
      <button onClick={() => reply(req.id, "reject")}>Reject</button>
    </div>
  ));
}
```

返回结构：

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| `pending` | `OpenCodePermissionRequest[]` | 等待回复的权限请求。 |
| `reply` | `(id, response) => Promise<void>` | 为待处理的权限发送回复。 |

回复值：

| 回复 | 含义 |
| --- | --- |
| `"once"` | 批准这一个权限请求。 |
| `"always"` | 批准此权限并记住该选择。 |
| `"reject"` | 拒绝该权限；工具调用将被取消。 |

## 问题

OpenCode 可以在运行期间提出交互式问题。`useOpenCodeQuestions` 会以数组形式返回待处理的问题：

```tsx
import {
  useOpenCodeQuestions,
  useOpenCodeRuntimeExtras,
} from "@assistant-ui/react-opencode";

function QuestionPrompt() {
  const questions = useOpenCodeQuestions();
  const { replyToQuestion, rejectQuestion } = useOpenCodeRuntimeExtras();

  return questions.map((req) => (
    <div key={req.id}>
      <p>{req.text}</p>
      <button
        onClick={() =>
          replyToQuestion(req.id, [
            /* QuestionAnswer[] from @opencode-ai/sdk */
          ])
        }
      >
        Answer
      </button>
      <button onClick={() => rejectQuestion(req.id)}>Skip</button>
    </div>
  ));
}
```

要回复问题，请使用 [`useOpenCodeRuntimeExtras`](#runtime-extras) 中的 `replyToQuestion(id, answers)` 或 `rejectQuestion(id)`。

## 会话

`useOpenCodeSession` 会返回当前 OpenCode `Session` 对象（服务端会话元数据）：

```tsx
import { useOpenCodeSession } from "@assistant-ui/react-opencode";

function SessionInfo() {
  const session = useOpenCodeSession();
  if (!session) return null;
  return <div>Session: {session.id}</div>;
}
```

## 线程状态

`useOpenCodeThreadState` 会返回完整的投影线程状态（消息、运行状态、交互和同步元数据）。可将其用于高级自定义视图；大多数应用不需要它。

```tsx
import { useOpenCodeThreadState } from "@assistant-ui/react-opencode";

function RunStatus() {
  const state = useOpenCodeThreadState();
  return <div>Run: {state.runState.type}</div>;
}
```

返回的 `OpenCodeThreadState` 包括：

- `sessionId`、`session`、`sessionStatus`、`loadState`、`runState`
- `messageOrder`、`messagesById`、`pendingUserMessages`
- `childSessionsById`（OpenCode `task` 子会话投影，以会话 ID 为键）
- `interactions.permissions`（待处理 + 已解决）、`interactions.questions`（待处理 + 已回答 + 已拒绝）
- `unhandledEvents`、`sync` 时间戳

你还可以传入选择器，以读取特定的数据切片：

```tsx
const isStreaming = useOpenCodeThreadState((s) => s.runState.type === "streaming");
```

## 运行时扩展

`useOpenCodeRuntimeExtras` 提供会话级命令式操作：

```tsx
import { useOpenCodeRuntimeExtras } from "@assistant-ui/react-opencode";

function SessionActions() {
  const {
    fork,
    revert,
    unrevert,
    cancel,
    refresh,
    replyToPermission,
    replyToQuestion,
    rejectQuestion,
  } = useOpenCodeRuntimeExtras();
  // ...
}
```

| 操作 | 描述 |
| --- | --- |
| `fork(messageId)` | 从给定消息派生并创建新的会话；返回新会话 ID。 |
| `revert(messageId)` | 将会话恢复到给定消息所对应的状态。 |
| `unrevert()` | 撤销上一次恢复操作。 |
| `cancel()` | 取消正在进行的运行。 |
| `refresh()` | 强制重新获取会话消息。 |
| `replyToPermission(id, response)` | 回复权限请求（`"once"`、`"always"`、`"reject"`）。 |
| `replyToQuestion(id, answers)` | 回答待处理的问题。 |
| `rejectQuestion(id)` | 拒绝待处理的问题。 |

`useOpenCodePermissions` 和 `useOpenCodeQuestions` 是对 `replyToPermission` / `replyToQuestion` / `rejectQuestion` 以及状态中的 `pending` 切片的语法糖。

## 底层构建模块

对于绕过 `useOpenCodeRuntime` 的自定义集成：

| 导出项 | 用途 |
| --- | --- |
| `OpenCodeEventSource` | 将 OpenCode 服务器的事件流封装为类型化订阅。 |
| `OpenCodeThreadController` | 管理消息状态的会话级控制器。 |
| `createOpenCodeThreadState`、`reduceOpenCodeThreadState` | 纯状态 reducer，用于自行驱动状态机。 |
| `projectOpenCodeThreadMessages` | 将原始 OpenCode 消息投影为 assistant-ui 线程消息。 |
| `createOpencodeClient`（从 `@opencode-ai/sdk` 重新导出） | 使用自定义配置构建客户端。 |

这些内容仅适用于高级场景；大多数应用应直接使用 `useOpenCodeRuntime`。
