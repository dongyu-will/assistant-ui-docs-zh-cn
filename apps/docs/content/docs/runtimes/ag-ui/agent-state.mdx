---
title: Agent 状态
description: 通过 AG-UI 使用 useAgUiState 读取助手拥有的状态，并使用 useAgUiSetState 乐观地更新状态。
---

`useAgUiState` 会镜像 AG-UI agent 所拥有的状态，并在 agent 运行期间实时更新。`useAgUiSetState` 可用于应用乐观的本地更新，这些更新会随下一次运行一起发送。

## 基本用法

```tsx
import { useAgUiState, useAgUiSetState } from "@assistant-ui/react-ag-ui";
import { useAuiState } from "@assistant-ui/react";

type ResearchState = {
  topic: string;
  sources: string[];
};

const state = useAgUiState<ResearchState>();
// state: ResearchState | undefined  (latest agent state; updates live while the agent runs)

const setState = useAgUiSetState<ResearchState>();
// setState(next | (prev) => next)   (optimistic local update; sent with the NEXT run)

const isRunning = useAuiState((s) => s.thread.isRunning);
// isRunning: boolean                (whether the thread is currently running)
```

## 示例

在聊天旁边渲染 agent 状态，并通过 UI 中的控件推送一次乐观更新：

```tsx
"use client";

import { useAgUiState, useAgUiSetState } from "@assistant-ui/react-ag-ui";
import { useAuiState } from "@assistant-ui/react";
import { Thread } from "@/components/assistant-ui/elements/thread.aui";

type ResearchState = {
  topic: string;
  sources: string[];
};

export function ResearchAssistant() {
  const state = useAgUiState<ResearchState>();
  const setState = useAgUiSetState<ResearchState>();
  const isRunning = useAuiState((s) => s.thread.isRunning);

  return (
    <div className="flex h-full">
      <aside className="w-72 border-r p-4">
        <h2>Research state</h2>
        {state ? (
          <ul>
            <li>Topic: {state.topic}</li>
            <li>Sources: {state.sources.join(", ") || "none"}</li>
          </ul>
        ) : (
          <p>No agent state yet.</p>
        )}
        <button
          type="button"
          disabled={isRunning}
          onClick={() =>
            setState((prev) => ({
              topic: prev?.topic ?? "market analysis",
              sources: [...(prev?.sources ?? []), "sec-filings"],
            }))
          }
        >
          Prefer SEC filings
        </button>
        {isRunning && <p>Agent is running…</p>}
      </aside>
      <main className="flex-1">
        <Thread />
      </main>
    </div>
  );
}
```

当 `STATE_SNAPSHOT` 和 `STATE_DELTA` 事件到达时，面板会重新渲染。按钮会立即更新本地快照；该值会作为下一次运行输入中的 `state` 字段传入。

## 状态如何同步

AG-UI 协议会通过传输层传递 agent 状态：

- `STATE_SNAPSHOT` 替换完整的客户端快照。
- `STATE_DELTA` 对当前快照应用 JSON Patch。

运行时会在客户端应用这两种事件，因此 `useAgUiState` 始终反映合并后的最新快照。从 `useAgUiSetState` 调用 setter 会更新同一个本地快照。下一次运行时，运行时会自动将其作为运行输入中的 `state` 字段包含在内。

这适用于任何 AG-UI agent（Mastra、Pydantic AI、CrewAI、通过 AG-UI 适配器接入的 LangGraph，以及其他符合 AG-UI 的服务器）。

## 回写时机

`useAgUiSetState` 会先在本地进行乐观更新。只有下一次运行开始时，该值才会到达 agent。它不是连接到已经在进行中的运行的实时通道。你可以使用它暂存偏好设置、筛选条件，或其他希望下一轮看到的 agent 所有字段。

## 与其他状态的关系

请区分以下三层状态：

- **你的应用状态**仍由你管理（React 状态、URL、状态存储）。assistant-ui 不会拥有它。
- **`useAuiState`** 读取 assistant-ui 的客户端状态（消息、输入框、线程状态）。
- **`useAgUiState` / `useAgUiSetState`** 镜像 **agent** 所拥有的状态，并通过快照和增量在 AG-UI 传输层上同步。

对于 agent 通过协议维护为共享状态的字段，请使用 `useAgUiState` 和 `useAgUiSetState`。对于依赖聊天线程本身的 UI，请使用 `useAuiState`。其他所有状态都使用你自己的状态管理。
