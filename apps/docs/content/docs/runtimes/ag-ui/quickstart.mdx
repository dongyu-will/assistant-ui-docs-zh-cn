description: 针对 AG-UI 服务器的最简 HttpAgent + useAgUiRuntime 设置。

只需三步，即可使用 AG-UI agent 完成可用的聊天。假设你已经安装了软件包，并且可以访问 AG-UI 服务器；如果还没有，请从[概览](/docs/runtimes/ag-ui/overview)开始。

<Steps>
<Step>

### 接入运行时提供者

创建一个指向 AG-UI endpoint 的 `HttpAgent`，并将其传递给 `useAgUiRuntime`：

<PlatformTabs>
<Tab value="React">

```tsx title="app/MyRuntimeProvider.tsx"
"use client";

import { useMemo } from "react";
import { AssistantRuntimeProvider } from "@assistant-ui/react";
import { useAgUiRuntime } from "@assistant-ui/react-ag-ui";
import { HttpAgent } from "@ag-ui/client";

export function MyRuntimeProvider({
  children,
}: {
  children: React.ReactNode;
}) {
  const agent = useMemo(
    () =>
      new HttpAgent({
        url: "http://localhost:8000/agent",
      }),
    [],
  );

  const runtime = useAgUiRuntime({ agent });

  return (
    <AssistantRuntimeProvider runtime={runtime}>
      {children}
    </AssistantRuntimeProvider>
  );
}
```

AG-UI 服务器可访问后，运行时会将传入的事件（`TEXT_MESSAGE_*`、`TOOL_CALL_*`、`STATE_SNAPSHOT`等）解析为 assistant-ui 消息。

## 显示思考和推理

`showThinking`（默认值为 `true`）控制 `THINKING_*` 和 `REASONING_*` 事件是否作为可见的推理内容渲染到 UI 中：

```tsx
const runtime = useAgUiRuntime({
  agent,
  showThinking: false, // hide thinking blocks
});
```

## 添加适配器

附件、语音、听写、反馈、历史记录以及自定义线程列表，都可以通过标准适配器插槽支持。请参阅[适配器](/docs/runtimes/concepts/adapters)：

```tsx
const runtime = useAgUiRuntime({
  agent,
  adapters: { attachments, history, speech, feedback },
});
```

要支持多线程，请传入 `adapters.threadList`（实验性功能）；请参阅[运行时选项](/docs/runtimes/ag-ui/runtime-options#thread-list-experimental)。
