`@assistant-ui/react-ag-ui` 是 [AG-UI（Agent-User Interaction）协议](https://github.com/ag-ui-protocol/ag-ui). 的运行时适配器。它让你的 assistant-ui 前端能够与任何符合 AG-UI 的代理服务器通信，包括基于 CopilotKit 的后端。

## 适用场景

在以下情况下选择 AG-UI 运行时：

- 你的后端实现了 AG-UI 协议（例如 CopilotKit 代理、自定义 AG-UI 服务器）。
- 你希望通过一个协议获得流式文本、思考事件、推理事件、工具调用和状态快照。
- 你需要通过 `STATE_SNAPSHOT` 和 `STATE_DELTA` 事件同步代理端状态。
- 你的后端运行子代理，并且希望将每次运行渲染为发起该运行的工具调用下的嵌套会话。

如果你的后端不符合 AG-UI，请参阅[选择运行时](/docs/runtimes/pick-a-runtime)了解其他选项。

## 架构

`@assistant-ui/react-ag-ui` 构建于 `ExternalStoreRuntime` 之上（参见[架构](/docs/runtimes/concepts/architecture)）。运行时负责 AG-UI 事件解析和消息重建；你只需从 `@ag-ui/client` 提供一个 `HttpAgent`，适配器会处理线协议。

共享适配器（附件、语音、听写、反馈、历史记录）的工作方式与[适配器](/docs/runtimes/concepts/adapters)中描述的相同。

## 要求

- 一个兼容 AG-UI 的代理服务器。
- React 18 或 19。

