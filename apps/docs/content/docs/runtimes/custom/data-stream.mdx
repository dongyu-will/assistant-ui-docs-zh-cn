---
title: 数据流协议
description: 构建于 LocalRuntime 之上的标准消息流式传输协议。
---

`@assistant-ui/react-data-stream` 使用数据流协议，这是一种用于流式传输 AI 响应的标准化格式。它构建于 `LocalRuntime` 之上（参见[架构](/docs/runtimes/concepts/architecture)），因此所有 `LocalRuntime` 功能均适用。

该协议支持文本流式传输、工具调用、会话上下文、错误处理、取消操作和附件。

## 适用场景

在以下情况下选择此运行时：

- 你的后端已经支持数据流协议（或者你可以让它支持）。
- 你希望使用精简的消息流契约，而无需编写 `ChatModelAdapter`。
- 你正在从 AI SDK v4 迁移，并希望保留 v4 模式（参见 [v4 文档](/docs/runtimes/ai-sdk/v4-legacy)）。

如果你的后端提供更丰富的状态接口，可以改用 [`AssistantTransport`](/docs/runtimes/custom/assistant-transport)。

## 线路协议

`useDataStreamRuntime` 接受两种线路格式。当省略 `protocol` 时，它会先检测已知的 Vercel AI 响应标记，然后回退到 UI 消息流以保持兼容性。

| 协议 | 检测方式 | 匹配的后端 |
| --- | --- | --- |
| `"ui-message-stream"` | `x-vercel-ai-ui-message-stream: v1`，否则回退 | AI SDK v5+ 的 `result.toUIMessageStreamResponse()`（SSE） |
| `"data-stream"` | `x-vercel-ai-data-stream: v1` | 来自 `assistant-stream` 的 `createAssistantStreamResponse`，或 AI SDK v4 的 `toDataStreamResponse()`（Vercel data stream v1） |

仅当自定义端点不会保留或公开响应标记时，才需要显式设置 `protocol`。

### 创建后端端点

你的后端应接受 POST 请求并返回数据流响应：
对于 React Native 和 Ink，请在单独的后端项目中托管此端点，并让客户端运行时指向其绝对 URL。

```ts title="app/api/chat/route.ts"
import { createAssistantStreamResponse } from "assistant-stream";

export async function POST(request: Request) {
  const { messages, tools, system, threadId } = await request.json();

  return createAssistantStreamResponse(async (controller) => {
    const stream = await processWithAI({ messages, tools, system });
    for await (const chunk of stream) {
      controller.appendText(chunk.text);
    }
  });
}
```

请求正文包含 `messages`、`tools`、`system`（如果已配置）以及 `threadId`。

`createAssistantStreamResponse` 返回标准的 Web `Response`。它可以直接用于任何 Fetch 风格的路由（Next.js App Router、Hono、Bun.serve、Deno、Cloudflare Workers），无需额外处理。对于使用自有响应对象的框架（Express、Fastify），请复制 `status` 和 `headers`，然后将 `response.body` 管道传输到框架的可写流中。避免将 `Response` 正文发送到生命周期已由框架控制的 `res` 对象中（这会导致 `ERR_INVALID_STATE: Controller is already closed` 失败模式）。

## 请求头和身份验证

```tsx
const runtime = useDataStreamRuntime({
  api: "/api/chat",
  headers: { Authorization: `Bearer ${token}`, "X-Custom-Header": "value" },
  credentials: "include",
});
```

针对每个请求进行评估：

```tsx
const runtime = useDataStreamRuntime({
  api: "/api/chat",
  headers: async () => ({
    Authorization: `Bearer ${await getAuthToken()}`,
  }),
  body: async () => ({
    requestId: crypto.randomUUID(),
    timestamp: Date.now(),
    signature: await computeSignature(),
  }),
});
```

## 事件回调

```tsx
const runtime = useDataStreamRuntime({
  api: "/api/chat",
  onResponse: (response) => console.log("status:", response.status),
  onFinish: (message) => console.log("done:", message),
  onError: (error) => console.error(error),
  onCancel: () => console.log("cancelled"),
});
```

## 工具集成

<Callout type="warn">
数据流运行时不支持人在回路工具（`unstable_humanToolNames`、`human()` 中断）。如果需要这些功能，请直接使用 [`LocalRuntime`](/docs/runtimes/custom/local-runtime#human-in-the-loop-tools)。
</Callout>

### 前端工具

使用 `toToolsJSONSchema` 序列化客户端工具：

```tsx
import { tool } from "@assistant-ui/react";
import { toToolsJSONSchema } from "assistant-stream";

const myTools = {
  get_weather: tool({
    description: "Get current weather",
    parameters: z.object({ location: z.string() }),
    execute: async ({ location }) => {
      const weather = await fetchWeather(location);
      return `Weather in ${location}: ${weather}`;
    },
  }),
};

const runtime = useDataStreamRuntime({
  api: "/api/chat",
  body: { tools: toToolsJSONSchema(myTools) },
});
```

### 后端工具处理

```ts title="Backend tool handling"
const { tools } = await request.json();
const response = await ai.generateText({ messages, tools });
```

工具结果会自动流式传回。

## 消息转换

### 通用方式（推荐）

```tsx
import { toGenericMessages, toToolsJSONSchema } from "assistant-stream";

const genericMessages = toGenericMessages(messages);
const toolSchemas = toToolsJSONSchema(tools);
```

`GenericMessage` 是 `system`、`user`（包含文本和文件部分）、`assistant`（包含文本和工具调用部分）以及 `tool`（包含工具结果部分）的联合类型。它可以轻松转换为任何 LLM 提供商所需的格式。

### AI SDK 专用方式

```tsx
import { toLanguageModelMessages } from "@assistant-ui/react-data-stream";

const languageModelMessages = toLanguageModelMessages(messages, {
  unstable_includeId: true,
});
```

`toLanguageModelMessages` 内部使用 `toGenericMessages`，并进行 AI SDK 专用转换。对于新的集成，建议直接使用 `toGenericMessages`。

## LocalRuntimeOptions

`useDataStreamRuntime` 除自身选项外，还接受所有 `LocalRuntimeOptions` 选项。`chatModel` 适配器插槽由内部处理，无法覆盖。

```tsx
const runtime = useDataStreamRuntime({
  api: "/api/chat",
  initialMessages: [
    { role: "user", content: [{ type: "text", text: "Hello" }] },
    { role: "assistant", content: [{ type: "text", text: "Hi!" }] },
  ],
  maxSteps: 5,
  cloud, // see "AssistantCloud" in /docs/runtimes/concepts/threads
  adapters: {
    attachments: myAttachmentAdapter,
    history: myHistoryAdapter,
    speech: mySpeechAdapter,
    feedback: myFeedbackAdapter,
    suggestion: mySuggestionAdapter,
  },
});
```

有关适配器契约，请参见[适配器](/docs/runtimes/concepts/adapters)；有关继承的选项，请参见 [LocalRuntime](/docs/runtimes/custom/local-runtime)。

## 错误处理

运行时会自动处理常见的错误场景：

- 网络错误：使用指数退避策略重试。
- 流中断：平稳处理并保留部分内容。
- 工具执行错误：在 UI 中以错误状态显示。
- 取消操作：正确处理 abort signal。
