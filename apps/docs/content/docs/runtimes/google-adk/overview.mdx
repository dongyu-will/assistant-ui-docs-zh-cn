`@assistant-ui/react-google-adk` 集成了 [Google ADK JS](https://github.com/google/adk-js), Google 官方的 TypeScript 智能体框架，同时也支持 ADK Python 后端。它支持文本流式输出、工具调用、多智能体编排、代码执行、会话状态、工具确认、身份验证流程和输入请求。

## 适用场景

在以下情况下选择 Google ADK 运行时：

- 使用 ADK JS（`LlmAgent`、顺序 / 并行 / 循环智能体）或 ADK Python 构建智能体。
- 希望获得对 ADK HITL（人在回路）原语的一流支持：工具确认、身份验证凭据流程、工作流输入请求。
- 需要多智能体作者和分支跟踪、智能体转移事件，以及 grounding / 引用元数据。

## 架构

`@assistant-ui/react-google-adk` 构建于 `ExternalStoreRuntime` 之上（参见[架构](/docs/runtimes/concepts/architecture)）。作为运行时适配器提供的功能在各处的工作方式相同；请参见[适配器](/docs/runtimes/concepts/adapters)。

该包会自动将 ADK Python 后端中的 snake_case 事件字段规范化为 camelCase。无需进行配置；连接到 ADK JS 或 ADK Python 服务器即可。所有嵌套字段（`function_call` → `functionCall`、`requested_tool_confirmations` → `requestedToolConfirmations`）都会得到处理。

## 要求

- 在服务器上运行的 Google ADK 智能体（ADK JS 或 ADK Python）。
- React 18 或 19。
