## 工具确认

当 ADK 的 `SecurityPlugin` 或工具回调在执行工具前请求用户确认时，使用 `useAdkToolConfirmations` 读取待处理的请求，并使用 `useAdkConfirmTool` 进行响应：

<PlatformTabs>
<Tab value="React">

```tsx
import {
  useAdkToolConfirmations,
  useAdkConfirmTool,
} from "@assistant-ui/react-google-adk";

function ToolConfirmationUI() {
  const confirmations = useAdkToolConfirmations();
  const confirmTool = useAdkConfirmTool();

  if (confirmations.length === 0) return null;

  return confirmations.map((conf) => (
    <div key={conf.toolCallId}>
      <p>
        Tool "{conf.toolName}" wants to run. {conf.hint}
      </p>
      <button onClick={() => confirmTool(conf.toolCallId, true)}>Approve</button>
      <button onClick={() => confirmTool(conf.toolCallId, false)}>Deny</button>
    </div>
  ));
}
```

</Tab>

```tsx
      <Text>
        Tool "{active.toolName}" wants to run. {active.hint}
      </Text>
      <Text>Press y to approve, n to deny.</Text>
    </Box>
  );
}
```

## 身份验证请求

当工具需要 OAuth 或其他身份验证时，使用 `useAdkAuthRequests` 读取待处理的请求，并使用 `useAdkSubmitAuth` 提交凭据：

<PlatformTabs>
<Tab value="React">

```tsx
import {
  useAdkAuthRequests,
  useAdkSubmitAuth,
  type AdkAuthCredential,
} from "@assistant-ui/react-google-adk";

function AuthUI() {
  const authRequests = useAdkAuthRequests();
  const submitAuth = useAdkSubmitAuth();

  if (authRequests.length === 0) return null;

  return authRequests.map((req) => (
    <div key={req.toolCallId}>
      <button
        onClick={() => {
          const credential: AdkAuthCredential = {
            authType: "oauth2",
            oauth2: { accessToken: "..." },
          };
          submitAuth(req.toolCallId, credential);
        }}
      >
        Authenticate
      </button>
    </div>
  ));
}
```

</Tab>

## 输入请求

当 ADK Python 2.0+ Workflow 的 `RequestInput` 节点暂停执行并向用户提问时，ADK 会发出标记为长时间运行的 `adk_request_input` 函数调用。在工具 UI 中使用 `useAdkSubmitInput` 进行响应；该辅助函数会将答案包装为 `{ result }`，以匹配 ADK 的 `unwrap_response` 契约，因此 Workflow 节点恢复执行时会获得未包装的值：

<PlatformTabs>
<Tab value="React">

```tsx
import type { ToolCallMessagePartComponent } from "@assistant-ui/react";
import { useAdkSubmitInput } from "@assistant-ui/react-google-adk";

type RequestInputArgs = {
  interrupt_id?: string;
  message?: string;
  payload?: unknown;
  response_schema?: unknown;
};

export const RequestInputToolUI: ToolCallMessagePartComponent<
  RequestInputArgs,
  unknown
> = function RequestInputUI({ toolCallId, args, result }) {
    const submitInput = useAdkSubmitInput();

    if (result !== undefined) {
      return <p>Answered: {String(result)}</p>;
    }

    return (
      <form
        onSubmit={(e) => {
          e.preventDefault();
          const value = (
            e.currentTarget.elements.namedItem("answer") as HTMLInputElement
          ).value;
          submitInput(toolCallId, value);
        }}
      >
        <p>{args.message ?? "Please provide input:"}</p>
        <input name="answer" autoFocus />
        <button type="submit">Submit</button>
      </form>
    );
};
```

</Tab>
<Tab value="React Native">

```tsx
import type { ToolCallMessagePartComponent } from "@assistant-ui/react-native";
import { useAdkSubmitInput } from "@assistant-ui/react-google-adk";
import { useState } from "react";
import { Pressable, Text, TextInput, View } from "react-native";

type RequestInputArgs = {
  interrupt_id?: string;
  message?: string;
  payload?: unknown;
  response_schema?: unknown;
};

export const RequestInputToolUI: ToolCallMessagePartComponent<
  RequestInputArgs,
  unknown
> = function RequestInputUI({ toolCallId, args, result }) {
    const submitInput = useAdkSubmitInput();
    const [value, setValue] = useState("");

    if (result !== undefined) {
      return <Text>Answered: {String(result)}</Text>;
    }

    return (
      <View>
        <Text>{args.message ?? "Please provide input:"}</Text>
        <TextInput value={value} onChangeText={setValue} autoFocus />
        <Pressable onPress={() => submitInput(toolCallId, value)}>
          <Text>Submit</Text>
        </Pressable>
      </View>
    );
};
```

</Tab>
<Tab value="React Ink">

```tsx
import type { ToolCallMessagePartComponent } from "@assistant-ui/react-ink";
import { useAdkSubmitInput } from "@assistant-ui/react-google-adk";
import { useState } from "react";
import { Box, Text, useInput } from "ink";

type RequestInputArgs = {
  interrupt_id?: string;
  message?: string;
  payload?: unknown;
  response_schema?: unknown;
};

export const RequestInputToolUI: ToolCallMessagePartComponent<
  RequestInputArgs,
  unknown
> = function RequestInputUI({ toolCallId, args, result }) {
    const submitInput = useAdkSubmitInput();
    const [value, setValue] = useState("");

    useInput((input, key) => {
      if (result !== undefined) return;
      if (key.return) submitInput(toolCallId, value);
      else if (key.backspace || key.delete) setValue((text) => text.slice(0, -1));
      else if (input) setValue((text) => text + input);
    });

    if (result !== undefined) {
      return <Text>Answered: {String(result)}</Text>;
    }

    return (
      <Box flexDirection="column">
        <Text>{args.message ?? "Please provide input:"}</Text>
        <Text>{value}</Text>
        <Text dimColor>Press enter to submit.</Text>
      </Box>
    );
};
```

<Callout type="info">
`adk_request_input` 仅由 ADK Python 2.0+ Workflow 的 `RequestInput` 节点发出；ADK JS 没有对应功能。始终通过工具 UI 使用 `useAdkSubmitInput` 进行响应。HITL 中断会自动排除在 `autoCancelPendingToolCalls` 之外，因此在输入框中输入普通消息不会覆盖待处理的中断。
</Callout>

`useAdkSubmitInput` 是通用 `addResult` 的语法糖。如果你愿意，也可以直接在 render 函数内部调用 `addResult({ result: value })`。无论采用哪种方式，都必须使用 `{ result }` 包装器：适配器会先将值转换为 JSON 字符串再发送，而 ADK 的 `unwrap_response` 会在后端恢复 Workflow 节点执行前将其解包。

## 工件

跟踪助手创建或修改的文件工件：

```ts
import { useAdkArtifacts } from "@assistant-ui/react-google-adk";

function ArtifactList() {
  const artifacts = useAdkArtifacts();
  // Record<string, number> — filename to version number
}
```

### 获取工件

使用 `createAdkSessionAdapter` 时（参见 [API 参考](/docs/runtimes/google-adk/api#direct-adk-server-connection)），返回的 `artifacts` 对象提供了从 ADK 服务器获取工件内容的函数：

```ts
const { artifacts } = createAdkSessionAdapter({ apiUrl, appName, userId });

// List all artifact filenames in a session
const filenames = await artifacts.list(sessionId);

// Load artifact content (latest version)
const data = await artifacts.load(sessionId, "document.pdf");
// data.inlineData?.data — base64 content
// data.inlineData?.mimeType — MIME type
// data.text — text content (if text artifact)

// Load a specific version
const v1 = await artifacts.load(sessionId, "document.pdf", 1);

// List all versions
const versions = await artifacts.listVersions(sessionId, "document.pdf");

// Delete an artifact
await artifacts.delete(sessionId, "document.pdf");
```

此 Hook 会报告 ADK 通过 `long_running_tool_ids` 标记的每个工具调用，包括 HITL 中断。若要响应特定的 HITL 类型，请参阅[工具确认](#tool-confirmations)、[身份验证请求](#auth-requests)或[输入请求](#input-requests)。

同一组标记还决定哪些工具调用由客户端负责。已注册前端工具的 `execute` 仅会在 ADK 将调用标记为长时间运行时执行，因为 ADK 会自行解析其他所有调用，并在生成自身响应前将调用交给客户端。将由客户端执行的工具注册为 agent 上的 `LongRunningFunctionTool`。

## 按范围划分的会话状态

ADK 使用键前缀来限定状态范围。这些辅助函数会过滤并移除前缀：

```ts
import {
  useAdkAppState,
  useAdkUserState,
  useAdkTempState,
} from "@assistant-ui/react-google-adk";

function StateDebug() {
  const appState = useAdkAppState(); // app:* keys (app-level, shared)
  const userState = useAdkUserState(); // user:* keys (user-level)
  const tempState = useAdkTempState(); // temp:* keys (not persisted)
}
```

使用 `useAdkSessionState()` 获取完整且未经筛选的状态增量。

## 结构化事件

将原始 ADK 事件转换为类型化的结构化事件，以供自定义渲染器使用：

```ts
import {
  toAdkStructuredEvents,
  AdkEventType,
  type AdkStructuredEvent,
} from "@assistant-ui/react-google-adk";

const structured = toAdkStructuredEvents(event);
for (const e of structured) {
  switch (e.type) {
    case AdkEventType.CONTENT:
      console.log("Text:", e.content);
      break;
    case AdkEventType.THOUGHT:
      console.log("Reasoning:", e.content);
      break;
    case AdkEventType.TOOL_CALL:
      console.log("Tool:", e.call.name, e.call.args);
      break;
    case AdkEventType.ERROR:
      console.error(e.errorMessage);
      break;
  }
}
```

## Hooks 参考

| Hook | 描述 |
| --- | --- |
| `useAdkAgentInfo()` | 当前 agent 名称和分支路径。 |
| `useAdkSessionState()` | 累积的完整会话状态增量。 |
| `useAdkAppState()` | 应用级状态（移除 `app:*` 前缀）。 |
| `useAdkUserState()` | 用户级状态（移除 `user:*` 前缀）。 |
| `useAdkTempState()` | 临时状态（移除 `temp:*` 前缀，不会持久化）。 |
| `useAdkSend()` | 发送原始 ADK 消息。 |
| `useAdkConfirmTool()` | 确认或拒绝待处理的工具确认。 |
| `useAdkSubmitAuth()` | 为待处理的身份验证请求提交身份验证凭据。 |
| `useAdkSubmitInput()` | 提交用户对待处理 `adk_request_input` HITL 中断的回答。 |
| `useAdkToolConfirmations()` | 待处理的工具确认请求。 |
| `useAdkAuthRequests()` | 待处理的身份验证凭据请求。 |
| `useAdkLongRunningToolIds()` | 等待输入的长时间运行工具的 ID。 |
| `useAdkArtifacts()` | 工件增量（文件名 → 版本）。 |
| `useAdkEscalation()` | 是否请求了升级。 |
| `useAdkMessageMetadata()` | 每条消息的 grounding、引用和使用元数据。 |
