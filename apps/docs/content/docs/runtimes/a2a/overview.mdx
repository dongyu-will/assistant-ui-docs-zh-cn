`@assistant-ui/react-a2a` 是 [A2A（Agent-to-Agent）v1.0 协议](https://github.com/a2aproject/A2A). 的运行时适配器。当你的后端使用 A2A 时可以使用它；该适配器会处理底层协议，让你专注于 UI。

## 适用场景

在以下情况下选择 A2A 运行时：

- 你拥有符合 A2A v1.0 的 Agent 服务器，或者正在构建一个 Agent 服务器并希望获得参考客户端。
- 你希望在 UI 中呈现任务状态的流式传输、工件以及协议的完整状态机。
- 你需要支持多租户或扩展感知的 A2A 客户端。

如果你的后端不符合 A2A，请参阅[选择运行时](/docs/runtimes/pick-a-runtime)了解其他选项。

## 架构

`@assistant-ui/react-a2a` 基于 `ExternalStoreRuntime` 构建（请参阅[架构](/docs/runtimes/concepts/architecture)）。作为运行时适配器提供的功能（附件、语音、反馈、历史记录、线程）在其他地方的工作方式相同；请参阅[适配器](/docs/runtimes/concepts/adapters)。

## 要求

- 符合 A2A v1.0 的 Agent 服务器。
- React 18 或 19。
