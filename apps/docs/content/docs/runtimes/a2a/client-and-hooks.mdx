## A2AClient

内置的 `A2AClient` 负责处理与 A2A 服务器的所有通信：JSON 序列化、SSE 流式传输、ProtoJSON 枚举规范化以及结构化错误处理。

```ts
import { A2AClient } from "@assistant-ui/react-a2a";

const client = new A2AClient({
  baseUrl: "https://my-agent.example.com",
  headers: { Authorization: "Bearer <token>" },
  tenant: "my-org",
  extensions: ["urn:a2a:ext:my-extension"],
  fetchOptions: { credentials: "include" },
});
```

将预构建的客户端传递给 `useA2ARuntime`：

```tsx
const runtime = useA2ARuntime({ client });
```

### 客户端选项

| 选项 | 类型 | 描述 |
| --- | --- | --- |
| `baseUrl` | `string` | A2A 服务器的基础 URL。 |
| `basePath` | `string` | API 端点的可选路径前缀（例如 `"/v1"`）。不会影响代理卡发现。 |
| `headers` | `Record<string, string>` 或 `() => Record<string, string>` | 静态或动态请求头（例如用于身份验证令牌）。 |
| `tenant` | `string` | 多租户服务器的租户 ID（会添加到 URL 路径前）。 |
| `extensions` | `string[]` | 通过 `A2A-Extensions` 请求头协商的扩展 URI。 |
| `fetchOptions` | `RequestInit`（部分） | 应用于每个请求的额外 fetch 选项（例如 `{ credentials: "include" }`）。`headers`、`body`、`method` 和 `signal` 由内部管理。 |

### 客户端方法

| 方法 | 描述 |
| --- | --- |
| `sendMessage(message, configuration?, metadata?)` | 发送消息（非流式）。 |
| `streamMessage(message, configuration?, metadata?)` | 使用 SSE 流式传输发送消息。 |
| `getTask(taskId, historyLength?)` | 根据 ID 获取任务。 |
| `listTasks(request?)` | 使用筛选和分页列出任务。 |
| `cancelTask(taskId, metadata?)` | 取消正在进行的任务。 |
| `subscribeToTask(taskId)` | 订阅任务的 SSE 更新。 |
| `getAgentCard()` | 从 `/.well-known/agent-card.json` 获取代理卡。 |
| `getExtendedAgentCard()` | 获取扩展版（经过身份验证的）代理卡。 |
| `createTaskPushNotificationConfig(config)` | 创建推送通知配置。 |
| `getTaskPushNotificationConfig(taskId, configId)` | 获取推送通知配置。 |
| `listTaskPushNotificationConfigs(taskId)` | 列出推送通知配置。 |
| `deleteTaskPushNotificationConfig(taskId, configId)` | 删除推送通知配置。 |

## useA2ARuntime 选项

传递预构建的 `client`，或传递 `baseUrl`（运行时会为你创建客户端）。其他选项会叠加在其上。

| 选项 | 类型 | 描述 |
| --- | --- | --- |
| `client` | `A2AClient` | 预构建的 A2A 客户端实例（提供此选项或 `baseUrl`）。 |
| `baseUrl` | `string` | A2A 服务器 URL（自动创建客户端）。 |
| `basePath` | `string` | API 端点的路径前缀。仅与 `baseUrl` 一起使用。 |
| `tenant` | `string` | 多租户服务器的租户 ID。仅与 `baseUrl` 一起使用。 |
| `headers` | `Record<string, string>` 或 `() => Record<string, string>` | 自动创建的客户端的请求头。 |
| `extensions` | `string[]` | 要协商的扩展 URI。仅与 `baseUrl` 一起使用。 |
| `fetchOptions` | `RequestInit`（部分） | 自动创建的客户端的额外 fetch 选项（例如 `{ credentials: "include" }`）。`headers`、`body`、`method` 和 `signal` 由内部管理。仅与 `baseUrl` 一起使用。 |
| `contextId` | `string` | 会话的初始上下文 ID。 |
| `configuration` | `A2ASendMessageConfiguration` | 默认的发送消息配置。 |
| `onError` | `(error: Error) => void` | 错误回调。 |
| `onCancel` | `() => void` | 取消回调。 |
| `onArtifactComplete` | `(artifact: A2AArtifact) => void` | 增量工件完成时触发。 |
| `adapters.attachments` | `AttachmentAdapter` | 自定义附件处理。请参阅[适配器](/docs/runtimes/concepts/adapters#attachment-adapter)。 |
| `adapters.speech` | `SpeechSynthesisAdapter` | 文本转语音。请参阅[适配器](/docs/runtimes/concepts/adapters#speech-adapter)。 |
| `adapters.feedback` | `FeedbackAdapter` | 收集反馈。请参阅[适配器](/docs/runtimes/concepts/adapters#feedback-adapter)。 |
| `adapters.history` | `ThreadHistoryAdapter` | 消息持久化。请参阅[适配器](/docs/runtimes/concepts/adapters#history-adapter)。 |
| `adapters.threadList` | `UseA2AThreadListAdapter` | 切换线程。请参阅[线程](/docs/runtimes/concepts/threads)。 |

## Hooks

### 任务状态

`useA2ATask` 返回当前的 A2A 任务对象，其中包括任务状态和状态消息。

<PlatformTabs>
<Tab value="React">

```tsx
import { useA2ATask } from "@assistant-ui/react-a2a";

function TaskStatus() {
  const task = useA2ATask();
  if (!task) return null;
  return (
    <div>
      Task {task.id}: {task.status.state}
    </div>
  );
}
```

## 任务状态

A2A 协议定义了 9 种任务状态。运行时会将它们映射为 assistant-ui 消息状态：

| A2A 任务状态 | 描述 | 消息状态 |
| --- | --- | --- |
| `unspecified` | 未知或默认状态。 | `running` |
| `submitted` | 任务已确认。 | `running` |
| `working` | 任务进行中。 | `running` |
| `completed` | 任务已完成。 | `complete` |
| `failed` | 任务出错。 | `incomplete (error)` |
| `canceled` | 任务已取消。 | `incomplete (cancelled)` |
| `rejected` | 代理拒绝了任务。 | `incomplete (error)` |
| `input_required` | 代理需要用户输入。 | `requires-action` |
| `auth_required` | 需要身份验证。 | `requires-action` |

<Callout type="info">
当任务进入 `input_required` 状态时，用户可以正常继续会话。运行时会使用相同的 `taskId` 发送下一条消息，以恢复任务。
</Callout>

## 工件

A2A 代理可以在返回响应的同时生成工件（文件、代码、数据）。工件会在流式传输期间累积，并可通过 `useA2AArtifacts` 访问。

运行时支持：

- 通过 `append` 模式进行**增量工件流式传输**。
- 通过 `onArtifactComplete` 回调发送**工件完成通知**。
- 每次新运行时**自动重置**工件。

```tsx
const runtime = useA2ARuntime({
  baseUrl: "http://localhost:9999",
  onArtifactComplete: (artifact) => {
    console.log("Artifact ready:", artifact.name);
  },
});
```

## 流式与非流式

运行时会根据代理的能力自动选择通信模式：

- 如果代理卡指示支持 `capabilities.streaming: true`（或该字段未设置），运行时会使用带 SSE 的 `POST /message:stream`。
- 如果 `capabilities.streaming: false`，运行时会回退到 `POST /message:send`。

## 错误处理

客户端会抛出 `A2AError` 实例，其中包含遵循 `google.rpc.Status` 格式的结构化错误信息：

```tsx
import { A2AError } from "@assistant-ui/react-a2a";

const runtime = useA2ARuntime({
  baseUrl: "http://localhost:9999",
  onError: (error) => {
    if (error instanceof A2AError) {
      console.log(error.code); // HTTP status code
      console.log(error.status); // e.g. "NOT_FOUND"
      console.log(error.details); // google.rpc.ErrorInfo details
    }
  },
});
```

## 多租户

对于多租户 A2A 服务器，请传递 `tenant` 选项：

```ts
const client = new A2AClient({
  baseUrl: "https://agent.example.com",
  tenant: "my-org",
});
```

此选项会将 `/{tenant}` 添加到所有 API 路径前（例如 `/my-org/message:send`）。

| 功能 | 是否支持 |
| --- | --- |
| 流式传输（SSE） | 是 |
| 非流式回退 | 是 |
| 全部 9 种任务状态 | 是 |
| 工件（文本、数据、文件） | 是 |
| 代理卡发现 | 是 |
| 多租户 | 是 |
| 结构化错误 | 是 |
| 推送通知 CRUD | 是 |
| 扩展协商 | 是 |
| 任务取消 | 是 |
| 消息编辑 | 是 |
| 消息重新加载 | 是 |
| 历史记录持久化 | 通过[历史记录适配器](/docs/runtimes/concepts/adapters#history-adapter) |
| 线程列表管理 | 通过[线程列表适配器](/docs/runtimes/concepts/threads) |
