原语是 assistant-ui 的无样式层：可访问的 React 组件，负责处理 AI 聊天的所有连接工作，包括状态管理、键盘快捷键、自动滚动、流式传输和工具调用，同时将所有视觉决策交给你。

## 原语还是元素？

assistant-ui 提供两个层级：

- **[元素](/elements)** 是使用原语构建的、带样式且可安装的组件。每个元素页面都会展示实时演示、安装命令，以及两种使用方式：连接到运行时，或通过普通 props 驱动。如果你想使用现成的 UI，或查找其他与元素相关的内容，请查看[元素目录](/elements)；本节不会重复介绍其中的内容。
- **原语**（本节）是元素的构成部分。当你需要的 UI 不存在对应元素时，请使用原语，例如浮动输入框、自定义消息布局或行内编辑体验。

```tsx
import { ComposerPrimitive } from "@assistant-ui/react";

<ComposerPrimitive.Root>
  <ComposerPrimitive.Input placeholder="Ask anything..." />
  <ComposerPrimitive.Send>Send</ComposerPrimitive.Send>
</ComposerPrimitive.Root>
```

这会渲染一个无样式的 `<form>`，其中包含一个 `<textarea>` 和一个 `<button>`。它没有样式，也不带任何预设，但已经处理了按 Enter 提交、焦点管理、空状态禁用和流式传输状态。

## 工作方式

每个原语都遵循同一种模式，其设计灵感来自 [Radix UI](https://www.radix-ui.com/):

- **`Primitive.Root`**：向子部件提供上下文的容器
- **`Primitive.PartName`**：单独的元素（输入框、按钮、文本等）
- **`asChild`**：将原语行为合并到你自己的元素上，而不是渲染一个包装器
- **`AuiIf`**：根据状态进行条件渲染

原语会读取最近的运行时上下文。将它们放在 `AssistantRuntimeProvider` 内部后，无需逐层传递 props 或手动连接状态即可工作。

## 常见错误

- 忘记为原语包裸运行时上下文（`AssistantRuntimeProvider` + 运行时 hook）
- 将已弃用的 props 与当前 API 混用（`submitOnEnter`、`autoSend`、旧版 `Suggestion`）
- 在错误的上下文中挂载原语（`ActionBarPrimitive` / `BranchPickerPrimitive` 位于 `MessagePrimitive.Root` 外部）
- 无意中使用不稳定的 props（`unstable_*` API）
