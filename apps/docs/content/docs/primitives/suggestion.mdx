## 快速开始

使用迭代器模式的建议列表：

```tsx
import { ThreadPrimitive, SuggestionPrimitive } from "@assistant-ui/react";

<ThreadPrimitive.Suggestions>
  {() => <MySuggestionItem />}
</ThreadPrimitive.Suggestions>

function MySuggestionItem() {
  return (
    <SuggestionPrimitive.Trigger className="rounded-lg border px-3 py-2 hover:bg-muted">
      <SuggestionPrimitive.Title />
    </SuggestionPrimitive.Trigger>
  );
}
```

`ThreadPrimitive.Suggestions` 会遍历可用建议，并为每条建议渲染你的组件。在组件内部，`SuggestionPrimitive` 部件会自动从建议上下文中读取数据。

<Callout type="info">
运行时设置：原语需要运行时上下文。将 UI 包裹在带有运行时的 `AssistantRuntimeProvider` 中（例如 `useLocalRuntime(...)`）。请参阅[选择运行时](/docs/runtimes/pick-a-runtime)。
</Callout>

## 核心概念

### 基于上下文的渲染

SuggestionPrimitive 部件会从建议上下文中读取数据。使用 `ThreadPrimitive.Suggestions` 提供此上下文。它会遍历线程中的建议，并为每条建议渲染你的组件：

```tsx
<ThreadPrimitive.Suggestions>
  {() => <MySuggestion />}
</ThreadPrimitive.Suggestions>
```

如果需要更灵活地控制布局，也可以使用 `ThreadPrimitive.SuggestionByIndex` 按索引渲染特定建议。

### 标题和描述

建议支持两个用于结构化展示的文本部件：

- **`Title`**：主要文本（例如“撰写一篇博客文章”）
- **`Description`**：次要文本——渲染建议配置中的 `label` 字段（例如 `{ prompt: "...", label: "About React Server Components" }`）

两者都会渲染一个 `<span>`，并接受 `children` 以覆盖状态中的值：

```tsx
<SuggestionPrimitive.Title>Custom title</SuggestionPrimitive.Title>
```

### 发送与填充

`Trigger` 的 `send` 属性控制点击后的行为：

- **`send={true}`**：立即将建议作为新消息发送。运行正在进行时，在支持排队的运行时中，建议会进入队列（不会修改输入框草稿）；否则会禁用触发器。
- **`send={false}`**（默认值）：填充输入框文本，以便用户在发送前进行编辑

```tsx
// Send immediately
<SuggestionPrimitive.Trigger send>
  <SuggestionPrimitive.Title />
</SuggestionPrimitive.Trigger>

// Populate composer for editing
<SuggestionPrimitive.Trigger>
  <SuggestionPrimitive.Title />
</SuggestionPrimitive.Trigger>
```

### clearComposer

当使用 `send={false}` 时，`clearComposer` 属性控制建议是替换还是追加到现有输入框文本：

- **`clearComposer={true}`**（默认值）：替换当前输入框文本
- **`clearComposer={false}`**：将建议追加到现有文本之后

### 静态配置与运行时建议

建议有两种数据流：

- **静态配置**通过 `suggestions` 作用域传递。在运行时提供程序中向 `Suggestions(...)` 传入数组，然后使用 `ThreadPrimitive.Suggestions` 进行渲染。适合欢迎屏幕提示。
- **运行时/动态建议**通过 `thread.suggestions` 传递。可以通过 `SuggestionAdapter`（本地运行时）或 `useExternalStoreRuntime` 上的 `suggestions` 字段填充；使用 shadcn `ThreadFollowupSuggestions` 组件，或使用读取 `useAuiState((s) => s.thread.suggestions)` 的自定义组件进行渲染。适合某轮对话结束后的后续提示。

未提供静态配置时，`suggestions` 作用域会从 `thread.suggestions` 派生，因此运行时建议也会通过 `ThreadPrimitive.Suggestions` 渲染。静态的 `Suggestions(...)` 配置优先于派生值。

请参阅[建议提示](/docs/guides/suggestions)了解端到端示例。

### ThreadPrimitive.Suggestion

`ThreadPrimitive.Suggestion` 是一个自包含按钮，通过属性接收 `prompt`，而不是从 `suggestions` 作用域中读取。两种方式都会执行相同的触发行为，包括上文所述的排队和禁用处理，因此选择哪种方式取决于提示的来源：

- 渲染 `suggestions` 作用域：使用带有 `SuggestionPrimitive` 部件的 `ThreadPrimitive.Suggestions`，它们会为你提供标题和描述。
- 从其他位置渲染提示：使用 `ThreadPrimitive.Suggestion`，直接传入提示。

```tsx
// Prompts from the suggestions scope
<ThreadPrimitive.Suggestions>
  {() => <MySuggestionItem />}
</ThreadPrimitive.Suggestions>

// A prompt the caller already holds
<ThreadPrimitive.Suggestion prompt="Write a blog post" />
```

第二种情况不是备用方案。应用同时配置静态建议后，渲染 `thread.suggestions` 的组件无法再通过 `suggestions` 作用域读取这些建议，因为静态配置优先于派生值。shadcn `ThreadFollowupSuggestions` 组件会读取 `thread.suggestions`，并使用 `ThreadPrimitive.Suggestion` 渲染每个条目，原因正在于此。

`autoSend` 和 `method` 属性已弃用；请优先使用 `send` 和 `clearComposer`。

## 部件

### 标题

渲染建议标题。当未设置 `asChild` 时，会渲染一个 `<span>` 元素。

```tsx
<SuggestionPrimitive.Title />
```

### 描述

渲染建议的次要描述文本。当未设置 `asChild` 时，会渲染一个 `<span>` 元素。

```tsx
<SuggestionPrimitive.Description />
```

### 触发器

用于发送或填充建议的可点击按钮。当未设置 `asChild` 时，会渲染一个 `<button>` 元素。

```tsx
<SuggestionPrimitive.Trigger send className="rounded-lg border px-3 py-2 hover:bg-muted">
  <SuggestionPrimitive.Title />
</SuggestionPrimitive.Trigger>
```

## 模式

### 欢迎屏幕网格

```tsx
function WelcomeSuggestions() {
  return (
    <AuiIf condition={(s) => s.thread.isEmpty}>
      <div className="text-center">
        <h2 className="text-lg font-semibold">How can I help you?</h2>
        <div className="mt-4 grid grid-cols-2 gap-2">
          <ThreadPrimitive.Suggestions>
            {() => <SuggestionCard />}
          </ThreadPrimitive.Suggestions>
        </div>
      </div>
    </AuiIf>
  );
}

function SuggestionCard() {
  return (
    <SuggestionPrimitive.Trigger
      send
      className="flex flex-col gap-1 rounded-2xl border px-4 py-3 text-left hover:bg-muted"
    >
      <span className="font-medium">
        <SuggestionPrimitive.Title />
      </span>
      <span className="text-sm text-muted-foreground">
        <SuggestionPrimitive.Description />
      </span>
    </SuggestionPrimitive.Trigger>
  );
}
```

### 点击发送建议

```tsx
<SuggestionPrimitive.Trigger send className="rounded-full border px-4 py-2 hover:bg-muted">
  <SuggestionPrimitive.Title />
</SuggestionPrimitive.Trigger>
```

### 仅填充建议

```tsx
<SuggestionPrimitive.Trigger
  send={false}
  clearComposer={false}
  className="rounded-lg border px-3 py-1.5 text-sm hover:bg-muted"
>
  <SuggestionPrimitive.Title />
</SuggestionPrimitive.Trigger>
```

## 与组件的关系

shadcn [Thread](/elements/thread) 组件会在欢迎屏幕中使用带有 `SuggestionPrimitive` 部件的 `ThreadPrimitive.Suggestions`，以响应式网格的形式包含建议。若要使用预构建的欢迎体验，可以从这里开始。
