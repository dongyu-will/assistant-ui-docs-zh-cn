## 快速开始

最小示例：

```tsx
import {
  ThreadListPrimitive,
  ThreadListItemPrimitive,
} from "@assistant-ui/react";

<ThreadListPrimitive.Root>
  <ThreadListPrimitive.New>New Thread</ThreadListPrimitive.New>
  <ThreadListPrimitive.Items>
    {() => (
      <ThreadListItemPrimitive.Root>
        <ThreadListItemPrimitive.Trigger>
          <ThreadListItemPrimitive.Title fallback="New Chat" />
        </ThreadListItemPrimitive.Trigger>
      </ThreadListItemPrimitive.Root>
    )}
  </ThreadListPrimitive.Items>
</ThreadListPrimitive.Root>
```

`Root` 渲染一个 `<div>`，`New` 渲染一个 `<button>` 来创建新线程，而 `Items` 遍历线程列表。每个项目由 `ThreadListItemPrimitive` 部件组合而成。

运行时设置：原语需要运行时上下文。请将 UI 包裹在带有运行时的 `AssistantRuntimeProvider` 中（例如 `useLocalRuntime(...)`）。请参阅[选择运行时](/docs/runtimes/pick-a-runtime)。

## 核心概念

### 三个命名空间

ThreadList 分为三个命名空间，使每个抽象层级都能进行组合：

- **`ThreadListPrimitive`**：外部容器。`Root` 包裹列表，`New` 创建线程，`Items` 遍历线程。
- **`ThreadListItemPrimitive`**：单个线程行。`Root` 提供上下文，`Trigger` 切换到该线程，`Title` 显示线程名称，操作按钮（归档、取消归档、删除）则管理线程的生命周期。
- **`ThreadListItemMorePrimitive`**：用于线程操作的溢出下拉菜单（基于 Radix DropdownMenu 构建）。使用 `asChild` 将操作按钮与菜单项组合起来。

### 活跃状态

当 `ThreadListPrimitive.New` 和 `ThreadListItemPrimitive.Root` 表示当前线程时，二者都会获得 `data-active` 属性。可以使用此属性进行样式设置：

```tsx
<ThreadListItemPrimitive.Root className="hover:bg-muted data-active:bg-muted">
  {/* ... */}
</ThreadListItemPrimitive.Root>
```

当用户处于全新的未保存线程时，`New` 按钮会获得 `data-active`。

### 键盘导航

每个项目都保留为原生 Tab 停靠点，并在此基础上增加方向键支持。上/下方向键可在项目之间移动，右方向键可将焦点移到项目的 `More` 按钮（在 RTL 中，左/右方向键的行为相反）。这是原语内置的功能，无需传入 prop。

要将 `More` 菜单纳入相同的导航，请使用 `sharedFocusGroup` 启用该功能：

```tsx
<ThreadListItemMorePrimitive.Root sharedFocusGroup>
  {/* Right opens the menu from the trigger; Left/Escape close it and
      return focus to the trigger, keeping the highlight continuous. */}
</ThreadListItemMorePrimitive.Root>
```

`sharedFocusGroup` 会将菜单加入列表的焦点组，使其触发器和打开的菜单作为一个可通过键盘导航的单元：右方向键打开菜单，左方向键/Escape 关闭菜单，并同步将焦点恢复到触发器，因此 `group-has-focus-visible` 高亮不会闪烁。启用此功能会强制菜单采用非模态模式，因为焦点陷阱与共享焦点组互斥——焦点陷阱会将焦点限制在菜单内，而共享焦点组允许焦点跨越边界移出菜单。不使用 `sharedFocusGroup` 时，菜单会保留标准 Radix `DropdownMenu` 键盘行为（默认采用模态模式），因此已经渲染的菜单不会发生变化。我们的 assistant-ui [thread-list](/elements/thread-list) 注册表组件会为你设置 `sharedFocusGroup`。

### Items 迭代器

`ThreadListPrimitive.Items` 现在优先使用 children 渲染函数，类似于 `ThreadPrimitive.Messages`：

```tsx
<ThreadListPrimitive.Items>
  {({ threadListItem }) => (
    <MyThreadItem threadId={threadListItem.id} />
  )}
</ThreadListPrimitive.Items>
```

`components` 已弃用。请改用 `children` 渲染函数。

### 已归档线程

将 `archived` 传递给 `Items`，即可单独渲染已归档的线程：

```tsx
<ThreadListPrimitive.Root>
  <ThreadListPrimitive.New>New Thread</ThreadListPrimitive.New>
  <ThreadListPrimitive.Items>
    {() => <ThreadListItem />}
  </ThreadListPrimitive.Items>

  <h3>Archived</h3>
  <ThreadListPrimitive.Items archived>
    {() => <ArchivedThreadItem />}
  </ThreadListPrimitive.Items>
</ThreadListPrimitive.Root>
```

### 线程操作

当运行时不具备相应能力时，`Archive`、`Unarchive` 和 `Delete` 按钮会自动禁用。

### 将操作与菜单项组合

标准模式是将 `ThreadListItemPrimitive.Archive asChild` 与 `ThreadListItemMorePrimitive.Item` 组合，以同时获得操作行为和菜单项样式：

```tsx
<ThreadListItemPrimitive.Archive asChild>
  <ThreadListItemMorePrimitive.Item>
    <ArchiveIcon className="size-4" /> Archive
  </ThreadListItemMorePrimitive.Item>
</ThreadListItemPrimitive.Archive>
```

`Archive` 提供点击处理函数和禁用逻辑。`Item` 提供菜单项行为和样式。`asChild` 将二者合并为一个元素。

## 可访问性

线程列表依赖原生按钮语义和 Radix 的 `DropdownMenu`；方向键导航只是额外提供的便利功能，并非必需。

- 每个 `ThreadListItemPrimitive.Trigger` 都是原生 `<button>`，并且拥有自己的 Tab 停靠点，因此仅使用 <Kbd>Tab</Kbd> 就可以访问整个列表。方向键（请参阅[键盘导航](#keyboard-navigation)）可以加快遍历速度，但功能并不依赖方向键。
- 表示当前线程的项目会在 `ThreadListItemPrimitive.Root` 上设置 `aria-current="true"`（以及 `data-active`），因此辅助技术可以播报当前打开的是哪个会话。
- `More` 触发器会暴露 `aria-haspopup="menu"`，其面板是一个 Radix `role="menu"`，包含 `role="menuitem"` 子项，因此屏幕阅读器会将其播报为菜单，用户也可以使用方向键循环浏览菜单项。
- 使用 `sharedFocusGroup` 时，`More` 菜单采用非模态模式并加入列表的焦点组：打开和关闭菜单时，焦点会在触发器与菜单之间同步移动，因此键盘焦点不会丢失，`group-has-focus-visible` 高亮也不会闪烁。不使用该属性时，菜单会保留 Radix 默认的模态焦点陷阱。

#### LoadMore

用于追加下一页线程的按钮。除非设置 `asChild`，否则会渲染一个 `<button>` 元素。当运行时正在加载，或适配器最后一次 `list()` 未返回 `nextCursor` 时，该按钮会自动禁用。有关适配器契约，请参阅[线程概念](/docs/runtimes/concepts/threads#paginating-the-thread-list)。

```tsx
<ThreadListPrimitive.LoadMore className="rounded-lg border px-3 py-2 text-sm">
  Load more
</ThreadListPrimitive.LoadMore>
```

对于基于滚动的加载，请在应用层将 `aui.threads.loadMore()` 包裹在你自己的 `IntersectionObserver` 中；assistant-ui 提供显式按钮，以保持原语接口的可预测性。

```tsx
import { useAui, useAuiState } from "@assistant-ui/react";
import { useEffect, useRef } from "react";

function LoadMoreSentinel() {
  const aui = useAui();
  const disabled = useAuiState(
    (s) =>
      !s.threads.hasMore || s.threads.isLoading || s.threads.isLoadingMore,
  );
  const ref = useRef<HTMLDivElement>(null);

  useEffect(() => {
    const el = ref.current;
    if (!el || disabled) return;
    const observer = new IntersectionObserver(([entry]) => {
      if (entry?.isIntersecting) aui.threads.loadMore();
    });
    observer.observe(el);
    return () => observer.disconnect();
  }, [aui, disabled]);

  return disabled ? null : <div ref={ref} className="h-9" />;
}
```

### ThreadListItemPrimitive

#### Root

单个线程列表项目的容器。除非设置 `asChild`，否则会渲染一个 `<div>` 元素。

```tsx
<ThreadListItemPrimitive.Root className="flex items-center gap-2 rounded-lg px-2 py-1.5">

  </ThreadListItemPrimitive.Trigger>
```

#### Trigger

用于选择线程的交互式按钮。除非设置 `asChild`，否则会渲染一个 `<button>` 元素。

```tsx
<ThreadListItemPrimitive.Trigger className="flex-1 text-left">
  <ThreadListItemPrimitive.Title fallback="New Chat" />
</ThreadListItemPrimitive.Trigger>
```

#### Title

使用 `fallback` prop 显示线程标题。它会渲染一个 React fragment（不包含包装元素）。如果需要设置样式，请使用 `<span>` 包装元素。

```tsx
<ThreadListItemPrimitive.Title fallback="New Chat" />
```

```tsx
<ThreadListItemPrimitive.Unarchive>Unarchive</ThreadListItemPrimitive.Unarchive>
```

### ThreadListItemMorePrimitive

#### Root

溢出菜单原语的根容器。传入 `sharedFocusGroup` 可将菜单纳入列表的方向键导航（请参阅[键盘导航](#keyboard-navigation)）；这样会强制菜单采用非模态模式。不传入该属性时，菜单会遵循 `modal` prop，默认采用模态模式，与 Radix 的 `DropdownMenu` 一致。

```tsx
<ThreadListItemMorePrimitive.Root sharedFocusGroup>
  <ThreadListItemMorePrimitive.Trigger>More</ThreadListItemMorePrimitive.Trigger>
</ThreadListItemMorePrimitive.Root>
```

#### Trigger

用于打开溢出菜单的按钮。除非设置 `asChild`，否则会渲染一个 `<button>` 元素。

```tsx
<ThreadListItemMorePrimitive.Trigger className="rounded-md p-1 hover:bg-muted">
  More
</ThreadListItemMorePrimitive.Trigger>
```

#### Content

下拉面板。它会通过 portal 渲染一个 `<div>`（相对于触发器定位）。

```tsx
<ThreadListItemMorePrimitive.Content className="rounded-md border bg-popover p-1 shadow-md">
  <ThreadListItemPrimitive.Archive asChild>
    <ThreadListItemMorePrimitive.Item>Archive</ThreadListItemMorePrimitive.Item>
  </ThreadListItemPrimitive.Archive>
</ThreadListItemMorePrimitive.Content>
```

<PrimitivesTypeTable type="ThreadListItemMorePrimitiveContentProps" parameters={ThreadListItemMorePrimitiveDocs.Content.props} />

#### Item

溢出菜单中的菜单项插槽。除非设置 `asChild`，否则会渲染一个 `<div>` 元素。

```tsx
<ThreadListItemMorePrimitive.Item>Archive</ThreadListItemMorePrimitive.Item>
```

#### Separator

菜单项组之间的视觉分隔线。除非设置 `asChild`，否则会渲染一个 `<div>` 元素。

```tsx
<ThreadListItemMorePrimitive.Separator className="my-1 h-px bg-border" />
```

### 已归档线程区域

```tsx
<ThreadListPrimitive.Root>
  <ThreadListPrimitive.New>New Thread</ThreadListPrimitive.New>

  <h3 className="px-3 pt-4 text-xs font-medium text-muted-foreground">Recent</h3>
  <ThreadListPrimitive.Items>
    {() => <ThreadListItem />}
  </ThreadListPrimitive.Items>

  <h3 className="px-3 pt-4 text-xs font-medium text-muted-foreground">Archived</h3>

```

在 `ArchivedItem` 组件中，使用 `ThreadListItemPrimitive.Unarchive` 代替 `Archive`，以便用户恢复线程。

## 与组件的关系

shadcn 的 [ThreadList](/elements/thread-list) 组件在侧边栏布局中使用 Tailwind 样式封装了这些原语，其中包括骨架加载状态，以及预构建的、包含归档和删除操作的更多菜单。默认的线程列表实现可以从这里开始。如果需要自定义布局、不同的操作，或与自己的侧边栏或导航系统集成，则可以直接使用这些原语。
