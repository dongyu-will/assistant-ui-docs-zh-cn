## 快速开始

输入框中的附件：

```tsx
import { AttachmentPrimitive, ComposerPrimitive } from "@assistant-ui/react";

<ComposerPrimitive.Root>
  <ComposerPrimitive.Attachments>
    {() => <MyAttachment />}
  </ComposerPrimitive.Attachments>
  <ComposerPrimitive.Input placeholder="Ask anything..." />
  <ComposerPrimitive.Send>Send</ComposerPrimitive.Send>
</ComposerPrimitive.Root>
```

`Root` 会渲染一个 `<div>`，`unstable_Thumb` 会渲染一个 `<div>`，显示带前导点的文件扩展名（例如 `.pdf`）；当文件名没有扩展名时（包括以点开头的名称，例如 `.env`），则显示附件类型（例如 `image`）。`Name` 会渲染纯文本，`Remove` 会渲染一个 `<button>`。如果将 `children` 传递给 `unstable_Thumb`，它们会覆盖该文本。

<Callout type="info">
运行时设置：原语需要运行时上下文。请将 UI 包裹在带有运行时的 `AssistantRuntimeProvider` 中（例如 `useLocalRuntime(...)`）。请参阅[选择运行时](/docs/runtimes/pick-a-runtime)。
</Callout>

## 核心概念

### 两种上下文

附件会出现在两种不同的上下文中：

- **输入框**：通过 `ComposerPrimitive.Attachments` 使用。这些是发送前可以移除的待上传附件。
- **消息**：通过 `MessagePrimitive.Attachments` 使用。这些是以只读方式显示的已发送附件（迭代器会为用户消息渲染附件）。

相同的 `AttachmentPrimitive` 部件可以在两种上下文中使用。区别在于行为：`Remove` 仅适用于输入框上下文。

### 迭代器模式

你无需自行遍历附件，而应使用 children 渲染函数：

```tsx
// Composer attachments
<ComposerPrimitive.Attachments>
  {({ attachment }) => {
    if (attachment.type === "image") return <ImageAttachment />;
    if (attachment.type === "document") return <DocumentAttachment />;
    return <GenericAttachment />;
  }}
</ComposerPrimitive.Attachments>

// Message attachments
<MessagePrimitive.Attachments>
  {({ attachment }) => {
    if (attachment.type === "image") return <ImageAttachment />;
    if (attachment.type === "document") return <DocumentAttachment />;
    return <GenericAttachment />;
  }}
</MessagePrimitive.Attachments>
```

每个组件都会自动接收其附件上下文，无需传递任何 props。`components` 已弃用，请改用 `children` 渲染函数。

### 移除按钮

`Remove` 会调用附件运行时的移除操作。在输入框附件中，它会从待发送消息中移除附件。在消息附件中不支持此操作，点击 `Remove` 会抛出 `"Message attachments cannot be removed"`。仅在输入框 UI 中渲染 `Remove`。

### 将名称作为文本

`Name` 会渲染不带包装元素的纯文本。请将它包裹在 `<span>` 或其他元素中，以便设置样式：

```tsx
<span className="text-sm font-medium">
  <AttachmentPrimitive.Name />
</span>
```

## 部件

### Root

单个附件项目的容器。除非设置了 `asChild`，否则会渲染一个 `<div>` 元素。

```tsx
<AttachmentPrimitive.Root className="flex items-center gap-2 rounded-lg border p-2">
  <AttachmentPrimitive.Name />
</AttachmentPrimitive.Root>
```

### unstable_Thumb

用于附件预览的缩略图插槽。除非设置了 `asChild`，否则会渲染一个 `<div>` 元素。默认情况下，它会显示带前导点的文件扩展名（例如 `.pdf`）；如果传入 `children`，则会覆盖自动生成的文本。

```tsx
<AttachmentPrimitive.unstable_Thumb className="flex size-10 items-center justify-center rounded bg-muted text-xs" />
```

### Name

渲染附件文件名文本。

```tsx
<AttachmentPrimitive.Name />
```

### Remove

在可移除附件上下文中使用时，移除当前附件的按钮。除非设置了 `asChild`，否则会渲染一个 `<button>` 元素。

```tsx
<AttachmentPrimitive.Remove className="rounded-full p-1 hover:bg-muted">
  <XIcon className="size-3" />
</AttachmentPrimitive.Remove>
```

## 使用模式

### 带移除按钮的输入框附件

```tsx
function ComposerAttachmentItem() {
  return (
    <AttachmentPrimitive.Root className="flex items-center gap-2 rounded-lg border p-2">
      <AttachmentPrimitive.unstable_Thumb className="flex size-10 items-center justify-center rounded bg-muted text-xs font-mono" />
      <span className="min-w-0 flex-1 truncate text-sm">
        <AttachmentPrimitive.Name />
      </span>
      <AttachmentPrimitive.Remove className="rounded-full p-1 hover:bg-muted">
        <XIcon className="size-3" />
      </AttachmentPrimitive.Remove>
    </AttachmentPrimitive.Root>
  );
}

<ComposerPrimitive.Root>
  <ComposerPrimitive.Attachments
    components={{ Attachment: ComposerAttachmentItem }}
  />
  <ComposerPrimitive.Input placeholder="Ask anything..." />
  <ComposerPrimitive.Send>Send</ComposerPrimitive.Send>
</ComposerPrimitive.Root>
```

### 消息附件（只读）

```tsx
function MessageAttachment() {
  return (
    <AttachmentPrimitive.Root className="flex items-center gap-2 rounded-lg border p-2">
      <AttachmentPrimitive.unstable_Thumb className="flex size-10 items-center justify-center rounded bg-muted text-xs font-mono" />
      <span className="text-sm">
        <AttachmentPrimitive.Name />
      </span>
    </AttachmentPrimitive.Root>
  );
}
```

### 使用 asChild 的自定义布局

```tsx
<AttachmentPrimitive.Root asChild>
  <li className="flex items-center gap-3 py-1">
    <AttachmentPrimitive.unstable_Thumb className="size-8 rounded bg-muted text-xs" />
    <span className="text-sm">
      <AttachmentPrimitive.Name />
    </span>
  </li>
</AttachmentPrimitive.Root>
```
