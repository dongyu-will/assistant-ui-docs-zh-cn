BranchPicker 原语让用户可以在消息分支之间导航。消息分支是通过编辑消息或重新生成回复所生成的备选响应。它通常与 ActionBar 一起用于消息组件中。

## 快速开始

最小示例：

```tsx
import { BranchPickerPrimitive } from "@assistant-ui/react";

<BranchPickerPrimitive.Root>
  <BranchPickerPrimitive.Previous>←</BranchPickerPrimitive.Previous>
  <BranchPickerPrimitive.Number /> / <BranchPickerPrimitive.Count />
  <BranchPickerPrimitive.Next>→</BranchPickerPrimitive.Next>
</BranchPickerPrimitive.Root>
```

`Root` 会渲染一个 `<div>`，`Previous` 和 `Next` 会渲染在边界处自动禁用的 `<button>` 元素。`Number` 和 `Count` 会渲染纯文本（当前分支索引和分支总数）。

<Callout type="info">
BranchPicker 必须放置在 `MessagePrimitive.Root` 内部，因为它会从最近的消息上下文中读取分支状态。
</Callout>

<Callout type="info">
运行时设置：原语需要运行时上下文。请将 UI 放在带有运行时的 `AssistantRuntimeProvider` 中（例如 `useLocalRuntime(...)`）。请参阅[选择运行时](/docs/runtimes/pick-a-runtime)。
</Callout>

## 核心概念

### 分支导航

`Previous` 和 `Next` 按钮会在边界处自动禁用。`Previous` 在第一个分支上时会被禁用，`Next` 在最后一个分支上时会被禁用。如果运行时不支持 `switchBranchDuringRun`，这两个按钮在线程运行期间也会被禁用。

### 编号与计数

`Number` 和 `Count` 是仅用于文本的原语，会直接渲染原始数字，不包含包装元素。如果需要为它们设置样式，请使用 `<span>`：

```tsx
<span className="tabular-nums">
  <BranchPickerPrimitive.Number /> / <BranchPickerPrimitive.Count />
</span>
```

### hideWhenSingleBranch

`Root` 上的 `hideWhenSingleBranch` 属性会在只有一个分支时隐藏整个选择器。这是生产环境中用于减少视觉干扰的常见模式：

```tsx
<BranchPickerPrimitive.Root hideWhenSingleBranch>
  <BranchPickerPrimitive.Previous>←</BranchPickerPrimitive.Previous>
  <BranchPickerPrimitive.Number /> / <BranchPickerPrimitive.Count />
  <BranchPickerPrimitive.Next>→</BranchPickerPrimitive.Next>
</BranchPickerPrimitive.Root>
```

### 上下文要求

BranchPicker 会从最近的消息上下文中读取分支状态。它必须放置在 `MessagePrimitive.Root` 内部，可以直接放置，也可以嵌套在消息组件中。

## 部件

### Root

带有可选 `hideWhenSingleBranch` 的容器。除非设置了 `asChild`，否则会渲染一个 `<div>` 元素。

```tsx
<BranchPickerPrimitive.Root hideWhenSingleBranch className="inline-flex items-center gap-1">
  <BranchPickerPrimitive.Previous>←</BranchPickerPrimitive.Previous>
  <BranchPickerPrimitive.Number /> / <BranchPickerPrimitive.Count />
  <BranchPickerPrimitive.Next>→</BranchPickerPrimitive.Next>
</BranchPickerPrimitive.Root>
```

<PrimitivesTypeTable type="BranchPickerPrimitiveRootProps" parameters={BranchPickerPrimitiveDocs.Root.props.filter(p => p.name !== "asChild")} />

### Previous

用于选择上一个分支的按钮。除非设置了 `asChild`，否则会渲染一个 `<button>` 元素。

```tsx
<BranchPickerPrimitive.Previous>Previous</BranchPickerPrimitive.Previous>
```

### Next

用于选择下一个分支的按钮。除非设置了 `asChild`，否则会渲染一个 `<button>` 元素。

```tsx
<BranchPickerPrimitive.Next>Next</BranchPickerPrimitive.Next>
```

### Number

显示当前分支编号。

```tsx
<BranchPickerPrimitive.Number />
```

### Count

显示当前消息的分支总数。

```tsx
<BranchPickerPrimitive.Count />
```

## 使用模式

### 带图标的标准选择器

```tsx
import { ChevronLeftIcon, ChevronRightIcon } from "lucide-react";

<BranchPickerPrimitive.Root
  hideWhenSingleBranch
  className="inline-flex items-center gap-1 text-xs text-muted-foreground"
>
  <BranchPickerPrimitive.Previous className="size-6 rounded-md hover:bg-muted disabled:opacity-30">
    <ChevronLeftIcon className="size-3.5" />
  </BranchPickerPrimitive.Previous>
  <span className="tabular-nums">
    <BranchPickerPrimitive.Number /> / <BranchPickerPrimitive.Count />
  </span>
  <BranchPickerPrimitive.Next className="size-6 rounded-md hover:bg-muted disabled:opacity-30">
    <ChevronRightIcon className="size-3.5" />
  </BranchPickerPrimitive.Next>
</BranchPickerPrimitive.Root>
```

### 使用 asChild 的自定义元素

```tsx
<BranchPickerPrimitive.Previous asChild>
  <MyIconButton tooltip="Previous branch">
    <ChevronLeftIcon />
  </MyIconButton>
</BranchPickerPrimitive.Previous>
```

原语的禁用状态和点击处理器会合并到你的元素上。

### 位于消息页脚中

最常见的模式是在消息页脚中将 BranchPicker 与 ActionBar 并列放置：

```tsx
function AssistantMessage() {
  return (
    <MessagePrimitive.Root>
      <div className="rounded-xl bg-muted p-3">
        <MessagePrimitive.Parts />
      </div>
      <div className="flex items-center justify-between">
        <BranchPickerPrimitive.Root hideWhenSingleBranch>
          {/* prev / number / count / next */}
        </BranchPickerPrimitive.Root>
        <ActionBarPrimitive.Root>
          <ActionBarPrimitive.Copy>Copy</ActionBarPrimitive.Copy>
          <ActionBarPrimitive.Reload>Reload</ActionBarPrimitive.Reload>
        </ActionBarPrimitive.Root>
      </div>
    </MessagePrimitive.Root>
  );
}
```

## 与组件的关系

shadcn 的 [Thread](/elements/thread) 组件在 AssistantMessage 和 UserMessage 的页脚中都包含 BranchPicker，并启用了 `hideWhenSingleBranch`。如果默认布局符合需求，请使用该组件。当需要自定义位置、不同的样式或非标准的分支导航体验时，可以直接使用 `BranchPickerPrimitive`。
