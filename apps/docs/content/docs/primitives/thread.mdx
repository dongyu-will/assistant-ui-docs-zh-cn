Thread 原语是可滚动的消息容器，也是任何聊天界面的核心。它负责视口管理、自动滚动、空状态、消息渲染和建议。你只需提供布局和样式。

## 快速开始

最小示例：

```tsx
import { ThreadPrimitive } from "@assistant-ui/react";

<ThreadPrimitive.Root>
  <ThreadPrimitive.Viewport>
    <ThreadPrimitive.Messages>
      {() => <MyMessage />}
    </ThreadPrimitive.Messages>
  </ThreadPrimitive.Viewport>
</ThreadPrimitive.Root>
```

`Root` 渲染一个 `<div>`，`Viewport` 渲染一个可滚动的 `<div>`，`Messages` 遍历会话线程中的消息。添加你自己的样式和组件；原语会处理其余工作。

<Callout type="info">
运行时设置：原语需要运行时上下文。将 UI 包裹在带有运行时的 `AssistantRuntimeProvider` 中（例如 `useLocalRuntime(...)`）。请参阅[选择运行时](/docs/runtimes/pick-a-runtime)。
</Callout>

## 核心概念

### 视口与自动滚动

`Viewport` 是可滚动容器。新内容流式传输时，它会自动滚动到底部，但仅当用户没有手动向上滚动时才会如此。设置 `autoScroll={false}` 可完全禁用此功能。

```tsx
<ThreadPrimitive.Viewport autoScroll={true}>
  {/* messages */}
</ThreadPrimitive.Viewport>
```

### 回合锚点

默认情况下，新消息会出现在底部，并向下滚动。使用 `turnAnchor="top"` 后，用户消息会锚定在视口顶部。这会带来现代的阅读体验：问题显示在顶部，回复在其下方逐步呈现。

```tsx
<ThreadPrimitive.Viewport turnAnchor="top">
  {/* messages */}
</ThreadPrimitive.Viewport>
```

设置 `turnAnchor="top"` 后，`MessagePrimitive.Root` 会自动将最新的助手消息注册为顶部锚点目标，并将前一条用户消息注册为锚点——无需额外组件。视口自身会管理一个稳定的预留元素，在助手回复不断增长时提供缺失的滚动范围。这就是 [Thread](/elements/thread) 组件默认使用的行为。

使用 `topAnchorMessageClamp` 控制 `turnAnchor="top"` 时长用户消息仍保持可见。高度不超过 `tallerThan` 的消息会完整显示。对于高度超过该值的消息，`visibleHeight` 控制其底部边缘在助手回复上方保持可见的范围：

```tsx
<ThreadPrimitive.Viewport
  turnAnchor="top"
  topAnchorMessageClamp={{ tallerThan: "10em", visibleHeight: "6em" }}
>
  {/* messages */}
</ThreadPrimitive.Viewport>
```

### 视口滚动选项

`ThreadPrimitive.Viewport` 提供三个针对特定事件的滚动控制项：

- `scrollToBottomOnRunStart`（默认值为 `true`）：`thread.runStart` 触发时滚动
- `scrollToBottomOnInitialize`（默认值为 `true`）：`thread.initialize` 触发时滚动
- `scrollToBottomOnThreadSwitch`（默认值为 `true`）：`threads.selectionChanged` 触发时滚动

这些选项与 `autoScroll` 一起生效。如果省略 `autoScroll`，则对于 `turnAnchor="bottom"` 默认为 `true`，对于 `turnAnchor="top"` 默认为 `false`。

```tsx
<ThreadPrimitive.Viewport
  turnAnchor="top"
  autoScroll={false}
  scrollToBottomOnRunStart={true}
  scrollToBottomOnInitialize={false}
  scrollToBottomOnThreadSwitch={true}
>
  <ThreadPrimitive.Messages>
    {({ message }) => {
      if (message.role === "user") return <UserMessage />;
      return <AssistantMessage />;
    }}
  </ThreadPrimitive.Messages>
</ThreadPrimitive.Viewport>
```

### ViewportFooter

`ViewportFooter` 固定在视口底部，并注册自身高度，以便自动滚动系统将其考虑在内。你可以在这里放置输入框：

```tsx
<ThreadPrimitive.Viewport>
  <ThreadPrimitive.Messages>
    {() => <MyMessage />}
  </ThreadPrimitive.Messages>
  <ThreadPrimitive.ViewportFooter className="sticky bottom-0">
    <MyComposer />
  </ThreadPrimitive.ViewportFooter>
</ThreadPrimitive.Viewport>
```

### 空状态

<Callout type="warn">
`ThreadPrimitive.Empty` 已弃用。请改用 [`AuiIf`](/docs/api-reference/primitives/assistant-if)。
</Callout>

```tsx
<AuiIf condition={(s) => s.thread.isEmpty}>
  <div className="flex flex-col items-center gap-2 text-center">
    <h2>Welcome!</h2>
    <p>How can I help you today?</p>
  </div>
</AuiIf>
```

### 消息迭代器

`Messages` 现在优先使用 children 渲染函数。它会提供当前消息状态，让你可以直接在内联逻辑中进行分支处理：

```tsx
<ThreadPrimitive.Messages>
  {({ message }) => {
    if (message.composer.isEditing) return <MyEditComposer />;
    if (message.role === "user") return <MyUserMessage />;
    return <MyAssistantMessage />;
  }}
</ThreadPrimitive.Messages>
```

`components` 已弃用。请改用 `children` 渲染函数。

### 建议迭代器

`Suggestions` 遵循相同模式。渲染自定义建议 UI 时，优先使用 children 渲染函数：

```tsx
<ThreadPrimitive.Suggestions>
  {() => <MySuggestionButton />}
</ThreadPrimitive.Suggestions>
```

## 部件

### Root

线程布局的顶层容器。除非设置了 `asChild`，否则会渲染一个 `<div>` 元素。

```tsx
<ThreadPrimitive.Root className="flex h-full flex-col">
  <ThreadPrimitive.Viewport>
    <ThreadPrimitive.Messages>
      {() => <MyMessage />}
    </ThreadPrimitive.Messages>
  </ThreadPrimitive.Viewport>
</ThreadPrimitive.Root>
```

### Viewport

带有自动滚动行为的可滚动区域。除非设置了 `asChild`，否则会渲染一个 `<div>` 元素。

```tsx
<ThreadPrimitive.Viewport
  turnAnchor="top"
  autoScroll={false}
  scrollToBottomOnRunStart={true}
>
  <ThreadPrimitive.Messages>
    {({ message }) => {
      if (message.role === "user") return <UserMessage />;
      return <AssistantMessage />;
    }}
  </ThreadPrimitive.Messages>
</ThreadPrimitive.Viewport>
```

<PrimitivesTypeTable type="ThreadPrimitiveViewportProps" parameters={ThreadPrimitiveDocs.Viewport.props.filter(p => p.name !== "asChild")} />

### ViewportFooter

向视口滚动系统注册自身高度的页脚容器。除非设置了 `asChild`，否则会渲染一个 `<div>` 元素。

```tsx
<ThreadPrimitive.ViewportFooter className="sticky bottom-0 pt-2">
  <ComposerPrimitive.Root>...</ComposerPrimitive.Root>
</ThreadPrimitive.ViewportFooter>
```

### ViewportProvider

提供视口上下文，但不会渲染可滚动元素。当你使用自定义滚动容器时可以使用它。

```tsx
<ThreadPrimitive.ViewportProvider>
  <div className="flex-1 overflow-y-auto">
    <ThreadPrimitive.Messages>
      {() => <MyMessage />}
    </ThreadPrimitive.Messages>
    <ThreadPrimitive.ViewportFooter>
      <MyComposer />
    </ThreadPrimitive.ViewportFooter>
  </div>
</ThreadPrimitive.ViewportProvider>
```

### ViewportSlack

<Callout type="warn">
  `ThreadPrimitive.ViewportSlack` 已从公共 API 中移除。当 `turnAnchor="top"` 时，`MessagePrimitive.Root` 会自动处理顶部锚点目标注册。从组件树中移除 `ViewportSlack`；如果你在 `ViewportSlack` 或 `MessagePrimitive.Root` 上自定义了 `fillClampThreshold` 或 `fillClampOffset`，请将这些 props 替换为 `ThreadPrimitive.Viewport` 上的 `topAnchorMessageClamp`。
</Callout>

### Messages

为线程中的每条消息渲染一个组件，并根据角色和编辑状态解析要渲染的组件。

```tsx
<ThreadPrimitive.Messages>
  {({ message }) => {
    if (message.composer.isEditing) return <MyEditComposer />;
    if (message.role === "user") return <MyUserMessage />;
    return <MyAssistantMessage />;
  }}
</ThreadPrimitive.Messages>
```

### MessageByIndex

在会话线程中的指定索引处渲染单条消息。

```tsx
<ThreadPrimitive.MessageByIndex
  index={0}
  components={{ Message: MyMessage }}
/>
```

<PrimitivesTypeTable type="ThreadPrimitiveMessageByIndexProps" parameters={ThreadPrimitiveDocs.MessageByIndex.props} />

### Unstable_MessageById

按 id 渲染单条消息，使用与 `MessageByIndex` 相同的 `components` 表面。将它与 `unstable_useThreadMessageIds` 搭配使用，可用于虚拟化消息列表或自定义消息列表，使其在重新排序和窗口化期间仍与消息保持关联。未知 id 会渲染 `null`。

```tsx
const messageIds = unstable_useThreadMessageIds();

messageIds.map((messageId) => (
  <ThreadPrimitive.Unstable_MessageById
    key={messageId}
    messageId={messageId}
    components={{ Message: MyMessage }}
  />
));
```

<Callout type="warn">
  `unstable_useThreadMessageIds` 和 `ThreadPrimitive.Unstable_MessageById` 处于实验阶段，可能在任何版本中发生变化。
</Callout>

### ScrollToBottom

将视口滚动到底部。已经位于底部时会自动禁用。除非设置了 `asChild`，否则会渲染一个 `<button>` 元素。

```tsx
<ThreadPrimitive.ScrollToBottom className="rounded-full bg-background p-2 shadow-md">
  <ArrowDownIcon />
</ThreadPrimitive.ScrollToBottom>
```

### Empty

<Callout type="warn">
已弃用。请改用带有 `s.thread.isEmpty` 的 [`AuiIf`](/docs/api-reference/primitives/assistant-if)。

### If（已弃用）

<Callout type="warn">
已弃用。请改用 [`AuiIf`](/docs/api-reference/primitives/assistant-if)。

```tsx

<AuiIf condition={(s) => s.thread.isEmpty}>...</AuiIf>

<AuiIf condition={(s) => s.thread.isDisabled}>...</AuiIf>
```

## 模式

### 带建议的欢迎屏幕

```tsx
<AuiIf condition={(s) => s.thread.isEmpty}>
  <div className="flex flex-col items-center gap-4 text-center">
    <h2>What can I help with?</h2>
    <div className="grid grid-cols-2 gap-2">
      <ThreadPrimitive.Suggestions>
        {() => <MySuggestionButton />}
      </ThreadPrimitive.Suggestions>
    </div>
  </div>
</AuiIf>
```

### 滚动到底部按钮

```tsx
<ThreadPrimitive.ScrollToBottom className="fixed bottom-24 right-4 rounded-full bg-background p-2 shadow-md">
  <ArrowDownIcon />
</ThreadPrimitive.ScrollToBottom>
```

当视口已经滚动到底部时，该按钮会自动禁用。

### 回合锚点顶部布局

```tsx
<ThreadPrimitive.Root className="flex h-full flex-col">
  <ThreadPrimitive.Viewport turnAnchor="top" className="flex-1 overflow-y-auto">
    <ThreadPrimitive.Messages>
      {({ message }) => {
        if (message.role === "user") return <UserMessage />;
        return <AssistantMessage />;
      }}
    </ThreadPrimitive.Messages>
    <ThreadPrimitive.ViewportFooter className="sticky bottom-0">
      <MyComposer />
    </ThreadPrimitive.ViewportFooter>
  </ThreadPrimitive.Viewport>
</ThreadPrimitive.Root>
```

### 自定义消息组件

```tsx
<ThreadPrimitive.Messages>
  {({ message }) => {
    if (message.role === "user") {
      return (
        <MessagePrimitive.Root>
          <div className="ml-auto rounded-xl bg-blue-500 p-3 text-white">
            <MessagePrimitive.Parts />
          </div>
        </MessagePrimitive.Root>
      );
    }

    return (
      <MessagePrimitive.Root>
        <div className="rounded-xl bg-gray-100 p-3">
          <MessagePrimitive.Parts />
        </div>
      </MessagePrimitive.Root>
    );
  }}
</ThreadPrimitive.Messages>
```

## 与组件的关系

[Thread](/elements/thread) 组件是使用这些原语和 Tailwind 样式构建的完整聊天界面。默认实现可以从这里开始。如果你需要自定义布局、不同的滚动行为或非标准的线程结构，请使用 `ThreadPrimitive`。
