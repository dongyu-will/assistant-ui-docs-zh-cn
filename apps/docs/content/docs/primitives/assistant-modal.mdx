## 快速开始

最小示例：

```tsx
import { AssistantModalPrimitive } from "@assistant-ui/react";

<AssistantModalPrimitive.Root>
  <AssistantModalPrimitive.Anchor>
    <AssistantModalPrimitive.Trigger>Open</AssistantModalPrimitive.Trigger>
  </AssistantModalPrimitive.Anchor>
  <AssistantModalPrimitive.Content>
    <Thread />
  </AssistantModalPrimitive.Content>
</AssistantModalPrimitive.Root>
```

`Root` 是 Radix Popover provider（不渲染 DOM），`Trigger` 会渲染一个 `<button>`，`Anchor` 会渲染一个 `<div>`，而 `Content` 会在 portal 中渲染一个 `<div>`。添加你自己的类名、动画和布局。

<Callout type="info">
运行时设置：原语需要运行时上下文。将 UI 包裹在带有运行时的 `AssistantRuntimeProvider` 中（例如 `useLocalRuntime(...)`）。请参阅[选择运行时](/docs/runtimes/pick-a-runtime)。
</Callout>

## 核心概念

### Popover 架构

AssistantModal 直接基于 Radix Popover 构建。`Root` 管理打开/关闭状态，`Trigger` 切换该状态，`Anchor` 定位弹出框，而 `Content` 则是浮动面板。Radix Popover 的所有属性都可用于相应部件。

### Anchor 与 Trigger

`Content` 会相对于 `Anchor` 而不是 `Trigger` 进行定位。常见模式是将 `Trigger` 包裹在 `Anchor` 中，使弹出框相对于更大的区域（例如固定位置的按钮容器）对齐，而不是相对于按钮本身对齐：

```tsx
<AssistantModalPrimitive.Anchor className="fixed right-4 bottom-4 size-11">
  <AssistantModalPrimitive.Trigger>
    Open
  </AssistantModalPrimitive.Trigger>
</AssistantModalPrimitive.Anchor>
```

### 运行开始时自动打开

`unstable_openOnRunStart` 属性（默认为 `true`）会在助手开始响应时自动打开模态框。这意味着，如果用户在模态框关闭时以编程方式触发运行，模态框会自动弹出以显示响应。设置为 `false` 可禁用此行为。

### 关闭行为

`Content` 使用 `dissmissOnInteractOutside`（*这是有意保留的当前 API 拼写，其中包含额外的 `s`*），默认值为 `false`。点击模态框外部**不会**关闭模态框。这符合预期的聊天 UX：用户可以与页面交互，同时保持聊天打开。将其设置为 `true` 可使用标准的弹出框关闭行为。

### 打开/关闭动画

`Content` 提供 `data-[state=open]` 和 `data-[state=closed]` 属性，用于 CSS 动画：

```tsx
<AssistantModalPrimitive.Content
  className="data-[state=open]:animate-in data-[state=open]:fade-in data-[state=closed]:animate-out data-[state=closed]:fade-out"
>
```

## 部件

### Root

Radix Popover provider，管理打开/关闭状态。不渲染 DOM 元素。

```tsx
<AssistantModalPrimitive.Root unstable_openOnRunStart={false}>
  ...
</AssistantModalPrimitive.Root>
```

<PrimitivesTypeTable type="AssistantModalPrimitiveRootProps" parameters={AssistantModalPrimitiveDocs.Root.props} />

### Trigger

用于切换模态框打开和关闭状态的按钮。除非设置了 `asChild`，否则会渲染一个 `<button>` 元素。

```tsx
<AssistantModalPrimitive.Trigger className="rounded-full bg-primary px-4 py-2 text-primary-foreground">
  Open Chat
</AssistantModalPrimitive.Trigger>
```

### Anchor

相对于共享锚点定位触发器和内容。除非设置了 `asChild`，否则会渲染一个 `<div>` 元素。

```tsx
<AssistantModalPrimitive.Anchor className="fixed right-4 bottom-4">
  <AssistantModalPrimitive.Trigger>Chat</AssistantModalPrimitive.Trigger>
</AssistantModalPrimitive.Anchor>
```

### Content

浮动聊天面板。在 portal 中渲染一个 `<div>` 元素。

```tsx
<AssistantModalPrimitive.Content
  sideOffset={16}
  className="h-[600px] w-[400px] rounded-xl border bg-background shadow-lg"
>
  <Thread />
</AssistantModalPrimitive.Content>
```

## 模式

### 右下角浮动组件

```tsx
<AssistantModalPrimitive.Root>
  <AssistantModalPrimitive.Anchor className="fixed right-4 bottom-4 size-11">
    <AssistantModalPrimitive.Trigger className="size-full rounded-full bg-primary text-primary-foreground shadow-lg">
      <BotIcon className="size-6" />
    </AssistantModalPrimitive.Trigger>
  </AssistantModalPrimitive.Anchor>
  <AssistantModalPrimitive.Content
    sideOffset={16}
    className="h-[600px] w-[400px] rounded-xl border bg-background shadow-lg"
  >
    <Thread />
  </AssistantModalPrimitive.Content>
</AssistantModalPrimitive.Root>
```

### 触发器图标切换

`Trigger` 按钮会从 Radix 接收 `data-state` 属性（`"open"` 或 `"closed"`）。若要将此状态传递给子图标，请将 `asChild` 与一个会解构并转发该状态的包装组件结合使用：

```tsx
import { forwardRef } from "react";

const ModalButton = forwardRef<
  HTMLButtonElement,
  React.ComponentPropsWithoutRef<"button"> & { "data-state"?: string }
>(({ "data-state": state, ...props }, ref) => (
  <button ref={ref} {...props} className="relative size-11 rounded-full">
    <BotIcon
      data-state={state}
      className="absolute size-6 transition-all data-[state=open]:rotate-90 data-[state=open]:scale-0"
    />
    <XIcon
      data-state={state}
      className="absolute size-6 transition-all data-[state=closed]:-rotate-90 data-[state=closed]:scale-0"
    />
  </button>
));

<AssistantModalPrimitive.Trigger asChild>
  <ModalButton />
</AssistantModalPrimitive.Trigger>
```

### 自定义 Portal 容器

将内容渲染到指定容器中，而不是渲染到 `document.body`：

```tsx
<AssistantModalPrimitive.Content
  portalProps={{ container: myContainerRef.current }}
>
  <Thread />
</AssistantModalPrimitive.Content>
```
