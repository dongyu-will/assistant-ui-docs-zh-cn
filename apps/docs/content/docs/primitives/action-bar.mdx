ActionBar 原语提供消息操作：复制、重新加载、编辑、反馈、语音和导出。它支持悬停时自动隐藏、根据消息状态自动禁用，以及浮动行为，从而智能控制可见性。你负责组合按钮，原语负责处理操作状态和可用性。

## 快速开始

包含复制和重新加载功能的最小操作栏：

```tsx
import { ActionBarPrimitive } from "@assistant-ui/react";

<ActionBarPrimitive.Root>
  <ActionBarPrimitive.Copy>Copy</ActionBarPrimitive.Copy>
  <ActionBarPrimitive.Reload>Reload</ActionBarPrimitive.Reload>
</ActionBarPrimitive.Root>
```

`Root` 会渲染一个 `<div>`，操作按钮会渲染为 `<button>` 元素。当操作不可用时，每个按钮都会自动禁用（例如，没有内容时 Copy 会被禁用，模型运行期间 Reload 会被禁用）。

<Callout type="info">
ActionBar 必须放置在 `MessagePrimitive.Root` 内，因为它会从最近的消息上下文中读取消息状态。
</Callout>

<Callout type="info">
运行时设置：原语需要运行时上下文。将 UI 包裹在带有运行时的 `AssistantRuntimeProvider` 中（例如 `useLocalRuntime(...)`）。请参阅[选择运行时](/docs/runtimes/pick-a-runtime)。
</Callout>

## 核心概念

### 自动隐藏与浮动

`autohide` 属性控制操作栏的显示时机：

- **`"never"`**（默认）：始终显示
- **`"not-last"`**：除最后一条消息外，对所有消息隐藏；悬停时显示
- **`"always"`**：对所有消息隐藏；悬停时显示

设置 `autohideFloat` 后，隐藏的操作栏会获得 `data-floating` 属性，而不是从 DOM 中移除。这样你就可以使用 CSS 为其添加动画：

```tsx
<ActionBarPrimitive.Root
  autohide="not-last"
  autohideFloat="always"
  className="data-[floating]:opacity-0 data-[floating]:group-hover:opacity-100 data-[floating]:transition-opacity"
>
  {/* buttons */}
</ActionBarPrimitive.Root>
```

`autohideFloat` 的 `"single-branch"` 选项仅在消息只有一个分支（没有其他选项）时启用浮动。

### 自动禁用

操作按钮会根据状态自动禁用，无需手动连接：

- **Copy**：没有可复制的文本内容，或助手消息仍在运行时禁用
- **Reload**：线程正在运行，或消息角色不是 assistant 时禁用
- **Edit**：消息已处于编辑状态时禁用
- **Speak**：没有可朗读的文本，或助手消息仍在运行时禁用

### 复制状态

点击 Copy 后，按钮会在可配置的时长内（默认为 3 秒）获得 `data-copied` 属性。可以使用该属性提供视觉反馈：

```tsx
<ActionBarPrimitive.Copy copiedDuration={2000} className="group">
  <CopyIcon className="group-data-[copied]:hidden" />
  <CheckIcon className="hidden group-data-[copied]:block" />
</ActionBarPrimitive.Copy>
```

### 反馈按钮

反馈按钮通过 `data-submitted` 跟踪提交状态：

```tsx
<ActionBarPrimitive.FeedbackPositive className="data-[submitted]:text-green-500">
  👍
</ActionBarPrimitive.FeedbackPositive>
<ActionBarPrimitive.FeedbackNegative className="data-[submitted]:text-red-500">
  👎
</ActionBarPrimitive.FeedbackNegative>
```

提交对当前消息的正面反馈。除非设置 `asChild`，否则会渲染一个 `<button>` 元素。

```tsx
</ActionBarPrimitive.FeedbackPositive>
```

提交对当前消息的负面反馈。除非设置 `asChild`，否则会渲染一个 `<button>` 元素。

```tsx
</ActionBarPrimitive.FeedbackNegative>
```

## 常见模式

### 助手操作栏

```tsx
<ActionBarPrimitive.Root
  hideWhenRunning
  autohide="not-last"
  autohideFloat="single-branch"
>
  <ActionBarPrimitive.Copy>Copy</ActionBarPrimitive.Copy>
  <ActionBarPrimitive.Reload>Regenerate</ActionBarPrimitive.Reload>
  <ActionBarPrimitive.ExportMarkdown>Export</ActionBarPrimitive.ExportMarkdown>
</ActionBarPrimitive.Root>
```

### 用户操作栏

```tsx
<ActionBarPrimitive.Root hideWhenRunning autohide="not-last">
  <ActionBarPrimitive.Edit>Edit</ActionBarPrimitive.Edit>
</ActionBarPrimitive.Root>
```

### 语音切换

```tsx
<AuiIf condition={(s) => !s.message.isSpeaking}>
  <ActionBarPrimitive.Speak>Play</ActionBarPrimitive.Speak>
</AuiIf>
<AuiIf condition={(s) => s.message.isSpeaking}>
  <ActionBarPrimitive.StopSpeaking>Stop</ActionBarPrimitive.StopSpeaking>
</AuiIf>
```

<Callout type="info">
语音功能需要在运行时中配置 `SpeechSynthesisAdapter`。设置方法请参阅[语音与听写](/docs/guides/speech)。
</Callout>

### 使用自定义处理程序导出

```tsx
<ActionBarPrimitive.ExportMarkdown
  onExport={async (content) => {
    await navigator.clipboard.writeText(content);
    toast("Copied as Markdown!");
  }}
>
  Copy Markdown
</ActionBarPrimitive.ExportMarkdown>
```

## 溢出菜单（ActionBarMorePrimitive）

`ActionBarMorePrimitive` 是用于溢出操作的 Radix DropdownMenu，采用与 `ThreadListItemMorePrimitive` 相同的模式。可以使用它将次要操作收纳到“更多”按钮后面。

`ActionBarMorePrimitive.Item` 对应 Radix `DropdownMenu.Item`，因此保留了菜单的键盘和焦点语义。在将 `ActionBarPrimitive` 按钮组合到菜单项中时，建议使用 `asChild`。

`ActionBarMorePrimitive.Content` 默认为 `sideOffset={4}`，使菜单与触发器之间保持较小间距。

| 部件 | 元素 | 用途 |
|------|---------|---------|
| `Root` | N/A | Radix DropdownMenu 提供程序 |
| `Trigger` | `<button>` | 打开下拉菜单 |
| `Content` | `<div>`（portal） | 下拉面板 |
| `Item` | `<div>` | 菜单项 |
| `Separator` | `<div>` | 项目之间的视觉分隔线 |

```tsx
import {
  ActionBarPrimitive,
  ActionBarMorePrimitive,
} from "@assistant-ui/react";
import { MoreHorizontalIcon } from "lucide-react";

<ActionBarPrimitive.Root>
  <ActionBarPrimitive.Copy>Copy</ActionBarPrimitive.Copy>
  <ActionBarPrimitive.Reload>Regenerate</ActionBarPrimitive.Reload>
  <ActionBarMorePrimitive.Root>
    <ActionBarMorePrimitive.Trigger className="flex size-8 items-center justify-center rounded-lg hover:bg-muted">
      <MoreHorizontalIcon className="size-4" />
    </ActionBarMorePrimitive.Trigger>
    <ActionBarMorePrimitive.Content side="bottom" align="end">
      <ActionBarMorePrimitive.Item asChild>
        <ActionBarPrimitive.ExportMarkdown>
          Export Markdown
        </ActionBarPrimitive.ExportMarkdown>
      </ActionBarMorePrimitive.Item>
      <ActionBarMorePrimitive.Separator />
      <ActionBarMorePrimitive.Item asChild>
        <ActionBarPrimitive.FeedbackPositive>
          Helpful
        </ActionBarPrimitive.FeedbackPositive>
      </ActionBarMorePrimitive.Item>
    </ActionBarMorePrimitive.Content>
  </ActionBarMorePrimitive.Root>
</ActionBarPrimitive.Root>
```

完整的属性详情请参阅 [ActionBarMorePrimitive API 参考](/docs/api-reference/primitives/action-bar-more)。

## 与组件的关系

shadcn 的 [Thread](/elements/thread) 组件在其 `AssistantMessage`（包含 Copy、Reload 和导出下拉菜单）和 `UserMessage`（包含 Edit）中使用 `ActionBarPrimitive`。如果这些默认设置满足需求，请使用该组件。当你需要不同的操作、自定义布局，或需要在标准线程 UI 之外使用操作时，可以直接使用 `ActionBarPrimitive`。

ActionBar 通常会与 [BranchPicker](/docs/primitives/branch-picker) 搭配使用，以便在助手消息的不同候选回复之间进行导航。
