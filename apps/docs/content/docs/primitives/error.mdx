## 快速开始

在消息下方显示错误的最简示例：

```tsx
import { ErrorPrimitive, MessagePrimitive } from "@assistant-ui/react";

<MessagePrimitive.Root>
  <MessagePrimitive.Parts />
  <ErrorPrimitive.Root>
    <ErrorPrimitive.Message />
  </ErrorPrimitive.Root>
</MessagePrimitive.Root>
```

`Root` 会渲染一个带有 `role="alert"` 的 `<div>`，以确保屏幕阅读器可访问。`Message` 会渲染一个 `<span>`，自动从消息状态中读取错误文本；没有错误时，它会返回 `null`。`Root` 本身始终会渲染。如果希望整个区块（包括 `Root`）按条件渲染，请将其包裹在 `<MessagePrimitive.Error>` 中。

<Callout type="info">
ErrorPrimitive 必须放置在 `MessagePrimitive.Root` 内，因为它会从最近的消息上下文中读取错误状态。
</Callout>

<Callout type="info">
运行时设置：原语需要运行时上下文。请将 UI 包裹在带有运行时的 `AssistantRuntimeProvider` 中（例如 `useLocalRuntime(...)`）。请参阅[选择运行时](/docs/runtimes/pick-a-runtime)。
</Callout>

## 核心概念

### 出错时自动渲染

`Message` 会检查消息状态，并且仅在 `status.type === "incomplete"` 和 `status.reason === "error"` 时渲染。`Root` 始终会渲染其 `<div role="alert">` 容器。如需完全按条件渲染，请将其包裹在 `<MessagePrimitive.Error>` 中。

### 自动提取错误文本

`ErrorPrimitive.Message` 会从消息状态中读取错误对象，并将其转换为字符串。如果传入 `children`，它们会覆盖自动提取的文本：

```tsx
// Auto-reads error text from state
<ErrorPrimitive.Message />

// Custom children override the default
<ErrorPrimitive.Message>
  Something went wrong. Please try again.
</ErrorPrimitive.Message>
```

### ErrorPrimitive 与 MessagePrimitive.Error 的区别

`MessagePrimitive.Error` 是一个更简单的替代方案。当消息存在错误时，它会渲染其子元素，但不提供 `role="alert"`，也不会自动提取错误文本。如果需要以可访问的方式渲染错误并自动提取文本，请使用 `ErrorPrimitive`。

```tsx
// ErrorPrimitive: accessible, auto-reads error text
<ErrorPrimitive.Root role="alert">
  <ErrorPrimitive.Message />
</ErrorPrimitive.Root>

// MessagePrimitive.Error: simpler, manual text
<MessagePrimitive.Error>
  <div>Something went wrong.</div>
</MessagePrimitive.Error>
```

## 部件

### 根部件

错误消息区块的容器。除非设置了 `asChild`，否则会渲染一个 `<div>` 元素。

```tsx
<ErrorPrimitive.Root className="rounded-md border border-destructive/20 bg-destructive/5 p-3">
  <ErrorPrimitive.Message />
</ErrorPrimitive.Root>
```

### 消息

渲染当前活动消息的错误文本。

```tsx
<ErrorPrimitive.Message className="text-destructive text-sm" />
```

## 模式

### 样式化错误警告

```tsx
<ErrorPrimitive.Root className="mt-2 flex items-center gap-2 rounded-md bg-destructive/10 px-3 py-2 text-sm text-destructive">
  <ErrorPrimitive.Message />
</ErrorPrimitive.Root>
```

### 自定义错误内容

```tsx
<ErrorPrimitive.Root className="mt-2 rounded-md border border-destructive/20 bg-destructive/5 p-3">
  <p className="font-medium text-destructive text-sm">Error</p>
  <ErrorPrimitive.Message className="text-destructive/80 text-sm" />
</ErrorPrimitive.Root>
```

## 与组件的关系

shadcn 的 [Thread](/elements/thread) 组件会在其 `AssistantMessage` 内使用 `ErrorPrimitive`，以在消息内容下方显示错误。如果需要预构建的错误显示组件，可以从这里开始。
