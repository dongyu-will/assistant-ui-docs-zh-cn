SelectionToolbar 原语是一个浮动工具栏，用户在消息中选中文本时会显示。它允许用户将选中的文本引用到输入框中。样式和操作布局均可完全自定义。

function FloatingSelectionToolbar() {

## 快速开始

一个最小化的选择工具栏：

```tsx
import { SelectionToolbarPrimitive } from "@assistant-ui/react";

<SelectionToolbarPrimitive.Root>
  <SelectionToolbarPrimitive.Quote>
    Quote
  </SelectionToolbarPrimitive.Quote>
</SelectionToolbarPrimitive.Root>
```

`Root` 会在 portal 中渲染一个 `<div>`，并将其定位在文本选区上方。`Quote` 会渲染一个 `<button>`，将选中的文本作为引用复制到输入框中。

<Callout type="info">
运行时设置：原语需要运行时上下文。请将 UI 包裹在带有运行时的 `AssistantRuntimeProvider` 中（例如 `useLocalRuntime(...)`）。请参阅[选择运行时](/docs/runtimes/pick-a-runtime)。
</Callout>

## 核心概念

### 自动定位

`Root` 会通过 portal 渲染到 `document.body`。在当前实现中，它使用 `position: fixed`、`top: rect.top - 8px`、`left: rect.left + rect.width / 2`、`transform: translate(-50%, -100%)`（将其居中放置在选区上方）以及 `z-index: 50` 进行定位。

### 单条消息验证

只有当选区完全位于单条消息内时，工具栏才会显示。跨消息选区会被忽略。检测机制会检查祖先元素上的 `data-message-id` 属性，该属性由 `MessagePrimitive.Root` 自动设置。

当不存在有效选区时（选区已折叠、文本为空，或未匹配到单条消息），`Root` 会返回 `null`。

### 引用区域

默认情况下，消息内的任何选中文本都可以被引用。对于包含工具卡片、附件或自定义控件的富消息，请将 `data-aui-quote-selectable` 添加到包含消息文本的元素上。消息拥有可选择引用的区域后，选区必须保持在同一个标记区域内，工具栏才会显示。

```tsx
<MessagePrimitive.Root>
  <div data-aui-quote-selectable="">
    <MessagePrimitive.Parts />
  </div>
  <ToolCard />
</MessagePrimitive.Root>
```

也可以设置 `data-aui-quote-selectable="false"` 来排除某个元素：在消息根元素上设置时，会禁用整条消息的引用功能；在可引用区域内设置时，则会从该区域中排除对应的子树。距离最近的标记优先，并且除 `"false"` 之外的任何值（包括空值）都会将该区域标记为可引用区域。

应用在渲染时知道消息角色，因此角色门控是一个条件属性：

```tsx
const UserMessage = () => (
  <MessagePrimitive.Root data-aui-quote-selectable="false">
    <MessagePrimitive.Parts />
  </MessagePrimitive.Root>
);
```

### 引用操作

点击 `Quote` 按钮时会执行两项操作：

1. 调用 `composer.setQuote({ text, messageId })`，将选中的文本作为引用片段填充到输入框中
2. 通过 `window.getSelection()?.removeAllRanges()` 清除浏览器选区

随后，输入框会显示引用的文本，用户可以在其前后输入后续消息。

### 隐藏

以下情况下，工具栏会自动隐藏：

- 用户滚动页面
- 选区折叠（点击其他位置或按下方向键）
- 选区通过程序清除（例如引用操作完成后）

点击工具栏本身不会取消选区。`Root` 会在 `mousedown` 上调用 `preventDefault`，以保留选区。

### 在线程中的放置位置

SelectionToolbar 必须放置在 `ThreadPrimitive.Root` 内部，但必须位于 `ThreadPrimitive.Viewport` **外部**。它会根据浏览器选区通过 portal 进行定位，与滚动容器无关：

```tsx
<ThreadPrimitive.Root>
  <ThreadPrimitive.Viewport>
    <ThreadPrimitive.Messages ... />
  </ThreadPrimitive.Viewport>
  <SelectionToolbarPrimitive.Root>
    <SelectionToolbarPrimitive.Quote>Quote</SelectionToolbarPrimitive.Quote>
  </SelectionToolbarPrimitive.Root>
  <ComposerPrimitive.Root>...</ComposerPrimitive.Root>
</ThreadPrimitive.Root>
```

## 部件

### 根部件

在存在有效文本选区时显示的浮动工具栏容器。除非设置了 `asChild`，否则会渲染一个 `<div>` 元素。

```tsx
<SelectionToolbarPrimitive.Root className="flex items-center gap-1 rounded-lg border bg-popover px-1 py-1 shadow-md">
  <SelectionToolbarPrimitive.Quote>Quote</SelectionToolbarPrimitive.Quote>
</SelectionToolbarPrimitive.Root>
```

### 引用

将当前选中的文本引用到输入框中。除非设置了 `asChild`，否则会渲染一个 `<button>` 元素。

```tsx
<SelectionToolbarPrimitive.Quote className="rounded-md px-2.5 py-1 text-sm hover:bg-accent">
  Quote
</SelectionToolbarPrimitive.Quote>
```

## 使用模式

### 带引用操作的基本工具栏

```tsx
<SelectionToolbarPrimitive.Root className="flex items-center gap-1 rounded-lg border bg-popover px-1 py-1 shadow-md">
  <SelectionToolbarPrimitive.Quote className="flex items-center gap-1.5 rounded-md px-2.5 py-1 text-sm text-popover-foreground hover:bg-accent">
    <QuoteIcon className="size-3.5" />
    Quote
  </SelectionToolbarPrimitive.Quote>
</SelectionToolbarPrimitive.Root>
```

### 带多个操作的工具栏

你可以在 `Quote` 旁边添加自定义按钮，以提供其他操作：

```tsx
<SelectionToolbarPrimitive.Root className="flex items-center gap-1 rounded-lg border bg-popover px-1 py-1 shadow-md">
  <SelectionToolbarPrimitive.Quote className="flex items-center gap-1.5 rounded-md px-2.5 py-1 text-sm hover:bg-accent">
    <QuoteIcon className="size-3.5" />
    Quote
  </SelectionToolbarPrimitive.Quote>
  <button
    className="flex items-center gap-1.5 rounded-md px-2.5 py-1 text-sm hover:bg-accent"
    onClick={() => navigator.clipboard.writeText(window.getSelection()?.toString() ?? "")}
  >
    <CopyIcon className="size-3.5" />
    Copy
  </button>
</SelectionToolbarPrimitive.Root>
```

## 与组件的关系
