`heat-graph` 提供无头、Radix 风格的原语，用于构建 GitHub 风格的活动热力图。

- **可组合** — 完全由你控制的 Radix 风格复合组件
- **无头** — 不附带任何样式方案，可使用自己的 CSS/Tailwind
- **内置工具提示** — 由 Radix Popper 提供定位支持
- **可自定义分桶** — 接入你自己的分类函数

## 快速开始

```tsx title="components/activity-graph.tsx"
"use client";

import * as HeatGraph from "heat-graph";

const COLORS = ["#ebedf0", "#c6d7f9", "#8fb0f3", "#5888e8", "#2563eb"];

export function ActivityGraph({ data }: { data: HeatGraph.DataPoint[] }) {
  return (
    <HeatGraph.Root data={data} weekStart="monday" colorScale={COLORS}>
      <HeatGraph.Grid className="gap-[3px]">
        {() => (
          <HeatGraph.Cell className="aspect-square rounded-sm" />
        )}
      </HeatGraph.Grid>
      <HeatGraph.Tooltip>
        {({ cell }) => (
          <div>
            {cell.count} contributions on {cell.date.toLocaleDateString()}
          </div>
        )}
      </HeatGraph.Tooltip>
    </HeatGraph.Root>
  );
}
```

<Callout type="info">
  使用 Heat Graph 的组件必须是客户端组件（`"use client"`），因为它们依赖 React Context 和交互功能。
</Callout>

## 结构

```tsx
import * as HeatGraph from "heat-graph";

<HeatGraph.Root data={data} colorScale={colors}>

  {/* Month labels — iterates internally, renders each label */}
  <HeatGraph.MonthLabels>
    {({ label, totalWeeks }) => (
      <span style={{ left: `${(label.column / totalWeeks) * 100}%` }}>
        {HeatGraph.MONTH_SHORT[label.month]}
      </span>
    )}
  </HeatGraph.MonthLabels>

  {/* Day-of-week labels — iterates internally, renders each label */}
  <HeatGraph.DayLabels>
    {({ label }) => (
      <span>{HeatGraph.DAY_SHORT[label.dayOfWeek]}</span>
    )}
  </HeatGraph.DayLabels>

  {/* Grid + Cells — iterates internally, renders each cell */}
  <HeatGraph.Grid>
    {() => <HeatGraph.Cell />}
  </HeatGraph.Grid>

  {/* Legend — iterates internally, renders each level */}
  <HeatGraph.Legend>
    {() => <HeatGraph.LegendLevel />}
  </HeatGraph.Legend>

  {/* Tooltip */}
  <HeatGraph.Tooltip>
    {({ cell }) => <div>{cell.count} on {cell.date.toLocaleDateString()}</div>}
  </HeatGraph.Tooltip>

</HeatGraph.Root>
```

## API 参考

### Root

顶层 provider。渲染一个 `<div>`，用于计算网格布局并向所有子组件提供状态。接受所有标准 div 属性。

| Prop         | Type                   | Default             | Description                                        |
| ------------ | ---------------------- | ------------------- | -------------------------------------------------- |
| `data`       | `DataPoint[]`          | 必填            | `{ date: string \| Date, count: number }` 数组 |
| `start`      | `string \| Date`       | `end` 前 1 年 | 日期范围的开始时间                            |
| `end`        | `string \| Date`       | 今天               | 日期范围的结束时间                              |
| `weekStart`  | `"sunday" \| "monday"` | `"sunday"`          | 一周的第一天                              |
| `classify`   | `ClassifyFn`           | `autoLevels(5)`     | 将计数映射到级别的分桶函数        |
| `colorScale` | `string[]`             | —                   | 颜色数组，每个级别对应一种颜色（索引 0 = 最低）  |

### Grid

一个采用 CSS Grid 布局的 `<div>`。根据计算出的数据渲染 `gridTemplateColumns` 和 `gridTemplateRows`。接受所有标准 div 属性。

内部会遍历所有单元格，为每个单元格调用 children 渲染函数。每个单元格都包装在一个上下文中，`Cell` 会从该上下文读取数据。

```ts
type CellData = {
  date: Date;
  count: number;
  level: number;
  column: number;
  row: number;
};
```

### Cell

一个从单元格上下文读取数据的 `<div>`。会自动应用：
- 网格定位（`gridColumn`、`gridRow`）
- 从 `colorScale` 获取背景颜色
- 工具提示悬停处理器

接受所有标准 div 属性。传入 `colorScale` 可覆盖 Root 级别的颜色比例。

### MonthLabels

遍历月份标签，为每个标签调用 children 渲染函数。

```tsx
<HeatGraph.MonthLabels>
  {({ label, totalWeeks }) => (
    <span style={{ left: `${(label.column / totalWeeks) * 100}%` }}>
      {HeatGraph.MONTH_SHORT[label.month]}
    </span>
  )}
</HeatGraph.MonthLabels>
```

每个标签都有 `{ month: number, column: number }`。使用 `totalWeeks` 计算标签位置。英文标签可使用 `MONTH_SHORT[label.month]`，本地化时可使用 `Intl.DateTimeFormat` 进行格式化。

### DayLabels

遍历星期标签，为每个标签调用 children 渲染函数。

```tsx
<HeatGraph.DayLabels>
  {({ label }) => (
    <span>{HeatGraph.DAY_SHORT[label.dayOfWeek]}</span>
  )}
</HeatGraph.DayLabels>
```

每个标签都有 `{ dayOfWeek: number, row: number }`，其中 `dayOfWeek` 的取值为 0=周日，6=周六。英文标签可使用 `DAY_SHORT[label.dayOfWeek]`，本地化时可使用 `Intl.DateTimeFormat` 进行格式化。

### Legend

遍历图例级别，为每个条目调用 children 渲染函数。每个条目都有 `{ level: number, color: string | undefined }`。

### LegendLevel

一个从图例条目上下文读取数据的 `<div>`。会自动从颜色比例应用 `backgroundColor`。请在 `Legend` 内使用。

### Tooltip

仅在单元格悬停时渲染。Radix Popper 会根据悬停的单元格对其进行定位。接受 Radix Popper `Content` 属性（`side`、`sideOffset`、`align` 等）。

```tsx
<HeatGraph.Tooltip side="top" sideOffset={8} className="...">
  {({ cell }) => <div>{cell.count} contributions</div>}
</HeatGraph.Tooltip>
```

### autoLevels(n)

默认分类函数。将计数映射到 `n` 个均匀分布的级别（0 到 n-1）。级别 0 始终对应计数 0。

```ts
type ClassifyFn = (counts: number[]) => (count: number) => number;
```

要提供自定义分类器：

```tsx
const myClassify: HeatGraph.ClassifyFn = (counts) => {
  const p75 = percentile(counts, 75);
  return (count) => {
    if (count === 0) return 0;
    if (count < p75 * 0.25) return 1;
    if (count < p75 * 0.5) return 2;
    if (count < p75) return 3;
    return 4;
  };
};

<HeatGraph.Root data={data} classify={myClassify}>
```

### MONTH_SHORT

英文月份缩写数组：`["Jan", "Feb", ..., "Dec"]`。通过 `MonthLabel.month` 进行索引。

### DAY_SHORT

英文星期缩写数组：`["Sun", "Mon", ..., "Sat"]`。通过 `DayLabel.dayOfWeek` 进行索引。
