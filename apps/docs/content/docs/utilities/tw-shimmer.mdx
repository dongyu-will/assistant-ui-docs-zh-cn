`tw-shimmer` 是一个零依赖的 Tailwind CSS v4 插件，为文本和骨架加载器提供精致的 shimmer 动画。它使用经过正弦缓动的渐变、17 个经过精心计算的色标，以及 OKLCH 颜色混合，从而实现平滑且无色带的效果。

- **仅 CSS** — 无 JavaScript 运行时，纯 Tailwind 工具类
- **文本 + 背景** — 为文本或骨架占位符添加 shimmer 效果
- **自动调整大小** — 使用 CSS 容器查询自动检测宽度
- **可自定义** — 速度、展开宽度、角度、颜色和时序

查看[交互式演示](/tw-shimmer)了解实时示例。

## 安装

<Tabs items={["npm", "pnpm", "yarn"]}>
  <Tab value="npm">
    ```sh
    npm install tw-shimmer
    ```
  </Tab>
  <Tab value="pnpm">
    ```sh
    pnpm add tw-shimmer
    ```
  </Tab>
  <Tab value="yarn">
    ```sh
    yarn add tw-shimmer
    ```
  </Tab>
</Tabs>

添加到 CSS 中：

```css title="app/globals.css"
@import "tailwindcss";
@import "tw-shimmer";
```

## 快速开始

### 文本 Shimmer

```html
<span class="shimmer text-foreground/60">Loading...</span>
```

<Callout type="info">
  设置半透明的文本颜色（例如 `text-foreground/40`），以便显示 shimmer 高亮效果。
</Callout>

### 骨架加载器

```html
<div class="shimmer shimmer-bg bg-muted h-4 w-48 rounded" />
```

### 自动调整大小的骨架卡片

```html
<div class="shimmer-container flex gap-3">
  <div class="shimmer-bg bg-muted size-12 rounded-full" />
  <div class="flex-1 space-y-2">
    <div class="shimmer-bg bg-muted h-4 w-1/4 rounded" />
    <div class="shimmer-bg bg-muted h-4 w-full rounded" />
    <div class="shimmer-bg bg-muted h-4 w-4/5 rounded" />
  </div>
</div>
```

## API 参考

### 核心工具类

#### `shimmer`

文本 shimmer 的基础工具类。在文本前景色上应用渐变动画。

#### `shimmer-bg`

用于骨架加载器的背景 shimmer。在元素背景上应用渐变动画。需要基础的 `bg-*` 类。

```html
<div class="shimmer shimmer-bg bg-muted h-4 w-64 rounded" />
```

#### `shimmer-container`

使用容器查询的纯 CSS 自动调整大小辅助工具。它会设置 `container-type: inline-size`，并根据容器宽度自动计算速度和展开宽度。

```html
<div class="shimmer-container">
  <div class="shimmer-bg bg-muted h-4 w-full rounded" />
</div>
```

<Callout type="warn">
  `shimmer-container` 会设置 `container-type: inline-size`，从而阻止收缩适应（shrink-to-fit）尺寸。不建议用于纯文本容器。
</Callout>

### 自定义工具类

| 工具类                     | 默认值（文本） | 默认值（背景） | 描述                        |
| --------------------------- | -------------- | ------------ | -------------------------- |
| `shimmer-speed-{n}`         | `150`          | `1000`       | 动画速度，单位为 px/s            |
| `shimmer-width-{n}`         | `200`          | `800`        | 用于计算时序的容器宽度，单位为 px   |
| `shimmer-spread-{n}`        | `6ch`          | —            | 文本 shimmer 高亮宽度       |
| `shimmer-bg-spread-{n}`     | —              | `480px`      | 背景 shimmer 高亮宽度 |
| `shimmer-color-{color}`     | auto           | auto         | 高亮颜色（Tailwind 调色板） |
| `shimmer-angle-{deg}`       | `90`           | `90`         | 扫掠方向，单位为度         |
| `shimmer-duration-{ms}`     | auto           | auto         | 固定动画时长           |
| `shimmer-repeat-delay-{ms}` | `1000`         | `1000`       | 周期间隔               |
| `shimmer-invert`            | —              | —            | 反转高亮方向         |

所有工具类都支持**继承**——在父元素上设置后，会影响所有 shimmer 子元素。

### 速度和宽度

速度控制 shimmer 每秒移动的像素数。宽度告知动画容器的宽度，用于计算时序。

```html
<span class="shimmer shimmer-speed-200 shimmer-width-400 text-foreground/40">
  Fast, wide shimmer
</span>
```

### 颜色

使用任意 Tailwind 颜色，并可选地指定不透明度：

```html
<span class="shimmer shimmer-color-blue-500 text-blue-500/40">
  Blue shimmer
</span>

<div class="shimmer shimmer-bg shimmer-color-blue-300/30 bg-muted h-4 rounded" />
```

### 角度

控制扫掠方向。默认值为 `90deg`（垂直扫掠）。

```html
<div class="shimmer-container shimmer-angle-15">
  <div class="shimmer-bg bg-muted h-4 w-full rounded" />
</div>
```

<Callout type="warn">
  避免使用恰好为 `0deg` 和 `180deg` 的值——它们会导致极长的动画延迟。安全范围：15-75° 或 105-165°。
</Callout>

### 位置提示（倾斜 Shimmer）

对于倾斜的 shimmer，使用 `shimmer-x-{n}` 和 `shimmer-y-{n}` 来同步元素：

```html
<div class="shimmer-container shimmer-angle-15 flex gap-3">
  <div class="shimmer-bg shimmer-x-20 shimmer-y-20 bg-muted size-12 rounded-full" />
  <div class="flex-1 space-y-2">
    <div class="shimmer-bg shimmer-x-52 shimmer-y-0 bg-muted h-4 w-24 rounded" />
    <div class="shimmer-bg shimmer-x-52 shimmer-y-24 bg-muted h-4 w-full rounded" />
  </div>
</div>
```

### 重复延迟

控制动画周期间的暂停时间：

```html
<!-- Continuous shimmer, no pause -->
<span class="shimmer shimmer-repeat-delay-0 text-foreground/40">
  Always moving
</span>

<!-- Long pause between cycles -->
<span class="shimmer shimmer-repeat-delay-3000 text-foreground/40">
  Slow pulse
</span>
```

## CSS 变量

所有值都可以通过 CSS 变量设置，以实现动态控制：

| 变量                 | 描述               |
| ------------------------ | ------------------------- |
| `--shimmer-speed`        | 速度，单位为 px/s             |
| `--shimmer-width`        | 轨道宽度，单位为 px         |
| `--shimmer-spread`       | 高亮宽度           |
| `--shimmer-angle`        | 扫掠角度               |
| `--shimmer-color`        | 高亮颜色           |
| `--shimmer-duration`     | 覆盖时长，单位为 ms    |
| `--shimmer-repeat-delay` | 周期间隔，单位为 ms |

```tsx
<div style={{ "--shimmer-width": containerWidth } as React.CSSProperties}>
  <div className="shimmer shimmer-bg bg-muted h-4 w-full rounded" />
</div>
```

## 浏览器支持

使用了现代 CSS 功能：`oklch()`、`color-mix()`、独立的 `translate` 变换，以及 CSS 容器查询。

**支持版本：**Chrome 111+、Firefox 113+、Safari 16.4+

较旧的浏览器会优雅降级——shimmer 效果将不会显示。
