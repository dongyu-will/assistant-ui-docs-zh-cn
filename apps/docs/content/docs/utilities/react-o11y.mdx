`@assistant-ui/react-o11y` 提供无头、Radix 风格的原语，用于将可观测性 span 渲染为可折叠、带缩进的层级 UI。你可以基于自己的 span 数据源，使用它构建跟踪检查器、瀑布图调试面板或 LLM 调用时间线。

- **无头** — 不附带任何样式约定，请使用你自己的 CSS / Tailwind。
- **可组合** — Radix 风格的原语部件，完全由你控制。
- **感知树结构** — 自动计算深度、父子折叠状态和时间范围。
- **响应式** — 基于与运行时相同的响应式核心构建，因此 span 发生变化时会流式传输到 UI 中。

## 快速开始

使用 span 数据挂载 `SpanResource`，然后渲染从资源状态中读取数据的原语：

```tsx title="components/trace-view.tsx"
"use client";

import {
  SpanPrimitive,
  SpanResource,
  type SpanData,
} from "@assistant-ui/react-o11y";
import { AuiConfig, AuiProvider } from "@assistant-ui/store";

function SpanRow() {
  return (
    <SpanPrimitive.Root className="flex items-center gap-2 py-1">
      <SpanPrimitive.Indent />
      <SpanPrimitive.CollapseToggle className="size-4 cursor-pointer">
        ▸
      </SpanPrimitive.CollapseToggle>
      <SpanPrimitive.StatusIndicator className="size-2 rounded-full data-[span-status=running]:bg-yellow-500 data-[span-status=completed]:bg-green-500 data-[span-status=failed]:bg-red-500" />
      <SpanPrimitive.TypeBadge className="rounded bg-muted px-1.5 text-xs" />
      <SpanPrimitive.Name className="text-sm" />
    </SpanPrimitive.Root>
  );
}

export function TraceView({ spans }: { spans: SpanData[] }) {
  const config = AuiConfig({ span: SpanResource({ spans }) });
  return (
    <AuiProvider extends={null} config={config}>
      <SpanPrimitive.Children components={{ Span: SpanRow }} />
    </AuiProvider>
  );
}
```

`SpanData` 是你的代码生成的输入结构（请参阅 [SpanData](#spandata)）。`SpanResource` 会为其补充深度、子级数量、时间范围和折叠状态。

## 结构

```tsx
import {
  SpanPrimitive,
  SpanResource,
  SpanByIndexProvider,
} from "@assistant-ui/react-o11y";

// Top-level: mount SpanResource via AuiProvider
const config = AuiConfig({ span: SpanResource({ spans }) });
<AuiProvider extends={null} config={config}>
  {/* Render visible spans (flat-list output respecting collapsed state) */}
  <SpanPrimitive.Children components={{ Span: SpanRow }} />
</AuiProvider>;

// Each <SpanRow /> sits inside its own SpanByIndexProvider context and reads via primitives
function SpanRow() {
  return (
    <SpanPrimitive.Root>
      <SpanPrimitive.Indent />
      <SpanPrimitive.CollapseToggle />
      <SpanPrimitive.StatusIndicator />
      <SpanPrimitive.TypeBadge />
      <SpanPrimitive.Name />
    </SpanPrimitive.Root>
  );
}
```

`SpanPrimitive.Children` 会生成可见 span 的扁平列表（不包含已折叠的子树）。每个渲染出的子级都会包装在 `SpanByIndexProvider` 中，使其中的原语解析到该特定 span 的状态。

## API 参考

### SpanResource

用于接收原始 span 数据，并向原语公开感知树结构的响应式状态的资源。

```ts
SpanResource({ spans }: { spans: SpanData[] }): ClientOutput<"span">;
```

通过 `config={config}` 挂载，其中 `const config = AuiConfig({ span: SpanResource({ spans }) })`。

该资源会计算：

- 基于父级链计算每个 span 的 **depth**。
- **hasChildren** 标志。
- 所有 span 的 **timeRange**（`min` / `max`）。
- 由内部管理的 **collapse state**；通过原语进行切换。

### SpanData

提供给 `SpanResource` 的输入结构：

| 字段 | 类型 | 描述 |
| --- | --- | --- |
| `id` | `string` | 唯一的 span 标识符。 |
| `parentSpanId` | `string \| null` | 父 span id；根 span 使用 `null`。 |
| `name` | `string` | 显示名称。 |
| `type` | `string` | Span 类别（例如 `llm`、`tool`、`http`）。由 `TypeBadge` 使用。 |
| `status` | `"running" \| "completed" \| "failed" \| "skipped"` | 生命周期状态。由 `StatusIndicator` 使用。 |
| `startedAt` | `number` | 开始时间戳（毫秒）。 |
| `endedAt` | `number \| null` | 结束时间戳（毫秒）；如果仍在运行，则为 `null`。 |
| `latencyMs` | `number \| null` | 预先计算的延迟；如果正在运行，则为 `null`。 |

### SpanState

由 `useAuiState((s) => s.span)` 在任意 span 作用域子树中返回：

```ts
type SpanState = {
  id: string;
  parentSpanId: string | null;
  name: string;
  type: string;
  status: "running" | "completed" | "failed" | "skipped";
  startedAt: number;
  endedAt: number | null;
  latencyMs: number | null;
  depth: number;
  hasChildren: boolean;
  isCollapsed: boolean;
  children: SpanItemState[];
  timeRange: { min: number; max: number };
};
```

### SpanPrimitive.Root

容器 `<div>`，通过数据属性公开 span 状态，以便设置样式：

| 属性 | 来源 |
| --- | --- |
| `data-span-id` | `span.id` |
| `data-span-status` | `span.status` |
| `data-span-type` | `span.type` |
| `data-span-depth` | `span.depth` |
| `data-collapsed` | `span.isCollapsed` |

接受所有标准 `<div>` props。

### SpanPrimitive.Indent

一种 `<div>`，根据 span 深度添加成比例的水平内边距。

| Prop | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `baseIndent` | `number` | `8` | 以像素为单位的基础内边距。 |
| `indentPerLevel` | `number` | `12` | 每个深度级别增加的内边距。 |

最终 `paddingLeft = baseIndent + depth * indentPerLevel`。

### SpanPrimitive.CollapseToggle

一种 `<button>`，用于切换当前 span 的折叠状态。仅当 span 包含子级时渲染。它会阻止点击事件传播，因此可以嵌套在可点击行中。

公开 `data-collapsed` 以便设置样式。接受所有标准 `<button>` props。

### SpanPrimitive.StatusIndicator

一种 `<span>`，公开 `data-span-status` 以便根据状态设置样式（颜色、图标切换等）。不会渲染内置图形；视觉表现由你提供。

```tsx
<SpanPrimitive.StatusIndicator className="size-2 rounded-full data-[span-status=running]:bg-yellow-500 data-[span-status=completed]:bg-green-500 data-[span-status=failed]:bg-red-500 data-[span-status=skipped]:bg-gray-400" />
```

### SpanPrimitive.TypeBadge

一种 `<span>`，其子级默认为 `span.type`（传入自定义子级即可覆盖）。公开 `data-span-type`。

### SpanPrimitive.Name

一种 `<span>`，其子级默认为 `span.name`。传入自定义子级即可覆盖。

### SpanPrimitive.Children

遍历可见的子 span，并渲染每个子 span。

有两种使用模式：

**Render-prop：**

```tsx
<SpanPrimitive.Children>
  {({ span }) => <CustomRow span={span} />}
</SpanPrimitive.Children>
```

**Component prop（推荐，性能更佳）：**

```tsx
<SpanPrimitive.Children components={{ Span: SpanRow }} />
```

`components.Span` 形式经过了记忆化；请传入稳定的组件引用，以避免无关状态变化导致重新渲染。

每个子级都会自动包装在 `SpanByIndexProvider` 中，因此 `SpanRow` 内部的原语会读取该子级的状态。

### SpanByIndexProvider

较低层级的备用入口。按索引选择一个 span，并将其作用域提供给后代：

```tsx
<SpanByIndexProvider index={0}>
  <SpanPrimitive.Root>{/* reads span at index 0 */}</SpanPrimitive.Root>
</SpanByIndexProvider>
```

大多数用户无需直接使用它；`SpanPrimitive.Children` 会自动完成连接。

### SpanPrimitive.ChildByIndex

将 `SpanByIndexProvider` 与渲染组件配对的便捷组件：

```tsx
<SpanPrimitive.ChildByIndex index={0} components={{ Span: SpanRow }} />
```

当你希望显式控制要渲染的子级索引时很有用（例如用于虚拟化）。

### SpanPrimitive.Timeline

一种 `<div>`，为后代 `TimelineBar` 原语提供时间线范围，并公开范围 CSS 变量。

| Prop | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `timeRange` | `{ min: number; max: number }` | `span.timeRange` | 覆盖用于定位条形图的范围。 |
| `paddingEnd` | `number` | `0` | 按时间范围持续时长的该比例扩展最大值，适用于在右侧留出呼吸空间。 |

公开 `data-span-timeline` 和以下 CSS 变量：

| 变量 | 描述 |
| --- | --- |
| `--span-timeline-min-ms` | 时间线开始时间戳。 |
| `--span-timeline-max-ms` | 添加内边距后的时间线结束时间戳。 |
| `--span-timeline-range-ms` | 添加内边距后的时间线持续时长。 |

### SpanPrimitive.TimelineBar

一种 `<div>`，用于在最近的 `SpanPrimitive.Timeline` 范围内定位当前 span。它会从当前 span 作用域读取 `startedAt`、`endedAt`、`status`、`type` 和 `timeRange`。

```tsx
<SpanPrimitive.Timeline>
  <SpanPrimitive.Children>
    {() => (
      <div className="relative h-8">
        <SpanPrimitive.TimelineBar className="top-1 h-6 rounded bg-blue-500" />
      </div>
    )}
  </SpanPrimitive.Children>
</SpanPrimitive.Timeline>
```

当省略 `now` 时，运行中的 span 使用时间线范围的最大值，从而确保 SSR 和 hydration 具有确定性。如需实时计时，请在 effect 或动画循环中更新时间戳，并将其作为 `now` 传入。

| Prop | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `now` | `number` | `undefined` | 用作运行中 span 结束时间的显式时间戳。 |
| `timeRange` | `{ min: number; max: number }` | 最近的 `Timeline` 范围 | 覆盖此条形图使用的范围。 |

公开 `data-span-status`、`data-span-type`、`data-span-running` 以及以下 CSS 变量：

| 变量 | 描述 |
| --- | --- |
| `--span-timeline-left` | 条形图起始位置的百分比。 |
| `--span-timeline-end` | 条形图结束位置的百分比。 |
| `--span-timeline-width` | 条形图宽度的百分比。 |
| `--span-timeline-duration-ms` | 条形图持续时间（毫秒）。 |
| `--span-timeline-min-width` | 可选的使用者设置的最小宽度，由默认内联尺寸使用。 |

## 样式

所有原语都会转发 refs，并接受标准 DOM props（`className`、`style` 等）。使用数据属性根据状态设置样式：

```css
[data-span-status="running"] {
  /* yellow indicator */
}
[data-span-status="failed"] {
  /* red indicator */
}
[data-collapsed="true"] svg {
  transform: rotate(0deg);
}
[data-collapsed="false"] svg {
  transform: rotate(90deg);
}
```
