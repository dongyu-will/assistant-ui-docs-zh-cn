---
title: 原语
description: 用于构建聊天 UI 的可组合 React Native 组件。
---

原语是对 React Native 组件（`View`、`TextInput`、`FlatList`、`Pressable` 的轻量封装，并与 assistant-ui 运行时集成。它们接受所有标准 React Native 属性，并添加感知运行时的行为。

原语通过命名空间导入访问（例如 `ThreadPrimitive.Root`、`ComposerPrimitive.Input`），与 `@assistant-ui/react` 中使用的模式一致。

许多原语通过 `@assistant-ui/core/react` 与 `@assistant-ui/react` 共享核心逻辑——只有 UI 层（View/Pressable/Text 与 DOM 元素）不同。

## 线程

```tsx
import { AuiIf, ThreadPrimitive } from "@assistant-ui/react-native";
```

### ThreadPrimitive.Root

线程区域的容器 `View`。

```tsx
<ThreadPrimitive.Root style={{ flex: 1 }}>
  {children}
</ThreadPrimitive.Root>
```

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `...rest` | `ViewProps` | 标准 React Native View 属性 |

### ThreadPrimitive.Messages

基于已弃用的 `FlatList` 的消息列表，为向后兼容而保留。它在内部使用 `ThreadPrimitive.MessagesFlatList`，但保留之前默认不自动滚动的行为，因此现有应用中自定义的滚动处理不会因升级而改变行为。

对于新的 React Native 线程，请使用 `ThreadPrimitive.MessagesFlatList`。

```tsx
<ThreadPrimitive.Messages>
  {() => <MyMessage />}
</ThreadPrimitive.Messages>
```

你也可以提供特定角色的组件：

```tsx
<ThreadPrimitive.Messages>
  {({ message }) => {
    if (message.role === "user") return <MyUserMessage />;
    return <MyAssistantMessage />;
  }}
</ThreadPrimitive.Messages>
```

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `components` | `MessageComponents` | 组件映射——提供 `Message` 组件（用于所有角色），或提供特定角色的 `UserMessage`、`AssistantMessage`，以及可选的 `SystemMessage`。编辑输入框可以通过 `EditComposer` 或特定角色的变体（`UserEditComposer`、`AssistantEditComposer`、`SystemEditComposer`）进行设置。 |
| `...rest` | `ThreadPrimitive.MessagesFlatList` 属性 | 与 `ThreadPrimitive.MessagesFlatList` 具有相同的属性，但在此已弃用的封装组件中，自动滚动选项默认设置为 `false` |

### ThreadPrimitive.MessagesFlatList

基于 `FlatList` 的标准 React Native 消息视口。它将每一行限定在对应的消息范围内，将 ref 转发到底层的 `FlatList`，并处理常见聊天流程中的滚动到底部行为。

```tsx
<ThreadPrimitive.MessagesFlatList autoScroll>
  {() => <MyMessage />}
</ThreadPrimitive.MessagesFlatList>
```

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `children` | `({ message }) => ReactNode` | 每条消息的渲染函数 |
| `components` | `MessageComponents` | `children` 的组件映射替代方案 |
| `autoScroll` | `boolean` | 当列表已经接近底部时，自动使列表保持在底部。默认为 `true` |
| `scrollToBottomOnRunStart` | `boolean` | 在运行开始时滚动到底部。默认为 `true` |
| `scrollToBottomOnInitialize` | `boolean` | 消息首次出现时滚动到底部。默认为 `true` |
| `scrollToBottomOnThreadSwitch` | `boolean` | 切换线程时滚动到底部。默认为 `true` |
| `...rest` | `FlatListProps` | 标准 FlatList 属性，但不包括 `data`、`renderItem` 和 `children` |

内置的自动滚动行为假定使用默认的非反转 `FlatList` 方向。

### ThreadPrimitive.MessageByIndex

在指定索引处渲染单条消息。提供消息上下文，使 `useAuiState((s) => s.message)` 可以在渲染的组件中正常工作。此组件共享自 `@assistant-ui/core/react`。

```tsx
<ThreadPrimitive.MessageByIndex
  index={0}
  components={{
    UserMessage: MyUserMessage,
    AssistantMessage: MyAssistantMessage,
  }}
/>
```

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `index` | `number` | 要渲染的消息的从零开始的索引 |
| `components` | `MessageComponents` | 与 `ThreadPrimitive.Messages` 相同的组件映射 |

### ThreadPrimitive.Empty

仅在线程为空（没有消息且未加载）时渲染其子元素。已弃用，建议使用 `AuiIf`。

```tsx
<ThreadPrimitive.Empty>
  <Text>Send a message to get started</Text>
</ThreadPrimitive.Empty>

// preferred
<AuiIf condition={(s) => s.thread.isEmpty}>
  <Text>Send a message to get started</Text>
</AuiIf>
```

### ThreadPrimitive.If

根据线程状态进行条件渲染。已弃用，建议使用 `AuiIf`。

```tsx
<ThreadPrimitive.If empty>
  <Text>No messages yet</Text>
</ThreadPrimitive.If>

// preferred
<AuiIf condition={(s) => s.thread.isEmpty}>
  <Text>No messages yet</Text>
</AuiIf>

<AuiIf condition={(s) => s.thread.isRunning}>
  <ActivityIndicator />
</AuiIf>
```

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `empty` | `boolean` | 在线程是否为空与此值匹配时渲染子元素 |
| `running` | `boolean` | 在线程运行状态与此值匹配时渲染子元素 |

### ThreadPrimitive.Suggestion

`Pressable`，用于插入或发送硬编码的建议提示词。与 `SuggestionPrimitive.Trigger` 不同，此组件不需要建议上下文——提示词直接通过属性传入。

```tsx
<ThreadPrimitive.Suggestion prompt="What can you help me with?" send>
  <Text>What can you help me with?</Text>
</ThreadPrimitive.Suggestion>
```

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `prompt` | `string` | 要发送或插入输入框的文本 |
| `send` | `boolean` | 为 true 时立即发送提示词；为 false 时将其插入输入框（默认值：false） |
| `clearComposer` | `boolean` | 是否替换输入框文本（默认值：true） |
| `...rest` | `PressableProps` | 标准 Pressable 属性（不包括 `onPress`） |

### ThreadPrimitive.Suggestions

使用提供的组件配置渲染所有建议。此组件共享自 `@assistant-ui/core/react`。

```tsx
<ThreadPrimitive.Suggestions>
  {() => <MySuggestion />}
</ThreadPrimitive.Suggestions>
```

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `components` | `{ Suggestion: ComponentType }` | 用于渲染每条建议的组件 |

### ThreadPrimitive.SuggestionByIndex

在指定索引处渲染单条建议，并提供建议上下文。此组件共享自 `@assistant-ui/core/react`。

```tsx
<ThreadPrimitive.SuggestionByIndex
  index={0}
  components={{ Suggestion: MySuggestion }}
/>
```

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `index` | `number` | 要渲染的建议的从零开始的索引 |
| `components` | `{ Suggestion: ComponentType }` | 用于渲染建议的组件 |

### AuiIf

根据助手状态进行条件渲染。替代已弃用的 `ThreadPrimitive.Empty`、`ThreadPrimitive.If`、`MessagePrimitive.If` 和 `ComposerPrimitive.If`。

```tsx
import { AuiIf } from "@assistant-ui/react-native";

<AuiIf condition={(s) => s.thread.isEmpty}>
  <Text>Send a message to get started</Text>
</AuiIf>

<AuiIf condition={(s) => s.thread.isRunning}>
  <ActivityIndicator />
</AuiIf>
```

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `condition` | `(state) => boolean` | 用于确定是否渲染子元素的选择器 |

## 输入框

```tsx
import {
  ComposerPrimitive,
  QueueItemPrimitive,
} from "@assistant-ui/react-native";
```

### ComposerPrimitive.Root

用于输入框区域的容器 `View`。

```tsx
<ComposerPrimitive.Root style={styles.composerContainer}>
  {children}
</ComposerPrimitive.Root>
```

### ComposerPrimitive.Input

`TextInput`，已连接到输入框运行时。值和 `onChangeText` 会自动管理。

```tsx
<ComposerPrimitive.Input
  placeholder="Message..."
  multiline
  style={styles.input}
/>
```

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `submitMode` | `"enter" \| "none"` | 在 Web 上按 Enter 是否发送消息（默认值：`"enter"`） |
| `...rest` | `TextInputProps` | 标准 TextInput 属性（`value`、`onChangeText` 除外） |

### ComposerPrimitive.Send

`Pressable`，用于发送当前消息。输入框为空时会自动禁用。

```tsx
<ComposerPrimitive.Send style={styles.sendButton}>
  <Text>Send</Text>
</ComposerPrimitive.Send>
```

### ComposerPrimitive.Cancel

`Pressable`，用于取消当前运行。没有活动运行时会自动禁用。

```tsx
<ComposerPrimitive.Cancel style={styles.cancelButton}>
  <Text>Stop</Text>
</ComposerPrimitive.Cancel>
```

### ComposerPrimitive.Attachments

使用提供的组件配置渲染输入框附件。

```tsx
<ComposerPrimitive.Attachments>
  {({ attachment }) => {
    if (attachment.type === "image") return <MyImageAttachment />;
    if (attachment.type === "document") return <MyDocumentAttachment />;
    return <MyFallbackAttachment />;
  }}
</ComposerPrimitive.Attachments>
```

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `components` | `{ Image?, Document?, File?, Attachment? }` | 按附件类型提供的组件渲染器 |

### ComposerPrimitive.AddAttachment

`Pressable`，用于触发添加附件。文件选择器必须由使用者实现（例如使用 `expo-document-picker` 或 `expo-image-picker`）。

```tsx
<ComposerPrimitive.AddAttachment>
  <Text>Attach</Text>
</ComposerPrimitive.AddAttachment>
```

### ComposerPrimitive.Queue

渲染所有排队中的输入框项目。每个项目都会包装在 `QueueItemByIndexProvider` 中，因此 `QueueItemPrimitive.*` 可以读取项目状态，并在渲染属性中调用队列操作。其基于来自 `@assistant-ui/core/react` 的共享 `ComposerPrimitiveQueue`。

```tsx
<ComposerPrimitive.Queue>
  {({ queueItem }) => (
    <View>
      <QueueItemPrimitive.Text />
      <QueueItemPrimitive.Steer>
        <Text>Run now</Text>
      </QueueItemPrimitive.Steer>
      <QueueItemPrimitive.Remove>
        <Text>Remove</Text>
      </QueueItemPrimitive.Remove>
    </View>
  )}
</ComposerPrimitive.Queue>
```

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `children` | `(value: { queueItem: QueueItemState }) => ReactNode` | 为每个队列项目调用的渲染函数 |

### ComposerPrimitive.Quote

渲染当前输入框引用的预览。仅当设置了 `s.composer.quote` 时才会渲染子元素，因此它同时充当容器和门控组件。

```tsx
<ComposerPrimitive.Quote>
  <View>
    <Text>Quoting:</Text>
    <ComposerPrimitive.QuoteText />
    <ComposerPrimitive.QuoteDismiss>
      <Text>Clear</Text>
    </ComposerPrimitive.QuoteDismiss>
  </View>
</ComposerPrimitive.Quote>
```

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `children` | `ReactNode` | 引用预览内容；仅在设置引用时渲染 |
| `...rest` | `ViewProps` | 标准 React Native View 属性 |

### ComposerPrimitive.QuoteText

渲染来自 `s.composer.quote?.text` 的引用文本。传入 `children` 可覆盖显示的值。

```tsx
<ComposerPrimitive.QuoteText />
```

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `children` | `ReactNode` | 覆盖内容；默认为 `s.composer.quote?.text` |
| `...rest` | `TextProps` | 标准 React Native Text 属性 |

### ComposerPrimitive.QuoteDismiss

`Pressable`，通过调用 `aui.composer.setQuote(undefined)` 清除当前引用。

```tsx
<ComposerPrimitive.QuoteDismiss>
  <Text>Clear</Text>
</ComposerPrimitive.QuoteDismiss>
```

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `children` | `PressableProps["children"]` | 按钮内容，包括 Pressable 渲染函数子元素 |
| `...rest` | `Omit<PressableProps, "onPress">` | 标准 React Native Pressable 属性，但不包括 `onPress` |

### ComposerPrimitive.AttachmentByIndex

渲染指定索引处的单个输入框附件。适用于构建自定义附件布局。

```tsx
<ComposerPrimitive.AttachmentByIndex
  index={0}
  components={{
    Image: MyImageAttachment,
    Attachment: MyFallbackAttachment,
  }}
/>
```

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `index` | `number` | 要渲染的附件的从零开始的索引 |
| `components` | `{ Image?, Document?, File?, Attachment? }` | 按附件类型提供的组件渲染器 |

### ComposerPrimitive.EditInput

`TextInput`，已连接到编辑输入框运行时。在编辑输入框中使用它可以编辑现有消息。值和 `onChangeText` 会自动管理。

```tsx
<ComposerPrimitive.EditInput

  style={styles.input}

```

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `...rest` | `TextInputProps` | 标准 TextInput 属性（`value`、`onChangeText` 除外） |

### ComposerPrimitive.EditSend

`Pressable`，用于确认并提交消息编辑。输入框为空时会自动禁用。

```tsx
<ComposerPrimitive.EditSend style={styles.sendButton}>
  <Text>Save</Text>
</ComposerPrimitive.EditSend>
```

### ComposerPrimitive.EditCancel

`Pressable`，用于取消正在进行的消息编辑并返回原始消息。

## 消息

```tsx
import { MessagePrimitive } from "@assistant-ui/react-native";
```

### MessagePrimitive.Root

单条消息的容器 `View`。

```tsx
<MessagePrimitive.Root style={styles.messageBubble}>
  {children}
</MessagePrimitive.Root>
```

### MessagePrimitive.Content

使用 render-prop 函数渲染消息内容部分，而不是采用 `MessagePrimitive.Parts` 使用的组件映射方式。每种部分类型都会接收一个 `part` 对象及其 `index`。已注册的工具包渲染器会自动分发，并优先于 `renderToolCall`。

```tsx
<MessagePrimitive.Content
  renderText={({ part }) => <Text>{part.text}</Text>}
  renderToolCall={({ part, index }) => (
    <Text>Tool: {part.toolName}</Text>
  )}
  renderImage={({ part }) => (
    <Image source={{ uri: part.image }} />
  )}
/>
```

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `renderText` | `(props: { part, index }) => ReactElement` | 文本部分的渲染器（默认：React Native `<Text>`） |
| `renderToolCall` | `(props: { part, index }) => ReactElement` | 未由已注册工具 UI 处理的工具调用部分的后备渲染器 |
| `renderImage` | `(props: { part, index }) => ReactElement` | 图像部分的渲染器 |
| `renderReasoning` | `(props: { part, index }) => ReactElement` | 推理部分的渲染器 |
| `renderSource` | `(props: { part, index }) => ReactElement` | 来源部分的渲染器 |
| `renderFile` | `(props: { part, index }) => ReactElement` | 文件部分的渲染器 |
| `renderData` | `(props: { part, index }) => ReactElement` | 未由已注册数据 UI 处理的数据部分的后备渲染器 |

#### 渲染 Markdown

`MessagePrimitive.Content` 默认使用 React Native 的 `<Text>` 渲染文本部分，因此 Markdown 语法会以纯文本形式显示。要渲染 Markdown，请安装 React Native Markdown 渲染器，并通过 `renderText` 传入：

<InstallCommand npm={["react-native-markdown-display"]} />

```tsx
import Markdown from "react-native-markdown-display";
import { MessagePrimitive } from "@assistant-ui/react-native";

const AssistantMessage = () => {
  return (
    <MessagePrimitive.Root>
      <MessagePrimitive.Content
        renderText={({ part }) => (
          <Markdown>{part.text}</Markdown>
        )}
      />
    </MessagePrimitive.Root>
  );
};
```

### MessagePrimitive.Parts

通过 `components` 属性渲染消息内容部分。工具调用和数据部分会自动渲染已注册的工具包渲染器和数据 UI（通过 `useAssistantDataUI`），未匹配时则回退到此处提供的组件。默认提供使用 React Native 的 `<Text>` 的 `Text` 组件。

```tsx
<MessagePrimitive.Parts>
  {({ part }) => {
    if (part.type === "text") return <Text>{part.text}</Text>;
    if (part.type === "image") return <Image source={{ uri: part.image }} />;
    if (part.type === "tool-call") return <MyToolCallComponent {...part} />;
    return null;
  }}
</MessagePrimitive.Parts>
```

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `components` | `object` | 用于渲染每种部分类型的组件映射。请参见下文。 |

**`components` 字段：**

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `Text` | `TextMessagePartComponent` | 文本部分渲染器（默认：React Native `<Text>`） |
| `Image` | `ImageMessagePartComponent` | 图像部分渲染器 |
| `Reasoning` | `ReasoningMessagePartComponent` | 推理部分渲染器 |
| `Source` | `SourceMessagePartComponent` | 来源部分渲染器 |
| `File` | `FileMessagePartComponent` | 文件部分渲染器 |
| `Unstable_Audio` | `Unstable_AudioMessagePartComponent` | 音频部分渲染器（已弃用，请从 `File` 渲染 `audio/*`） |
| `tools` | `{ by_name?, Fallback? }` 或 `{ Override }` | 工具调用渲染配置——使用 `by_name` 将工具名称映射到组件，使用 `Fallback` 处理未注册的工具，或使用 `Override` 处理所有工具调用 |
| `data` | `{ by_name?, Fallback? }` | 数据部分渲染配置——使用 `by_name` 映射数据事件名称，使用 `Fallback` 处理未匹配的事件 |
| `Empty` | `EmptyMessagePartComponent` | 用于显示空消息的组件 |
| `Quote` | `QuoteMessagePartComponent` | 用于渲染引用消息的组件 |
| `ChainOfThought` | `ComponentType` | 将所有推理和工具调用部分组合到单个组件中（与 `Reasoning`/`tools`/`ToolGroup`/`ReasoningGroup` 互斥） |

### MessagePrimitive.PartByIndex

渲染指定索引处的单个消息部分，并提供部分上下文。适用于在 `MessagePrimitive.Parts` 之外构建自定义部分布局。此组件从 `@assistant-ui/core/react` 共享。

```tsx
<MessagePrimitive.PartByIndex
  index={0}
  components={{
    Text: ({ text }) => <Text>{text}</Text>,
    tools: { Fallback: MyToolComponent },
  }}
/>
```

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `index` | `number` | 要渲染的消息部分的从零开始的索引 |
| `components` | `object` | 与 `MessagePrimitive.Parts` 相同的组件映射 |

## 附件

```tsx
import { AttachmentPrimitive } from "@assistant-ui/react-native";
```

```tsx
<AttachmentPrimitive.Root style={styles.attachment}>

```

### AttachmentPrimitive.Name

用于显示附件文件名的 `Text` 组件。

```tsx
<AttachmentPrimitive.Name style={styles.filename} />
```

```tsx
import * as Clipboard from "expo-clipboard";

  copyToClipboard={copyToClipboard}

  {({ isCopied }) => <Text>{isCopied ? "Copied!" : "Copy"}</Text>}
```
