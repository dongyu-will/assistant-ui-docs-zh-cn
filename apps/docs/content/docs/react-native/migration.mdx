---
title: 从 Web 迁移
description: 将现有的 @assistant-ui/react 应用迁移到 React Native。
---

如果你已经有一个 assistant-ui Web 应用，大部分代码都可以直接迁移。通过 `@assistant-ui/core`，`@assistant-ui/react` 和 `@assistant-ui/react-native` 共享运行时核心——只有 UI 层需要更改。

## 保持不变的部分

- **运行时设置**——`useChatRuntime`、`useLocalRuntime`、`ChatModelAdapter` 以及所有运行时选项的工作方式完全相同。
- **AI SDK 集成**——`@assistant-ui/ai-sdk` 支持 React Native。你的 `useChatRuntime` + `AssistantChatTransport` 设置可以直接迁移。
- **工具定义**——`Tools({ toolkit })` 和工具包渲染器使用相同的 API。
- **状态 Hooks**——`useAuiState`、`useAui` 以及选择器模式保持不变。
- **后端代码**——你的 API 路由、流式传输端点和服务端逻辑完全无需更改。

## 需要更改的部分

| Web（`@assistant-ui/react`） | React Native（`@assistant-ui/react-native`） |
|---|---|
| `AssistantRuntimeProvider` | `AssistantRuntimeProvider`（名称相同） |
| DOM 原语（`div`、`button`、`input`） | Native 原语（`View`、`Pressable`、`TextInput`） |
| CSS / Tailwind 样式 | React Native `StyleSheet` 或内联样式 |
| `@assistant-ui/ui`（shadcn 组件） | 使用原语构建自己的 Native UI |

### 保留你的运行时 Hook

你的 `useChatRuntime` 设置可以直接使用——无需任何更改：

```tsx title="hooks/use-app-runtime.ts"
// This file is identical to your web version
import { useChatRuntime, AssistantChatTransport } from "@assistant-ui/ai-sdk";

export function useAppRuntime() {
  return useChatRuntime({
    transport: new AssistantChatTransport({
      api: "/api/chat",
    }),
  });
}
```

<Callout type="tip">
  如果你使用 monorepo，可以直接在 Web 和 Native 项目之间共享此文件。
</Callout>

  </Step>
  <Step>

### 替换 Provider

```tsx
// Before (web)
// import { AssistantRuntimeProvider } from "@assistant-ui/react";

// After (React Native) — same component name, different package
import { AssistantRuntimeProvider } from "@assistant-ui/react-native";

export default function App() {
  const runtime = useAppRuntime();
  return (
    <AssistantRuntimeProvider runtime={runtime}>
      {/* your native UI */}
    </AssistantRuntimeProvider>
  );
}
```

  </Step>
  <Step>

### 重建 UI 层

这是迁移工作的主要部分。Web 组件（来自 `@assistant-ui/ui` 的 `Thread`、`ThreadList`）无法在 React Native 中渲染。请将它们替换为 Native 原语：

```tsx
// Web — DOM-based
// import { Thread } from "@/components/assistant-ui/elements/thread.aui";

// React Native — use primitives or build custom
import {
  ThreadPrimitive,
  ComposerPrimitive,
  MessagePrimitive,
} from "@assistant-ui/react-native";
import { View } from "react-native";

function MyMessage() {
  return (
    <View style={{ padding: 12 }}>
      <MessagePrimitive.Content />
    </View>
  );
}

function ChatScreen() {
  return (
    <ThreadPrimitive.Root style={{ flex: 1 }}>
      <ThreadPrimitive.Messages>
        {() => <MyMessage />}
      </ThreadPrimitive.Messages>
      <ComposerPrimitive.Root>
        <ComposerPrimitive.Input placeholder="Message..." />
        <ComposerPrimitive.Send />
      </ComposerPrimitive.Root>
    </ThreadPrimitive.Root>
  );
}
```

请参阅[原语参考](/docs/react-native/primitives)，查看所有可用组件的完整列表。

  </Step>
</Steps>

## Monorepo 代码共享

在 monorepo 中，除了 UI 层之外，你可以共享所有内容：

```
packages/
  shared/
    hooks/          ← useAppRuntime with useChatRuntime (shared)
    tools/          ← tool definitions (shared)
  web/
    components/     ← DOM-based UI
  native/
    components/     ← React Native UI
```

运行时 Hook、工具定义和后端代码与平台无关。只有 UI 组件需要分别为 Web 和 Native 实现。
