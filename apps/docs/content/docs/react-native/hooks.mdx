## 状态 Hooks

### useAuiState

用于访问响应式状态的主要 Hook。它接受一个选择器函数，以实现细粒度的重新渲染——只有所选值发生变化时，组件才会重新渲染（浅比较）。

```tsx
import { useAuiState } from "@assistant-ui/react-native";

// Thread state
const messages = useAuiState((s) => s.thread.messages);
const isRunning = useAuiState((s) => s.thread.isRunning);
const isEmpty = useAuiState((s) => s.thread.isEmpty);

// Composer state
const text = useAuiState((s) => s.composer.text);
const composerIsEmpty = useAuiState((s) => s.composer.isEmpty);
const attachments = useAuiState((s) => s.composer.attachments);

// Message state (inside a message context)
const role = useAuiState((s) => s.message.role);
const isLast = useAuiState((s) => s.message.isLast);

// Thread list item state
const threadId = useAuiState((s) => s.threadListItem.id);
const title = useAuiState((s) => s.threadListItem.title);
```

### useAui

访问 store 方法，以执行命令式操作。

```tsx
import { useAui } from "@assistant-ui/react-native";

const aui = useAui();

// Composer actions
aui.composer.setText("Hello");
aui.composer.send();

// Thread actions
aui.thread.cancelRun();
```

### useAuiEvent

订阅事件，且不会触发重新渲染。

```tsx
import { useAuiEvent } from "@assistant-ui/react-native";

useAuiEvent("thread.modelContextUpdate", ({ threadId }) => {
  console.log("Model context updated:", threadId);
});
```

## 运行时钩子

### useLocalRuntime

使用 `ChatModelAdapter` 创建 `AssistantRuntime`。

```tsx
import { useLocalRuntime } from "@assistant-ui/react-native";

const runtime = useLocalRuntime(chatModel, {
  initialMessages: [],
});
```

| 选项 | 类型 | 描述 |
|--------|------|-------------|
| `initialMessages` | `ThreadMessageLike[]` | 用于预填充的消息 |
| `maxSteps` | `number` | 每次运行的最大工具调用步骤数 |
| `cloud` | `AssistantCloud` | 用于持久化的可选云实例 |
| `adapters` | `object` | 可选的适配器覆盖配置（见下文） |
| `unstable_humanToolNames` | `string[]` | 在通过 `addResult` 添加结果之前暂停运行的工具名称 |

`adapters` 选项接受以下字段（全部为可选字段）：

| 适配器 | 类型 | 描述 |
|---------|------|-------------|
| `history` | `ThreadHistoryAdapter` | 加载和保存线程消息历史记录 |
| `attachments` | `AttachmentAdapter` | 处理文件和附件上传 |
| `speech` | `SpeechSynthesisAdapter` | 文本转语音播放 |
| `dictation` | `DictationAdapter` | 语音转文本输入 |
| `feedback` | `FeedbackAdapter` | 点赞/点踩反馈 |
| `suggestion` | `SuggestionAdapter` | 提示建议 |

### useRemoteThreadListRuntime

创建一个 `AssistantRuntime`，并使用 `RemoteThreadListAdapter` 作为持久化线程列表的后端。它可以包装任意运行时钩子（例如调用 `useLocalRuntime` 的钩子或自定义 AI SDK 钩子），并在其上添加线程列表管理功能。

```tsx
import { useRemoteThreadListRuntime } from "@assistant-ui/react-native";

const runtime = useRemoteThreadListRuntime({
  runtimeHook: () => useLocalRuntime(chatModel),
  adapter: myThreadListAdapter,
});
```

| 选项 | 类型 | 描述 |
|--------|------|-------------|
| `runtimeHook` | `() => AssistantRuntime` | 返回每个线程运行时的钩子 |
| `adapter` | `RemoteThreadListAdapter` | 用于列出、创建和归档线程的后端适配器 |
| `allowNesting` | `boolean` | 当 `true` 时，如果已经处于另一个 `useRemoteThreadListRuntime` 中，则会静默变为无操作 |

## 模型上下文钩子

### 工具

在 `"use generative"` 文件中使用 `defineToolkit` 编写工具，其 API 与网页端相同（[定义工具](/docs/tools/defining-tools)）。工具定义会转发给模型；当模型调用该工具时，`execute` 函数会运行，而 `render` 组件会显示结果。

添加 [`@assistant-ui/metro`](https://www.npmjs.com/package/@assistant-ui/metro) 插件，使 Metro 能够编译 `"use generative"` 指令：

```js title="metro.config.js"
const { getDefaultConfig } = require("expo/metro-config");
const { withAui } = require("@assistant-ui/metro");

module.exports = withAui(getDefaultConfig(__dirname));
```

```tsx title="weather-toolkit.tsx"
"use generative";

import { defineToolkit } from "@assistant-ui/react-native";
import { Text, View } from "react-native";
import { z } from "zod";

export default defineToolkit({
  get_weather: {
    description: "Get the current weather for a city",
    parameters: z.object({ city: z.string() }),
    execute: async ({ city }) => {
      "use client";
      const res = await fetch(`https://api.weather.example/${city}`);
      return res.json();
    },
    render: ({ args, result }) => (
      <View>
        <Text>
          {args.city}: {result?.temperature}°F
        </Text>
      </View>
    ),
  },
});
```

```tsx title="ToolProvider.tsx"
import {
  AuiConfig,
  AuiProvider,
  Tools,
  useAui,
} from "@assistant-ui/react-native";
import toolkit from "./weather-toolkit";

function ToolProvider({ children }: { children: React.ReactNode }) {
  const aui = useAui();
  const config = AuiConfig({ tools: Tools({ toolkit }) });
  return (
    <AuiProvider extends={aui} config={config}>
      {children}
    </AuiProvider>
  );
}
```

### useAssistantDataUI

为命名的数据消息部分注册 UI 渲染器。

```tsx
import { useAssistantDataUI } from "@assistant-ui/react-native";

useAssistantDataUI({
  name: "weather_card",
  render: ({ data }) => (
    <View>
      <Text>{data.city}: {data.temperature}°F</Text>
    </View>
  ),
});
```

### useAssistantInstructions

在模型上下文中注册系统指令。

```tsx
import { useAssistantInstructions } from "@assistant-ui/react-native";

useAssistantInstructions("You are a helpful weather assistant.");
```

### useInlineRender

包装工具 UI 组件，使内联状态更新（来自父组件的渲染）能够在不重新挂载组件的情况下反映出来。当渲染函数闭包引用了会随时间变化的 props 时，请使用此方法。

```tsx title="my-tool-toolkit.tsx"
import { defineToolkit, useInlineRender } from "@assistant-ui/react-native";
import { Text } from "react-native";
import { useMemo } from "react";

export function useMyToolToolkit(someOuterProp: string) {
  const stableRender = useInlineRender(({ args, result }) => (
    <Text>{someOuterProp}: {result?.value}</Text>
  ));

  return useMemo(
    () =>
      defineToolkit({
        my_tool: {
          type: "backend",
          render: stableRender,
        },
      }),
    [stableRender],
  );
}
```

导入工具包 hook，在组件主体中提升 `const aui = useAui()` 和 `const config = AuiConfig({ tools: Tools({ toolkit }) })`，并使用 `<AuiProvider extends={aui} config={config}>` 挂载它，如上方[工具](#tools)部分所示。

### makeAssistantDataUI

创建一个组件，在挂载时注册数据 UI 渲染器。

```tsx
import { makeAssistantDataUI } from "@assistant-ui/react-native";

const WeatherCard = makeAssistantDataUI({
  name: "weather_card",
  render: ({ data }) => <Text>{data.city}: {data.temperature}°F</Text>,
});

<WeatherCard />
```

## 共享提供者

这些上下文提供者从 `@assistant-ui/core/react` 重新导出，原语在内部使用它们将 `aui` 存储限定到特定项目（消息、部分、线程列表项等）。它们适用于高级自定义渲染场景。

### MessageByIndexProvider

将 `aui` 上下文限定为线程中指定索引对应的消息。

```tsx
import { MessageByIndexProvider } from "@assistant-ui/react-native";

<MessageByIndexProvider index={2}>
  {/* children can read s.message, s.composer */}
</MessageByIndexProvider>
```

### PartByIndexProvider

将 `aui` 上下文限定到指定索引的消息部分。

```tsx
import { PartByIndexProvider } from "@assistant-ui/react-native";

<PartByIndexProvider index={0}>
  {/* children can read s.part */}
</PartByIndexProvider>
```

### TextMessagePartProvider

从普通字符串提供合成的文本部分上下文。适用于在常规消息部分管道之外渲染文本。

```tsx
import { TextMessagePartProvider } from "@assistant-ui/react-native";

<TextMessagePartProvider text="Hello world" isRunning={false}>
  {/* children can read s.part as a text part */}
</TextMessagePartProvider>
```

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `text` | `string` | 文本内容 |
| `isRunning` | `boolean` | 文本部分是否仍在进行流式传输（默认为 `false`） |

### ChainOfThoughtByIndicesProvider

将 `aui` 上下文限定为构成思维链区块的消息部分切片。

```tsx
import { ChainOfThoughtByIndicesProvider } from "@assistant-ui/react-native";

<ChainOfThoughtByIndicesProvider startIndex={1} endIndex={3}>
  {/* children can read s.chainOfThought */}
</ChainOfThoughtByIndicesProvider>
```

### ChainOfThoughtPartByIndexProvider

将 `aui` 上下文的作用域限定为思维链区块中的特定部分。

```tsx
import { ChainOfThoughtPartByIndexProvider } from "@assistant-ui/react-native";

<ChainOfThoughtPartByIndexProvider index={0}>
  {/* children can read s.part */}
</ChainOfThoughtPartByIndexProvider>
```

### ThreadListItemByIndexProvider

将 `aui` 上下文限定到按索引指定的线程列表项。

```tsx
import { ThreadListItemByIndexProvider } from "@assistant-ui/react-native";

<ThreadListItemByIndexProvider index={0} archived={false}>
  {/* children can read s.threadListItem */}
</ThreadListItemByIndexProvider>
```

### SuggestionByIndexProvider

将 `aui` 上下文限定为索引对应的特定建议。

```tsx
import { SuggestionByIndexProvider } from "@assistant-ui/react-native";

<SuggestionByIndexProvider index={0}>
  {/* children can read s.suggestion */}
</SuggestionByIndexProvider>
```
