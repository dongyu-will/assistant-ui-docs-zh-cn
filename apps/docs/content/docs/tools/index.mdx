工具是模型执行操作的方式：获取数据、调用 API、查询数据库、驱动 UI 或运行工作流。在 assistant-ui 中，你可以在**工具包**中声明工具——这是一个命名映射，其中每个键都是模型看到的工具名称，每个值描述工具的架构、运行位置，以及其调用在聊天中的渲染方式。

## 使用 `"use generative"` 定义工具

<Callout type="info">
  使用 `"use generative"` + `defineToolkit` 创建工具包。对于在其他位置执行的工具，可以展开 `defineMcpToolkit({ ... })` 以连接 MCP 服务器，或使用 `execute: externalTool()` 为非 MCP 外部工具附加渲染器。
</Callout>

在 `"use generative"` 文件中，每个工具都会声明一个 `execute`，其类型会从中**推断**出来（无需手动写入 `type`）。请参阅[定义工具](/docs/tools/defining-tools#define-tools-with-use-generative)。

## 将 AI 输出渲染为 UI

assistant-ui 提供了多种将模型输出转换为 React UI 的方式。请根据**谁决定渲染什么**进行选择：

| 你的需求是…… | 使用 | 决策者 |
| --- | --- | --- |
| 为已知的工具调用（表单、选择器、图表、状态）创建自定义组件 | [工具 UI](/docs/tools/tool-ui)——在工具包条目上使用 `render` | **模型**，通过调用工具决定 |
| AI 可以读写的持久化线程外状态 | [可交互组件](/docs/tools/interactables) | **模型 + 用户**，双向决定 |
| 使用你提供的组件词汇组合 UI | [生成式 UI](/docs/tools/generative-ui)——`present` 工具 | **模型**，组合出组件树 |
| LangGraph 节点随消息推送的 UI | [LangGraph 生成式 UI](/docs/runtimes/langgraph/generative-ui)——`makeAssistantDataUI` | **后端 / 编排器** |
| 使用 OpenUI Lang 组合 UI，并由 OpenUI 工具包渲染（第三方） | [OpenUI](/docs/tools/openui)——`@openuidev/assistant-ui` | **模型**，组合出组件树 |
