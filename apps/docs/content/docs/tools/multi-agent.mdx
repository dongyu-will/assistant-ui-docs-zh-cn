在多代理（或编排器）架构中，主代理通过工具调用来调用子代理。每个子代理都可以生成自己的对话（用户/助手消息、工具调用等）。assistant-ui 支持使用 `MessagePartPrimitive.Messages` 原语渲染这些嵌套对话。

## 概览

当工具调用包含 `messages` 字段（`ToolCallMessagePart.messages`）时，它表示子代理的对话历史。`MessagePartPrimitive.Messages` 会从当前工具调用部分读取此字段，并将其渲染为嵌套线程。

主要行为：

- **作用域继承** — 父级工具包渲染器可用于子代理消息。在顶层注册的 `Tools({ toolkit })` 同样适用于子代理对话。
- **递归嵌套** — 子代理消息可以包含自身带有嵌套消息的工具调用。只需再次使用 `MessagePartPrimitive.Messages`。
- **只读** — 子代理消息会在只读上下文中渲染。不支持编辑、分支或输入。

<Callout type="info">
  这里渲染的是子代理的**消息**。如果要可视化子代理的**执行轨迹**（计时、跨度层级、瀑布图），请参阅 [react-o11y](/docs/utilities/react-o11y)，它会将可观测性跨度渲染为可折叠的树和时间线。
</Callout>

## 快速开始

<Steps>
  <Step>

### 为子代理注册工具 UI

```tsx
import {
  defineToolkit,
  Tools,
  MessagePartPrimitive,
} from "@assistant-ui/react";

const toolkit = defineToolkit({
  invoke_researcher: {
    type: "backend",
    render: ({ args, status }) => (
    <div className="my-2 rounded-lg border p-4">
      <div className="mb-2 text-sm font-medium text-gray-500">
        Researcher Agent {status.type === "running" && "(working...)"}
      </div>
      <MessagePartPrimitive.Messages>
        {({ message }) => {
          if (message.role === "user") return <MyUserMessage />;
          return <MyAssistantMessage />;
        }}
      </MessagePartPrimitive.Messages>
    </div>
  ),
  },
});
```

  </Step>

### 从后端提供消息

子代理的对话必须传递到 `ToolCallMessagePart.messages`。AI SDK 和 LangGraph 后端会从工具结果中填充该字段；AG-UI 后端则会发出协议定义的子代理生命周期事件，并由运行时将其组装起来。

<Tabs items={["AI SDK", "LangGraph", "AG-UI"]}>
<Tab value="AI SDK">

```ts title="api/chat/route.ts"
tools: {
  invoke_researcher: tool({
    description: "Invoke the researcher sub-agent",
    parameters: z.object({ query: z.string() }),
    execute: async ({ query }) => {
      const subAgentMessages = await runResearcherAgent(query);
      return {
        answer: subAgentMessages.at(-1)?.content,
        messages: subAgentMessages,
      };
    },
  }),
},
```

</Tab>
<Tab value="LangGraph">

使用 `@assistant-ui/react-langgraph` 时，请使用 `unstable_createLangGraphStream` 并设置 `unstable_allowCancellation: true`，以连接停止按钮。当图运行子图时，只要处理 `onSubgraphValues` / `onSubgraphUpdates` 事件，子图的消息就会自动显示在 `ToolCallMessagePart.messages` 上。

```ts title="runtime.ts"
import {
  useLangGraphRuntime,
  unstable_createLangGraphStream,
} from "@assistant-ui/react-langgraph";

const runtime = useLangGraphRuntime({
  unstable_allowCancellation: true,
  stream: unstable_createLangGraphStream({
    client,
    assistantId,
    // "custom" is required for generative UI; "updates" for subgraph events
    streamMode: ["messages", "updates", "custom"],
    // abort the run server-side when the user clicks stop
    onDisconnect: "cancel",
  }),
  eventHandlers: {
    onSubgraphValues: (namespace, values) => {
      // namespace = e.g. "tools:call_abc" — the sub-agent's node path
      // values contains the subgraph state, including its messages array
    },
    onSubgraphUpdates: (namespace, updates) => {
      // incremental state updates from the subgraph
    },
    onSubgraphError: (namespace, error) => {
      // error scoped to the subgraph; does not mark the parent message failed
    },
    onMessageChunk: (chunk, metadata) => {
      // metadata.namespace is set when the chunk originates from a subgraph
      // use it to attribute the chunk to the correct sub-agent
    },
  },
});
```

完整的事件处理器参考请参阅 [LangGraph 流式传输](/docs/runtimes/langgraph/streaming)。

</Tab>
<Tab value="AG-UI">

使用 `@assistant-ui/react-ag-ui` 时，无需填充 `messages` 字段：运行时会根据协议自身的子代理生命周期构建嵌套关系。采用 agents-as-tools 模式的后端会发出 `SUBAGENT_STARTED`，将生成该调用的调用命名为 `parentToolCallId`；为该子代理生成的每个事件添加其 `subagentRunId`；并使用 `SUBAGENT_FINISHED` 或 `SUBAGENT_ERROR` 结束运行。运行时会将每次运行归组为一条嵌套助手消息，并将其附加到该调用的 `ToolCallMessagePart.messages` 上，因此上面的工具 UI 会原样渲染它。

子代理的 `name`、`description`、`result`、`interruptIds` 和 `errorCode` 会随嵌套消息的 `metadata.custom.agui` 一起传递。若某次运行的 `parentToolCallId` 未命名任何可访问的调用，则没有可嵌套的位置，消息会改为渲染在父线程中。

完整行为、与 LangChain discovery-hook 形式的比较，以及两个限制（重新加载后嵌套关系不会保留，嵌套的人在回路没有恢复路径），请参阅 [AG-UI 子代理](/docs/runtimes/ag-ui/runtime-options#subagents)。

</Tab>
</Tabs>

## 子图命名空间事件

使用 LangGraph 时，子图事件（`onSubgraphValues` / `onSubgraphUpdates` / `onSubgraphError`，以及 `onMessageChunk` 上的 `namespace`）会携带一个 `namespace`，用于标识发出事件的子代理，从而可以将消息和状态归属到特定的子代理。完整参考请参阅 [LangGraph 流式传输](/docs/runtimes/langgraph/streaming)。

## 递归子代理

如果子代理的工具调用也包含嵌套消息，则同样的模式会递归应用：

```tsx
const toolkit = defineToolkit({
  invoke_planner: {
    type: "backend",
    render: () => (
    <div className="rounded border p-3">
      <h4>Planner Agent</h4>
      <MessagePartPrimitive.Messages>
        {({ message }) => {
          if (message.role === "user") return <MyUserMessage />;
          return (
            <MessagePrimitive.Parts>
              {({ part }) => {
                if (part.type === "text") return <MyText />;
                if (part.type === "tool-call" && part.toolName === "invoke_researcher") return (
                  <div className="ml-4 rounded border p-3">
                    <h5>Researcher Agent</h5>
                    {/* Nested sub-agent renders recursively */}
                    <MessagePartPrimitive.Messages>
                      {({ message }) => {
                        if (message.role === "user") return <MyUserMessage />;
                        return <MyAssistantMessage />;
                      }}
                    </MessagePartPrimitive.Messages>
                  </div>
                );
                if (part.type === "tool-call") return <MyToolFallback {...part} />;
                return null;
              }}
            </MessagePrimitive.Parts>
          );
        }}
      </MessagePartPrimitive.Messages>
    </div>
  ),
  },
});
```

## ReadonlyThreadProvider

对于更高级的使用场景，如果你有一个 `ThreadMessage[]` 数组，并希望在工具调用上下文之外将其渲染为线程，可以直接使用 `ReadonlyThreadProvider`：

```tsx
import {
  ReadonlyThreadProvider,
  ThreadPrimitive,
  type ThreadMessage,
} from "@assistant-ui/react";

function SubConversation({
  messages,
}: {
  messages: readonly ThreadMessage[];
}) {
  return (
    <ReadonlyThreadProvider messages={messages}>
      <ThreadPrimitive.Messages>
        {({ message }) => {
          if (message.role === "user") return <MyUserMessage />;
          return <MyAssistantMessage />;
        }}
      </ThreadPrimitive.Messages>
    </ReadonlyThreadProvider>
  );
}
```

`ReadonlyThreadProvider` 会通过作用域继承机制继承父级的工具 UI 注册和模型上下文。
