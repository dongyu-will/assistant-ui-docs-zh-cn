[A2UI](https://a2ui.org/) 是一种声明式生成式 UI 协议：助手流式传输界面操作（创建界面、插入或更新组件、更新数据模型），宿主则根据预先批准的组件目录进行渲染，整个过程中不会传输代码。AG-UI 生态将 A2UI 作为 `ACTIVITY_SNAPSHOT` 事件传输，其中包含 `activityType: "a2ui-surface"`，操作则位于 `content.a2ui_operations` 下；这是由 [`@ag-ui/a2ui-middleware`](https://github.com/ag-ui-protocol/ag-ui/tree/main/middlewares/a2ui-middleware).

`useAgUiRuntime` 原生使用这些快照。每个界面都会成为一个工具调用部分，其中包含 `toolCallId` `a2ui:<surfaceId>` 和 `toolName` `"present"`，其参数是转换后的生成式 UI 规范，因此界面会通过与 [`present` 前端工具](/docs/tools/generative-ui)相同的路径进行渲染。任何其他 `activityType` 的快照都会被忽略，MCP Apps 的活动路径不受影响。

## 传输协议

后端通过在 AG-UI 流中发出活动快照来绘制或更新界面：

```json
{
  "type": "ACTIVITY_SNAPSHOT",
  "messageId": "a2ui-surface-call_1",
  "activityType": "a2ui-surface",
  "replace": true,
  "content": {
    "a2ui_operations": [
      { "version": "v0.9", "createSurface": { "surfaceId": "s1" } },
      {
        "version": "v0.9",
        "updateComponents": {
          "surfaceId": "s1",
          "components": [
            { "id": "root", "component": "Card", "title": "Order", "children": ["total"] },
            { "id": "total", "component": "Text", "text": { "path": "/total" } }
          ]
        }
      },
      {
        "version": "v0.9",
        "updateDataModel": { "surfaceId": "s1", "path": "/", "contents": { "total": "$42" } }
      }
    ]
  }
}
```

- 包含 `replace: true`（模式默认值）的快照，会根据其中携带的操作重建该 `messageId` 的界面状态。如果已经看到该 `messageId`，则 `replace: false` 表示忽略该快照，这与 AG-UI 事件规范一致。中间件始终会发出 `replace: true`。
- 界面由操作中的 `surfaceId` 标识，而不是由 `messageId` 标识。共享同一 `messageId` 的多个快照会原地更新其界面，并且合成部分会保留其 `toolCallId`，因此渲染后的界面会更新，而不会重复创建部分。
- 组件树使用 A2UI 邻接表模型：节点通过 id 引用子节点，根节点的 id 为 `root`，而形如 `{ "path": "/x/y" }` 的 props 是 JSON Pointer 绑定，会根据界面数据模型进行解析。v0.9 和 v1.0 的操作负载均受支持，包括 `createSurface` 上 v1.0 内联的 `components` 和 `dataModel`。
- 携带 `status`（例如 `"building"`）但不包含 `a2ui_operations` 的生命周期快照会被容忍，在操作到达前不会生成部分。`deleteSurface` 操作会移除界面的部分。
- `a2ui:` 工具调用 ID 前缀专用于合成的界面部分：它们是客户端的渲染产物，不会包含在发回助手的历史记录中，因此真实的助手工具调用不得使用以 `a2ui:` 开头的 ID。

## 快速开始

从 `@assistant-ui/react-generative-ui` 注册 `present` 前端工具；传入的界面随后会使用默认词汇进行渲染：

```tsx
import {
  JSONGenerativeUI,
  defaultGenerativeUILibrary,
} from "@assistant-ui/react-generative-ui";

const generative = new JSONGenerativeUI({
  library: defaultGenerativeUILibrary,
});

const toolkit = {
  present: generative.present({ display: "standalone" }),
};
```

按照 [生成式 UI](/docs/tools/generative-ui) 页面中的方式，将工具包传递给助手；`useAgUiRuntime` 无需其他配置。

## 操作

`Button` 节点会通过操作注册表分发类型为 `"a2ui:action"` 的 `$action` 对象。在组件内部，将注册表连接到 `useAgUiSendA2uiAction`；该 hook 会返回一个稳定函数，因此工具包可以基于它进行记忆化：

```tsx
import { useMemo } from "react";
import { useAgUiSendA2uiAction } from "@assistant-ui/react-ag-ui";
import {
  JSONGenerativeUI,
  createActionRegistry,
  defaultGenerativeUILibrary,
} from "@assistant-ui/react-generative-ui";

function useA2uiToolkit() {
  const sendA2uiAction = useAgUiSendA2uiAction();
  return useMemo(() => {
    const generative = new JSONGenerativeUI({
      library: defaultGenerativeUILibrary,
      actions: createActionRegistry({
        "a2ui:action": ({ payload }) => sendA2uiAction(payload),
      }),
    });
    return { present: generative.present({ display: "standalone" }) };
  }, [sendA2uiAction]);
}
```

发送操作会触发一次不包含新用户消息的运行，助手会以 `forwardedProps.a2uiAction.userAction` 的形式接收它，这是 `@ag-ui/a2ui-middleware` 所使用的约定。该操作只在一次运行中传递；`type` 字段会被移除，并且在缺失时会添加 `timestamp`。

中间件会将该操作转换为合成的 `log_a2ui_event` 工具调用对，但它从未在 `input.tools` 中声明；如果后端根据已声明的工具列表验证工具调用，就会拒绝它。

## 组件映射

转换器会将 A2UI 基础目录映射到默认的生成式 UI 词汇：`Text` 变为 `Markdown`（`h1` 至 `h6` 变体会变为 `Header`，`caption` 变为 `Caption`），`Column` 变为 `Col`，`TextField` 变为 `Input`（控件名称取自其绑定路径的最后一段），`CheckBox` 变为 `Checkbox`，而 `Image`、`Row`、`Card`、`Divider`、`Button` 则一一对应映射。带有模板子节点的节点会根据绑定列表展开为一个 `ListView`。`Button` 操作会变为类型为 `"a2ui:action"` 的 `$action` 对象，其中包含操作名称、`surfaceId` 和 `sourceComponentId`，操作注册表正是通过这些内容接收操作。未知组件和操作会跳过，并输出调试警告；转换受到限制（深度 32、100 个模板项、5000 个节点），因此格式错误的流不会使客户端挂起。

## 限制

- 上游中间件目前发出 v0.9 操作负载；渲染器同时接受 v0.9 和 v1.0 形状。
