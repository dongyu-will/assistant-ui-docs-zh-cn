### AuiConfig

构建用于 [AuiProvider](/docs/api-reference/context-providers/assistant-runtime-provider#auiprovider) 的配置；`config` 属性只接受
使用此辅助工具构建的配置。

配置是普通数据：可以将其提升到模块作用域、在每次渲染时以内联方式创建，或进行记忆化处理——provider
从不依赖配置的身份。

```tsx
const aui = useAui();
const config = AuiConfig({
  message: Derived({
    source: "thread",
    query: { index: 0 },
    get: (aui) => aui.thread.message({ index: 0 }),
  }),
});

<AuiProvider extends={aui} config={config}>{children}</AuiProvider>;
```

### MessageNotSentError

用于表示发送请求从未到达后端的拒绝原因，因此没有任何操作执行，
线程中也没有任何内容可以恢复。运行时适配器会从
`onNew` 抛出该错误，将消息交还给线程输入框；如果此后没有其他内容占用输入框，
线程输入框会恢复其在分发时清除的草稿。编辑输入框会在分发时关闭，因此被拒绝的编辑不会
恢复。

### RemoteThreadList

由 `RemoteThreadListAdapter` 支持的 `AuiConfig` `threads` 条目。线程
主体由客户端树中的 `thread` 工厂创建，因此任何
`AssistantClient` 宿主都可以运行远程列表或云列表。每个线程的历史记录
和附件来自 `unstable_useAdapters`。当省略 `unstable_Provider` 时，`useRemoteThreadListRuntime`
使用相同的 hook。使用 `withKey` 作为工厂的 key，
这样可在可见线程发生变化时重新加载历史记录。
使用 `backgroundThreads` 时，每个访问过的线程都会保持挂载：切换线程期间运行会继续，
每个条目的 `isRunning` 保持实时更新，新初始化的线程会自动设置标题。

### unstable_defaultWebMcpFilter

当未传入 `filter` 时，WebMCP provider 使用的谓词：一个已启用的
前端工具，并带有客户端 `execute`。未使用 `type` 编写的工具也会被包含，
因为 `execute` 才是区分已弃用的无类型形式与后端工具或人工工具的依据。
`filter` 会替代此默认值，因此应将其传入以缩小默认集合，而不是扩大集合。

```ts
const unstable_defaultWebMcpFilter: (_name: string, tool: Tool<any, any>) => boolean;
```

### unstable_useWebMcpProvider

将模型上下文中的前端工具发布到支持 WebMCP 的浏览器，
这样用户自己的浏览器代理就可以调用这些工具。

当页面未公开任何 `document.modelContext`（或 `navigator.modelContext`）时，返回
`status: "unsupported"`；否则返回当前向宿主注册的工具名称（已排序）。

### useSmooth

以打字机式的显示效果为流式消息部分的文本添加动画。

接收当前部分状态和一个 `smooth` 参数：`false` 表示禁用，
`true` 使用默认速率，SmoothOptions 对象则用于调整
显示效果。返回部分状态，其中 `text` 被替换为已显示的
前缀，并由 `status` 报告 `running`，直到显示进度追上源文本。
如果源文本在尚未显示任何字符前就已稳定，则会立即提交文本，这样即使错过动画帧，也不会留下
空的消息气泡。

在 `prefers-reduced-motion: reduce` 下，显示效果会自动禁用，
并立即提交完整文本；这优先于显式设置的 `smooth={true}`。

```tsx
const { text, status } = useSmooth(useMessagePartText(), {
  drainMs: 500,
  maxCharsPerFrame: 30,
});
```
