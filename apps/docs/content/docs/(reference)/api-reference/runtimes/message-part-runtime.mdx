## API 参考

### EnrichedPartState

传递给子级渲染函数的增强部分状态。

对于工具调用部分，会额外添加 `toolUI`、`addResult` 和 `resume`。
对于数据部分，会额外添加 `dataRendererUI`。

当助手消息尚无任何部分但处于运行状态时，渲染函数还会使用合成的空文本部分
（`{ type: "text", text: "", status: { type: "running" } }`）调用一次，
以便渲染加载指示器。通过 `part.status?.type === "running" && part.text === ""` 将其与真实的空文本区分开来。
