### useMessageQuote

如果当前消息包含引用信息，则返回该信息的 Hook。


### useScrollLock

在可折叠动画或高度动画期间锁定滚动位置，并隐藏滚动条。

此工具可防止动画期间内容高度变化导致页面跳动，
从而提供流畅的用户体验。它会查找最近的可滚动祖先元素，并在动画完成期间
暂时锁定其滚动位置。

- 防止强制重排：不读取布局，仅对可滚动父元素进行变更
- 响应式：仅在浏览器实际调整滚动位置时拦截滚动事件
- 动画持续时间结束后自动清理

```tsx
const collapsibleRef = useRef<HTMLDivElement>(null);
const lockScroll = useScrollLock(collapsibleRef, 200);

const handleCollapse = () => {
  lockScroll(); // Lock scroll before collapsing
  setIsOpen(false);
};
```

### unstable_useComposerInput

<Callout type="tip">
<strong>实验性 API。</strong> 正在积极开发中，可能会在不另行通知的情况下发生变化。
</Callout>

用于连接输入框文本值和发送操作的无头桥接层，可在不使用 `ComposerPrimitive.Input` 的情况下构建
自定义输入框。它是一个轻量桥接层，而不是第二个输入框：它不负责键盘行为、自动调整大小、IME 或
contentEditable 同步、粘贴/拖放附件、焦点管理或富文本状态。将 `unstable_useTriggerPopoverAriaProps()`
展开到你的元素上，以实现触发器弹出框组合框语义。

```tsx
const { value, setText, send, isDisabled, canSend } = unstable_useComposerInput();
<textarea
  value={value}
  disabled={isDisabled}
  onChange={(e) => setText(e.target.value)}
  onKeyDown={(e) => {
    if (e.key === "Enter" && !e.shiftKey && canSend) {
      e.preventDefault();
      send();
    }
  }}
/>
```

### unstable_useComposerInputHistory

<Callout type="tip">
<strong>实验性 API。</strong> 正在积极开发中，可能会在不另行通知的情况下发生变化。
</Callout>

面向终端风格的线程输入框输入历史：在草稿为空时按 ArrowUp 可调出之前发送的用户消息（按最新优先），
按 ArrowDown 可向最新消息方向返回，最后恢复开始浏览历史时正在输入的草稿。

仅当光标位于首行或末行且没有选区时才会触发调出操作，因此多行编辑仍保持原生箭头键行为。
如果提及/斜杠弹出框已打开、正在进行 IME 组合、按下了修饰键，或消费者处理程序已经调用
`preventDefault`，处理程序会让出控制权。对于编辑输入框，此 Hook 不执行任何操作。

```tsx
const history = unstable_useComposerInputHistory();
<ComposerPrimitive.Input {...history} />
```

```ts
function unstable_useComposerInputHistory(): Unstable_ComposerInputHistory;
```

### unstable_useMessageStallDetection

<Callout type="tip">
<strong>实验性 API。</strong> 正在积极开发中，可能会在不另行通知的情况下发生变化。
</Callout>

检测当前消息在运行过程中的输出停滞：消息运行期间，监视其内容的指纹（部分数量以及文本、

### unstable_useThreadMessageIds

<Callout type="tip">
<strong>实验性 API。</strong> 不稳定/实验性 API——可能在任何版本中发生变化。
</Callout>

按顺序返回当前线程中消息的 ID。

返回的数组在仅内容更新（例如流式传输）期间保持稳定的身份，只有 ID 序列本身发生变化时才会更改引用。
将它与 `ThreadPrimitive.Unstable_MessageById` 配合使用，可驱动虚拟化消息列表或自定义消息列表。

```ts
const unstable_useThreadMessageIds: () => readonly string[];
```
