## API 参考

### useAui

从上下文中返回当前的 `AssistantClient`。

读取最近的 [AuiProvider](/docs/api-reference/context-providers/assistant-runtime-provider#auiprovider) 或
[AssistantRuntimeProvider](/docs/api-reference/context-providers/assistant-runtime-provider#assistantruntimeprovider) 提供的客户端，然后访问其上的作用域 —
`aui.thread`、`aui.composer`、`aui.message` 等。结合
[useAuiState](/docs/api-reference/hooks/state#useauistate) 读取响应式状态，并使用 [useAuiEvent](/docs/api-reference/hooks/state#useauievent)
订阅事件。返回的客户端还会暴露 `aui.on(...)` 和
`aui.subscribe(...)` 等较底层的方法；对于 React 事件订阅，优先使用
`useAuiEvent`。

如果在 provider 外部渲染，返回客户端的作用域访问器会在每次调用时
抛出描述性错误。

{/* api-example:useAui:start */}
```tsx
import { useAui } from "@assistant-ui/react";

const aui = useAui();

aui.composer().setText("Hello");
aui.composer().send();
aui.thread().cancelRun();
```
{/* api-example:useAui:end */}

```ts
function useAui(): AssistantClient;
```

### useAuiEvent

在组件的整个生命周期内订阅助手事件。

订阅会在挂载时建立，并在作用域或事件名称发生变化时重新建立。
`callback` 会通过 effect-event 兼容层包装，因此每次触发时都会调用最新的闭包 —
无需对其进行记忆化。

{/* api-example:useAuiEvent:start */}
```tsx
import { useAuiEvent } from "@assistant-ui/react";

useAuiEvent("thread.modelContextUpdate", ({ threadId }) => {
  console.log("Model context updated", threadId);
});
```

### useAuiState

订阅 [AssistantState](/docs/api-reference/primitives/assistant-if#assistantstate) 的一个切片，并在该切片发生变化时重新渲染
组件。

每次状态存储更新时都会调用 `selector`；其返回值会通过
`Object.is` 进行比较，只有选中的切片发生变化时组件才会重新渲染。不支持返回
完整的状态对象，并且会在运行时抛出错误 — 请改为选择特定字段，或组合多个
`useAuiState` 调用。返回新的对象或数组字面量（包括将 `s.thread`
展开到新对象中）会导致组件在每次状态存储更新时重新渲染；请改为选择基本类型值，
或返回经过记忆化的引用。

可能不可用的作用域可以通过 `s.optional.<scope>` 读取；该方法会解析为
`undefined`，而不是抛出错误。

{/* api-example:useAuiState:start */}
```tsx
import { useAuiState } from "@assistant-ui/react";

const messages = useAuiState((s) => s.thread.messages);
const isRunning = useAuiState((s) => s.thread.isRunning);
const composerText = useAuiState((s) => s.composer.text);
```
