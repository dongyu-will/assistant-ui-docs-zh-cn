### unstable_useLiveCompletionAdapter

<Callout type="tip">
<strong>实验性功能。</strong> 正在积极开发中，可能会在不另行通知的情况下发生变化。
</Callout>

将异步补全源（例如服务器搜索或网关 RPC）桥接到
`Unstable_TriggerAdapter` 消费的同步 `ComposerTriggerPopover`。
`search(query)` 会同步返回最近获取的项目，并在查询发生变化时安排防抖请求；结果返回后，返回的
`adapter` 标识会发生变化，从而重新运行弹出框的查找逻辑，使新项目得以渲染。这是一个仅用于搜索的适配器（`categories` 为空）。

请求进行期间，`isLoading` 为 `true`。将其传递给弹出框的
`isLoading` 属性即可渲染加载状态。

```tsx
const mentions = unstable_useLiveCompletionAdapter({
  fetcher: (query) => searchUsers(query),
});

<ComposerTriggerPopover
  char="@"
  adapter={mentions.adapter}
  isLoading={mentions.isLoading}
  directive={{ onInserted }}
/>
```

### unstable_useSlashCommandAdapter

<Callout type="tip">
<strong>实验性功能。</strong> 正在积极开发中，可能会在不另行通知的情况下发生变化。
</Callout>

将斜杠命令定义（包含内联 `execute` 回调）打包为
`{adapter, action}`，可直接接入 `ComposerTriggerPopover`。
`execute` 保留在 hook 闭包中，绝不会附加到返回的
`TriggerItem` 上，从而确保项目可序列化。

```tsx
const slash = unstable_useSlashCommandAdapter({
  commands: [
    { id: "summarize", execute: () => runSummarize(), icon: "FileText" },
    { id: "translate", execute: () => runTranslate(), icon: "Languages" },
  ],
});

<ComposerTriggerPopover char="/" {...slash} />
```
