### AuiProvider

向 React 树提供一个 `AssistantClient`。

将其放置在使用 [useAui](/docs/api-reference/hooks/state#useaui) 或基于它构建的原语的任意子树根部附近。在 `AuiProvider`
之外渲染的组件会收到一个默认客户端，该客户端的作用域访问器在使用时会抛出错误，因此
缺少提供者的问题会在使用点暴露出来。

`config` 是必需的，并且必须使用 [AuiConfig](/docs/api-reference/utilities/miscellaneous#auiconfig) 构建。在顶层，
仅使用 `config` 即可创建此子树自己的客户端。在父级提供者下，`extends`
是必需的：传入 `extends={aui}` 以扩展父级客户端，或传入 `extends={null}` 以与其隔离（通过开发环境错误强制执行）。
配置不依赖对象身份——每次渲染创建新对象也是安全的。
所有作用域均为 Derived 的配置会在挂载时固定其作用域集合（开发环境强制执行）；包含根作用域的配置以及空配置
可以在多次渲染期间增减作用域。挂载后，`ref` 会收到生成的
客户端。

挂载使用运行时钩子之一构建的运行时时，请使用
[AssistantRuntimeProvider](/docs/api-reference/context-providers/assistant-runtime-provider#assistantruntimeprovider)——它会在内部安装 `AuiProvider`——
而不是自行连接 `AuiProvider`。

```tsx
function MessageScope({ index, children }) {
  const aui = useAui();
  const config = AuiConfig({
    message: Derived({
      source: "thread",
      query: { index },
      get: (aui) => aui.thread.message({ index }),
    }),
  });
  return (
    <AuiProvider extends={aui} config={config}>
      {children}
    </AuiProvider>
  );
}
```
