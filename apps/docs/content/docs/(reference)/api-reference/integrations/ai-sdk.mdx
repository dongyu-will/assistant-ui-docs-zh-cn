## API 参考

### AISDKChat

`AuiConfig` 条目，以 `threads` 作用域运行 AI SDK 聊天。它在客户端自己的资源树中托管与 `useChatRuntime` 相同的编排，因此可与任何 `AssistantClient` 宿主一起使用，无论是否为 React。单线程；多线程和 assistant-cloud 功能由 [AISDKThreads](/docs/api-reference/integrations/ai-sdk#aisdkthreads) 提供。聊天 id 会在条目挂载时捕获，因此之后对选项中的 `id` 所做的更改不会生效。

### AISDKThreads

`AuiConfig` 条目，为每个线程运行一个 AI SDK 聊天。它在客户端自己的资源树中托管与 [AISDKChat](/docs/api-reference/integrations/ai-sdk#aisdkchat) 相同的按线程编排，因此可与任何 `AssistantClient` 宿主一起使用，无论是否为 React。
如果没有 `cloud`，线程会在客户端生命周期内保存在内存中，并在切换线程时保留历史记录；只有可见线程会被挂载，而切换离开的聊天会继续将流式内容写入其存储状态，直到完成或线程被删除。如果使用 `cloud`，列表将成为带有 `RemoteThreadList` 的 `backgroundThreads`：每个访问过的线程都会保持挂载并拥有自己的历史记录，运行会在切换后继续，并在删除时停止，新创建的线程会自动为自己生成标题。每个已挂载的线程都会注册模型上下文。

### injectQuoteContext

将引用上下文以 Markdown 引用块的形式注入消息。

在 `convertToModelMessages` 之前，在路由处理程序中使用此函数，以便 LLM
能够看到用户所指的引用文本。

```ts
import { convertToModelMessages, streamText } from "ai";
import { injectQuoteContext } from "@assistant-ui/ai-sdk";

export async function POST(req: Request) {
  const { messages } = await req.json();
  const result = streamText({
    model: myModel,
    messages: await convertToModelMessages(injectQuoteContext(messages)),
  });
  return result.toUIMessageStreamResponse();
}
```

### unstable_injectInteractableContext

将可交互状态快照作为模型可见文本注入消息。

它与 [injectQuoteContext](/docs/api-reference/integrations/ai-sdk#injectquotecontext) 的行为类似：读取用户消息的 `metadata.custom.interactables` 上记录的冻结快照（由发送时的可交互对象作用域写入），并在消息前置入一个文本部分。在 `convertToModelMessages` 之前，在路由处理程序中运行此函数，否则 `metadata.custom` 会被忽略。

措辞由使用方决定——传入 `format` 以控制每个快照的描述方式。快照可能源自用户编辑或代理的 `update_*` 调用，因此默认措辞保持中性。在自定义措辞中保留实例 id 的可见性：模型需要使用它来寻址 `update_*` 工具的 `id` 参数。自定义的 `format` 还必须处理包含 `partial: true` 的条目，其中 `state` 仅携带自模型上次已知状态以来发生变化的字段。

```ts
import { convertToModelMessages, streamText } from "ai";
import { unstable_injectInteractableContext } from "@assistant-ui/ai-sdk";

export async function POST(req: Request) {
  const { messages } = await req.json();
  const result = streamText({
    model: myModel,
    messages: await convertToModelMessages(unstable_injectInteractableContext(messages)),
  });
  return result.toUIMessageStreamResponse();
}
```

### useAISDKError


### generativeTools

<Callout type="warn">
<strong>已弃用。</strong> 请改用 [AISDKToolkit](/docs/api-reference/integrations/ai-sdk#aisdktoolkit)：
`new AISDKToolkit({ toolkit }).tools({ frontend })`。它是严格的超集（还会打开 MCP 服务器连接），因此可以在所有地方替代 `generativeTools`。`frontendTools` 选项在 `.tools()` 中命名为 `frontend`，并且 `.tools()` 是异步的。`generativeTools` 将在未来版本中移除。
</Callout>

根据生成式 `toolkit` 和前端上传的工具，构建一个用于服务端、配合 `streamText` /
`generateText` 使用的 AI SDK `ToolSet`。

每个工具包工具的 `execute` 都在服务器上运行。将其与 `"use generative"` 编译器搭配使用：在服务器路由中导入工具包（此时它会解析为服务器构建版本——schema + `execute`，并移除 `render`），然后将其传入此处。没有 `execute` 的工具仍会暴露给模型，但会留给客户端完成。`frontendTools` 允许客户端提供静态工具包中不存在的工具。

```ts
// Define once at module scope so any MCP connections pool across requests.
const aiToolkit = new AISDKToolkit({ toolkit: docsToolkit });

// In your route handler:
const { tools } = await req.json();
streamText({
  model,
  messages,
  tools: await aiToolkit.tools({ frontend: tools }),
});
```
