当助手需要调用应用代码、渲染自定义工具结果，或在 React UI 中公开工具状态时，请使用这些 API。

工具包是当前的注册 API。工具的**渲染**和**状态**与工具的执行位置相互独立，适用于前端、后端、人工和 MCP 工具。

| | `Tools({ toolkit })` |
| --- | --- |
| 作用域 | 挂载点下方的整个助手子树 |
| 生命周期 | 与运行时 / 提供者树绑定 |
| 典型用途 | 应用级工具、动态作用域工具、合并 MCP、与运行时一同定义的工具 |
| 稳定引用 | 传入稳定的 `toolkit`（模块作用域或 `useMemo`） |

`useAssistantTool`、`makeAssistantTool`、`useAssistantToolUI` 和 `makeAssistantToolUI` 是已弃用的兼容 API。请参阅[将工具迁移到工具包](/docs/migrations/toolkit-tools)。
