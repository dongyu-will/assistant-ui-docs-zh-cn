## API 参考

### useToolArgsStatus

读取当前工具调用消息部分中每个参数字段是否仍在流式传输或已完成。

在工具调用渲染器中使用，以避免将不完整的参数值显示为最终值。

```tsx
function WeatherToolUI({
  args,
}: ToolCallMessagePartProps<{ city: string }>) {
  const { propStatus } = useToolArgsStatus<{ city: string }>();

  return (
    <span>
      {propStatus.city === "streaming" ? "Reading city..." : args.city}
    </span>
  );
}
```

```ts
const useToolArgsStatus: <TArgs extends Record<string, unknown> = Record<string, unknown>>() => ToolArgsStatus<TArgs>;
```

### useToolCallElapsed

返回当前工具调用已经过的墙上时钟时间（以毫秒为单位）的 Hook；工具调用运行期间每秒更新一次。

读取 `part.timing`。当消息部分不是工具调用、不包含计时信息、在未记录完成时间的情况下结束（持续时间未知），或没有可用的消息部分作用域时，返回 `undefined`（这样 kit 组件仍可独立渲染，例如在文档预览中）。

```tsx
function ToolDuration() {
  const elapsedMs = useToolCallElapsed();
  if (elapsedMs === undefined) return null;
  return <span>{(elapsedMs / 1000).toFixed(1)}s</span>;
}
```

```ts
const useToolCallElapsed: () => number | undefined;
```
