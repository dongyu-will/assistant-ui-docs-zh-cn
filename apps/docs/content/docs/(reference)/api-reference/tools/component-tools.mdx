## API 参考

### makeAssistantTool

<Callout type="warn">
<strong>已弃用。</strong>请改用包含 `Tools({ toolkit })` 的 toolkit，并通过
`useAui({ tools: Tools({ toolkit }) })` 注册。请参阅
https://assistant-ui.com/docs/migrations/toolkit-tools.
</Callout>

创建一个在渲染时注册助手工具的 React 组件。

当导出可复用的工具模块，并希望将其包含在 JSX 中，而不是直接调用
[useAssistantTool](/docs/api-reference/tools/component-tools#useassistanttool) 时，请使用此 API。

```ts
type AssistantToolProps = CoreAssistantToolProps<TArgs, TResult> & {
  /** Component used to render calls to this tool in assistant messages. */
  render?: ToolCallMessagePartComponent<TArgs, TResult> | undefined;
  /** Lightweight text rendered while a tool call is running or complete. */
  renderText?: ToolCallText<TArgs, TResult> | undefined;
};

const makeAssistantTool: <TArgs extends Record<string, unknown>, TResult>(tool: AssistantToolProps<TArgs, TResult>) => AssistantTool;
```

### useAssistantTool

<Callout type="warn">
<strong>已弃用。</strong>请改用包含 `Tools({ toolkit })` 的 toolkit，并通过
`useAui({ tools: Tools({ toolkit }) })` 注册。请参阅
https://assistant-ui.com/docs/migrations/toolkit-tools.
</Callout>

在组件挂载期间，将工具注册到助手模型上下文中。

如果提供了 `render`，它还会被安装为匹配工具调用消息部分的渲染器。
当组件卸载或工具定义发生变化时，注册会自动移除。

请传入引用稳定的工具对象，例如在模块作用域中声明的对象，或使用
`useMemo` 记忆化的对象，以避免每次渲染都重新注册。

```tsx
const weatherTool = {
  toolName: "get_weather",
  type: "frontend",
  description: "Get the weather for a city.",
  parameters: weatherSchema,
  execute: async ({ city }: { city: string }) => fetchWeather(city),
  render: WeatherToolUI,
} satisfies AssistantToolProps<{ city: string }, Weather>;

function WeatherToolRegistration() {
  useAssistantTool(weatherTool);
  return null;
}
```
