## API 参考

### GenerativeUIMessagePart

承载描述待渲染 UI 的 JSON 规范的消息部分。

使用 `<MessagePrimitive.GenerativeUI components={...} />` 进行渲染。该原语会根据使用者提供的允许列表解析组件名称——任何未知名称都会抛出类型化错误，而不会进行渲染。适用于流式传输：部分流式传输的规范也会逐步渲染。

### GenerativeUINode

描述待渲染 UI 组件树的 JSON 规范。

助手会发送包含此规范的 [GenerativeUIMessagePart](/docs/api-reference/generative-ui/spec#generativeuimessagepart)，并使用使用者提供的组件允许列表来解析 `component` 名称。任何引用但不在允许列表中的组件都会因类型化错误而被拒绝——在默认的同一 realm 渲染路径中，允许列表是安全边界。
