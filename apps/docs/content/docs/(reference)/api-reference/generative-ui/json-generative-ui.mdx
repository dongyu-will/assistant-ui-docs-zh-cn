## API 参考

### JSONGenerativeUI

[JSONGenerativeUI](/docs/api-reference/generative-ui/json-generative-ui#jsongenerativeui) 的客户端构建版本，通过包的
`default` 导出条件解析（浏览器和 SSR）。

`present` 是一个前端工具，用于根据组件库渲染模型的 `{ $type,...props }`
树，并立即解析。`prompt_user` 是一个 human-in-the-loop（人在回路）工具：模型会暂停，由渲染后的 UI
提供结果。两者以相同方式绘制该树，因此共享一个 `render`。如果提供了
`actions` 注册表，它会传入渲染上下文，使交互式组件能够通过
`$dispatch` 触发 `$action`。
