## 助手上下文

`<AssistantRuntimeProvider />` 内部组件可用的上下文。通常会用此上下文包裹整个应用。

### AssistantRuntime

通过 `useAui()` 以编程方式访问助手的状态和操作。

### 指令

添加系统提示词指令

- [`useAssistantInstructions`](/docs/api-reference/model-context/context)

### 工具 UI

注册工具包和工具 UI

- [`Toolkit`](/docs/api-reference/tools/toolkits#toolkit)
- [`Tools`](/docs/api-reference/tools/toolkits#tools)

通过 `useAuiState((s) => s.tools)` 和 `useAui().tools()` 以编程方式访问已注册工具 UI 的列表。

## 线程上下文

单个线程的上下文。目前始终对应运行时的主线程。

### ThreadRuntime

以编程方式访问线程的状态和操作。

- 状态：`useAuiState((s) => s.thread)`
- 操作：`useAui().thread()`
- 输入框：`useAuiState((s) => s.composer)`

### ModelContext

- `useAui().thread().getModelContext()`

### ThreadViewportStore

- [`useThreadViewport`](/docs/api-reference/hooks/primitives)
- [`useThreadViewportStore`](/docs/api-reference/hooks/primitives)
