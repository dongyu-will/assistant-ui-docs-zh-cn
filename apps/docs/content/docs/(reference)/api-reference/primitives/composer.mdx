#### 键盘快捷键

默认设置（`submitMode="enter"`）：

| 按键 | 描述 |
| --- | --- |
| <Kbd>Enter</Kbd> | 发送消息。 |
| <Kbd>Shift + Enter</Kbd> | 插入换行符。 |
| <Kbd>Escape</Kbd> | 发送取消操作。 |

使用 `submitMode="ctrlEnter"`时：

| 按键 | 描述 |
| --- | --- |
| <Kbd>Ctrl/Cmd + Enter</Kbd> | 发送消息。 |
| <Kbd>Enter</Kbd> | 插入换行符。 |
| <Kbd>Escape</Kbd> | 发送取消操作。 |

使用 `submitMode="none"`时：

| 按键 | 描述 |
| --- | --- |
| <Kbd>Enter</Kbd> | 插入换行符（不通过键盘提交）。 |
| <Kbd>Escape</Kbd> | 发送取消操作。 |

#### 触控优先设备

传入 `unstable_insertNewlineOnTouchEnter`，可让通过 `(pointer: coarse) and (not (any-pointer: fine))`媒体查询检测到的、没有硬件键盘的手机和平板电脑使用普通 Enter 插入换行符。之后，消息只能通过显式的 Send 按钮发送，这与 WhatsApp、Slack、Discord、iMessage、ChatGPT 和 Claude.ai 使用的聊天输入约定一致。

```tsx
<ComposerPrimitive.Input
  placeholder="Ask anything..."
  unstable_insertNewlineOnTouchEnter
/>
```

仅当 `submitMode` 解析为 `"enter"`（默认值）时生效；`"ctrlEnter"` 和 `"none"` 不受影响，因此连接了硬件键盘的平板电脑仍可通过 Cmd/Ctrl+Enter 提交。
