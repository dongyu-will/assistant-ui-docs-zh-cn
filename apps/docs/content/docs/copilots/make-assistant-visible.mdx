`makeAssistantVisible` 是一个高阶组件（HOC），可以让 React 组件对助手“可见”，使助手能够理解并与组件的 HTML 结构进行交互。

## 用法

```tsx
import { makeAssistantVisible } from "@assistant-ui/react";

const Button = ({ onClick, children }) => (
  <button onClick={onClick}>{children}</button>
);

// Basic usage - makes component HTML readable
const ReadableButton = makeAssistantVisible(Button);

// With clickable configuration
const ClickableButton = makeAssistantVisible(Button, {
  clickable: true, // Enables the click tool
});

// With editable configuration
const EditableInput = makeAssistantVisible(Input, {
  editable: true, // Enables the edit tool
});
```

## API 参考

### 参数

- `Component`：要增强的基础 React 组件
- `config`：可选配置对象
  - `clickable`：为 true 时，允许助手以编程方式点击组件
  - `editable`：为 true 时，允许助手以编程方式设置组件内输入框或文本区域的值

### 行为

该 HOC 将：

1. 通过系统上下文向助手提供组件的 HTML 结构
2. 当 `clickable` 为 true 时，可选提供一个 `click` 工具
3. 当 `editable` 为 true 时，可选提供一个 `edit` 工具，用于设置组件内 `<input>` 或 `<textarea>` 的值
4. 处理嵌套的可读取组件（只提供最外层组件的 HTML）
5. 转发 ref 并保留组件 props

## 示例

```tsx
// Create a readable form input that the assistant can also edit
const Input = ({ label, ...props }) => (
  <div>
    <label>{label}</label>
    <input {...props} />
  </div>
);

const EditableInput = makeAssistantVisible(Input, { editable: true });

// Use in your component
function Form() {
  return (
    <EditableInput label="Email" type="email" placeholder="Enter your email" />
  );
}
```

## 技术细节

当组件变为可读取时：

- 组件会被包装在 `ReadableContext.Provider` 中，以处理嵌套
- 组件的 `outerHTML` 会作为系统上下文提供
- 如果 `clickable` 为 true，则会添加唯一的 `data-click-id`，并提供一个 `click` 工具
- 点击工具使用 `querySelector` 并模拟点击事件
- 如果 `editable` 为 true，则会添加唯一的 `data-edit-id`，并提供一个 `edit` 工具
- 编辑工具使用 `querySelector` 查找 `<input>` 或 `<textarea>`，设置其值，并分发 `input` 和 `change` 事件
- 所有 props 和 ref 都会正确转发，以保持组件功能不变
