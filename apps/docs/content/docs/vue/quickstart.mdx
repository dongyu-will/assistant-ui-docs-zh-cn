title: 快速入门
description: 使用 Vue、assistant-ui 和 AI SDK 构建流式 Nuxt 聊天应用。
---

本指南将在大约五分钟内为 Nuxt 应用添加流式聊天功能。运行时保留在仅客户端组件中，模型调用保留在 Nitro 路由中。

<Steps>
  <Step>

### 安装运行时

安装 Vue 绑定、AI SDK 运行时和 AI SDK 提供商：

```sh
pnpm add @assistant-ui/vue @assistant-ui/ai-sdk ai @ai-sdk/openai react
```

`react` 是 AI SDK 运行时的基础层——它是 `@assistant-ui/ai-sdk` 的可选对等依赖，因此不会自行安装。对于 `nuxi typecheck`，将 `@types/react` 添加为开发依赖：仅用于类型的 React 引用会通过核心运行时类型传递。

```bash
pnpm add -D @types/react
```

将提供商密钥添加到 `.env`：

```sh title=".env"
OPENAI_API_KEY="sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

  </Step>
  <Step>

### 安装样式组件

在 `components.json` 中添加一次 Vue assistant-ui 注册表：

```json title="components.json"
{
  "registries": {
    "@assistant-ui": "https://r.assistant-ui.com/vue/{name}.json"
  }
}
```

安装聊天界面：

```sh
npx shadcn@latest add @assistant-ui/thread @assistant-ui/thread-list
```

这会在 `components/assistant-ui` 下写入 Vue 组件。该注册表会安装这些组件所需的 assistant-ui、Vue 和 UI 依赖。

  </Step>
  <Step>

### 创建助手客户端

使用 `.client.vue` 文件，使运行时仅在浏览器中创建：

```vue title="app/components/Assistant.client.vue"
<script setup lang="ts">
import { AuiConfig, AuiProvider } from "@assistant-ui/vue";
import { AISDKChat } from "@assistant-ui/ai-sdk";
import Thread from "~/components/assistant-ui/thread.vue";

const config = AuiConfig({
  threads: AISDKChat(),
});
</script>

<template>
  <AuiProvider :config="config">
    <Thread class="h-dvh" />
  </AuiProvider>
</template>
```

`AISDKChat()` 会创建一个流式线程。其默认传输层会将请求发送到 `/api/chat`。

  </Step>
  <Step>

### 添加流式路由

创建接收 UI 消息并返回 AI SDK UI 消息流的 Nitro 路由：

```ts title="server/api/chat.post.ts"
import { openai } from "@ai-sdk/openai";
import { convertToModelMessages, streamText, type UIMessage } from "ai";

export default defineEventHandler(async (event) => {
  const { messages, system } = await readBody<{
    messages: UIMessage[];
    system?: string;
  }>(event);

  const result = streamText({
    model: openai("gpt-5.6-luna"),
    messages: await convertToModelMessages(messages),
    system,
  });

  return result.toUIMessageStreamResponse();
});
```

  </Step>
  <Step>

### 渲染助手

Nuxt 会识别 `.client.vue` 后缀，并且只在浏览器中挂载此组件：

```vue title="app/pages/index.vue"
<template>
  <Assistant />
</template>
```

使用 `pnpm dev` 启动应用，然后发送一条消息。响应会从 `server/api/chat.post.ts` 流式传输到线程中。

  </Step>
</Steps>
