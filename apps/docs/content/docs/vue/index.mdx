`@assistant-ui/vue` 为 assistant-ui 的运行时提供 Vue 组件和组合式函数。将其与 Nuxt 搭配使用，即可构建流式聊天路由、客户端助手树，以及来自 assistant-ui registry 的样式化聊天组件。

Vue API 包括 `AuiProvider` 和 `AuiIf`、`useAui`、`useAuiState` 和 `useAuiEvent` 组合式函数，以及用于线程、消息、输入框、线程列表、附件、建议、操作、分支、错误和思维链的原语。

## 工作原理

`AuiProvider` 负责管理助手客户端。其 `AuiConfig` 将诸如 `AISDKChat()` 的运行时连接到 Vue 原语和组合式函数。AI SDK 运行时会将消息发送到 Nuxt 路由，而该路由会将 UI 消息流返回给浏览器。

为 provider 和运行时使用 `.client.vue` 边界。将模型凭据和 `streamText` 保存在 Nitro 路由中。[快速入门](/docs/vue/quickstart)包含完整流程。
