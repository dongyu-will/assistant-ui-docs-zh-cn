---
title: 运行时
description: 选择单个 AI SDK 聊天、多线程 AI SDK 聊天或自定义外部状态存储。
---

运行时（runtime）将 Vue 原语连接到消息状态和操作。将运行时放入由仅客户端 `AuiProvider` 提供的 `AuiConfig` 中。

## AISDKChat

`AISDKChat` 是最简配置。它拥有一个客户端线程，默认使用 `AssistantChatTransport` 调用 `/api/chat`。

```vue title="app/components/Assistant.client.vue"
<script setup lang="ts">
import { AuiConfig, AuiProvider } from "@assistant-ui/vue";
import { AISDKChat } from "@assistant-ui/ai-sdk";

const config = AuiConfig({
  threads: AISDKChat(),
});
</script>

<template>
  <AuiProvider :config="config">
    <slot />
  </AuiProvider>
</template>
```

当端点或传输层行为不同时，传入 `AISDKChat({ transport })`。聊天 ID 会在资源首次挂载时捕获，因此当不同的 ID 必须创建不同的聊天时，请重新挂载 Provider。

## AISDKThreads

`AISDKThreads` 会创建线程列表，并为每个线程创建一个 AI SDK 聊天。不使用云端选项时，线程及其历史记录会在助手客户端的生命周期内保存在内存中。

```ts title="app/components/Assistant.client.vue"
import { AuiConfig } from "@assistant-ui/vue";
import { AISDKThreads } from "@assistant-ui/ai-sdk";

const config = AuiConfig({
  threads: AISDKThreads(),
});
```

使用云端支持的列表时，`AISDKThreads` 会选择加入 `backgroundThreads`。每个访问过的线程都会连同自己的历史记录保持挂载，切换线程后运行仍会继续，每个线程列表项的 `isRunning` 状态也会保持活动，并且会在线程的初始化操作完成后生成新的线程标题。这种连续性所使用的内存与访问过的线程数量成正比。删除线程会停止其运行。

每个线程会在首次挂载时捕获其 AI SDK 选项。之后更改 `transport`、初始消息或其他线程级选项，不会重新配置现有聊天。当这些选项需要更改时，请创建新线程或重新挂载助手客户端。

对于内存中的列表，assistant-ui 会在切换过程中保留每个聊天及其历史记录，而当前可见的线程则是已挂载的 UI。对于服务器支持的历史记录，请配置云端支持的路径，或在外部状态存储中自行持久化。在这两种情况下，都应将此客户端状态置于 [Nuxt 客户端边界](/docs/vue/ssr)之后。

## 外部状态存储

当其他客户端状态存储负责管理消息、流式传输状态或线程状态时，请使用 `RuntimeAdapter` 和 `ExternalStoreRuntimeCore`。Vue echo 示例遵循这一模式：创建外部状态存储适配器，在状态存储发生变化时更新它，然后通过 `AuiConfig` 暴露其运行时。

这些构造函数来自 `@assistant-ui/core/internal`，这是用于构建自定义运行时的高级入口；它的迭代速度可能快于公共入口，因此在依赖它时请固定版本。

```ts title="app/runtime/echo.ts"
import type { AppendMessage, ExternalStoreAdapter } from "@assistant-ui/core";
import {
  AssistantRuntimeImpl,
  ExternalStoreRuntimeCore,
} from "@assistant-ui/core/internal";

type EchoMessage = {
  id: string;
  role: "user" | "assistant";
  text: string;
};

export const createEchoRuntime = () => {
  let messages: EchoMessage[] = [];
  let isRunning = false;
  let nextId = 0;

  const makeAdapter = (): ExternalStoreAdapter<EchoMessage> => ({
    messages,
    isRunning,
    convertMessage: (message) => ({
      id: message.id,
      role: message.role,
      content: [{ type: "text", text: message.text }],
    }),
    setMessages: (next) => {
      messages = [...next];
      sync();
    },
    onNew: async (message: AppendMessage) => {
      const text = message.content
        .map((part) => (part.type === "text" ? part.text : ""))
        .join("");
      messages = [
        ...messages,
        { id: `user-${nextId++}`, role: "user", text },
      ];
      isRunning = true;
      sync();
      messages = [
        ...messages,
        { id: `assistant-${nextId++}`, role: "assistant", text: `Echo: ${text}` },
      ];
      isRunning = false;
      sync();
    },
  });

  const core = new ExternalStoreRuntimeCore(makeAdapter());
  const sync = () => core.setAdapter(makeAdapter());
  return new AssistantRuntimeImpl(core);
};
```

使用 `RuntimeAdapter` 将运行时连接到 Vue：

```ts title="app/components/Assistant.client.vue"
import { AuiConfig } from "@assistant-ui/vue";
import { RuntimeAdapter } from "@assistant-ui/core/store";
import { createEchoRuntime } from "~/runtime/echo";

const config = AuiConfig({
  threads: RuntimeAdapter(createEchoRuntime()),
});
```

适配器负责转换和变更。当外部后端支持这些操作时，请实现 `onEdit`、`onReload`、`onCancel` 以及线程列表方法。
