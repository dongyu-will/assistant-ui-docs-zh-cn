---
title: 服务端渲染
description: 将 Vue 助手状态保存在仅客户端运行的 Nuxt 组件中，并通过 Nitro 进行流式传输。
---

将 `AuiProvider` 及其运行时放在 `.client.vue` 组件中。即使外层 Nuxt 页面采用服务端渲染，这也是必需的。

助手运行时拥有一个客户端树和响应式作用域。如果它在服务端渲染，每个请求都会创建一个 Vue SSR 永不释放的客户端树。这样每个请求都会泄漏一个助手树。`.client.vue` 边界可以防止提供者、其运行时及其作用域在服务端渲染期间被创建。

```vue title="app/components/Assistant.client.vue"
<script setup lang="ts">
import { AuiConfig, AuiProvider } from "@assistant-ui/vue";
import { AISDKChat } from "@assistant-ui/ai-sdk";
import Thread from "~/components/assistant-ui/thread.vue";

const config = AuiConfig({
  threads: AISDKChat(),
});
</script>

<template>
  <AuiProvider :config="config">
    <Thread class="h-dvh" />
  </AuiProvider>
</template>
```

## 哪些内容属于服务端

将提供者凭据、`streamText` 和流式响应保存在 Nitro 路由中。Nitro 在服务端运行 `server/api/chat.post.ts`，而浏览器只接收 UI 消息流。

```ts title="server/api/chat.post.ts"
import { openai } from "@ai-sdk/openai";
import { convertToModelMessages, streamText, type UIMessage } from "ai";

export default defineEventHandler(async (event) => {
  const { messages, system } = await readBody<{
    messages: UIMessage[];
    system?: string;
  }>(event);

  const result = streamText({
    model: openai("gpt-5.6-luna"),
    messages: await convertToModelMessages(messages),
    system,
  });

  return result.toUIMessageStreamResponse();
});
```

## Nuxt 接入

服务端渲染的页面可以正常包含客户端组件。Nuxt 会解析 `.client.vue` 后缀，并在 hydration（水合）后挂载该组件。

```vue title="app/pages/index.vue"
<template>
  <main>
    <Assistant />
  </main>
</template>
```

边界之外只保留页面数据和普通的、可由服务端渲染的 UI。不要在 `app.vue`、SSR 期间运行的页面 setup 代码块或 Nitro 路由中创建 `AuiConfig`、`AISDKChat`、`AISDKThreads` 或 `AuiProvider`。
