---
title: 适配器
description: 用于 React Ink 的附件、标题生成和存储适配器。
---

适配器用于自定义运行时行为。它们可以作为选项传递给 `useLocalRuntime` 或 `useRemoteThreadListRuntime`。

## createFileStorageAdapter

一种 `RemoteThreadListAdapter`，用于将线程和消息持久化到本地目录。有关用法，请参阅[自定义后端 → 选项 2](/docs/ink/custom-backend#option-2-local-file-persistence)。

```ts
import { createFileStorageAdapter } from "@assistant-ui/react-ink";

const adapter = createFileStorageAdapter({
  dir: "/path/to/threads",
});
```

## 附件适配器

`SimpleTextAttachmentAdapter` 和 `SimpleImageAttachmentAdapter` 在终端中的工作方式与在 Web 和 React Native 中相同。文本内容会封装在 `<attachment name=...>` 标签中发送给模型，图像则以 base64 数据 URL 的形式发送。

```ts
import {
  CompositeAttachmentAdapter,
  SimpleImageAttachmentAdapter,
  SimpleTextAttachmentAdapter,
  useLocalRuntime,
} from "@assistant-ui/react-ink";

const runtime = useLocalRuntime(chatModelAdapter, {
  adapters: {
    attachments: new CompositeAttachmentAdapter([
      new SimpleTextAttachmentAdapter(),
      new SimpleImageAttachmentAdapter(),
    ]),
  },
});
```

## TitleGenerationAdapter

根据线程消息生成线程标题。将其作为 `titleGenerator` 选项传递给 `createFileStorageAdapter`，或从自定义的 `RemoteThreadListAdapter` 中调用它。

```ts
type TitleGenerationAdapter = {
  generateTitle(messages: readonly ThreadMessage[]): Promise<string>;
};
```

`createSimpleTitleAdapter` 是内置实现；它根据第一条用户消息生成标题，并将标题截断为 50 个字符。

```ts
import {
  createFileStorageAdapter,
  createSimpleTitleAdapter,
} from "@assistant-ui/react-ink";

const adapter = createFileStorageAdapter({
  dir: "/path/to/threads",
  titleGenerator: createSimpleTitleAdapter(),
});
```

## RemoteThreadListAdapter

通过 `RemoteThreadListAdapter` 上的 `generateTitle` 方法配置标题生成。有关完整示例，请参阅[自定义后端](/docs/ink/custom-backend)页面。

```tsx
import type { RemoteThreadListAdapter } from "@assistant-ui/react-ink";
import { createAssistantStream } from "assistant-stream";

const myAdapter: RemoteThreadListAdapter = {
  // ... other methods ...

  async generateTitle(remoteId, unstable_messages) {
    return createAssistantStream(async (controller) => {
      const res = await fetch(`/api/threads/${remoteId}/title`, {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({ messages: unstable_messages }),
      });
      const { title } = await res.json();
      controller.appendText(title);
    });
  },
};
```

## 应该选择哪个选项？

| | ChatModelAdapter + `useLocalRuntime` | RemoteThreadListAdapter + `useRemoteThreadListRuntime` |
|---|---|---|
| **线程存储** | 内存中 | 您的后端 |
| **消息存储** | 内存中 | 内存中（可以添加历史记录适配器，以支持服务端存储） |
| **跨会话持久化** | 否 | 是 |
| **设置复杂度** | 最低 | 中等 |
| **适用场景** | CLI 工具、演示、原型 | 需要持久化的生产应用 |
