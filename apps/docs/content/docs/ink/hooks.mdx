## 状态 Hook

### useAuiState

用于访问响应式状态的主要 Hook。它接受一个选择器函数，以实现细粒度重新渲染——只有在选定值发生变化时（浅比较），组件才会重新渲染。

```tsx
import { useAuiState } from "@assistant-ui/react-ink";

// Thread state
const messages = useAuiState((s) => s.thread.messages);
const isRunning = useAuiState((s) => s.thread.isRunning);
const isEmpty = useAuiState((s) => s.thread.isEmpty);

// Composer state
const text = useAuiState((s) => s.composer.text);
const composerIsEmpty = useAuiState((s) => s.composer.isEmpty);
const attachments = useAuiState((s) => s.composer.attachments);

// Message state (inside a message context)
const role = useAuiState((s) => s.message.role);
const isLast = useAuiState((s) => s.message.isLast);

// Thread list item state
const threadId = useAuiState((s) => s.threadListItem.id);
const title = useAuiState((s) => s.threadListItem.title);
```

### useAui

访问 store 方法以执行命令式操作。

```tsx
import { useAui } from "@assistant-ui/react-ink";

const aui = useAui();

// Composer actions
aui.composer.setText("Hello");
aui.composer.send();

// Thread actions
aui.thread.cancelRun();
```

### useAuiEvent

订阅事件，且不会触发重新渲染。

```tsx
import { useAuiEvent } from "@assistant-ui/react-ink";

useAuiEvent("thread.runStart", (payload) => {
  console.log("Run started:", payload);
});
```

### useNotification

当助手完成一次运行、因错误停止，或暂停等待用户输入时，响起终端铃声并发送 OSC 桌面通知。

```tsx
import { useNotification } from "@assistant-ui/react-ink";

useNotification();
```

默认值：

- `task-complete`：铃声 + OSC 9
- `task-incomplete`：铃声
- `needs-input`（`requires-action` 中的助手消息具有 `reason: "interrupt"`）：铃声

传入 `false` 可抑制一次触发，或传入 `NotificationHandler` 进行覆盖：

```tsx
useNotification({
  onTaskComplete: { osc: "osc99" },
  onTaskIncomplete: false,
  onNeedsInput: {
    custom: (event) => myLogger.log(event),
  },
});
```

| 选项 | 类型 | 描述 |
|--------|------|-------------|
| `enabled` | `boolean` | 总开关。默认为 `true`。 |
| `onTaskComplete` | `NotificationHandler<"task-complete"> \| false` | 在观测到一次运行后，最新助手消息的状态变为 `complete` 时触发。 |
| `onTaskIncomplete` | `NotificationHandler<"task-incomplete"> \| false` | 在观测到一次运行后，最新助手消息的状态变为 `incomplete` 时触发。 |
| `onNeedsInput` | `NotificationHandler<"needs-input"> \| false` | 当最新助手消息在具有 `reason: "interrupt"` 的情况下进入 `requires-action` 时触发。工具调用暂停会被跳过。 |

`NotificationHandler<T>` 字段（均为可选，可任意组合）：

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `bell` | `boolean` | 响起终端铃声（`\x07`）。 |
| `osc` | `boolean \| "osc9" \| "osc99" \| "osc777"` | 发送 OSC 通知。`true` 等同于 `"osc9"`。 |
| `custom` | `(event: Extract<NotificationEvent, { type: T }>) => void` | 用户回调，其接收的事件负载类型会收窄为此处理器的类型。 |

通知会根据 `thread:message:status:reason` 元组进行去重，因此传入内联配置对象不会导致重复触发。`ringBell` 和 `sendOSCNotification(title, body?, variant?)` 也会导出，供命令式使用。OSC 支持取决于终端模拟器。

## 运行时 Hook

### useLocalRuntime

使用 `ChatModelAdapter` 创建一个 `AssistantRuntime`。

```tsx
import { useLocalRuntime } from "@assistant-ui/react-ink";

const runtime = useLocalRuntime(chatModel, {
  initialMessages: [],
});
```

| 选项 | 类型 | 描述 |
|--------|------|-------------|
| `initialMessages` | `ThreadMessageLike[]` | 用于预填充线程的消息 |
| `maxSteps` | `number` | 停止前允许的最大智能体步骤数 |
| `adapters.history` | `ThreadHistoryAdapter` | 用于持久化线程历史记录的适配器 |
| `adapters.attachments` | `AttachmentAdapter` | 用于处理文件附件的适配器 |
| `adapters.speech` | `SpeechSynthesisAdapter` | 用于文本转语音输出的适配器 |
| `adapters.dictation` | `DictationAdapter` | 用于语音转文本输入的适配器 |
| `adapters.feedback` | `FeedbackAdapter` | 用于消息反馈（赞/踩）的适配器 |
| `adapters.suggestion` | `SuggestionAdapter` | 用于建议提示词的适配器 |
| `cloud` | `AssistantCloud` | 通过 `assistant-cloud` 持久化线程的云实例 |
| `unstable_humanToolNames` | `string[]` | 会暂停运行、直到通过 `addResult` 添加结果的工具名称 |

### useRemoteThreadListRuntime

创建一个由 `RemoteThreadListAdapter` 支持的 `AssistantRuntime`，用于多线程持久化。系统会为每个线程调用 `runtimeHook`，以生成该线程的运行时（通常为 `useLocalRuntime`）。

```tsx
import { useRemoteThreadListRuntime, useLocalRuntime } from "@assistant-ui/react-ink";

const runtime = useRemoteThreadListRuntime({
  adapter: myRemoteAdapter,
  runtimeHook: () => useLocalRuntime(chatModel),
});
```

| 选项 | 类型 | 描述 |
|--------|------|-------------|
| `runtimeHook` | `() => AssistantRuntime` | 用于生成线程级运行时的 Hook |
| `adapter` | `RemoteThreadListAdapter` | 实现线程列表持久化的适配器 |
| `allowNesting` | `boolean` | 为 true 时，如果嵌套在另一个 `RemoteThreadListRuntime` 中，则不执行任何操作 |

## 模型上下文 Hook

### 工具

使用 `defineToolkit` 编写工具，其 API 与 Web 端相同（[定义工具](/docs/tools/defining-tools)）。工具定义会转发给模型；当模型调用工具时，`execute` 函数会运行，`render` 组件会显示结果。

<Callout type="info">
  Ink 应用运行在单个 Node 进程中，因此不存在需要拆分的客户端/服务器边界，也不需要构建步骤。`defineToolkit` 来自
  `@assistant-ui/react-ink` 的代码会在运行时执行：将其作为值导入，无需
  `"use generative"` 指令，也无需在 `execute` 内使用 `"use client"`。
</Callout>

```tsx title="weather-toolkit.tsx"
import { defineToolkit } from "@assistant-ui/react-ink";
import { Text } from "ink";
import { z } from "zod";

export default defineToolkit({
  get_weather: {
    description: "Get the current weather for a city",
    parameters: z.object({ city: z.string() }),
    execute: async ({ city }) => {
      const res = await fetch(`https://api.weather.example/${city}`);
      return res.json();
    },
    render: ({ args, result }) => (
      <Text>
        {args.city}: {result?.temperature}°F
      </Text>
    ),
  },
});
```

```tsx title="ToolProvider.tsx"
import { AuiConfig, AuiProvider, Tools, useAui } from "@assistant-ui/react-ink";
import toolkit from "./weather-toolkit";

function ToolProvider({ children }: { children: React.ReactNode }) {
  const aui = useAui();
  const config = AuiConfig({ tools: Tools({ toolkit }) });
  return (
    <AuiProvider extends={aui} config={config}>
      {children}
    </AuiProvider>
  );
}
```

### useAssistantInstructions

在模型上下文中注册系统指令。

```tsx
import { useAssistantInstructions } from "@assistant-ui/react-ink";

useAssistantInstructions("You are a helpful terminal assistant.");
```

### useAssistantDataUI

为命名的数据部分类型注册 UI 渲染器。当消息包含具有给定 `name` 的数据部分时，会使用 `render` 组件。

```tsx
import { useAssistantDataUI } from "@assistant-ui/react-ink";
import { Text } from "ink";

useAssistantDataUI({
  name: "weather_card",
  render: ({ data }) => (
    <Text>{data.city}: {data.temperature}°F</Text>
  ),
});
```
### 动态工具渲染器

当渲染器闭包捕获会变化的 props 时，使用带有 `useInlineRender` 的工具包。

### makeAssistantDataUI

创建一个组件，在挂载时注册数据 UI 渲染器。

```tsx
import { makeAssistantDataUI } from "@assistant-ui/react-ink";
import { Text } from "ink";

const WeatherCardUI = makeAssistantDataUI({
  name: "weather_card",
  render: ({ data }) => (
    <Text>{data.city}: {data.temperature}°F</Text>
  ),
});

// Mount inside AssistantRuntimeProvider to register
<WeatherCardUI />
```

### useInlineRender

包装一个渲染函数组件，使其始终使用最新版本，同时不重新创建稳定引用。当以内联方式传递 render prop，且该函数闭包捕获会变化的状态时，此 Hook 很有用。

```tsx title="weather-toolkit.tsx"
import { defineToolkit, useInlineRender } from "@assistant-ui/react-ink";
import { Text } from "ink";
import { useMemo } from "react";

export function useWeatherToolkit() {
  const render = useInlineRender(({ args, result }) => (
    <Text>{args.city}: {result?.temperature}°F</Text>
  ));

  return useMemo(
    () =>
      defineToolkit({
        get_weather: {
          type: "backend",
          render,
        },
      }),
    [render],
  );
}
```

导入工具包 Hook，并在 `const aui = useAui()` 和 `const config = AuiConfig({ tools: Tools({ toolkit }) })` 的位置使用 `<AuiProvider extends={aui} config={config}>` 挂载它，如上方[工具](#tools)部分所示。

## 运行时 Provider

### AssistantRuntimeProvider

将 `AssistantRuntime` 连接到 React 树。所有原语和 Hook 都必须在此 Provider 内部使用。

```tsx
import { AssistantRuntimeProvider, useLocalRuntime } from "@assistant-ui/react-ink";

const runtime = useLocalRuntime(chatModel);

<AssistantRuntimeProvider runtime={runtime}>
  {/* app content */}
</AssistantRuntimeProvider>
```

| Prop | 类型 | 描述 |
|------|------|-------------|
| `runtime` | `AssistantRuntime` | 要提供的运行时实例 |

## 上下文 Provider

这些底层 Provider 用于设置作用域上下文，以便在标准 `ThreadPrimitive.Messages` / `MessagePrimitive.Parts` 层级之外渲染原语。

### MessageByIndexProvider

为线程中指定消息索引设置消息上下文。由 `ThreadPrimitive.Messages` 在内部使用。

```tsx
import { MessageByIndexProvider } from "@assistant-ui/react-ink";

<MessageByIndexProvider index={0}>
  <MessagePrimitive.Root>...</MessagePrimitive.Root>
</MessageByIndexProvider>
```

| Prop | 类型 | 描述 |
|------|------|-------------|
| `index` | `number` | 消息在线程中的从零开始索引 |

### PartByIndexProvider

为当前消息中指定的部分索引设置部分上下文。由 `MessagePrimitive.Parts` 在内部使用。

```tsx
import { PartByIndexProvider } from "@assistant-ui/react-ink";

<PartByIndexProvider index={0}>
  {/* part content */}
</PartByIndexProvider>
```

| Prop | 类型 | 描述 |
|------|------|-------------|
| `index` | `number` | 部分在消息中的从零开始索引 |

### TextMessagePartProvider

提供带有固定文本值的合成文本部分上下文。适合在真实消息部分之外渲染文本内容（例如在预览或测试中）。

```tsx
import { TextMessagePartProvider } from "@assistant-ui/react-ink";

<TextMessagePartProvider text="Hello world" isRunning={false}>
  {/* content rendered with a text part context */}
</TextMessagePartProvider>
```

| Prop | 类型 | 描述 |
|------|------|-------------|
| `text` | `string` | 合成部分的文本内容 |
| `isRunning` | `boolean` | 部分是否应显示为运行中（默认：`false`） |

### ChainOfThoughtByIndicesProvider

根据起始索引和结束索引，为跨越一定消息部分范围的思维链设置上下文。用于将连续的推理部分分组。


```tsx
import { ChainOfThoughtByIndicesProvider } from "@assistant-ui/react-ink";

<ChainOfThoughtByIndicesProvider startIndex={1} endIndex={3}>
  <ChainOfThoughtPrimitive.Root>...</ChainOfThoughtPrimitive.Root>
</ChainOfThoughtByIndicesProvider>
```

| Prop | 类型 | 描述 |
|------|------|-------------|
| `startIndex` | `number` | 思维链范围中第一个部分的索引 |
| `endIndex` | `number` | 思维链范围中最后一个部分的索引 |

### ChainOfThoughtPartByIndexProvider

根据索引，为当前思维链中的指定部分设置部分上下文。

```tsx
import { ChainOfThoughtPartByIndexProvider } from "@assistant-ui/react-ink";

<ChainOfThoughtPartByIndexProvider index={0}>
  {/* chain-of-thought part content */}
</ChainOfThoughtPartByIndexProvider>
```

| Prop | 类型 | 描述 |
|------|------|-------------|
| `index` | `number` | 部分在思维链中的从零开始索引 |

### SuggestionByIndexProvider

为指定建议索引设置建议上下文。由 `ThreadPrimitive.Suggestions` 在内部使用。

```tsx
import { SuggestionByIndexProvider } from "@assistant-ui/react-ink";

<SuggestionByIndexProvider index={0}>
  <SuggestionPrimitive.Title />
</SuggestionByIndexProvider>
```

| Prop | 类型 | 描述 |
|------|------|-------------|
| `index` | `number` | 建议的从零开始索引 |

### ThreadListItemByIndexProvider

为指定索引设置线程列表项上下文，并区分常规线程和已归档线程。

```tsx
import { ThreadListItemByIndexProvider } from "@assistant-ui/react-ink";

<ThreadListItemByIndexProvider index={0} archived={false}>
  <ThreadListItemPrimitive.Root>...</ThreadListItemPrimitive.Root>
</ThreadListItemByIndexProvider>
```

| Prop | 类型 | 描述 |
|------|------|-------------|
| `index` | `number` | 在线程列表中的从零开始索引 |
| `archived` | `boolean` | 是否索引已归档线程列表 |

### ThreadListItemRuntimeProvider

直接根据 `ThreadListItemRuntime` 实例设置线程列表项上下文。

```tsx
import { ThreadListItemRuntimeProvider } from "@assistant-ui/react-ink";

<ThreadListItemRuntimeProvider runtime={threadListItemRuntime}>
  <ThreadListItemPrimitive.Root>...</ThreadListItemPrimitive.Root>
</ThreadListItemRuntimeProvider>
```

| Prop | 类型 | 描述 |
|------|------|-------------|
| `runtime` | `ThreadListItemRuntime` | 线程列表项运行时实例 |

### MessageAttachmentByIndexProvider

根据索引为指定消息附件设置附件上下文。

```tsx
import { MessageAttachmentByIndexProvider } from "@assistant-ui/react-ink";
```

### ComposerAttachmentByIndexProvider

根据索引为指定输入框附件设置附件上下文。

```tsx
import { ComposerAttachmentByIndexProvider } from "@assistant-ui/react-ink";

```

| Prop | 类型 | 描述 |
|------|------|-------------|
| `index` | `number` | 附件在输入框中的从零开始索引 |
