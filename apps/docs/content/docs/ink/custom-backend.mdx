description: 将终端应用连接到你自己的后端 API。

默认情况下，`useLocalRuntime`会在内存中管理线程和消息。根据你的需求，你可以通过两种方式连接到自己的后端。

## 选项 1：仅使用 ChatModelAdapter

最简单的方式——在线程管理保持本地化的同时，将消息发送到你的后端进行推理。

```tsx title="adapters/my-chat-adapter.ts"
import type { ChatModelAdapter } from "@assistant-ui/react-ink";

export const myChatAdapter: ChatModelAdapter = {
  async *run({ messages, abortSignal }) {
    const response = await fetch("https://my-api.com/chat", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ messages }),
      signal: abortSignal,
    });

    const reader = response.body?.getReader();
    if (!reader) throw new Error("No response body");

    const decoder = new TextDecoder();
    let fullText = "";

    while (true) {
      const { done, value } = await reader.read();
      if (done) break;

      const chunk = decoder.decode(value, { stream: true });
      fullText += chunk;
      yield { content: [{ type: "text", text: fullText }] };
    }
  },
};
```

```tsx title="app.tsx"
import { useLocalRuntime, AssistantRuntimeProvider } from "@assistant-ui/react-ink";
import { myChatAdapter } from "./adapters/my-chat-adapter.js";

export function App() {
  const runtime = useLocalRuntime(myChatAdapter);
  return (
    <AssistantRuntimeProvider runtime={runtime}>
      {/* your chat UI */}
    </AssistantRuntimeProvider>
  );
}
```

你将获得：

- 来自 API 的流式聊天响应
- 内存中的线程列表（进程退出后丢失）
- 多线程支持

## 选项 2：本地文件持久化

如果你希望线程和消息能够跨会话保留，同时又不运行后端，可以使用 `createFileStorageAdapter`。它会将每个线程写入磁盘上的 JSON 文件，并接入 `useRemoteThreadListRuntime`。

```tsx title="app.tsx"
import { join } from "node:path";
import { homedir } from "node:os";
import {
  useLocalRuntime,
  useRemoteThreadListRuntime,
  createFileStorageAdapter,
  AssistantRuntimeProvider,
} from "@assistant-ui/react-ink";
import { myChatAdapter } from "./adapters/my-chat-adapter.js";

const threadListAdapter = createFileStorageAdapter({
  dir: join(homedir(), ".my-cli", "threads"),
});

function useAppRuntime() {
  return useRemoteThreadListRuntime({
    runtimeHook: () => useLocalRuntime(myChatAdapter),
    adapter: threadListAdapter,
  });
}

export function App() {
  const runtime = useAppRuntime();
  return (
    <AssistantRuntimeProvider runtime={runtime}>
      {/* your chat UI */}
    </AssistantRuntimeProvider>
  );
}
```

写入操作是原子的（临时文件 + `rename`），因此即使在写入过程中发生崩溃，也不会留下不完整的 JSON 文件。目录会在首次写入时按需创建。

### 选项

| 选项 | 描述 |
|---|---|
| `dir` | 存储线程文件的目录。如果目录不存在则创建。 |
| `prefix` | 已存储文件的键前缀。默认为 `@assistant-ui:`。当两个应用共享同一目录时很有用。 |
| `titleGenerator` | 可选的 [`TitleGenerationAdapter`](/docs/ink/adapters#titlegenerationadapter)，根据首条消息自动生成线程标题。传入 `createSimpleTitleAdapter()` 可使用内置实现。 |

### 适用场景

适用于单进程终端应用，即同一用户一次只运行一个 CLI。线程列表中封装的读取-修改-写入操作不具备锁安全性，因此，指向同一目录的两个 CLI 进程可能会丢失线程元数据更新（重命名、归档）。如果你的场景属于这种情况，请改用选项 3。

## 选项 3：由后端完整管理线程

如果你希望后端负责线程状态（例如实现跨会话持久化、团队共享或服务端历史记录），请实现一个 `RemoteThreadListAdapter`。

### 实现适配器

```tsx title="adapters/my-thread-list-adapter.ts"
import type { RemoteThreadListAdapter } from "@assistant-ui/react-ink";
import { createAssistantStream } from "assistant-stream";

const API_BASE = "https://my-api.com";

export const myThreadListAdapter: RemoteThreadListAdapter = {
  async list() {
    const res = await fetch(`${API_BASE}/threads`);
    const threads = await res.json();
    return {
      threads: threads.map((t: any) => ({
        remoteId: t.id,
        status: t.archived ? "archived" : "regular",
        title: t.title,
      })),
    };
  },

  async initialize(localId) {
    const res = await fetch(`${API_BASE}/threads`, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ localId }),
    });
    const { id } = await res.json();
    return { remoteId: id, externalId: undefined };
  },

  async rename(remoteId, title) {
    await fetch(`${API_BASE}/threads/${remoteId}`, {
      method: "PATCH",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ title }),
    });
  },

  async archive(remoteId) {
    await fetch(`${API_BASE}/threads/${remoteId}/archive`, {
      method: "POST",
    });
  },

  async unarchive(remoteId) {
    await fetch(`${API_BASE}/threads/${remoteId}/unarchive`, {
      method: "POST",
    });
  },

  async delete(remoteId) {
    await fetch(`${API_BASE}/threads/${remoteId}`, { method: "DELETE" });
  },

  async fetch(remoteId) {
    const res = await fetch(`${API_BASE}/threads/${remoteId}`);
    const t = await res.json();
    return {
      remoteId: t.id,
      status: t.archived ? "archived" : "regular",
      title: t.title,
    };
  },

  async generateTitle(remoteId, unstable_messages) {
    return createAssistantStream(async (controller) => {
      const res = await fetch(`${API_BASE}/threads/${remoteId}/title`, {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({ messages: unstable_messages }),
      });
      const { title } = await res.json();
      controller.appendText(title);
    });
  },
};
```

## 适配器方法

| 方法 | 描述 |
|--------|-------------|
| `list()` | 挂载时返回所有线程 |
| `initialize(localId)` | 在服务端创建线程，并返回 `{ remoteId }` |
| `rename(remoteId, title)` | 持久化标题更改 |
| `archive(remoteId)` | 将线程标记为已归档 |
| `unarchive(remoteId)` | 恢复已归档的线程 |
| `delete(remoteId)` | 永久删除线程 |
| `fetch(remoteId)` | 获取单个线程的元数据 |
| `generateTitle(remoteId, unstable_messages)` | 返回包含生成标题的 `AssistantStream` |

## 应该选择哪个选项？

| | 选项 1：ChatModelAdapter | 选项 2：createFileStorageAdapter | 选项 3：RemoteThreadListAdapter |
|---|---|---|---|
| **线程存储** | 内存（进程生命周期内） | 本地磁盘 | 你的后端 |
| **消息存储** | 内存 | 本地磁盘 | 内存（可以添加历史适配器以支持服务端存储） |
| **跨会话持久化** | 否 | 是 | 是 |
| **多进程安全** | 不适用 | 否 | 取决于后端 |
| **设置复杂度** | 最低 | 最低 | 中等 |
| **最适合** | 演示、原型 | 本地 CLI 工具 | 需要同步或团队共享的生产应用 |
