### 上下文文件

将 assistant-ui 上下文添加到项目的 `CLAUDE.md` 或 `.cursorrules`：

```md
## assistant-ui

This project uses assistant-ui for chat interfaces.

Documentation: https://www.assistant-ui.com/llms-full.txt

Key patterns:
- Use AssistantRuntimeProvider at the app root
- Thread component for full chat interface
- AssistantModal for floating chat widget
- useChatRuntime hook with AI SDK transport
```

## Skills

为 AI 工具安装 assistant-ui skills：

```sh
npx skills add assistant-ui/skills
```

| Skill | 用途 |
|-------|---------|
| `/assistant-ui` | 通用架构和概览指南 |
| `/setup` | 项目设置和配置（AI SDK、LangGraph、自定义后端） |
| `/primitives` | UI 组件原语（Thread、Composer、Message 等） |
| `/runtime` | 运行时系统和状态管理 |
| `/tools` | 工具注册和工具 UI |
| `/streaming` | 使用 assistant-stream 的流式传输协议 |
| `/cloud` | 云端持久化和授权 |
| `/thread-list` | 多线程管理 |
| `/update` | 将 assistant-ui 和 AI SDK 更新到最新版本 |

在 Claude Code 中输入命令即可使用，例如，主指南使用 `/assistant-ui`，设置项目时使用 `/setup`。

## MCP

assistant-ui 在 `https://www.assistant-ui.com/mcp` 提供 MCP 服务器（Streamable HTTP）。该服务器提供实时文档、示例、设计组件和 Tap 文档，并开放托管的应用模板。无需安装，且始终保持最新。

连接后，你的 AI 助手将理解 assistant-ui 的全部内容。直接自然地提问即可：

- “为我的应用添加支持流式传输的聊天界面”
- “如何将 assistant-ui 与 Vercel AI SDK 集成？”
- “我的 Thread 组件没有更新，可能是什么问题？”

### 快速安装

对于 Claude Code：

```bash
claude mcp add --transport http assistant-ui https://www.assistant-ui.com/mcp
```

对于其他 IDE，assistant-ui CLI 会为你配置正确的客户端：

```bash
npx assistant-ui@latest mcp
```

### 可用工具

| 工具 | 描述 |
|------|-------------|
| `list_pages` | 列出文档页面，可选择按路径前缀过滤，例如 `/docs/tools` 或 `/examples` |
| `get_navigation` | 返回文档导航树 |
| `search_docs` | 搜索文档、示例、设计组件和 Tap 文档 |
| `read_page` | 按 slug、路径或 URL 以 Markdown 格式读取单个页面 |
| `list_templates` | 列出托管的应用模板和固定演示 |
| `read_template` | 获取模板完整的创作界面：配置 schema、规则和配置示例 |
| `preview_template` | 创建配置好的预览会话，并返回预览和下载 URL |

服务器还会将每个页面作为 MCP 资源（`assistant-ui://{path}`）以及用于模板驱动应用构建的 `assistant-ui-template-workflow` prompt 暴露出来。

### 本地 stdio 服务器

`@assistant-ui/mcp-docs-server` 仍会继续发布，供只能启动本地 stdio 服务器的客户端使用。它是托管端点的轻量代理，因此提供相同的实时内容：

```bash
npx add-mcp @assistant-ui/mcp-docs-server
```

### 故障排除

- **连接失败**：托管服务器需要网络访问。请检查 URL 是否准确为 `https://www.assistant-ui.com/mcp`，并确认你的客户端支持 Streamable HTTP。
- **stdio 服务器无法启动**：请确保已安装并正常运行 `npx`，然后重启 MCP 服务器和 IDE。
