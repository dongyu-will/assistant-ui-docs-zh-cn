使用 `assistant-ui` CLI 快速设置新项目，并向现有项目添加组件。

## init

使用 `init` 命令为新项目初始化配置和依赖项。

`init` 命令会安装依赖项、添加组件，并为 assistant-ui 配置项目。

```bash
npx assistant-ui@latest init
```

此命令将：
- 检测你是否已有包含 `package.json` 的项目
- 使用 `shadcn add` 安装 assistant-ui 快速启动组件
- 将默认的 assistant-ui 组件（thread、composer 等）添加到项目中
- 配置 TypeScript 路径和导入

**适用场景：**
- 将 assistant-ui 添加到**现有的** Next.js 项目
- 在包含 `package.json` 的项目中进行首次设置

**选项**

```bash
Usage: assistant-ui init [options]

initialize assistant-ui in a new or existing project

Options:
  -c, --cwd <cwd>  the working directory. defaults to the current directory.
  -h, --help       display help for command
```

## create

使用 `create` 命令搭建一个预配置 assistant-ui 的新 Next.js 项目。

```bash
npx assistant-ui@latest create [project-directory]
```

此命令会基于 assistant-ui starter 模板或示例搭建项目。

**可用模板**

| 模板 | 描述 | 命令 |
|----------|-------------|---------|
| `default` | 包含 Vercel AI SDK 的默认模板 | `npx assistant-ui create` |
| `minimal` | 精简的起始项目 | `npx assistant-ui create -t minimal` |
| `cloud` | 云端持久化 starter | `npx assistant-ui create -t cloud` |
| `cloud-clerk` | 带 Clerk 身份验证的云端 starter | `npx assistant-ui create -t cloud-clerk` |
| `langchain` | 使用 react-langchain adapter 的 LangGraph starter | `npx assistant-ui create -t langchain` |
| `mcp` | MCP 工具 + MCP Apps 渲染器 starter | `npx assistant-ui create -t mcp` |
| `eve` | Eve agent + Next.js starter | `npx assistant-ui create -t eve` |

**可用示例**

使用 `--example` 从 monorepo 示例中创建项目，这些示例包含完整的功能演示：

| 示例 | 描述 | 命令 |
|---------|-------------|---------|
| `with-ai-sdk-v7` | Vercel AI SDK v7 集成 | `npx assistant-ui create my-app -e with-ai-sdk-v7` |
| `with-eve` | Eve agent 集成 | `npx assistant-ui create my-app -e with-eve` |
| `with-artifacts` | 支持实时预览的 HTML artifact 渲染 | `npx assistant-ui create my-app -e with-artifacts` |
| `with-langgraph` | 使用自定义工具的 LangGraph agent | `npx assistant-ui create my-app -e with-langgraph` |

| `with-cloud` | Assistant Cloud 持久化 | `npx assistant-ui create my-app -e with-cloud` |
| `with-ag-ui` | [AG-UI protocol](/docs/runtimes/ag-ui/overview) 集成 | `npx assistant-ui create my-app -e with-ag-ui` |
| `with-assistant-transport` | 通过 Assistant Transport 使用自定义后端 | `npx assistant-ui create my-app -e with-assistant-transport` |
| `with-resumable-stream` | 可恢复的 LLM 流，即使在响应过程中重新加载页面也能继续 | `npx assistant-ui create my-app -e with-resumable-stream` |
| `with-chain-of-thought` | 思维链推理、工具调用和来源引用 | `npx assistant-ui create my-app -e with-chain-of-thought` |

| `with-interactables` | AI 驱动的交互式 UI 组件 | `npx assistant-ui create my-app -e with-interactables` |
| `with-openui` | [OpenUI](/docs/tools/openui) 生成式 UI 集成 | `npx assistant-ui create my-app -e with-openui` |

| `with-react-hook-form` | React Hook Form 集成 | `npx assistant-ui create my-app -e with-react-hook-form` |
| `with-ffmpeg` | FFmpeg 视频处理工具 | `npx assistant-ui create my-app -e with-ffmpeg` |
| `with-elevenlabs-conversational` | 使用 ElevenLabs 的实时语音 | `npx assistant-ui create my-app -e with-elevenlabs-conversational` |

| `with-elevenlabs-scribe` | ElevenLabs 语音转录 | `npx assistant-ui create my-app -e with-elevenlabs-scribe` |
| `with-expo` | Expo / React Native | `npx assistant-ui create my-app -e with-expo` |
| `with-react-ink` | 终端 UI 聊天 | `npx assistant-ui create my-app -e with-react-ink` |

| `with-tanstack` | TanStack Start 集成 | `npx assistant-ui create my-app -e with-tanstack` |

**示例**

```bash
# Create with default template
npx assistant-ui@latest create my-app

# Create with cloud template
npx assistant-ui@latest create my-app -t cloud

# Create with cloud + clerk template
npx assistant-ui@latest create my-app -t cloud-clerk

# Create from an example
npx assistant-ui@latest create my-app --example with-langgraph

# Create with specific package manager
npx assistant-ui@latest create my-app --use-pnpm

# Skip package installation
npx assistant-ui@latest create my-app --skip-install
```

**选项**

```bash
Usage: assistant-ui create [project-directory] [options]

create a new project

Arguments:
  project-directory         name of the project directory

Options:
  -t, --template <template>      template to use (default, minimal, cloud, cloud-clerk, langchain, mcp, eve)
  -e, --example <example>        create from an example (e.g., with-langgraph)
  -p, --preset <name-or-url>     preset name or URL (e.g., chatgpt)
  --native                       create an Expo / React Native project
  --ink                          create a React Ink terminal project
  --use-npm                      explicitly use npm
  --use-pnpm                     explicitly use pnpm
  --use-yarn                     explicitly use yarn
  --use-bun                      explicitly use bun
  --skip-install                 skip installing packages
  -h, --help                     display help for command
```

## add

使用 `add` 命令向项目中添加单个组件。

```bash
npx assistant-ui@latest add [component]
```

`add` 命令会从 assistant-ui registry 获取组件并将其添加到项目中。它会自动：
- 安装所需的依赖项
- 添加 TypeScript 类型
- 配置导入

**常用组件**

```bash
# Add the basic thread component
npx assistant-ui add thread

# Add thread list for multi-conversation support
npx assistant-ui add thread-list

# Add assistant modal
npx assistant-ui add assistant-modal

# Add multiple components at once
npx assistant-ui add thread thread-list assistant-sidebar
```

**选项**

```bash
Usage: assistant-ui add [options] <components...>

add a component to your project

Arguments:
  components             the components to add

Options:
  -y, --yes              skip confirmation prompt. (default: true)
  -o, --overwrite        overwrite existing files. (default: false)
  -c, --cwd <cwd>        the working directory. defaults to the current directory.
  -p, --path <path>      the path to add the component to.
  -h, --help             display help for command
```

## update

使用 `update` 命令将所有 `@assistant-ui/*` packages 更新到最新版本。

```bash
npx assistant-ui@latest update
```

此命令将：
- 扫描你的 `package.json`，查找 assistant-ui packages
- 使用你的包管理器将它们更新到最新版本
- 保留其他依赖项

**示例**

```bash
# Update all assistant-ui packages
npx assistant-ui update

# Dry run to see what would be updated
npx assistant-ui update --dry
```

**选项**

```bash
Usage: assistant-ui update [options]

update all '@assistant-ui/*' packages to latest versions

Options:
  --dry          print the command instead of running it
  -c, --cwd <cwd>  the working directory. defaults to the current directory.
  -h, --help       display help for command
```

## upgrade

使用 `upgrade` 命令，在出现破坏性变更时自动迁移代码库。

```bash
npx assistant-ui@latest upgrade
```

此命令将：
- 运行 codemod 转换代码
- 更新导入路径和 API 用法
- 检测所需的依赖项变更
- 提示安装新 packages

**功能说明：**
- 按顺序应用当前捆绑的 codemod
- 显示包含文件数量的进度条
- 报告转换错误
- 自动检测并提供安装新依赖项的选项

最新的 upgrade 不包含历史上的 v0.8 UI package 拆分，因为其
`@assistant-ui/react-ui` 目标与当前运行时版本不兼容。
不要在 v0.15 upgrade 中运行 `codemod v0-8/ui-package-split`。

**输出示例：**

```bash
Starting upgrade...
Found 24 files to process.
Progress |████████████████████| 100% | ETA: 0s || Running v0-11/content-part-to-message-part...
Checking for package dependencies...
✅ Upgrade complete!
```

**选项**

```bash
Usage: assistant-ui upgrade [options]

upgrade and apply codemods for breaking changes

Options:
  -d, --dry              dry run (no changes are made to files)
  -p, --print            print transformed files to stdout
  --verbose              show more information about the transform process
  -j, --jscodeshift <options>  pass options directly to jscodeshift
  -h, --help             display help for command
```

## codemod

使用 `codemod` 命令运行特定的 codemod 转换。

```bash
npx assistant-ui@latest codemod <codemod> <source>
```

当你希望运行特定迁移，而不是所有可用的升级时，此命令非常有用。

**示例**

```bash
# Run specific codemod on a directory
npx assistant-ui codemod v0-11/content-part-to-message-part ./src

# Run with dry run to preview changes
npx assistant-ui codemod v0-11/content-part-to-message-part ./src --dry

# Print transformed output
npx assistant-ui codemod v0-11/content-part-to-message-part ./src --print
```

**选项**

```bash
Usage: assistant-ui codemod [options] <codemod> <source>

run a specific codemod transformation

Arguments:
  codemod                codemod to run
  source                 path to source files or directory to transform

Options:
  -d, --dry              dry run (no changes are made to files)
  -p, --print            print transformed files to stdout
  --verbose              show more information about the transform process
  -j, --jscodeshift <options>  pass options directly to jscodeshift
  -h, --help             display help for command
```

## mcp

使用 `mcp` 命令将 IDE 连接到 assistant-ui MCP server。

```bash
npx assistant-ui@latest mcp
```

此命令会为 Cursor、Windsurf、VSCode 和 Claude Code 注册托管的 [Model Context Protocol](/docs/llm#mcp) endpoint（`https://www.assistant-ui.com/mcp`）。Zed 和 Claude Desktop 只能启动本地 stdio server，因此对于这两个工具，它会改为配置 `@assistant-ui/mcp-docs-server` package。

**示例**

```bash
# Interactive - prompts to select IDE
npx assistant-ui mcp

# Install for specific IDE
npx assistant-ui mcp --cursor
npx assistant-ui mcp --windsurf
npx assistant-ui mcp --vscode
npx assistant-ui mcp --zed
npx assistant-ui mcp --claude-code
npx assistant-ui mcp --claude-desktop
```

**选项**

```bash
Usage: assistant-ui mcp [options]

connect your IDE to the assistant-ui MCP server

Options:
  --cursor          install for Cursor
  --windsurf        install for Windsurf
  --vscode          install for VSCode
  --zed             install for Zed
  --claude-code     install for Claude Code
  --claude-desktop  install for Claude Desktop
  -h, --help        display help for command
```


- 所有已安装的 `@assistant-ui/*` 和 `assistant-*` package 版本
- 关键生态依赖项的版本（React、Next.js、AI SDK 等）

## 常见工作流

### 创建新项目

```bash
# Create a new project with the default template
npx assistant-ui@latest create my-chatbot

# Navigate into the directory
cd my-chatbot

# Start development
npm run dev
```

### 添加到现有项目

```bash
# Initialize assistant-ui
npx assistant-ui@latest init

# Add additional components
npx assistant-ui@latest add thread-list assistant-modal

# Start development
npm run dev
```

### 保持最新

```bash
# Check for updates (dry run)
npx assistant-ui@latest update --dry

# Update all packages
npx assistant-ui@latest update

# Run upgrade codemods if needed
npx assistant-ui@latest upgrade
```

### 迁移版本

```bash
# Run automated migration
npx assistant-ui@latest upgrade

# Or run specific codemod
npx assistant-ui@latest codemod v0-11/content-part-to-message-part ./src

# Update packages after migration
npx assistant-ui@latest update
```

## 组件注册表

CLI 会从我们的公共 registry [r.assistant-ui.com](https://r.assistant-ui.com). 获取组件。

在 `components.json` 中配置支持样式的 URL，使 `@assistant-ui/*` 安装的组件与您的 shadcn 样式保持一致：

```json title="components.json"
{
  "registries": {
    "@assistant-ui": "https://r.assistant-ui.com/styles/{style}/{name}.json"
  }
}
```

`{style}` 占位符的值来自你的 `components.json` `style` 字段。名称以 `base-` 开头的样式会解析为 Base UI 风格的组件；其他所有样式都会解析为 Radix。现有 Radix 项目可以保留 `https://r.assistant-ui.com/{name}.json` 作为回退值。

每个组件都包含：
- 完整的 TypeScript 源代码
- 所有必需的依赖项
- Tailwind CSS 配置
- 使用示例

组件会直接添加到项目的源代码中，让你可以完全控制组件的自定义方式。

## 故障排除

### 找不到命令

如果收到“找不到命令”错误，请确保使用的是 `npx`：

```bash
npx assistant-ui@latest init
```

### 权限错误

在 Linux/macOS 上，如果遇到权限错误：

```bash
sudo npx assistant-ui@latest init
```

或者修复 npm 权限：https://docs.npmjs.com/resolving-eacces-permissions-errors-when-installing-packages-globally

### 诊断问题

提交 bug report 时，运行 `npx assistant-ui info` 以收集环境详细信息：

```bash
npx assistant-ui info
```

将输出粘贴到 [bug report 模板](https://github.com/assistant-ui/assistant-ui/issues/new?template=bug_report.yml). 的“Environment info”字段中。

### 依赖项冲突

如果看到依赖项冲突：

```bash
# Try with --force flag
npm install --force

# Or use legacy peer deps
npm install --legacy-peer-deps
```

### 组件已存在

使用 `--overwrite` flag 替换现有组件：

```bash
npx assistant-ui@latest add thread --overwrite
```

## 配置

CLI 遵循项目的配置：

- **包管理器**：自动检测 npm、pnpm、yarn 或 bun
- **TypeScript**：使用你的 `tsconfig.json` 路径
- **Tailwind**：使用你的 `tailwind.config.js` 设置
- **导入别名**：遵循 `components.json` 或 `assistant-ui.json` 配置
