## CSS 设置

Streamdown 的控件（代码块复制/下载按钮、mermaid 全屏覆盖层）以及流式传输光标均使用 Tailwind 工具类编写。Tailwind v4 默认不会扫描 `node_modules`，因此请在导入 Tailwind 的同一个全局样式表中，为 Streamdown 添加一个 `@source` 指令（每个已安装的插件也各添加一个）：

```css
@import "tailwindcss";

@source "../node_modules/streamdown/dist/*.js";
@source "../node_modules/@streamdown/code/dist/*.js";
@source "../node_modules/@streamdown/math/dist/*.js";
@source "../node_modules/@streamdown/mermaid/dist/*.js";
@source "../node_modules/@streamdown/cjk/dist/*.js";
```

请根据项目中 `node_modules` 所在的位置调整相对路径。在使用 pnpm 或 Turbo monorepo 且依赖被提升的情况下，通常需要更多 `../` 片段才能到达工作区根目录。只为实际安装的包添加插件行。

如果缺少这些指令，复制/下载/全屏按钮将不会应用内边距或光标样式（显示效果异常），并且 `caret` 指示器会保持不可见。

<Callout type="info">
  Streamdown 的组件依赖 shadcn/ui 设计令牌（`--background`、`--muted-foreground`、`--border` 等）。如果你未使用 shadcn/ui，请从 [Streamdown README](https://github.com/vercel/streamdown#css-custom-properties-design-tokens).
</Callout>

如果你选择使用 `animated` prop，或使用 `createAnimatePlugin` 实现逐词淡入效果，还需要在应用入口处导入一次关键帧：

```ts
import "streamdown/styles.css";
```

单独使用 `caret` prop **不**需要此导入；只有逐词动画需要。

## 基本用法

```tsx
import { StreamdownTextPrimitive } from "@assistant-ui/react-streamdown";

// Inside a MessagePrimitive.Parts component
<MessagePrimitive.Parts>
  {({ part }) => part.type === "text" ? <StreamdownText {...part} /> : null}
</MessagePrimitive.Parts>

// Where StreamdownText is:
const StreamdownText = () => <StreamdownTextPrimitive />;
```

## 使用插件（推荐）

```tsx
import { StreamdownTextPrimitive } from "@assistant-ui/react-streamdown";
import { code } from "@streamdown/code";
import { math } from "@streamdown/math";
import { mermaid } from "@streamdown/mermaid";
import "katex/dist/katex.min.css";

const StreamdownText = () => (
  <StreamdownTextPrimitive
    plugins={{ code, math, mermaid }}
    shikiTheme={["github-light", "github-dark"]}
  />
);
```

提供 `@streamdown/code` 时，默认主题为 `["github-light", "github-dark"]`，以支持亮色/暗色模式。

## 从 react-markdown 迁移

如果你要从 `@assistant-ui/react-markdown` 迁移，你现有的 `SyntaxHighlighter` 和 `CodeHeader` 组件仍可继续使用：

```tsx
import { StreamdownTextPrimitive } from "@assistant-ui/react-streamdown";

const StreamdownText = () => (
  <StreamdownTextPrimitive
    components={{
      SyntaxHighlighter: MySyntaxHighlighter,
      CodeHeader: MyCodeHeader,
    }}
    componentsByLanguage={{
      mermaid: { SyntaxHighlighter: MermaidRenderer }
    }}
  />
);
```

## 属性

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `mode` | `"streaming" \| "static"` | `"streaming"` | 渲染模式 |
| `plugins` | `PluginConfig` | - | Streamdown 插件（代码、数学公式、mermaid、CJK） |
| `shikiTheme` | `[string, string]` | `["github-light", "github-dark"]` | Shiki 的浅色和深色主题 |
| `components` | `object` | - | 自定义组件，包括 `SyntaxHighlighter` 和 `CodeHeader` |
| `componentsByLanguage` | `object` | - | 针对特定语言的组件覆盖 |
| `preprocess` | `(text: string) => string` | - | 文本预处理函数 |
| `defer` | `boolean` | `false` | 通过 `useDeferredValue` 将 Markdown 解析延迟到较低优先级，从而在流式传输期间保持输入和滚动响应 |
| `smooth` | `boolean \| SmoothOptions` | `false` | 通过 `useSmooth` 实现打字机式显示；在显示追上之前，光标和控件会保持活动状态。对于入场动画，建议使用原生的 `animated` 属性 |
| `controls` | `boolean \| object` | `true` | 启用或禁用代码块和表格的 UI 控件 |
| `caret` | `"block" \| "circle"` | - | 流式传输光标样式 |
| `mermaid` | `MermaidOptions` | - | Mermaid 图表配置 |
| `linkSafety` | `LinkSafetyConfig` | - | 链接安全确认对话框 |
| `remend` | `RemendConfig` | - | 不完整 Markdown 的自动补全 |
| `allowedTags` | `Record<string, string[]>` | - | HTML 标签白名单 |
| `containerProps` | `object` | - | 容器 div 的属性 |
| `containerClassName` | `string` | - | 容器的类名 |
| `remarkRehypeOptions` | `object` | - | 传递给 remark-rehype 的选项 |
| `BlockComponent` | `ComponentType` | - | 用于渲染块的自定义组件 |
| `parseMarkdownIntoBlocksFn` | `(md: string) => string[]` | - | 自定义块解析函数 |
| `parseIncompleteMarkdown` | `boolean` | `false` | 按原样解析不完整的 Markdown（跳过 remend） |
| `security` | `SecurityConfig` | - | URL/图片安全限制 |

## 高级配置

### Mermaid 选项

自定义 Mermaid 图表的渲染方式以及错误处理：

```tsx
import { mermaid } from "@streamdown/mermaid";

<StreamdownTextPrimitive
  plugins={{ mermaid }}
  mermaid={{
    config: { theme: "dark" },
    errorComponent: ({ error, chart, retry }) => (
      <div>
        <p>Failed to render diagram: {error}</p>
        <button onClick={retry}>Retry</button>
      </div>
    ),
  }}
/>
```

### 流式光标

在流式输出期间显示光标指示器：

```tsx
<StreamdownTextPrimitive caret="block" />  // ▋
<StreamdownTextPrimitive caret="circle" /> // ●
```

光标通过 wrapper 上的 Tailwind `::after` 工具类实现，因此只有在 Tailwind 配置中包含来自 [CSS 设置](#css-setup) 的 `@source` 指令时才会显示。

### 链接安全

在打开外部链接前显示确认提示：

```tsx
<StreamdownTextPrimitive
  linkSafety={{
    enabled: true,
    onLinkCheck: (url) => url.startsWith("https://trusted.com"),
  }}
/>
```

### 不完整 Markdown 处理（Remend）

配置流式传输期间如何处理不完整的 Markdown 语法：

```tsx
<StreamdownTextPrimitive
  remend={{
    links: true,           // Complete incomplete links
    images: true,          // Handle incomplete images
    linkMode: "protocol",  // How to handle incomplete links: 'protocol' or 'text-only'
    bold: true,            // Complete **text → **text**
    italic: true,          // Complete *text → *text*
    boldItalic: true,      // Complete ***text → ***text***
    inlineCode: true,      // Complete `code → `code`
    strikethrough: true,   // Complete ~~text → ~~text~~
    katex: true,           // Complete $$equation → $$equation$$
    setextHeadings: true,  // Handle incomplete setext headings
    handlers: [],          // Custom handlers for incomplete markdown completion
  }}
/>
```

### 允许的 HTML 标签

允许 Markdown 内容中使用特定的 HTML 标签：

```tsx
<StreamdownTextPrimitive
  allowedTags={{
    div: ["class", "id"],
    span: ["class", "style"],
    iframe: ["src", "width", "height"],
  }}
/>
```

### 安全配置

限制链接和图片允许使用的 URL。这会覆盖 streamdown 默认的全部允许策略：

```tsx
<StreamdownTextPrimitive
  security={{
    // Only allow links to trusted domains
    allowedLinkPrefixes: ["https://example.com", "https://docs.example.com"],
    // Only allow images from your CDN
    allowedImagePrefixes: ["https://cdn.example.com"],
    // Restrict protocols
    allowedProtocols: ["https", "mailto"],
    // Disable base64 data images
    allowDataImages: false,
    // Default origin for relative URLs
    defaultOrigin: "https://example.com",
    // CSS class for blocked elements
    blockedLinkClass: "blocked-link",
    blockedImageClass: "blocked-image",
  }}
/>
```

## 检测行内代码与块级代码

构建自定义代码组件时，可以使用 `useIsStreamdownCodeBlock` 来检测当前位于代码块还是行内代码中：

```tsx
import { useIsStreamdownCodeBlock } from "@assistant-ui/react-streamdown";

function MyCodeComponent({ children, ...props }) {
  const isCodeBlock = useIsStreamdownCodeBlock();

  if (!isCodeBlock) {
    return <code className="inline-code" {...props}>{children}</code>;
  }

  return <pre><code {...props}>{children}</code></pre>;
}
```

你还可以使用 `useStreamdownPreProps` 来访问传递给父级 `<pre>` 元素的 props：

```tsx
import { useStreamdownPreProps } from "@assistant-ui/react-streamdown";

function MyCodeComponent({ children }) {
  const preProps = useStreamdownPreProps();

  if (!preProps) {
    // Inline code
    return <code>{children}</code>;
  }

  // Block code - preProps contains className, node, etc.
  return <code className={preProps.className}>{children}</code>;
}
```

## 与 react-markdown 的比较

| 特性 | react-markdown | react-streamdown |
|---------|---------------|------------------|
| 包体积 | 更小 | 更大（包含插件时） |
| 语法高亮 | 自行配置 | 内置 Shiki |
| 数学公式渲染 | 手动配置 | 内置 KaTeX |
| Mermaid 图表 | 手动配置 | 内置支持 |
| 中日韩文字优化 | 无 | 内置 |
| 流式传输 | `smooth` 属性 | `mode` + 基于块 |
