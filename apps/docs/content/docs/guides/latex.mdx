## 支持的格式

默认情况下，remark-math（react-markdown 路径）支持：
- `$...$` 表示行内数学公式
- `$$...$$` 表示展示数学公式
- 使用 `math` 语言标识符的围栏代码块

## 支持替代 LaTeX 分隔符

许多语言模型会使用 remark-math 无法识别的分隔符输出数学公式：
- `\(...\)` 用于行内数学公式，`\[...\]` 用于块级数学公式
- `[/math]...[/math]` 和 `[/inline]...[/inline]` 等自定义标签

`@assistant-ui/react-markdown` 导出 `normalizeMathDelimiters`，它会将这些分隔符重写为 remark-math 可解析的 `$...$` 和 `$$...$$` 形式。将其传递给 `MarkdownTextPrimitive` 的 `preprocess` 属性：

```tsx title="/components/assistant-ui/elements/markdown-text.tsx"
import {
  MarkdownTextPrimitive,
  normalizeMathDelimiters, // [!code ++]
} from "@assistant-ui/react-markdown";

const MarkdownTextImpl = () => {
  return (
    <MarkdownTextPrimitive
      remarkPlugins={[remarkGfm, remarkMath]}
      rehypePlugins={[rehypeKatex]}
      preprocess={normalizeMathDelimiters} // [!code ++]
      className="aui-md"
      components={defaultComponents}
    />
  );
};
```

此外，还会导出单独的转换函数 `rewriteLatexBracketDelimiters` 和 `rewriteCustomMathTags`，以便更精细地控制要规范化的分隔符。

<Callout type="info">
  使用 [Streamdown](/docs/guides/streamdown) 作为渲染器？相同的辅助函数也会从 `@assistant-ui/react-streamdown` 导出，并可传递给 `StreamdownTextPrimitive` 的 `preprocess` 属性。
</Callout>

### 货币金额

启用单美元符号行内数学公式后（react-markdown 路径上的默认设置），remark-math 会将单独的 `$` 读取为数学公式分隔符，因此像 `$5 ... $10` 这样的正文会被解析为数学公式。`escapeCurrencyDollars` 会对紧跟数字的 `$` 进行转义，使货币金额保持原样，同时保留块级数学公式的 `$$`。将它与分隔符规范化组合使用：

```tsx title="/components/assistant-ui/elements/markdown-text.tsx"
import {
  normalizeMathDelimiters,
  escapeCurrencyDollars, // [!code ++]
} from "@assistant-ui/react-markdown";

<MarkdownTextPrimitive
  preprocess={(text) => escapeCurrencyDollars(normalizeMathDelimiters(text))} // [!code ++]
  // ...
/>;
```

<Callout type="tip">
在 `MarkdownTextPrimitive` 内部，流式文本首先经过 `preprocess`（分隔符规范化），然后经过 `useSmooth`（逐字符累积），最后才会到达 Markdown 解析器。两者都在 remark-math 处理文本之前运行，因此分隔符替换和流式平滑处理都能安全地用于流式传输；尚未完整接收的分隔符会累积在平滑缓冲区中，而不会在片段中途被解析。
</Callout>
