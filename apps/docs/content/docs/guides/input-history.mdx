---
title: 输入历史
description: 在 assistant-ui React 输入框中，以终端风格通过 ArrowUp/ArrowDown 调取之前发送的消息。
platforms: ["react"]
---

输入历史允许用户在输入框为空时按下 ArrowUp，像 shell 提示符一样调取之前发送的消息，且从最新消息开始。ArrowDown 会向最新条目逐步返回，最后恢复开始浏览历史时正在输入的草稿。

<Callout type="warn">
  此 API 标记为不稳定，可能会随时变更，恕不另行通知。
</Callout>

## 用法

将该 hook 的 bundle 展开到 `ComposerPrimitive.Input` 上：

```tsx
import {
  ComposerPrimitive,
  unstable_useComposerInputHistory,
} from "@assistant-ui/react";

const Composer = () => {
  const history = unstable_useComposerInputHistory();

  return (
    <ComposerPrimitive.Root>
      <ComposerPrimitive.Input {...history} />
      <ComposerPrimitive.Send />
    </ComposerPrimitive.Root>
  );
};
```

历史记录会根据当前线程中的用户消息实时生成（会进行 trim，并合并相邻的重复消息），因此无需持久化或配置。

## 行为

- 只有在输入框为空时，ArrowUp 才会开始调取历史记录（仅包含空白字符的草稿也视为空，并会在返回时恢复）。
- 显示调取的多行消息时，方向键会逐行移动光标；只有当光标位于第一行（ArrowUp）或最后一行（ArrowDown）时，才会切换历史记录。
- 打开的 mention 或斜杠命令弹出框会继续处理方向键；当触发器弹出框处于活动状态时，该 hook 会让出控制权。
- IME 组合输入、修饰键、文本选择，以及前置处理程序已经`preventDefault`的事件均保持不变。
- 切换线程或发送消息会重置浏览位置。
- 该 hook 在编辑输入框中不会生效。

如果要在历史记录处理之前插入自定义的 ArrowUp 处理逻辑（例如，逐条浏览排队的消息），请先组合你的处理程序，再组合该 hook，并在消费该按键时调用 `preventDefault`：

```tsx
<ComposerPrimitive.Input
  onKeyDown={(e) => {
    myHandler(e);
    history.onKeyDown(e);
  }}
/>
```
