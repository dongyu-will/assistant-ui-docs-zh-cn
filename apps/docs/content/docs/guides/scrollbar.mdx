如果你想使用 `ThreadPrimitive.Viewport` 的自定义滚动条 UI 来替代系统默认滚动条，可以集成 `radix-ui` 的 Scroll Area。
一个示例实现是 [shadcn/ui 的 Scroll Area](https://ui.shadcn.com/docs/components/scroll-area).

<Steps>

<Step>

### 添加 shadcn Scroll Area

```bash
npx shadcn@latest add scroll-area
```

</Step>

<Step>

### 添加其他样式

Radix UI 的 Viewport 组件会添加一个中间的 `<div data-radix-scroll-area-content>` 元素。
将以下 CSS 添加到你的 `globals.css`：

```css title="@/app/globals.css"
.thread-viewport > [data-radix-scroll-area-content] {
  @apply flex flex-col items-center self-stretch bg-inherit;
}
```

</Step>

<Step>

### 与 Thread 集成

- 将 `ThreadPrimitive.Root` 包裹在 `<ScrollAreaPrimitive.Root asChild>` 中
- 将 `ThreadPrimitive.Viewport` 包裹在 `<ScrollAreaPrimitive.Viewport className="thread-viewport" asChild>` 中
- 将 shadcn 的 `<ScrollBar />` 添加到 `ThreadPrimitive.Root`

最终的 MyThread 组件应如下所示：

```tsx {1-2,6,8,12-13,15}
import { ScrollArea as ScrollAreaPrimitive } from "radix-ui";
import { ScrollBar } from "@/components/ui/scroll-area";

const MyThread: FC = () => {
  return (
    <ScrollAreaPrimitive.Root asChild>
      <ThreadPrimitive.Root className="...">
        <ScrollAreaPrimitive.Viewport className="thread-viewport" asChild>
          <ThreadPrimitive.Viewport className="...">
            ...
          </ThreadPrimitive.Viewport>
        </ScrollAreaPrimitive.Viewport>
        <ScrollBar />
      </ThreadPrimitive.Root>
    </ScrollAreaPrimitive.Root>
  );
};
```

</Step>

</Steps>
