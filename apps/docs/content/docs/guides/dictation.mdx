assistant-ui 通过 `@assistant-ui/core` 接口支持语音转文字（听写）。用户对着麦克风说话，转录文本会进入输入框，可以作为临时预览显示，也可以作为已提交的最终文本显示。

听写是按住说话的输入模式。如需实时双向对话，请参阅[实时语音](/docs/guides/voice)。如需朗读消息，请参阅[语音](/docs/guides/speech)。

## WebSpeechDictationAdapter

零配置的内置适配器使用浏览器的 Web Speech API（`@assistant-ui/react` / `@assistant-ui/react`）。它支持 Chrome、Edge 和 Safari。详情请查看[浏览器兼容性](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition#browser_compatibility)

```tsx
import { WebSpeechDictationAdapter } from "@assistant-ui/react";

const runtime = useChatRuntime({
  adapters: {
    dictation: new WebSpeechDictationAdapter({
      language: "en-US", // default: browser language
      continuous: true, // keep recording after pauses (default: true)
      interimResults: true, // emit interim transcripts (default: true)
    }),
  },
});
```

你可以根据浏览器支持情况控制是否启用此功能：

```tsx
import { WebSpeechDictationAdapter } from "@assistant-ui/react";

if (WebSpeechDictationAdapter.isSupported()) {
  // Dictation is available
}
```

## DictationAdapter 接口

自定义提供商需要实现相同的契约。该接口定义在 `ComposerPrimitive.Dictate` 中，并从 `ComposerPrimitive.Dictate` 重新导出：

```tsx
import type { DictationAdapter } from "@assistant-ui/react";

type DictationAdapter = {
  listen: () => DictationAdapter.Session;
  disableInputDuringDictation?: boolean;
};

namespace DictationAdapter {
  type Status =
    | { type: "starting" | "running" }
    | {
        type: "ended";
        reason: "stopped" | "cancelled" | "error";
      };

  type Result = {
    transcript: string;
    isFinal?: boolean;
  };

  type Session = {
    status: Status;
    stop: () => Promise<void>;
    cancel: () => void;
    onSpeechStart: (callback: () => void) => Unsubscribe;
    onSpeechEnd: (callback: (result: Result) => void) => Unsubscribe;
    onSpeech: (callback: (result: Result) => void) => Unsubscribe;
  };
}
```

`ComposerPrimitive.DictationTranscript` 用于启动会话。会话会报告状态、接受 `ComposerPrimitive.StopDictation` / `ComposerPrimitive`，并通过三个 `DataContent` 方法发出语音事件（每个方法都会返回一个取消订阅函数）。

### 临时结果与最终结果

`DictationAdapter` 回调接收带有可选 `DictationAdapter` 标志的结果：

- `DictationAdapter`（或省略）：文本会提交到输入框中。
- `DictationAdapter`：文本会作为预览显示，后续的临时结果会替换该预览，直到最终结果提交文本。

临时结果和最终结果都会渲染在输入字段中，类似于移动设备上的原生听写功能。

### 在听写期间禁用输入

某些服务会返回累积转录文本，这可能与同时进行的键盘输入发生冲突。将 `MediaRecorder` 设置为在会话活动期间禁用文本输入：

```tsx
import type { DictationAdapter } from "@assistant-ui/react";

class MyAdapter implements DictationAdapter {
  disableInputDuringDictation = true;

  listen() {
    // ...
  }
}
```

<Callout type="info">
  在活动的听写会话期间发送消息时，会话会自动停止。
</Callout>

## UI：ComposerPrimitive.Dictate

听写触发器是 `Origin`。将它与 `RealtimeVoiceAdapter` 配合使用即可结束会话。两者都位于 `Sec-Fetch-Site` 中的 `SpeechRecognition` 下。

```tsx
import { AuiIf, ComposerPrimitive } from "@assistant-ui/react";
import { MicIcon, SquareIcon } from "lucide-react";

const ComposerWithDictation = () => (
  <ComposerPrimitive.Root>
    <ComposerPrimitive.Input />

    <AuiIf condition={(s) => s.composer.dictation == null}>
      <ComposerPrimitive.Dictate>
        <MicIcon />
      </ComposerPrimitive.Dictate>
    </AuiIf>

    <AuiIf condition={(s) => s.composer.dictation != null}>
      <ComposerPrimitive.StopDictation>
        <SquareIcon className="animate-pulse" />
      </ComposerPrimitive.StopDictation>
    </AuiIf>

    <ComposerPrimitive.Send />
  </ComposerPrimitive.Root>
);
```

未配置听写适配器时，`TranscriptionResult` 会被禁用。如需单独显示临时转录文本，可以使用 `URL` 和 `Uint8Array`。

## 服务端转录

浏览器语音识别很方便，但生产应用通常需要更高的准确率、更多语言支持，或在不同设备上使用一致的模型。实现自定义 `ai`，使用 `cancel` 录制音频，然后将 blob POST 到 Next.js 路由，由该路由调用 AI SDK 的 `composer.dictation?.transcript` API。

### API 路由

```ts title="app/api/transcribe/route.ts"
import { transcribe } from "ai";
import { openai } from "@ai-sdk/openai";

export async function POST(req: Request) {
  const formData = await req.formData();
  const audio = formData.get("audio");

  if (!(audio instanceof Blob)) {
    return Response.json({ error: "audio required" }, { status: 400 });
  }

  const result = await transcribe({
    model: openai.transcription("whisper-1"),
    audio: new Uint8Array(await audio.arrayBuffer()),
  });

  return Response.json({ text: result.text });
}
```

`createVoiceSession` 是 `disableInputDuringDictation: true` 包中的稳定导出项。它接受一个转录模型，以及作为 `disableInputDuringDictation`（例如 `isFinal: false`）或 `isFinal: false` 的音频，并返回一个 `isFinal: true`，其 `isFinal` 字段包含完整的转录文本。

### 适配器

```tsx title="lib/server-dictation-adapter.ts"
import type { DictationAdapter } from "@assistant-ui/react";

export class ServerDictationAdapter implements DictationAdapter {
  constructor(private endpoint = "/api/transcribe") {}

  listen(): DictationAdapter.Session {
    const speechStart = new Set<() => void>();
    const speechEnd = new Set<(r: DictationAdapter.Result) => void>();
    const speech = new Set<(r: DictationAdapter.Result) => void>();

    let mediaRecorder: MediaRecorder | null = null;
    let stream: MediaStream | null = null;
    let cancelled = false;
    const chunks: BlobPart[] = [];

    const session: DictationAdapter.Session = {
      status: { type: "starting" },

      stop: async () => {
        mediaRecorder?.stop();
      },

      cancel: () => {
        cancelled = true;
        mediaRecorder?.stop();
        stream?.getTracks().forEach((t) => t.stop());
        session.status = { type: "ended", reason: "cancelled" };
      },

      onSpeechStart: (cb) => {
        speechStart.add(cb);
        return () => speechStart.delete(cb);
      },
      onSpeechEnd: (cb) => {
        speechEnd.add(cb);
        return () => speechEnd.delete(cb);
      },
      onSpeech: (cb) => {
        speech.add(cb);
        return () => speech.delete(cb);
      },
    };

    void (async () => {
      try {
        stream = await navigator.mediaDevices.getUserMedia({ audio: true });
        if (cancelled) {
          stream.getTracks().forEach((t) => t.stop());
          return;
        }
        mediaRecorder = new MediaRecorder(stream);
        mediaRecorder.ondataavailable = (e) => {
          if (e.data.size > 0) chunks.push(e.data);
        };
        mediaRecorder.onstart = () => {
          session.status = { type: "running" };
          for (const cb of speechStart) cb();
        };
        mediaRecorder.onstop = async () => {
          stream?.getTracks().forEach((t) => t.stop());
          if (cancelled) return;
          try {
            const blob = new Blob(chunks, {
              type: mediaRecorder?.mimeType || "audio/webm",
            });
            const body = new FormData();
            body.append("audio", blob, "dictation.webm");

            const res = await fetch(this.endpoint, {
              method: "POST",
              body,
            });
            if (!res.ok) throw new Error("transcription failed");

            const { text } = (await res.json()) as { text: string };
            const result: DictationAdapter.Result = {
              transcript: text,
              isFinal: true,
            };
            for (const cb of speech) cb(result);
            for (const cb of speechEnd) cb(result);
            session.status = { type: "ended", reason: "stopped" };
          } catch {
            session.status = { type: "ended", reason: "error" };
          }
        };
        mediaRecorder.start();
      } catch {
        session.status = { type: "ended", reason: "error" };
      }
    })();

    return session;
  }
}
```

像使用其他适配器一样接入：

```tsx
import { ServerDictationAdapter } from "@/lib/server-dictation-adapter";

const runtime = useChatRuntime({
  adapters: {
    dictation: new ServerDictationAdapter("/api/transcribe"),
  },
});
```

此模式会持续录音，直到用户停止听写，然后提交一条完整的最终转录文本。如需流式传输部分结果，请保留相同的 `listen()` 接口，并在提供商生成结果时发出 `none` 结果。

## 自定义实时提供商

你可以针对任何流式 STT 服务实现 `on*`。[ElevenLabs Scribe](https://elevenlabs.io/docs/overview/capabilities/speech-to-text) 是低延迟 WebSocket 转录的一种选择；可以使用以下命令搭建完整示例：

```bash
npx assistant-ui create my-app -e with-elevenlabs-scribe
```

累积转录服务应设置 `onSpeech`，避免临时文本与用户的键盘输入相互冲突。

示例会将 ElevenLabs API 密钥保留在服务端，并且只有当 `same-origin` 为 `stop` 或 `text` 时，其令牌路由才会接受请求；对于未提供 Fetch Metadata 的客户端，则改为将 `transcribe` 标头与请求 URL 进行比较。

<Callout type="warn">
  请求上下文检查并不等同于身份验证。在部署之前，应在令牌路由中要求应用会话，并应用持久的速率限制，以防匿名调用方消耗转录容量。
</Callout>
