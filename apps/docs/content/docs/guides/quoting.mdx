## 开始使用

按照[引用组件页面](/elements/quote)中的说明，安装并配置 `quote` registry 组件。其中涵盖安装命令、组件放置位置，以及用于将引用数据转发给 LLM 的 `injectQuoteContext` 辅助函数。

<Callout type="warn">
  **限制：** 同时只能有一个处于活动状态的引用。`setQuote` 会替换之前的引用，而不是追加内容。只有当选区完全位于同一消息部分内时，浮动工具栏才会显示；跨消息和跨部分的选区会被忽略。
</Callout>

## 工作原理

当用户在助手消息中选择文本时，会出现包含“引用”按钮的浮动工具栏。点击该按钮会调用 `composer.setQuote()`，将选中的内容存储到输入框中。[引用组件](/elements/quote)默认已实现此功能。

发送消息时，输入框运行时会自动将引用写入 `message.metadata.custom.quote`，并从输入框中清除该引用。

在后端，路由处理程序会从元数据中提取引用，并将其提供给 LLM。我们导出了名为 `injectQuoteContext` 的辅助函数，可自动为 AI-SDK 处理此流程。如果缺少这一步，引用虽然会显示在 UI 中，但不会作为上下文发送给模型。有关更多信息和替代方案，请参阅[后端处理](#backend-handling)。

### 数据结构

```typescript
type QuoteInfo = {
  readonly text: string;       // selected plain text
  readonly messageId: string;  // source message ID
};

// Stored at: message.metadata.custom.quote
```

## 后端处理

引用数据位于消息元数据中，而不是消息内容中，因此除非后端提取并提供这些数据，否则 LLM 无法看到引用。最简单的方式是使用[`injectQuoteContext`](/elements/quote#forward-quote-context-to-the-llm)，它会在消息部分之前，将引用文本作为 Markdown 引用块添加。

如需针对特定提供商进行处理，请直接使用引用元数据。

### Claude SDK 引用

将引用文本作为引用来源传入，使 Claude 生成引用该文本的引用标注：

```typescript title="app/api/chat/route.ts"
import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic();

export async function POST(req: Request) {
  const { messages } = await req.json();

  const claudeMessages = messages.map((msg) => {
    const quote = msg.metadata?.custom?.quote;
    if (!quote?.text) {
      return { role: msg.role, content: extractText(msg) };
    }

    return {
      role: "user",
      content: [
        {
          type: "text",
          text: quote.text,
          cache_control: { type: "ephemeral" },
          citations: { enabled: true },
        },
        {
          type: "text",
          text: extractText(msg),
        },
      ],
    };
  });

  const response = await client.messages.create({
    model: "claude-sonnet-4-6",
    max_tokens: 1024,
    messages: claudeMessages,
  });

  // ... stream response back
}
```

### OpenAI 消息上下文

将引用作为额外上下文注入用户消息：

```typescript title="app/api/chat/route.ts"
function injectQuoteForOpenAI(messages) {
  return messages.map((msg) => {
    const quote = msg.metadata?.custom?.quote;
    if (!quote?.text || msg.role !== "user") return msg;

    return {
      ...msg,
      content: `[Referring to: "${quote.text}"]\n\n${msg.content}`,
    };
  });
}
```

## 读取引用数据

在自定义组件中，使用 `useMessageQuote` 访问引用数据：

```tsx
import { useMessageQuote } from "@assistant-ui/react";

function CustomQuoteDisplay() {
  const quote = useMessageQuote();
  if (!quote) return null;

  return (
    <blockquote className="border-l-2 pl-3 text-sm text-muted-foreground">
      {quote.text}
    </blockquote>
  );
}
```

## 编程式 API

通过 `@assistant-ui/react` 中的 `useAui` 设置或清除引用。当组件在特定线程上下文之外渲染时，调用 `aui.thread.composer().setQuote()`；当组件在线程内部渲染时，调用 `aui.composer.setQuote()`：

```tsx
import { useAui } from "@assistant-ui/react";

function MyComponent() {
  const aui = useAui();

  const quoteText = () => {
    aui.thread.composer().setQuote({
      text: "The text to quote",
      messageId: "msg-123",
    });
  };

  const clearQuote = () => {
    aui.thread.composer().setQuote(undefined);
  };

  return (
    <>
      <button onClick={quoteText}>Set Quote</button>
      <button onClick={clearQuote}>Clear Quote</button>
    </>
  );
}
```

## 设计说明

- **文本快照：** 选中的文本会在创建引用时被捕获，之后不会再与源消息关联。
- **流式传输消息：** 消息处于流式传输状态时，工具栏仍然有效，因为它依赖捕获的选区，而不是消息状态。
- **`isEmpty` 保持不变：** 单独的引用不会使输入框变为非空；用户仍需要输入回复。
- **滚动时隐藏工具栏：** 工具栏会在滚动时隐藏，否则其位置可能会过时。
