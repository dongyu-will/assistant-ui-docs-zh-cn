分支功能允许用户在消息的不同版本之间导航。以下情况会创建新分支：

- 编辑用户消息
- 重新加载助手消息（重新加载会在同一消息上创建新分支）

assistant-ui 会通过观察 `messages` 数组的变化，自动跟踪分支。

## 最简可用模式

<BranchingSample />

将分支选择器放置在消息组件中：

```tsx
import { BranchPickerPrimitive } from "@assistant-ui/react";

const BranchPicker = () => (
  <BranchPickerPrimitive.Root hideWhenSingleBranch>
    <BranchPickerPrimitive.Previous />
    <BranchPickerPrimitive.Number /> / <BranchPickerPrimitive.Count />
    <BranchPickerPrimitive.Next />
  </BranchPickerPrimitive.Root>
);
```

`BranchPickerPrimitive.Previous` 和 `.Next` 会在分支边界处以及运行正在进行时自动禁用（除非运行时支持 `switchBranchDuringRun`）。如需查看完整的原语 API，请参阅 [BranchPickerPrimitive](/docs/primitives/branch-picker)。

## 触发重新加载

`ActionBarPrimitive.Reload` 会在助手消息上创建新分支，并从该分支重新运行：

```tsx
import { ActionBarPrimitive, MessagePrimitive } from "@assistant-ui/react";

const AssistantMessage = () => (
  <MessagePrimitive.Root>
    <MessagePrimitive.Parts />
    <ActionBarPrimitive.Root>
      <ActionBarPrimitive.Reload />
    </ActionBarPrimitive.Root>
  </MessagePrimitive.Root>
);
```

当 `thread.isRunning` 或 `thread.isDisabled` 为 true 时，`Reload` 会被禁用。如需查看完整参考，请参阅 [ActionBarPrimitive](/docs/primitives/action-bar)。

## 以编程方式进行分支导航

对于无头模式或键盘快捷键流程，可以通过 `aui.message.switchToBranch` 直接导航到指定 id 的分支：

```tsx
import { useAui } from "@assistant-ui/react";

const SwitchToBranch = ({ branchId }: { branchId: string }) => {
  const aui = useAui();
  return (
    <button onClick={() => aui.message.switchToBranch({ branchId })}>
      Go to branch
    </button>
  );
};
```

必须在消息上下文中调用此方法（例如嵌套在 `MessagePrimitive.Root` 中）。

## 分支后的分组部分

每个分支都是一个独立的消息版本，并拥有自己的内容部分。`MessagePrimitive.GroupedParts` 会对这些部分进行层级相邻分组；当一条消息跨分支混合工具调用和文本时，这非常有用。有关 `GroupedParts` 的用法，请参阅 [MessagePrimitive](/docs/primitives/message) 参考文档。
