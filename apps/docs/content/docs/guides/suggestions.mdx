建议提示词是预先定义的提示词，可帮助用户了解助手的功能。它们会显示在欢迎屏幕中，为开始对话提供快捷方式。

## 概览

Suggestions API 允许你配置一组建议提示词，并在线程为空时显示。用户可以点击建议，将其填入输入框，或立即发送消息。

## 快速开始

在运行时提供程序中使用 `Suggestions()` API 配置建议：

```tsx
import { AuiConfig, Tools, Suggestions } from "@assistant-ui/react";
import { useChatRuntime } from "@assistant-ui/ai-sdk";

function MyRuntimeProvider({ children }: { children: React.ReactNode }) {
  const runtime = useChatRuntime();

  const config = AuiConfig({
    tools: Tools({ toolkit: myToolkit }),
    suggestions: Suggestions([
      "What can you help me with?",
      "Tell me a joke",
      "Explain quantum computing",
    ]),
  });

  return (
    <AssistantRuntimeProvider runtime={runtime} config={config}>
      {children}
    </AssistantRuntimeProvider>
  );
}
```

## 建议格式

建议可以是字符串，也可以是包含 title、label 和 prompt 的对象：

### 简单字符串

```tsx
AuiConfig({
  suggestions: Suggestions([
    "What's the weather today?",
    "Help me write an email",
    "Explain React hooks",
  ]),
});
```

### 包含标题和描述的对象

如果需要将显示文本与提示词分开，可以使用更详细的建议：

```tsx
AuiConfig({
  suggestions: Suggestions([
    {
      title: "Weather",
      label: "in San Francisco",
      prompt: "What's the weather in San Francisco?",
    },
    {
      title: "React Hooks",
      label: "useState and useEffect",
      prompt: "Explain React hooks like useState and useEffect",
    },
    {
      title: "Travel Tips",
      label: "for Tokyo",
      prompt: "Give me travel tips for visiting Tokyo",
    },
  ]),
});
```

## 显示建议

shadcn 注册表中的默认 Thread 组件已经包含建议渲染功能。线程为空时，建议会显示在欢迎屏幕中。

### 自定义建议显示方式

如果你想自定义建议的显示方式，可以修改 Thread 组件。惯用模式是将建议包裹在 `AuiIf` 中，使其仅在线程为空时显示：

```tsx
import {
  ThreadPrimitive,
  SuggestionPrimitive,
  AuiIf,
} from "@assistant-ui/react";

const ThreadWelcome = () => {
  return (
    <AuiIf condition={(s) => s.thread.isEmpty}>
      <div className="flex flex-col items-center justify-center">
        <h1>Welcome!</h1>
        <p>How can I help you today?</p>

        <div className="grid grid-cols-2 gap-2">
          <ThreadPrimitive.Suggestions>
            {() => <SuggestionItem />}
          </ThreadPrimitive.Suggestions>
        </div>
      </div>
    </AuiIf>
  );
};

const SuggestionItem = () => {
  return (
    <SuggestionPrimitive.Trigger send asChild>
      <button className="rounded-lg border p-3 hover:bg-muted">
        <div className="font-medium">
          <SuggestionPrimitive.Title />
        </div>
        <div className="text-muted-foreground text-sm">
          <SuggestionPrimitive.Description />
        </div>
      </button>
    </SuggestionPrimitive.Trigger>
  );
};
```

### 隐藏建议

用户发送消息后，建议会自动隐藏，因为 `thread.isEmpty` 会变为 false。无需额外管理状态。如果你希望在不发送消息的情况下隐藏建议（例如用户点击其他位置后），可以管理一个本地布尔值，并将其与 `AuiIf` 条件结合，或直接使用条件渲染。

## 建议原语

用于渲染建议的原语包括 `ThreadPrimitive.Suggestions`、`ThreadPrimitive.SuggestionByIndex`、`SuggestionPrimitive.Title`、`SuggestionPrimitive.Description` 和 `SuggestionPrimitive.Trigger`。当你需要控制特定建议插槽的布局，而不是遍历所有建议时，`ThreadPrimitive.SuggestionByIndex` 会很有用。有关完整的 prop 参考和使用模式，请参阅[建议原语文档](/docs/primitives/suggestion)。

## 由运行时驱动的建议

静态的 `Suggestions(...)` API 用于欢迎屏幕。对于依赖对话内容、工具结果或后端的后续提示词，可以通过运行时本身推送建议。它们会存储在 `thread.suggestions` 中；当未设置静态的 `Suggestions(...)` 配置时，`suggestions` 作用域会从这些建议中派生，因此 `ThreadPrimitive.Suggestions` 也会渲染它们。运行时建议使用 `ThreadSuggestion` 结构：必需的 `prompt`，以及可选的 `title` 和 `label`。省略 `title` 时，它会回退到 prompt；省略 `label` 时会渲染为空。因此，仅包含 prompt 的运行时建议看起来与普通字符串建议完全相同。

### 本地运行时：`SuggestionAdapter`

将 `suggestion` 适配器传递给 `useLocalRuntime`。其 `generate` 函数会在每次助手轮次结束后运行，并且可以返回 promise 或用于流式更新的异步生成器。

```tsx
import { useLocalRuntime, type SuggestionAdapter } from "@assistant-ui/react";

const suggestionAdapter: SuggestionAdapter = {
  async generate({ messages }) {
    const response = await fetch("/api/follow-ups", {
      method: "POST",
      body: JSON.stringify({ messages }),
    });
    const data: { prompt: string }[] = await response.json();
    return data;
  },
};

const runtime = useLocalRuntime(myChatModel, {
  adapters: { suggestion: suggestionAdapter },
});
```

对于由 LLM 驱动的后续提示词，请使用 `createSuggestionAdapter`。它会根据最近的消息构建确定性的会话记录提示词，并调用你的 `complete` 函数。传递可选的 `signal`，这样新运行开始时就可以取消正在进行的生成。

```tsx
import { createSuggestionAdapter, useLocalRuntime } from "@assistant-ui/react";

const suggestionAdapter = createSuggestionAdapter({
  async complete({ prompt, signal }) {
    const response = await fetch("/api/suggestions", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ prompt }),
      signal,
    });
    const data: string[] = await response.json();
    return data;
  },
  count: 3,
});

const runtime = useLocalRuntime(myChatModel, {
  adapters: { suggestion: suggestionAdapter },
});
```

### 外部状态存储运行时

`useExternalStoreRuntime` 提供 `suggestions` 字段，因此你可以直接通过应用状态驱动后续提示词。

```tsx
const [suggestions, setSuggestions] = useState<ThreadSuggestion[]>([]);

const runtime = useExternalStoreRuntime({
  messages,
  onNew,
  suggestions,
});

// Push a follow up after a tool result, a stream chunk, or any app event.
setSuggestions([{ prompt: "Summarize this case" }]);
```

### AI SDK 运行时

`useChatRuntime` 和 `useAISDKRuntime` 接受相同的 `suggestions` 字段，并将其转发到底层外部状态存储。

```tsx
const [suggestions, setSuggestions] = useState<ThreadSuggestion[]>([]);

const runtime = useChatRuntime({ suggestions });
```

它们还接受与本地运行时相同的 `suggestion` 适配器，并通过 `adapters` 传入，因此同一个适配器可以在两种运行时之间复用。设置后，适配器会在每次运行完成后负责管理 `thread.suggestions`，任何静态的 `suggestions` 选项都会被忽略。将其与 `createSuggestionAdapter` 搭配使用，即可内置提示词构建：

```tsx
import { createSuggestionAdapter } from "@assistant-ui/react";
import { useChatRuntime } from "@assistant-ui/ai-sdk";

const runtime = useChatRuntime({
  adapters: {
    suggestion: createSuggestionAdapter({
      async complete({ prompt, signal }) {
        const response = await fetch("/api/suggestions", {
          method: "POST",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify({ prompt }),
          signal,
        });
        return response.json();
      },
    }),
  },
});
```

以下是使用 AI SDK 返回建议字符串的示例路由：

```ts
// app/api/suggestions/route.ts
import { generateObject } from "ai";
import { z } from "zod";

export async function POST(req: Request) {
  const { prompt } = await req.json();

  const { object } = await generateObject({
    model: yourModel,
    schema: z.object({
      suggestions: z.array(z.string()).min(1).max(5),
    }),
    prompt,
  });

  return Response.json(object.suggestions);
}
```

本地运行时会在新运行开始时清除建议。外部状态存储运行时会保留你推送的状态，因此建议的生命周期由你控制。在 AI SDK 运行时上使用 `adapters.suggestion` 后，建议会在运行开始时清除，并在运行完成后重新生成，与本地运行时的行为一致。

### 渲染运行时建议

运行时建议会存储在 `thread.suggestions` 中，除非静态的 `Suggestions(...)` 配置覆盖了该作用域，否则 `ThreadPrimitive.Suggestions` 会读取这些建议。shadcn 注册表提供了 `ThreadFollowupSuggestions`，用于常见的单行胶囊式布局。如果需要自定义布局，可以自行读取该数组：

```tsx
import { useAuiState, ThreadPrimitive, AuiIf } from "@assistant-ui/react";

function FollowUps() {
  const suggestions = useAuiState((s) => s.thread.suggestions);
  return (
    <AuiIf condition={(s) => !s.thread.isEmpty && !s.thread.isRunning}>
      <div className="flex gap-2">
        {suggestions.map((s, i) => (
          <ThreadPrimitive.Suggestion key={i} prompt={s.prompt} send>
            {s.title ?? s.prompt}
            {s.label && (
              <span className="text-muted-foreground ms-1">{s.label}</span>
            )}
          </ThreadPrimitive.Suggestion>
        ))}
      </div>
    </AuiIf>
  );
}
```

## 响应应用状态

你可以根据应用状态动态更改静态建议列表：

```tsx
import { useMemo } from "react";

function MyRuntimeProvider({ children }: { children: React.ReactNode }) {
  const runtime = useChatRuntime();
  const user = useUser(); // Your user hook

  const suggestions = useMemo(() => {
    if (user.isPremium) {
      return [
        "Analyze my business data",
        "Generate a detailed report",
        "Create a custom workflow",
      ];
    }
    return [
      "What can you do?",
      "Tell me a joke",
      "Help me get started",
    ];
  }, [user.isPremium]);

  const config = AuiConfig({
    tools: Tools({ toolkit: myToolkit }),
    suggestions: Suggestions(suggestions),
  });

  return (
    <AssistantRuntimeProvider runtime={runtime} config={config}>
      {children}
    </AssistantRuntimeProvider>
  );
}
```

## 最佳实践

1. **保持建议简洁**：使用清晰、可执行的提示词，让用户一眼就能理解
2. **展示功能**：使用建议突出助手的核心功能
3. **提供多样性**：针对不同使用场景提供建议
4. **复杂建议使用对象格式**：需要分别设置标题和描述时，请使用对象格式
5. **限制数量**：建议使用 3–6 条，以免让用户感到不知所措
6. **确保可执行**：每条建议都应引导用户进行有意义的交互

## 从 `ThreadPrimitive.Suggestion` 迁移

如果你的代码库使用内联的 `ThreadPrimitive.Suggestion` 组件（该组件通过硬编码的 `prompt` / `send` props 一次渲染一条建议），可以迁移到由运行时驱动的 `Suggestions()` API，以便集中配置。内联组件仍受支持，但当建议需要动态更新时，由运行时驱动的方式具有更好的扩展性。

### 内联形式

```tsx
<ThreadPrimitive.Suggestion
  prompt="What's the weather?"
  send
/>
```

### 由运行时驱动的形式

1. 在运行时提供程序的 `config` 中配置建议：

```tsx
AuiConfig({
  suggestions: Suggestions(["What's the weather?"]),
});
```

2. 使用原语显示建议：

```tsx
<ThreadPrimitive.Suggestions>
  {() => <SuggestionItem />}
</ThreadPrimitive.Suggestions>
```

新 API 提供：
- **集中配置**：在运行时提供程序中定义一次建议
- **更好的关注点分离**：将配置与展示分离
- **类型安全**：完整支持 TypeScript
- **一致性**：遵循与 Tools API 相同的模式
