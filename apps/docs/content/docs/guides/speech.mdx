assistant-ui 通过 `SpeechSynthesisAdapter` 接口支持文本转语音。配置语音适配器后，用户可以触发任意助手消息的播放。

Speech 是朗读模式：一次朗读一条消息，将文本转换为音频。如需实时双工对话，请参阅 [Realtime Voice](/docs/guides/voice)。如需通过按住说话将语音输入到输入框，请参阅 [Dictation](/docs/guides/dictation)。

## SpeechSynthesisAdapter

该适配器只有一个方法。其类型定义位于 `@assistant-ui/core`，并从 `@assistant-ui/react` 重新导出：

```tsx
import type { SpeechSynthesisAdapter } from "@assistant-ui/react";

type SpeechSynthesisAdapter = {
  speak: (text: string) => SpeechSynthesisAdapter.Utterance;
};
```

`speak` 接收助手消息的纯文本，并返回一个 `Utterance`：

```tsx
namespace SpeechSynthesisAdapter {
  type Status =
    | { type: "starting" | "running" }
    | {
        type: "ended";
        reason: "finished" | "cancelled" | "error";
        error?: unknown;
      };

  type Utterance = {
    status: Status;
    cancel: () => void;
    subscribe: (callback: () => void) => Unsubscribe;
  };
}
```

## WebSpeechSynthesisAdapter

内置适配器使用浏览器的 Web Speech API（`SpeechSynthesis` / `SpeechSynthesisUtterance`）：

```tsx
import { WebSpeechSynthesisAdapter } from "@assistant-ui/react";

const runtime = useChatRuntime({
  adapters: {
    speech: new WebSpeechSynthesisAdapter(),
  },
});
```

提供语音适配器后，`capabilities.speech` 会自动设置为 `true`。

## UI：ActionBarPrimitive.Speak

默认操作栏不包含语音按钮。将 `ActionBarPrimitive.Speak` 和 `ActionBarPrimitive.StopSpeaking` 添加到助手消息操作栏中：

```tsx
import { ActionBarPrimitive, AuiIf } from "@assistant-ui/react";
import { AudioLinesIcon, StopCircleIcon } from "lucide-react";

const AssistantActionBar = () => {
  return (
    <ActionBarPrimitive.Root>
      <AuiIf condition={(s) => s.message.speech == null}>
        <ActionBarPrimitive.Speak>
          <AudioLinesIcon />
        </ActionBarPrimitive.Speak>
      </AuiIf>
      <AuiIf condition={(s) => s.message.speech != null}>
        <ActionBarPrimitive.StopSpeaking>
          <StopCircleIcon />
        </ActionBarPrimitive.StopSpeaking>
      </AuiIf>
      <ActionBarPrimitive.Copy />
    </ActionBarPrimitive.Root>
  );
};
```

未配置语音适配器时，`ActionBarPrimitive.Speak` 会被禁用。播放过程中，`message.speech` 保存当前语音状态，因此 UI 可以切换为 `StopSpeaking`。

## 自定义适配器

实现 `SpeechSynthesisAdapter`，即可调用任意外部 TTS 提供商。从 API 获取音频，使用 `HTMLAudioElement` 播放，并通过 `subscribe` 驱动语音状态：

```tsx title="lib/custom-tts-adapter.ts"
import type { SpeechSynthesisAdapter } from "@assistant-ui/react";

export class CustomTTSAdapter implements SpeechSynthesisAdapter {
  constructor(private apiUrl: string) {}

  speak(text: string): SpeechSynthesisAdapter.Utterance {
    const subscribers = new Set<() => void>();
    let status: SpeechSynthesisAdapter.Status = { type: "starting" };
    let audio: HTMLAudioElement | null = null;

    const notify = () => {
      for (const cb of subscribers) cb();
    };

    const finish = (
      reason: "finished" | "cancelled" | "error",
      error?: unknown,
    ) => {
      if (status.type === "ended") return;
      status = { type: "ended", reason, error };
      notify();
    };

    fetch(this.apiUrl, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ text }),
    })
      .then((res) => res.blob())
      .then((blob) => {
        if (status.type === "ended") return;
        audio = new Audio(URL.createObjectURL(blob));
        status = { type: "running" };
        notify();
        audio.onended = () => finish("finished");
        audio.onerror = (e) => finish("error", e);
        audio.play().catch((err) => finish("error", err));
      })
      .catch((err) => finish("error", err));

    return {
      get status() {
        return status;
      },
      cancel: () => {
        audio?.pause();
        finish("cancelled");
      },
      subscribe: (cb) => {
        subscribers.add(cb);
        return () => subscribers.delete(cb);
      },
    };
  }
}
```

将其配置到与内置适配器相同的 `adapters.speech` 插槽：

```tsx
import { CustomTTSAdapter } from "@/lib/custom-tts-adapter";

const runtime = useChatRuntime({
  adapters: {
    speech: new CustomTTSAdapter("/api/tts"),
  },
});
```

任何提供商的 TTS 都可以采用这种形式（例如 OpenAI、ElevenLabs、云语音 API 等）。请让服务器路由负责管理 API 密钥；适配器只需要一个返回音频字节的 URL。
