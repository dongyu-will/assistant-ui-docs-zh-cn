在助手消息上显示流性能指标——时长、每秒 Token 数和 TTFT（首个 Token 的耗时）。

<Callout type="warn">
  此功能为实验性功能。`useMessageTiming()` API 以及跟踪字段集合未来版本可能会发生变化。
</Callout>

<Callout type="info">
  [`MessageTiming`](/elements/message-timing) 注册表组件提供了开箱即用的徽章 + 弹出层 UI。本指南介绍底层的 `useMessageTiming()` hook，用于自定义实现和特定运行时的配置。
</Callout>

## 读取计时数据

在消息组件中使用 `useMessageTiming()` 访问计时数据：

```tsx
import type { FC } from "react";
import { useMessageTiming } from "@assistant-ui/react";

const MessageTimingDisplay: FC = () => {
  const timing = useMessageTiming();
  if (!timing?.totalStreamTime) return null;

  const formatMs = (ms: number) =>
    ms < 1000 ? `${Math.round(ms)}ms` : `${(ms / 1000).toFixed(2)}s`;

  return (
    <span className="text-xs text-muted-foreground">
      {formatMs(timing.totalStreamTime)}
      {timing.tokensPerSecond !== undefined &&
        ` · ${timing.tokensPerSecond.toFixed(1)} tok/s`}
    </span>
  );
};
```

将其放在 `MessagePrimitive.Root` 内，通常位于操作栏附近：

```tsx {8}
const AssistantMessage: FC = () => {
  return (
    <MessagePrimitive.Root>
      <MessagePrimitive.Parts>{...}</MessagePrimitive.Parts>
      <ActionBarPrimitive.Root>
        <ActionBarPrimitive.Copy />
        <ActionBarPrimitive.Reload />
        <MessageTimingDisplay />
      </ActionBarPrimitive.Root>
    </MessagePrimitive.Root>
  );
};
```

### `useMessageTiming()` 返回字段

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `streamStartTime` | `number` | 流开始时的 Unix 时间戳 |
| `firstTokenTime` | `number?` | 首个文本 Token 的耗时（毫秒） |
| `totalStreamTime` | `number?` | 流的总时长（毫秒） |
| `tokenCount` | `number?` | 从消息元数据 usage 中获取的输出 Token 数 |
| `tokensPerSecond` | `number?` | 吞吐量（Token/秒），在 Token 使用量可用时提供 |
| `totalChunks` | `number` | 接收到的流区块总数 |
| `toolCallCount` | `number` | 工具调用次数 |

## 运行时支持

| 运行时 | 支持 | 说明 |
|---------|:-:|-------|
| [数据流](/docs/runtimes/custom/data-stream) | 是 | 通过 `AssistantMessageAccumulator` 自动处理 |
| AI SDK（`useChatRuntime`） | 是 | 通过客户端跟踪自动处理 |
| 本地（`useLocalRuntime`） | 是 | 在 `ChatModelRunResult.metadata` 中传入计时数据 |
| ExternalStore | 是 | 在 `ThreadMessageLike.metadata` 中传入计时数据 |
| LangGraph | 是 | 通过客户端跟踪自动处理 |
| AG-UI | 是 | 通过客户端跟踪自动处理 |
| OpenCode | 是 | 通过客户端跟踪自动处理 |

### 数据流

`AssistantMessageAccumulator` 内部会自动跟踪计时数据。无需配置。

```tsx
import { useDataStreamRuntime } from "@assistant-ui/react-data-stream";

const runtime = useDataStreamRuntime({ api: "/api/chat" });
// useMessageTiming() works out of the box
```

### AI SDK（`useChatRuntime`）

客户端会通过观察流式状态转换和内容变化自动跟踪计时数据。每个流完成时，计时数据会最终确定。

<Callout type="warn">
  `tokenCount` 和 `tokensPerSecond` 需要在 AI SDK 路由中从 `finish` 或 `finish-step` 获取 usage 元数据。如果未发出 usage 元数据，时长和 TTFT 指标仍然有效，但会省略基于 Token 的指标。
</Callout>

```tsx
import { useChatRuntime } from "@assistant-ui/ai-sdk";

const runtime = useChatRuntime();
// useMessageTiming() works out of the box
```

### 本地（`useLocalRuntime`）

在 `ChatModelRunResult` 的 `metadata` 字段中传入计时数据：

```tsx
import type { ChatModelAdapter } from "@assistant-ui/react";

const myAdapter: ChatModelAdapter = {
  async run({ messages, abortSignal }) {
    const startTime = Date.now();
    const result = await callMyAPI(messages, abortSignal);
    const totalStreamTime = Date.now() - startTime;

    return {
      content: [{ type: "text", text: result.text }],
      metadata: {
        timing: {
          streamStartTime: startTime,
          totalStreamTime,
          tokenCount: result.usage?.completionTokens,
          tokensPerSecond:
            result.usage?.completionTokens
              ? result.usage.completionTokens / (totalStreamTime / 1000)
              : undefined,
          totalChunks: 1,
          toolCallCount: 0,
        },
      },
    };
  },
};
```

### ExternalStore（`useExternalStoreRuntime`）

在 `ThreadMessageLike` 消息的 `metadata.timing` 字段中传入计时数据：

```tsx
import type { ThreadMessageLike } from "@assistant-ui/react";

const message: ThreadMessageLike = {
  role: "assistant",
  content: [{ type: "text", text: fullText }],
  metadata: {
    timing: {
      streamStartTime: startTime,
      firstTokenTime,
      totalStreamTime,
      tokenCount,
      tokensPerSecond,
      totalChunks: chunks,
      toolCallCount: 0,
    },
  },
};
```

### LangGraph（`useLangGraphRuntime`）

客户端会通过观察流式状态转换和 `LangChainMessage` 内容变化自动跟踪计时数据。无需配置。

```tsx
import { useLangGraphRuntime } from "@assistant-ui/react-langgraph";

const runtime = useLangGraphRuntime({ stream: myStream });
// useMessageTiming() works out of the box
```

### AG-UI（`useAgUiRuntime`）

AG-UI 运行聚合器会在客户端自动跟踪计时数据。每条发出的消息都包含根据流区块观察结果计算出的计时元数据。

```tsx
import { useMemo } from "react";
import { useAgUiRuntime } from "@assistant-ui/react-ag-ui";
import { HttpAgent } from "@ag-ui/client";

const agent = useMemo(
  () => new HttpAgent({ url: "http://localhost:8000/agent" }),
  [],
);
const runtime = useAgUiRuntime({ agent });
// useMessageTiming() works out of the box
```

### OpenCode（`useOpenCodeRuntime`）

客户端会通过观察 `OpenCodeThreadState` 转换和助手消息内容增量自动跟踪计时数据。无需配置。

```tsx
import { useOpenCodeRuntime } from "@assistant-ui/react-opencode";

const runtime = useOpenCodeRuntime();
// useMessageTiming() works out of the box
```

## API 参考

### `useMessageTiming()`

```tsx
const timing: MessageTiming | undefined = useMessageTiming();
```

返回当前助手消息的计时元数据；对于非助手消息或没有可用计时数据的情况，返回 `undefined`。

必须在 `MessagePrimitive.Root` 上下文中使用。
