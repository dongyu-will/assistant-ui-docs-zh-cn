## 三种语音模式

assistant-ui 提供三种相关但各不相同的语音能力。请选择与产品界面相匹配的模式：

| 模式 | 指南 | 适配器 | 方向 |
|------|-------|---------|-----------|
| **实时双工** | 本页 | `RealtimeVoiceAdapter` | 音频 ↔ 音频，实时会话 |
| **按住说话听写** | [听写](/docs/guides/dictation) | `DictationAdapter` | 音频 → 输入框中的文本 |
| **朗读** | [语音](/docs/guides/speech) | `SpeechSynthesisAdapter` | 文本 → 单条消息的音频 |

实时语音是唯一同时负责两个方向的模式。听写会填充输入框；语音会朗读已完成的消息。

## RealtimeVoiceAdapter

实现 `RealtimeVoiceAdapter` 即可连接任意语音提供商。契约定义在 `@assistant-ui/core` 中，并从 `@assistant-ui/react` 重新导出：

```tsx
import type { RealtimeVoiceAdapter } from "@assistant-ui/react";

type RealtimeVoiceAdapter = {
  connect: (options: {
    abortSignal?: AbortSignal;
  }) => RealtimeVoiceAdapter.Session;
};
```

会话提供连接状态、静音控制和事件订阅：

```tsx
namespace RealtimeVoiceAdapter {
  type Status =
    | { type: "starting" | "running" }
    | {
        type: "ended";
        reason: "finished" | "cancelled" | "error";
        error?: unknown;
      };

  type Mode = "listening" | "speaking";

  type TranscriptItem = {
    role: "user" | "assistant";
    text: string;
    isFinal?: boolean;
  };

  type Session = {
    status: Status;
    isMuted: boolean;

    disconnect: () => void;
    mute: () => void;
    unmute: () => void;

    onStatusChange: (callback: (status: Status) => void) => Unsubscribe;
    onTranscript: (
      callback: (transcript: TranscriptItem) => void,
    ) => Unsubscribe;
    onModeChange: (callback: (mode: Mode) => void) => Unsubscribe;
    onVolumeChange: (callback: (volume: number) => void) => Unsubscribe;
  };
}
```

会话状态依次从 `starting` → `running` → `ended` 变化。`ended` 状态包含原因：`"finished"`、`"cancelled"` 或 `"error"`（以及可选的 `error` 字段）。

来自 `onTranscript` 的转录文本会自动追加到消息线程中：

- 用户转录文本（`role: "user"`、`isFinal: true`）会成为用户消息。
- 助手转录文本（`role: "assistant"`）会流式传输到助手消息中。该消息会一直保持运行状态，直到 `isFinal: true`。

`onModeChange` 报告 `"listening"`（用户回合）或 `"speaking"`（助手回合）。`onVolumeChange` 报告从 `0` 到 `1` 的实时音量级别，用于语音球等视觉反馈。

## createVoiceSession

实现适配器时，`createVoiceSession` 可以省去手动编写回调集合的样板代码。向它传入连接选项和异步 `setup` 函数；该函数接收 `VoiceSessionHelpers` 并返回 `VoiceSessionControls`：

```tsx
import {
  createVoiceSession,
  type RealtimeVoiceAdapter,
  type VoiceSessionControls,
  type VoiceSessionHelpers,
} from "@assistant-ui/react";

export class MyVoiceAdapter implements RealtimeVoiceAdapter {
  connect(options: {
    abortSignal?: AbortSignal;
  }): RealtimeVoiceAdapter.Session {
    return createVoiceSession(options, async (helpers: VoiceSessionHelpers) => {
      const client = await MyVoiceClient.connect();

      client.on("open", () => helpers.setStatus({ type: "running" }));
      client.on("close", () => helpers.end("finished"));
      client.on("error", (err: unknown) => helpers.end("error", err));
      client.on("transcript", (item) => helpers.emitTranscript(item));
      client.on("mode", (mode) => helpers.emitMode(mode));
      client.on("volume", (v: number) => helpers.emitVolume(v));

      const controls: VoiceSessionControls = {
        disconnect: () => client.close(),
        mute: () => client.setMuted(true),
        unmute: () => client.setMuted(false),
      };
      return controls;
    });
  }
}
```

`VoiceSessionHelpers` 提供以下功能：

| 辅助函数 | 作用 |
|--------|------|
| `setStatus(status)` | 更新会话状态（例如更新为 `{ type: "running" }`） |
| `end(reason, error?)` | 结束会话并清理订阅者 |
| `emitTranscript(item)` | 将转录文本推送到线程中 |
| `emitMode(mode)` | 报告 `"listening"` 或 `"speaking"` |
| `emitVolume(volume)` | 报告从 `0` 到 `1` 的音量级别 |
| `isDisposed()` | 拆除后跳过事件 |

`createVoiceSession` 会为你处理状态跟踪、静音状态、AbortSignal 断开连接，以及所有 `on*` 订阅。

## 配置

在运行时中传入 `RealtimeVoiceAdapter` 实现：

```tsx
const runtime = useChatRuntime({
  adapters: {
    voice: new MyVoiceAdapter({ /* provider options */ }),
  },
});
```

提供语音适配器后，`capabilities.voice` 会自动设置为 `true`。

## React Hooks

这些 Hook 从 `@assistant-ui/react` 导出，并读取当前线程中的活动语音会话。

### useVoiceState

返回当前 `VoiceSessionState`；没有活动会话时返回 `undefined`：

```tsx
import { useVoiceState } from "@assistant-ui/react";

const voiceState = useVoiceState();
// voiceState?.status.type: "starting" | "running" | "ended"
// voiceState?.isMuted: boolean
// voiceState?.mode: "listening" | "speaking"
```

`VoiceSessionState` 的值为：

```tsx
type VoiceSessionState = {
  readonly status: RealtimeVoiceAdapter.Status;
  readonly isMuted: boolean;
  readonly mode: RealtimeVoiceAdapter.Mode;
};
```

### useVoiceVolume

独立于会话状态订阅实时音频级别：

```tsx
import { useVoiceVolume } from "@assistant-ui/react";

const volume = useVoiceVolume(); // number from 0 to 1
```

### useVoiceControls

返回用于驱动会话的方法：

```tsx
import { useVoiceControls } from "@assistant-ui/react";

const { connect, disconnect, mute, unmute } = useVoiceControls();
```

### 无头控制栏

需要自定义布局时，可以使用这些 Hook 构建自己的控制项：

```tsx
import { useVoiceState, useVoiceControls } from "@assistant-ui/react";
import { PhoneIcon, PhoneOffIcon, MicIcon, MicOffIcon } from "lucide-react";

function VoiceControls() {
  const voiceState = useVoiceState();
  const { connect, disconnect, mute, unmute } = useVoiceControls();

  const isRunning = voiceState?.status.type === "running";
  const isStarting = voiceState?.status.type === "starting";
  const isMuted = voiceState?.isMuted ?? false;

  if (!isRunning && !isStarting) {
    return (
      <button onClick={() => connect()}>
        <PhoneIcon /> Connect
      </button>
    );
  }

  return (
    <>
      <button onClick={() => (isMuted ? unmute() : mute())} disabled={!isRunning}>
        {isMuted ? <MicOffIcon /> : <MicIcon />}
        {isMuted ? "Unmute" : "Mute"}
      </button>
      <button onClick={() => disconnect()}>
        <PhoneOffIcon /> Disconnect
      </button>
    </>
  );
}
```

## 语音 UI 组件

最快的方式是使用样式化的 `voice` 注册表组件。它提供 `VoiceControl` 栏、静音和断开连接按钮、状态指示器，以及基于上述 Hook 构建的动画 `VoiceOrb`。

### 安装

<InstallCommand shadcn={["voice"]} />

这会将 `/components/assistant-ui/elements/voice.tsx` 添加到项目中。请根据需要调整样式。

### 与运行时搭配使用

```tsx title="app/page.tsx"
import { Thread } from "@/components/assistant-ui/elements/thread.aui";
import { VoiceControl } from "@/components/assistant-ui/elements/voice.aui";
import { AuiIf } from "@assistant-ui/react";

export default function Chat() {
  return (
    <div className="flex h-full flex-col">
      <AuiIf condition={(s) => s.thread.capabilities.voice}>
        <VoiceControl />
      </AuiIf>
      <div className="min-h-0 flex-1">
        <Thread />
      </div>
    </div>
  );
}
```

有关结构、变体和状态示例，请参阅[语音球页面](/elements/orb)。

## 示例：LiveKit

[LiveKit](https://livekit.io/) 通过支持转录的 WebRTC 房间提供实时语音。浏览器适配器加入一个房间；单独的助手工作进程（STT、LLM、TTS）加入同一个房间。如果房间中没有助手，客户端虽然可以连接，但没有可对话的对象。

[`with-livekit`](https://github.com/assistant-ui/assistant-ui/tree/main/examples/with-livekit) 示例展示了完整的连接方式：

1. **适配器**（`examples/with-livekit/lib/livekit-voice-adapter.ts`）：`LiveKitVoiceAdapter` 实现 `RealtimeVoiceAdapter`。`connect` 调用 `createVoiceSession`，连接 LiveKit `Room`，启用本地麦克风，附加远程音频轨道，并将房间事件映射到辅助函数（`setStatus`、`end`、`emitMode`、`emitVolume`、`emitTranscript`）。
2. **令牌路由**（`examples/with-livekit/app/api/livekit-token/route.ts`）：为隔离房间生成有效期十分钟的令牌，使密钥不会暴露在客户端。
3. **助手工作进程**（`examples/with-livekit/agent/`）：加入房间并运行语音流水线的 Python LiveKit Agents 进程。

最小运行时连接代码：

```tsx
import { LiveKitVoiceAdapter } from "@/lib/livekit-voice-adapter";

const runtime = useChatRuntime({
  adapters: {
    voice: new LiveKitVoiceAdapter({
      url: process.env.NEXT_PUBLIC_LIVEKIT_URL!,
      token: async () => {
        const res = await fetch("/api/livekit-token", { method: "POST" });
        if (!res.ok) throw new Error("Failed to create a LiveKit session");
        const { token } = await res.json();
        return token;
      },
    }),
  },
});
```

请直接克隆示例以获取适配器源代码、令牌端点和助手工作进程，而不要从头重新实现完整的 LiveKit 事件映射。

令牌路由仅在 `Sec-Fetch-Site` 为 `same-origin` 或 `none` 时接受请求；对于省略 Fetch Metadata 的客户端，则会回退为将 `Origin` 标头与请求 URL 进行比较。在反向代理后运行时，该回退逻辑要求请求 URL 保留公开的协议和主机。

<Callout type="warn">
  请求上下文检查并不等同于身份验证。部署前，请在令牌路由中要求应用会话，并应用持久的速率限制，避免匿名调用方消耗语音容量。
</Callout>

你也可以使用 CLI 搭建该示例：

```bash
npx assistant-ui create my-app -e with-livekit
```
