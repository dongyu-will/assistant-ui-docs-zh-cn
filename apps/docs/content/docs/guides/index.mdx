指南是基于 assistant-ui 构建特定功能的任务导向型教程。它们位于[原语](/docs/primitives)（底层构建块）和[组件](/elements/thread)（预设样式的安装项）之间——当你明确要构建什么功能，并需要推荐实现模式时，可以选择相应的指南。

## 输入框

为消息输入框扩展文件附件、提及、斜杠命令、语音和引用功能。

<Cards>
  <Card title="附件" href="/docs/guides/attachments">
    允许用户在消息中附加文件、图像和文档。涵盖上传适配器、验证以及类型化的 `attachmentAddError` 事件。
  </Card>
  <Card title="提及" href="/docs/guides/mentions">
    `@` 风格的触发器，可将指令插入输入框。介绍同步和异步搜索模式。
  </Card>
  <Card title="斜杠命令" href="/docs/guides/slash-commands">
    `/` 风格的命令，支持参数、异步加载以及与提及组合使用。
  </Card>
  <Card title="引用" href="/docs/guides/quoting">
    选择工具栏、编程式 `setQuote`，以及将引用上下文转发给 LLM。
  </Card>
  <Card title="听写" href="/docs/guides/dictation">
    使用 `DictationAdapter` 和 `ComposerPrimitive.Dictate` 将语音转换为文本并输入到输入框中。
  </Card>
</Cards>

## 消息

自定义消息的渲染、编辑、分支和建议方式。

<Cards>
  <Card title="建议" href="/docs/guides/suggestions">
    欢迎屏幕提示、动态建议，以及 `AuiIf` 空线程模式。
  </Card>
  <Card title="编辑" href="/docs/guides/editing">
    使用 `UserEditComposer`、`beginEdit()` 编辑用户消息，以及处理流式传输期间的编辑行为。
  </Card>
  <Card title="分支" href="/docs/guides/branching">
    使用 `BranchPickerPrimitive` 浏览消息的其他版本，重新加载，并直接通过分支 ID 导航。
  </Card>
  <Card title="消息计时" href="/docs/guides/message-timing">
    使用 `useMessageTiming`（实验性）显示响应时长和流式传输计时。
  </Card>
</Cards>
