## 概述

此示例演示如何将 assistant-ui 与 Vercel AI SDK 集成，用于构建适合生产环境的聊天界面。它展示了一个完整的聊天应用，包含线程管理、消息持久化，以及用于查看对话历史记录的可折叠侧边栏。

## 功能

- **AI SDK 集成**：与 Vercel 的 `ai` 包无缝连接
- **线程管理**：创建、切换和删除对话线程
- **可折叠侧边栏**：切换侧边栏可见性，专注于聊天
- **模型选择器**：在不同 AI 模型之间切换
- **响应式设计**：适配移动设备，采用基于 sheet 的导航
- **实时流式输出**：实时传输消息，并显示加载状态

## 快速开始

```bash
npm install @assistant-ui/react @assistant-ui/ai-sdk ai@^6 @ai-sdk/react@^3 @ai-sdk/openai
```

## 代码

### 客户端组件

```tsx
"use client";

import { AssistantRuntimeProvider } from "@assistant-ui/react";
import { Thread } from "@/components/assistant-ui/elements/thread.aui";
import { useChatRuntime } from "@assistant-ui/ai-sdk";

export default function Chat() {
  const runtime = useChatRuntime();

  return (
    <AssistantRuntimeProvider runtime={runtime}>
      <div className="flex h-full">
        <Sidebar />
        <main className="flex-1">
          <Thread />
        </main>
      </div>
    </AssistantRuntimeProvider>
  );
}
```

### API 路由

```ts
// app/api/chat/route.ts
import { openai } from "@ai-sdk/openai";
import { streamText, convertToModelMessages } from "ai";
import type { UIMessage } from "ai";

export async function POST(req: Request) {
  const { messages }: { messages: UIMessage[] } = await req.json();

  const result = streamText({
    model: openai("gpt-5.6-luna"),
    messages: await convertToModelMessages(messages),
    // Optional: Add system prompt
    system: "You are a helpful assistant.",
  });

  return result.toUIMessageStreamResponse();
}
```

### 关键集成点

| 钩子/函数 | 用途 |
|---------------|---------|
| `useChatRuntime` | 将 AI SDK 连接到 assistant-ui |
| `streamText` | 在服务器端生成流式响应 |
| `toUIMessageStreamResponse` | 将流转换为 Response 对象 |

### 添加持久化

<Callout type="info">
  `useChatRuntime()` 本身不会在重新加载后持久化线程。下面的代码片段是一个最小化的服务器端保存示例。若要实现完整的线程持久化（重新加载历史记录、创建分支），请使用 [Assistant Cloud](/docs/cloud) 或[自定义持久化适配器](/docs/integrations/persistence/custom-adapter)。
</Callout>

要持久化对话，请添加数据库并修改 API 路由。`useChatRuntime` 会在请求体中以 `id` 发送当前线程 ID，因此你可以将其与 `messages` 一起读取：

```ts
// In your POST /api/chat handler:
const { id: threadId, messages } = await req.json();

// Save the latest user message
const last = messages.at(-1);
if (last) {
  await db.messages.create({
    threadId,
    role: last.role,
    parts: last.parts,
  });
}

// Load messages when opening a thread (e.g., from a ThreadHistoryAdapter):
const savedMessages = await db.messages.findMany({ threadId });
```
