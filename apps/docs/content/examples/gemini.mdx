## 概览

Gemini Clone 展示了如何重新设计 assistant-ui 的样式，使其匹配 Google Gemini 的当前界面。空状态会将单行问候语置于柔和的蓝色光晕上方并居中显示，空状态和聊天状态共用单行胶囊式输入框。助手回复以无头像的全宽 Markdown 形式呈现，用户消息则位于圆角灰色气泡中。

## 功能

- **居中问候语**：一条“How can I help you today?”标题，置于模糊的径向光晕上方并居中显示。
- **单行输入框**：一个 32px 的胶囊式输入框，在同一行容纳 `+` 菜单、输入框、模型选择器、麦克风和发送按钮。
- **组合式 `+` 菜单**：“Add photos & files”与 Deep Research、Canvas、Create image 和 Guided Learning 工具并列显示。
- **模型选择器**：Fast 和 Thinking 两个模型，各自带有简短描述，当前模型旁显示勾选标记。
- **发送状态**：为空时显示禁用的灰色箭头，就绪时显示蓝色箭头，响应进行流式输出时显示停止方块。
- **无头像回复**：助手消息以全宽 Markdown 形式呈现，悬停时显示操作栏。
- **灰色用户气泡**：一个 `rounded-3xl` 暖灰色气泡，右对齐，悬停时显示复制和编辑操作。

## 快速开始

```bash
npx assistant-ui add thread
```

## 代码

空状态和聊天状态会渲染相同的 `Composer`。它是一个 flex 列布局：顶部是可选的附件行，下面是单行操作区，输入框位于 `flex-1` 中间，控件在其周围沿底部对齐。

```tsx
import {
  AuiIf,
  ComposerPrimitive,
  ThreadPrimitive,
} from "@assistant-ui/react";

export const Gemini = () => (
  <ThreadPrimitive.Root className="bg-[#fdfcfc] dark:bg-[#131314]">
    <AuiIf condition={(s) => s.thread.isEmpty}>
      <EmptyState />
    </AuiIf>
    <AuiIf condition={(s) => !s.thread.isEmpty}>
      <ThreadPrimitive.Viewport>
        <ThreadPrimitive.Messages components={{ Message: ChatMessage }} />
        <ThreadPrimitive.ViewportFooter className="sticky bottom-0">
          <Composer />
        </ThreadPrimitive.ViewportFooter>
      </ThreadPrimitive.Viewport>
    </AuiIf>
  </ThreadPrimitive.Root>
);

const Composer = () => (
  <ComposerPrimitive.Root className="flex flex-col rounded-4xl bg-white p-3 shadow-[0_2px_10px_-2px_rgba(0,0,0,0.18)] dark:bg-[#1e1f20]">
    <AuiIf condition={(s) => s.composer.attachments.length > 0}>
      <ComposerPrimitive.Attachments
        components={{ Attachment: GeminiAttachment }}
      />
    </AuiIf>
    <div className="flex items-end gap-1">
      <PlusMenu />
      <ComposerPrimitive.Input
        placeholder="Ask Gemini"
        className="flex-1 resize-none bg-transparent text-[17px]"
      />
      <ModelPicker />
      <VoiceButton />
      <SendButton />
    </div>
  </ComposerPrimitive.Root>
);
```

### 发送状态

通过 `AuiIf`，末尾插槽会在 Send 和 Cancel 之间切换。输入框为空时，`ComposerPrimitive.Send` 会自动禁用自身，因此禁用、就绪和运行中的外观都由状态驱动，无需手动切换 class：

```tsx
{/* Send: disabled grey when empty, blue when there is text */}
<AuiIf condition={(s) => !s.thread.isRunning}>
  <ComposerPrimitive.Send className="bg-[#d3e3fd] text-[#062e6f] disabled:bg-[#e8eaed] disabled:text-[#1f1f1f]/40">
    <ArrowUpIcon />
  </ComposerPrimitive.Send>
</AuiIf>
{/* Cancel: stop square while a response streams */}
<AuiIf condition={(s) => s.thread.isRunning}>
  <ComposerPrimitive.Cancel className="bg-[#d3e3fd] text-[#062e6f]">
    <span className="size-3 rounded-[3px] bg-current" />
  </ComposerPrimitive.Cancel>
</AuiIf>
```

### 组合式 `+` 菜单

`+` 按钮会为附件和工具打开同一个菜单。`ComposerPrimitive.AddAttachment` 通过 `render` prop 作为第一项渲染，因此选择它会打开文件对话框并关闭菜单：

```tsx
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuSeparator,
  DropdownMenuTrigger,
} from "@/components/ui/dropdown-menu";

<DropdownMenu>
  <DropdownMenuTrigger>
    <PlusIcon />
  </DropdownMenuTrigger>
  <DropdownMenuContent align="start" side="bottom">
    <DropdownMenuItem render={<ComposerPrimitive.AddAttachment />}>
      <Paperclip /> Add photos & files
    </DropdownMenuItem>
    <DropdownMenuSeparator />
    <DropdownMenuItem>
      <Telescope /> Deep Research
    </DropdownMenuItem>
    <DropdownMenuItem>
      <PencilRuler /> Canvas
    </DropdownMenuItem>
    {/* Create image, Guided Learning ... */}
  </DropdownMenuContent>
</DropdownMenu>
```

### 环境光晕

空状态会在问候语和输入框后方放置一个模糊的椭圆。它仅用于装饰，因此设置为 `pointer-events-none` 和 `aria-hidden`：

```tsx
<div className="relative flex grow items-center justify-center">
  <div
    aria-hidden="true"
    className="pointer-events-none absolute top-1/2 left-1/2 h-[330px] w-[720px] -translate-x-1/2 -translate-y-1/2 bg-[radial-gradient(closest-side,#a9d1fb,transparent)] opacity-70 blur-[55px] dark:bg-[radial-gradient(closest-side,#1d4068,transparent)] dark:opacity-65"
  />
  <div className="relative z-10">
    <h1 className="text-center text-4xl">How can I help you today?</h1>
    <Composer />
  </div>
</div>
```

### 消息

助手回复不包含头像；Markdown 会占据完整内容宽度，操作栏（反馈、复制、重新生成、更多）会在悬停时淡入。用户消息位于右对齐的圆角灰色气泡中，其左侧提供复制和编辑操作：

```tsx
<div className="max-w-[75%] rounded-3xl bg-[#f2f0f0] px-5 py-3 dark:bg-[#333537]">
  <MessagePrimitive.Parts components={{ Text: MarkdownText }} />
</div>
```
