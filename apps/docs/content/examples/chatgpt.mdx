## 概述

ChatGPT Clone 演示了如何自定义 assistant-ui，使其匹配 OpenAI 的 ChatGPT 界面。此版本复刻了当前 chatgpt.com 的布局：居中的欢迎输入框、带工具提示的附件/听写/语音控件、带有 Copy + Edit 操作的高对比度用户气泡，以及始终可见的助手操作栏，其中包含点赞、分享、朗读、重新加载等更多操作。

## 功能

- **主题感知**：白色浅色模式（`#ffffff`）和黑色深色模式（`#000000`），搭配 ChatGPT 风格的 `#212121` 输入框表面
- **居中的空状态**："我们从哪里开始？"标题与输入框一起渲染在视口中心上方
- **带工具提示的输入框控件**：添加附件、听写和语音模式按钮采用 ChatGPT 的圆形控件，并在悬停时显示工具提示
- **四状态主操作**：Cancel（运行中）、StopDictation（录音中）、Send（输入中）、Dictate + 语音模式（空闲）
- **助手操作栏**：始终可见——Copy、Good response、Bad response、Read aloud、Share、Regenerate、More
- **用户气泡**：右对齐的高对比度气泡，悬停时在下方显示 Copy + Edit 操作
- **粘性页脚**：在聊天底部显示输入框和“ChatGPT 可能会犯错”免责声明

## 快速开始

```bash
npx assistant-ui add thread
```

## 代码

ChatGPT 克隆版由 `EmptyState` 和粘性聊天布局组成。两者共享同一个输入框外壳：

```tsx
import {
  AuiIf,
  ThreadPrimitive,
  ComposerPrimitive,
  ActionBarPrimitive,
} from "@assistant-ui/react";
import { PlusIcon } from "lucide-react";
import { TooltipIconButton } from "@/components/assistant-ui/elements/tooltip-icon-button";

export const ChatGPT = () => (
  <ThreadPrimitive.Root className="bg-white text-[#0d0d0d] dark:bg-black dark:text-[#ececec]">
    <AuiIf condition={(s) => s.thread.isEmpty}>
      <EmptyState />
    </AuiIf>
    <AuiIf condition={(s) => !s.thread.isEmpty}>
      <ThreadPrimitive.Viewport>
        <ThreadPrimitive.Messages />
        <ThreadPrimitive.ViewportFooter className="sticky bottom-0">
          <Composer placeholder="Ask anything" />
          <p>ChatGPT can make mistakes. Check important info.</p>
        </ThreadPrimitive.ViewportFooter>
      </ThreadPrimitive.Viewport>
    </AuiIf>
  </ThreadPrimitive.Root>
);

const Composer = ({ placeholder }: { placeholder: string }) => (
  <ComposerPrimitive.Root className="rounded-[28px] border border-[#e5e5e5] bg-white dark:border-transparent dark:bg-[#212121]">
    <div className="flex items-end gap-1">
      <ComposerPrimitive.AddAttachment asChild>
        <TooltipIconButton tooltip="Add photos & files" aria-label="Add attachment">
          <PlusIcon />
        </TooltipIconButton>
      </ComposerPrimitive.AddAttachment>
      <ComposerPrimitive.Input autoFocus rows={1} placeholder={placeholder} />
      <PrimaryAction />
    </div>
  </ComposerPrimitive.Root>
);
```

### 四状态主操作

```tsx
<AuiIf condition={(s) => s.thread.isRunning}>
  <ComposerPrimitive.Cancel />
</AuiIf>
<AuiIf condition={(s) => !s.thread.isRunning && s.composer.dictation != null}>
  <ComposerPrimitive.StopDictation />
</AuiIf>
<AuiIf
  condition={(s) =>
    !s.thread.isRunning && s.composer.dictation == null && !s.composer.isEmpty
  }
>
  <ComposerPrimitive.Send />
</AuiIf>
<AuiIf
  condition={(s) =>
    !s.thread.isRunning && s.composer.dictation == null && s.composer.isEmpty
  }
>
  <ComposerPrimitive.Dictate asChild>
    <TooltipIconButton tooltip="Dictate" aria-label="Dictate">
      <Mic />
    </TooltipIconButton>
  </ComposerPrimitive.Dictate>
  <TooltipIconButton
    tooltip="Use voice mode"
    aria-hidden="true"
    tabIndex={-1}
    className="bg-[#0d0d0d] text-white dark:bg-white dark:text-black"
  >
    <AudioLines />
  </TooltipIconButton>
</AuiIf>
```

这些条件按照优先级顺序互斥（`Cancel > StopDictation > Send > Dictate/voice mode`），因此即使输入框中已有转录文本，也可以暂停听写。

### 用户气泡和操作

```tsx
<MessagePrimitive.Root className="flex flex-col items-end gap-1">
  <div className="max-w-[70%] rounded-[22px] bg-[#0d0d0d] px-4 py-2.5 text-white dark:bg-[#ececec] dark:text-[#0d0d0d]">
    <MessagePrimitive.Parts />
  </div>

  <ActionBarPrimitive.Root autohide="always">
    <ActionBarPrimitive.Copy asChild>
      <TooltipIconButton tooltip="Copy" />
    </ActionBarPrimitive.Copy>
    <ActionBarPrimitive.Edit asChild>
      <TooltipIconButton tooltip="Edit" />
    </ActionBarPrimitive.Edit>
  </ActionBarPrimitive.Root>
</MessagePrimitive.Root>
```

### 颜色调色板

| 元素 | 浅色 | 深色 |
|---------|-------|------|
| 背景 | `#ffffff` | `#000000` |
| 输入框表面 | `#ffffff` | `#212121` |
| 输入框边框 / 边缘 | `#e5e5e5` | `transparent` + 内嵌白色边缘 |
| 主要文本 | `#0d0d0d` | `#ececec` |
| 弱化文本 | `#5d5d5d` | `#afafaf` |
| 用户气泡 | `#0d0d0d`（白色文本） | `#ececec`（`#0d0d0d` 文本） |
| 操作图标 | `#5d5d5d` | `#cdcdcd` |
| 图标悬停背景 | 黑色，7% | 白色，15% |
| 发送 / 语音按钮 | `#0d0d0d`（白色图标） | `#ffffff`（黑色图标） |

### 样式详情

- **输入框**：`rounded-[28px]`，带有浅色模式细边框、深色 `#212121` 表面，以及内嵌的深色模式边缘
- **空布局**：24px/400 标题，输入框上移至中心上方；不显示头像
- **输入框按钮**：36px 圆形控件，带悬停工具提示，并且仅在悬停时改变背景
- **助手操作栏**：32px 控件、8px 圆角、零间距，仅在悬停时改变背景，并为每个操作提供工具提示
- **用户气泡**：`rounded-[22px]`，最大宽度为 70%，使用高对比度主题颜色，悬停时在下方显示 Copy + Edit 操作
