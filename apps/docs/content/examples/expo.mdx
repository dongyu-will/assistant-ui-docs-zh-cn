## 概述

一个使用 Expo 和 `@assistant-ui/react-native` 构建的功能完整的 React Native 聊天应用。该应用演示了基于抽屉的线程管理、OpenAI 响应的流式输出，以及支持深色模式的精致原生 UI。

## 功能

- **原生 UI**：使用 React Native 原语构建，不包含 WebView
- **抽屉式导航**：可滑动的侧边栏，用于管理线程
- **线程管理**：创建、切换和浏览对话
- **流式传输**：通过服务端聊天 API 端点实现实时流式传输
- **深色模式**：自动支持浅色和深色主题
- **键盘处理**：正确集成 `KeyboardAvoidingView`

## 快速开始

```bash
# Clone the repo
git clone https://github.com/assistant-ui/assistant-ui.git
cd assistant-ui

# Install dependencies
pnpm install

# Set your API key
echo 'OPENAI_API_KEY="sk-..."' > examples/with-expo/.env

# Run the example
pnpm --filter with-expo start
```

## 代码

### 运行时设置

运行时使用来自 `@assistant-ui/ai-sdk` 的 `useChatRuntime`，并配合连接到聊天 API 端点的 `AssistantChatTransport`：

```tsx title="hooks/use-app-runtime.ts"
import { useMemo } from "react";
import {
  useChatRuntime,
  AssistantChatTransport,
} from "@assistant-ui/ai-sdk";
import { Platform } from "react-native";
import {
  createAnonymousSessionFetch,
  shouldUseAnonymousSessionFetch,
} from "./anonymous-session-fetch";

const CHAT_API = process.env.EXPO_PUBLIC_CHAT_ENDPOINT_URL ?? "/api/chat";

export function useAppRuntime() {
  const transport = useMemo(
    () =>
      new AssistantChatTransport({
        api: CHAT_API,
        ...(shouldUseAnonymousSessionFetch(CHAT_API, Platform.OS)
          ? { fetch: createAnonymousSessionFetch(CHAT_API) }
          : {}),
      }),
    [],
  );
  return useChatRuntime({ transport });
}
```

托管文档端点会为浏览器演示签发经过签名的匿名会话。原生构建会跳过仅限浏览器的引导流程，应使用内置的 API 路由，或使用专为该应用准备的其他后端。

### 应用布局

`AssistantRuntimeProvider` 将 Expo Router 抽屉布局封装在 `GestureHandlerRootView` 中。该布局还负责字体加载、主题设置、页眉中的“新建聊天”按钮，以及通过 provider 的 `config` 注册工具：

```tsx title="app/_layout.tsx"
import {
  DarkTheme,
  DefaultTheme,
  ThemeProvider,
} from "@react-navigation/native";
import { Drawer } from "expo-router/drawer";
import { StatusBar } from "expo-status-bar";
import "react-native-reanimated";
import { Pressable, useColorScheme } from "react-native";
import { Ionicons } from "@expo/vector-icons";
import { useFonts } from "expo-font";
import { GestureHandlerRootView } from "react-native-gesture-handler";

import {
  AssistantRuntimeProvider,
  AuiConfig,
  useAui,
  Tools,
} from "@assistant-ui/react-native";
import { useAppRuntime } from "@/hooks/use-app-runtime";
import { ThreadListDrawer } from "@/components/thread-list/ThreadListDrawer";
import { expoToolkit } from "@/components/assistant-ui/elements/tools";

function NewChatButton() {
  const aui = useAui();
  const colorScheme = useColorScheme();
  const isDark = colorScheme === "dark";

  return (
    <Pressable
      onPress={() => {
        aui.threads.switchToNewThread();
      }}
      style={{ marginRight: 16 }}
    >
      <Ionicons
        name="create-outline"
        size={24}
        color={isDark ? "#ffffff" : "#000000"}
      />
    </Pressable>
  );
}

function DrawerLayout() {
  const colorScheme = useColorScheme();

  return (
    <ThemeProvider value={colorScheme === "dark" ? DarkTheme : DefaultTheme}>
      <Drawer
        drawerContent={(props) => <ThreadListDrawer {...props} />}
        screenOptions={{
          headerRight: () => <NewChatButton />,
          drawerType: "front",
          swipeEnabled: true,
          drawerStyle: { backgroundColor: "transparent" },
        }}
      >
        <Drawer.Screen name="index" options={{ title: "Chat" }} />
      </Drawer>
      <StatusBar style="auto" />
    </ThemeProvider>
  );
}

export default function RootLayout() {
  const [fontsLoaded] = useFonts(Ionicons.font);
  const runtime = useAppRuntime();
  const config = AuiConfig({ tools: Tools({ toolkit: expoToolkit }) });
  if (!fontsLoaded) return null;

  return (
    <GestureHandlerRootView style={{ flex: 1 }}>
      <AssistantRuntimeProvider runtime={runtime} config={config}>
        <DrawerLayout />
      </AssistantRuntimeProvider>
    </GestureHandlerRootView>
  );
}
```

```tsx title="app/index.tsx"
import { Thread } from "@/components/assistant-ui/elements/thread.aui";

export default function ChatPage() {
  return <Thread />;
}
```

### 核心架构

| 层 | 用途 |
|-------|---------|
| `useChatRuntime` | 创建一个由连接到聊天 API 端点的 `AssistantChatTransport` 支持的运行时 |
| `AssistantRuntimeProvider` | 向整个应用提供运行时（线程和输入框作用域会自动设置） |
| `useAuiState((s) => s.thread)` | 响应式访问线程状态，并通过选择器实现细粒度重新渲染 |
| `useAuiState((s) => s.composer)` | 响应式访问输入框状态 |
| 原语 | `ThreadMessages`、`ComposerInput`、`MessageContent` 等 |
