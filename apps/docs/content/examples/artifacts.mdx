## 概述

这是 Claude Artifacts 的开源实现，允许用户直接在聊天界面中生成网站、文档和应用等交互式内容。AI 会生成 HTML、CSS 和 JavaScript 代码，并在对话旁的实时预览面板中渲染。

## 功能

- **实时预览**：生成的 Artifacts 会立即在隔离的沙盒 iframe 中渲染
- **代码生成**：创建完整的 HTML、CSS 和 JavaScript 应用
- **交互元素**：Artifacts 可以包含按钮、表单和动画
- **迭代支持**：要求 AI 修改和改进生成的 Artifacts
- **安全执行**：代码在启用脚本的沙盒 iframe 中运行，但无法访问父级文档页面
- **导出选项**：将生成的 Artifacts 下载为独立文件

## 工作原理

1. **请求**：要求 AI 创建某些内容（例如：“创建一个计算器应用”）
2. **生成**：AI 生成所需的 HTML、CSS 和 JavaScript
3. **渲染**：代码会在隔离的预览面板中安全渲染
4. **迭代**：请求更改并实时查看更新结果

## 使用场景

- **原型设计**：快速创建 UI 模型和交互式演示
- **学习**：生成代码示例以理解相关概念
- **可视化**：创建图表、示意图和数据可视化
- **游戏**：构建简单的浏览器游戏和交互式体验
- **工具**：生成计算器、转换器和实用应用
