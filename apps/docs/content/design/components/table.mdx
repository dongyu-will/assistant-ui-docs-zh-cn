## 用法

```tsx
import {
  Table,
  TableBody,
  TableCell,
  TableHead,
  TableHeader,
  TableRow,
} from "@/components/ui/table";

export function Example() {
  return (
    <Table>
      <TableHeader>
        <TableRow>
          <TableHead>Token</TableHead>
          <TableHead>Value</TableHead>
        </TableRow>
      </TableHeader>
      <TableBody>
        <TableRow>
          <TableCell>--radius-control</TableCell>
          <TableCell>8px</TableCell>
        </TableRow>
      </TableBody>
    </Table>
  );
}
```

表格顶部以一条极细线开始，最后一行下方以一条极细线结束，不绘制垂直线或填充背景。包装器会自行进行水平滚动，因此宽表格不会导致整个页面滚动。

## API 参考

每个部件都会渲染其原生元素，并接受该元素的 props。

| 部件           | 元素    | 作用                                            |
| -------------- | ---------- | ----------------------------------------------- |
| `Table`        | `table`    | 滚动包装器和表格表面。          |
| `TableHeader`  | `thead`    | 表头行组。                               |
| `TableBody`    | `tbody`    | 数据行。                                      |
| `TableFooter`  | `tfoot`    | 结尾行，使用中等字重。             |
| `TableRow`     | `tr`       | 单行，以极细线结束。                  |
| `TableHead`    | `th`       | 等宽字体列标签。                              |
| `TableCell`    | `td`       | 单元格，多行内容采用顶部对齐。   |
| `TableCaption` | `caption`  | 表格下方的等宽字体说明文字。                   |
