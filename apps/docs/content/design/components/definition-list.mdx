## 用法

```tsx
import {
  Definition,
  DefinitionAnnotation,
  DefinitionDetails,
  DefinitionList,
  DefinitionName,
  DefinitionTerm,
} from "@/components/ui/definition-list";

export function Example() {
  return (
    <DefinitionList>
      <Definition>
        <DefinitionTerm>
          <DefinitionName>storageKey?</DefinitionName>
          <DefinitionAnnotation>string</DefinitionAnnotation>
        </DefinitionTerm>
        <DefinitionDetails>
          Persists the selected tab across reloads.
        </DefinitionDetails>
      </Definition>
    </DefinitionList>
  );
}
```

列表以一条细线开头，每一行也以一条细线结尾；术语由等宽名称和低调的等宽注释组成，详细信息则以文本形式显示在下方。本网站中的每个 API 参考都通过这些部分进行渲染。

## API 参考

每个部分都会渲染其对应的原生元素，并接受该元素的 props。

| 部分                   | 元素   | 作用                                       |
| ---------------------- | --------- | ------------------------------------------ |
| `DefinitionList`       | `dl`      | 由细线开头的列表。           |
| `Definition`           | `div`     | 由细线结尾的一行。             |
| `DefinitionTerm`       | `dt`      | 术语行；包含名称和注释。 |
| `DefinitionName`       | `code`    | 使用等宽字体显示的术语本身。              |
| `DefinitionAnnotation` | `code`    | 低调的等宽注释：类型或默认值。      |
| `DefinitionDetails`    | `dd`      | 术语下方的描述。            |
