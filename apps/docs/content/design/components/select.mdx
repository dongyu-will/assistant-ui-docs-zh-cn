## 使用

```tsx
import {
  Select,
  SelectContent,
  SelectItem,
  SelectTrigger,
  SelectValue,
} from "@/components/ui/select";

const fruits = [
  { value: "apple", label: "Apple" },
  { value: "banana", label: "Banana" },
  { value: "orange", label: "Orange" },
];

export function FruitPicker() {
  return (
    <Select defaultValue="apple" items={fruits}>
      <SelectTrigger className="w-44">
        <SelectValue placeholder="Select a fruit..." />
      </SelectTrigger>
      <SelectContent>
        {fruits.map((fruit) => (
          <SelectItem key={fruit.value} value={fruit.value}>
            {fruit.label}
          </SelectItem>
        ))}
      </SelectContent>
    </Select>
  );
}
```

Base UI 版本使用 `items` 属性来解析选中的标签。Radix 会从选中的项目中读取标签，因此在 Radix 中可以省略该属性。

## API 参考

### 可组合 API

| 组件 | 描述 |
|-----------|-------------|
| `Select` | 管理选择状态的根组件。 |
| `SelectTrigger` | 用于打开下拉菜单的按钮。 |
| `SelectValue` | 选中的值或占位符。 |
| `SelectContent` | 下拉菜单内容容器。 |
| `SelectItem` | 单个可选项目。 |
| `SelectGroup` | 相关项目的分组。 |
| `SelectLabel` | 分组标签。 |
| `SelectSeparator` | 项目或分组之间的视觉分隔线。 |
| `SelectScrollUpButton` | 长列表的向上滚动控件。 |
| `SelectScrollDownButton` | 长列表的向下滚动控件。 |
