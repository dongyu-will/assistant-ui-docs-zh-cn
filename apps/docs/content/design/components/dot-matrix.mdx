这会向项目添加一个 `/components/ui/dot-matrix.tsx` 文件，你可以根据需要进行调整。除了 React 之外，该组件没有其他依赖。

## 用法

```tsx
import { DotMatrix } from "@/components/ui/dot-matrix";

export function RunIndicator({ isRunning }: { isRunning: boolean }) {
  return <DotMatrix state={isRunning ? "loading" : "success"} />;
}
```

点会继承周围文本的颜色，因此无需配置，点阵即可在浅色背景上显示深色点，在深色背景上显示浅色点。每种状态都由点阵图案、动效和颜色组合而成，切换状态时，每个点都会交叉淡入到新的图案。

## 状态

| 状态 | 图案 |
|-------|---------|
| `idle` | 暗淡的静态网格 |
| `loading` | 随机闪烁（默认） |
| `thinking` | 对角波 |
| `streaming` | 下落的雨滴，每列形成拖影 |
| `searching` | 水平扫过 |
| `syncing` | 围绕中心旋转扫过 |
| `connecting` | 从中心扩散的波纹 |
| `waiting` | 省略号圆点依次闪烁 |
| `uploading` | 向上升起的波浪 |
| `downloading` | 向下落下的波浪 |
| `listening` | 缓慢的均衡器柱 |
| `speaking` | 快速的均衡器柱 |
| `recording` | 红色中心点呼吸闪烁 |
| `success` | 绿色勾形图标，静态 |
| `error` | 红色叉形图标，闪烁 |
| `warning` | 琥珀色感叹号图标，慢速闪烁 |
| `info` | 蓝色信息图标，静态 |
| `paused` | 暂停条图标，静态 |
| `stopped` | 方形图标，静态 |
| `offline` | 非常暗淡的静态网格 |

该组件导出 `dotMatrixStates`（上方列出的有序列表）和 `DotMatrixState` 联合类型，因此 UI 可以枚举或映射状态，而无需重复维护列表。添加新状态时，只需在组件源代码中扩展 `STATES` 记录，并提供一个图标和逐点闪烁函数。

## 工作原理

网格是一个由 `currentColor` 个圆组成的 5x5 SVG。闪烁使用单个 CSS 关键帧动画，其不透明度上下限来自每个点注册的 CSS 变量；动画在每种状态下都会运行（静态状态会折叠上下限），并且上下限带有过渡效果，这正是状态变化时每个点能够交叉淡入的原因。随机加载节奏使用确定性的逐点延迟和持续时间，因此服务端与客户端会渲染出完全相同的标记，并且渲染完成后不会运行 JavaScript。使用 `prefers-reduced-motion` 时，点会保持静止时的不透明度，而不会闪烁。

根元素是一个 `role="status"` live region（实时区域），其文本内容为状态名称（或 `label` 属性），因此屏幕阅读器会播报状态变化；SVG 本身则是 `aria-hidden`。

### 样式

颜色遵循 `currentColor`，因此 `className="text-blue-500"` 可以重新设置整个点阵的颜色；结果状态（`success`、`error`、`warning`、`info`、`recording` 以及静音静态状态）会设置自身颜色，`className` 可以覆盖该颜色。可以通过 `[data-slot="dot-matrix"]` 和 `[data-slot="dot-matrix-dot"]` 定位各个点，当前状态则会在根元素上通过 `data-state` 暴露。
