## 使用

```tsx
import { DiffViewer } from "@/components/ui/diff-viewer";

// With a unified diff patch
<DiffViewer patch={diffString} />

// With file comparison
<DiffViewer
  oldFile={{ content: "old content", name: "file.txt" }}
  newFile={{ content: "new content", name: "file.txt" }}
/>
```

### 作为 Markdown 语言覆盖

与 `MarkdownTextPrimitive` 集成，以渲染差异代码块：

```tsx title="/components/assistant-ui/elements/markdown-text.tsx"
import { DiffViewer } from "@/components/ui/diff-viewer"; // [!code ++]

const MarkdownTextImpl = () => {
  return (
    <MarkdownTextPrimitive
      remarkPlugins={[remarkGfm]}
      className="aui-md"
      components={defaultComponents}
      componentsByLanguage={{                                       // [!code ++]
        diff: {                                                     // [!code ++]
          SyntaxHighlighter: ({ code }) => <DiffViewer patch={code} /> // [!code ++]
        },                                                          // [!code ++]
      }}                                                            // [!code ++]
    />
  );
};

export const MarkdownText = memo(MarkdownTextImpl);
```

### 主题

更改的行带有 2px 的槽线和淡淡的填充；除此之外，差异色调只显示在 `+`/`-` 标记和标题统计信息上，代码仍使用墨色。覆盖 CSS 变量即可自定义主题：

```css
[data-slot="diff-viewer"] {
  --diff-add-bg: color-mix(in oklab, var(--color-green-500) 8%, transparent);
  --diff-add-rule: var(--color-green-500);
  --diff-add-text: var(--color-green-600);
  --diff-add-text-dark: var(--color-green-400);
  --diff-del-bg: color-mix(in oklab, var(--color-red-500) 8%, transparent);
  --diff-del-rule: var(--color-red-500);
  --diff-del-text: var(--color-red-600);
  --diff-del-text-dark: var(--color-red-400);
}
```

| 变量 | 描述 |
|----------|-------------|
| `--diff-add-bg` | 新增行的填充色 |
| `--diff-add-rule` | 新增行的槽线 |
| `--diff-add-text` | 新增内容的标记和统计信息颜色（浅色模式） |
| `--diff-add-text-dark` | 新增内容的标记和统计信息颜色（深色模式） |
| `--diff-del-bg` | 删除行的填充色 |
| `--diff-del-rule` | 删除行的槽线 |
| `--diff-del-text` | 删除内容的标记和统计信息颜色（浅色模式） |
| `--diff-del-text-dark` | 删除内容的标记和统计信息颜色（深色模式） |

### 可组合 API

| 组件 | 描述 |
|-----------|-------------|
| `DiffViewer` | 渲染差异的主要组件。 |
| `DiffViewerFile` | 多文件差异中每个文件的包装器。 |
| `DiffViewerHeader` | 带图标和统计信息的文件名标题。 |
| `DiffViewerContent` | 可滚动的内容区域。 |
| `DiffViewerLine` | 统一模式中的单独行。 |
| `DiffViewerSplitLine` | 拆分模式中的并排行对。 |
| `DiffViewerFileBadge` | 文件扩展名徽章（例如 “TS”）。 |
| `DiffViewerStats` | 新增/删除数量显示。 |

### 样式变体（CVA）

| 导出项 | 描述 |
|--------|-------------|
| `diffViewerVariants` | 根容器的样式。 |
| `diffLineVariants` | 差异行的背景样式。 |
| `diffLineTextVariants` | 差异行的文本颜色样式。 |

```tsx
import {
  diffViewerVariants,
  diffLineVariants,
  diffLineTextVariants,
} from "@/components/ui/diff-viewer";

// Use variants directly
<div className={diffViewerVariants({ variant: "ghost", size: "sm" })}>
  Custom diff container
</div>
```

### 工具函数

| 导出项 | 描述 |
|--------|-------------|
| `parsePatch(patch)` | 将统一差异字符串解析为结构化数据。 |
| `computeDiff(old, new)` | 计算两个字符串之间的差异。 |
| `ParsedLine` | 单个差异行的类型。 |
| `ParsedFile` | 包含行和统计信息的已解析文件类型。 |
| `SplitLinePair` | 并排行对的类型。 |

## 样式

### 数据属性

使用数据属性进行自定义样式设置：

| 属性 | 值 | 描述 |
|-----------|--------|-------------|
| `data-slot` | `"diff-viewer"`、`"diff-viewer-header"`、`"diff-viewer-line"` 等 | 组件标识 |
| `data-type` | `"add"`、`"del"`、`"normal"`、`"empty"` | 行类型 |
| `data-view-mode` | `"unified"`、`"split"` | 当前视图模式 |
| `data-variant` | `"default"`、`"ghost"`、`"muted"` | 当前变体 |

### 自定义 CSS 示例

```css
[data-slot="diff-viewer"][data-view-mode="split"] {
  /* Custom split view styles */
}

[data-slot="diff-viewer-line"][data-type="add"] {
  /* Custom addition styles */
}

[data-slot="diff-viewer-line"][data-type="del"] {
  /* Custom deletion styles */
}
```
