## 用法

```tsx
import {
  Breadcrumb,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbList,
  BreadcrumbPage,
  BreadcrumbSeparator,
} from "@/components/ui/breadcrumb";

export function Example() {
  return (
    <Breadcrumb>
      <BreadcrumbList>
        <BreadcrumbItem>
          <BreadcrumbLink href="/design">Design</BreadcrumbLink>
        </BreadcrumbItem>
        <BreadcrumbSeparator />
        <BreadcrumbItem>
          <BreadcrumbPage>Breadcrumb</BreadcrumbPage>
        </BreadcrumbItem>
      </BreadcrumbList>
    </Breadcrumb>
  );
}
```

## API 参考

### 部件

| 部件 | 描述 |
|------|-------------|
| `Breadcrumb` | `nav` 地标。 |
| `BreadcrumbList` | 层级的有序列表。 |
| `BreadcrumbItem` | 一个层级。 |
| `BreadcrumbLink` | 可导航的层级；与 `render` 组合使用以创建路由链接。 |
| `BreadcrumbPage` | 当前页面，而不是链接。 |
| `BreadcrumbSeparator` | 层级之间的分隔符图形。 |
| `BreadcrumbEllipsis` | 折叠层级的占位符。 |
