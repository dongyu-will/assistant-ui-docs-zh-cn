该包装器会重新设置 [Sonner](https://sonner.emilkowal.ski) 的样式，并且在两种风格中保持一致。带类型的 toast 在边框、淡色填充和图标上使用同一种色调，而消息本身保持墨色。卡片使用浮层圆角：toast 会悬浮在页面上方，因此和套件中所有浮起的表面一样采用圆角。

## 安装

<KitInstall name="sonner" />

## 用法

在根部挂载一个 `Toaster`，然后从任意位置调用 `toast`。本网站会在根提供程序中挂载它。

```tsx
import { Toaster } from "@/components/ui/sonner";

export function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <>
      {children}
      <Toaster position="top-center" />
    </>
  );
}
```

```tsx
import { toast } from "sonner";

toast.success("Command copied");
toast("Thread archived", {
  description: "It stays in the archive until you restore it.",
  action: { label: "Undo", onClick: restore },
});
```

### toast

直接从 `sonner` 导入 `toast`：`toast(title, options)`、`toast.success`、`toast.error`、`toast.info`、`toast.warning` 和 `toast.promise` 是该套件设置样式的调用。
