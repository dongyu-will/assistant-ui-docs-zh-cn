## 安装

滚动条随 assistant-ui 的 thread 样式一起提供。文档页面介绍了如何将其接入你自己的滚动容器。

## 用法

任何自行管理滚动的窗格（例如 thread 视口或侧边栏）都会渲染覆盖式滚动条，而不是原生滚动条，因此只有在滚动时，这条细线才会显示。
