## 用法

该组件提供外观框架；向其传入一个 `pre` 元素，可以是高亮代码，也可以是普通代码。在此网站的 MDX 中，每个围栏代码块都会通过它进行渲染。

```tsx
import { CodeBlock } from "@/components/ui/code-block";

export function Example() {
  return (
    <CodeBlock title="example.ts">
      <pre>
        <code>{'const answer = 42;'}</code>
      </pre>
    </CodeBlock>
  );
}
```
