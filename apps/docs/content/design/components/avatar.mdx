## 用法

```tsx
import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar";

export function Example() {
  return (
    <Avatar>
      <AvatarImage src="/avatar.png" alt="Ada" />
      <AvatarFallback>AD</AvatarFallback>
    </Avatar>
  );
}
```

### 部件

| 部件 | 描述 |
|------|-------------|
| `AvatarImage` | 加载完成后显示的图片。 |
| `AvatarFallback` | 图片缺失时显示的首字母或图标。 |
| `AvatarBadge` | 固定在边缘的状态标记。 |
| `AvatarGroup` | 相互重叠的 Avatar 堆叠。 |
| `AvatarGroupCount` | 用于结束分组的溢出数量。 |
