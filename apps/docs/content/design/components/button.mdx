<KitInstall name="button" />

## 用法

```tsx
import { Button } from "@/components/ui/button";

export function Example() {
  return <Button variant="outline">Read the docs</Button>;
}
```

## 示例

### 尺寸

默认高度为 32px；`sm` 是 28px 的页眉控件。`xs` 和 `lg` 适用于紧凑型侧栏和醒目的行动号召。

<PreviewCode file="components/pages/design/specimens" name="ButtonSizesSpecimen" base={<ButtonSizesSpecimen />}>
  <RadixSpecimens.ButtonSizesSpecimen />
</PreviewCode>

### 图标按钮

方形的 `icon` 尺寸与 `aria-label` 搭配使用；图标放在标签旁边时，会自动获得相应间距。

### 样式变体（CVA）

| 导出项 | 描述 |
|--------|-------------|
| `buttonVariants` | Button 组件的样式。 |

```tsx
import { buttonVariants } from "@/components/ui/button";

<a className={buttonVariants({ variant: "outline", size: "sm" })}>
  Styled link
</a>
```
