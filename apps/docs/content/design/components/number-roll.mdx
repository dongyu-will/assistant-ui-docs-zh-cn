## 安装

<InstallCommand shadcn={["number-roll"]} />

这会在项目中添加一个 `/components/ui/number-roll.tsx` 文件，你可以根据需要进行调整。该组件除 React 外没有其他依赖。

## 用法

```tsx
import { NumberRoll } from "@/components/ui/number-roll";

export function TokenCounter({ count }: { count: number }) {
  return <NumberRoll value={count} format={{ notation: "compact" }} />;
}
```

当 `value` 发生变化时，每个数字都会在原位滚动到新值。格式化由 `Intl.NumberFormat` 处理，因此结构变化也会产生动画：当使用紧凑表示法时，`700` 变为 `1.1K`，保留的个位数字会从 0 滚动到 1，同时开头的 `70` 滑出，小数点、小数位数字和 `K` 后缀滑入。

## 工作原理

数值会使用 `Intl.NumberFormat.formatToParts` 格式化，并拆分为带键的部分。整数数字按从右侧开始计算的位值设置键，因此当 `999` 变为 `1,000` 时，已有的列会保留其身份并在原位滚动，只有新的前导数字和分隔符会进入。符号（小数点、分组分隔符、货币符号、紧凑表示法后缀）会通过动画 `grid-template-columns` 淡入淡出并收缩。

每个数字都会渲染一个包含 0 到 9 的条带，并为注册的 CSS 自定义属性设置动画；CSS `mod()` 数学会将条带环绕成无尽的带状轨道，因此从 9 滚动到 0 时会沿趋势方向继续滚动，而不是反向旋转。这里没有 JavaScript 动画循环，也不依赖动画库。

在不支持 CSS `mod()` 的浏览器中，以及服务器渲染期间，组件会渲染普通的格式化字符串。使用 `prefers-reduced-motion` 时，数值会立即切换而不会滚动。在服务器渲染时，请传入明确的 `locales`：服务器的默认区域设置可能与访问者浏览器的区域设置不同，而格式化字符串不匹配会导致 React 水合错误。默认编号系统为非拉丁数字的区域设置（例如 `ar-EG`）会将数字作为符号进行淡入淡出，而不是滚动。

格式化后的值会以纯文本形式提供给屏幕阅读器，而动画数字则为 `aria-hidden`。值的变化不会自动播报；如果需要播报，请将组件包裹在 `aria-live` 区域中。

### 样式

根元素应用 `tabular-nums`，使数字在滚动时保持固定宽度；你使用的字体必须提供等宽数字，以确保布局保持稳定。大小和颜色会继承周围文本，因此可以像设置任意 span 一样设置它的样式：

```tsx
<NumberRoll value={value} className="text-4xl font-semibold" />
```

通过 `duration` prop 更改动画速度；它同时控制 CSS 时序以及卸载已退出字符的清理过程，因此仅在 CSS 中覆盖时长变量会导致字符在淡出过程中途被移除。可以通过 `style` prop 安全地覆盖淡入淡出和缓动变量（默认值通过内联样式设置，因此普通的 `className` 覆盖不会生效）：

| 变量 | 默认值 | 描述 |
|----------|---------|-------------|
| `--aui-number-roll-duration` | `500ms`（来自 `duration` prop） | 数字滚动时长。 |
| `--aui-number-roll-fade` | 时长的 60% | 进入/退出淡入淡出和宽度收缩时长。 |
| `--aui-number-roll-ease` | `cubic-bezier(0.23, 1, 0.32, 1)` | 数字滚动缓动。 |

可以通过 data 属性定位各个部分：`[data-slot="number-roll"]`、`[data-slot="number-roll-part"]`、`[data-slot="number-roll-digit"]` 和 `[data-slot="number-roll-symbol"]`。
