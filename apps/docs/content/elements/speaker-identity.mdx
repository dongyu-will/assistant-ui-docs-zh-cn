SpeakerIdentity 会为每个回合添加图标和色调，具体取决于产生该回合的对象：你、助手、子代理或工具。使用运行时（runtime）时，用户、助手和工具之间的区别直接来自消息和部分数据；单独使用时，则需要自行组装列表。

## 入门

<RuntimeMode>

`s.message.role` 会直接提供用户/助手的区分。工具调用作为部分存在于助手消息的 `content` 中，每个部分都有一个 `toolName`，并且在运行时进行跟踪时还会有一个 `timing`。嵌套的子代理运行会显示为工具调用自身的 `messages` 字段；对于这种情况，它正是 `ToolCallMessagePart` 的一个真实部分。除了这一点，assistant-ui 没有固定的“代理名称”概念：特定代理或模型的显示名称，需要你自行通过消息的开放式 `metadata.custom` 数据包附加。

<Steps>
  <Step>

### 将顶层消息转换为行

```tsx title="components/assistant-ui/elements/speaker-list.tsx"
"use client";

import type { ThreadMessage } from "@assistant-ui/react";
import type { SpeakerTurn } from "@/components/assistant-ui/elements/speaker-identity";

function textOf(content: readonly { type: string; text?: string }[]) {
  return content
    .filter((part): part is { type: "text"; text: string } => part.type === "text")
    .map((part) => part.text)
    .join(" ");
}

function customString(message: ThreadMessage, key: string): string | undefined {
  const value = message.metadata.custom[key];
  return typeof value === "string" ? value : undefined;
}

function messageTurn(message: ThreadMessage): SpeakerTurn {
  if (message.role === "user") {
    return { id: message.id, kind: "user", name: "You", text: textOf(message.content) };
  }
  return {
    id: message.id,
    kind: "agent",
    name: customString(message, "agentName") ?? "Assistant",
    detail: customString(message, "model"),
    text: textOf(message.content),
  };
}
```

上面的 `agentName` 和 `model` 是一种示例约定，并非内置字段；你自己的多代理后端决定在 `metadata.custom` 中存储哪些内容，以及使用哪些键。

  </Step>
  <Step>

### 添加工具调用和嵌套子代理

```tsx
import type { ToolCallMessagePart } from "@assistant-ui/react";

function toolTurn(part: ToolCallMessagePart): SpeakerTurn {
  const ms =
    part.timing?.completedAt !== undefined
      ? part.timing.completedAt - part.timing.startedAt
      : undefined;
  return {
    id: part.toolCallId,
    kind: "tool",
    name: part.toolName,
    detail: ms !== undefined ? `${ms}ms` : undefined,
    text: part.argsText,
  };
}

function turnsFor(message: ThreadMessage): SpeakerTurn[] {
  const turns = [messageTurn(message)];
  if (message.role !== "assistant") return turns;

  for (const part of message.content) {
    if (part.type !== "tool-call") continue;
    turns.push(toolTurn(part));
    for (const sub of part.messages ?? []) {
      turns.push({ ...messageTurn(sub), kind: "subagent" });
    }
  }
  return turns;
}
```

工具行的 `text` 应该显示哪个参数，取决于具体工具；`argsText`（原始流式 JSON）是安全的通用后备方案，但如果你有 `toolName` 可以进行判断，通常显示 `read_file` 工具的路径或 `search` 工具的查询会更易读。

  </Step>
</Steps>

### 构建回合列表

```tsx title="app/session.tsx"
import { SpeakerIdentity, type SpeakerTurn } from "@/components/assistant-ui/elements/speaker-identity";

const TURNS: SpeakerTurn[] = [
  { id: "1", kind: "user", name: "You", text: "Find out why the converter drops turns." },
  { id: "2", kind: "agent", name: "Maintainer", detail: "opus", text: "Splitting this up." },
  { id: "3", kind: "subagent", name: "reader", detail: "haiku", text: "convertMessages returns early." },
```

## 结构

```tsx
<div data-slot="speaker-identity">
  {/* per turn: an icon in a tinted badge, then a name/detail line and the text below it */}
</div>
```

每个 `kind` 都映射到固定的图标和色调：`user` 和 `subagent` 共享中性色调，`agent` 是唯一使用蓝色色调的类型，而 `tool` 在四者中显示得最暗。`subagent` 是唯一一种徽章会渲染为完整圆形而非圆角方形的类型，这也体现了它代表的是整个嵌套会话，而不是单个说话者。

## 示例

### 重新设置徽章样式

两条轨道都会在根元素上接收 `className`。`detail` 会从 `surfaces.tsx` 读取共享的 `mono` 表面。

```tsx
<SpeakerIdentity className="gap-4" turns={turns} />
```

### 只有一种声音的线程

<RuntimeMode>

大多数线程都不会产生 `subagent` 或 `tool` 行；对于这些线程，上面的 `turnsFor` 仍会返回一个简单的两类型列表（`user`、`agent`），因为遍历 `content` 时根本找不到可添加的内容。

</RuntimeMode>

<StandaloneMode>

传入只包含单个 `kind` 的回合，其工作方式与混合列表相同；图标和色调会按行查找，而不是为整个列表统一选择一次。

```tsx
<SpeakerIdentity turns={turns.filter((t) => t.kind === "user" || t.kind === "agent")} />
```

</StandaloneMode>

## API 参考

<RuntimeMode>

### 消息状态

| 选择器 / 字段 | 类型 | 描述 |
|-------------------|------|-------------|
| `s.message.role` | `"user" \| "assistant" \| "system"` | 真正的区分方式；`"agent"` 和 `"subagent"` 是此组件自身的词汇，而不是运行时角色。 |
| `s.message.metadata.custom` | `Record<string, unknown>` | 用于存放应用定义的显示数据的开放式数据包，例如代理名称或模型名称。 |
| `ToolCallMessagePart.toolName` | `string` | 被调用工具的名称。 |
| `ToolCallMessagePart.timing` | `{ startedAt: number; completedAt?: number } \| undefined` | Epoch 毫秒数；设置 `completedAt` 后，两者相减即可得到持续时间。 |
| `ToolCallMessagePart.messages` | `readonly ThreadMessage[] \| undefined` | 此调用产生的嵌套线程消息，例如子代理自己的会话。 |

</RuntimeMode>

<StandaloneMode>
