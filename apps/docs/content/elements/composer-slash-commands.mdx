---
title: "斜杠命令"
description: "输入斜杠后，命令菜单会浮动在输入框上方，并随着继续输入进行筛选。"
---

在草稿开头输入 `/`，会在输入框上方打开一个浮动的命令菜单；每次按键都会缩小列表范围，选中命令后即可执行。使用运行时时，菜单由连接到命令适配器的触发器原语驱动；单独使用时，则可以通过 `useSlashMatches` 自行筛选普通列表。

## 入门

<RuntimeMode>

assistant-ui 的输入框提供了一个由字符激活的弹出框触发器系统：输入类似 `/` 的字符后，会打开一个作用域内的弹出框，该弹出框拥有独立的搜索、键盘导航和选择功能，不会影响输入框的其他内容。这些原语标记为 `Unstable_`：其结构未来版本仍可能发生变化。

<Steps>
  <Step>

### 定义命令

`unstable_useSlashCommandAdapter` 会将命令列表封装为触发器所需的 `{ adapter, action }` 对。每个命令的 `execute` 都保留在 hook 的闭包中，因此不需要进行序列化：

```tsx title="components/assistant-ui/elements/composer-commands.tsx"
"use client";

import { unstable_useSlashCommandAdapter } from "@assistant-ui/react";

export function useComposerCommands() {
  return unstable_useSlashCommandAdapter({
    commands: [
      { id: "summarize", description: "Summarize this thread", icon: "FileText", execute: () => runSummarize() },
      { id: "translate", description: "Translate the last reply", icon: "Languages", execute: () => runTranslate() },
    ],
  });
}
```

  </Step>
  <Step>

### 在 `/` 上打开弹出框

```tsx title="components/assistant-ui/elements/composer-bar.tsx"
"use client";

import { ComposerPrimitive } from "@assistant-ui/react";
import { cn } from "@/lib/utils";
import { floating } from "@/components/assistant-ui/elements/surfaces";
import { useComposerCommands } from "./composer-commands";

export function ComposerBar() {
  const slash = useComposerCommands();

  return (
    <ComposerPrimitive.Unstable_TriggerPopoverRoot>
      <ComposerPrimitive.Unstable_TriggerPopover char="/" adapter={slash.adapter}>
        <ComposerPrimitive.Unstable_TriggerPopover.Action
          onExecute={slash.action.onExecute}
          removeOnExecute={slash.action.removeOnExecute}
        />
        <ComposerPrimitive.Unstable_TriggerPopoverItems>
          {(items) => (
            <div className={cn(floating, "absolute bottom-full z-10 mb-2 w-72 rounded-2xl p-1.5")}>
              {items.map((item, index) => (
                <ComposerPrimitive.Unstable_TriggerPopoverItem
                  key={item.id}
                  item={item}
                  index={index}
                  className="data-[highlighted]:bg-foreground/[0.04] flex w-full flex-col items-start gap-0.5 rounded-[10px] px-2.5 py-2 text-start outline-none"
                >
                  <span className="text-[13.5px] font-medium">/{item.id}</span>
                  {item.description && <span className="text-foreground/45 text-xs">{item.description}</span>}
                </ComposerPrimitive.Unstable_TriggerPopoverItem>
              ))}
            </div>
          )}
        </ComposerPrimitive.Unstable_TriggerPopoverItems>
      </ComposerPrimitive.Unstable_TriggerPopover>
      <ComposerPrimitive.Root className="flex w-full flex-col gap-2 rounded-[24px] p-2.5">
        <ComposerPrimitive.Input placeholder="Message, or / for commands..." rows={1} className="min-h-11 w-full resize-none bg-transparent px-3 outline-none" />
      </ComposerPrimitive.Root>
    </ComposerPrimitive.Unstable_TriggerPopoverRoot>
  );
}
```

`Unstable_TriggerPopoverRoot` 包裹的是整个输入栏，而不仅仅是输入框；`Unstable_TriggerPopover` 和 `ComposerPrimitive.Root` 会并排放在其中。`.Action` 行为会在选中命令的瞬间触发 `onExecute`；从适配器传入 `removeOnExecute`，这样当 `false` 执行时，`/summarize` 文本就会被清除，否则它会作为审计记录残留。`Unstable_TriggerPopoverItem` 会在键盘导航到达的行上设置 `data-highlighted`，因此活动行的着色只需使用普通的 `data-[highlighted]:` 类，而不必自行跟踪状态。assistant-ui 已经预先提供了完整的组合：安装 [Composer 触发器弹出框](/elements/composer-trigger-popover) 后，无需手动组装即可获得分类、无搜索结果和加载状态。

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

单独使用时，不会有任何机制替你检测 `/`。`useSlashMatches` 会根据当前草稿文本筛选命令列表，并返回匹配项供你渲染到菜单中；高亮哪一项需要由你自行保存。

<Steps>
  <Step>

### 随草稿变化进行筛选

```tsx title="app/chat-box.tsx"
"use client";

import { useState } from "react";
import { useSlashMatches, ComposerMenu, ComposerCommandItem, type ComposerCommand } from "@/components/assistant-ui/elements/composer";
import { FileTextIcon, LanguagesIcon } from "lucide-react";

const commands: ComposerCommand[] = [
  { name: "summarize", description: "Summarize this thread", icon: FileTextIcon },
  { name: "translate", description: "Translate the last reply", icon: LanguagesIcon },
];

export function ChatBox() {
  const [text, setText] = useState("");
  const matches = useSlashMatches(text, commands);

  return (
    <div className="relative">
      <ComposerMenu open={matches.length > 0}>
        {matches.map((command) => (
          <ComposerCommandItem key={command.name} command={command} active={false} onClick={() => runCommand(command.name)} />
        ))}
      </ComposerMenu>
      {/* ComposerInput below */}
    </div>
  );
}
```

  </Step>
  <Step>

### 跟踪高亮行

`useSlashMatches` 只返回筛选后的列表；箭头键高亮和按 Enter 执行需要由你自行添加，通常可以使用 `highlightedIndex` 状态，在每次按键时将其限制在 `matches.length` 范围内，并将该行标记为 `active`。

</Steps>

## 结构

```tsx
<div data-slot="composer-menu" data-open={/* true while a "/query" is being typed */}>
  <button data-slot="composer-menu-item" data-active={/* the highlighted row */}>
    {/* icon, /name, description, and a "↵" hint on the active row */}
  </button>
</div>
```

只有当草稿以 `/` 开头时，菜单才会打开；斜杠后的所有输入都是筛选查询，会与每个命令的 id 开头进行匹配。`ComposerCommandItem` 的 `active` 属性仅用于视觉呈现（背景着色以及末尾的 `↵` 提示）；在两种方式中，哪一行算作活动行都由调用方跟踪状态。

## 示例

### 随输入进行筛选

<RuntimeMode>

适配器的 `search` 会在每次按键时接收斜杠后的文本；`unstable_useSlashCommandAdapter` 会以不区分大小写的方式，将其与每个命令的 `id`、`label` 和 `description` 进行匹配。

```tsx
slash.adapter.search("sum"); // → [{ id: "summarize", ... }]
```

</RuntimeMode>

<StandaloneMode>

`useSlashMatches` 会针对命令的 `name` 执行相同的前缀匹配：

```tsx
const matches = useSlashMatches("/sum", commands); // → [commands[0]]
```

</StandaloneMode>

### 重新设置菜单样式

两种方式都会将内容渲染到 `ComposerMenu` 中。它接收 `className`，并读取 `open`，以便从 `scale-[0.97] opacity-0` 动画进入。`ComposerMenuItem` 的活动状态使用 `field` 表面令牌；如果希望分别隐藏或重新设置主题，可以为描述文本和 `↵` 提示使用各自的工具类。

```tsx
<ComposerMenu className="w-96" open={open}>
  {/* items */}
</ComposerMenu>
```

## API 参考

<RuntimeMode>

### ComposerPrimitive（触发器）

| 部件 | 渲染内容 | 说明 |
|------|---------|------|
| `Unstable_TriggerPopoverRoot` | provider | 每个输入栏包裹一次；收集其中注册的所有触发字符。 |
| `Unstable_TriggerPopover` | `div`（打开时） | `char="/"`、`adapter`；在行为子项注册且触发器处于活动状态前不渲染任何内容。 |
| `Unstable_TriggerPopover.Action` | behavior | `onExecute(item)`、`formatter?`、`removeOnExecute?`（默认值为 `false`，保留 `/id` 文本）。 |
| `Unstable_TriggerPopoverItems` | render prop | `{(items) => ReactNode}`；仅在某个分类处于活动状态或搜索模式开启时渲染。 |
| `Unstable_TriggerPopoverItem` | `button` | `item`、`index?`；在键盘导航期间获取 `data-highlighted`。 |
| `Unstable_TriggerPopoverCategories` / `CategoryItem` / `Back` | render prop / `button` / `button` | 仅当适配器将命令分组为分类时才需要。 |

### unstable_useSlashCommandAdapter

| 选项 | 类型 | 说明 |
|--------|------|-------------|
| `commands` | `Unstable_SlashCommand[]` | `{ id, label?, description?, icon?, execute }`。 |
| `removeOnExecute` | `boolean` | 执行后移除 `/id` 文本。@default `false` |

返回 `{ adapter, action, iconMap?, fallbackIcon? }`；将 `action` 展开到 `Unstable_TriggerPopover.Action` 上。

</RuntimeMode>

<StandaloneMode>

### useSlashMatches

| 参数 | 类型 | 说明 |
|-----------|------|-------------|
| `value` | `string` | 当前草稿文本。 |
| `commands` | `readonly ComposerCommand[] \| undefined` | 完整的命令列表。 |

返回 `name` 以 `/` 后的文本开头的命令；如果 `value` 不以 `/` 开头，则返回 `[]`。

### ComposerCommand

| 字段 | 类型 | 说明 |
|-------|------|-------------|
| `name` | `string` | 用于与查询匹配；显示为 `/name`。 |
| `description` | `string` | 显示在名称旁边。 |
| `icon` | `LucideIcon` | 渲染在行的开头。 |

### ComposerCommandItem

| 属性 | 类型 | 默认值 | 说明 |
|------|------|---------|-------------|
| `command` | `ComposerCommand` | 必填 | 要渲染的命令。 |
| `active` | `boolean` | 必填 | 为行着色并显示 `↵` 提示。 |

</StandaloneMode>
