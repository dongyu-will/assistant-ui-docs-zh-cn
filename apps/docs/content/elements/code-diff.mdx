---
title: "代码差异"
description: "适用于聊天的统一差异视图，为新增和删除内容添加色调。"
---

代码差异显示一个文件中发生变化的行：顶部显示文件名以及新增和删除的净数量，下面依次显示所有上下文行、新增行和删除行，并根据类型为每行添加色调和 gutter 标记。在运行时中，文件名和行内容来自编辑工具的结果；独立使用时，则直接提供相同的数据结构。

### 渲染工具调用

```tsx title="components/assistant-ui/elements/edit-file-tool-ui.tsx"
"use client";

import type { ToolCallMessagePartComponent } from "@assistant-ui/react";
import { CodeDiff, type DiffLine } from "@/components/assistant-ui/elements/code-diff";

type EditFileArgs = { path: string };
type EditFileResult = { additions: number; deletions: number; lines: DiffLine[] };

export const EditFileToolUI: ToolCallMessagePartComponent<
  EditFileArgs,
  EditFileResult
> = ({ args, result }) => {
  if (!result) return null;
  return (
    <CodeDiff
      filename={args.path}
      additions={result.additions}
      deletions={result.deletions}
      lines={result.lines}
      cycle={0}
    />
  );
};
```

  </Step>
  <Step>

### 注册工具

```tsx title="app/toolkit.ts"
import { defineToolkit } from "@assistant-ui/react";
import { EditFileToolUI } from "@/components/assistant-ui/elements/edit-file-tool-ui";

export const toolkit = defineToolkit({
  edit_file: {
    type: "backend",
    render: EditFileToolUI,
  },
});
```

```tsx title="app/MyRuntimeProvider.tsx"
import { AssistantRuntimeProvider, AuiConfig, Tools } from "@assistant-ui/react";
import { useChatRuntime } from "@assistant-ui/ai-sdk";
import { toolkit } from "./toolkit";

export function MyRuntimeProvider({ children }: { children: React.ReactNode }) {
  const runtime = useChatRuntime();
  const config = AuiConfig({ tools: Tools({ toolkit }) });
  return (
    <AssistantRuntimeProvider runtime={runtime} config={config}>
      {children}
    </AssistantRuntimeProvider>
  );
}
```

工具调用完成后，差异视图会进行渲染；运行期间，`result` 为 `undefined`，上面的渲染器则返回 `null`。有关中间状态下的加载状态，请参阅 [工具 UI](/docs/tools/tool-ui)。

### 保持差异视图

```tsx title="app/patch.tsx"
"use client";

import { CodeDiff, type DiffLine } from "@/components/assistant-ui/elements/code-diff";

const LINES: DiffLine[] = [
  { kind: "context", text: "export function Composer() {" },
  { kind: "removed", text: '  const [draft, setDraft] = useState("");' },
  { kind: "added", text: "  const draft = useDraft(threadId);" },
];

export function Patch() {
  return (
    <CodeDiff
      filename="composer.tsx"
      additions={1}
      deletions={1}
      lines={LINES}
      cycle={0}
    />
  );
}
```

### 在新的差异视图上重播

同时递增 `cycle` 并提供新的 `lines` 数组，即使组件仍处于挂载状态，也可以重新启动交错动画：

```tsx
async function reEdit(path: string) {
  const next = await fetchDiff(path);
  setLines(next.lines);
  setCounts({ additions: next.additions, deletions: next.deletions });
  setCycle((c) => c + 1);
}
```

## 结构

```tsx
<div data-slot="code-diff">
  <div>{/* filename, +additions and −deletions counts */}</div>
  <div>{/* horizontally scrollable line list, colored and gutter-marked by kind */}</div>
</div>
```

新增和删除数量始终会渲染，即使数量为零；不存在会隐藏 `+0` 或 `−0` 的阈值。每行会保留自身的空白，并在自己的容器中水平滚动，而不是换行，因此长行不会使卡片宽度超过其 `max-w-md`。每行的进入动画按每行 `60ms` 的间隔交错显示，并以 `cycle` 作为 key，因此递增 `cycle` 会为相同的行文本重新播放交错动画。

## 示例

### 重新设置差异视图的样式

两条轨道都会在根元素上接收 `className`。卡片表面使用共享的 `paper` token，滚动区域使用 `codeScroll`/`codeSurface`；二者都位于 `surfaces.tsx` 中。

```tsx
<CodeDiff className="max-w-none" /* ... */ />
```

### 没有行发生变化

空的 `lines` 数组是有效的差异视图：标题仍会显示文件名和数量，正文则渲染为空的滚动区域。

```tsx
<CodeDiff filename="README.md" additions={0} deletions={0} lines={[]} cycle={0} />
```

### 重播进入动画

将 `cycle` 计数器与负责加载下一个差异视图的逻辑配对，这样同一个已挂载的卡片就能在不卸载的情况下显示新的补丁：

```tsx
const [cycle, setCycle] = useState(0);
const [lines, setLines] = useState<DiffLine[]>(INITIAL_LINES);
```

## API 参考

<RuntimeMode>

### 工具调用渲染属性

| Prop | Type | Description |
|------|------|-------------|
| `args` | `{ path: string }` | 模型要求编辑的文件。 |
| `result` | `{ additions: number; deletions: number; lines: DiffLine[] } \| undefined` | 工具调用完成后应用的补丁。 |

有关完整的渲染属性列表以及后端工具注册方式，请参阅[工具 UI](/docs/tools/tool-ui)。

</RuntimeMode>

<StandaloneMode>

### CodeDiff

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `filename` | `string` | required | 在标题中显示。 |
| `additions` | `number` | required | 标题中的绿色数量。 |
| `deletions` | `number` | required | 标题中的红色数量。 |
| `lines` | `readonly DiffLine[]` | required | 按顺序排列的差异正文。 |
| `cycle` | `number` | required | 合并到每行的 key 中；递增后可重新播放进入动画。 |
| `className` | `string` | | 合并到根元素上。 |

`DiffLine` 是 `{ kind: "context" | "added" | "removed"; text: string }`。所有其他 `div` props 都会转发到根元素。

</StandaloneMode>
