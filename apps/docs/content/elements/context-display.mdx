---
title: "上下文显示"
description: "以环形、条形或文本值的形式显示模型上下文使用量，并在悬停时查看详细信息。"
---

上下文显示会将模型的 token 使用量转换为一个小型仪表盘，提供三种形式：环形、条形或纯文本分数；悬停时它们都会打开相同的工具提示明细。在运行时中，它会读取最新助手消息中的使用量；在独立模式下，则由你自行传入 usage 对象。

## 快速开始

<RuntimeMode>

运行时使用量需要满足两点：你的服务器确实返回 token 计数，并且在 UI 的某处挂载一个预设组件。

<Steps>
  <Step>

### 从路由处理程序转发 token 使用量

`useThreadTokenUsage()` 会从最新助手消息的 `metadata` 中读取使用量，因此你的 AI SDK 路由必须附加该信息。在 `finish` 步骤中返回 `usage`，并通过 `messageMetadata` 在 `finish-step` 上返回 `modelId`：

```tsx title="app/api/chat/route.ts"
import { streamText, convertToModelMessages } from "ai";

export async function POST(req: Request) {
  const { messages } = await req.json();
  const result = streamText({
    model: getModel(),
    messages: await convertToModelMessages(messages),
  });
  return result.toUIMessageStreamResponse({
    messageMetadata: ({ part }) => {
      if (part.type === "finish") return { usage: part.totalUsage };
      if (part.type === "finish-step")
        return { modelId: part.response.modelId };
      return undefined;
    },
  });
}
```

如果省略此步骤，每个预设组件读取到的总量都会是零，工具提示中的明细也会保持为空。

  </Step>
  <Step>

### 挂载预设组件

选择 `Ring`、`Bar` 或 `Text`，并传入模型的 `modelContextWindow`。每个预设都会通过 `useThreadTokenUsage()` 在内部获取使用量，并在当前线程的 id 发生变化时重新开始累计总量。

```tsx title="components/assistant-ui/elements/thread.aui.tsx"
import { ContextDisplay } from "@/components/assistant-ui/elements/context-display.aui";

function ThreadFooter() {
  return (
    <div className="flex items-center justify-end px-3 py-1.5">
      <ContextDisplay.Bar modelContextWindow={128000} />
    </div>
  );
}
```

`Thread` 默认不会挂载预设组件；请将其放置在页脚、输入框侧栏或侧边栏中。

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

在独立模式下，每个预设组件和可组合的 `Root` 都会将 `usage` 对象作为 prop，而不是从运行时中读取；此外还可以传入可选的 `resetKey`，以便在切换对话时自行重新开始累计总量（例如传入线程 id）。

<Steps>
  <Step>

### 将使用量作为 prop 传入

```tsx title="app/usage-badge.tsx"
import { ContextDisplayBar } from "@/components/assistant-ui/elements/context-display";

export function UsageBadge() {
  return (
    <ContextDisplayBar
      modelContextWindow={128000}
      usage={{ totalTokens: 42000, inputTokens: 38000, outputTokens: 4000 }}
    />
  );
}
```

## 组成结构

每个预设组件的结构都相同：一个包裹在共享工具提示中的触发器。

```tsx
<button data-slot="context-display-trigger">
  {/* Ring: SVG donut + percent. Bar: fill bar + token count. Text: "12k / 128k" */}
</button>
<div data-slot="context-display-popover">
  <div>Context usage   <span>{/* used of total */}</span></div>
  <div>{/* progress bar, min-width 1px once usage is nonzero */}</div>
  <div>Input           <span>{/* only when > 0 */}</span></div>
  <div>Cached input    <span>{/* only when > 0 */}</span></div>
  <div>Output          <span>{/* only when > 0 */}</span></div>
  <div>Reasoning       <span>{/* only when > 0 */}</span></div>
</div>
```

明细只会列出 token 计数不为零的分段，因此仅包含 `totalTokens` 的 usage 对象会显示摘要行，但下方没有任何行。即使使用量超过上下文窗口，百分比也会限制为 100。累计总量具有粘滞性，而不是对每次更新做出反应：只有当传入的总量本身不为零，或 `resetKey` 发生变化时，它才会更新。在两次交互之间短暂出现 `undefined`（或零）的使用量时，数字不会闪回较低值；但当 `resetKey` 发生变化时，数字会立即跳转到新使用量报告的值。

## 示例

### 三种预设组件

每个预设组件都会以一种特定的视觉形式包装 `Root`、`Trigger` 和 `Content`。`Ring` 绘制带百分比标签的 SVG 圆环，`Bar` 绘制旁边带 token 计数的填充条，而 `Text` 则显示纯文本分数，完全不使用严重程度颜色。`Ring` 和 `Bar` 都会在相同的两个阈值处切换颜色：使用量低于 65% 时使用默认色调，65% 到 85% 时使用琥珀色，高于 85% 时使用红色。

<RuntimeMode>

```tsx
<ContextDisplay.Ring modelContextWindow={128000} />
<ContextDisplay.Bar modelContextWindow={128000} />
<ContextDisplay.Text modelContextWindow={128000} />
```

任何预设组件也可以直接接收 `usage`。传入该值后会跳过内部的 `useThreadTokenUsage()` 获取，同时也会跳过自动的 thread-id 重置键。当你已经从其他地方获得使用量，并希望自行驱动徽章，同时又不想放弃页面其他部分的运行时连接时，这种方式非常有用。

</RuntimeMode>

<StandaloneMode>

```tsx
<ContextDisplay.Ring modelContextWindow={128000} usage={usage} />
<ContextDisplay.Bar modelContextWindow={128000} usage={usage} />
<ContextDisplay.Text modelContextWindow={128000} usage={usage} />
```

</StandaloneMode>

### 组合自定义视觉样式

`Root`、`Trigger` 和 `Content` 都会单独导出，用于创建完全自定义的触发器视觉样式。`Root` 会为 `Content` 的工具提示计算共享百分比和分段明细，但该计算逻辑位于模块内部。传给 `Trigger` 的自定义子项会渲染你放入其中的任意内容，因此应将其与自己的 `modelContextWindow`/usage 计算配合使用，而不要期待它读取 `Root` 的数值。

<RuntimeMode>

```tsx
<ContextDisplay.Root modelContextWindow={128000}>
  <ContextDisplay.Trigger aria-label="Context usage">
    <MyCustomGauge />
  </ContextDisplay.Trigger>
  <ContextDisplay.Content side="top" />
</ContextDisplay.Root>
```

</RuntimeMode>

<StandaloneMode>

在独立模式下，以与上述预设组件相同的方式，将 `usage` 传给 `Root`；无论使用哪种模式，`Trigger` 和 `Content` 接收的 props 都相同。

</StandaloneMode>

### 重新设置触发器样式

两种模式中的触发器都接收 `className`，而 `side` 控制弹出层朝哪个边缘打开。

```tsx
<ContextDisplay.Bar className="px-1" side="bottom" modelContextWindow={128000} />
```

## API 参考

<RuntimeMode>

### 预设组件 props（Ring、Bar、Text）

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `modelContextWindow` | `number` | required | 用于计算百分比的 token 上限。 |
| `className` | `string` | | 合并到触发器上。 |
| `side` | `"top" \| "bottom" \| "left" \| "right"` | `"top"` | 工具提示的位置。 |
| `usage` | `TokenUsage` | | 直接提供使用量以跳过内部获取；设置后，预设组件也会跳过自动的 thread-id 重置键。 |

### 可组合 Root

| Prop | Type | Description |
|------|------|-------------|
| `modelContextWindow` | `number` | 用于计算百分比的 token 上限。 |
| `children` | `ReactNode` | 必需；通常为 `Trigger` 和 `Content`。 |
| `usage` | `TokenUsage` | 与上述预设组件相同的覆盖行为。 |

`Trigger` 和 `Content` 在两种模式下接收完全相同的 props；请参阅下方独立模式中的对应表格。

### 线程状态

| Selector | Type | Description |
|----------|------|-------------|
| `useThreadTokenUsage()` | `ThreadTokenUsage \| undefined` | 从最新的、包含任意使用量信息的助手消息中提取使用量；读取来源包括 `metadata.usage`、旧版 `metadata.custom.usage`，或对 `metadata.steps` 中的值求和。 |
| `s.threadListItem.id` | `string` | 在内部用作每个预设组件的重置键，因此切换线程时会重新开始累计总量。 |

</RuntimeMode>

<StandaloneMode>

### Root

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `modelContextWindow` | `number` | required | 用于计算百分比的 token 上限。 |
| `usage` | `TokenUsage` | | `{ totalTokens?, inputTokens?, cachedInputTokens?, outputTokens?, reasoningTokens? }`。 |
| `resetKey` | `string` | | 更改此值会立即将累计总量跳转到当前使用量，绕过组成结构中所述的粘滞行为。 |

### Trigger

| Prop | Type | Description |
|------|------|-------------|
| `className` | `string` | 合并到按钮上。 |
| `children` | `ReactNode` | 工具提示触发器内部显示的视觉内容。 |

### Content

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `side` | `"top" \| "bottom" \| "left" \| "right"` | `"top"` | 工具提示的位置。 |
| `className` | `string` | | 合并到弹出层上。 |

</StandaloneMode>
