---
title: "指令文本"
description: "一种消息渲染器，可将提及指令转换为内联的、可感知运行时的芯片。"
---

指令文本会解析消息纯文本中的指令语法，并将每条指令渲染为内联芯片，而不是原始标记，同时保持普通文本不变。搭配运行时使用时，它会作为文本渲染器接入 `MessagePrimitive.Parts`，并开箱即用地理解 assistant-ui 自有的指令格式；单独使用时，你可以提供自己的解析器，在没有运行时的情况下获得相同的芯片渲染效果。

## 快速开始

<RuntimeMode>

<Steps>
  <Step>

### 注册渲染器

`DirectiveText` 已预先接入 assistant-ui 的默认指令格式。在指令芯片应出现的位置，将它作为 `MessagePrimitive.Parts` 上的 `Text` 渲染器传入。

```tsx title="components/assistant-ui/elements/thread.aui.tsx"
import { DirectiveText } from "@/components/assistant-ui/elements/directive-text.aui";
import { MessagePrimitive } from "@assistant-ui/react";

function UserMessage() {
  return (
    <MessagePrimitive.Root>
      <MessagePrimitive.Parts components={{ Text: DirectiveText }} />
    </MessagePrimitive.Root>
  );
}
```

没有指令语法的消息会完全按照纯文本渲染；没有内容可解析时不会添加任何额外内容。

### 根据自定义格式构建组件

```tsx title="app/message.tsx"
import {
  createDirectiveText,
  type DirectiveTextFormatter,
  type DirectiveTextSegment,
} from "@/components/assistant-ui/elements/directive-text";

const bracketFormatter: DirectiveTextFormatter = {
  parse(text) {
    const segments: DirectiveTextSegment[] = [];
    const re = /@\[([^\]]+)\]\(([^)]+)\)/g;
    let last = 0;
    for (const m of text.matchAll(re)) {
      if (m.index > last) segments.push({ kind: "text" as const, text: text.slice(last, m.index) });
      segments.push({ kind: "mention" as const, type: "user", label: m[1]!, id: m[2]! });
      last = m.index + m[0].length;
    }
    if (last < text.length) segments.push({ kind: "text" as const, text: text.slice(last) });
    return segments;
  },
};

const MentionText = createDirectiveText(bracketFormatter);

export function Message({ text }: { text: string }) {
  return <MentionText text={text} />;
}
```

</Steps>

## 结构

文本中没有指令匹配项的消息会渲染为原始字符串，不包含包装元素。一旦至少存在一个匹配项，文本就会拆分为一系列片段：

```tsx
<>
  <span>{textBetweenDirectives}</span>
  <span data-slot="directive-text-chip" data-directive-type={type} data-directive-id={id} aria-label={`${type}: ${label}`}>
    <Icon />
    {label}
  </span>
  {/* repeated per segment, in order */}
</>
```

每个芯片的图标来自 `iconMap[type]`；当映射中没有该类型的条目时，则回退到 `fallbackIcon`；如果两者都未提供，则不显示图标。芯片是固定的、采用 secondary 样式的徽章，不提供 `className` 覆盖；需要不同样式的渲染器应自行调用 `formatter.parse`，将片段映射为自己的标记，而不是使用 `createDirectiveText`。

## 示例

### Assistant-ui 的默认指令格式

不使用自定义解析器时，`DirectiveText` 和传入 `unstable_defaultDirectiveFormatter` 的 `createDirectiveText` 调用都能理解 `:type[label]{name=id}`；当 `id` 等于 `label` 时会省略 `{name=…}` 属性，因此 `:tool[Search]` 和 `:tool[Search]{name=web-search}` 都可以解析，后者使用不同的 `id`。

```tsx
"Ask :tool[Search]{name=web-search} to look this up."
// → "Ask ", a chip labeled "Search" (type "tool", id "web-search"), " to look this up."
```

### 将指令类型映射到图标

无论格式化器是默认格式化器还是你自己的格式化器，`iconMap` 和 `fallbackIcon` 的工作方式都相同；键名与每个片段的 `type` 匹配。

```tsx
import { WrenchIcon, SlashIcon, SparklesIcon } from "lucide-react";

createDirectiveText(unstable_defaultDirectiveFormatter, {
  iconMap: { tool: WrenchIcon, command: SlashIcon },
  fallbackIcon: SparklesIcon,
});
```

`unstable_useMentionAdapter` 的模型上下文工具默认为 `type: "tool"`，而 `unstable_useSlashCommandAdapter` 的命令默认为 `type: "command"`，因此这对键可以开箱即用地覆盖两者。

## API 参考

<RuntimeMode>

### DirectiveText

| 导出项 | 类型 | 描述 |
|--------|------|-------------|
| `DirectiveText` | `TextMessagePartComponent` | 开箱即用；解析 assistant-ui 的默认 `:type[label]{name=id}` 语法。作为 `MessagePrimitive.Parts` 的 `components.Text` 传入。 |
| `createDirectiveText(formatter, options?)` | `(formatter, options?) => TextMessagePartComponent` | 围绕任意格式化器构建 `Text` 渲染器，用于自定义 `iconMap` 或 `fallbackIcon`。 |

### 指令片段

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `kind` | `"text" \| "mention"` | 片段所属的形状。 |
| `text` | `string` | 原义文本片段，用于 `kind: "text"`。 |
| `type` | `string` | 指令的类型，用于 `kind: "mention"`；也用于查找图标。 |
| `label` | `string` | 显示在芯片内部。 |
| `id` | `string` | 不会显示；包含在 `data-directive-id` 中。 |

</RuntimeMode>

<StandaloneMode>

### createDirectiveText

| 参数 | 类型 | 描述 |
|-----------|------|-------------|
| `formatter` | `DirectiveTextFormatter` | 包含 `parse(text): readonly DirectiveTextSegment[]` 方法的对象。 |
| `options.iconMap` | `Record<string, IconComponent>` | 将片段的 `type` 映射到图标。 |
| `options.fallbackIcon` | `IconComponent` | 当 `iconMap` 中没有片段 `type` 对应的条目时使用。 |

返回一个只有单个属性 `text: string` 的组件。

### DirectiveTextFormatter

| 方法 | 类型 | 描述 |
|--------|------|-------------|
| `parse` | `(text: string) => readonly DirectiveTextSegment[]` | 独立渲染器所需的唯一方法；你可以编写任意语法。`Unstable_DirectiveFormatter`（同时还具有 `serialize`）满足此类型，因此 `unstable_defaultDirectiveFormatter` 在这里同样适用。 |

</StandaloneMode>
