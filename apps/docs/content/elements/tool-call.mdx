---
title: "工具调用"
description: "一次工具调用，其请求和结果收纳在折叠面板后方。"
---

工具调用在执行期间会折叠为一行：显示一个尖括号、闪烁的标签，以及作为标签芯片显示的工具主要参数；完成后显示对勾。点击后可查看原始请求和结果。在运行时中，请求、结果和运行状态来自匹配的工具调用部分；单独使用时，则由你直接提供这些值。

## 入门

<RuntimeMode>

工具调用通过工具包条目的 `render` 字段渲染，而不是通过独立的原语树渲染。渲染器会接收此次调用对应的实时 `args`、`argsText`、`result` 和 `status`。

<Steps>
  <Step>

### 渲染工具调用

```tsx title="components/assistant-ui/elements/search-docs-tool-ui.tsx"
"use client";

import { useState } from "react";
import type { ToolCallMessagePartComponent } from "@assistant-ui/react";
import { ToolCall } from "@/components/assistant-ui/elements/tool-call";

type SearchDocsResult = { count: number; bestPath: string };

export const SearchDocsToolUI: ToolCallMessagePartComponent<
  { query: string },
  SearchDocsResult
> = ({ args, argsText, result, status }) => {
  const [open, setOpen] = useState(false);
  return (
    <ToolCall
      label="Searched the docs"
      activeLabel="Searching the docs"
      query={args.query ?? ""}
      request={argsText}
      result={result ? `${result.count} matches, best hit ${result.bestPath}` : ""}
      running={status.type === "running"}
      open={open}
      onOpenChange={setOpen}
    />
  );
};
```

  </Step>
  <Step>

### 注册工具

```tsx title="app/toolkit.ts"
import { defineToolkit } from "@assistant-ui/react";
import { z } from "zod";
import { SearchDocsToolUI } from "@/components/assistant-ui/elements/search-docs-tool-ui";

export const toolkit = defineToolkit({
  search_docs: {
    type: "frontend",
    description: "Search the assistant-ui documentation.",
    parameters: z.object({ query: z.string() }),
    execute: async ({ query }) => {
      const res = await fetch(`/api/search?q=${encodeURIComponent(query)}`);
      return res.json() as Promise<SearchDocsResult>;
    },
    render: SearchDocsToolUI,
  },
});
```

```tsx title="app/MyRuntimeProvider.tsx"
import { AssistantRuntimeProvider, AuiConfig, Tools } from "@assistant-ui/react";
import { useChatRuntime } from "@assistant-ui/ai-sdk";
import { toolkit } from "./toolkit";

export function MyRuntimeProvider({ children }: { children: React.ReactNode }) {
  const runtime = useChatRuntime();
  const config = AuiConfig({ tools: Tools({ toolkit }) });
  return (
    <AssistantRuntimeProvider runtime={runtime} config={config}>
      {children}
    </AssistantRuntimeProvider>
  );
}
```

有关后端定义的工具、人工工具和审批门控，请参阅 [工具 UI](/docs/tools/tool-ui)。

### 使用自己的请求填充

`running`、`result` 以及两个标签都是普通字符串和一个布尔值，因此任何异步调用都可以直接驱动它们：

```tsx
async function search(query: string) {
  setRunning(true);
  const res = await fetch(`/api/search?q=${encodeURIComponent(query)}`).then((r) =>
    r.json(),
  );
  setResult(`${res.count} matches, best hit ${res.bestPath}`);
  setRunning(false);
}
```

  </Step>
</Steps>

## 结构

```tsx
<div data-slot="tool-call">
  <button>
    {/* chevron, shimmering label while running, query chip, checkmark once settled */}
  </button>
  <div>{/* Request block, divider, Result block — mounted only while open */}</div>
</div>
```

触发器始终可见；只有当 `running` 变为 false 时，对勾才会替换空白区域。内容面板的高度会在零和测量得到的高度之间进行动画过渡，因此展开和收起都不会跳动。`open` 完全由 `onOpenChange` 驱动：没有内部状态、没有循环切换，也没有禁用状态，因为请求或结果为空的工具调用只会渲染空字符串。

## 示例

### 重新设置折叠面板样式

两种路径都会在根元素上接收 `className`。触发器、查询芯片以及请求和结果块都读取 `surfaces.tsx` 中共享的 `mono`、`field` 和 `collapsePanel` 令牌，因此重新设置这些令牌的主题即可一次性重新设置所有基于折叠面板的元素样式。

```tsx
<ToolCall className="max-w-none" /* ... */ />
```

<RuntimeMode>

### 注册更多工具

渲染器工厂将标签对排除在工具包定义之外，因此同一个组件可以支持多个搜索类工具：

```tsx
function makeSearchToolUI(label: string, activeLabel: string) {
  const SearchToolUI: ToolCallMessagePartComponent<
    { query: string },
    SearchDocsResult
  > = ({ args, argsText, result, status }) => {
    const [open, setOpen] = useState(false);
    return (
      <ToolCall
        label={label}
        activeLabel={activeLabel}
        query={args.query ?? ""}
        request={argsText}
        result={result ? `${result.count} matches, best hit ${result.bestPath}` : ""}
        running={status.type === "running"}
        open={open}
        onOpenChange={setOpen}
      />
    );
  };
  return SearchToolUI;
}

const toolkit = defineToolkit({
  search_docs: {
    /* ... */ render: makeSearchToolUI("Searched the docs", "Searching the docs"),
  },
  search_issues: {
    /* ... */ render: makeSearchToolUI("Searched issues", "Searching issues"),
  },
});
```

</RuntimeMode>

### 挂载时展开

在首次渲染时将 `open` 作为 `true` 传入（之后再像往常一样在 `onOpenChange` 中切换它），即可让折叠面板初始就处于展开状态，例如重放过去的运行记录时：

```tsx
const [open, setOpen] = useState(true);
```

## API 参考

<RuntimeMode>

### 工具调用渲染 props

| Prop | Type | Description |
|------|------|-------------|
| `args` | `TArgs` | 解析后的参数。模型仍在流式传输参数时，该值可能不完整。 |
| `argsText` | `string` | 模型流式传输的原始 JSON 参数文本；会直接传给 `request`。 |
| `result` | `TResult \| undefined` | 工具完成后返回的值。运行期间为 `undefined`。 |
| `status` | `ToolCallMessagePartStatus` | `status.type` 为 `"running"`、`"requires-action"`、`"complete"` 或 `"incomplete"`。 |
| `toolName` | `string` | 模型调用的工具名称。 |
| `toolCallId` | `string` | 此次调用的稳定 ID。 |
| `isError` | `boolean \| undefined` | `result` 是否表示工具执行错误。 |

在工具包条目的 `render` 字段上注册渲染器，并使用 `Tools({ toolkit })` 附加工具包。有关完整的渲染 props，包括 `addResult`、人工工具和审批门控，请参阅 [工具 UI](/docs/tools/tool-ui)。

</RuntimeMode>

<StandaloneMode>

### ToolCall

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `label` | `string` | required | 调用完成后显示的文本。 |
| `activeLabel` | `string` | required | 当 `running` 为 true 时显示的闪烁文本。 |
| `query` | `string` | required | 主要参数，作为芯片显示在标签旁边。 |
| `request` | `string` | required | 折叠面板中显示的原始请求文本。 |
| `result` | `string` | required | 折叠面板中显示的结果文本。 |
| `running` | `boolean` | required | 为 true 时替换标签并隐藏对勾。 |
| `open` | `boolean` | required | 折叠面板是否展开。 |
| `onOpenChange` | `(open: boolean) => void` | required | 点击触发器时调用。 |
| `className` | `string` | | 合并到根元素上。 |

与此目录中的大多数元素不同，`ToolCall` 不会将额外的 `div` props 展开到根元素上；只接受上述 props。

</StandaloneMode>
