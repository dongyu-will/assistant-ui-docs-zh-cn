一个有节奏 pulsating 的圆点、每次变化时都会重新淡入的标签，以及可选的已用时间徽章。使用运行时（runtime）时，你可以根据消息当前能提供的信息推导标签，并自行更新已用时间徽章；单独使用时，则直接传入这两个值。

## 入门

<RuntimeMode>

运行时不会直接提供“正在阅读文档”这样的短语，而是提供截至目前组成消息的各个部分。你能据此构建的最具体标签，就是当前仍在等待的工具调用名称；当运行仍处于活动状态但暂时没有其他进展时，则回退为普通的“思考中”。

<Steps>
  <Step>

### 根据消息部分命名当前操作

```tsx title="components/assistant-ui/elements/thinking-indicator.tsx"
"use client";

import { useAuiState } from "@assistant-ui/react";

function useThinkingLabel() {
  return useAuiState((s) => {
    if (s.message.status?.type !== "running") return undefined;
    const pending = s.message.parts.find(
      (part) => part.type === "tool-call" && part.result === undefined,
    );
    if (pending?.type === "tool-call") return `Running ${pending.toolName}`;
    return s.message.parts.length === 0 ? "Thinking" : undefined;
  });
}
```

助手完成可见文本的流式输出且没有待处理的工具调用后，这会返回 `undefined`：这就是你应停止渲染指示器、改为显示实际内容的信号。

  </Step>
  <Step>

### 更新已用时间徽章

```tsx
import { useEffect, useState } from "react";
import { ThinkingIndicator } from "@/components/assistant-ui/elements/thinking-indicator";

function useElapsedLabel(active: boolean) {
  const [label, setLabel] = useState<string | undefined>(undefined);
  useEffect(() => {
    if (!active) {
      setLabel(undefined);
      return;
    }
    const start = Date.now();
    const id = setInterval(() => {
      setLabel(`${Math.round((Date.now() - start) / 1000)}s`);
    }, 1000);
    return () => clearInterval(id);
  }, [active]);
  return label;
}

function AssistantThinking() {
  const label = useThinkingLabel();
  const elapsed = useElapsedLabel(label !== undefined);
  if (label === undefined) return null;
  return <ThinkingIndicator label={label} elapsed={elapsed} />;
}
```

运行时没有用于获取“目前已经过了多少秒”的选择器：`metadata.timing` 只有在消息停止流式输出后才会最终确定，因此实时徽章需要使用自己的计时器，并在有标签可显示的瞬间启动。

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

单独使用时，`label` 是普通字符串，`elapsed` 也是普通字符串；组件只负责标签之间的淡入效果和布局。

<Steps>
  <Step>

### 自行维护标签

```tsx title="app/status.tsx"
"use client";

import { useState } from "react";
import { ThinkingIndicator } from "@/components/assistant-ui/elements/thinking-indicator";

export function Status() {
  const [label, setLabel] = useState("Thinking");
  return <ThinkingIndicator label={label} />;
}
```

更改 `label` 会在新文本上重新播放闪光和滑入动画；组件会根据字符串本身为内部标签设置 key。

  </Step>
  <Step>

### 添加已用时间

```tsx
<ThinkingIndicator label={label} elapsed="12s" />
```

完全省略 `elapsed` 即可隐藏徽章；传入空字符串仍会渲染徽章。

  </Step>
</Steps>

</StandaloneMode>

## 示例

### 响应待处理的工具调用

只需更改标签即可；由于元素会根据标签文本为其闪光动画的 span 设置 key，淡入效果会自动触发。

```tsx
const pending = message.parts.find(
  (part) => part.type === "tool-call" && part.result === undefined,
);
const label = pending?.type === "tool-call" ? `Running ${pending.toolName}` : "Thinking";
```

### 重新设置状态行样式

圆点固定使用 `bg-blue-500`；标签使用 `ShimmerLabel`，已用时间徽章使用来自 `surfaces.tsx` 的共享 `mono` token。根元素上的 `className` 只会影响布局（初始值为 `flex items-center gap-2.5`）。

```tsx
<ThinkingIndicator label={label} elapsed={elapsed} className="gap-1.5 text-xs" />
```

## API 参考

<RuntimeMode>

### 消息状态

| 选择器 | 类型 | 描述 |
|----------|------|-------------|
| `s.message.status` | `MessageStatus \| undefined` | 助手仍在生成此消息时为 `status.type === "running"`。 |
| `s.message.parts` | `readonly PartState[]` | 查找尚未包含 `result` 的 `"tool-call"` 部分，以确定当前正在运行的操作；如果消息仍在运行但数组为空，则表示尚未收到任何内容。 |

</RuntimeMode>

<StandaloneMode>

### ThinkingIndicator

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `label` | `string` | 必填 | 状态文本；更改后会重新播放淡入效果。 |
| `elapsed` | `string \| undefined` | | 显示在标签后的预格式化已用时间。省略此属性即可隐藏徽章。 |
| `className` | `string` | | 合并到根元素上。 |

除 `children` 外，所有其他 `div` 属性都会转发到根元素。

</StandaloneMode>
