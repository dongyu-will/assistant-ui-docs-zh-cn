---
title: "提及"
description: "输入 @，即可将人员和代理引入对话，并在输入过程中进行筛选。"
---

输入 `@` 后，会在输入框上方打开一个浮动的人员菜单；选择人员后会插入一条提及内容，并可紧接着继续输入。在运行时中，该菜单由与斜杠命令相同的触发原语驱动，只是连接的是提及适配器，而不是命令适配器；单独使用时，则可以通过 `useMentionMatches` 自行筛选普通列表，并使用 `applyMention` 插入所选项目。

## 快速开始

<RuntimeMode>

提及和斜杠命令共享同一个触发系统，该系统根据打开弹出层的字符进行区分；有关该机制本身，请参阅[斜杠命令](/elements/composer-slash-commands)。提及使用 `@` 字符和 `Directive` 行为，后者会插入文本，而不是触发处理器。

<Steps>
  <Step>

### 定义人员

`unstable_useMentionAdapter` 将人员列表封装为触发器所需的 `{ adapter, directive }` 对。如果不提供 `items` 或 `categories`，它会默认列出在线程模型上下文中注册的工具，因此 `@` 既可以像提及人员一样轻松地提及工具：

```tsx title="components/assistant-ui/elements/composer-mentions.tsx"
"use client";

import { unstable_useMentionAdapter } from "@assistant-ui/react";

export function useComposerMentions() {
  return unstable_useMentionAdapter({
    items: [
      { id: "ada", type: "person", label: "Ada Lovelace" },
      { id: "grace", type: "person", label: "Grace Hopper" },
    ],
  });
}
```

  </Step>
  <Step>

### 在 `@` 上打开弹出层

```tsx title="components/assistant-ui/elements/composer-bar.tsx"
"use client";

import { ComposerPrimitive } from "@assistant-ui/react";
import { cn } from "@/lib/utils";
import { floating, mono } from "@/components/assistant-ui/elements/surfaces";
import { useComposerMentions } from "./composer-mentions";

export function ComposerBar() {
  const mention = useComposerMentions();

  return (
    <ComposerPrimitive.Unstable_TriggerPopoverRoot>
      <ComposerPrimitive.Unstable_TriggerPopover char="@" adapter={mention.adapter}>
        <ComposerPrimitive.Unstable_TriggerPopover.Directive
          formatter={mention.directive.formatter}
          onInserted={mention.directive.onInserted}
        />
        <ComposerPrimitive.Unstable_TriggerPopoverItems>
          {(items) => (
            <div className={cn(floating, "absolute bottom-full z-10 mb-2 w-64 rounded-2xl p-1.5")}>
              {items.map((item, index) => (
                <ComposerPrimitive.Unstable_TriggerPopoverItem
                  key={item.id}
                  item={item}
                  index={index}
                  className="data-[highlighted]:bg-foreground/[0.04] flex w-full items-center gap-2.5 rounded-[10px] px-2.5 py-2 outline-none"
                >
                  <span className="bg-foreground/[0.06] text-foreground/45 flex size-5 shrink-0 items-center justify-center rounded-full text-[9px] font-medium">
                    {item.label[0]}
                  </span>
                  <span className="flex-1 truncate text-start">{item.label}</span>
                  <span className={cn(mono, "text-foreground/35")}>{item.type}</span>
                </ComposerPrimitive.Unstable_TriggerPopoverItem>
              ))}
            </div>
          )}
        </ComposerPrimitive.Unstable_TriggerPopoverItems>
      </ComposerPrimitive.Unstable_TriggerPopover>
      <ComposerPrimitive.Root className="flex w-full flex-col gap-2 rounded-[24px] p-2.5">
        <ComposerPrimitive.Input placeholder="Message, or @ to mention..." rows={1} className="min-h-11 w-full resize-none bg-transparent px-3 outline-none" />
      </ComposerPrimitive.Root>
    </ComposerPrimitive.Unstable_TriggerPopoverRoot>
  );
}
```

`.Directive` 会在触发位置插入项目的序列化文本，随后调用 `onInserted`，而不是像 `.Action` 那样触发处理器。若要在消息中将已发送的提及重新渲染为标签（而不是字面指令文本），请在消息渲染侧将其与[指令文本](/elements/directive-text)搭配使用。

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

单独使用时，不会有任何机制替你检测 `@`。`useMentionMatches` 会根据以末尾 `@query` 结尾的文本筛选人员列表，而 `applyMention` 会在选择后用所选人员的姓名替换该末尾查询文本。

<Steps>
  <Step>

### 随草稿变化进行筛选

```tsx title="app/chat-box.tsx"
"use client";

import { useState } from "react";
import { useMentionMatches, applyMention, ComposerMenu, ComposerPersonItem, type ComposerPerson } from "@/components/assistant-ui/elements/composer";

const people: ComposerPerson[] = [
  { name: "Ada", role: "human" },
  { name: "Grace", role: "human" },
  { name: "Reviewer", role: "agent" },
];

export function ChatBox() {
  const [text, setText] = useState("");
  const matches = useMentionMatches(text, people);

  return (
    <div className="relative">
      <ComposerMenu open={matches.length > 0}>
        {matches.map((person) => (
          <ComposerPersonItem
            key={person.name}
            person={person}
            active={false}
            onClick={() => setText((current) => applyMention(current, person.name))}
          />
        ))}
      </ComposerMenu>
      {/* ComposerInput below, controlled by the same text state */}
    </div>
  );
}
```

  </Step>
  <Step>

### 选择后继续输入

`applyMention` 会在插入的姓名后保留一个末尾空格，因此光标可以立即继续输入；它只会处理末尾的 `@query`，不会影响草稿中更早输入的文本。

  </Step>
</Steps>

</StandaloneMode>

## 构成

```tsx
<div data-slot="composer-menu" data-open={/* true while a trailing "@query" exists */}>
  <button data-slot="composer-menu-item" data-active={/* the highlighted row */}>
    {/* initial-letter avatar, name, and a role label ("agent" or "human") */}
  </button>
</div>
```

在运行时中，选择项目不会直接将标签插入文本区域；它会按照 `unstable_defaultDirectiveFormatter` 的 `:type[label]{name=id}` 语法插入字面指令文本（当 `id` 和 `label` 匹配时，会移除 `{name=…}` 部分），只有消息渲染器将其重新解析后，才会渲染为标签。单独使用时，`applyMention` 会直接插入普通姓名，因为没有消息渲染步骤来接收指令。

## 示例

### 随输入进行筛选

<RuntimeMode>

适配器的 `search` 会以不区分大小写的方式，将人员的 `id`、`label` 和 `description` 与 `@` 之后的文本进行匹配；使用 `categories` 而不是 `items` 时，匹配会按类别逐级展开，而不是一次搜索所有内容。

```tsx
mention.adapter.search("ada"); // → [{ id: "ada", label: "Ada Lovelace", ... }]
```

</RuntimeMode>

<StandaloneMode>

`useMentionMatches` 会在文本中查找末尾的 `@word`，并将其与每个人的 `name` 开头进行匹配：

```tsx
const matches = useMentionMatches("cc @ada", people); // → [{ name: "Ada", ... }]
```

</StandaloneMode>

### 提及工具而不是人员

<RuntimeMode>

不设置 `items` 和 `categories`（或同时传入 `includeModelContextTools: true`）时，会列出当前在 `aui.thread.getModelContext.tools` 上注册的所有工具，因此 `@` 也可以用来引用模型可访问的工具：

```tsx
const mention = unstable_useMentionAdapter({
  includeModelContextTools: true,
});
```

改为传入 `includeModelContextTools: { category }` 时，工具会置于一个可逐级展开的入口下，而不是平铺列出，除非同时提供 `items`。

</RuntimeMode>

### 重新设置菜单样式

两种展示路径都会渲染到 `ComposerMenu` 中；头像圆圈、姓名和角色标签分别是独立的 `span`，因此重新设置其中一项的样式无需修改其他项。

```tsx
<ComposerMenu className="w-80" open={open}>
  {/* items */}
</ComposerMenu>
```

## API 参考

<RuntimeMode>

### ComposerPrimitive（触发器）

| 部分 | 渲染内容 | 说明 |
|------|---------|-------|
| `Unstable_TriggerPopoverRoot` | provider | 与其中注册的每个触发字符共享；请参阅[斜杠命令](/elements/composer-slash-commands)。 |
| `Unstable_TriggerPopover` | `div`（打开时） | `char="@"`、`adapter`。 |
| `Unstable_TriggerPopover.Directive` | 行为 | `formatter?`、`onInserted?`；在触发位置插入序列化的指令文本。 |
| `Unstable_TriggerPopoverItems` / `Item` | render prop / `button` | 形状与斜杠命令弹出层相同；在键盘导航下，`Item` 会获得 `data-highlighted`。 |

### unstable_useMentionAdapter

| 选项 | 类型 | 描述 |
|--------|------|-------------|
| `items` | `Unstable_Mention[]` | 平铺列表：`{ id, type, label, description?, icon?, metadata? }`；提供该选项后，即使配置了工具 `category`，适配器仍会保持平铺。 |
| `categories` | `Unstable_MentionCategory[]` | 用于逐级展开导航的分组提及；优先级高于 `items`。 |
| `includeModelContextTools` | `boolean \| { category?, formatLabel?, icon? }` | 从 `aui.thread.getModelContext()` 包含工具；对象 `category` 会自行选择逐级展开，除非提供 `items`。当既未提供 `items` 也未提供 `categories` 时，默认值为 `true` |
| `formatter` | `Unstable_DirectiveFormatter` | 默认值为 `unstable_defaultDirectiveFormatter` |
| `onInserted` | `(item) => void` | 指令文本写入输入框后触发。 |

返回 `{ adapter, directive, iconMap?, fallbackIcon? }`；将 `directive` 展开到 `Unstable_TriggerPopover.Directive` 上。

</RuntimeMode>

<StandaloneMode>

### useMentionMatches

| 参数 | 类型 | 描述 |
|-----------|------|-------------|
| `value` | `string` | 当前草稿文本。 |
| `people` | `readonly ComposerPerson[] \| undefined` | 完整的人员列表。 |

返回 `name` 以末尾 `@query` 开头的人员；如果光标不在其中，则返回 `[]`。

### applyMention

`applyMention(value: string, name: string): string` 会将 `value` 中末尾的 `@query` 替换为 `@{name} `（包括末尾空格）。

### ComposerPerson

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `name` | `string` | 用于与查询匹配；显示由姓名首字母构成的头像。 |
| `role` | `"agent" \| "human"` | 作为行标签显示。 |

### ComposerPersonItem

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `person` | `ComposerPerson` | required | 要渲染的人员。 |
| `active` | `boolean` | required | 为该行设置色调。 |

</StandaloneMode>
