---
title: "时间戳"
description: "长线程中的时间顺序：标记日期，悬停显示时间。"
---

DaySeparator 将扁平的消息列表排列为文字记录，在日期发生变化时插入日期标题，并在悬停时显示每条消息的时间。使用运行时（runtime）时，你可以从线程自身的消息中派生出这个列表；独立使用时，你已经持有该列表。

## 开始使用

<RuntimeMode>

每条消息都包含真实的 `createdAt`（一个 `Date`）和 `role`，而线程的完整消息列表以普通状态提供，因此构建按日期分组的结构只涉及格式化和文本提取，不需要新增连接逻辑。

<Steps>
  <Step>

### 读取线程的消息

```tsx title="components/assistant-ui/elements/thread-history.tsx"
"use client";

import { useAuiState } from "@assistant-ui/react";
import { DaySeparator, type DatedMessage } from "@/components/assistant-ui/elements/day-separator";

const dayFormat = new Intl.DateTimeFormat("en-US", { month: "short", day: "numeric" });
const timeFormat = new Intl.DateTimeFormat("en-US", { hour: "numeric", minute: "2-digit" });

export function ThreadHistory() {
  const messages = useAuiState((s) => s.thread.messages);

  const dated: DatedMessage[] = messages
    .filter((m) => m.role !== "system")
    .map((m) => ({
      id: m.id,
      day: dayFormat.format(m.createdAt),
      time: timeFormat.format(m.createdAt),
      role: m.role === "user" ? "user" : "assistant",
      text: m.content
        .filter((part): part is { type: "text"; text: string } => part.type === "text")
        .map((part) => part.text)
        .join(" "),
    }));

  return <DaySeparator messages={dated} />;
}
```

`s.thread.messages` 仅包含当前分支：重新加载消息或编辑较早的消息时，这里显示的消息会随之切换，与线程中其他位置的行为一致。

  </Step>
  <Step>

### 将其作为预览，而不是消息记录

将内容扁平化为 `text` 会丢失工具调用、图片和推理，因此这种组合更适合紧凑的历史记录视图，而不是实时对话。使用 `ThreadPrimitive.Messages` 和 `MessagePrimitive.Parts` 渲染线程本身；组合 `Thread` 已经随附，这样丰富内容仍能在那里完整渲染。

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

独立使用时，DaySeparator 一次接收完整列表：你持有这个数组，并在对话增长时向其中追加内容。

<Steps>
  <Step>

### 持有消息列表

```tsx title="app/history.tsx"
"use client";

import { useState } from "react";
import { DaySeparator, type DatedMessage } from "@/components/assistant-ui/elements/day-separator";

const MESSAGES: DatedMessage[] = [
  { id: "1", day: "Yesterday", time: "16:04", role: "user", text: "Why does the draft survive a reload?" },
  { id: "2", day: "Yesterday", time: "16:04", role: "assistant", text: "It's persisted per thread." },
];

export function History() {
  const [messages, setMessages] = useState(MESSAGES);
  return <DaySeparator messages={messages} />;
}
```

  </Step>
  <Step>

### 随对话增长进行追加

```tsx
setMessages((prev) => [
  ...prev,
  { id: crypto.randomUUID(), day: "Today", time: "09:12", role: "user", text },
]);
```

当某条记录的 `day` 与前一条记录不同时，日期标题会自动出现；无需进行其他更改。

  </Step>
</Steps>

</StandaloneMode>

## 结构

```tsx
<div data-slot="day-separator">
  {/* per message: an optional day header (rule, label, rule) when `day` differs from the previous entry, then the row */}
  <div>{/* user rows sit right-aligned in a filled bubble; assistant rows sit left-aligned as plain text */}</div>
</div>
```

日期比较只会查看紧邻的前一条记录，因此列表必须已经按时间顺序排列；顺序错乱的记录会重复显示标题，而不会合并到上一个标题中。每一行的时间默认是透明的，仅在悬停该行时淡入（`group-hover`），因此在查找时间戳之前，列表始终保持简洁。

## 示例

### 紧凑的历史记录，而不是实时消息记录

<RuntimeMode>

将 `ThreadHistory` 与真实的 `Thread` 并列使用，例如将其作为可搜索的侧边栏或“跳转到”列表，而不是替代后者。用户在其中选择条目时，执行的是普通的分支或线程切换，而不是该组件自行完成的操作。

</RuntimeMode>

<StandaloneMode>

同样的结构也适用于只读消息记录，例如从 API 一次性获取完整内容，并在未连接任何运行时的情况下进行渲染。

</StandaloneMode>

### 重新设置分隔线和气泡的样式

两条轨道的根元素都接收 `className`。日期标签和悬停显示的时间会从 `surfaces.tsx` 读取共享的 `mono` 表面样式。

```tsx
<DaySeparator className="max-w-none gap-3" messages={messages} />
```

## API 参考

<RuntimeMode>

### 线程状态

| 选择器 | 类型 | 描述 |
|----------|------|-------------|
| `s.thread.messages` | `readonly MessageState[]` | 线程当前分支中的每条消息，每条消息都包含 `id`、`role`、`createdAt` 和 `content`。 |
| `message.createdAt` | `Date` | 用于派生 `day` 和 `time`；格式由你自行决定，运行时不会提供预先格式化的结果。 |
| `message.content` | `readonly ThreadAssistantMessagePart[] \| readonly ThreadUserMessagePart[]` | 用于筛选 `type === "text"` 部分，以构建扁平的预览字符串。 |

</RuntimeMode>

<StandaloneMode>

### DaySeparator

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `messages` | `readonly DatedMessage[]` | 必填 | 要渲染的完整有序列表。 |
| `className` | `string` | | 合并到根元素上。 |

### DatedMessage

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `id` | `string` | |
| `day` | `string` | 与前一条记录的 `day` 比较，以决定是否渲染标题。 |
| `time` | `string` | 在悬停该行时显示。 |
| `role` | `"user" \| "assistant"` | 控制对齐方式和气泡样式。 |
| `text` | `string` | |

其他所有 `div` 属性都会转发到根元素。

</StandaloneMode>
