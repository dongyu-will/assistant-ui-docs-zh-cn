title: "语法高亮器"

SyntaxHighlighter 通过 `react-syntax-highlighter` 的异步轻量构建，使用 Prism 对一个围栏代码块进行分词，同时渲染浅色和深色主题变体，因此切换主题无需重新渲染。在运行时中，它会替换 [Markdown 文本](/elements/markdown-text) 默认渲染的纯代码；单独使用时，则需要直接传入代码、语言以及它要挂载到的标签组件。

## 快速开始

<Steps>

### 将其添加到 MarkdownText 的组件中

```tsx title="components/assistant-ui/elements/markdown-text.tsx"
import { SyntaxHighlighter } from "./syntax-highlighter";

const defaultComponents = memoizeMarkdownComponents({
  SyntaxHighlighter,
  h1: /* ... */,
  // ...other elements...
});
```

现在，助手消息中的每个围栏代码块都会使用浅色和深色 Coldark Prism 主题进行高亮。[Shiki 高亮器](/elements/shiki-highlighter) 是更新且支持运行时感知的替代方案：如果你已经在使用 `react-syntax-highlighter`，可以优先选择它。

  </Step>
</Steps>

### 直接调用

```tsx
import { SyntaxHighlighter } from "@/components/assistant-ui/elements/syntax-highlighter";

<SyntaxHighlighter
  language="tsx"
  code="const x = 1;"
  components={{
    Pre: (props) => <pre {...props} />,
    Code: (props) => <code {...props} />,
  }}
/>;
```

`components.Pre` 和 `components.Code` 是高亮器用于渲染的标签组件。`react-markdown` 的代码块处理流程会在 MarkdownText 内自动提供真实组件；单独使用时，请自行传入元素。

  </Step>
</Steps>

## 构成

```tsx
<>
  <Pre className="dark:hidden">{/* Coldark Cold tokens */}</Pre>
  <Pre className="hidden dark:block">{/* Coldark Dark tokens */}</Pre>
</>
```

浅色和深色高亮器都会在每次渲染时挂载；Tailwind 的 `dark:` 类会隐藏与当前主题不匹配的那个变体，因此切换主题时只需切换可见性，无需重新进行分词。

## 示例

### 注册其他语言

```tsx title="components/assistant-ui/elements/syntax-highlighter.tsx"
import { PrismAsyncLight } from "react-syntax-highlighter";
import go from "react-syntax-highlighter/dist/esm/languages/prism/go";

PrismAsyncLight.registerLanguage("go", go);
```

默认仅注册了 `js`、`jsx`、`ts`、`tsx`（它们都映射到 TSX 语法）以及 `python`。语言未注册的围栏代码块仍会渲染，但不会进行高亮。

### 改为加载所有语言

```tsx title="components/assistant-ui/elements/syntax-highlighter.tsx"
import { makePrismAsyncSyntaxHighlighter } from "@assistant-ui/react-syntax-highlighter/full";
```

将轻量构建的导入替换为完整构建，即可完全跳过按语言注册，但代价是更大的 bundle。

### 选择其他主题

```tsx title="components/assistant-ui/elements/syntax-highlighter.tsx"
import { oneLight, oneDark } from "react-syntax-highlighter/dist/cjs/styles/prism";

const LightSyntaxHighlighter = makePrismAsyncLightSyntaxHighlighter({
  style: oneLight,
  customStyle: syntaxHighlighterCustomStyle,
  className: "dark:hidden",
});
```

可以传入任意 `react-syntax-highlighter` Prism 样式，以替代 `coldarkCold`/`coldarkDark`；深色变体同样如此。

## API 参考

<RuntimeMode>

MarkdownText 的代码块处理流程会根据正在渲染的围栏代码块，自动提供下面的所有 prop；将其接入 `components` 后，无需再自行调用 `SyntaxHighlighter`。

</RuntimeMode>

### SyntaxHighlighter

| Prop | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `language` | `string` | 必填 | 围栏代码块的语言，例如 `"tsx"`。用于选择 Prism 语法。 |
| `code` | `string` | 必填 | 要高亮的代码。 |
| `components` | `{ Pre: ComponentType; Code: ComponentType }` | 必填 | 高亮器用于渲染的标签组件，例如 `PreTag`/`CodeTag`。 |
