`ClaudeLogo`、`OpenAILogo` 和 `GeminiLogo` 是三个模型提供商的内联 SVG 标志，尺寸和颜色行为与其他图标一致。使用运行时（runtime）时，通常会将其中一个作为图标传给模型列表；单独使用时，则可以将其放在任何需要展示提供商标志的位置。

## 入门

<RuntimeMode>

`ModelSelector` 自带的 `ModelOption` 类型包含一个可选的 `icon: ReactNode`，会在触发器和列表中显示在模型名称旁边。assistant-ui 不知道哪个标志对应哪个提供商；构建选项列表时，需要由你自行设置这种映射关系。

<Steps>
  <Step>

### 为每个模型选项附加 logo

```tsx title="components/assistant-ui/elements/model-catalog.ts"
import { ClaudeLogo, OpenAILogo, GeminiLogo } from "@/components/assistant-ui/elements/logos";
import type { ModelOption } from "@/components/assistant-ui/elements/model-selector";

export const models: ModelOption[] = [
  { id: "claude-sonnet-5", name: "Sonnet 5", icon: <ClaudeLogo className="size-4" /> },
  { id: "gpt-5.6-luna", name: "GPT-5.6", icon: <OpenAILogo className="size-4" /> },
  { id: "gemini-3-pro", name: "Gemini 3 Pro", icon: <GeminiLogo className="size-4" /> },
];
```

按照 [模型选择器](/elements/model-selector) 文档中的方式，将 `models` 传给 `ModelSelectorRoot`，或传给连接运行时的 `ModelSelector` kit 组件；只要图标位于选项中，它就会自动显示。

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

单独使用时完全不涉及状态：渲染所需的标志即可，其尺寸和颜色行为与其他图标一致。

<Steps>
  <Step>

### 渲染标志

```tsx title="app/providers.tsx"
import { ClaudeLogo, OpenAILogo, GeminiLogo } from "@/components/assistant-ui/elements/logos";

export function Providers() {
  return (
    <div className="flex items-center gap-3">
      <OpenAILogo className="size-6" />
      <ClaudeLogo className="size-6" />
      <GeminiLogo className="size-6" />
    </div>
  );
}
```

  </Step>
</Steps>

</StandaloneMode>

## 示例

### 重新着色

`OpenAILogo` 使用 `currentColor` 填充，因此和其他图标一样，会遵循文本颜色类：

```tsx
<OpenAILogo className="size-5 text-foreground/60" />
```

`ClaudeLogo` 和 `GeminiLogo` 使用各自固定的品牌颜色，分别是纯橙色填充和从左到右的渐变，因此文本颜色类对它们都不起作用。

### `svg` 接受的每个 prop 仍然有效

`LogoProps` 与 `ComponentProps<"svg">` 完全一致，因此 `width`、`height`、`aria-hidden` 以及其他原生 `svg` 属性都会直接透传，并分别覆盖此文件自身的默认值（`aria-hidden="true"`；对于 OpenAI 和 Gemini，还包括 `fill`）。

```tsx
<ClaudeLogo width={20} height={20} aria-hidden={false} role="img" />
```

## API 参考

<RuntimeMode>

### ModelOption

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `icon` | `ReactNode` | `ModelSelector` 的触发器和列表会将其渲染在模型名称旁边。三个 logo 中的任意一个都可以使用；这种映射不会由系统自动计算。 |

这里没有专用的选择器：这是一个由你设置的字段，位于你已经传给 `ModelSelectorRoot` 的数组中。其余数据结构请参阅[模型选择器](/elements/model-selector)。

</RuntimeMode>

<StandaloneMode>

### ClaudeLogo、OpenAILogo、GeminiLogo

| 导出项 | 填充 | 备注 |
|--------|------|-------|
| `ClaudeLogo` | 固定，`#D97757` | 忽略 `currentColor`；只有 `<path>` 自身的填充会绘制该标志。 |
| `OpenAILogo` | `currentColor` | 会使用文本颜色工具类重新着色。 |
| `GeminiLogo` | 固定，从左到右的渐变 | 通过 `useId` 为每个实例生成全新的渐变 ID，因此同一页面上的多个副本不会发生冲突。 |

每个组件都接受 `LogoProps`，其内容与 `ComponentProps<"svg">` 完全一致。三个组件都不会设置默认尺寸；未指定尺寸时，它们会以 SVG 的固有尺寸渲染，因此请显式传入 `className="size-N"` 或 `width` / `height`。

</StandaloneMode>
