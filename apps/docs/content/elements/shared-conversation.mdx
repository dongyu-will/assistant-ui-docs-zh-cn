---
title: "共享会话"
description: "他人发送给你的只读会话记录，并提供继续使用你自己的副本的方式。"
---

共享会话是他人已经完成并交给你阅读的会话线程：每一轮内容都保持对方留下时的原样，无法进行任何修改，但可以返回到你自己的副本中继续使用。配合运行时使用时，它是通过只读运行时渲染的真实会话线程；单独使用时，则直接渲染 transcript 数组。

## 开始使用

<RuntimeMode>

`ReadonlyThreadProvider` 会将子内容包裹在一个所有变更操作都会抛出异常的会话线程中：发送、取消、编辑和分支操作都不可用。普通的会话线程原语会像渲染其他会话线程一样渲染它，只是处于不可交互状态。

<Steps>
  <Step>

### 将会话记录包裹在只读会话线程中

```tsx title="app/shared/[id]/page.tsx"
"use client";

import { ReadonlyThreadProvider, ThreadPrimitive, MessagePrimitive } from "@assistant-ui/react";
import type { ThreadMessage } from "@assistant-ui/react";

export function SharedThread({ messages }: { messages: readonly ThreadMessage[] }) {
  return (
    <ReadonlyThreadProvider messages={messages}>
      <ThreadPrimitive.Viewport>
        <ThreadPrimitive.Messages>
          {() => <MessagePrimitive.Parts />}
        </ThreadPrimitive.Messages>
      </ThreadPrimitive.Viewport>
    </ReadonlyThreadProvider>
  );
}
```

此会话线程上的每项能力，包括 `edit`、`delete`、`reload`、`cancel` 等，都会报告 `false`，因此会检查 `s.thread.capabilities` 的输入框、重新生成和分支控件无需额外处理就会自动禁用。

  </Step>
  <Step>

### 提供进入真实会话线程的方式

`ReadonlyThreadProvider` 完全没有发送路径；请将继续操作放在它的外部，并连接到应用的真实运行时：

```tsx
import { useAui } from "@assistant-ui/react";
import type { ThreadMessage } from "@assistant-ui/react";

function ContinueButton({ messages }: { messages: readonly ThreadMessage[] }) {
  const app = useAui();
  return (
    <button
      onClick={() =>
        app.thread.import({
          messages: messages.map((message, i) => ({ message, parentId: messages[i - 1]?.id ?? null })),
        })
      }
    >
      Continue in your own chat
    </button>
  );
}
```

将其放置在 `ReadonlyThreadProvider` 上方后，`useAui()` 仍会解析到应用的真实客户端，而不是只读客户端。

  </Step>
</Steps>

</RuntimeMode>

单独使用时，`SharedConversation` 是一张自包含卡片：标题、分享者、各轮消息以及继续按钮都来自 props。

<Steps>
  <Step>

### 渲染共享卡片

```tsx title="app/shared-card.tsx"
"use client";

import { SharedConversation } from "@/components/assistant-ui/elements/shared-conversation";

export function SharedCard({ onContinue }: { onContinue: () => void }) {
  return (
    <SharedConversation
      title="Debugging the flaky test"
      sharedBy="Jordan"
      sharedAt="2 days ago"
      turns={[
        { id: "1", role: "user", text: "Why does this test fail only in CI?" },
        { id: "2", role: "assistant", text: "Most likely a timing assumption..." },
      ]}
      onContinue={onContinue}
    />
  );
}
```

  </Step>
  <Step>

### 保持只读

没有用于编辑或删除某一轮消息的 prop：`turns` 会完全按照给定内容进行渲染，唯一可交互的元素是继续按钮，这与运行时通道中不可用的输入框保持一致。

  </Step>
</Steps>

</StandaloneMode>

## 组成

```tsx
<div data-slot="shared-conversation">
  <div>{/* link icon, title, "shared by X, when" */}</div>
  <div>{/* turns, most recent last */}</div>
  <div>
    <span>read only</span>
    <button>{/* Continue in your own chat */}</button>
  </div>
</div>
```

从行为上看，它更像一张收据，而不是聊天面板：其中除了继续按钮之外没有任何可点击内容，也没有加载状态或空状态；`turns` 应当已经是完整且已结束的会话记录。

## 示例

### 重新设置标题样式

`title`、`sharedBy` 和 `sharedAt` 在内容溢出时都会截断而不是换行，从而无论标题或分享者姓名多长，标题栏都会保持为单行：

```tsx
<SharedConversation title="A very long conversation title that will truncate" sharedBy="Jordan Alvarez" sharedAt="Aug 12" turns={turns} />
```

### 空会话记录

<StandaloneMode>

传入空的 `turns` 数组会渲染标题栏和页脚，中间不显示任何内容；它没有专门的空状态消息，因此能够接收空共享内容的应用应在渲染卡片前将其过滤掉。

</StandaloneMode>

<RuntimeMode>

`ReadonlyThreadProvider` 对空的 `messages` 数组也采用相同处理方式：会话线程会报告 `isEmpty: true`，周围 UI 中的任何 `<AuiIf condition={(s) => s.thread.isEmpty}>` 块也会显示出来，就像真实的空会话线程一样。

</RuntimeMode>

## API 参考

<RuntimeMode>

### 原语部分

| 部分 | 渲染内容 | 备注 |
|------|---------|-------|
| `ReadonlyThreadProvider` | 子内容 | 将 `children` 包裹在由 `messages` 构建的会话线程作用域中。对其执行的任何变更操作都会抛出异常。 |
| `ThreadPrimitive.Viewport` / `.Messages` | `div` / 子内容 | 与其他会话线程中的渲染方式相同。 |

### 会话线程状态和能力

| 选择器 | 类型 | 描述 |
|----------|------|-------------|
| `s.thread.messages` | `readonly MessageState[]` | `messages` prop，形式为已渲染的消息。 |
| `s.thread.isEmpty` | `boolean` | 当 `messages` 为空时为 `true`。 |
| `s.thread.capabilities` | `RuntimeCapabilities` | 每个标志（`edit`、`delete`、`reload`、`cancel`、`attachments` 等）都是 `false`。 |

</RuntimeMode>

<StandaloneMode>

### SharedConversation

| Prop | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `title` | `string` | 必需 | 在标题栏中以截断形式显示。 |
| `sharedBy` | `string` | 必需 | 在标题栏的“分享者”文字后显示。 |
| `sharedAt` | `string` | 必需 | 在分享者姓名后显示，已经过格式化。 |
| `turns` | `readonly SharedTurn[]`（`{ id, role: "user" \| "assistant", text }`） | 必需 | 按顺序渲染。 |
| `onContinue` | `() => void` | | 由页脚按钮调用。 |
| `className` | `string` | | 合并到根元素上。 |

所有其他 `div` props 都会转发到根元素。

</StandaloneMode>
