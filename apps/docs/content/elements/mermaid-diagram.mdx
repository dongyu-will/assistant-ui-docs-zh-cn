title: "Mermaid 图表"
description: "在消息中渲染 Mermaid 图表，包括部分流式输入。"
---

MermaidDiagram 会将带围栏的 `mermaid` 代码块渲染为 SVG 图表；源代码仍在流式传输时显示骨架屏，解析失败时则回退到原始源代码视图。在运行时中，它会从当前消息部分派生流式标志；单独使用时，需要自行传入 `streaming`。

## 快速开始

<RuntimeMode>

该工具包会包装基础图表，并读取当前消息部分是否仍在运行，使模型可以持续输出 `mermaid` 语法，而不会在每个 token 到达时都闪现尚未绘制完成的图表。

<Steps>
  <Step>

### 将其添加到 markdown-text 的语言覆盖项中

```tsx title="components/assistant-ui/elements/markdown-text.tsx"
import { MermaidDiagram } from "@/components/assistant-ui/elements/mermaid-diagram.aui";

const MarkdownTextImpl = () => {
  return (
    <MarkdownTextPrimitive
      remarkPlugins={[remarkGfm]}
      className="aui-md"
      components={defaultComponents}
      componentsByLanguage={{
        mermaid: { SyntaxHighlighter: MermaidDiagram },
      }}
    />
  );
};
```

助手消息中的带围栏 `mermaid` 代码块现在会渲染为图表，而不是代码。

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

单独使用时，需要自行管理流式标志。

<Steps>
  <Step>

### 使用受控的流式标志渲染图表

```tsx
import { MermaidDiagram } from "@/components/assistant-ui/elements/mermaid-diagram";

<MermaidDiagram code={code} streaming={isStreaming} />;
```

当 `streaming` 为 true 时，它会显示骨架屏而不是进行解析；Mermaid 源代码完成后，将其设置为 `false`。

  </Step>
</Steps>

## 结构

```tsx
// streaming
<div data-slot="mermaid-skeleton" aria-label="Rendering diagram" />

// parsed
<div data-slot="mermaid-zoom-wrap">
  <div data-slot="mermaid-diagram" />
  <button data-slot="mermaid-zoom-trigger" aria-label="Expand diagram" />
</div>

// unparseable
<div data-slot="mermaid-fallback">
  <pre>{/* raw mermaid source */}</pre>
  <p>diagram could not be rendered</p>
</div>
```

渲染是同步进行的：图表使用 `useMemo` 从 `code` 构建，因此解析错误会在同一轮处理中捕获，而不会表现为抛出的渲染错误。传递给渲染器的颜色（`bg`、`fg`、`muted`、`border`、`accent`）是 CSS 变量（`--background`、`--foreground` 等），因此图表会自动匹配当前主题。缩放触发器会在悬停（或聚焦）时出现，并打开全屏覆盖层：以指针为中心滚动缩放，范围为 0.5 倍到 4 倍；拖动以平移；提供 `+`/`-`/重置/关闭按钮；按 Escape 关闭；打开时启用焦点陷阱。

## 示例

### 包装已经渲染的图表

`MermaidDiagram.Zoom`（也以 `MermaidZoom` 的形式导出）本身就是平移和缩放交互外壳。将任何预渲染的 SVG 包装在其中，即可获得相同的展开按钮和灯箱效果，而无需经过 Mermaid 解析：

```tsx
import { MermaidZoom } from "@/components/assistant-ui/elements/mermaid-diagram";

<MermaidZoom svg={mySvgString}>
  <div dangerouslySetInnerHTML={{ __html: mySvgString }} />
</MermaidZoom>;
```

### 重新设置框架样式

两个通道都会在根元素上接收 `className`，并将其应用于当前显示的三种状态之一（骨架屏、图表或回退视图）。

```tsx
<MermaidDiagram className="rounded-none" code={code} />
```

## API 参考

<RuntimeMode>

### 消息部分状态

| 选择器 | 类型 | 描述 |
|----------|------|-------------|
| `s.optional.part?.status.type === "running"` | `boolean` | 使用 `useAuiState` 读取。转发为 `streaming`。当当前消息部分存在且正在运行时为 `true`。 |

`node`、`components` 和 `language`（react-markdown 的代码块包装器属性）会被接受，以便与 `MarkdownText` 的 `componentsByLanguage` 插槽保持类型兼容，除此之外不会使用。

</RuntimeMode>

### MermaidDiagram

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `code` | `string` | 必填 | Mermaid 源代码。支持流程图、时序图、类图、状态图、实体关系图以及 XY 图表（柱状图、折线图或组合图）；其他图表类型会回退到原始源代码视图。 |
| `streaming` | `boolean` | `false` | 当 `true` 时显示骨架屏，而不是进行解析。 |
| `className` | `string` | | 合并到当前显示的状态上。 |

### MermaidZoom

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `svg` | `string` | 必填 | 在缩放覆盖层中显示的 SVG 标记。其 `id` 属性和内部引用会被重写，因此覆盖层副本不会与内联副本发生冲突。 |
| `children` | `ReactNode` | 必填 | 内联内容，会在展开触发器旁按原样渲染。 |

<StandaloneMode>

如上面的单独使用步骤所示，自行传入 `streaming`；其他所有属性的行为都与运行时通道相同。

</StandaloneMode>
