title: "Agent 状态"

一个带有状态圆点的圆角胶囊，标签变化时会交叉淡化，Agent 运行期间会显示已用时间，并带有尾部图标。使用运行时（runtime）时，状态和标签会跟踪工具调用（tool call）自身的生命周期；独立使用时，则由你持有这三个值并自行更新。

## 开始使用

<RuntimeMode>

这个胶囊很自然地对应单个工具调用：调用正在做什么就是标签，而它是否仍在运行、正在等待某项操作，或已经完成，则由状态表示。

<Steps>
  <Step>

### 渲染工具调用

```tsx title="app/toolkit.tsx"
"use client";

import { defineToolkit } from "@assistant-ui/react";
import { AgentStatus } from "@/components/assistant-ui/elements/agent-status";

export const toolkit = defineToolkit({
  report_status: {
    type: "backend",
    render: ({ args, status }) => (
      <AgentStatus
        state={
          status.type === "requires-action"
            ? "waiting"
            : status.type === "running"
              ? "working"
              : "done"
        }
        label={args.label}
        elapsed={args.elapsed}
      />
    ),
  },
});
```

`state` 会跟随调用自身的状态：`requires-action` 表示等待，`running` 表示工作中，而 `complete` 和 `incomplete` 都表示已完成，因为无论哪种情况，调用都不再处于活动状态。`label` 和 `elapsed` 携带的内容就是调用的 `args`，因此你可以让服务器按照希望展示的方式格式化 `elapsed`（`"2m14s"`）。

  </Step>
  <Step>

### 注册工具包

```tsx title="app/MyRuntimeProvider.tsx"
import { AssistantRuntimeProvider, AuiConfig, Tools } from "@assistant-ui/react";
import { toolkit } from "./toolkit";

const config = AuiConfig({ tools: Tools({ toolkit }) });

export function MyRuntimeProvider({ children }: { children: React.ReactNode }) {
  return (
    <AssistantRuntimeProvider runtime={runtime} config={config}>
      {children}
    </AssistantRuntimeProvider>
  );
}
```

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

独立使用时，该元素是一个受控显示组件：由你管理 `state`、`label` 和 `elapsed`，并随着 Agent 的工作推进而更新它们。

<Steps>
  <Step>

### 保存状态

```tsx title="app/status.tsx"
"use client";

import { useState } from "react";
import {
  AgentStatus,
  type AgentState,
} from "@/components/assistant-ui/elements/agent-status";

export function Status() {
  const [state, setState] = useState<AgentState>("working");
  const [label, setLabel] = useState("Refactoring composer");
  const [elapsed, setElapsed] = useState("0:04");

  return <AgentStatus state={state} label={label} elapsed={elapsed} />;
}
```

  </Step>
  <Step>

### 在运行过程中推进状态

```tsx
setState("waiting");
setLabel("Waiting for approval");
// later
setState("done");
setLabel("Finished, 2 files changed");
```

仅更改 `label` 仍然会触发动画：文本值之间会淡出并模糊过渡，因为该元素会根据标签自身的内容设置键。

  </Step>
</Steps>

</StandaloneMode>

## 组成

```tsx
<div data-slot="agent-status">
  <span>{/* check, a pulsing dot, or an outlined one */}</span>
  <span>{/* visually hidden state */}</span>
  <span>{/* label */}</span>
  <span>{/* elapsed, only while state !== "done" */}</span>
  <span aria-hidden>{/* decorative trailing icon */}</span>
</div>
```

当前导指示器在 `state` 为 `"done"` 时显示为勾选标记，否则显示为圆点：`"working"` 时为实心蓝色并持续脉动，`"waiting"` 时为静态的低调描边，因此这两种状态的区别不仅体现在颜色上，也体现在形状和动效上。状态还会渲染为视觉隐藏文本，使辅助技术能够获取它，而不是仅依赖圆点的颜色来传达状态。只有在提供 `elapsed` 且 `state` 不为 `"done"` 时，才会渲染它。尾部图标会根据 `state` 在暂停和重播样式之间切换，并且仅用于装饰：它没有悬停或按下样式，也会对辅助技术隐藏。传递给组件的 Props 会展开到根胶囊上。

## 示例

### 重新设置胶囊样式

两种方式都在根元素上接收 `className`。已用时间文本使用来自 `surfaces.tsx` 的 `mono` 令牌。

```tsx
<AgentStatus className="gap-3" state={state} label={label} elapsed={elapsed} />
```

### 不显示已用时间的胶囊

对于不值得计时的工作，可以省略 `elapsed`，例如没有有用持续时间的等待状态。

```tsx
<AgentStatus state="waiting" label="Waiting for approval" />
```

## API 参考

<RuntimeMode>

### 渲染属性

| 来源 | 类型 | 描述 |
|--------|------|-------------|
| `status.type` | `"running" \| "requires-action" \| "incomplete" \| "complete"` | 驱动 `state`：`requires-action` 对应 `"waiting"`，`running` 对应 `"working"`，否则对应 `"done"`。 |
| `args.label` | `string` | Agent 当前正在做什么。 |
| `args.elapsed` | `string \| undefined` | 预格式化的已用时间，仅在映射的 `state` 不为 `"done"` 时显示。 |

</RuntimeMode>

<StandaloneMode>

### AgentStatus

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `state` | `"working" \| "waiting" \| "done"` | 必填 | 驱动当前导指示器、视觉隐藏的状态文本和尾部图标。 |
| `label` | `string` | 必填 | 每当其值发生变化时进行交叉淡化。 |
| `elapsed` | `string` | | 仅在 `state` 不为 `"done"` 时显示。 |
| `className` | `string` | | 合并到根元素上。 |

其余所有 `div` props 都会转发到根元素。

</StandaloneMode>
