---
title: "行内引用"
description: "句子中的编号引用，每个引用都可悬停预览其来源。"
---

行内引用会在句子中插入小型编号标记；悬停在标记上时，会打开一个预览卡片，显示来源的域名、标题和摘要。此元素没有运行时组合：assistant-ui 无法将引用标记与流式消息文本中的偏移位置关联起来，因此它以独立示例的形式提供，你可以直接在已安装的文件中调整它所包裹的句子。

## 开始使用

<Steps>
  <Step>

### 渲染引用

```tsx title="app/answer.tsx"
"use client";

import { useState } from "react";
import {
  InlineCitation,
  type Source,
} from "@/components/assistant-ui/elements/inline-citation";

const SOURCES: Source[] = [
  {
    domain: "assistant-ui.com",
    title: "Optimistic updates in the runtime",
    snippet:
      "The runtime applies local edits immediately and reconciles them once the server acknowledges the write.",
  },
  {
    domain: "react.dev",
    title: "useSyncExternalStore reference",
    snippet:
      "Subscribes a component to an external store, re-rendering on every store change with a consistent snapshot.",
  },
];

export function Answer() {
  const [openIndex, setOpenIndex] = useState<number | null>(null);

  return (
    <InlineCitation
      sources={SOURCES}
      openIndex={openIndex}
      onOpenIndexChange={setOpenIndex}
    />
  );
}
```

这会渲染元素自身的固定句子，并在其两个锚点处附加标记 `1` 和 `2`，分别预览 `SOURCES[0]` 和 `SOURCES[1]`。

  </Step>
  <Step>

### 替换固定句子

段落文本直接写在源代码中，而不是作为 prop 传入。编辑已安装的文件，包裹你自己的句子，并在需要引用的论断处放置 `<Citation index={n} source={...} open={...} onOpenChange={...} />`：

```tsx title="components/assistant-ui/elements/inline-citation.tsx"
<p data-slot="inline-citation" className={cn("...", className)} {...props}>
  Revenue grew 12 percent year over year
  {sources[0] && (
    <Citation
      index={0}
      source={sources[0]}
      open={openIndex === 0}
      onOpenChange={(open) => onOpenIndexChange(open ? 0 : null)}
    />
  )}
  , driven mostly by the enterprise tier.
</p>
```

  </Step>
</Steps>

## 组成

```tsx
<p data-slot="inline-citation">
  {/* fixed sentence text, with a numbered marker after each of two anchor points */}
</p>
```

句子本身不会变化：两个内置锚点中哪一个获得标记，取决于 `sources`。传入零个或一个来源时，会省略相应的标记（`sources[0] &&` 和 `sources[1] &&` 分别负责保护它们）；传入超过两个来源时，其余来源没有可附加的位置，会被直接忽略。`openIndex` 一次只允许打开一个预览：将其设置为 `0` 意味着索引 `1` 已关闭，因为每个 `Citation` 的 `open` 都会读取 `openIndex === <its own index>`。传入 `null` 会关闭所有标记。

## 示例

### 重新设置标记样式

根元素接受 `className`。每个标记及其预览弹出层都会从 `surfaces.tsx` 读取共享的 `floating` 表面和 `mono` 令牌。

```tsx
<InlineCitation className="max-w-none" /* ... */ />
```

### 保持不同引用之间的预览互斥

由于 `openIndex` 是单个值，打开一个标记时，其他标记已经会关闭。“滚动时关闭”或“发送时关闭”功能只需将其重置一次：

```tsx
useEffect(() => {
  const onScroll = () => setOpenIndex(null);
  window.addEventListener("scroll", onScroll, true);
  return () => window.removeEventListener("scroll", onScroll, true);
}, []);
```

## API 参考

### InlineCitation

| Prop | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `sources` | `Source[]` | 必填 | 引用目标。只有索引 `0` 和 `1` 会附加到标记上。 |
| `openIndex` | `number \| null` | 必填 | 当前打开预览的引用。`null` 会关闭所有标记。 |
| `onOpenIndexChange` | `(index: number \| null) => void` | 必填 | 打开时使用标记的索引调用，关闭时使用 `null` 调用。 |
| `className` | `string` | | 合并到根元素上。 |

`Source` 是 `{ domain: string; title: string; snippet: string }`。其他所有 `p` prop 都会转发到根元素。
