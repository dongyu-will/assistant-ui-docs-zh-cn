---
title: "滚动锚点"
description: "流式输出不会夺走你的滚动位置；提示条提供返回底部的入口。"
---

滚动锚点会在消息列表不断增长时将其固定在底部；一旦有人向上滚动阅读较早的内容，它就会立即让开。在运行时（runtime）中，固定和返回底部按钮都是视口自身的行为；在独立模式下，你需要自行跟踪固定状态和未读消息数量。

## 快速开始

<RuntimeMode>

<Steps>
  <Step>

### 让视口自行固定

```tsx title="components/assistant-ui/elements/thread.aui.tsx"
"use client";

import { ThreadPrimitive } from "@assistant-ui/react";

function Viewport() {
  return (
    <ThreadPrimitive.Viewport className="relative h-64 w-full max-w-sm overflow-hidden rounded-2xl">
      <ThreadPrimitive.Messages>{({ message }) => null}</ThreadPrimitive.Messages>
    </ThreadPrimitive.Viewport>
  );
}
```

`autoScroll` 默认值为 `true`（除非 `turnAnchor="top"`），因此视口会自行滚动到最新内容；向上滚动的读者会中断这一行为，直到他们自行滚回底部。

  </Step>
  <Step>

### 添加返回底部提示条

```tsx
import { ThreadPrimitive } from "@assistant-ui/react";
import { ArrowDownIcon } from "lucide-react";

<ThreadPrimitive.ScrollToBottom className="absolute inset-x-0 bottom-3 mx-auto flex w-fit items-center gap-1.5 rounded-full px-3.5 py-1.5 text-xs">
  <ArrowDownIcon className="size-3 opacity-60" />
  New messages
</ThreadPrimitive.ScrollToBottom>
```

当视口已经位于底部时，`ThreadPrimitive.ScrollToBottom` 会自行渲染 `null`，因此不需要手动检查是否已固定。它不会内置错过了多少条消息的计数；如果你想显示“n 条新消息”标签 `ScrollAnchor`，可以根据 `s.thread.messages.length` 自行跟踪。

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

在独立模式下，`ScrollAnchor` 负责整个模拟过程：它按计时器追加 `messages`，决定何时处于固定状态，并自行显示提示条。

<Steps>
  <Step>

### 为其提供不断增长的列表

```tsx title="app/scroll-demo.tsx"
"use client";

import { useState } from "react";
import { ScrollAnchor, type ScrollAnchorMessage } from "@/components/assistant-ui/elements/scroll-anchor";

const messages: ScrollAnchorMessage[] = [
  { role: "user", text: "Keep summarizing as you go." },
  { role: "assistant", text: "Starting now." },
  { role: "assistant", text: "Here's the first section..." },
];

export function ScrollDemo() {
  const [paused, setPaused] = useState(false);
  return <ScrollAnchor messages={messages} paused={paused} onSettled={() => setPaused(true)} />;
}
```

  </Step>
  <Step>

### 追赶完成后做出响应

`onSettled` 会在数组中的每条消息都已追加，且视口仍固定在底部时触发一次。这相当于流式输出完成，而读者从未滚离底部：

```tsx
<ScrollAnchor messages={messages} onSettled={() => console.log("caught up")} />
```

  </Step>
</Steps>

</StandaloneMode>

## 组成

```tsx
<div data-slot="scroll-anchor">
  <div>{/* viewport: messages, newest last */}</div>
  <button>{/* jump to bottom, only rendered while unpinned */}</button>
</div>
```

在独立模式下，只有处于固定状态时，追加消息才会自动滚动；滚动离开后，下一条追加的消息会将 `pinned` 切换为 `false`，未读消息数量也会从此开始增长。当有两条或更多未读消息到达后，除非 `paused`，它会在 2.4 秒后自行返回底部；按下提示条则会立即返回。只有当整个数组都已加载且视图仍处于固定状态时，`onSettled` 才会触发，因此读者滚动离开并阅读内容时，它永远不会触发。

## 示例

### 暂停消息流

<StandaloneMode>

当读者正在进行可能被新消息打断的操作（例如选择文本或打开菜单）时，设置 `paused`：

```tsx
<ScrollAnchor messages={messages} paused={isMenuOpen} />
```

</StandaloneMode>

<RuntimeMode>

运行时视口没有对应的暂停功能：新消息始终会以模型流式输出的速度到达。你可以改为设置 `autoScroll`，停止自动固定，但不会停止流式传输本身：

```tsx
<ThreadPrimitive.Viewport autoScroll={false}>
  {/* ... */}
</ThreadPrimitive.Viewport>
```

</RuntimeMode>

### 滚动到特定消息，而不是底部

<RuntimeMode>

`turnAnchor="top"` 会改变“固定”的含义：视口不再跟踪底部，而是将最新的用户轮次固定在可视区域顶部附近。这适用于专注阅读布局，而不是经典聊天式滚动：

```tsx
<ThreadPrimitive.Viewport turnAnchor="top">
  {/* ... */}
</ThreadPrimitive.Viewport>
```

</RuntimeMode>

## API 参考

<RuntimeMode>

### 原语部件

| 部件 | 渲染内容 | 说明 |
|------|---------|-------|
| `ThreadPrimitive.Viewport` | `div` | 可滚动容器。`autoScroll`、`turnAnchor` 和 `scrollToBottomOn*` 标志控制其何时固定。 |
| `ThreadPrimitive.ScrollToBottom` | `button` | 在已经位于底部时渲染 `null`。接受 `asChild` 和 `behavior` 属性（`"smooth" \| "auto"`）。 |

### 视口属性

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `autoScroll` | `boolean` | `true`（`turnAnchor="top"` 时为 `false`） | 内容到达时自动滚动到底部。 |
| `turnAnchor` | `"top" \| "bottom"` | `"bottom"` | `"top"` 会将每个新的用户轮次锚定在顶部附近，而不是固定底部。 |
| `scrollToBottomOnRunStart` | `boolean` | `true` | 新运行开始时滚动到底部。 |
| `scrollToBottomOnInitialize` | `boolean` | `true` | 线程历史记录首次加载时滚动到底部。 |
| `scrollToBottomOnThreadSwitch` | `boolean` | `true` | 切换到其他线程时滚动到底部。 |

</RuntimeMode>

<StandaloneMode>

### ScrollAnchor

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `messages` | `ScrollAnchorMessage[]`（`{ role: "user" \| "assistant"; text: string }`） | 必填 | 按 1300ms 的计时器逐条追加。 |
| `paused` | `boolean` | `false` | 当 `true` 时停止继续追加消息。 |
| `onSettled` | `() => void` | | 在所有消息都已追加且仍固定在底部时触发一次。 |
| `className` | `string` | | 合并到根元素上。 |

所有其他 `div` 属性都会转发到根元素。

</StandaloneMode>
