---
title: "使用以下模型重新生成"
description: "将同一轮分叉到其他模型，而不是重复投掷同一枚骰子。"
---

RegenerateMenu 将重新生成操作变成一个小型选择器：打开它，查看标记了当前选项的备选项，然后选择一个再次尝试。在运行时中，选择一个选项会携带你的选择启动一次新的运行；单独使用时，菜单的打开状态和选择操作都由你控制。

## 开始使用

<RuntimeMode>

`aui.message.reload(config)` 会为当前轮次启动一次新的运行，而 `config.runConfig.custom` 会原样传递给你的模型适配器。assistant-ui 本身不会在运行中内置 "model" 字段；在同时使用 `useLocalRuntime` 和 `ChatModelAdapter` 的运行时中，这正是 `ChatModelAdapter.run(options)` 以 `options.runConfig` 接收到的内容，因此自定义适配器只需从这一次运行中读取选择，而不会改变后续轮次所使用的内容。

<Steps>
  <Step>

### 将选择连接到重新加载

```tsx title="components/assistant-ui/elements/thread.aui.tsx"
"use client";

import { useState } from "react";
import { useAui } from "@assistant-ui/react";
import { RegenerateMenu, type RegenerateOption } from "@/components/assistant-ui/elements/regenerate-menu";

const MODELS: RegenerateOption[] = [
  { id: "opus", label: "Try again with Opus 5", detail: "slower" },
  { id: "sonnet", label: "Try again with Sonnet 5", detail: "balanced" },
  { id: "haiku", label: "Try again with Haiku 4.5", detail: "fastest" },
];

function RegenerateWith({ currentModel }: { currentModel: string }) {
  const aui = useAui();
  const [open, setOpen] = useState(false);

  return (
    <RegenerateMenu
      options={MODELS}
      open={open}
      currentId={currentModel}
      onOpenChange={setOpen}
      onPick={(id) => {
        aui.message.reload({ runConfig: { custom: { model: id } } });
        setOpen(false);
      }}
    />
  );
}
```

  </Step>
  <Step>

### 在模型侧读取选择

```tsx title="lib/model-adapter.ts"
import type { ChatModelAdapter } from "@assistant-ui/react";

export const adapter: ChatModelAdapter = {
  async run({ messages, runConfig, abortSignal }) {
    const model = (runConfig.custom?.model as string | undefined) ?? "sonnet";
    // call `model` for this run
  },
};
```

### 保存打开状态和当前选择

```tsx title="app/answer.tsx"
"use client";

import { useState } from "react";
import { RegenerateMenu, type RegenerateOption } from "@/components/assistant-ui/elements/regenerate-menu";

const OPTIONS: RegenerateOption[] = [
  { id: "opus", label: "Try again with Opus 5", detail: "slower" },
  { id: "sonnet", label: "Try again with Sonnet 5", detail: "balanced" },
];

export function Answer() {
  const [open, setOpen] = useState(false);
  const [model, setModel] = useState("sonnet");

  return (
    <RegenerateMenu
      options={OPTIONS}
      open={open}
      currentId={model}
      onOpenChange={setOpen}
      onPick={(id) => {
        setModel(id);
        setOpen(false);
        regenerate(id);
      }}
    />
  );
}
```

  </Step>
  <Step>

### 自行处理外部交互

该组件没有内置的点击外部区域或 Escape 处理逻辑；它只是由 `open` 控制的简单条件渲染。如果需要菜单自行关闭，请将它包装在你自己的弹出层原语中，或自行监听外部点击。

  </Step>
</Steps>

</StandaloneMode>

## 结构

```tsx
<div data-slot="regenerate-menu">
  <button aria-expanded aria-label="Regenerate with a different model" />
  {open && (
    <div>
      {/* one row per option: its label, and "current" in place of the detail for the active one */}
    </div>
  )}
</div>
```

组件没有内置点击外部区域、Escape 或键盘循环导航功能；每一行都只是一个普通按钮。当前选项（`option.id === currentId`）会用字面文本 "current" 替代自身的 `detail`，因此，如果某个 `detail` 字符串恰好也是 "current"，它将无法与真正的当前标记区分开来。

## 示例

### 使用相同模型重新生成

<RuntimeMode>

不带配置的 `reload()` 只会原样重试当前轮次；只有在确实想使用其他模型时，才需要 `runConfig.custom` 中的覆盖配置：

```tsx
<button onClick={() => aui.message.reload()}>Try again</button>
```

</RuntimeMode>

<StandaloneMode>

选择不要求菜单处于打开状态；例如，可以直接调用 `onPick`，也可以从绑定到当前模型 id 的键盘快捷键中调用。

```tsx
onPick(currentId);
```

</StandaloneMode>

### 重新设置触发器和菜单的样式

两种方式都会在根元素上接收 `className`。下拉菜单会从 `surfaces.tsx` 读取共享的 `floating` 表面，这是其他弹出层和工具提示所使用的同一个令牌。

```tsx
<RegenerateMenu className="gap-1" /* ... */ />
```

## API 参考

<RuntimeMode>

### 消息状态

| 选择器 / 方法 | 类型 | 描述 |
|--------------------|------|-------------|
| `aui.message.reload(config?)` | `(config?: { runConfig?: RunConfig }) => void` | 为此轮次启动一次新的运行。`runConfig.custom` 会将内容原样传递给你的 `ChatModelAdapter`，作为 `options.runConfig.custom`。 |
| `RunConfig` | `{ custom?: Record<string, unknown> }` | `reload` 的 `runConfig` 所接受的数据结构。assistant-ui 没有内置的 model 字段；你读取回来的键由你自行约定。 |

</RuntimeMode>

<StandaloneMode>

### RegenerateMenu

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `options` | `readonly RegenerateOption[]` | 必填 | 提供的备选项。 |
| `open` | `boolean` | 必填 | 是否显示下拉菜单。 |
| `currentId` | `string` | 必填 | 显示为 "current" 的 id。不匹配的 id 不会将任何行标记为当前项。 |
| `onOpenChange` | `(open: boolean) => void` | | 按下触发器时调用，并传入下一个打开状态值。 |
| `onPick` | `(id: string) => void` | | 按下某一行时调用。不会自行关闭菜单。 |
| `className` | `string` | | 合并到根元素上。 |

### RegenerateOption

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `id` | `string` | |
| `label` | `string` | |
| `detail` | `string` | 对除当前选项之外的每个选项显示。 |

其他所有 `div` 属性都会转发到根元素。

</StandaloneMode>
