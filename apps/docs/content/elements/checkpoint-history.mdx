检查点列表会显示可以还原到的节点：标签、创建时间以及涉及的文件数量。这是一个简单列表，其中一项会标记为当前项；还原操作需要由你自行接入回调。

## 快速开始

<StandaloneMode>

<Steps>
  <Step>

### 使用当前检查点渲染列表

```tsx title="app/checkpoints.tsx"
"use client";

import { CheckpointHistory, type Checkpoint } from "@/components/assistant-ui/elements/checkpoint-history";

const checkpoints: Checkpoint[] = [
  { id: "1", label: "Initial scaffold", at: "10:02", files: 4 },
  { id: "2", label: "Added auth", at: "10:19", files: 7 },
  { id: "3", label: "Fixed layout bug", at: "10:41", files: 2 },
];

export function History() {
  return <CheckpointHistory checkpoints={checkpoints} currentId="3" />;
}
```

  </Step>
  <Step>

### 点击时还原

`onRestore`只会报告选中了哪个检查点；移动`currentId`以及回滚检查点所代表的状态，都需要在你的处理函数中完成。

```tsx
"use client";

import { useState } from "react";

export function History() {
  const [currentId, setCurrentId] = useState("3");

  return (
    <CheckpointHistory
      checkpoints={checkpoints}
      currentId={currentId}
      onRestore={(id) => {
        rollBackTo(id);
        setCurrentId(id);
      }}
    />
  );
}
```

  </Step>
</Steps>

## 结构

```tsx
<div data-slot="checkpoint-history">
  <span>Checkpoints</span>
  <div>
    {/* one row per checkpoint */}
    <span>{/* dot: solid blue = current, hollow ring = ahead, solid gray = behind */}</span>
    <span>{label}</span>
    <span>{/* at · N files */}</span>
    <span>{/* "current" label, or a Restore button */}</span>
  </div>
</div>
```

通过将`currentId`与`checkpoints`进行匹配来确定当前行。数组中位于当前行之后的行属于“前方”：它们会以较低的不透明度和空心圆点进行渲染，因为只有再次向前移动才能到达这些行。位于当前行之前或与当前行相同位置的行属于“后方”：使用完整不透明度和实心灰色圆点。当前行本身会显示高亮背景，并显示“当前”文字而不是按钮；其他每一行，无论在前方还是后方，都会显示一个仅在悬停或获得焦点时出现的“还原”按钮。如果`currentId`在`checkpoints`中找不到匹配项，则没有任何行是当前行：所有行都会被视为后方，并且每一行都会显示“还原”按钮。空的`checkpoints`数组只会渲染“检查点”标签。

## 示例

### 当前检查点前方的检查点

将`currentId`传入数组中早于列表末尾的位置，会让后续条目保持可见但变暗，以展示向前移动后可以还原的内容：

```tsx
<CheckpointHistory checkpoints={checkpoints} currentId="2" onRestore={onRestore} />
```

### 无法识别的当前 id

适用于检查点刚在服务端被删除、调用方尚未选择新的当前检查点的情况：

```tsx
<CheckpointHistory checkpoints={checkpoints} currentId="" onRestore={onRestore} />
```

### 重新设置列表样式

根元素使用共享的`paper`表面；时间戳和文件数量使用`mono`。

```tsx
<CheckpointHistory className="max-w-md rounded-3xl" {...rest} />
```

## API 参考

<StandaloneMode>

### CheckpointHistory

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `checkpoints` | `readonly Checkpoint[]` | 必填 | 按顺序渲染的行。 |
| `currentId` | `string` | 必填 | 活动检查点的 id。没有匹配项的 id 会使所有行都不带标记。 |
| `onRestore` | `(id: string) => void` | | 点击某行的“还原”按钮时调用。 |
| `className` | `string` | | 合并到根元素上。 |

### Checkpoint

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `id` | `string` | 与`currentId`进行匹配。 |
| `label` | `string` | 行标题。 |
| `at` | `string` | 显示在文件数量之前；格式由你自行决定。 |
| `files` | `number` | 显示为`"{files} files"`。 |

所有其他`div`属性都会转发到根元素。

</StandaloneMode>
