一个可搜索、由键盘驱动的应用操作列表，按每个操作的作用范围分组；使用箭头键移动时，高亮行会自动滚动到可视区域。在运行时模式下，面板自身的列表、搜索和键盘处理都保留在应用状态中，只有每个命令实际执行的操作才会访问运行时；在独立模式下，每个命令及其处理程序都由你负责。

## 开始使用

<RuntimeMode>

使用运行时时，无需读取一个包含“应用可以执行的所有操作”的注册表：assistant-ui 会在你已经使用的作用域（会话线程、消息、线程列表）上公开操作，而不是提供一个扁平的命令目录。自行构建列表，并按照应用的组织方式进行分组，为每个条目提供一个 id，以便在 `onRun` 中进行路由。

<Steps>
  <Step>

### 将命令路由到实际操作

`onRun` 接收所选命令的 id；查找该 id，然后调用它应执行的操作。当前会话线程、线程列表以及活动线程的列表项上的操作，都是可以实际调用的运行时方法。

```tsx title="components/assistant-ui/elements/app-command-palette.tsx"
"use client";

import { useAui } from "@assistant-ui/react";
import { useState } from "react";
import {
  CommandPalette,
  type PaletteCommand,
} from "@/components/assistant-ui/elements/command-palette";

const commands: PaletteCommand[] = [
  { id: "new-thread", label: "New thread", group: "Thread list", keys: ["⌘", "N"] },
  { id: "stop", label: "Stop generating", group: "Thread", keys: ["Esc"] },
  { id: "archive", label: "Archive this thread", group: "Thread", keys: ["⌘", "⇧", "A"] },
];

export function AppCommandPalette() {
  const aui = useAui();
  const [query, setQuery] = useState("");
  const [activeId, setActiveId] = useState(commands[0]!.id);

  const run = (id: string) => {
    if (id === "new-thread") aui.threads.switchToNewThread();
    if (id === "stop") aui.thread.cancelRun();
    if (id === "archive") aui.threadListItem.archive();
  };

  return (
    <CommandPalette
      commands={commands}
      query={query}
      activeId={activeId}
      onQueryChange={setQuery}
      onActiveChange={setActiveId}
      onRun={run}
    />
  );
}
```

### 保存列表、查询文本和活动 id

```tsx title="app/command-palette.tsx"
"use client";

import { useState } from "react";
import { CommandPalette } from "@/components/assistant-ui/elements/command-palette";

const commands = [
  { id: "new-doc", label: "New document", group: "File", keys: ["⌘", "N"] },
  { id: "share", label: "Share", group: "File", keys: ["⌘", "⇧", "S"] },
];

export function AppCommandPalette({
  handlers,
}: {
  handlers: Record<string, () => void>;
}) {
  const [query, setQuery] = useState("");
  const [activeId, setActiveId] = useState(commands[0].id);

  return (
    <CommandPalette
      commands={commands}
      query={query}
      activeId={activeId}
      onQueryChange={setQuery}
      onActiveChange={setActiveId}
      onRun={(id) => handlers[id]?.()}
    />
  );
}
```

## 结构

```tsx
<div data-slot="command-palette">
  <div>
    <svg /* search icon */ />
    <input placeholder="Type a command" role="combobox" />
    <span>esc</span>
  </div>
  <div role="listbox" aria-label="Commands">
    {/* one group per PaletteCommand.group, each with its rows */}
  </div>
  {/* "No command matches “query”" when there are no matches */}
</div>
```

匹配过程会在 `label` 上通过不区分大小写的子字符串匹配，将 `commands` 与 `query` 进行匹配；随后根据保留下来的匹配项生成分组，并保持它们首次出现的顺序，该顺序可能不同于匹配项被过滤时的顺序。箭头键会在经过分组和过滤的顺序中移动 `activeId`，并在两端循环；Enter 会运行当前活动的命令。每当 `activeId` 发生变化时，活动行都会通过 `{ block: "nearest" }` 滚动到可视区域，因为 `aria-activedescendant` 只会移动视觉高亮而不会移动键盘焦点，因此不会自行滚动。`PromptLibrary` 也采用相同的过滤和导航模式，但不会执行此自动滚动。

## 示例

### 分组与过滤顺序

即使某个分组中没有其他仍然匹配的命令，该命令仍会拥有自己的标题；分组不会合并或消失，只会缩减为一行。

```tsx
{ id: "archive", label: "Archive this thread", group: "Thread", keys: ["⌘", "⇧", "A"] }
```

### 重新设置行样式和 esc 标签

esc 提示和每个快捷键标签都共享 `surfaces.tsx` 中的 `field` 和 `mono` 表面。

```tsx
<CommandPalette className="max-w-lg" commands={commands} query={query} activeId={activeId} onQueryChange={setQuery} onActiveChange={setActiveId} onRun={onRun} />
```

## API 参考

<RuntimeMode>

### 操作示例

| 调用 | 类型 | 描述 |
|------|------|-------------|
| `aui.threads.switchToNewThread()` | `() => Promise<void>` | 开始新的会话线程，是“新建线程”命令的自然目标。 |
| `aui.thread.cancelRun()` | `() => void` | 取消活动线程中正在进行的运行。 |
| `aui.threadListItem.archive()` | `() => void` | 将活动线程的列表项归档。 |

这些只是示例，并非组件自身的契约：`CommandPalette` 本身不会调用运行时，只会调用 `onRun` 根据接收到的 id 执行的操作。不存在用于获取命令目录的选择器。

</RuntimeMode>

<StandaloneMode>

### CommandPalette

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `commands` | `readonly PaletteCommand[]` | 必填 | 所有可运行的操作。分组根据条目生成，并保持首次出现的顺序。 |
| `query` | `string` | 必填 | 当前的过滤文本。 |
| `activeId` | `string` | 必填 | 当前高亮的行。箭头键会移动高亮行，Enter 会运行该行，两者都由元素处理；元素通过 `onActiveChange` 报告移动结果。 |
| `onQueryChange` | `(query: string) => void` | | 输入过滤文本时调用。 |
| `onActiveChange` | `(id: string) => void` | | 使用箭头键浏览列表时调用。元素负责键盘处理并报告最终位置，因此 `activeId` 仍由你保存。 |
| `onRun` | `(id: string) => void` | | 选择命令时调用。 |
| `className` | `string` | | 合并到根元素上。 |

### PaletteCommand

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `id` | `string` | 必填 | 稳定标识，会与 `activeId` 进行比较，并由 `onRun` 报告。 |
| `label` | `string` | 必填 | 命令文本，也是查询进行过滤时使用的字段。 |
| `group` | `string` | 必填 | 命令所属的标题。 |
| `keys` | `readonly string[]` | 必填 | 快捷键，每个按键对应一个标签。 |

其他所有 `div` 属性都会转发到根元素。

</StandaloneMode>
