一个紧凑的 MCP 服务器列表：每一行默认折叠为名称和状态点，打开后即可查看其传输层和工具列表。在运行时中，服务器来自你的 MCP 连接；在独立模式下，你需要传入服务器列表。

## 入门

<RuntimeMode>

`@assistant-ui/react-mcp`负责管理 MCP 连接状态。挂载一次其管理器后，即可在组件树的任意位置读取服务器及其工具。

<Steps>
  <Step>

### 挂载 MCP 管理器

```tsx title="app/providers.tsx"
"use client";

import { useAui } from "@assistant-ui/store";
import { McpManagerResource } from "@assistant-ui/react-mcp";

function McpManagerMount({ connectors }: { connectors: MCPConnector[] }) {
  useAui({ mcp: McpManagerResource({ connectors }) });
  return null;
}
```

`connectors`中的每个连接器都会成为一个服务器，由管理器负责连接、跟踪并列出其工具。用户通过 `McpAddFormPrimitive` 添加的自定义服务器也会加入同一列表，无需再次挂载。

  </Step>
  <Step>

### 列出服务器及其工具

```tsx title="components/assistant-ui/elements/mcp-servers.tsx"
"use client";

import { useState } from "react";
import { McpManagerPrimitive, McpServerPrimitive } from "@assistant-ui/react-mcp";
import { useAuiState } from "@assistant-ui/store";
import { PlugIcon } from "lucide-react";

function ServerRow() {
  const [open, setOpen] = useState(false);
  const name = useAuiState((s) => s.mcpServer.name);
  return (
    <McpServerPrimitive.Root>
      <button type="button" onClick={() => setOpen((v) => !v)}>
        <PlugIcon className="size-3.5" />
        {name}
      </button>
      {open && (
        <McpServerPrimitive.Tools>
          {(tool) => <span key={tool.name}>{tool.name}</span>}
        </McpServerPrimitive.Tools>
      )}
    </McpServerPrimitive.Root>
  );
}

export function McpServerList() {
  return (
    <McpManagerPrimitive.Root>
      <McpManagerPrimitive.Connectors>{() => <ServerRow />}</McpManagerPrimitive.Connectors>
      <McpManagerPrimitive.CustomServers>{() => <ServerRow />}</McpManagerPrimitive.CustomServers>
    </McpManagerPrimitive.Root>
  );
}
```

`McpServerPrimitive.Root`将这一行限定在对应服务器的作用域内，因此 `useAuiState((s) => s.mcpServer...)` 和 `McpServerPrimitive.Tools` 都会解析到该服务器。每一行在此处维护自己的 `open` 状态，因此可以同时展开多行；[MCP 配置对话框](/elements/mcp-config)在对话框外壳中提供了同一列表的完整版本，并包含连接和授权操作。

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

在独立模式下，该面板是一个受控列表：服务器、服务器状态以及展开哪一行都由你管理。

<Steps>
  <Step>

### 保存服务器列表

```tsx title="app/servers.tsx"
"use client";

import { useState } from "react";
import { McpServerPanel, type McpServer } from "@/components/assistant-ui/elements/mcp-server-panel";

const servers: McpServer[] = [
  { id: "files", name: "Filesystem", transport: "stdio", status: "connected", tools: ["read_file", "write_file"] },
  { id: "search", name: "Web search", transport: "http", status: "needs-auth", tools: ["search"] },
];

export function Servers() {
  const [expandedId, setExpandedId] = useState<string>();
  return (
    <McpServerPanel
      servers={servers}
      expandedId={expandedId}
      onToggle={(id) => setExpandedId((current) => (current === id ? undefined : id))}
    />
  );
}
```

  </Step>
  <Step>

### 一次展开一个服务器

`expandedId`保存单个 ID，因此将其切换到新服务器时，会关闭当前已打开的行。再次点击已打开行自身的触发器会清除该值，这与上方的 `current === id ? undefined : id` 检查逻辑一致。

  </Step>
</Steps>

</StandaloneMode>

## 组成

```tsx
<div data-slot="mcp-server-panel">
  <div>{/* "n of m connected" */}</div>
  <button aria-expanded>
    {/* chevron, plug icon, name, tool count, status dot */}
  </button>
  {/* expanded: transport, status label, optional Authorize action, tool chips */}
</div>
```

标题中的数量只统计 `status` 为 `"connected"` 的服务器。状态点在已连接时显示为翠绿色，连接中时显示为脉动的暗色点，需要授权时显示为琥珀色，失败时显示为红色；每种状态都配有仅供屏幕阅读器读取的文本。只有在需要授权的行传入 `onAuthorize` 时，才会渲染 Authorize 标签；如果不传入，该行仍可展开，但无法执行操作。

## 示例

### 将连接状态映射到四种点

<RuntimeMode>

`McpServerPrimitive.Status`（以及其背后的 `s.mcpServer.connectionState` 选择器）包含六种状态：`connected`、`connecting`、`authRequired`、`authPending`、`error`、`disconnected`。而面板自身的 `McpServerStatus` 类型只有四种状态。将多出的两种状态折叠到最接近的点后，再将值传给面板：

```tsx
import type { MCPConnectionState } from "@assistant-ui/react-mcp";
import type { McpServerStatus } from "@/components/assistant-ui/elements/mcp-server-panel";

function toPanelStatus(state: MCPConnectionState): McpServerStatus {
  switch (state) {
    case "connected":
      return "connected";
    case "connecting":
    case "authPending":
      return "connecting";
    case "authRequired":
      return "needs-auth";
    case "error":
    case "disconnected":
      return "failed";
  }
}
```

</RuntimeMode>

### 接入授权操作

<RuntimeMode>

`McpServerPrimitive.OAuthLink`会启动与配置对话框相同的 OAuth 流程。当 `connectionState` 为 `authRequired` 后，将其渲染为该行的授权操作：

```tsx
<McpServerPrimitive.OAuthLink className="rounded-full bg-amber-500/15 px-2 py-0.5 text-[11px] font-medium text-amber-700">
  Authorize
</McpServerPrimitive.OAuthLink>
```

</RuntimeMode>

<StandaloneMode>

```tsx
<McpServerPanel
  servers={servers}
  onAuthorize={(id) => startOAuthFlow(id)}
/>
```

</StandaloneMode>

### 重新设置面板样式

两条通道都会在根元素上接收 `className`。面板使用共享的 `paper` 表面作为背景，使用 `mono` 设置数量和状态文本的样式，并将 `field` 与 `mono` 搭配用于工具标签。因此，在 `surfaces.tsx` 中重新指定这些设计令牌，就能重新设置所有基于它们构建的元素的样式。

## API 参考

<RuntimeMode>

### McpManagerPrimitive 和 McpServerPrimitive

| 部件 | 渲染内容 | 备注 |
|------|---------|-------|
| `McpManagerPrimitive.Root` | `div` | 提供管理器作用域；将列表包裹在其中。 |
| `McpManagerPrimitive.Connectors` | 渲染 prop | 遍历应用声明的连接器，每次调用传入一个 `{ server }`。 |
| `McpManagerPrimitive.CustomServers` | 渲染 prop | 以相同方式遍历用户添加的自定义服务器。 |
| `McpServerPrimitive.Root` | `div` | 将 `useAuiState((s) => s.mcpServer...)` 及以下子部件限定到一个服务器的作用域内。 |
| `McpServerPrimitive.Name` | 文本 | 服务器的显示名称。 |
| `McpServerPrimitive.Status` | `span` | 将 `data-state` 设置为连接状态；默认将该状态渲染为文本。 |
| `McpServerPrimitive.Tools` | 渲染 prop | 遍历服务器的工具，每次调用传入一个 `MCPToolInfo`。列表为空时不渲染任何内容。 |
| `McpServerPrimitive.ConnectButton` / `.DisconnectButton` / `.OAuthLink` / `.RemoveButton` | `button` | 在当前服务器作用域内调用 `connect()`、`disconnect()`、启动 OAuth，或调用 `remove()`。 |

### 服务器状态

| 选择器 | 类型 | 描述 |
|----------|------|-------------|
| `s.mcpServer.name` | `string` | 显示名称。 |
| `s.mcpServer.connectionState` | `"connected" \| "connecting" \| "authRequired" \| "authPending" \| "error" \| "disconnected"` | 完整的连接状态，共六种值。 |
| `s.mcpServer.tools` | `MCPToolInfo[]` | 服务器列出的每个工具对应的 `{ name, description?, inputSchema }`。 |
| `s.mcpServer.lastError` | `{ message: string } \| null` | 连接或列出工具的调用失败时设置。 |
| `useMcpServerTool()` | `MCPToolInfo` | `McpServerPrimitive.Tools` 内的当前工具；在其作用域外调用会抛出异常。 |

</RuntimeMode>

<StandaloneMode>

### McpServerPanel

| Prop | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `servers` | `readonly McpServer[]` | 必填 | 要列出的服务器。 |
| `expandedId` | `string` | | 当前展开的服务器 ID。 |
| `onToggle` | `(id: string) => void` | | 点击服务器行时，传入该服务器 ID 调用。 |
| `onAuthorize` | `(id: string) => void` | | 从需要授权行的 Authorize 标签调用。省略时不会渲染该标签。 |
| `className` | `string` | | 合并到根元素上。 |

### McpServer 和 McpServerStatus

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `id` | `string` | 服务器的稳定键。 |
| `name` | `string` | 显示名称。 |
| `transport` | `string` | 展开时显示在状态标签旁，例如 `"stdio"` 或 `"http"`。 |
| `status` | `McpServerStatus` | `"connected" \| "connecting" \| "needs-auth" \| "failed"`。 |
| `tools` | `readonly string[]` | 工具名称，展开时渲染为标签。 |

所有其他 `div` props 都会转发到根元素。

</StandaloneMode>
