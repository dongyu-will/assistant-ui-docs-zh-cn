description: "文件会在消息发送前暂存于输入框中，并显示每个文件的上传进度。"

添加到输入框中的文件会变成一个标签：显示文件类型图标、名称和大小，并带有一个尾部插槽。上传时插槽显示加载指示器，完成后显示移除按钮。使用运行时（runtime）时，标签会通过附件适配器跟踪实际上传进度；在独立模式下，则由你自行维护文件列表及其状态。

## 快速开始

<RuntimeMode>

输入框暂存文件的方式与暂存文本相同：`aui.composer.addAttachment(file)` 添加一个文件，`AttachmentAdapter` 将其转换为 `PendingAttachment`，然后再转换为 `CompleteAttachment`，而 `s.composer.attachments` 会在每一步反映文件列表。

<Steps>
  <Step>

### 配置附件适配器

附件默认不启用：没有适配器时，`s.thread.capabilities.attachments` 为 `false`，`AddAttachment`、粘贴和拖放操作都不会执行任何操作。assistant-ui 为常见场景提供了适配器：

```tsx title="app/chat-provider.tsx"
import { useLocalRuntime, CompositeAttachmentAdapter, SimpleImageAttachmentAdapter, SimpleTextAttachmentAdapter } from "@assistant-ui/react";

const runtime = useLocalRuntime(chatModel, {
  adapters: {
    attachments: new CompositeAttachmentAdapter([
      new SimpleImageAttachmentAdapter(),
      new SimpleTextAttachmentAdapter(),
    ]),
  },
});
```

  </Step>
  <Step>

### 添加和列出附件

```tsx title="components/assistant-ui/elements/composer-attachments.tsx"
"use client";

import { ComposerPrimitive, AttachmentPrimitive } from "@assistant-ui/react";
import { PlusIcon, XIcon } from "lucide-react";
import { cn } from "@/lib/utils";
import { field, ghostButton } from "@/components/assistant-ui/elements/surfaces";

export function ComposerAttachmentsRow() {
  return (
    <ComposerPrimitive.Attachments>
      {({ attachment }) => (
        <AttachmentPrimitive.Root
          className={cn(field, "flex items-center gap-2.5 rounded-[14px] py-1.5 ps-1.5 pe-2.5")}
        >
          <span className="max-w-36 truncate text-xs font-medium">
            <AttachmentPrimitive.Name />
          </span>
          {attachment.status.type === "complete" && (
            <AttachmentPrimitive.Remove aria-label={`Remove ${attachment.name}`} className={cn(ghostButton, "size-5")}>
              <XIcon className="size-3" />
            </AttachmentPrimitive.Remove>
          )}
        </AttachmentPrimitive.Root>
      )}
    </ComposerPrimitive.Attachments>
  );
}

export function AddAttachmentButton() {
  return (
    <ComposerPrimitive.AddAttachment aria-label="Add attachment" className={cn(ghostButton, "size-8")}>
      <PlusIcon className="size-4" />
    </ComposerPrimitive.AddAttachment>
  );
}
```

`ComposerPrimitive.Attachments` 是遍历每个暂存文件的 render prop；`AttachmentPrimitive.Root` 会将 `.Name`、`.Remove` 和 `.unstable_Thumb` 限定到对应位置的附件，因此无需手动传入索引或 id。`AddAttachment` 会打开原生文件选择器，并将文件类型过滤为 `s.composer.attachmentAccept`（即适配器的 `accept`；未配置时则允许所有文件类型）。

  </Step>
  <Step>

### 接受拖放

```tsx
<ComposerPrimitive.AttachmentDropzone className="data-[dragging=true]:border-dashed data-[dragging=true]:bg-blue-500/[0.04]">
  {/* the rest of the bar */}
</ComposerPrimitive.AttachmentDropzone>
```

文件拖动到 `AttachmentDropzone` 上方时，它会设置 `data-dragging="true"`，并以与 `addAttachment` 相同的方式暂存所有拖放的文件；即使未配置适配器，它也会接管此次放置操作，因此未被阻止的拖放不会导致标签页跳转到该文件。

  </Step>
</Steps>

</RuntimeMode>

### 保存附件列表

```tsx title="app/chat-box.tsx"
"use client";

import { useState } from "react";
import { ComposerAttachments, ComposerAttachmentChip, type ComposerAttachment } from "@/components/assistant-ui/elements/composer";

export function ChatBox() {
  const [attachments, setAttachments] = useState<ComposerAttachment[]>([]);

  const remove = (name: string) =>
    setAttachments((prev) => prev.filter((a) => a.name !== name));

  return (
    <ComposerAttachments>
      {attachments.map((attachment) => (
        <ComposerAttachmentChip key={attachment.name} attachment={attachment} onRemove={remove} />
      ))}
    </ComposerAttachments>
  );
}
```

  </Step>
  <Step>

### 自行驱动上传

```tsx
async function upload(file: File) {
  const attachment: ComposerAttachment = { name: file.name, meta: "0%", state: "uploading", progress: 0, kind: "image" };
  setAttachments((prev) => [...prev, attachment]);

  await uploadWithProgress(file, (progress) =>
    setAttachments((prev) => prev.map((a) => (a.name === file.name ? { ...a, progress, meta: `${progress}%` } : a))),
  );

  setAttachments((prev) => prev.map((a) => (a.name === file.name ? { ...a, state: "done", meta: formatSize(file.size) } : a)));
}
```

  </Step>
</Steps>

## 结构

```tsx
<div data-slot="composer-attachment" data-state={/* "uploading" | "done" | "error" */}>
  <span>{/* icon: image, text, or archive, by kind */}</span>
  <span>
    <span>{/* name */}</span>
    <span>{/* meta; turns red when state is "error" */}</span>
  </span>
  <span>{/* trailing slot */}</span>
  {/* progress bar along the bottom edge, only while uploading */}
</div>
```

尾部插槽有三种状态，而不是两种：上传中显示加载指示器；上传完成且存在 `onRemove` 处理器时显示移除按钮；上传完成但没有 `onRemove` 时则显示普通的勾选标记，因为既然没有任何监听者，就没有可移除的内容。`"error"` 状态不会显示这三者中的任何一个（只显示红色元信息文本），这与运行时自身的 `"incomplete"` 状态一致；该状态包含 `message`，但自身没有内置的重试操作入口。

## 示例

### 上传进度

<RuntimeMode>

适配器流式传输 `PendingAttachment` 时，`aui.composer.getState().attachments[i].status` 为 `{ type: "running", reason: "uploading", progress }`；你可以读取它来驱动自己的进度条，也可以使用 `AttachmentPrimitive.unstable_Thumb`。未提供缩略图时，后者会回退到使用文件扩展名或 MIME 类型。

```tsx
const status = useAuiState((s) => s.attachment.status);
// { type: "running", reason: "uploading", progress: 42 } while uploading
// { type: "complete" } once sent
```

</RuntimeMode>

<StandaloneMode>

示例中的标签会直接读取 `progress`，并在 `state` 为 `"uploading"` 时，将蓝色进度条扩展到对应宽度；当你将 `state` 切换为 `"done"` 后，进度条会完全消失，而不是停留在满宽状态。

```tsx
<ComposerAttachmentChip attachment={{ name: "photo.png", meta: "1.2 MB", state: "uploading", progress: 62, kind: "image" }} />
```

</StandaloneMode>

### 重新设置标签样式

两种方式都在外层元素上接收 `className`；图标方块、两行标签文本和尾部插槽通过 `flex` 进行布局，无需一起移动。

```tsx
<AttachmentPrimitive.Root className="rounded-2xl py-2" />
```

### 消息发送后

输入框中的附件仍然是本地的，并且可以移除；消息发送后，附件会改为存放在消息内部，并变为只读。[Attachment](/elements/attachment) 介绍运行时在消息侧的渲染方式，其[已接收文件设计](/elements/attachment#the-received-files-design)则介绍对应的独立模式实现。

## API 参考

<RuntimeMode>

### ComposerPrimitive

| Part | Renders | Notes |
|------|---------|-------|
| `Attachments` | render prop | `{({ attachment }) => ReactNode}`，每个暂存文件渲染一次。 |
| `AttachmentByIndex` | wrapper | 在固定的 `index` 上渲染一个附件；由 `Attachments` 在内部使用。 |
| `AddAttachment` | `button` | 打开原生文件选择器，并将文件类型过滤为 `attachmentAccept`；仅当输入框不可编辑时禁用。因此，在未配置适配器时进行选择会打开文件选择器，但添加文件会静默失败。 |
| `AttachmentDropzone` | `div`（或 `asChild`） | 文件拖动到其上方时显示 `data-dragging="true"`；放置文件时会对每个文件调用 `addAttachment`。 |

### AttachmentPrimitive

| Part | Renders | Notes |
|------|---------|-------|
| `Root` | `div` | 将 `.Name`、`.Remove` 和 `.unstable_Thumb` 限定到当前位置的附件。必须位于 `ComposerPrimitive.Attachments` 内（如果附件已经属于已发送的消息，则位于 `MessagePrimitive.Attachments` 内）。 |
| `Name` | text | 附件的 `name`。 |
| `Remove` | `button` | 调用 `aui.attachment.remove()`。 |
| `unstable_Thumb` | `div` | 渲染其 `children`；如果没有，则将文件扩展名（或 MIME 类型）作为文本显示。 |

### 输入框和附件状态

| Selector | Type | Description |
|----------|------|-------------|
| `s.composer.attachments` | `readonly Attachment[]` | 此输入框中暂存的所有文件。 |
| `s.composer.attachmentAccept` | `string` | 已配置适配器的 `accept`，或 `"*"`。 |
| `s.thread.capabilities.attachments` | `boolean` | 是否配置了附件适配器。 |
| `s.attachment.name` / `.type` / `.contentType?` | `string` | 当前作用域内附件的标识。 |
| `s.attachment.status` | `PendingAttachmentStatus \| CompleteAttachmentStatus` | 见下文。 |
| `aui.composer.addAttachment(file)` | `(file: File \| CreateAttachment) => Promise<void>` | 暂存一个文件。 |
| `aui.composer.clearAttachments()` | `() => Promise<void>` | 移除所有暂存的附件。 |

`PendingAttachmentStatus` 可以是 `{ type: "running", reason: "uploading", progress: number }`、`{ type: "requires-action", reason: "composer-send" }`（已上传，等待发送），或 `{ type: "incomplete", reason: "error" | "upload-paused", message?: string }`。`CompleteAttachmentStatus` 为 `{ type: "complete" }`。

</RuntimeMode>

<StandaloneMode>

### ComposerAttachment

| Field | Type | Description |
|-------|------|-------------|
| `name` | `string` | 作为标签的文本显示。 |
| `meta` | `string` | 名称下方的一行文本（大小、百分比或错误提示）。 |
| `state` | `"uploading" \| "done" \| "error"` | 控制图标、尾部插槽和元信息文本的颜色。 |
| `progress` | `number` | 当 `state` 为 `"uploading"` 时，进度条的宽度，取值范围为 0 到 100。 |
| `kind` | `"image" \| "text" \| "archive"` | 选择前置图标。@default 会渲染文本图标。 |

### ComposerAttachments / ComposerAttachmentChip

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `attachment` | `ComposerAttachment` | required | 要渲染的文件（仅限 `ComposerAttachmentChip`）。 |
| `onRemove` | `(name: string) => void` | | 当 `state` 为 `"done"` 时显示为移除按钮；省略时则显示勾选标记。 |
| `className` | `string` | | 合并到根元素上。 |

</StandaloneMode>
