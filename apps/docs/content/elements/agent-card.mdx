代理卡片是远程代理在你与其交谈前展示的身份信息：名称、能力以及所在位置。在运行时中，卡片来自你连接的 A2A 代理；在独立模式下，则由你自行提供相同的字段。

## 入门

<RuntimeMode>

`@assistant-ui/react-a2a` 会在连接远程代理的过程中获取其代理卡片，并通过只读 Hook 暴露该卡片。

<Steps>
  <Step>

### 连接代理

```tsx title="app/A2AProvider.tsx"
"use client";

import { AssistantRuntimeProvider } from "@assistant-ui/react";
import { useA2ARuntime } from "@assistant-ui/react-a2a";

export function A2AProvider({ children }: { children: React.ReactNode }) {
  const runtime = useA2ARuntime({ baseUrl: "https://weather-agent.example.com" });
  return (
    <AssistantRuntimeProvider runtime={runtime}>
      {children}
    </AssistantRuntimeProvider>
  );
}
```

  </Step>
  <Step>

### 渲染发现的卡片

```tsx title="components/assistant-ui/elements/connected-agent-card.tsx"
"use client";

import { useA2AAgentCard } from "@assistant-ui/react-a2a";
import { AgentCard } from "@/components/assistant-ui/elements/agent-card";

export function ConnectedAgentCard() {
  const agentCard = useA2AAgentCard();
  if (!agentCard) return null;

  return (
    <AgentCard
      name={agentCard.name}
      description={agentCard.description}
      provider={agentCard.provider?.organization ?? ""}
      version={agentCard.version}
      endpoint={agentCard.supportedInterfaces[0]?.url ?? ""}
      skills={agentCard.skills.map((skill) => ({
        name: skill.name,
        description: skill.description,
      }))}
      model="gpt-5.6-sol"
      connected
    />
  );
}
```

`useA2AAgentCard` 会在客户端获取卡片之前返回 `undefined`，因此上面的连接检查可以充当加载状态。A2A 协议本身的卡片中没有模型标识符，除了到达代理之外也没有单独的连接步骤，因此 `model` 是由你的应用提供的值，而卡片存在后，`connected` 就只是 `true`。

  </Step>
</Steps>

</RuntimeMode>

## 结构

```tsx
<div data-slot="agent-card">
  <div>
    <span>{/* bot icon avatar */}</span>
    <div>
      <span>{name} <span>v{version}</span></span>
      <span>{provider}</span>
    </div>
  </div>
  <p>{description}</p>
  <div>{/* one row per skill: name pill + description */}</div>
  <div>
    <span>{endpoint}</span>
    <span>{model}</span>
  </div>
  <button>{connected ? "Connected" : "Connect"}</button>
</div>
```

名称、提供商、端点和模型文本都会截断，而不会换行。按钮是唯一的交互部分：当 `connected` 为 true 时，按钮会显示为禁用状态，并带有勾选图标和“已连接”标签；否则，点击时会调用 `onConnect`。空的 `skills` 数组只会让该部分不渲染任何行，不会显示占位文本。

## 示例

### 技能列表

每项技能包含名称和一行描述；名称会渲染在共享的 `field` 徽标标记中。

```tsx
<AgentCard
  {...rest}
  skills={[
    { name: "search_docs", description: "Full-text search over indexed documents" },
    { name: "summarize", description: "Condense a document to key points" },
  ]}
/>
```

### 获取你自己的代理注册表

<StandaloneMode>

一种常见的独立模式场景是维护自己的代理目录，而不是使用 A2A 端点。将获取到的记录保存在状态中，并在记录到达之前不渲染任何内容：

```tsx
"use client";

import { useEffect, useState } from "react";
import { AgentCard } from "@/components/assistant-ui/elements/agent-card";

export function AgentDirectoryCard({ id }: { id: string }) {
  const [agent, setAgent] = useState<AgentRecord | null>(null);

  useEffect(() => {
    fetch(`/api/agents/${id}`)
      .then((res) => res.json())
      .then(setAgent);
  }, [id]);

  if (!agent) return null;
  return <AgentCard {...agent} onConnect={() => selectAgent(id)} />;
}
```

</StandaloneMode>

### 重新设置卡片样式

根元素使用共享的 `paper` 表面；版本徽标、端点和模型使用 `mono`；连接状态和技能名称使用 `field`。在 `surfaces.tsx` 中重新设置这些标记的样式后，所有基于它们构建的元素都会同步应用新样式。

```tsx
<AgentCard className="max-w-md rounded-3xl" {...rest} />
```

## API 参考

<RuntimeMode>

### Hook

| Hook | 返回值 | 描述 |
|------|---------|-------------|
| `useA2AAgentCard()` | `A2AAgentCard \| undefined` | 为已连接代理获取的卡片；解析完成前为 `undefined`。 |

### 将 A2AAgentCard 映射到 AgentCard

| `AgentCard` prop | 来源 |
|-------------------|--------|
| `name` | `agentCard.name` |
| `description` | `agentCard.description` |
| `provider` | `agentCard.provider?.organization` |
| `version` | `agentCard.version` |
| `endpoint` | `agentCard.supportedInterfaces[0]?.url` |
| `skills` | `agentCard.skills.map(s => ({ name: s.name, description: s.description }))` |
| `model` | `A2AAgentCard` 中不存在；请提供自己的标签。 |
| `connected` | `agentCard` 定义后为 `true`；A2A 没有单独的连接步骤。 |

</RuntimeMode>

<StandaloneMode>

### AgentCard

| Prop | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `name` | `string` | 必填 | 代理名称，会截断。 |
| `description` | `string` | 必填 | 一段完整显示的文字。 |
| `provider` | `string` | 必填 | 显示在名称下方，会截断。 |
| `version` | `string` | 必填 | 以 `v{version}` 的形式显示在名称旁边。 |
| `model` | `string` | 必填 | 显示在页脚行中，会截断。 |
| `endpoint` | `string` | 必填 | 显示在页脚行中，会截断。 |
| `skills` | `readonly AgentSkill[]` | 必填 | 渲染为名称/描述行；为空时不渲染任何内容。 |
| `connected` | `boolean` | 必填 | 为 true 时禁用按钮，并替换其标签和图标。 |
| `onConnect` | `() => void` | | 当按钮点击时 `connected` 为 false，会调用此函数。 |
| `className` | `string` | | 合并到根元素上。 |

### AgentSkill

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `name` | `string` | 显示为徽标。 |
| `description` | `string` | 显示在徽标旁边，会截断。 |

其他所有 `div` props 都会转发到根元素。

</StandaloneMode>
