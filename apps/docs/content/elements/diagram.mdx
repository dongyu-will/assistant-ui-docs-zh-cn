Diagram 是已经由其他地方渲染好的图形的外壳：它会在你传入 `children` 的内容周围包裹标题、缩放百分比和缩放控件。使用运行时（runtime）时，你可以将工具渲染出的任意内容传递给它；单独使用时，则由你自己管理缩放级别和图形。

## 入门

<RuntimeMode>

使用运行时时，`Diagram` 会渲染工具已经转换成的图形：图片 URL、图表库的输出，或 Mermaid 等渲染器生成的标记。它只负责缩放外壳；缩放级别本身仍由调用方管理，因为每个缩放回调都是可选的，而当前的 `zoom` 只是一个普通 prop。

  <Step>

### 渲染工具调用

```tsx title="components/assistant-ui/elements/render-diagram-tool-ui.tsx"
"use client";

import { useState } from "react";
import type { ToolCallMessagePartComponent } from "@assistant-ui/react";
import { Diagram } from "@/components/assistant-ui/elements/diagram";

type RenderDiagramResult = { title: string; imageUrl: string };

export const RenderDiagramToolUI: ToolCallMessagePartComponent<
  { prompt: string },
  RenderDiagramResult
> = ({ result }) => {
  const [zoom, setZoom] = useState(1);
  if (!result) return null;

  return (
    <Diagram
      title={result.title}
      zoom={zoom}
      onZoomIn={() => setZoom((z) => Math.min(2, z + 0.2))}
      onZoomOut={() => setZoom((z) => Math.max(0.4, z - 0.2))}
      onReset={() => setZoom(1)}
    >
      <img src={result.imageUrl} alt={result.title} className="max-w-none" />
    </Diagram>
  );
};
```

  </Step>
  <Step>

### 注册工具

```tsx title="app/toolkit.ts"
import { defineToolkit } from "@assistant-ui/react";
import { z } from "zod";
import { RenderDiagramToolUI } from "@/components/assistant-ui/elements/render-diagram-tool-ui";

export const toolkit = defineToolkit({
  render_diagram: {
    type: "frontend",
    description: "Render a labeled diagram from a text description.",
    parameters: z.object({ prompt: z.string() }),
    execute: async ({ prompt }) => renderDiagramImage(prompt),
    render: RenderDiagramToolUI,
  },
});
```

```tsx title="app/MyRuntimeProvider.tsx"
import { AssistantRuntimeProvider, AuiConfig, Tools } from "@assistant-ui/react";
import { useChatRuntime } from "@assistant-ui/ai-sdk";
import { toolkit } from "./toolkit";

export function MyRuntimeProvider({ children }: { children: React.ReactNode }) {
  const runtime = useChatRuntime();
  const config = AuiConfig({ tools: Tools({ toolkit }) });
  return (
    <AssistantRuntimeProvider runtime={runtime} config={config}>
      {children}
    </AssistantRuntimeProvider>
  );
}
```

有关后端定义的工具和审批闸门，请参阅 [Tool UI](/docs/tools/tool-ui)。

单独使用时，`Diagram` 不会自行处理 `zoom`：请将其保存在状态中，并像下面的处理器一样自行限制其范围。

<Steps>
  <Step>

### 保存缩放级别

```tsx title="app/message-flow.tsx"
"use client";

import { useState } from "react";
import { Diagram } from "@/components/assistant-ui/elements/diagram";
import { FlowSvg } from "./flow-svg";

export function MessageFlow() {
  const [zoom, setZoom] = useState(1);

  return (
    <Diagram
      title="message flow"
      zoom={zoom}
      onZoomIn={() => setZoom((z) => Math.min(1.6, z + 0.2))}
      onZoomOut={() => setZoom((z) => Math.max(0.6, z - 0.2))}
      onReset={() => setZoom(1)}
    >
      <FlowSvg />
    </Diagram>
  );
}
```

  </Step>
  <Step>

### 打开全出血视图

除非传入处理器，否则 `onExpand` 会处于禁用状态。因此，当你有地方可以显示展开视图（例如对话框）时，请将其连接起来。

```tsx
const [open, setOpen] = useState(false);

<Diagram title="message flow" zoom={zoom} onExpand={() => setOpen(true)} /* ... */>
  <FlowSvg />
</Diagram>;
```

  </Step>
</Steps>

## 结构

```tsx
<div data-slot="diagram">
  <div>{/* title, zoom percentage, zoom-out / zoom-in / reset / expand buttons */}</div>
  <div>{/* children, scaled by `zoom` via a CSS transform */}</div>
</div>
```

展开按钮是唯一具有禁用状态的按钮：如果省略 `onExpand`，它会渲染 `disabled` 并显示为暗色，因为没有可供其打开的位置。其他三个按钮没有禁用状态，而且 `Diagram` 不会自行限制 `zoom` 的范围，因此超出范围的值就是调用方传入的值。百分比标签会将 `zoom` 四舍五入为最接近的整数。

## 示例

### 重新设置框架样式

两种方式都会在根元素上接收 `className`。标题栏按钮读取共享的 `ghostButton` 令牌，百分比读取 `mono`，二者都来自 `surfaces.tsx`。

```tsx
<Diagram className="max-w-none" /* ... */ />
```

### 限制缩放范围

`Diagram` 会报告按钮按下事件，但不会自行限制 `zoom` 的范围，因此请在修改它的同一组处理器中进行限制：

```tsx
const clamp = (z: number) => Math.min(2, Math.max(0.4, z));

<Diagram
  zoom={zoom}
  onZoomIn={() => setZoom((z) => clamp(z + 0.2))}
  onZoomOut={() => setZoom((z) => clamp(z - 0.2))}
  /* ... */
/>;
```

## API 参考

<RuntimeMode>

### 工具调用渲染 props

| Prop | 类型 | 描述 |
|------|------|-------------|
| `args` | `TArgs` | 解析后的参数。模型仍在流式传输参数时，该值可能是不完整的。 |
| `argsText` | `string` | 模型流式传输的原始 JSON 参数文本。 |
| `result` | `TResult \| undefined` | 工具完成后返回的值。运行期间为 `undefined`。 |
| `status` | `ToolCallMessagePartStatus` | `status.type` 为 `"running"`、`"requires-action"`、`"complete"` 或 `"incomplete"`。 |
| `toolName` | `string` | 模型调用的工具名称。 |
| `toolCallId` | `string` | 此次调用的稳定 ID。 |
| `isError` | `boolean \| undefined` | `result` 是否表示工具执行错误。 |

在工具包条目的 `render` 字段上注册渲染器，并使用 `Tools({ toolkit })` 挂载工具包。有关完整的渲染 props 接口（包括 `addResult`、人工工具和审批闸门），请参阅 [Tool UI](/docs/tools/tool-ui)。

</RuntimeMode>

<StandaloneMode>

### Diagram

| Prop | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `title` | `string` | 必填 | 显示在标题栏左侧。 |
| `zoom` | `number` | 必填 | 通过 CSS `transform` 应用于 `children` 的缩放比例。元素不会限制其范围。 |
| `children` | `React.ReactNode` | 必填 | 渲染后的图形。 |
| `onZoomIn` | `() => void` | | 点击放大按钮时调用。 |
| `onZoomOut` | `() => void` | | 点击缩小按钮时调用。 |
| `onReset` | `() => void` | | 点击重置按钮时调用。 |
| `onExpand` | `() => void` | | 点击全屏按钮时调用。省略此项会禁用该按钮。 |
| `className` | `string` | | 合并到根元素上。 |

所有其他 `div` props 都会转发到根元素。

</StandaloneMode>
