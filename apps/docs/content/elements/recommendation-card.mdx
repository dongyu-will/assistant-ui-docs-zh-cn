title: "推荐卡片"
description: "助手提出一项更改并给出置信度，等待用户确认。"

一张用于提出问题的卡片：通过一行正文说明提出该问题的理由，并在“替代方案”和“接受”按钮旁显示置信度；用户接受后，卡片会折叠为一行确认信息。在运行时中，该提议是一个由用户回答的工具调用；单独使用时，则由你保存状态并自行响应回调。

## 快速开始

<RuntimeMode>

这样的提议属于人在回路（human in the loop）工具调用：模型调用它来提出问题，用户选择答案后，卡片本身会提供结果。

<Steps>
  <Step>

### 渲染工具调用

```tsx title="app/toolkit.tsx"
"use client";

import { defineToolkit } from "@assistant-ui/react";
import { RecommendationCard } from "@/components/assistant-ui/elements/recommendation-card";

export const toolkit = defineToolkit({
  propose_change: {
    type: "human",
    render: ({ args, result, addResult }) => (
      <RecommendationCard
        state={result ? "accepted" : "idle"}
        question={args.question}
        confidenceLabel={args.confidenceLabel}
        acceptedLabel={args.acceptedLabel}
        onAccept={() => addResult({ accepted: true })}
        onAlternatives={() => addResult({ accepted: false })}
      >
        {args.detail}
      </RecommendationCard>
    ),
  },
});
```

调用 `addResult` 恰好一次来解析调用并让模型继续执行。结果的形状完全由你决定；这里的 `{ accepted: false }` 只是“显示其他内容”的约定，并不是固定的协议值。如果应用希望模型在尚未解析调用时继续提出建议，也可以让调用保持待处理状态，然后发送一条后续用户消息。

  </Step>
  <Step>

### 注册工具包

```tsx title="app/MyRuntimeProvider.tsx"
import { AssistantRuntimeProvider, AuiConfig, Tools } from "@assistant-ui/react";
import { toolkit } from "./toolkit";

const config = AuiConfig({ tools: Tools({ toolkit }) });

export function MyRuntimeProvider({ children }: { children: React.ReactNode }) {
  return (
    <AssistantRuntimeProvider runtime={runtime} config={config}>
      {children}
    </AssistantRuntimeProvider>
  );
}
```

<StandaloneMode>

单独使用时，该元素是一个受控显示组件：由你管理 `state`，并决定“接受”和“替代方案”的行为。

<Steps>
  <Step>

### 保存推荐状态

```tsx title="app/recommendation.tsx"
"use client";

import { useState } from "react";
import {
  RecommendationCard,
  type RecommendationState,
} from "@/components/assistant-ui/elements/recommendation-card";

export function Recommendation() {
  const [state, setState] = useState<RecommendationState>("idle");

  return (
    <RecommendationCard
      state={state}
      question="Enable draft autosave?"
      confidenceLabel="high confidence"
      acceptedLabel="Enabled for every thread"
      onAccept={() => setState("accepted")}
      onAlternatives={() => showAlternatives()}
    >
      Threads lose their draft on switch. Wiring runtime.drafts fixes it with
      three lines and no migration.
    </RecommendationCard>
  );
}
```

  </Step>
  <Step>

### 决定“替代方案”的行为

`onAlternatives` 没有内置含义；请将它连接到应用中“其他内容”的具体行为，例如打开其他选项的列表。

```tsx
function showAlternatives() {
  setOptionsOpen(true);
}
```

  </Step>
</Steps>

</StandaloneMode>

## 组成结构

```tsx
<div data-slot="recommendation-card">
  <p>{/* question */}</p>
  <p>{/* body, from children */}</p>
  <div>
    {/* state === "idle": confidence bars + confidenceLabel, then Alternatives and Accept */}
    {/* state === "accepted": a check and acceptedLabel */}
  </div>
</div>
```

三个置信度条具有固定形状（始终保持相同的三种高度），并不代表数值置信度的读数；只有 `confidenceLabel` 的文本是由数据驱动的。卡片本身不保存状态：`state` 决定渲染哪个页脚，并且会一直保持在 `"accepted"`，直到你将其改回其他值。

## 示例

### 重新设置卡片样式

两种布局都在根元素上接收 `className`。“接受”按钮使用 `inkButton`，置信度标签使用 `mono`；二者都来自 `surfaces.tsx`。

```tsx
<RecommendationCard className="max-w-md" /* ... */ />
```

### 没有替代方案的推荐

对于只能接受或忽略的提议，可以省略 `onAlternatives`；按钮仍会渲染，但没有可调用的处理逻辑。

```tsx
<RecommendationCard onAccept={() => setState("accepted")} /* ... */ />
```

## API 参考

<RuntimeMode>

### 渲染属性

| 来源 | 类型 | 描述 |
|--------|------|-------------|
| `args.question` / `args.confidenceLabel` / `args.acceptedLabel` | `string` | 用于标题、置信度行和已接受行的文本。 |
| `args.detail` | `string` | 渲染为卡片正文（即其 `children`）。 |
| `result` | `unknown` | 是否存在会映射到 `state="accepted"`。具体形状由应用定义。 |
| `addResult(result)` | `(result: TResult) => void` | 解析调用。请恰好调用一次。 |

</RuntimeMode>

<StandaloneMode>

### RecommendationCard

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `state` | `"idle" \| "accepted"` | required | 要渲染的页脚。 |
| `question` | `string` | required | 标题行。 |
| `children` | `ReactNode` | required | 问题下方的正文。 |
| `confidenceLabel` | `string` | required | 固定置信度条旁的文本。 |
| `acceptedLabel` | `string` | required | 当 `state` 为 `"accepted"` 后显示。 |
| `onAccept` | `() => void` | | 由“接受”按钮触发。 |
| `onAlternatives` | `() => void` | | 由“替代方案”按钮触发。 |
| `className` | `string` | | 合并到根元素上。 |

所有其他 `div` 属性都会转发到根元素。

</StandaloneMode>
