---
title: "终端块"
description: "按行流式传输并以退出状态结束的命令输出。"
---

终端块会回显命令，并逐行显示其输出；命令完成后显示对勾，运行期间则显示闪烁的光标。在运行时中，命令及其各行输出来自工具调用的参数和结果；单独使用时，则需要直接提供这两者。

## 快速开始

### 渲染工具调用

```tsx title="components/assistant-ui/elements/run-command-tool-ui.tsx"
"use client";

import type { ToolCallMessagePartComponent } from "@assistant-ui/react";
import { TerminalBlock } from "@/components/assistant-ui/elements/terminal-block";

type RunCommandArgs = { command: string };
type RunCommandResult = { output: string };

export const RunCommandToolUI: ToolCallMessagePartComponent<
  RunCommandArgs,
  RunCommandResult
> = ({ args, result, status }) => {
  const lines = result ? result.output.split("\n") : [];
  return (
    <TerminalBlock
      command={args.command ?? ""}
      lines={lines}
      visibleCount={lines.length}
      done={status.type !== "running"}
    />
  );
};
```

  </Step>
  <Step>

### 注册工具

```tsx title="app/toolkit.ts"
import { defineToolkit } from "@assistant-ui/react";
import { RunCommandToolUI } from "@/components/assistant-ui/elements/run-command-tool-ui";

export const toolkit = defineToolkit({
  run_command: {
    type: "backend",
    render: RunCommandToolUI,
  },
});
```

```tsx title="app/MyRuntimeProvider.tsx"
import { AssistantRuntimeProvider, AuiConfig, Tools } from "@assistant-ui/react";
import { useChatRuntime } from "@assistant-ui/ai-sdk";
import { toolkit } from "./toolkit";

export function MyRuntimeProvider({ children }: { children: React.ReactNode }) {
  const runtime = useChatRuntime();
  const config = AuiConfig({ tools: Tools({ toolkit }) });
  return (
    <AssistantRuntimeProvider runtime={runtime} config={config}>
      {children}
    </AssistantRuntimeProvider>
  );
}
```

拥有 `run_command` 的后端会提供其架构和执行器；请参阅[后端工具](/docs/tools/backend)。

### 保存命令及其各行输出

```tsx title="app/run.tsx"
"use client";

import { TerminalBlock } from "@/components/assistant-ui/elements/terminal-block";

const LINES = ["RUN v4.0.5", "✓ 3 tests passed"] as const;

export function TestRun() {
  return (
    <TerminalBlock
      command="pnpm vitest run"
      lines={LINES}
      visibleCount={LINES.length}
      done
    />
  );
}
```

### 显示运行状态

进程运行期间，将 `done` 切换为 `false`；标题中的对勾会替换为加载指示器，并在最后一行可见输出之后显示闪烁的光标：

```tsx
<TerminalBlock command="pnpm vitest run" lines={LINES} visibleCount={1} done={false} />
```

## 组成

```tsx
<div data-slot="terminal-block">
  <div>{/* command text, a spinner while running, a checkmark + "exit 0" once done */}</div>
  <div>{/* lines revealed up to visibleCount; the last line stays bright; a blinking cursor while !done */}</div>
</div>
```

无论实际结果如何，退出行始终显示 `exit 0`：`done` 只会在加载指示器和对勾之间切换标题；没有用于表示非零退出代码或运行失败的 prop。正文会保留最小高度，因此随着各行输出到达，终端块不会调整大小。`visibleCount` 会限制为 `lines` 的长度，且只有最近显示的行以完全不透明度渲染；更早的行会逐渐变暗。

## 示例

### Ink 变体

`variant="ink"` 会将终端块反转为纯深色面板，并使文字在其上呈现更浅的颜色。其他所有 prop 和行为均保持不变。

```tsx
<TerminalBlock variant="ink" command="pnpm vitest run" lines={LINES} visibleCount={2} done />
```

### 重新设置终端样式

两种变体都会在根元素上接收 `className`。paper 变体的背景和边框来自 `surfaces.tsx` 中共享的 `paper` token；ink 变体则直接设置自己的背景。

```tsx
<TerminalBlock className="max-w-none" /* ... */ />
```

<StandaloneMode>

### 重放输出

通过定时器递增 `visibleCount`，即可像目录自身的预览一样，逐行重放捕获的运行结果：

```tsx
const [visibleCount, setVisibleCount] = useState(0);

useEffect(() => {
  if (visibleCount >= LINES.length) return;
  const id = setTimeout(() => setVisibleCount((n) => n + 1), 700);
  return () => clearTimeout(id);
}, [visibleCount]);
```

## API 参考

<RuntimeMode>

### 工具调用渲染 props

| Prop | 类型 | 描述 |
|------|------|-------------|
| `args` | `{ command: string }` | 模型请求运行的命令。 |
| `result` | `{ output: string } \| undefined` | 工具调用完成后捕获的输出。 |
| `status` | `ToolCallMessagePartStatus` | 进程仍在执行时的 `status.type === "running"`。 |

有关完整的渲染 props，以及后端工具注册，请参阅[工具 UI](/docs/tools/tool-ui)。

</RuntimeMode>

<StandaloneMode>

### TerminalBlock

| Prop | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `command` | `string` | 必填 | 标题中显示的命令行。 |
| `lines` | `readonly string[]` | 必填 | 按顺序排列的输出行。 |
| `visibleCount` | `number` | 必填 | 要从 `lines` 开始渲染的行数。 |
| `done` | `boolean` | 必填 | 在加载指示器和对勾之间切换标题，并隐藏闪烁的光标。 |
| `variant` | `"paper" \| "ink"` | `"paper"` | 视觉表面。 |
| `className` | `string` | | 合并到根元素上。 |

其他所有 `div` props 都会转发到根元素。

</StandaloneMode>
