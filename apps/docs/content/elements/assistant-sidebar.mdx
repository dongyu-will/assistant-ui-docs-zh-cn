---
title: "助手侧边栏"
description: "用于副驾驶体验和上下文辅助的可调整大小侧面板。"
---

助手侧边栏将屏幕划分为应用和线程，中间带有拖动手柄。它没有独立的表单，因为它唯一持有的状态就是可调整大小的分栏，而会话窗格始终是一个实时线程。

## 开始使用

<RuntimeMode>

`AssistantSidebar`除了组件树上层的运行时提供程序以及要显示在左侧窗格中的内容外，无需其他配置。

<Steps>
  <Step>

### 包裹你的应用

```tsx title="app/layout.tsx"
import { AssistantSidebar } from "@/components/assistant-ui/elements/assistant-sidebar.aui";

export default function Layout({ children }: { children: React.ReactNode }) {
  return <AssistantSidebar>{children}</AssistantSidebar>;
}
```

需要一个 `AssistantRuntimeProvider` 祖先组件。`children` 会渲染在左侧窗格中；完整的[线程](/elements/thread)会填充右侧窗格。

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

助手侧边栏没有独立的表单：它唯一的 prop 是 `children`，会话窗格始终是仅运行时的线程。如果要使用静态或其他非运行时的右侧窗格创建可调整大小的分栏，请直接围绕你自己的内容组合 `ResizablePanelGroup`。

</StandaloneMode>

## 结构

```tsx
<ResizablePanelGroup orientation="horizontal">
  <ResizablePanel>{children}</ResizablePanel>
  <ResizableHandle />
  <ResizablePanel>
    <Thread />
  </ResizablePanel>
</ResizablePanelGroup>
```

两个窗格都没有设置 `defaultSize` 或 `minSize`，因此分组会从均等分栏开始，并且任一侧都可以拖动到无限接近零的宽度。

## 示例

### 限制分栏范围

```tsx
<ResizablePanelGroup orientation="horizontal">
  <ResizablePanel defaultSize={70} minSize={30}>
    {children}
  </ResizablePanel>
  <ResizableHandle />
  <ResizablePanel defaultSize={30} minSize={20}>
    <Thread />
  </ResizablePanel>
</ResizablePanelGroup>
```

### 在手柄上显示抓手

```tsx
<ResizableHandle withHandle />
```

## API 参考

<RuntimeMode>

### AssistantSidebarProps

| Prop | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `children` | `ReactNode` | 必填 | 在左侧窗格中渲染。 |

### 窗格

`ResizablePanelGroup`、`ResizablePanel` 和 `ResizableHandle` 来自 `@/components/ui/resizable`，后者是对 `react-resizable-panels` 的轻量封装；底层库的所有 prop（包括 `defaultSize`、`minSize`、`maxSize` 和 `order`）都会直接透传。

</RuntimeMode>
