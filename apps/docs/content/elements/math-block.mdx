展示推导过程而非最终结果的答案：由一组简短步骤组成，每一步都是一个表达式，下方可带有可选说明，并且只展示到你指定的步骤。在运行时中，步骤会随着模型的流式输出通过工具调用到达；单独使用时，则由你自行持有步骤数组和展示数量。

## 入门

<RuntimeMode>

此元素没有专属的 assistant-ui 原语：推导过程正是工具调用所携带的结构化内容，因此运行时接入使用的是工具渲染器，而不是原语组合。

### 注册渲染函数

```tsx title="app/toolkit.tsx"
"use client";

import { defineToolkit } from "@assistant-ui/react";
import { MathBlock } from "@/components/assistant-ui/elements/math-block";

export const toolkit = defineToolkit({
  show_derivation: {
    type: "backend",
    render: ({ args }) => {
      const steps = args.steps ?? [];
      return (
        <MathBlock
          label={args.label}
          steps={steps}
          visibleSteps={steps.length}
        />
      );
    },
  },
});
```

`show_derivation` 除了返回自身参数外无需执行任何操作：推导过程就是模型流式输出的内容，因此渲染器会在每种状态下读取 `args`，无需设计单独的结果结构，而匹配的服务端入口可以精简为 `execute: async (args) => args`。完整了解工具的 schema、执行器和渲染器之间的划分，请参阅[定义工具](/docs/tools/defining-tools)。

  </Step>
  <Step>

### 让消息列表渲染它

```tsx title="app/MyRuntimeProvider.tsx"
import {
  AssistantRuntimeProvider,
  AuiConfig,
  Tools,
} from "@assistant-ui/react";
import { useChatRuntime } from "@assistant-ui/ai-sdk";
import { toolkit } from "./toolkit";

export function MyRuntimeProvider({
  children,
}: {
  children: React.ReactNode;
}) {
  const runtime = useChatRuntime();
  const config = AuiConfig({ tools: Tools({ toolkit }) });
  return (
    <AssistantRuntimeProvider runtime={runtime} config={config}>
      {children}
    </AssistantRuntimeProvider>
  );
}
```

注册工具包后，`Thread` 以及任何基于 assistant-ui 消息部分原语构建的自定义消息列表（`MessagePrimitive.Parts` 或 `MessagePrimitive.GroupedParts`），都会在消息中出现 `show_derivation` 调用的位置自动渲染已注册的 UI，因此无需手动放置任何内容。

  </Step>
</Steps>

### 直接传入步骤

```tsx title="app/answer.tsx"
"use client";

import {
  MathBlock,
  type MathStep,
} from "@/components/assistant-ui/elements/math-block";

const steps: readonly MathStep[] = [
  { expression: "p′(x) = p(x)·(1 − p(x))", note: "the derivative" },
  {
    expression: "max p′(x) = 0.25 at x = 0",
    note: "steepest at the midpoint",
  },
];

export function Derivation() {
  return (
    <MathBlock label="derivation" steps={steps} visibleSteps={steps.length} />
  );
}
```

  </Step>

### 按自己的节奏展示步骤

```tsx
"use client";

import { useEffect, useState } from "react";

export function Derivation() {
  const [visibleSteps, setVisibleSteps] = useState(0);

  useEffect(() => {
    if (visibleSteps >= steps.length) return;
    const id = setTimeout(() => setVisibleSteps((n) => n + 1), 900);
    return () => clearTimeout(id);
  }, [visibleSteps]);

  return (
    <MathBlock label="derivation" steps={steps} visibleSteps={visibleSteps} />
  );
}
```

每次递增都会重新渲染，并多展示一个步骤；只有新显示的步骤会执行动画，因为之前的步骤已经挂载在相同的数组索引上。

  </Step>
</Steps>

</StandaloneMode>

## 组成

```tsx
<div data-slot="math-block">
  {/* optional label, monospace */}
  <span>{/* label */}</span>

  {/* one row per visible step, in array order */}
  <div>
    <span>{/* step.expression, a ReactNode */}</span>
    <span>{/* optional step.note */}</span>
  </div>
</div>
```

`visibleSteps` 会向下取整并限制在 `0…steps.length` 范围内：NaN 或负数会映射为 0，超过数组长度的值会映射为数组长度，因此超出范围或带小数的数量不会抛出异常，而只会向下取整为完整步骤。超出可见数量的步骤根本不会出现在 DOM 中，而不只是被隐藏；每个新显示的步骤都会在 300ms 内淡入并滑入。`label` 仅在其值为真值字符串时渲染。

## 示例

### 使用 Frac、Sup 和 Sub 组合表达式

工具调用只能将纯文本流式传输到 `expression`，因此运行时到达的分数或上标会渲染为普通字符，而不是堆叠布局。使用 `Frac`、`Sup` 和 `Sub` 构建更丰富的视觉效果属于单独使用时的工作：自行组装 JSX，并将其作为步骤的 `expression` 传入；无论在哪种使用方式下，渲染效果都相同。

```tsx
import { Frac, Sub, Sup } from "@/components/assistant-ui/elements/math-block";

const steps = [
  {
    expression: (
      <>
        p(x) ={" "}
        <Frac
          over={<>1</>}
          under={
            <>
              1 + e<Sup>−x</Sup>
            </>
          }
        />
      </>
    ),
    note: "the logistic",
  },
  {
    expression: (
      <>
        max<Sub>x</Sub> p′(x) = 0.25
      </>
    ),
  },
];
```

### 步骤的来源

<RuntimeMode>

推导过程由模型负责，因此后端入口只需要一个足够描述任意推导答案的 schema；执行器直接返回这些参数，首个步骤中的渲染器会完成其余工作。

```ts title="app/api/chat/route.ts"
show_derivation: tool({
  description: "Show a worked, step by step derivation.",
  inputSchema: z.object({
    label: z.string().optional(),
    steps: z.array(
      z.object({ expression: z.string(), note: z.string().optional() }),
    ),
  }),
  execute: async (args) => args,
}),
```

</RuntimeMode>

<StandaloneMode>

当步骤来自你自己的请求而不是固定常量时，请获取一次步骤，并重置展示数量，以便动画从头开始播放。

```tsx
async function loadDerivation(question: string) {
  const { steps: nextSteps } = await askForWorkedAnswer(question);
  setSteps(nextSteps);
  setVisibleSteps(0);
}
```

</StandaloneMode>

### 重新设置块的样式

两种使用方式都会在根元素上接收 `className`。标签使用来自 `surfaces.tsx` 的共享 `mono` 表面，因此重新设置该令牌的样式会同时重新设置所有使用它的元素。


```tsx
<MathBlock className="max-w-none gap-4" /* ... */ />
```

## API 参考

<RuntimeMode>

### 渲染属性

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `args` | `{ label?: string; steps: { expression: string; note?: string }[] }` | 模型流式传输的工具参数；当 `status.type` 为 `"running"` 时，它是一个部分解析结果。 |
| `status` | `ToolCallMessagePartStatus` | 在模型仍在输出 `args` 时为 `"running"`，调用完成后为 `"complete"`。 |

### show_derivation 参数

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `label` | `string` | 显示在步骤上方的可选标题。 |
| `steps[].expression` | `string` | 按纯文本渲染；如果步骤需要使用 `Frac`、`Sup` 和 `Sub`，请自行组装。 |
| `steps[].note` | `string` | 表达式下方的可选小标题。 |

</RuntimeMode>

<StandaloneMode>

### MathBlock

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `label` | `string` | | 显示在步骤上方的可选标题。 |
| `steps` | `readonly MathStep[]` | 必填 | 完整的步骤列表，仅渲染前 `visibleSteps` 个步骤。 |
| `visibleSteps` | `number` | 必填 | 要显示的步骤数量，会向下取整并限制在 `0…steps.length` 范围内。 |
| `className` | `string` | | 合并到根元素上。 |

其他所有 `div` 属性都会转发到根元素。

### MathStep

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `expression` | `ReactNode` | 步骤的表达式。接受纯文本，或使用 `Frac`、`Sup` 和 `Sub` 构建的 JSX。 |
| `note` | `string` | 表达式下方的可选标题。 |

</StandaloneMode>
