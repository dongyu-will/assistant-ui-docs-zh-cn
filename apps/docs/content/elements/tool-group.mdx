---
title: "工具组"
description: "在一次助手响应中包裹连续工具调用的可折司运行时包装器。"
---

工具组会将一串连续的工具调用折叠到单行中：显示调用数量、任一调用仍在运行时显示状态图标，以及一个可展开查看下方每次调用的箭头。使用运行时时，`Thread` 会决定哪些工具调用彼此相邻，并为工具组提供实时数量和状态；不存在此包装器的独立形式，因为分组只存在于一串自身的工具调用中。它有两种设计：运行时变体会自动将消息自身的工具调用部分分组，而静态变体 `ToolGroup` 接收一个显式数组中的调用，让你自行分组和控制（参见[并行工具设计](#the-parallel-tools-design)）。

## 入门

<RuntimeMode>

`Thread` 已经为你接入了此功能。

<Steps>
  <Step>

### 默认已启用

`Thread` 会使用 `MessagePrimitive.GroupedParts` 将相邻的工具调用部分分组，并严格使用下面的组成部分渲染每个组。

```tsx title="components/assistant-ui/elements/thread.aui.tsx"
import { groupPartByType, MessagePrimitive } from "@assistant-ui/react";
import {
  ToolGroupContent,
  ToolGroupRoot,
  ToolGroupTrigger,
} from "@/components/assistant-ui/elements/tool-group.aui";

<MessagePrimitive.GroupedParts
  groupBy={groupPartByType({
    "tool-call": ["group-tool"],
  })}
>
  {({ part, children }) => {
    switch (part.type) {
      case "group-tool":
        return (
          <ToolGroupRoot variant="ghost">
            <ToolGroupTrigger
              count={part.indices.length}
              active={part.status.type === "running"}
            />
            <ToolGroupContent>{children}</ToolGroupContent>
          </ToolGroupRoot>
        );
      // ...other cases
    }
  }}
</MessagePrimitive.GroupedParts>
```

  </Step>
  <Step>

### 为每个组覆盖默认实现

将 `components.ToolGroup` 传递给 `Thread`，即可替换所有工具调用组出现位置的这一组合方式。你的组件会接收与上述默认组合相同的 `group`（包含 `status` 和 `indices`）以及预渲染的 `children`。

```tsx
<Thread
  components={{
    ToolGroup: ({ group, children }) => (
      <MyToolGroup running={group.status.type === "running"} count={group.indices.length}>
        {children}
      </MyToolGroup>
    ),
  }}
/>
```

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

在独立使用时，没有可用于分组调用的调用序列。请参见下方的[并行工具设计](#the-parallel-tools-design)，了解可以自行分组和控制的 props 驱动版本。

</StandaloneMode>

## 结构

<RuntimeMode>

```tsx
<div data-slot="tool-group-root" data-variant="outline">
  <button data-slot="tool-group-trigger" aria-expanded={/* open */}>
    {/* spinner, only while active */}
    <span data-slot="tool-group-trigger-label">{/* "3 tool calls" / "1 tool call" */}</span>
    {/* chevron, rotates open */}
  </button>
  <div data-slot="tool-group-content">
    {/* each tool call, revealed with a staggered fade/slide */}
  </div>
</div>
```

触发器的标签始终使用复数形式“工具调用”，但恰好包含一个调用的组会显示“1 个工具调用”。内容中的子项会以轻微的交错效果淡入并滑入，每个子项的延迟最多递增到第五项；超过第五项后，其余所有子项共享相同的延迟。折叠或展开时，页面滚动位置会被短暂锁定，从而避免高度变化导致视口跳动。

</RuntimeMode>

## 示例

<RuntimeMode>

### 变体

`variant` 会改变工具组的外观：`"outline"`（默认值）会绘制带边框和内边距的卡片；`"ghost"`（`Thread` 实际使用的变体）完全没有边框或背景；`"muted"` 会绘制带边框和弱化背景的卡片。

```tsx
<ToolGroupRoot variant="outline">{/* ... */}</ToolGroupRoot>
<ToolGroupRoot variant="ghost">{/* ... */}</ToolGroupRoot>
<ToolGroupRoot variant="muted">{/* ... */}</ToolGroupRoot>
```

### 受控打开状态

`ToolGroupRoot` 默认是非受控的（`defaultOpen={false}`）；传入 `open` 和 `onOpenChange` 即可自行控制，例如一次展开所有组。

```tsx
<ToolGroupRoot open={expanded} onOpenChange={setExpanded}>
  {/* ... */}
</ToolGroupRoot>
```

</RuntimeMode>

## API 参考

<RuntimeMode>

### 部件

| 部件 | 渲染内容 | 说明 |
|------|---------|------|
| `ToolGroupRoot` | `div` | 可折叠容器。接受 `variant`、`open`、`onOpenChange` 和 `defaultOpen`。 |
| `ToolGroupTrigger` | `button` | 接收 `count` 和 `active`；用于切换工具组。 |
| `ToolGroupContent` | `div` | 可折叠面板；打开时渲染 `children`。 |

### ToolGroupRoot props

| Prop | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `variant` | `"outline" \| "ghost" \| "muted"` | `"outline"` | 视觉外观。 |
| `open` | `boolean` | | 受控的打开状态。 |
| `onOpenChange` | `(open: boolean) => void` | | 切换时调用。 |
| `defaultOpen` | `boolean` | `false` | 非受控时的初始状态。 |

### ToolGroupTrigger props

| Prop | 类型 | 描述 |
|------|------|-------------|
| `count` | `number` | 工具组中的工具调用数量；用于生成标签文本。 |
| `active` | `boolean` | 在 `true` 时显示加载指示器和闪烁标签。 |

### 组合

| 部件 | 类型 | 描述 |
|------|------|-------------|
| `group.status` | `MessagePartStatus \| ToolCallMessagePartStatus` | 任一包含的调用运行时显示运行中，否则反映最后一个调用的状态。 |
| `group.indices` | `readonly number[]` | 此组中消息部分的索引；其长度就是工具调用数量。 |
| `components.ToolGroup` | `ComponentType<PropsWithChildren<{ group }>>` | `Thread` prop，用于覆盖每个 `"group-tool"` 节点的默认组合。 |

</RuntimeMode>

## 并行工具设计

侧栏中的 Static 变体是相同折叠功能的第二种设计：`ToolGroup` 接收显式的 `tools` 数组中的调用，而不是读取消息的分组部分；它会根据每个调用的 `state` 计算自己的摘要（进度、失败数量或完成数量），而不是使用该工具包触发器所接收的 `count` 和 `active` props。它是一个不依赖运行时的单一 props 驱动组件：

```sh
npx shadcn@latest add "@assistant-ui/elements-tool-group"
```

<RuntimeMode>

将消息的 `tool-call` 部分映射为 `GroupedTool` 记录即可完成接入。`s.message.parts` 是存储自身的数组，因此直接选取它开销很小；派生 `tools` 仍然需要 `useMemo`，因为每次调用都映射出新数组会导致工具组在每次存储更新时重新渲染。

```tsx title="components/assistant-ui/elements/tool-group-live.tsx"
"use client";

import { useMemo, useState } from "react";
import { useAuiState, type ToolCallMessagePart } from "@assistant-ui/react";
import {
  ToolGroup,
  type GroupedTool,
} from "@/components/assistant-ui/elements/tool-group";

function toGroupedTool(part: ToolCallMessagePart): GroupedTool {
  const args = part.args as Record<string, unknown>;
  const state =
    part.status.type === "running"
      ? "running"
      : part.status.type === "complete"
        ? "done"
        : "failed";
  return {
    id: part.toolCallId,
    name: part.toolName,
    target: String(args.path ?? args.command ?? part.toolCallId),
    state,
    durationMs:
      part.timing && part.timing.completedAt
        ? part.timing.completedAt - part.timing.startedAt
        : undefined,
  };
}

function AssistantToolGroup() {
  const parts = useAuiState((s) => s.message.parts);
  const tools = useMemo(
    () =>
      parts.flatMap((part) =>
        part.type === "tool-call" ? [toGroupedTool(part)] : [],
      ),
    [parts],
  );
  const [open, setOpen] = useState(false);

  if (tools.length === 0) return null;

  return (
    <ToolGroup
      label={tools.length === 1 ? "1 tool call" : `${tools.length} tool calls`}
      tools={tools}
      open={open}
      onOpenChange={setOpen}
    />
  );
}
```

`state` 会将部分自身的状态折叠为 `ToolGroup` 所需的三个值：调用停止 `"running"` 后，任何不是 `"complete"` 的状态都会被视为 `"failed"`。与工具包的 `ToolGroupTrigger` 不同，`ToolGroup` 不会为你将 `label` 变为复数，因此调用方需要自行拼接该字符串。

</RuntimeMode>

<StandaloneMode>

在独立使用时，由你自行保存调用数组，并在点击时切换 `open`；触发器会在每次渲染时根据 `tools` 重新计算，因此更新某个调用的 `state` 后，整个工具组就会从运行中变为已完成，无需额外接线。

```tsx title="app/turn.tsx"
"use client";

import { useState } from "react";
import { ToolGroup, type GroupedTool } from "@/components/assistant-ui/elements/tool-group";

const initialCalls: GroupedTool[] = [
  { id: "1", name: "read_file", target: "src/index.ts", state: "done", durationMs: 120 },
  { id: "2", name: "read_file", target: "src/utils.ts", state: "running" },
];

export function Turn() {
  const [open, setOpen] = useState(false);
  const [tools, setTools] = useState(initialCalls);
  return (
    <ToolGroup label="2 tool calls" tools={tools} open={open} onOpenChange={setOpen} />
  );
}
```

</StandaloneMode>

触发器末尾的文本和图标来自 `tools`，而不是某个 prop：当任一调用处于 `"running"` 状态时，它会显示 `done/total` 和加载指示器；已完成且失败数量不为零的工具组会显示 `n failed` 和红色 X；完全完成且没有失败的工具组会显示 `n done` 和绿色勾号。

### ToolGroup

| Prop | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `label` | `string` | 必填 | 显示在箭头旁边的文本。 |
| `tools` | `readonly GroupedTool[]` | 必填 | 此工具组中的调用，按顺序排列。 |
| `open` | `boolean` | 必填 | 列表是否展开。 |
| `onOpenChange` | `(open: boolean) => void` | | 点击触发器时调用。 |
| `className` | `string` | | 合并到根元素上。 |

### GroupedTool

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `id` | `string` | React key。 |
| `name` | `string` | 工具名称，以等宽字体显示。 |
| `target` | `string` | 调用所操作的对象。 |
| `state` | `"running" \| "done" \| "failed"` | 控制行图标和触发器摘要。 |
| `durationMs` | `number` | 可选；存在时显示在行末尾。 |

所有其他 `div` props 都会转发到根元素。
