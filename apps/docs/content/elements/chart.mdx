---
title: "图表"
description: "面积图、折线图和柱状图，随着序列流式传输，数据点逐个呈现。"
---

图表会在小型 SVG 序列上方绘制标签、主要数值和可选的变化值，数据点会在可用时逐个呈现。在运行时中，序列会直接从工具调用的参数中流式传输出来；单独使用时，你可以控制显示其中多少内容。

## 开始使用

<RuntimeMode>

图表的序列通常来自生成主要数值的同一个工具调用，因此会通过该工具的 `render` 字段进行渲染。由于 `args` 是对模型仍在编写的 JSON 进行的尽力解析，`args.points` 会保存目前已流式传输的元素数量；将其长度直接作为 `visibleCount` 传入，图表就会随着数据到达逐个显示数据点。

<Steps>
  <Step>

### 渲染工具调用

```tsx title="components/assistant-ui/elements/plot-metric-tool-ui.tsx"
"use client";

import type { ToolCallMessagePartComponent } from "@assistant-ui/react";
import { Chart } from "@/components/assistant-ui/elements/chart";

type PlotMetricArgs = { label: string; points: number[] };
type PlotMetricResult = { value: string; delta?: string };

export const PlotMetricToolUI: ToolCallMessagePartComponent<
  PlotMetricArgs,
  PlotMetricResult
> = ({ args, result }) => {
  const points = args.points ?? [];
  return (
    <Chart
      label={args.label ?? ""}
      value={result?.value ?? "…"}
      delta={result?.delta}
      points={points}
      visibleCount={points.length}
      variant="area"
    />
  );
};
```

  </Step>
  <Step>

### 注册工具

```tsx title="app/toolkit.ts"
import { defineToolkit } from "@assistant-ui/react";
import { z } from "zod";
import { PlotMetricToolUI } from "@/components/assistant-ui/elements/plot-metric-tool-ui";

export const toolkit = defineToolkit({
  plot_metric: {
    type: "frontend",
    description: "Plot a metric's recent history as a small chart.",
    parameters: z.object({ label: z.string(), points: z.array(z.number()) }),
    execute: async ({ label, points }) => summarize(label, points),
    render: PlotMetricToolUI,
  },
});
```

```tsx title="app/MyRuntimeProvider.tsx"
import { AssistantRuntimeProvider, AuiConfig, Tools } from "@assistant-ui/react";
import { useChatRuntime } from "@assistant-ui/ai-sdk";
import { toolkit } from "./toolkit";

export function MyRuntimeProvider({ children }: { children: React.ReactNode }) {
  const runtime = useChatRuntime();
  const config = AuiConfig({ tools: Tools({ toolkit }) });
  return (
    <AssistantRuntimeProvider runtime={runtime} config={config}>
      {children}
    </AssistantRuntimeProvider>
  );
}
```

<StandaloneMode>

单独使用时，`points` 是完整序列，`visibleCount` 表示要绘制其中多少内容。在计时器上递增 `visibleCount`，即可重放一次流式传输。

<Steps>
  <Step>

### 暂存序列

```tsx title="app/runs-chart.tsx"
"use client";

import { useState } from "react";
import { Chart } from "@/components/assistant-ui/elements/chart";

const POINTS = [18, 22, 19, 31, 28, 42, 38, 51, 47, 63, 58, 71, 69, 84, 92];

export function RunsChart() {
  const [visibleCount, setVisibleCount] = useState(POINTS.length);
  return (
    <Chart
      label="Runs this week"
      value="92"
      delta="+34%"
      points={POINTS}
      visibleCount={visibleCount}
      variant="area"
    />
  );
}
```

  </Step>
  <Step>

### 按计时器显示数据点

```tsx
useEffect(() => {
  if (visibleCount >= POINTS.length) return;
  const id = setTimeout(() => setVisibleCount((n) => n + 1), 180);
  return () => clearTimeout(id);
}, [visibleCount]);
```

## 组成

```tsx
<div data-slot="chart">
  <div>{/* label, delta */}</div>
  <span>{/* value */}</span>
  <svg>{/* baseline, then an area+line, a line, or bars depending on variant */}</svg>
</div>
```

`visibleCount` 会限制在 `1…points.length` 范围内，因此图表始终至少绘制一个数据点，并且不会超出数组范围。在 `line` 和 `area` 变体中，只有最后一个可见数据点会显示实心圆点；在 `bars` 中，只有最后一个可见柱状条会着色，其余柱状条显示为柔和色。`delta` 的颜色取决于其开头的字符：减号、短破折号或长破折号表示下降，并显示为红色；其他字符表示上升，并显示为绿色；省略 `delta` 即可完全隐藏它。

## 示例

### 选择变体

`variant` 决定序列的绘制方式。无论选择哪种方式，标签、数值和变化值都保持在相同位置。

| 变体 | 绘制内容 |
|---------|-------|
| `"area"`（默认） | 折线下方的填充渐变，以及折线本身。 |
| `"line"` | 仅绘制折线，不进行填充。 |
| `"bars"` | 每个可见数据点对应一个柱状条，而不是绘制折线。 |

```tsx
<Chart variant="bars" /* ... */ />
```

### 重新设置图表样式

两种变体都会在根元素上接收 `className`。标签和数值从 `surfaces.tsx` 中共享的 `mono` 和 `paper` token 读取；序列本身使用 `chart.tsx` 中固定的蓝色填充和描边类进行绘制，因此要重新设置折线或柱状条的颜色，需要直接编辑该文件。

```tsx
<Chart className="max-w-none" /* ... */ />
```

## API 参考

<RuntimeMode>

### 工具调用渲染属性

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `args` | `TArgs` | 已解析的参数。模型仍在流式传输参数时，该值是不完整的。 |
| `argsText` | `string` | 模型流式传输的原始 JSON 参数文本。 |
| `result` | `TResult \| undefined` | 工具完成后返回的值。运行期间为 `undefined`。 |
| `status` | `ToolCallMessagePartStatus` | `status.type` 的值为 `"running"`、`"requires-action"`、`"complete"` 或 `"incomplete"`。 |
| `toolName` | `string` | 模型调用的工具名称。 |
| `toolCallId` | `string` | 此次调用的稳定 ID。 |
| `isError` | `boolean \| undefined` | `result` 是否表示工具执行错误。 |

在工具包条目的 `render` 字段上注册渲染器，并使用 `Tools({ toolkit })` 附加工具包。有关完整的渲染属性范围（包括 `addResult`、人工工具和审批门），请参阅[工具 UI](/docs/tools/tool-ui)。

</RuntimeMode>

<StandaloneMode>

### 图表

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `label` | `string` | 必填 | 数值上方的标题。 |
| `value` | `string` | 必填 | 已完成格式化的主要数值。 |
| `delta` | `string` | | 可选的变化指示器。以 `-`、`−` 或 `–` 开头表示下降；其他情况表示上升。 |
| `points` | `readonly number[]` | 必填 | 完整序列。 |
| `visibleCount` | `number` | 必填 | 要从 `points` 开头绘制的数据点数量。限制在 `1…points.length` 范围内。 |
| `variant` | `"area" \| "line" \| "bars"` | `"area"` | 序列的绘制方式。 |
| `className` | `string` | | 合并到根元素上。 |

其他所有 `div` 属性都会转发到根元素。

</StandaloneMode>
