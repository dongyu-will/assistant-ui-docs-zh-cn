---
title: "Tooltip 图标按钮"
description: "带有工具提示标签和共享交互状态的可访问图标按钮。"
---

TooltipIconButton 将单个图标包裹在按钮中，使按钮始终具有可访问名称和悬停工具提示，两者都由同一个 `tooltip` 字符串驱动。在运行时环境中，只要原语需要触发器，大多数 kit 元素都会使用这个按钮；单独使用时，则由你自行通过 `onClick` 和 `disabled` 驱动它。

## 开始使用

<RuntimeMode>

运行时连接的 kit 元素、线程、语音、附件和助手模态框中的每个操作按钮，都是一个 `TooltipIconButton`，通常通过 `render` 与原语组合，从而由原语负责点击处理以及禁用或隐藏状态。

<Steps>
  <Step>

### 与原语组合

```tsx title="components/assistant-ui/elements/thread.aui.tsx"
"use client";

import { ThreadPrimitive } from "@assistant-ui/react";
import { ArrowDownIcon } from "lucide-react";
import { TooltipIconButton } from "@/components/assistant-ui/elements/tooltip-icon-button";

function ScrollToBottom() {
  return (
    <ThreadPrimitive.ScrollToBottom
      render={<TooltipIconButton tooltip="Scroll to bottom" variant="outline" />}
    >
      <ArrowDownIcon />
    </ThreadPrimitive.ScrollToBottom>
  );
}
```

原语提供点击处理并将自身隐藏，尤其是 `ScrollToBottom` 在线程已经位于底部时不会渲染任何内容；`TooltipIconButton` 只提供外观、工具提示和可访问名称。

  </Step>
  <Step>

### 安装预先连接好的 kit 元素

仅 `@assistant-ui/thread` 就可以连接滚动到底部、发送、开始和停止语音听写、复制、刷新、编辑，以及切换到上一个和下一个分支等功能，并且全部作为 `TooltipIconButton` 使用。`@assistant-ui/voice`、`@assistant-ui/attachment` 和 `@assistant-ui/assistant-modal` 还会分别添加一些自身的功能。这些组合逻辑都不在此文件中，因此安装它们后，你很少需要直接使用 `TooltipIconButton`。

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

单独使用时，没有可与之组合的原语，因此点击处理、禁用状态，以及在操作可能失败或需要耗时执行时的加载状态，都需要由你自行管理。

<Steps>
  <Step>

### 像使用普通图标按钮一样使用

```tsx title="app/toolbar.tsx"
"use client";

import { useState } from "react";
import { SparklesIcon } from "lucide-react";
import { TooltipIconButton } from "@/components/assistant-ui/elements/tooltip-icon-button";

export function GenerateButton() {
  const [busy, setBusy] = useState(false);
  return (
    <TooltipIconButton
      tooltip="Generate"
      variant="outline"
      disabled={busy}
      onClick={async () => {
        setBusy(true);
        await generate();
        setBusy(false);
      }}
    >
      <SparklesIcon />
    </TooltipIconButton>
  );
}
```

  </Step>
</Steps>

</StandaloneMode>

## 结构

```tsx
<button data-slot="button">
  {/* the icon you pass as children */}
  <span className="sr-only">{/* tooltip text, as the accessible name */}</span>
</button>
```

工具提示提供器和浮动内容面板会包裹按钮，但在按钮获得悬停或焦点之前，它们自身不会渲染任何内容。`tooltip` 身兼二职：它既是浮动标签，也是按钮唯一的可访问名称（通过 sr-only span 实现），不存在单独的 `aria-label` 属性。`side` 用于定位浮动工具提示，默认值为 `"bottom"`。

## 示例

### `Button` 接受的每个属性都仍然有效

`TooltipIconButtonProps` 扩展了 `Button` 自身的属性，因此 `variant`（`"default" | "outline" | "secondary" | "ghost" | "destructive" | "link"`）、`size` 和 `disabled` 都会直接透传。组件本身只将 `variant="ghost"` 和 `size="icon"` 固定为默认值，两者都可以按常规方式覆盖：

```tsx
<TooltipIconButton tooltip="Delete" variant="destructive">
  <TrashIcon />
</TooltipIconButton>
```

### 重新设置按钮样式

`className` 会合并到渲染出的 `Button` 上，并覆盖此文件自身的 `size-6 p-1` 默认值。它不会从 `surfaces.tsx` 读取样式；与目录中的大多数组件不同，它的外观来自 `components/ui` 中 shadcn 风格的 `Button` 和工具提示原语。

```tsx
<TooltipIconButton tooltip="Copy" className="size-8">
  <CopyIcon />
</TooltipIconButton>
```

## API 参考

<RuntimeMode>

### 组合位置

| 文件 | 工具提示文本 |
|------|--------------|
| `thread.aui.tsx` | “滚动到底部”、“发送消息”、“语音输入”、“停止听写” |
| `thread.aui.tsx` | “复制”、“刷新”、“更多”、“编辑”、“上一个”、“下一个” |
| `voice.aui.tsx` | “静音”/“取消静音”、“断开连接” |
| `attachment.aui.tsx` | “添加附件”、“移除文件” |
| `assistant-modal.aui.tsx` | “打开助手”/“关闭助手” |
| `markdown-text.tsx` | 在渲染出的代码块上显示“复制” |

它自身没有状态选择器：它会通过 `render` 渲染其所包裹的原语决定的内容。

</RuntimeMode>

<StandaloneMode>

### TooltipIconButton

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `tooltip` | `string` | 必填 | 悬停或获得焦点时显示的浮动标签，也是按钮的可访问名称。 |
| `side` | `"top" \| "bottom" \| "left" \| "right"` | `"bottom"` | 工具提示展开的方向。 |
| `variant` | `"default" \| "outline" \| "secondary" \| "ghost" \| "destructive" \| "link"` | `"ghost"` | 继承自 `Button`。 |
| `size` | `"default" \| "xs" \| "sm" \| "lg" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg"` | `"icon"` | 继承自 `Button`。 |
| `className` | `string` | | 合并到渲染出的按钮上。 |

其他所有 `Button` 属性（`disabled`、`onClick`、`type` 等）都会被透传。

</StandaloneMode>
