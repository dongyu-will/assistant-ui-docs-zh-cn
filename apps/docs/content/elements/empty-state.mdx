空状态是线程显示的第一个屏幕：尚未发送任何内容，显示问候语、几个入口，并且输入框已经可见。在运行时中，它会随线程自身是否为空而显示和消失；在独立使用时，则由你控制它何时显示以及提供哪些选项。

## 入门

<RuntimeMode>

assistant-ui 线程在第一条消息到达前会保持为空，而 `s.thread.isEmpty` 正是用于跟踪这一状态。

<Steps>
  <Step>

### 在线程为空时显示


```tsx title="components/assistant-ui/elements/thread.aui.tsx"
"use client";

import { AuiIf } from "@assistant-ui/react";
import { EmptyState, EmptyStateGreeting } from "./empty-state";

function Welcome() {
  return (
    <AuiIf condition={(s) => s.thread.isEmpty}>
      <EmptyState>
        <EmptyStateGreeting>How can I help?</EmptyStateGreeting>
        {/* suggestions, composer */}
      </EmptyState>
    </AuiIf>
  );
}
```

`isEmpty` 会在仍处于加载历史记录期间保持 `false`，因此已持久化的会话不会先短暂显示问候语。

  </Step>
  <Step>

### 将建议转换为真实提示词


```tsx
import { useAuiState, ThreadPrimitive } from "@assistant-ui/react";
import { EmptyStateSuggestions, EmptyStateSuggestion } from "./empty-state";

function Suggestions() {
  const suggestions = useAuiState((s) => s.thread.suggestions);
  return (
    <EmptyStateSuggestions>
      {suggestions.map((suggestion, index) => (
        <ThreadPrimitive.Suggestion key={suggestion.prompt} prompt={suggestion.prompt} asChild>
          <EmptyStateSuggestion index={index}>
            {suggestion.title ?? suggestion.prompt}
          </EmptyStateSuggestion>
        </ThreadPrimitive.Suggestion>
      ))}
    </EmptyStateSuggestions>
  );
}
```

默认情况下，`ThreadPrimitive.Suggestion` 会将 `prompt` 填入输入框，因此读者可以在发送前进行编辑；也可以传入 `send`，让点击操作直接提交。`s.thread.suggestions` 是应用在运行时中配置的内容，可以是静态的引导提示词，也可以是模型在之前轮次中提出的提示词。

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

独立使用时，整个屏幕都由你控制：问候文本、建议列表，以及按下某个建议后执行的操作。

<Steps>
  <Step>

### 列出几个起始点


```tsx title="app/welcome.tsx"
"use client";

import {
  EmptyState,
  EmptyStateGreeting,
  EmptyStateSuggestions,
  EmptyStateSuggestion,
  EmptyStateComposer,
} from "@/components/assistant-ui/elements/empty-state";

const STARTERS = ["Summarize this doc", "Draft a reply", "Explain this error"];

export function Welcome({ onPick }: { onPick: (prompt: string) => void }) {
  return (
    <EmptyState>
      <EmptyStateGreeting>How can I help?</EmptyStateGreeting>
      <EmptyStateSuggestions>
        {STARTERS.map((prompt, index) => (
          <EmptyStateSuggestion key={prompt} index={index} onClick={() => onPick(prompt)}>
            {prompt}
          </EmptyStateSuggestion>
        ))}
      </EmptyStateSuggestions>
      <EmptyStateComposer placeholder="Ask anything" onSend={() => onPick("")} />
    </EmptyState>
  );
}
```

  </Step>
  <Step>

### 让入口依次出现

每条建议在挂载时都会以从 `index` 派生的延迟进行动画显示；传入该项在数组中的位置，使这一行依次展开，而不是同时突然出现：

```tsx
{STARTERS.map((prompt, index) => (
  <EmptyStateSuggestion key={prompt} index={index}>
    {prompt}
  </EmptyStateSuggestion>
))}
```

  </Step>
</Steps>

</StandaloneMode>

## 结构


```tsx
<div data-slot="empty-state">
  <h2 data-slot="empty-state-greeting" />
  <div data-slot="empty-state-suggestions">
    <button data-slot="empty-state-suggestion" />
  </div>
  <div data-slot="empty-state-composer">
    <span>{/* placeholder text */}</span>
    <button aria-label="Send" />
  </div>
</div>
```

问候语、建议行和输入框会在挂载时分别以逐渐增加的延迟淡入并滑入，其中输入框最后出现，延迟为 360ms。这样屏幕会从上到下逐步构建，而不是一次性全部出现。`EmptyStateComposer` 与 `ChatPanelComposer` 使用相同的外壳：`placeholder` 是显示文本，而不是绑定值；只要 `onSend` 保持 `undefined`，发送按钮就会自动禁用。

## 示例

### 重新设置布局样式

`EmptyState` 只设置最大宽度和垂直间距；每个部件都接受 `className`，因此建议行可以换行为网格，或者让问候语取消动画：

```tsx
<EmptyState className="max-w-lg gap-4">
  <EmptyStateGreeting className="animate-none text-3xl">
    How can I help?
  </EmptyStateGreeting>
  {/* ... */}
</EmptyState>
```

### 建议延迟

<RuntimeMode>

依次出现的效果完全来自你传入的 `index`；经过筛选或重新排序的列表会根据数组位置重新计算延迟，而不是使用存储的值：

```tsx
{suggestions.map((suggestion, index) => (
  <ThreadPrimitive.Suggestion key={suggestion.prompt} prompt={suggestion.prompt} asChild>
    <EmptyStateSuggestion index={index}>{suggestion.prompt}</EmptyStateSuggestion>
  </ThreadPrimitive.Suggestion>
))}
```

</RuntimeMode>

<StandaloneMode>

独立使用时，同样的规则也适用：`index` 会在每次渲染时读取一次，用于计算延迟，因此在同一列表重新渲染期间应保持其稳定。

</StandaloneMode>

## API 参考

<RuntimeMode>

### 原语部件

| 部件 | 渲染内容 | 备注 |
|------|---------|-------|
| `AuiIf` | children | 当 `condition` 选择 `true` 时渲染 `children`；使用 `(s) => s.thread.isEmpty`。 |
| `ThreadPrimitive.Suggestion` | `button` | 默认在点击时将 `prompt` 填入输入框；传入 `send` 可立即提交。接受 `asChild`。 |

### 线程状态

| 选择器 | 类型 | 描述 |
|----------|------|-------------|
| `s.thread.isEmpty` | `boolean` | 当线程没有消息且未加载历史记录时为 `true`。 |
| `s.thread.suggestions` | `readonly ThreadSuggestion[]` | 在运行时中配置的 `{ title?, label?, prompt }` 条目。 |

</RuntimeMode>

<StandaloneMode>

### EmptyState 系列

| 部件 | 渲染内容 | 属性 | 描述 |
|------|---------|-------|-------------|
| `EmptyState` | `div` | `className` | 根列容器，`max-w-md`。 |
| `EmptyStateGreeting` | `h2` | `className` | 居中的标题；首先淡入并滑入。 |
| `EmptyStateSuggestions` | `div` | `className` | 用于建议按钮的可换行行容器。 |
| `EmptyStateSuggestion` | `button` | `index?: number`（默认值为 `0`）、`className` | `index` 设置依次出现的延迟（`120ms + index * 70ms`）。 |
| `EmptyStateComposer` | `div` | `placeholder`（必需的 `string`）、`onSend?: () => void`、`className` | 与 `ChatPanelComposer` 使用相同的外壳；最后进行动画显示。 |

每个部件的其他属性都会转发到其根元素。

</StandaloneMode>
