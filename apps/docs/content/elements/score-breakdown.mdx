---
title: "评分明细"
description: "展示计算过程的评判结果：标准、权重，以及拉低分数的因素。"
---

一个由自身计算过程支撑的评判结果：显示总分与满分、带颜色的评判标签，以及产生该结果的加权标准。每项标准都有自己的进度条，并可选地附带说明其得分原因。在运行时中，分数来自工具结果；独立使用时，则由你自行传入标准和总分。

## 快速开始

<RuntimeMode>

此元素没有专属的 assistant-ui 原语，因此运行时接入使用的是工具渲染器，而不是原语组合。分数通常来自实际的评分工作：运行测试、检查差异、根据评分标准进行比较等，因此这些标准应放在工具的 `result` 上，而不是放在其流式传输的 `args` 上。

<Steps>
  <Step>

### 注册渲染函数

```tsx title="app/toolkit.tsx"
"use client";

import { defineToolkit } from "@assistant-ui/react";
import { ScoreBreakdown } from "@/components/assistant-ui/elements/score-breakdown";

export const toolkit = defineToolkit({
  review_change: {
    type: "backend",
    render: ({ args, result }) => {
      if (!result) return <p>Reviewing {args.target}…</p>;
      return (
        <ScoreBreakdown
          verdict={result.verdict}
          total={result.total}
          outOf={result.outOf}
          criteria={result.criteria}
          visibleCount={result.criteria.length}
        />
      );
    },
  },
});
```

由于整个明细会作为一个结果一次性到达，而不是作为流式步骤到达，`visibleCount` 只是 `result.criteria.length`；没有部分状态需要据此调整大小。

  </Step>
  <Step>

### 让消息列表渲染它

```tsx title="app/MyRuntimeProvider.tsx"
import {
  AssistantRuntimeProvider,
  AuiConfig,
  Tools,
} from "@assistant-ui/react";
import { useChatRuntime } from "@assistant-ui/ai-sdk";
import { toolkit } from "./toolkit";

export function MyRuntimeProvider({
  children,
}: {
  children: React.ReactNode;
}) {
  const runtime = useChatRuntime();
  const config = AuiConfig({ tools: Tools({ toolkit }) });
  return (
    <AssistantRuntimeProvider runtime={runtime} config={config}>
      {children}
    </AssistantRuntimeProvider>
  );
}
```

注册工具包后，`Thread` 以及任何基于 assistant-ui 消息部分原语（`MessagePrimitive.Parts` 或 `MessagePrimitive.GroupedParts`）构建的自定义消息列表，都会在消息中出现 `review_change` 调用的位置自动渲染已注册的 UI，因此无需手动放置。

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

独立使用时，此元素是一个普通的展示组件：它不管理自身状态，因此最简单的用法是一次性显示一组固定的标准。

<Steps>
  <Step>

### 直接传入标准

```tsx title="app/review-verdict.tsx"
"use client";

import {
  ScoreBreakdown,
  type ScoreCriterion,
} from "@/components/assistant-ui/elements/score-breakdown";

const criteria: readonly ScoreCriterion[] = [
  {
    label: "Fixes the root cause",
    score: 4.5,
    weight: 3,
    note: "Clears the slot at the source rather than at the call site.",
  },
  { label: "Test coverage", score: 4, weight: 2 },
  { label: "Scope discipline", score: 3, weight: 1 },
];

export function ReviewVerdict() {
  return (
    <ScoreBreakdown
      verdict="approve"
      total={4.1}
      outOf={5}
      criteria={criteria}
      visibleCount={criteria.length}
    />
  );
}
```

  </Step>
  <Step>

### 按自己的节奏逐项展示标准

```tsx
"use client";

import { useEffect, useState } from "react";

export function ReviewVerdict() {
  const [visibleCount, setVisibleCount] = useState(0);

  useEffect(() => {
    if (visibleCount >= criteria.length) return;
    const id = setTimeout(() => setVisibleCount((n) => n + 1), 600);
    return () => clearTimeout(id);
  }, [visibleCount]);

  return (
    <ScoreBreakdown
      verdict="approve"
      total={4.1}
      outOf={5}
      criteria={criteria}
      visibleCount={visibleCount}
    />
  );
}
```

  </Step>
</Steps>

</StandaloneMode>

## 组成

```tsx
<div data-slot="score-breakdown">
  <div>
    <span>{/* total.toFixed(1) */}</span>
    <span>{/* "/ outOf" */}</span>
    <span>{/* verdict pill, colored by the total/outOf ratio */}</span>
  </div>

  <div>
    {/* one row per visible criterion */}
    <div>
      <span>{/* criterion.label */}</span>
      <span>{/* "×" + weight */}</span>
      <span>{/* criterion.score.toFixed(1) */}</span>
    </div>
    <span>{/* per-criterion bar */}</span>
    <span>{/* optional criterion.note */}</span>
  </div>
</div>
```

无论 `visibleCount` 如何设置，页眉（总分、`/ outOf` 和评判标签）都会始终渲染；只有标准列表会像其他结构化输出元素一样，被切片、向下取整并限制在 `0…criteria.length` 中。评判标签的颜色只是基于 `total / outOf` 的简单阈值判断：当 `outOf` 为 `0` 时，`0` 会被视为：`0.75` 及以上为翠绿色，`0.5` 到低于 `0.75` 为琥珀色，低于 `0.5` 为红色。每项标准的进度条都以整体 `outOf` 为基准进行缩放，而不是以该标准自身的 `weight` 或任何单项标准的最大值为基准，因此，即使权重不同，具有相同 `score` 的两项标准也始终会绘制出相同宽度的进度条；`weight` 只会以分数旁边的 `×N` 标签形式显示。

## 示例

### 分母为空

`outOf: 0` 是组件会处理的真实边界情况，而不是直接进行除零运算：比率会显示为 `0`，因此无论 `total` 表示什么，评判标签始终会落入红色区间。

```tsx
<ScoreBreakdown
  verdict="not scored"
  total={0}
  outOf={0}
  criteria={[]}
  visibleCount={0}
/>
```

### 分数的来源

<RuntimeMode>

后端入口只声明待评审的内容。模型提供 `target`，你的服务器执行实际评分，而客户端渲染器看到的始终只有最终评判结果。

```ts title="app/api/chat/route.ts"
review_change: tool({
  description: "Grade a proposed change against a rubric.",
  inputSchema: z.object({ target: z.string() }),
  execute: async ({ target }) => gradeChange(target),
}),
```

</RuntimeMode>

<StandaloneMode>

当标准来自你自己的请求，而不是固定常量时，请获取一次这些标准，并重置展示数量，这样动画就会从头开始播放。

```tsx
async function loadReview(target: string) {
  const verdict = await gradeChange(target);
  setCriteria(verdict.criteria);
  setVisibleCount(0);
}
```

</StandaloneMode>

### 重新设置明细样式

两个轨道都会在根元素上接收 `className`。权重和分数标签使用来自 `surfaces.tsx` 的共享 `mono` 表面，因此重新设置该 token 的样式会同步更新所有使用它的元素。

```tsx
<ScoreBreakdown className="max-w-none gap-4" /* ... */ />
```

## API 参考

<RuntimeMode>

### 渲染属性

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `args` | `{ target: string }` | 工具的参数，用于说明待评审的内容。 |
| `result` | `{ verdict: string; total: number; outOf: number; criteria: ScoreCriterion[] } \| undefined` | 最终评判结果，在后端执行器完成解析前为 undefined。 |

### review_change 结果

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `verdict` | `string` | 显示在评判标签中的简短标签。 |
| `total` | `number` | 总分，显示为一位小数。 |
| `outOf` | `number` | 可能的最高分，也是每项标准的进度条所依据的分母。 |
| `criteria[].label` | `string` | 标准的名称。 |
| `criteria[].score` | `number` | 该标准自身的分数，显示为一位小数。 |
| `criteria[].weight` | `number` | 显示为 `×weight`，不会影响进度条宽度。 |
| `criteria[].note` | `string` | 进度条下方的可选说明文字。 |

</RuntimeMode>

<StandaloneMode>

### ScoreBreakdown

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `verdict` | `string` | 必填 | 显示在评判标签中的简短标签。 |
| `total` | `number` | 必填 | 总分，显示为一位小数。 |
| `outOf` | `number` | 必填 | 可能的最高分，也是每项标准的进度条所依据的分母。 |
| `criteria` | `readonly ScoreCriterion[]` | 必填 | 完整的标准列表，但只渲染前 `visibleCount` 项。 |
| `visibleCount` | `number` | 必填 | 要显示的标准数量，会向下取整并限制在 `0…criteria.length` 中。 |
| `className` | `string` | | 合并到根元素上。 |

其他所有 `div` 属性都会传递给根元素。

### ScoreCriterion

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `label` | `string` | 标准的名称。 |
| `score` | `number` | 该标准自身的分数，显示为一位小数。 |
| `weight` | `number` | 显示为 `×weight`，不会影响进度条宽度。 |
| `note` | `string` | 进度条下方的可选说明文字。 |

</StandaloneMode>
