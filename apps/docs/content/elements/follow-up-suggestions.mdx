---
title: "后续建议"
description: "由运行时生成的后续建议填充的提示词芯片。"
---

Follow-up suggestions 会将线程自身建议的下一步提示词渲染为最新回复下方的一行芯片，用户只需轻点一下即可发送。在运行时中，芯片来自运行时的 `suggestions`；不存在这一精确行布局的独立形式，因为它的核心用途就是跟随运行时自行生成的列表。它有两种设计：运行时变体会渲染一行可水平滚动、带渐隐遮罩的芯片；静态变体 `Suggestions` 则渲染交错排列的药丸按钮或列表（参见[纸张药丸设计](#the-paper-pill-design)）。

## 入门

<RuntimeMode>

`Thread` 已经在其视口页脚中渲染了此组件；只有在自行组合布局时，才需要直接使用它。

<Steps>
  <Step>

### 为运行时提供建议

任何基于 external-store adapter（外部状态存储适配器）构建的运行时，包括 `useExternalStoreRuntime` 和 AI SDK 集成，都接受静态的 `suggestions` 列表。

```tsx title="app/assistant.tsx" {6-9}
const runtime = useExternalStoreRuntime({
  messages,
  convertMessage,
  onNew: async (message) => {
    /* append the message in your store */
  },
  suggestions: [
    { prompt: "Summarize this as action items" },
    { prompt: "Write a shorter version" },
  ],
});
```

AI SDK 集成也可以生成此列表，而不是接收静态列表：将 `adapters: { suggestion: createSuggestionAdapter({ complete }) }` 传递给 `useAISDKRuntime`，它会在每次回复后根据最近的对话记录重新生成建议。

  </Step>
  <Step>

### 在消息之后渲染

将 `ThreadFollowupSuggestions` 放置在消息列表之后、输入框之前。

```tsx title="components/assistant-ui/elements/thread.aui.tsx"
import { ThreadPrimitive } from "@assistant-ui/react";
import { ThreadFollowupSuggestions } from "@/components/assistant-ui/elements/follow-up-suggestions.aui";

function ThreadViewportFooter() {
  return (
    <ThreadPrimitive.ViewportFooter>
      <ThreadFollowupSuggestions />
      <Composer />
    </ThreadPrimitive.ViewportFooter>
  );
}
```

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

单独使用时，没有运行时可以生成列表。此时应改用静态的 `Suggestions` 组件渲染自定义芯片行（参见[纸张药丸设计](#the-paper-pill-design)）。

</StandaloneMode>

## 组成

<RuntimeMode>

```tsx
<div> {/* horizontally scrolling, no visible scrollbar */}
  <button>{/* title (or prompt as fallback) */}<span>{/* label, when set */}</span></button>
  {/* one per suggestion */}
</div>
```

只有在线程不为空、当前未运行且至少有一条建议时，才会渲染整行内容。任一条件不满足时，整行都会隐藏，而不是显示为空。芯片始终保持在同一行；溢出时，该行可以水平滚动，并且每个被裁切的边缘都会渐隐，因此在实际滚动过去之前，起始边缘不会显示渐隐效果。

</RuntimeMode>

## 示例

<RuntimeMode>

### 标题、标签和提示词

设置后，芯片会显示 `title`；未设置时则回退到 `prompt`；`label` 会以末尾的弱化文本渲染。无论芯片显示的标题是否更短，实际发送的始终是完整的 `prompt`。

```tsx
suggestions: [
  { title: "Weather", label: "in SF", prompt: "What is the weather in San Francisco today?" },
  { prompt: "Summarize this" },
]
```

第一个芯片显示为“Weather”，末尾附带“in SF”，但发送的是完整的天气提示词；第二个芯片直接显示“Summarize this”，因为它没有 `title`。

### 建议的发送方式

每个芯片都会使用带有 `send` 的 `ThreadPrimitive.Suggestion`，因此点击芯片后会立即发送建议的提示词并清空输入框，无需确认。

</RuntimeMode>

## API 参考

<RuntimeMode>

`ThreadFollowupSuggestions` 不接受任何 props。

### 线程状态

| 选择器 | 类型 | 描述 |
|----------|------|-------------|
| `s.thread.suggestions` | `readonly ThreadSuggestion[]` | `{ prompt: string; title?: string; label?: string }[]`，来自运行时的 `suggestions` 选项。 |
| `s.thread.isEmpty` | `boolean` | 线程尚无消息时，该行会隐藏。 |
| `s.thread.isRunning` | `boolean` | 运行正在进行时，该行会隐藏。 |

### 组合的原语

| 部件 | 说明 |
|------|-------|
| `ThreadPrimitive.Suggestion` | 一个芯片。接受 `prompt` 和 `send`。 |

</RuntimeMode>

## 纸张药丸设计

Rail 中的 Static 变体是同一后续建议行的第二种设计：`Suggestions` 会根据你自行维护的纯字符串列表，渲染交错排列的圆角药丸按钮或左对齐列表，而不是由运行时自身的 `suggestions` 驱动的水平滚动行。它是一个由 props 驱动且不依赖运行时的单一组件：

```sh
npx shadcn@latest add "@assistant-ui/elements-suggestions"
```

<RuntimeMode>

运行时会将活动线程的后续建议记录为 `s.thread.suggestions`；`ThreadPrimitive.Suggestion` 会将其中一项转换为可点击的提示词。应对其进行样式设置以匹配纸张药丸的外观，而不是自行驱动 `Suggestions`，因为运行时建议会立即发送，并且该行会卸载，而不会保留选中状态：

```tsx title="components/assistant-ui/elements/suggestions.tsx"
"use client";

import { ThreadPrimitive, useAuiState } from "@assistant-ui/react";
import { cn } from "@/lib/utils";
import { paper } from "@/components/assistant-ui/elements/surfaces";

function SuggestionRow() {
  const suggestions = useAuiState((s) => s.thread.suggestions);

  return (
    <div className="flex max-w-md flex-wrap justify-center gap-2">
      {suggestions.map((suggestion, index) => (
        <ThreadPrimitive.Suggestion
          key={suggestion.prompt}
          prompt={suggestion.prompt}
          send
          className={cn(
            paper,
            "fade-in slide-in-from-bottom-2 animate-in fill-mode-both rounded-full px-4 py-2 text-[13px]",
          )}
          style={{ animationDelay: `${index * 70}ms` }}
        >
          {suggestion.title ?? suggestion.prompt}
        </ThreadPrimitive.Suggestion>
      ))}
    </div>
  );
}
```

`send` 会立即提交提示词；省略它则会将提示词载入输入框，供用户在发送前编辑（添加 `clearComposer={false}` 可将其追加到输入框中已有的内容，而不是替换已有内容）。

</RuntimeMode>

<StandaloneMode>

单独使用时，`Suggestions` 会渲染传入的列表，并报告用户按下了其中哪一项；发送和输入框状态均不是其内置功能。

```tsx title="app/next-turn.tsx"
"use client";

import { useState } from "react";
import { Suggestions } from "@/components/assistant-ui/elements/suggestions";

export function NextTurn() {
  const [cycle, setCycle] = useState(0);
  const [selected, setSelected] = useState<string | null>(null);
  const suggestions = ["Explain that differently", "Show an example", "What's next?"];

  return (
    <Suggestions
      suggestions={suggestions}
      selectedSuggestion={selected}
      cycle={cycle}
      onSuggestion={(suggestion) => {
        setSelected(suggestion);
        send(suggestion);
      }}
    />
  );
}
```

`cycle` 用作根元素的 React `key`；每当替换为新一批建议时，都应递增它，以重新播放渐隐和滑入动画。

</StandaloneMode>

每个按钮都会以 `index * 70ms` 的延迟渐隐并滑入，因此在 `list` 中，整行会从左到右或从上到下依次显示。与 `selectedSuggestion` 匹配的建议会反转为纯色的前景色-背景色填充，并持续保持该状态，直到 prop 发生变化；`aria-pressed` 也会反映相同的匹配状态；`variant="list"` 会让按钮以全宽堆叠、文本起始对齐，而不是将其排列为居中的药丸按钮行。

### 建议

| Prop | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `suggestions` | `readonly string[]` | 必填 | 要显示的提示词。 |
| `selectedSuggestion` | `string \| null` | 必填 | 要渲染为选中状态的建议（如果有）。 |
| `cycle` | `number` | 必填 | 用作根元素的 `key`；递增它可重新播放进入动画。 |
| `onSuggestion` | `(suggestion: string) => void` | 必填 | 使用按下的建议文本进行调用。 |
| `variant` | `"pills" \| "list"` | `"pills"` | 该行的布局。 |
| `className` | `string` | | 合并到根元素。 |

其他所有 `div` props 都会转发到根元素。
