---
title: "数字滚动器"
description: "计数实时更新时，数字滚动到位。"
---

数字滚动器会让每一位数字通过各自的短暂过渡动画滚动到位，而不是直接替换原有文本，因此变化中的计数呈现为动态效果，而非闪烁。在运行时（runtime）中，数值来自工具调用的结果；单独使用时，则可以直接传入数值。

## 快速开始

<RuntimeMode>

在运行时中，数字滚动器只需要一个数字和一个标签，因此它的渲染器是目录中最精简的渲染器之一：从工具调用中读取 `result`，在工具仍处于运行状态时回退为零。

<Steps>
  <Step>

### 渲染工具调用

```tsx title="components/assistant-ui/elements/token-count-tool-ui.tsx"
"use client";

import type { ToolCallMessagePartComponent } from "@assistant-ui/react";
import { NumberTicker } from "@/components/assistant-ui/elements/number-ticker";

export const TokenCountToolUI: ToolCallMessagePartComponent<
  Record<string, never>,
  { total: number }
> = ({ result, status }) => (
  <NumberTicker
    value={status.type === "complete" ? (result?.total ?? 0) : 0}
    label="tokens generated"
  />
);
```

  </Step>
  <Step>

### 注册工具

```tsx title="app/toolkit.ts"
import { defineToolkit } from "@assistant-ui/react";
import { z } from "zod";
import { TokenCountToolUI } from "@/components/assistant-ui/elements/token-count-tool-ui";

export const toolkit = defineToolkit({
  get_token_count: {
    type: "frontend",
    description: "Get the number of tokens generated so far this session.",
    parameters: z.object({}),
    execute: async () => ({ total: currentTokenCount() }),
    render: TokenCountToolUI,
  },
});
```

```tsx title="app/MyRuntimeProvider.tsx"
import { AssistantRuntimeProvider, AuiConfig, Tools } from "@assistant-ui/react";
import { useChatRuntime } from "@assistant-ui/ai-sdk";
import { toolkit } from "./toolkit";

export function MyRuntimeProvider({ children }: { children: React.ReactNode }) {
  const runtime = useChatRuntime();
  const config = AuiConfig({ tools: Tools({ toolkit }) });
  return (
    <AssistantRuntimeProvider runtime={runtime} config={config}>
      {children}
    </AssistantRuntimeProvider>
  );
}
```

有关后端定义的工具和审批闸门，请参阅 [Tool UI](/docs/tools/tool-ui)。

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

单独使用时，数字滚动器完全由你控制：无论 `value` 来自何处，只要它发生变化，组件就会重新渲染并滚动。

<Steps>
  <Step>

### 保存数值

```tsx title="app/token-count.tsx"
"use client";

import { useState } from "react";
import { NumberTicker } from "@/components/assistant-ui/elements/number-ticker";

export function TokenCount() {
  const [value, setValue] = useState(0);
  return <NumberTicker value={value} label="tokens generated" />;
}
```

  </Step>
  <Step>

### 随工作进展更新

任何会改变 `value` 的状态更新都会触发滚动，因此轮询或 socket 消息的工作方式完全相同。

```tsx
useEffect(() => {
  const id = setInterval(() => {
    setValue((v) => v + Math.round(Math.random() * 40));
  }, 900);
  return () => clearInterval(id);
}, []);
```

  </Step>
</Steps>

</StandaloneMode>

## 示例

### 格式化大数值

`value` 会先使用 `toLocaleString("en-US")` 进行格式化，然后再拆分为各个数字，因此千位分隔符会作为滚动数字之间的静态字符显示，而不是数字本身。屏幕阅读器会从行上的 `aria-label` 读取同一个格式化字符串，而不是解析单独的滚动 span。

```tsx
<NumberTicker value={1234567} label="tokens generated" />
// renders "1,234,567", with "," as plain characters between the rollers
```

### 重新设置数字滚动器样式

两个区域都会在根元素上接收 `className`；根元素是一个围绕数字及其标签的纵向 flex 容器。标签从 `surfaces.tsx` 中共享的 `mono` token 读取。

```tsx
<NumberTicker className="gap-1" /* ... */ />
```

## API 参考

<RuntimeMode>

### 工具调用渲染属性

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `args` | `TArgs` | 解析后的参数。模型仍在流式传输参数时，该值可能不完整。 |
| `argsText` | `string` | 模型流式传输的原始 JSON 参数文本。 |
| `result` | `TResult \| undefined` | 工具完成后返回的值。运行期间为 `undefined`。 |
| `status` | `ToolCallMessagePartStatus` | `status.type` 为 `"running"`、`"requires-action"`、`"complete"` 或 `"incomplete"`。 |
| `toolName` | `string` | 模型调用的工具名称。 |
| `toolCallId` | `string` | 此次调用的稳定 ID。 |
| `isError` | `boolean \| undefined` | `result` 是否表示工具执行错误。 |

将渲染器注册到工具包条目的 `render` 字段，并使用 `Tools({ toolkit })` 附加工具包。有关完整的渲染属性接口（包括 `addResult`、人工工具和审批闸门），请参阅 [Tool UI](/docs/tools/tool-ui)。

</RuntimeMode>

<StandaloneMode>

### NumberTicker

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `value` | `number` | 必填 | 要显示的数字，会使用 `toLocaleString("en-US")` 格式化，并拆分为滚动数字。 |
| `label` | `string` | 必填 | 显示在数字下方的说明文字。 |
| `className` | `string` | | 合并到根元素上。 |

其他所有 `div` 属性都会转发到根元素。

</StandaloneMode>
