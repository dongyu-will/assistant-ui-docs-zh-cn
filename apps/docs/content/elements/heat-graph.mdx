title: "热力图"
description: "带有月份标签、星期标签、图例和工具提示的活动热力图。"
---

HeatGraph 绘制 GitHub 风格的活动日历：每天一个单元格，根据计数着色，并显示月份和星期标签、图例以及悬停工具提示。assistant-ui 的运行时没有每日活动计数这一概念，线程自身的消息列表也不会在任何地方按日期分桶，因此该元素只有一种独立形式：传入带计数的日期。

## 快速开始

<Steps>
  <Step>

### 传入带计数的日期

```tsx title="app/activity.tsx"
import { HeatGraph } from "@/components/assistant-ui/elements/heat-graph";

const data = [
  { date: "2026-01-01", count: 3 },
  { date: "2026-01-02", count: 0 },
  { date: new Date(2026, 0, 3), count: 7 },
];

export function Activity() {
  return <HeatGraph data={data} />;
}
```

`date` 接受 ISO 字符串或 `Date`；`count` 则是你所度量的任意单位。组件会自动将计数归入五个颜色级别之一。

  </Step>
  <Step>

### 可见窗口始终是最近一年

`HeatGraph` 从不暴露 `start` 或 `end`，也就是底层原语用于设置日期范围的选项，因此网格始终覆盖截至今天的 365 天。日期范围会在每次渲染时重新计算，并向前对齐到所在周的开始日期。超出该窗口的 `data` 数据点（过于久远或位于未来）会被静默地从网格中省略，而不会显示或报告错误。如果你需要固定窗口或其他时间窗口，请自行组合这些原语；请参阅下方的[直接编辑组合](#editing-the-composition-directly)。

  </Step>
</Steps>

## 组成

```tsx
<div>
  <div>{/* month abbreviations, positioned over the grid's columns */}</div>
  <div>
    <div>{/* weekday abbreviations, every other row */}</div>
    <div>{/* the cell grid, one column per week */}</div>
  </div>
  <div>{/* "Less" ... five legend swatches ... "More" */}</div>
  <div>{/* hover tooltip: count and date */}</div>
</div>
```

`HeatGraph` 只接受 `data`。它没有 `className` prop，根元素上也没有 `data-slot` 标记；这两点都不同于目录中的其他组件，因此从外部进行重新样式化时，唯一可用的钩子是包裹它的 `<div>`。每周从星期一开始，五级蓝色比例由此文件固定，无法通过 prop 配置；该比例由五个普通十六进制颜色值组成，也没有单独的深色模式变体。星期标签显示在交替的行上，而不是每一行都显示，以避免在紧凑网格中挤入六个行高的标签。图例始终显示恰好五个色块，每个颜色级别对应一个，并以“Less”和“More”括住。悬停或聚焦单元格时，会显示内容为 `"{count} contributions on {date}"` 的工具提示，其中日期会完整显示月份、日期和年份。

## 示例

### 直接编辑组合

由于没有对应的 prop，要更改颜色比例、每周起始日，或硬编码的灰色和白色 Tailwind 类，需要直接编辑 `heat-graph.tsx`，而不是传入类名。该文件只是对 `heat-graph` 包自身原语的薄层组合：`Root`、`MonthLabels`、`DayLabels`、带有 `Cell` 的 `Grid`、带有 `LegendLevel` 的 `Legend`，以及 `Tooltip`。在 `Root` 上替换 `colorScale` 或 `weekStart`，或者移除某个子部分（例如图例），即可更改渲染内容。

```tsx
<HeatGraphPrimitive.Root data={data} weekStart="sunday" colorScale={["#eee", "#0a5"]}>
  {/* your own MonthLabels / DayLabels / Grid / Legend, or a subset of them */}
</HeatGraphPrimitive.Root>
```

### 目录中其他位置的第二种组合

`activity-graph` 基于同一个 `heat-graph` 包的原语独立构建自己的日历，使用共享的 `paper` 和 `mono` 表面设计令牌、`className` prop，以及支持深色模式的色调比例，而不是包装此文件的 `HeatGraph`。如果你需要可重新样式化的日历，请从[活动图](/elements/activity-graph)或直接从原始的 `heat-graph` 原语开始，而不要派生这个固定版本。

## API 参考

### HeatGraph

| Prop | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `data` | `readonly DataPoint[]` | 必填 | 每个有计数的日期对应一个条目。数组中缺失的日期会以最低颜色级别渲染。 |

`DataPoint` 是 `{ date: string | Date; count: number }`，来自该元素所包装的 `heat-graph` 包。
