活动图是一个由单元格组成的日历，工作越多的日期颜色越深。它在 `heat-graph` 包的网格基础上，增加了标题、总数以及自身的五级颜色深浅刻度。在运行时中，每天的计数来自工具的结果；单独使用时，则直接传入相同的数据。

## 快速开始

<RuntimeMode>

在运行时中，`data` 的形状正是工具会返回的形状：在某个时间范围内每天一个计数。注册一个报告这些数据的工具后，活动图无需其他配置。

  <Step>

### 渲染工具调用

```tsx title="components/assistant-ui/elements/run-activity-tool-ui.tsx"
"use client";

import type { ToolCallMessagePartComponent } from "@assistant-ui/react";
import type { DataPoint } from "heat-graph";
import { ActivityGraph } from "@/components/assistant-ui/elements/activity-graph";

type ActivityArgs = { days: number };
type ActivityResult = {
  title: string;
  total: string;
  start: string;
  end: string;
  data: DataPoint[];
};

export const RunActivityToolUI: ToolCallMessagePartComponent<
  ActivityArgs,
  ActivityResult
> = ({ result }) => {
  if (!result) return null;
  return (
    <ActivityGraph
      data={result.data}
      start={result.start}
      end={result.end}
      title={result.title}
      total={result.total}
    />
  );
};
```

  </Step>
  <Step>

### 注册工具

```tsx title="app/toolkit.ts"
import { defineToolkit } from "@assistant-ui/react";
import { z } from "zod";
import { RunActivityToolUI } from "@/components/assistant-ui/elements/run-activity-tool-ui";

export const toolkit = defineToolkit({
  get_run_activity: {
    type: "frontend",
    description: "Get daily run counts for the last N days as a heat map.",
    parameters: z.object({ days: z.number() }),
    execute: async ({ days }) => fetchRunActivity(days),
    render: RunActivityToolUI,
  },
});
```

```tsx title="app/MyRuntimeProvider.tsx"
import { AssistantRuntimeProvider, AuiConfig, Tools } from "@assistant-ui/react";
import { useChatRuntime } from "@assistant-ui/ai-sdk";
import { toolkit } from "./toolkit";

export function MyRuntimeProvider({ children }: { children: React.ReactNode }) {
  const runtime = useChatRuntime();
  const config = AuiConfig({ tools: Tools({ toolkit }) });
  return (
    <AssistantRuntimeProvider runtime={runtime} config={config}>
      {children}
    </AssistantRuntimeProvider>
  );
}
```

单独使用时，需要自行保存相同的 `data`、`start` 和 `end`；该元素负责网格布局、颜色深浅处理和图例。

<Steps>

### 保存数据

```tsx title="app/agent-activity.tsx"
"use client";

import type { DataPoint } from "heat-graph";
import { ActivityGraph } from "@/components/assistant-ui/elements/activity-graph";

const START = new Date(2026, 1, 2);
const DAYS = 182;
const dayAfterStart = (offset: number) =>
  new Date(START.getFullYear(), START.getMonth(), START.getDate() + offset);
const END = dayAfterStart(DAYS - 1);

const DATA: readonly DataPoint[] = Array.from({ length: DAYS }, (_, i) => ({
  date: dayAfterStart(i),
  count: Math.round(Math.random() * 12),
}));

const TOTAL = DATA.reduce((sum, point) => sum + point.count, 0);

export function AgentActivity() {
  return (
    <ActivityGraph
      data={DATA}
      start={START}
      end={END}
      title="Agent runs"
      total={`${TOTAL.toLocaleString("en-US")} in 6 months`}
    />
  );
}
```

  </Step>
  <Step>

### 刷新时间范围

该元素内部不会实时更新：每当时间范围发生变化时，调整 `start` 和 `end`，并将重新计算的 `data` 数组传给它。

```tsx
const [days, setDays] = useState(182);
const start = daysAgo(days);
const end = new Date();
const data = useRunHistory(start, end);
```

## 组成

```tsx
<div data-slot="activity-graph">
  <div>{/* title, total */}</div>
  {/* HeatGraph.Root: day labels down the left, a grid of cells, a less-to-more legend */}
</div>
```

每个单元格的颜色深浅来自 `heat-graph` 自身针对该 `DataPoint` 的 `level` 分类（0 到 4），并在此映射为五级蓝色色阶；超出该范围的级别会回退到最浅的颜色。日期标签只显示在奇数网格行中，每隔一周显示一个，这样左侧边缘不会过于拥挤。每周始终从星期一开始；此选择由该元素固定，不作为 prop 暴露。

## 示例

### 选择日期范围

`start` 和 `end` 界定网格范围；`heat-graph` 会根据 `data` 填充两者之间的每一天，包括没有匹配数据点的日期，这些日期会以最低级别的颜色显示。

```tsx
<ActivityGraph data={data} start={sixMonthsAgo} end={today} title="Agent runs" total={total} />
```

### 重新设置活动图样式

两条轨道都会在根元素上接收 `className`。标题显示为纯文本，总数则读取 `surfaces.tsx` 中共享的 `mono` token。颜色深浅刻度本身是 `activity-graph.tsx` 内的固定数组，因此要重新设置单元格颜色，需要直接编辑该文件。

```tsx
<ActivityGraph className="max-w-none" /* ... */ />
```

## API 参考

<RuntimeMode>

### 工具调用渲染 props

| Prop | 类型 | 描述 |
|------|------|-------------|
| `args` | `TArgs` | 解析后的参数。模型仍在流式传输参数时，该值可能不完整。 |
| `argsText` | `string` | 模型流式传输的原始 JSON 参数文本。 |
| `result` | `TResult \| undefined` | 工具完成后的返回值。运行时为 `undefined`。 |
| `status` | `ToolCallMessagePartStatus` | `status.type` 为 `"running"`、`"requires-action"`、`"complete"` 或 `"incomplete"`。 |
| `toolName` | `string` | 模型调用的工具名称。 |
| `toolCallId` | `string` | 此次调用的稳定 ID。 |
| `isError` | `boolean \| undefined` | `result` 是否表示工具执行错误。 |

在工具包条目的 `render` 字段上注册渲染器，并使用 `Tools({ toolkit })` 附加工具包。有关完整的渲染 props 接口（包括 `addResult`、人工工具和审批关卡），请参阅[工具 UI](/docs/tools/tool-ui)。

</RuntimeMode>

<StandaloneMode>

### ActivityGraph

| Prop | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `data` | `readonly DataPoint[]` | 必填 | 每天一个计数。 |
| `start` | `string \| Date` | 必填 | 绘制时间范围的开始日期。 |
| `end` | `string \| Date` | 必填 | 绘制时间范围的结束日期。 |
| `title` | `string` | 必填 | 网格上方的标题。 |
| `total` | `string` | 必填 | 已格式化的摘要文本，显示在标题对面。 |
| `className` | `string` | | 合并到根元素上。 |

来自 `heat-graph` 包的 `DataPoint` 是 `{ date: string | Date; count: number }`。所有其他 `div` props 都会转发到根元素。

</StandaloneMode>
