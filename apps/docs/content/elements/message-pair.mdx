---
title: "消息对"
description: "一个用户气泡和一条流式助手回复，操作会在悬停时显示。"
---

消息对是一次对话轮次：你发送的消息，以及显示在下方的回复；复制和重新生成操作会一直隐藏，直到你将鼠标悬停其上。`bubble` 会将发送的消息包裹在填充样式的圆角气泡中；`flat` 则将其显示为没有容器的右对齐纯文本。在运行时中，这一对由线程驱动的组合消息构成；单独使用时，则需要传入发送的文本和要显示的词语。

## 快速开始

<RuntimeMode>

线程会渲染为消息列表，每条消息分别来自用户或助手。为每条消息使用 `MessagePrimitive.Root` 组合消息对，并添加一个仅在悬停时显示的操作行。

<Steps>
  <Step>

### 组合消息对

`ThreadPrimitive.Messages` 会遍历线程；根据 `s.message.role` 分支，选择要渲染消息对中的哪一部分。

```tsx title="components/assistant-ui/elements/message-pair.tsx"
"use client";

import { MessagePrimitive, ThreadPrimitive, useAuiState } from "@assistant-ui/react";
import { cn } from "@/lib/utils";
import { paper } from "@/components/assistant-ui/elements/surfaces";

export function Turn() {
  return <ThreadPrimitive.Messages>{() => <TurnMessage />}</ThreadPrimitive.Messages>;
}

function TurnMessage() {
  const role = useAuiState((s) => s.message.role);
  return (
    <MessagePrimitive.Root className="flex w-full flex-col gap-5">
      {role === "user" ? (
        <div className={cn(paper, "max-w-[85%] self-end rounded-2xl px-3.5 py-2 text-sm")}>
          <MessagePrimitive.Parts />
        </div>
      ) : (
        <AssistantReply />
      )}
    </MessagePrimitive.Root>
  );
}
```

  </Step>
  <Step>

### 在悬停时显示操作

在 `ActionBarPrimitive.Root` 中使用 `autohide="always"` 包裹操作行：在 `s.message.isHovering` 变为 true 之前，它不会渲染任何内容；`MessagePrimitive.Root` 已经会根据指针进入和离开跟踪这一状态。

```tsx
import { ActionBarPrimitive } from "@assistant-ui/react";
import { CopyIcon, RefreshCwIcon } from "lucide-react";
import { ghostButton } from "@/components/assistant-ui/elements/surfaces";

function AssistantReply() {
  return (
    <div className="group/message flex flex-col items-start">
      <div className="min-h-[4.25rem] text-sm leading-relaxed">
        <MessagePrimitive.Parts />
      </div>
      <ActionBarPrimitive.Root autohide="always" className="flex items-center gap-1 pt-1">
        <ActionBarPrimitive.Copy aria-label="Copy response" className={cn(ghostButton, "size-7")}>
          <CopyIcon className="size-3.5" />
        </ActionBarPrimitive.Copy>
        <ActionBarPrimitive.Reload aria-label="Regenerate response" className={cn(ghostButton, "size-7")}>
          <RefreshCwIcon className="size-3.5" />
        </ActionBarPrimitive.Reload>
      </ActionBarPrimitive.Root>
    </div>
  );
}
```

`Thread` 元素已经提供了一个与此高度相似的用户消息和助手消息组合，不过它的操作行使用 `autohide="not-last"`（旧回复在悬停时显示，最新回复始终显示），而不是这里建模的严格仅悬停显示行为；安装 `@assistant-ui/thread` 即可使用完整且功能更丰富的版本。

  </Step>
</Steps>

<StandaloneMode>

单独使用时，消息对是一种受控显示效果：你保存完整的词语列表以及当前已显示的词语数量，而元素负责淡入效果和末尾光标。

<Steps>
  <Step>

### 驱动显示效果

```tsx title="app/turn.tsx"
"use client";

import { useEffect, useState } from "react";
import { MessagePair } from "@/components/assistant-ui/elements/message-pair";

const reply = "Paris is the capital of France.".split(" ");

export function Turn() {
  const [visibleWords, setVisibleWords] = useState(0);
  const streaming = visibleWords < reply.length;

  useEffect(() => {
    if (!streaming) return;
    const id = setInterval(() => setVisibleWords((n) => n + 1), 120);
    return () => clearInterval(id);
  }, [streaming]);

  return (
    <MessagePair
      userMessage="What's the capital of France?"
      words={reply}
      visibleWords={visibleWords}
      streaming={streaming}
    />
  );
}
```

  </Step>
  <Step>

### 处理悬停操作

`MessagePair` 会渲染复制和重新生成按钮，但具体行为由你负责；在渲染元素的位置绑定 `onClick` 处理函数，或者通过 `[data-slot="message-pair"] button` 从外部访问它们。

  </Step>
</Steps>

</StandaloneMode>

## 结构

```tsx
<div data-slot="message-pair">
  <p>{/* the sent message */}</p>
  <div>
    <p>{/* the reply, word by word */}</p>
    <div>{/* copy, regenerate, hidden until hover or focus */}</div>
  </div>
</div>
```

在回复所属的组中的任意位置悬停或聚焦时，操作行会通过 `opacity-0` 显示到 `opacity-100`；每个词都会单独淡入，最新的两个词会在 `streaming` 为 true 时显示为蓝色，然后在 700ms 内逐渐变为墨色。流式传输期间，末尾光标会在最后一个词后闪烁；当 `streaming` 为 false 或尚未显示任何内容时，光标会消失。单独使用时，这一显示效果由 `visibleWords` 追赶 `words.length` 驱动，是一种适用于演示和回放的受控打字机效果。运行时则只会随着文本流式传入渲染累积的文本：无需管理单独的显示数量，并且默认的 `Text` 部分渲染器会通过 `MessagePartPrimitive.InProgress` 在末尾显示一个“●”，而不是显示彩色的末尾边缘，因此逐词蓝色着色是此设计特有的效果。

## 示例

### 气泡或扁平样式

<RuntimeMode>

运行时没有 `variant` prop；在你于“组合消息对”中组合的气泡上切换同样的两个 class：

```tsx
<div
  className={
    role === "user"
      ? "text-foreground/90 self-end text-end text-sm"
      : cn(paper, "max-w-[85%] self-end rounded-2xl px-3.5 py-2 text-sm")
  }
>
```

</RuntimeMode>

<StandaloneMode>

`variant="flat"` 会移除圆角气泡，并将发送的消息右对齐为纯文本，从而实现更紧凑的布局。

```tsx
<MessagePair variant="flat" userMessage="..." words={words} visibleWords={n} streaming={false} />
```

</StandaloneMode>

### 回复的来源

<RuntimeMode>

助手仍在流式传输时，`s.message.status?.type` 为 `"running"`；完成后则为 `"complete"`。对于依赖“这条消息是否仍在传入”的任何 UI，都应直接使用它，而不是使用本地的 `streaming` 标志。

```tsx
const streaming = useAuiState((s) => s.message.status?.type === "running");
```

</RuntimeMode>

<StandaloneMode>

当 `visibleWords` 到达 `words.length` 的瞬间，流式传输就会结束；追加一个新词并递增计数器即可让流式传输继续，或者在来源完成后设置 `streaming={false}`。

</StandaloneMode>

### 重新设置消息对样式

两个区域的根元素都使用 `className`，而来自 `surfaces.tsx` 的共享 `paper` 和 `ghostButton` token 会为所有使用它们的气泡和操作按钮设置样式。

```tsx
<MessagePair className="max-w-none gap-3" /* ... */ />
```

## API 参考

<RuntimeMode>

### 消息部分

| 部分 | 渲染内容 | 说明 |
|------|---------|-------|
| `MessagePrimitive.Root` | `div` | 跟踪操作行的悬停状态；每条消息都应包裹在其中。 |
| `MessagePrimitive.Parts` | fragment | 渲染消息内容，包括流式文本。 |
| `ActionBarPrimitive.Root` | `div` | `autohide="always"` 会一直隐藏，直到 `message.isHovering` 为 true。 |
| `ActionBarPrimitive.Copy` | `button` | 尚无可复制内容时处于禁用状态。 |
| `ActionBarPrimitive.Reload` | `button` | 线程正在运行或消息并非来自助手时处于禁用状态。 |

### 消息状态

| 选择器 | 类型 | 描述 |
|----------|------|-------------|
| `s.message.role` | `"user" \| "assistant" \| "system"` | 此消息属于消息对中的哪一部分。 |
| `s.message.status?.type` | `"running" \| "complete" \| "incomplete" \| "requires-action"` | 存在于助手消息上；仍在流式传输时为 `"running"`。 |
| `s.message.isHovering` | `boolean` | 由 `MessagePrimitive.Root` 根据指针进入和离开进行设置。 |
| `aui.message.reload()` | `(config?) => void` | 将此助手消息重新生成为新的同级分支。 |

</RuntimeMode>

<StandaloneMode>

### MessagePair

| Prop | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `userMessage` | `string` | required | 发送的消息，以气泡或扁平文本行显示。 |
| `words` | `readonly string[]` | required | 完整的回复，已拆分为词语。 |
| `visibleWords` | `number` | required | 从 `words` 开始显示的词语数量。 |
| `streaming` | `boolean` | required | 为最新词语着色，并在为 true 时显示末尾光标。 |
| `variant` | `"bubble" \| "flat"` | `"bubble"` | 发送的消息的呈现方式。 |
| `className` | `string` | | 合并到根元素上。 |

其他所有 `div` props 都会转发到根元素。

</StandaloneMode>
