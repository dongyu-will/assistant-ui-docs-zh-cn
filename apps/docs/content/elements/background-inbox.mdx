后台收件箱会列出你移开视线后仍在继续的工作：仍在运行，或已经完成并等待打开的工作。使用运行时时，行项目来自你自己的线程列表；独立使用时，则由你自行持有这个数组。

## 入门

<RuntimeMode>

每个 assistant-ui 线程都可以在你切换离开后继续运行。线程列表已经记录了哪些线程仍处于活动状态，因此收件箱只是对这些状态的小型投影，而不是一个独立的子系统。

<Steps>
  <Step>

### 根据线程状态构建运行列表

```tsx title="components/assistant-ui/elements/running-elsewhere.tsx"
"use client";

import { useAui, useAuiState } from "@assistant-ui/react";
import type { BackgroundRun } from "@/components/assistant-ui/elements/background-inbox";

function formatElapsed(date: Date | undefined) {
  if (!date) return "";
  const minutes = Math.round((Date.now() - date.getTime()) / 60000);
  return minutes < 1 ? "just now" : minutes < 60 ? `${minutes}m` : `${Math.round(minutes / 60)}h`;
}

function useBackgroundRuns(): BackgroundRun[] {
  const aui = useAui();
  const threadIds = useAuiState((s) => s.threads.threadIds);

  return threadIds.map((_, index) => {
    const item = aui.threads.item({ index }).getState();
    return {
      id: item.id,
      title: item.title ?? "Untitled",
      state: item.isRunning ? "running" : "ready",
      elapsed: formatElapsed(item.lastMessageAt),
    };
  });
}
```

  </Step>
  <Step>

### 渲染列表，并将收集操作连接到线程切换

```tsx
import { BackgroundInbox } from "@/components/assistant-ui/elements/background-inbox";

export function RunningElsewhere() {
  const aui = useAui();
  const runs = useBackgroundRuns();

  return (
    <BackgroundInbox
      runs={runs}
      onCollect={(id) => aui.threads.item({ id }).switchTo()}
    />
  );
}
```

`ThreadListItemState.isRunning` 只能告诉你某次运行是否仍在进行，因此此映射最多只能生成 `"running"` 或 `"ready"`。它无法提供运行因错误结束的信号，因此 `"failed"` 行需要在线程列表之上自行维护状态。

  </Step>
</Steps>

</RuntimeMode>

独立使用时，该元素完全受控：你持有运行列表数组，并在应用的其他位置更新运行状态时同步更新其中的条目。

<Steps>
  <Step>

### 持有运行列表

```tsx title="app/inbox.tsx"
"use client";

import { useState } from "react";
import { BackgroundInbox, type BackgroundRun } from "@/components/assistant-ui/elements/background-inbox";

const initialRuns: BackgroundRun[] = [
  { id: "1", title: "Refactor auth module", state: "running", elapsed: "2m" },
  { id: "2", title: "Nightly report", state: "ready", elapsed: "14m", summary: "3 files changed" },
];

export function Inbox() {
  const [runs, setRuns] = useState(initialRuns);
  return <BackgroundInbox runs={runs} onCollect={(id) => openRun(id)} />;
}
```

  </Step>
  <Step>

### 运行结束时更新运行状态

```tsx
function settle(id: string, ok: boolean) {
  setRuns((prev) =>
    prev.map((run) =>
      run.id === id ? { ...run, state: ok ? "ready" : "failed" } : run,
    ),
  );
}
```

  </Step>
</Steps>

</StandaloneMode>

## 结构

```tsx
<div data-slot="background-inbox">
  <div>
    <span>Running elsewhere</span>
    <span>{/* "{ready} ready" or "{running} in flight" */}</span>
  </div>
  <button>
    {/* one per run */}
    <span>{/* spinner, check, or x */}</span>
    <span>{/* title */}</span>
    <span>{/* summary, when present */}</span>
    <span>{/* elapsed */}</span>
  </button>
</div>
```

标题摘要只统计 `ready` 和 `running` 行：只要至少有一次运行准备就绪，就显示 `"{ready} ready"`；否则显示 `"{running} in flight"`。`failed` 运行不会计入其中任何一个数字，因此只包含失败运行的收件箱会显示 `"0 in flight"`。每一行都是一个按钮：在 `running` 时处于禁用状态且不可点击；对于 `ready` 和 `failed` 都可以点击（因此失败的运行仍然可以打开，而不只是被关闭）。`summary` 对每一行都是可选的，仅在存在时渲染。`runs` 数组为空时，标题仍会显示 `"0 in flight"`，但后面不会有任何行；不会显示占位消息。

## 示例

### 全部三种状态

```tsx
<BackgroundInbox
  runs={[
    { id: "1", title: "Refactor auth module", state: "running", elapsed: "2m" },
    { id: "2", title: "Nightly report", state: "ready", elapsed: "14m", summary: "3 files changed" },
    { id: "3", title: "Migrate schema", state: "failed", elapsed: "1h" },
  ]}
/>
```

### 收集到已归档线程

<RuntimeMode>

`switchTo` 接受 `{ unarchive: true }`，因此在已归档线程上完成的后台运行仍然可以被收集，而无需单独执行取消归档步骤：

```tsx
onCollect={(id) => aui.threads.item({ id }).switchTo({ unarchive: true })}
```

</RuntimeMode>

### 重新设置收件箱样式

根元素使用共享的 `paper` 表面；摘要计数、每次运行的摘要和经过时间使用 `mono`。

```tsx
<BackgroundInbox className="max-w-md rounded-3xl" runs={runs} onCollect={onCollect} />
```

## API 参考

<RuntimeMode>

### 线程列表状态

| 选择器 | 类型 | 描述 |
|----------|------|-------------|
| `s.threads.threadIds` | `readonly string[]` | 所有开放（未归档）线程的 ID。 |
| `aui.threads.item({ index }).getState()` | `ThreadListItemState` | 对应索引处线程的完整状态，包括 `title`、`lastMessageAt` 和 `isRunning`。 |
| `.isRunning` | `boolean` | 该线程是否有正在进行的运行，包括在你切换离开后仍继续运行的情况。 |

### 客户端调用

| 调用 | 描述 |
|------|-------------|
| `aui.threads.item({ id }).switchTo(options?)` | 将该线程设为活动线程。`{ unarchive: true }` 还会取消归档该线程。 |

</RuntimeMode>

<StandaloneMode>

### BackgroundInbox

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `runs` | `readonly BackgroundRun[]` | 必填 | 要按顺序渲染的行。 |
| `onCollect` | `(id: string) => void` | | 点击 `ready` 或 `failed` 行时调用。对于 `running` 行不会调用。 |
| `className` | `string` | | 合并到根元素上。 |

### BackgroundRun

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `id` | `string` | 行的键，会传回 `onCollect`。 |
| `title` | `string` | 截断后的行标签。 |
| `state` | `"running" \| "ready" \| "failed"` | 决定图标以及该行是否可点击。 |
| `elapsed` | `string` | 右对齐的时间标签；格式由你自行决定。 |
| `summary` | `string` | 可选的第二行文本，显示在标题下方。 |

其他所有 `div` 属性都会转发到根元素。

</StandaloneMode>
