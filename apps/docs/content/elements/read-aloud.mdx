---
title: "朗读"
description: "播放答案，随着朗读进行高亮当前文字，并可随时调节速度。"
---

朗读会播放消息内容，同时高亮当前朗读的文字，并提供进度条和速度控制。在运行时模式下，它使用 assistant-ui 的 speech adapter（语音适配器）获取粗粒度的播放状态；独立使用时，所有数字、词语索引、已用时间和速率都由你提供。

## 快速开始

<RuntimeMode>

assistant-ui 中的文本转语音功能，是运行时上的 speech adapter（语音适配器），以及正在朗读的消息上的粗粒度 `status`；运行时状态本身没有词语级边界或已用时间字段，因此该元素展示的细节——当前高亮的词语、相对于总时长的已用时间以及可调节的速率——需要由你的适配器或应用在此基础上提供。运行时的这部分功能仍处于实验阶段，未来可能发生变化。

<Steps>
  <Step>

### 配置 speech adapter

```tsx title="app/layout.tsx"
"use client";

import { WebSpeechSynthesisAdapter } from "@assistant-ui/react";
import { useChatRuntime } from "@assistant-ui/ai-sdk";

const runtime = useChatRuntime({
  adapters: { speech: new WebSpeechSynthesisAdapter() },
});
```

`speech` 是运行时的可选适配器之一，与附件等功能并列，所有运行时 hook 都以相同方式接受它。

  </Step>
  <Step>

### 从消息中开始和停止

将其渲染在消息内部或消息的操作行中，与复制和重新生成按钮并列，这样 `aui.message` 和 `s.message.speech` 就会解析到该消息：

```tsx
import { useAui, useAuiState } from "@assistant-ui/react";
import { ReadAloud } from "./read-aloud";

function Playback() {
  const aui = useAui();
  const speech = useAuiState((s) => s.message.speech);
  const playing = speech?.status.type === "running" || speech?.status.type === "starting";

  return (
    <ReadAloud
      words={[]}
      spokenIndex={0}
      playing={playing}
      rate={1}
      elapsed="0:00"
      duration="0:00"
      onToggle={() => (playing ? aui.message.stopSpeaking() : aui.message.speak())}
    />
  );
}
```

在对该消息调用 `speak()` 之前，`s.message.speech` 为 `undefined`；当 `status.type` 达到 `"ended"` 后，它会再次清除；其中不包含词语索引、已用时间或速率。这三个 prop 在这里仍是占位值，直到你的应用自行跟踪它们。如果你直接驱动 `WebSpeechSynthesisAdapter`，而不是通过 `speak()` 驱动，通常可以使用浏览器自身的 utterance（朗读事件）边界事件和结束事件来跟踪。

  </Step>
</Steps>

</RuntimeMode>

独立使用时，`ReadAloud` 是一个纯粹的显示组件：向它提供文字、当前正在朗读的词语索引以及传输状态，它就会渲染高亮和进度条。

### 从 utterance 驱动

```tsx title="app/playback.tsx"
"use client";

import { useState } from "react";
import { ReadAloud } from "@/components/assistant-ui/elements/read-aloud";

const words = "Paris is the capital of France.".split(" ");

export function Playback() {
  const [spokenIndex, setSpokenIndex] = useState(0);
  const [playing, setPlaying] = useState(false);
  const [rate, setRate] = useState(1);

  return (
    <ReadAloud
      words={words}
      spokenIndex={spokenIndex}
      playing={playing}
      rate={rate}
      elapsed="0:02"
      duration="0:05"
      onToggle={() => setPlaying((p) => !p)}
      onRateChange={() => setRate((r) => (r >= 2 ? 1 : r + 0.25))}
    />
  );
}
```

  </Step>
  <Step>

### 推进词语索引

如果你使用浏览器原生的语音合成，它的 utterance 会为每个词语触发一个带有字符偏移量的边界事件；将该偏移量映射回词语索引，就可以随着播放继续推进高亮位置。

  </Step>
</Steps>

</StandaloneMode>

## 组成结构

```tsx
<div data-slot="read-aloud">
  <p>{/* words, the spoken one highlighted */}</p>
  <div>
    <button aria-label="Play" />
    <span>{/* progress bar, width = spokenIndex / words.length */}</span>
    <span>{/* elapsed / duration */}</span>
    <button>{/* rate, e.g. 1x */}</button>
  </div>
</div>
```

进度完全由 `spokenIndex` 除以 `words.length` 计算得出，不存在单独的 progress prop，因此进度条和高亮词语始终保持一致。`spokenIndex` 之前的词语会变暗，当前词语会获得高亮背景，其余词语保持完全不透明，因此整个句子中的三种状态都仅由 `spokenIndex` 决定。

## 示例

### 速率控制

```tsx
<ReadAloud
  words={words}
  spokenIndex={2}
  playing
  rate={1.5}
  elapsed="0:03"
  duration="0:08"
  onRateChange={() => cycleRate()}
/>
```

`rate` 是一个显示值；`ReadAloud` 不会对其进行限制或格式化，而 `onRateChange` 不接受参数，因此由你负责在固定的速率列表（例如 `1, 1.25, 1.5, 2`）中循环切换。

### 开始播放前

<StandaloneMode>

在 `spokenIndex={0}` 且使用 `playing={false}` 时，整个句子会以完全不透明的状态渲染，但第一个词语仍会获得高亮背景；同时将 `elapsed` 保持为 `"0:00"`，即可让进度条从 0% 开始。

</StandaloneMode>

<RuntimeMode>

在调用 `speak()` 之前，`s.message.speech` 为 `undefined`；根据它推导 `playing={false}`。由于还没有任何内容流式传输了边界事件，因此此时还没有正在朗读的词语。

</RuntimeMode>

## API 参考

<RuntimeMode>

### 消息方法和状态

| 成员 | 类型 | 描述 |
|--------|------|-------------|
| `aui.message.speak()` | `() => void` | 开始朗读当前消息。实验性功能。 |
| `aui.message.stopSpeaking()` | `() => void` | 停止朗读。实验性功能。 |
| `s.message.speech` | `{ messageId: string; status } \| undefined` | `status.type` 为 `"starting"`、`"running"` 或 `"ended"`。不包含词语索引、已用时间或速率。实验性功能。 |

</RuntimeMode>

<StandaloneMode>

### ReadAloud

| Prop | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `words` | `readonly string[]` | 必填 | 按你希望高亮的方式拆分；渲染时会使用空格连接。 |
| `spokenIndex` | `number` | 必填 | 当前高亮词语的索引；同时驱动进度条。 |
| `playing` | `boolean` | 必填 | 在播放和暂停图标之间切换。 |
| `rate` | `number` | 必填 | 显示为 `${rate}x`；纯粹是显示值。 |
| `elapsed` | `string` | 必填 | 已完成格式化，例如 `"0:42"`。 |
| `duration` | `string` | 必填 | 已完成格式化。 |
| `onToggle` | `() => void` | | 由播放和暂停按钮调用。 |
| `onRateChange` | `() => void` | | 由速率按钮调用；不接受参数。 |
| `className` | `string` | | 合并到根元素上。 |

其他所有 `div` props 都会转发到根元素。

</StandaloneMode>
