这是一个可搜索的已保存提示词列表。在你确认使用之前，它会预览当前高亮提示词的正文和变量占位符。使用运行时（runtime）时，只有最终插入操作会触及 assistant-ui 状态；在独立模式下，你还需要自行管理选择和插入。

## 快速开始

<RuntimeMode>

使用运行时时，没有可供读取的已保存提示词库：assistant-ui 不负责管理你为重复使用而收藏的提示词。该目录、存储和搜索完全由你负责，与独立模式相同。运行时真正参与的唯一环节，是提示词被使用的时刻。

### 将插入操作连接到输入框

`onInsert` 会在按下 Enter 或双击时触发。将所选提示词的正文直接写入当前输入框；该元素不会处理类似 `{topic}` 的变量占位符，因此如果你希望替换它们，应在调用此方法之前完成。

```tsx title="components/assistant-ui/elements/prompt-library-panel.tsx"
"use client";

import { useAui } from "@assistant-ui/react";
import { useState } from "react";
import {
  PromptLibrary,
  type SavedPrompt,
} from "@/components/assistant-ui/elements/prompt-library";

export function PromptLibraryPanel({
  prompts,
}: {
  prompts: readonly SavedPrompt[];
}) {
  const aui = useAui();
  const [query, setQuery] = useState("");
  const [selectedId, setSelectedId] = useState(prompts[0]?.id ?? "");

  return (
    <PromptLibrary
      prompts={prompts}
      query={query}
      selectedId={selectedId}
      onQueryChange={setQuery}
      onSelect={setSelectedId}
      onInsert={(id) => {
        const prompt = prompts.find((p) => p.id === id);
        if (prompt) aui.composer.setText(prompt.body);
      }}
    />
  );
}
```

### 持有列表、查询文本和选择状态

```tsx title="app/prompt-library-panel.tsx"
"use client";

import { useState } from "react";
import { PromptLibrary } from "@/components/assistant-ui/elements/prompt-library";

const prompts = [
  {
    id: "bug-report",
    name: "Bug report",
    body: "Describe the bug, the steps to reproduce it, and the expected behavior.",
    variables: [],
  },
  {
    id: "summarize",
    name: "Summarize {topic}",
    body: "Summarize {topic} in three sentences for a non-technical reader.",
    variables: ["topic"],
  },
];

export function PromptLibraryPanel({
  onInsert,
}: {
  onInsert: (text: string) => void;
}) {
  const [query, setQuery] = useState("");
  const [selectedId, setSelectedId] = useState(prompts[0].id);

  return (
    <PromptLibrary
      prompts={prompts}
      query={query}
      selectedId={selectedId}
      onQueryChange={setQuery}
      onSelect={setSelectedId}
      onInsert={(id) => {
        const prompt = prompts.find((p) => p.id === id);
        if (prompt) onInsert(prompt.body);
      }}
    />
  );
}
```

## 结构

```tsx
<div data-slot="prompt-library">
  <div role="combobox" aria-expanded aria-controls>
    <svg /* bookmark icon */ />
    <input placeholder="Search prompts" />
  </div>
  <div role="listbox" aria-label="Saved prompts">
    {/* one option row per match, filtered by name */}
  </div>
  {/* "Nothing matches “query”" when there are no matches */}
  {/* preview: body text, then a chip per variable, only for the selected match */}
</div>
```

筛选时，仅在 `name` 上以不区分大小写的子字符串方式，将 `prompts` 与 `query` 进行匹配；只有当 `selectedId` 位于当前匹配项中时，底部的预览面板才会渲染。因此，如果查询将选中的提示词筛除，其预览也会一并隐藏。方向键会在当前匹配项中移动高亮行；如果之前选中的 id 已被筛除，第一次按键会从该方向所对应的边缘开始，而不会从一个不存在的位置跳转。Enter 会插入高亮的匹配项，这与双击某一行执行的操作相同。

## 示例

### 设置变量数量的格式

匹配项旁边的标签以及预览中的标签仅用于显示；该元素会统计并列出 `variables`，但不会将它们替换到 `body` 中。

```tsx
{prompt.variables.length > 0 && <span>{prompt.variables.length} vars</span>}
```

### 重新设置列表样式

搜索字段和预览面板都使用共享的 `field` 表面，而每个数量值都使用 `mono`，来源为 `surfaces.tsx`。

```tsx
<PromptLibrary className="max-w-md" prompts={prompts} query={query} selectedId={selectedId} onQueryChange={setQuery} onSelect={setSelectedId} onInsert={onInsert} />
```

## API 参考

<RuntimeMode>

### 输入框操作

| 选择器 / 调用 | 类型 | 描述 |
|------------------|------|-------------|
| `aui.composer.setText(text)` | `(text: string) => void` | 使用来自 `useAui()` 的客户端，将文本写入活动输入框。`onInsert` 的自然目标。 |

没有用于已保存提示词目录的选择器：列表、存储和搜索都由你自己的状态管理。

</RuntimeMode>

<StandaloneMode>

### PromptLibrary

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `prompts` | `readonly SavedPrompt[]` | 必填 | 所有已保存的内容。筛选会在组件内部根据名称进行。 |
| `query` | `string` | 必填 | 当前搜索文本。 |
| `selectedId` | `string` | 必填 | 列表下方要预览的提示词。 |
| `onQueryChange` | `(query: string) => void` | | 输入搜索内容时调用。 |
| `onSelect` | `(id: string) => void` | | 高亮提示词时调用。 |
| `onInsert` | `(id: string) => void` | | 双击或按下 Enter 时调用，以便将提示词放入输入框。 |
| `className` | `string` | | 合并到根元素上。 |

### SavedPrompt

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `id` | `string` | 必填 | 稳定的标识，与 `selectedId` 进行比较。 |
| `name` | `string` | 必填 | 提示词名称，也是搜索筛选的唯一字段。 |
| `body` | `string` | 必填 | 提示词文本，显示在列表下方的预览中。 |
| `variables` | `readonly string[]` | 必填 | 正文中的占位符名称，会列出这些名称，以便你了解该提示词会要求填写哪些内容。 |

所有其他 `div` 属性都会转发到根元素。

</StandaloneMode>
