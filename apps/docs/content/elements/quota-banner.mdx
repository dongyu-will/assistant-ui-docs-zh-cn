QuotaBanner 显示使用配额的剩余情况：醒目的计数、填充条，以及接近上限时变为琥珀色的升级按钮。assistant-ui 的运行时没有计划上限或速率预算的概念；这些属于宿主应用负责的账户和计费状态。因此，该元素只有一种独立形式：由你保存已使用量和上限，并在它们变化时重新渲染。

## 开始使用

你可以自行决定“已使用量”和“上限”的含义，单位可以是计划统计的消息、令牌或请求，然后从账户状态所在的位置向下传递当前数值。

<Steps>
  <Step>

### 保存使用状态

```tsx title="app/quota.tsx"
"use client";

import { useState } from "react";
import { QuotaBanner } from "@/components/assistant-ui/elements/quota-banner";

export function Quota() {
  const [used, setUsed] = useState(32);

  return (
    <QuotaBanner
      used={used}
      limit={50}
      unit="messages"
      resetsIn="3h 12m"
      upgradeLabel="Upgrade"
      onUpgrade={() => (window.location.href = "/billing")}
    />
  );
}
```

  </Step>
  <Step>

### 按自己的时钟重新计算 `resetsIn`

组件不会自行倒计时。`resetsIn` 就是你传入的任意字符串，因此请自行刷新它，可以使用计时器，也可以根据账户的重置时间戳刷新：

```tsx
const resetsIn = formatDistanceToNowStrict(resetAt);
```

  </Step>
</Steps>

## 结构

```tsx
<div data-slot="quota-banner">
  <div>
    <span>{/* "{left} {unit} left", amber past 90% used */}</span>
    <span>{/* "resets in {resetsIn}" */}</span>
  </div>
  <span>{/* fill bar, amber past 90% used */}</span>
  <div>
    <span>{/* "{used} of {limit} used" */}</span>
    <button>{/* upgradeLabel, always rendered */}</button>
  </div>
</div>
```

`left` 等于 `limit` 减去 `used`，并限制最小值为零，因此超出配额时显示为 `"0 {unit} left"`，而不是负数。紧张的琥珀色状态从已使用 90% 时开始（`used / limit >= 0.9`），醒目的计数和填充条都会变为该颜色；`0` 的 `limit` 会被视为已使用 `0%`，而不是产生 `NaN`。无论账户是否接近上限，升级按钮始终会渲染；如果你传入 `onUpgrade`，按钮会调用它；如果不传入，则没有默认操作。

## 示例

### 重新设置横幅样式

填充条的已填充部分和按钮都会从 `surfaces.tsx` 读取共享的表面令牌，按钮是 `inkButton`，根元素是 `paper`。根元素上的 `className` 会与这些属性合并。

```tsx
<QuotaBanner className="max-w-none" /* ... */ />
```

### 从计费 API 读取计划使用量

```tsx
const { data } = useSWR("/api/usage", fetcher);
if (!data) return null;

return (
  <QuotaBanner
    used={data.used}
    limit={data.limit}
    unit={data.unit}
    resetsIn={data.resetsIn}
    upgradeLabel="Upgrade"
    onUpgrade={() => router.push("/billing")}
  />
);
```

## API 参考

### QuotaBanner

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `used` | `number` | 必填 | 截至目前已消耗的单位数。 |
| `limit` | `number` | 必填 | 重置前允许使用的单位数。 |
| `unit` | `string` | 必填 | 计数标签，例如 `"messages"`。 |
| `resetsIn` | `string` | 必填 | 预先格式化的倒计时文本。 |
| `upgradeLabel` | `string` | 必填 | 升级按钮上的文本。 |
| `onUpgrade` | `() => void` | | 按下升级按钮时调用。 |
| `className` | `string` | | 合并到根元素。 |

所有其他 `div` 属性都会转发到根元素。
