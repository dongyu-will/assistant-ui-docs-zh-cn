三个圆点以交错波浪的形式上下跳动，可以单独显示，也可以放在圆角气泡中。在运行时中，你可以在第一个 token 到达前的短暂窗口内挂载它；单独使用时，则由你自行控制显示和隐藏。

## 入门

<RuntimeMode>

它只应在一个特定窗口内显示：一次运行处于活动状态，且最新消息尚未产生任何内容。圆点本身与运行时无关；只有是否渲染它的决定依赖运行时。

<Steps>
  <Step>

### 在第一个 token 前显示

```tsx title="components/assistant-ui/elements/typing-indicator.tsx"
"use client";

import { useAuiState } from "@assistant-ui/react";
import { TypingIndicator } from "@/components/assistant-ui/elements/typing-indicator";

function AssistantTyping() {
  const waiting = useAuiState((s) => {
    if (!s.thread.isRunning) return false;
    const last = s.thread.messages.at(-1);
    return last?.role === "assistant" && last.parts.length === 0;
  });
  if (!waiting) return null;
  return <TypingIndicator />;
}
```

  </Step>
  <Step>

### 放置在回复将要渲染的位置

将 `AssistantTyping` 渲染在助手消息正文开始接收内容后将占据的同一位置，这样它消失时不会造成布局偏移。

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

单独使用时，`TypingIndicator` 完全不需要任何数据；何时挂载和卸载它完全由你决定。

<Steps>
  <Step>

### 等待时将其放入界面

```tsx title="app/chat.tsx"
"use client";

import { useState } from "react";
import { TypingIndicator } from "@/components/assistant-ui/elements/typing-indicator";

export function Chat() {
  const [waiting, setWaiting] = useState(false);
  return waiting ? <TypingIndicator /> : null;
}
```

  </Step>
  <Step>

### 选择变体

```tsx
<TypingIndicator variant="bare" />
```

  </Step>
</Steps>

</StandaloneMode>

## 示例

### 不带气泡的纯圆点

`variant="bare"` 移除圆角 `paper` 表面，只渲染三个圆点，适合放置在你自己的容器中。

```tsx
<TypingIndicator variant="bare" className="gap-0.5" />
```

### 重新设置圆点样式

气泡变体会使用 `surfaces.tsx` 中共享的 `paper` 表面包裹圆点；在任一变体上使用 `className` 只会影响最外层元素（对于 `"bubble"`，即气泡本身；对于 `"bare"`，即圆点行）。圆点的颜色、大小和跳动时序是固定的，不会作为 props 暴露。

```tsx
<TypingIndicator className="px-3 py-2.5" />
```

## API 参考

<RuntimeMode>

### 线程状态

| 选择器 | 类型 | 描述 |
|----------|------|-------------|
| `s.thread.isRunning` | `boolean` | 一次运行是否处于活动状态。 |
| `s.thread.messages` | `readonly MessageState[]` | `.at(-1)` 是最新消息；如果助手消息的 `parts` 数组为空，则表示尚未有任何内容流式传输进来。 |

</RuntimeMode>

<StandaloneMode>

### TypingIndicator

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `variant` | `"bubble" \| "bare"` | `"bubble"` | `"bubble"` 会将圆点包裹在圆角表面中；`"bare"` 只渲染圆点。 |
| `className` | `string` | | 合并到根元素上。 |

`role` 和 `aria-label` 由组件固定（`"status"` 和 `"Assistant is typing"`），不属于属性类型；除 `children` 和 `variant` 外，其他所有 `div` 属性都会被转发。

</StandaloneMode>
