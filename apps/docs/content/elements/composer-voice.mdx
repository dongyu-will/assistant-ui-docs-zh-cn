---
title: "听写"
description: "麦克风会将输入框变为实时波形，随后将听写文本写入输入框。"
---

点击麦克风后，用户讲话时文本输入框会替换为实时波形，随后进入短暂的“正在转写”状态，最后将文字写入输入框。在运行时中，这由 `DictationAdapter` 提供支持，最常见的是浏览器自身的语音识别功能；单独使用时，则需要自行控制录音标志和已用时计时器。

## 快速开始

<RuntimeMode>

听写与附件一样是可选功能：如果未配置 `DictationAdapter`，则 `s.thread.capabilities.dictation` 为 `false`，并且 `ComposerPrimitive.Dictate` 会以禁用状态渲染。

<Steps>
  <Step>

### 配置听写适配器

assistant-ui 提供了基于浏览器 `SpeechRecognition` API 的 `WebSpeechDictationAdapter`；在依赖它之前，请检查 `.isSupported()`，因为并非所有浏览器都支持该功能：

```tsx title="app/chat-provider.tsx"
import { useLocalRuntime, WebSpeechDictationAdapter } from "@assistant-ui/react";

const runtime = useLocalRuntime(chatModel, {
  adapters: {
    dictation: WebSpeechDictationAdapter.isSupported()
      ? new WebSpeechDictationAdapter({ interimResults: true })
      : undefined,
  },
});
```

  </Step>
  <Step>

### 开始、显示和停止

```tsx title="components/assistant-ui/elements/composer-voice.tsx"
"use client";

import { AuiIf, ComposerPrimitive } from "@assistant-ui/react";
import { MicIcon, SquareIcon } from "lucide-react";
import { cn } from "@/lib/utils";
import { ghostButton, inkButton } from "@/components/assistant-ui/elements/surfaces";

export function DictationControl() {
  return (
    <AuiIf condition={(s) => s.thread.capabilities.dictation}>
      <AuiIf condition={(s) => s.composer.dictation == null}>
        <ComposerPrimitive.Dictate aria-label="Start voice input" className={cn(ghostButton, "size-8")}>
          <MicIcon className="size-4" />
        </ComposerPrimitive.Dictate>
      </AuiIf>
      <AuiIf condition={(s) => s.composer.dictation != null}>
        <ComposerPrimitive.StopDictation
          aria-label="Stop voice input"
          className={cn(inkButton, "flex size-8 items-center justify-center rounded-full")}
        >
          <SquareIcon className="size-3 fill-current" />
        </ComposerPrimitive.StopDictation>
      </AuiIf>
    </AuiIf>
  );
}
```

只有当 `s.composer.dictation` 不为 null 时，`StopDictation` 才会渲染为启用状态（与 `Send` 和 `Cancel` 一样，它不会自行卸载）；上面的 `AuiIf` 组合只会挂载相关按钮，这与 `Thread` 自带的输入框所执行的切换相同。`Dictate` 会通过已配置的适配器启动会话，并在识别到语音后将其直接写入 `s.composer.text`。

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

单独使用时，`ComposerVoice` 和 `ComposerVoiceButton` 只会渲染你已经持有的录音状态；这里的任何内容都不会操作麦克风。你需要自行启动浏览器的语音识别 API（或其他采集方式），并通过它为 `recording` 和 `seconds` 提供数据。

<Steps>
  <Step>

### 保存录音状态

```tsx title="app/chat-box.tsx"
"use client";

import { useEffect, useState } from "react";
import { ComposerVoice, ComposerVoiceButton, ComposerInput } from "@/components/assistant-ui/elements/composer";

export function VoiceInput() {
  const [active, setActive] = useState(false); // from the first tap until the final transcript lands
  const [recording, setRecording] = useState(false);
  const [seconds, setSeconds] = useState(0);

  useEffect(() => {
    if (!recording) return;
    setSeconds(0);
    const id = setInterval(() => setSeconds((s) => s + 1), 1000);
    return () => clearInterval(id);
  }, [recording]);

  const start = () => {
    setActive(true);
    setRecording(true);
    startBrowserRecognition({
      onFinal: (text) => {
        setRecording(false); // waveform settles into "Transcribing"
        commitTranscript(text).finally(() => setActive(false));
      },
    });
  };

  return active ? (
    <div className="flex items-center gap-2">
      <ComposerVoice recording={recording} seconds={seconds} className="flex-1" />
      <ComposerVoiceButton active={recording} onClick={stopBrowserRecognition} />
    </div>
  ) : (
    <div className="flex items-center gap-2">
      <ComposerInput className="flex-1" />
      <ComposerVoiceButton active={false} onClick={start} />
    </div>
  );
}
```

  </Step>
  <Step>

### 将输入框替换为波形

`ComposerVoice` 在激活时应替换 `ComposerInput`，而不是像上面那样与其并列显示；在状态稳定期间，`active` 会保持为 `true`，这样计时器的“正在转写”状态就有位置进行渲染，之后视图才会回退为普通文本。

  </Step>
</Steps>

</StandaloneMode>

## 组成结构

```tsx
<div data-slot="composer-voice" data-recording={/* true while capturing */}>
  {/* a pulsing dot, only while recording */}
  <div>{/* 14 bars, animated only while recording */}</div>
  {/* a mono "0:SS" timer while recording, or a "Transcribing" shimmer once stopped */}
</div>
```

这两种状态不是“录音”和“空闲”，而是“录音”和“稳定中”。`ComposerVoice` 没有第三种空白状态，因此挂载它始终意味着采集正在进行或刚刚结束；这些条形本身由以条形索引和已用秒数为种子的正弦波产生波动，因此图案会持续变化，而不是循环播放。

## 示例

### 在提供麦克风前检查支持情况

<RuntimeMode>

```tsx
const dictationAvailable = WebSpeechDictationAdapter.isSupported();
```

仅在 `true` 时配置适配器（如“快速开始”中所示）即可；`s.thread.capabilities.dictation` 会自动反映这一点，因此麦克风按钮无需单独检查支持情况。

</RuntimeMode>

### 覆盖显示实时转写文本

<RuntimeMode>

`ComposerVoice` 显示的是计时器，而不是正在说出的文字；可以将 `ComposerPrimitive.DictationTranscript` 叠加在其上方（或放在旁边），以便在临时转写文本流入时显示它，并在最终提交到 `s.composer.text` 之前持续更新：

```tsx
<ComposerPrimitive.DictationTranscript className="text-foreground/55 absolute inset-x-3 bottom-full text-sm" />
```

</RuntimeMode>

### 重新设置波形样式

两个通道渲染相同的形状；脉动圆点、条形、计时器和闪烁标签分别使用各自的 class，因此重新设置录音状态的颜色无需修改稳定状态。

```tsx
<ComposerVoice recording={recording} seconds={seconds} className="gap-4" />
```

## API 参考

<RuntimeMode>

### ComposerPrimitive

| 部件 | 渲染内容 | 说明 |
|------|---------|-------|
| `Dictate` | `button` | 通过已配置的 `DictationAdapter` 启动会话；未配置时处于禁用状态。 |
| `StopDictation` | `button` | 仅当 `s.composer.dictation` 不为 null 时才会渲染为启用状态。 |
| `DictationTranscript` | `span` | 渲染实时临时转写文本；没有文本时不渲染任何内容。 |

### WebSpeechDictationAdapter

| 选项 | 类型 | 默认值 | 描述 |
|--------|------|---------|-------------|
| `language` | `string` | `navigator.language` | 传递给 `SpeechRecognition` 的 BCP 47 语言标签。 |
| `continuous` | `boolean` | `true` | 在暂停期间继续监听，而不是在一次话语后停止。 |
| `interimResults` | `boolean` | `true` | 在识别语音时发出部分结果，而不仅仅是最终结果。 |

`WebSpeechDictationAdapter.isSupported()` 是一个静态方法；如果在 `SpeechRecognition` 不可用的环境中构造并使用该适配器，适配器本身会抛出错误。

### 输入框状态

| 选择器 | 类型 | 描述 |
|----------|------|-------------|
| `s.composer.dictation` | `{ status; transcript?: string; inputDisabled?: boolean } \| undefined` | 仅在听写会话处于活动状态或正在完成时不为 null。 |
| `s.thread.capabilities.dictation` | `boolean` | 是否配置了 `DictationAdapter`。 |
| `aui.composer.startDictation()` | `() => void` | 启动会话；未配置适配器时抛出错误。 |
| `aui.composer.stopDictation()` | `() => void` | 停止当前会话并提交最终转写文本。 |

`status` 在监听时为 `{ type: "starting" \| "running" }`，完成后为 `{ type: "ended", reason: "stopped" \| "cancelled" \| "error" }`；它没有已用秒数字段，因此类似 `ComposerVoice` 的实时计数器需要与 `status` 分开计时（一个由 `s.composer.dictation != null` 控制的 `setInterval`，与单独使用示例相对应）。

</RuntimeMode>

### ComposerVoice

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `recording` | `boolean` | 必填 | 选择“动态条形和计时器”状态，或“静态条形和闪烁”状态。 |
| `seconds` | `number` | 必填 | 当 `recording` 为 `true` 时显示为 `0:SS`。 |
| `className` | `string` | | 合并到根元素上。 |

### ComposerVoiceButton

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `active` | `boolean` | 必填 | 将麦克风图标替换为实心停止图标，并将幽灵样式替换为墨色样式。 |
