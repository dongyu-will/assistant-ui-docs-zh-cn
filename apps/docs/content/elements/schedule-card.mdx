计划任务卡片展示一个会自动重复运行的任务：其执行周期、下一次运行时间，以及最近的运行是否成功。它只是一个展示组件；计划任务本身以及暂停操作的实际行为，都由你自己的后端负责。

### 渲染计划任务

```tsx title="app/schedule.tsx"
"use client";

import { ScheduleCard, type ScheduleRun } from "@/components/assistant-ui/elements/schedule-card";

const history: ScheduleRun[] = [
  { id: "1", at: "Today 06:00", ok: true },
  { id: "2", at: "Yesterday 06:00", ok: true },
  { id: "3", at: "Tue 06:00", ok: false },
];

export function NightlyReport() {
  return (
    <ScheduleCard
      name="Nightly report"
      cadence="Daily at 06:00"
      nextRun="Tomorrow 06:00"
      enabled
      history={history}
    />
  );
}
```

  </Step>

### 接入切换开关

`onToggle` 只报告点击操作；`enabled` 持续驱动开关，因此由你的处理函数负责切换它（通常在暂停/恢复请求成功后进行）。

```tsx
"use client";

import { useState } from "react";

export function NightlyReport() {
  const [enabled, setEnabled] = useState(true);

  return (
    <ScheduleCard
      name="Nightly report"
      cadence="Daily at 06:00"
      nextRun="Tomorrow 06:00"
      enabled={enabled}
      history={history}
      onToggle={async () => {
        await setScheduleEnabled("nightly-report", !enabled);
        setEnabled((prev) => !prev);
      }}
    />
  );
}
```

## 结构

```tsx
<div data-slot="schedule-card">
  <div>
    <span>{/* clock icon avatar */}</span>
    <div>
      <span>{name}</span>
      <span>{cadence}</span>
    </div>
    <button role="switch" aria-checked={enabled} />
  </div>
  <div>
    <span>next</span>
    <span>{/* nextRun, or the literal text "paused" */}</span>
  </div>
  <div>
    <span>recent runs</span>
    {/* one row per history entry */}
    <span>{/* check or x */}</span>
    <span>{run.at}</span>
    <span>{/* "ok" or "failed" */}</span>
  </div>
</div>
```

“下一次”这一行始终会渲染。当 `enabled` 为 true 时，它会显示 `nextRun`；为 false 时则显示字面文本 “paused”，并使整行变暗。开关是一个受控的视觉元素：其轨道颜色和滑块位置完全来自 `enabled`，点击开关只会触发 `onToggle`，因此在你的处理函数更新该属性之前，开关不会移动。空的 `history` 数组会渲染“最近运行”标签，但其下方不会显示任何行。

## 示例

### 已暂停的计划任务

```tsx
<ScheduleCard name="Nightly report" cadence="Daily at 06:00" nextRun="Tomorrow 06:00" enabled={false} history={history} />
```

### 读取运行历史

每条记录彼此独立；成功和失败记录的组合会按照你传入的顺序渲染：

```tsx
<ScheduleCard
  {...rest}
  history={[
    { id: "1", at: "Today 06:00", ok: true },
    { id: "2", at: "Yesterday 06:00", ok: false },
  ]}
/>
```

### 重新设置卡片样式

根元素使用共享的 `paper` 表面；执行周期、“下一次”和“最近运行”标签使用 `mono`，而“下一次”这一行位于 `field` 胶囊中。

```tsx
<ScheduleCard className="max-w-md rounded-3xl" {...rest} />
```

## API 参考

<StandaloneMode>

### ScheduleCard

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `name` | `string` | 必填 | 截断后的标题。 |
| `cadence` | `string` | 必填 | 显示在名称下方。 |
| `nextRun` | `string` | 必填 | 当 `enabled` 为 true 时，显示在“下一次”这一行中。 |
| `enabled` | `boolean` | 必填 | 驱动开关，并决定显示 `nextRun` 还是 “paused”。 |
| `history` | `readonly ScheduleRun[]` | 必填 | 最近的运行记录，顺序与传入顺序一致。 |
| `onToggle` | `() => void` | | 点击开关时调用。它本身不会改变 `enabled`。 |
| `className` | `string` | | 合并到根元素上。 |

### ScheduleRun

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `id` | `string` | 行键。 |
| `at` | `string` | 行标签；格式由你自行决定。 |
| `ok` | `boolean` | 选择勾号/叉号图标以及 “ok”/“failed” 标签。 |

其他所有 `div` 属性都会转发到根元素。

</StandaloneMode>
