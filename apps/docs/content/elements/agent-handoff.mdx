---
title: "交接"
description: "控制权在助手之间传递，并说明原因和随之传递的内容。"
---

交接标志着控制权从一个助手传递到另一个助手的时刻：之前由哪个助手控制、现在由哪个助手控制、交接原因，以及传递了哪些上下文。整个组件仅负责展示；你可以决定何时发生交接，并提供所有字段。

## 开始使用

<Steps>
  <Step>

### 渲染正在进行的交接

```tsx title="app/handoff.tsx"
"use client";

import { AgentHandoff } from "@/components/assistant-ui/elements/agent-handoff";

export function RoutingHandoff() {
  return (
    <AgentHandoff
      from="Router"
      to="Billing"
      reason="Question is about a refund, not routing."
      carried={["order #48213", "customer tier: pro"]}
      settled={false}
    />
  );
}
```

  </Step>
  <Step>

### 新助手接管后完成交接

`settled` 仅控制样式；当你的应用通过某种方式获知目标助手确实已开始响应时，从那里切换它。

```tsx
"use client";

import { useState } from "react";

export function RoutingHandoff() {
  const [settled, setSettled] = useState(false);

  return (
    <AgentHandoff
      from="Router"
      to="Billing"
      reason="Question is about a refund, not routing."
      carried={["order #48213"]}
      settled={settled}
    />
  );
}
```

  </Step>

## 结构

```tsx
<div data-slot="agent-handoff">
  <div>
    <span>{/* from pill */}</span>
    <svg>{/* arrow */}</svg>
    <span>{/* to pill */}</span>
  </div>
  <p>{reason}</p>
  <div>{/* one line per carried item, only when carried.length > 0 */}</div>
</div>
```

在 `settled` 之前，箭头和 `to` 标签以蓝色显示，表示交接正在传递中，而 `from` 标签保持完全不透明。`settled` 后，`from` 标签变暗，箭头变为灰色，`to` 标签切换为完全不透明的中性标签样式，因为它现在是当前发言者。两种过渡都会以 500ms 的时长执行动画。`carried` 是必需的，而不是可选项：传入空数组即可完全不渲染“传递内容”部分，而不是渲染一个空部分。

## 示例

### 不包含传递上下文的交接

```tsx
<AgentHandoff from="Planner" to="Executor" reason="Plan is complete." carried={[]} settled />
```

### 将完成状态连接到你自己的事件

组件不会监听任何事件；`setSettled(true)` 应放在应用已知交接完成的位置，例如 websocket 消息或状态机转换：

```tsx
useEffect(() => {
  const unsubscribe = subscribeToAgentEvents((event) => {
    if (event.type === "agent_took_over" && event.agent === "Billing") {
      setSettled(true);
    }
  });
  return unsubscribe;
}, []);
```

### 重新设置交接样式

`from` 标签始终使用共享的 `field` 表面；`to` 标签在 `settled` 后切换为 `field`，在此之前显示为蓝色调。“传递内容”标签使用 `mono`。

```tsx
<AgentHandoff className="max-w-md gap-3" {...rest} />
```

## API 参考

<StandaloneMode>

### AgentHandoff

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `from` | `string` | 必需 | 之前拥有控制权的助手。 |
| `to` | `string` | 必需 | 接管控制权的助手。 |
| `reason` | `string` | 必需 | 显示在标签下方。 |
| `carried` | `readonly string[]` | 必需 | 列在“传递内容”下的上下文项。传入 `[]` 可不渲染任何内容。 |
| `settled` | `boolean` | 必需 | 在传递中和已完成样式之间切换。 |
| `className` | `string` | | 合并到根元素上。 |

所有其他 `div` 属性都会转发到根元素。

</StandaloneMode>
