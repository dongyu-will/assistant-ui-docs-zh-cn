MapAnswer 将位置结果显示在示意网格上：可供选择的标记、连接它们的可选路线，以及下方的来源列表。在运行时中，标记来自用于查找地点的工具调用；独立使用时，你已经持有这些标记。

## 快速开始

<RuntimeMode>

assistant-ui 没有地图或地理编码概念，MapAnswer 也不会绘制真实的地图瓦片或投影：`x` 和 `y` 只是用于在网格上放置标记的 0 到 100 百分比，而不是纬度和经度。负责查找地点的逻辑需要在结果传递给此组件之前，将真实坐标转换为这种百分比布局。

  <Step>

### 渲染工具调用

```tsx title="components/assistant-ui/elements/find-places-tool-ui.tsx"
"use client";

import { useState } from "react";
import type { ToolCallMessagePartComponent } from "@assistant-ui/react";
import {
  MapAnswer,
  type MapPin,
} from "@/components/assistant-ui/elements/map-answer";

type FindPlacesResult = {
  pins: MapPin[];
  route: boolean;
};

export const FindPlacesToolUI: ToolCallMessagePartComponent<
  { query: string },
  FindPlacesResult
> = ({ result }) => {
  const [activeId, setActiveId] = useState("");

  if (!result) return null;
  const activePin = activeId || (result.pins[0]?.id ?? "");

  return (
    <MapAnswer
      pins={result.pins}
      activeId={activePin}
      route={result.route}
      onSelect={setActiveId}
    />
  );
};
```

  </Step>
  <Step>

### 注册工具

```tsx title="app/toolkit.ts"
import { defineToolkit } from "@assistant-ui/react";
import { z } from "zod";
import { FindPlacesToolUI } from "@/components/assistant-ui/elements/find-places-tool-ui";

export const toolkit = defineToolkit({
  find_places: {
    type: "frontend",
    description: "Find places for a query and lay them out on a schematic map.",
    parameters: z.object({ query: z.string() }),
    execute: async ({ query }) => lookupPlaces(query),
    render: FindPlacesToolUI,
  },
});
```

`lookupPlaces` 负责坐标计算：根据整个结果集的边界框，对每个结果的真实纬度和经度进行归一化，使距离最近的标记在网格上也彼此接近。使用 `Tools({ toolkit })` 接入工具包；请参阅 [工具 UI](/docs/tools/tool-ui)。

  </Step>
</Steps>

### 保存当前激活的标记

```tsx title="app/places.tsx"
"use client";

import { useState } from "react";
import {
  MapAnswer,
  type MapPin,
} from "@/components/assistant-ui/elements/map-answer";

const PINS: MapPin[] = [
  { id: "a", label: "Ferry Building", detail: "0.4 mi", x: 28, y: 62 },
  { id: "b", label: "Coit Tower", detail: "1.1 mi", x: 55, y: 20 },
  { id: "c", label: "Chinatown", detail: "0.8 mi", x: 40, y: 45 },
];

export function Places() {
  const [activeId, setActiveId] = useState(PINS[0].id);
  return (
    <MapAnswer pins={PINS} activeId={activeId} route onSelect={setActiveId} />
  );
}
```

  </Step>
  <Step>

### 替换标记集

新的搜索会替换整个数组，并重置当前激活的标记。

```tsx
async function search(query: string) {
  const places = await fetchPlaces(query);
  setPins(places);
  setActiveId(places[0]?.id ?? "");
}
```

## 结构

```tsx
<div data-slot="map-answer">
  <div>
    <svg>{/* hairline grid, plus an optional dashed route through pins in array order */}</svg>
    {/* one marker button per pin, positioned by x/y percentage */}
  </div>
  <div>
    {/* one row per pin, top-bordered, including the first */}
  </div>
</div>
```

仅当 `route` 为 true 且至少有两个标记时，才会绘制路线。它是一条严格按照数组顺序连接标记的静态虚线折线，而不是计算得出的路径，因此重新排列 `pins` 会改变绘制的路线，但不会添加或删除任何标记。`x` 和 `y` 会在 0 到 100 的 viewBox 中按百分比放置标记；超出范围的值不会被限制。激活标记的形状会变大，并切换为蓝色填充；其他标记保持较小的中性填充。两者都使用与背景同色的环形边框，因此在网格线背景上都能清晰显示。点击标记或点击下方列表中的对应行，都会使用相同的 `pin.id` 调用 `onSelect`，因此两种操作都会移动当前激活的标记。每个列表行都带有顶部分隔线，包括第一行，因为列表直接位于网格下方，而不是位于另一行下方。空的 `pins` 数组会渲染为空网格，网格细线仍然可见，下方则显示空列表。

## 示例

### 绘制路线

虚线表示装饰性的连接关系，而不是规划出的路径：它始终按照 `pins` 的顺序绘制，且不会根据当前激活的标记进行调整。

```tsx
<MapAnswer pins={pins} activeId={activeId} route onSelect={onSelect} />
```

### 重新设置地图样式

两条区域都会在根元素上接收 `className`。网格背景使用共享的 `field` 令牌，卡片本身使用 `paper`，列表的详情列使用 `mono`，这些令牌都来自 `surfaces.tsx`。

```tsx
<MapAnswer className="max-w-none" /* ... */ />
```

## API 参考

<RuntimeMode>

### 工具调用渲染属性

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `args` | `TArgs` | 解析后的参数。在模型仍处于流式传输状态时，该值可能不完整。 |
| `argsText` | `string` | 模型流式传输的原始 JSON 参数文本。 |
| `result` | `TResult \| undefined` | 工具完成后的返回值。运行期间为 `undefined`。 |
| `status` | `ToolCallMessagePartStatus` | `status.type` 为 `"running"`、`"requires-action"`、`"complete"` 或 `"incomplete"`。 |
| `toolName` | `string` | 模型调用的工具名称。 |
| `toolCallId` | `string` | 此次调用的稳定 ID。 |
| `isError` | `boolean \| undefined` | `result` 是否表示工具执行错误。 |

在工具包条目的 `render` 字段上注册渲染器，并使用 `Tools({ toolkit })` 附加工具包。完整的渲染属性接口请参阅[工具 UI](/docs/tools/tool-ui)，其中包括 `addResult`、人工工具和审批门控。

</RuntimeMode>

<StandaloneMode>

### MapAnswer

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `pins` | `readonly MapPin[]` | 必填 | 要放置的标记，按顺序排列。路线也会按此顺序连接这些标记。 |
| `activeId` | `string` | 必填 | 高亮标记的 ID。如果没有标记匹配该 ID，则不会高亮任何标记。 |
| `route` | `boolean` | | 按数组顺序绘制一条穿过 `pins` 的虚线。即使 `true`，少于两个标记时也不会绘制路线。 |
| `onSelect` | `(id: string) => void` | | 从标记或其列表行触发，并接收该标记的 `id`。 |
| `className` | `string` | | 合并到根元素上。 |

### MapPin

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `id` | `string` | |
| `label` | `string` | 标记的 `aria-label` 和列表行的主要文本。 |
| `detail` | `string` | 列表行中的辅助文本，例如距离。 |
| `x` | `number` | 水平位置，0 到 100 百分比。不是经度。 |
| `y` | `number` | 垂直位置，0 到 100 百分比。不是纬度。 |

所有其他 `div` 属性都会转发到根元素。

</StandaloneMode>
