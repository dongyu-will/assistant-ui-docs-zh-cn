---
title: "文件"
description: "文件消息部分，提供基于类型的图标、文件名、大小和下载操作。"
---

File 会将一个文件消息部分渲染为一行：根据 MIME 类型选择的图标、文件名、可选的大小以及下载链接。使用运行时（runtime）时，它会直接从消息的文件部分进行渲染；单独使用时，则需要手动传入该部分。

## 快速开始

<RuntimeMode>

<Steps>
  <Step>

### 从消息渲染文件

将 `File` 注册为 `MessagePrimitive.Parts` 上的 `File` 渲染器。

```tsx title="components/assistant-ui/elements/thread.aui.tsx"
import { File } from "@/components/assistant-ui/elements/file";
import { MessagePrimitive } from "@assistant-ui/react";

function AssistantMessage() {
  return (
    <MessagePrimitive.Root>
      <MessagePrimitive.Parts components={{ File }} />
    </MessagePrimitive.Root>
  );
}
```

`Thread` 元素已经通过 `File` 同时渲染助手和用户的文件部分，因此安装 `@assistant-ui/thread` 后无需进行上述任何操作即可获得此功能。

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

单独使用时，`File` 是一个只接收单个部分对象的普通函数：不需要上下文，也不需要运行时。

<Steps>
  <Step>

### 直接渲染文件

```tsx title="app/answer.tsx"
import { File } from "@/components/assistant-ui/elements/file";

export function Attachment() {
  return (
    <File
      type="file"
      filename="report.pdf"
      mimeType="application/pdf"
      data="https://example.com/report.pdf"
      sourceType="url"
      status={{ type: "complete" }}
    />
  );
}
```

  </Step>
</Steps>

</StandaloneMode>

## 构成

```tsx
<div data-slot="file-root" data-variant={variant} data-size={size}>
  <span data-slot="file-icon" />
  <div>
    <span data-slot="file-name">{filename ?? "Unnamed file"}</span>
    <span data-slot="file-size" /> {/* only for inline (base64 / data URI) data */}
  </div>
  <a data-slot="file-download" />{/* omitted when data can't produce a safe href */}
</div>
```

图标取决于 `mimeType`：图像使用图像图标，PDF 和其他文本使用文档图标，JSON 使用大括号图标，音频和视频使用各自的图标，其他内容则使用通用文件图标。`sourceType` 说明了 `data` 在传输中的编码方式：链接使用 `"url"`，下载链接无法自行解析的不透明引用使用 `"id"`，省略该字段时则根据内容推断（`http(s)://` 字符串会被视为 URL，其他内容则视为 base64）。大小行仅会对内联数据（base64 或 `data:` URI）显示，因为 URL 或 id 引用不包含可读取的字节数。下载链接本身仅会对 base64 和 `data:` URI 数据显示，或者对实际以 `http(s)://` 或 `blob:` 开头的 URL 显示；`"id"` 引用或未通过该检查的 URL 完全不会渲染链接。

## 示例

### 变体和尺寸

```tsx
<File variant="muted" size="sm" {...part} />
```

| 变体 | 描述 |
|---------|-------------|
| `outline` | 边框，悬停时显示背景（默认） |
| `ghost` | 无边框，悬停时显示背景 |
| `muted` | 柔和背景 |

| 尺寸 | 描述 |
|------|-------------|
| `sm` | 紧凑内边距，较小文本 |
| `default` | 标准内边距 |
| `lg` | 更大的内边距和文本 |

### 重新设置行样式

`File.Root`、`File.Icon`、`File.Name`、`File.Size` 和 `File.Download` 均单独导出，可用于自定义布局：

```tsx
import { File } from "@/components/assistant-ui/elements/file";

<File.Root variant="ghost">
  <File.Icon mimeType={part.mimeType} />
  <File.Name>{part.filename}</File.Name>
  <File.Download
    data={part.data}
    mimeType={part.mimeType}
    filename={part.filename}
    sourceType={part.sourceType}
  />
</File.Root>;
```

## API 参考

<RuntimeMode>

### File

| 导出项 | 渲染内容 | 说明 |
|--------|---------|-------|
| `File` | `div` | `File` 消息部分渲染器。作为 `components.File` 传递给 `MessagePrimitive.Parts`。 |
| `File.Root` | `div` | 包含 `variant` 和 `size` 的行。 |
| `File.Icon` | `span` | 根据 `mimeType` 选择图标。 |
| `File.Name` | `span` | 文件名文本；为空时显示“未命名文件”。 |
| `File.Size` | `span` | 格式化后的字节大小；需要提供 `bytes`。 |
| `File.Download` | `a` | 下载链接；当 `data` 无法生成安全的 `href` 时为 `null`。 |

### 文件部分

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `filename` | `string` | 可选的显示名称。 |
| `data` | `string` | 文件载荷：base64、`data:` URI，或根据 `sourceType` 规定的 URL/id。 |
| `mimeType` | `string` | 决定图标，并在 base64/`data:` 载荷中决定下载 `href`。 |
| `sourceType` | `"url" \| "id"` | 可选。说明如何解释 `data`；省略时根据其形式推断。 |

</RuntimeMode>

<StandaloneMode>

### File 属性

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `type` | `"file"` | 必需 | 由部分类型要求。 |
| `filename` | `string` | | 显示名称；未提供时回退为“未命名文件”。 |
| `data` | `string` | 必需 | 文件载荷：base64、`data:` URI，或根据 `sourceType` 规定的 URL/id。 |
| `mimeType` | `string` | 必需 | 决定图标，并在 base64/`data:` 载荷中决定下载 `href`。 |
| `sourceType` | `"url" \| "id"` | | 说明如何解释 `data`；省略时根据其形式推断。 |
| `status` | `MessagePartStatus` | | 类型要求的属性；渲染器不会读取。 |
| `variant` | `"outline" \| "ghost" \| "muted"` | `"outline"` | 行样式，设置在 `File.Root` 上。 |
| `size` | `"sm" \| "default" \| "lg"` | `"default"` | 行尺寸，设置在 `File.Root` 上。 |

`File.Root`、`File.Icon`、`File.Name`、`File.Size` 和 `File.Download` 均单独导出，可用于自定义布局，具体请参见[重新设置行样式](#restyle-the-row)。

</StandaloneMode>
