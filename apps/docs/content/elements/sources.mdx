---
title: "Sources"
description: "带有 favicon、标题和外部链接的运行时 URL 来源。"
---

Sources 用于渲染消息中的一个引用：`url`来源会显示为带有 favicon 和标题的小型链接，`document`来源会显示为带有文档图标的徽章。在运行时中，它会直接从消息的 source part 渲染；单独使用时，则需要手动传入该 part。它提供两种设计：运行时变体会在消息文本旁渲染内联链接或徽章，静态 source-cards 变体则会将所有引用折叠到一个圆角标签中，展开后显示由便于浏览的卡片组成的网格（参见[Source-cards 设计](#the-source-cards-design)）。

## 开始使用

<RuntimeMode>

<Steps>
  <Step>

### 从消息渲染来源

在 `MessagePrimitive.Parts` 上，将 `Sources` 注册为 `Source` 渲染器。消息中的每个 source part 都会自动通过它进行路由。

```tsx title="components/assistant-ui/elements/thread.aui.tsx"
import { Sources } from "@/components/assistant-ui/elements/sources.aui";
import { MessagePrimitive } from "@assistant-ui/react";

function AssistantMessage() {
  return (
    <MessagePrimitive.Root>
      <MessagePrimitive.Parts components={{ Source: Sources }} />
    </MessagePrimitive.Root>
  );
}
```

`url` part 会变成链接，`document` part 会变成徽章，其他任何形状都不会渲染任何内容。

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

单独使用时，`Sources` 是一个只接收单个 part 对象的普通函数：不需要上下文，也不需要运行时。

<Steps>
  <Step>

### 直接渲染来源

```tsx title="app/answer.tsx"
import { Sources } from "@/components/assistant-ui/elements/sources.aui";

export function Citation() {
  return (
    <Sources
      type="source"
      sourceType="url"
      id="src-1"
      url="https://example.com/article"
      title="Example Article"
      status={{ type: "complete" }}
    />
  );
}
```

`status` 属于该类型的一部分，但渲染器不会使用它；传入 `{ type: "complete" }` 即可满足类型要求。

## 组成

```tsx
{/* sourceType: "url" */}
<a data-slot="source" href={url}>
  <img data-slot="source-icon" />
  <span data-slot="source-title">{title ?? domain}</span>
</a>

{/* sourceType: "document" */}
<span data-slot="source">
  <span data-slot="source-document-icon" />
  <span data-slot="source-title">{title}</span>
</span>
```

默认情况下，favicon 会请求 `https://icons.duckduckgo.com/ip3/<domain>.ico`；当该图像加载失败时，图标会回退为从域名中提取的单个字母。来源提供标题时，链接显示的标题为 `title`；否则会显示去除 `www.` 后的纯域名。`document`来源不会链接到任何位置，并始终显示其 `title`。`url`来源的 `url` 为空，或来源属于其他任何 `sourceType` 时，不会渲染任何内容。

## 示例

### 自定义 favicon 和变体

`Sources` 本身只接收 part；如果要覆盖 favicon 查找逻辑或重新设置链接样式，可以将导出的子 part 组合到自定义渲染器中，并注册该渲染器：

```tsx
import { Sources } from "@/components/assistant-ui/elements/sources.aui";
import type { ComponentProps } from "react";

function CustomSource(part: ComponentProps<typeof Sources>) {
  if (part.sourceType !== "url" || !part.url) return null;
  return (
    <Sources.Root href={part.url} variant="secondary">
      <Sources.Icon
        url={part.url}
        faviconUrl={(domain) => `https://logo.clearbit.com/${domain}`}
      />
      <Sources.Title>{part.title}</Sources.Title>
    </Sources.Root>
  );
}
```

在 `MessagePrimitive.Parts` 中使用 `CustomSource` 替代 `Sources`，或者直接传入手动构造的 part 调用它。

### 变体和尺寸

`Sources.Root` 负责样式；按照上面的方式组合自定义渲染器时，传入 `variant` 和 `size`。

| 变体 | 描述 |
|---------|-------------|
| `outline` | 边框，透明背景（默认） |
| `secondary` | 实心次要背景 |
| `muted` | 弱化背景 |
| `ghost` | 悬停前无背景 |
| `info` | 蓝色色调 |
| `warning` | 琥珀色色调 |
| `success` | 翡翠色色调 |
| `destructive` | 红色色调 |

| 尺寸 | 描述 |
|------|-------------|
| `sm` | 紧凑内边距 |
| `default` | 标准内边距 |
| `lg` | 更大的内边距和文本 |

## API 参考

<RuntimeMode>

### Sources

| 导出项 | 渲染内容 | 说明 |
|--------|---------|-------|
| `Sources` | `a` 或徽章 | `Source` 消息 part 渲染器。将其作为 `components.Source` 传入 `MessagePrimitive.Parts`。 |
| `Sources.Root` | `a` | `url` 来源对应的链接。接受 `variant`、`size`、`href` 以及其他锚点属性。 |
| `Sources.Icon` | `img` 或回退的 `span` | `url` 来源的 favicon。接受 `url` 和可选的 `faviconUrl` 解析器。 |
| `Sources.Title` | `span` | 两种来源形状共用的截断标题或域名文本。 |

### Source part

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `sourceType` | `"url" \| "document"` | 要渲染的形状。 |
| `id` | `string` | 来源标识符。 |
| `url` | `string` | 链接目标。当 `sourceType` 为 `"url"` 时，该字段为必填项且会被读取。 |
| `title` | `string` | 对于 `"url"` 可选（回退为域名）；对于 `"document"` 必填。 |
| `mediaType` | `string` | 当 `sourceType` 为 `"document"` 时必填。`Sources` 不会读取该字段。 |
| `filename` | `string` | 可选，仅用于 `"document"`。`Sources` 不会读取该字段。 |

</RuntimeMode>

<StandaloneMode>

### Sources 属性

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `type` | `"source"` | part 类型要求提供。 |
| `sourceType` | `"url" \| "document"` | 要渲染的形状。 |
| `id` | `string` | 来源标识符。类型要求提供；渲染器不会读取。 |
| `url` | `string` | `sourceType: "url"` 对应的链接目标。 |
| `title` | `string` | 显示的标题。`"url"` 可选，`"document"` 必填。 |
| `mediaType` | `string` | 类型对 `"document"` 的要求；渲染器不会读取。 |
| `filename` | `string` | 可选，仅用于 `"document"`；渲染器不会读取。 |
| `status` | `MessagePartStatus` | 类型要求提供；渲染器不会读取。 |

`Sources.Root`、`Sources.Icon` 和 `Sources.Title` 可用于构建自定义渲染器，具体如[自定义 favicon 和变体](#custom-favicon-and-variant)所示。

## Source-cards 设计

侧栏中的 Static 变体是针对相同引用的第二种设计：它不会在消息文本旁显示内联链接或徽章，而是将所有引用折叠到一个圆角标签中，展开后显示卡片网格。每张卡片包含域名头像、域名和标题。这是一个由属性驱动且不依赖运行时的单一组件：

```sh
npx shadcn@latest add "@assistant-ui/elements-sources"
```

<RuntimeMode>

运行时不会将消息的来源收集到同一位置：它们会作为单独的 `source` parts 到达，因此需要通过选择器将它们收集为该组件所需的形状。

```tsx title="components/assistant-ui/elements/message-sources.tsx"
"use client";

import { useMemo, useState } from "react";
import { useAuiState } from "@assistant-ui/react";
import { Sources, type Source } from "@/components/assistant-ui/elements/sources";

function extractDomain(url: string) {
  try {
    return new URL(url).hostname.replace(/^www\./, "");
  } catch {
    return url;
  }
}

export function MessageSources() {
  const parts = useAuiState((s) => s.message.parts);
  const [open, setOpen] = useState(false);

  const sources = useMemo<Source[]>(
    () =>
      parts.flatMap((part) => {
        if (part.type !== "source" || part.sourceType !== "url") return [];
        const domain = extractDomain(part.url);
        return [{ domain, title: part.title ?? domain }];
      }),
    [parts],
  );

  if (sources.length === 0) return null;
  return <Sources sources={sources} open={open} onOpenChange={setOpen} />;
}
```

`parts` 会在过滤前读取一次并进行记忆化，因为当选择器本身返回新数组时，`useAuiState` 会在每次 store 更新时重新渲染。`MessageSources` 必须渲染在消息作用域内，并放置在助手消息中的 `MessagePrimitive.Parts` 之后。

</RuntimeMode>

<StandaloneMode>

单独使用时，该元素完全受控：由你持有来源列表并控制面板是否打开。

```tsx title="app/answer.tsx"
"use client";

import { useState } from "react";
import { Sources, type Source } from "@/components/assistant-ui/elements/sources";

const SOURCES: Source[] = [
  { domain: "assistant-ui.com", title: "Runtime drafts API" },
  { domain: "react.dev", title: "You might not need an effect" },
];

export function Citations() {
  const [open, setOpen] = useState(false);
  return <Sources sources={SOURCES} open={open} onOpenChange={setOpen} />;
}
```

</StandaloneMode>

元素内部没有任何逻辑会打开或关闭面板：由 `open` 和 `onOpenChange` 完成。无论面板是否打开，触发器中的计数始终显示 `sources.length`；空的 `sources` 数组会使触发器显示“0”，面板打开后则显示空网格。

### Sources 组件

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `sources` | `readonly Source[]` | 必填 | 完整的来源列表。 |
| `open` | `boolean` | 必填 | 卡片网格是否展开。 |
| `onOpenChange` | `(open: boolean) => void` | 必填 | 点击触发器时调用。 |
| `className` | `string` | | 合并到根元素上。 |

`Source` 是 `{ domain: string; title: string }`。与此目录中的大多数元素不同，该 `Sources` 不会将额外属性展开到根元素上：只有上面的四个属性会传递给它。
