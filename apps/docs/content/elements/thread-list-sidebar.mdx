---
title: "线程列表侧边栏"
description: "一个完整的侧边栏外壳，将运行时线程列表置于活动会话旁边。"
---

线程列表侧边栏将运行时的[线程列表](/elements/thread-list)包装在一个完整的可折叠侧边栏外壳中：包含页眉、页脚，以及用于折叠侧边栏的可选轨道。它没有独立形式，因为它会在内部渲染仅限运行时的线程列表，并将其他所有属性直接传递给底层的 `Sidebar` 外壳。

## 开始使用

<RuntimeMode>

`ThreadListSidebar` 周围需要一个运行时提供程序和侧边栏外壳自身的布局提供程序。

<Steps>
  <Step>

### 与 Thread 组合使用

```tsx title="app/layout.tsx"
import { SidebarInset, SidebarProvider } from "@/components/ui/sidebar";
import { ThreadListSidebar } from "@/components/assistant-ui/elements/threadlist-sidebar.aui";
import { Thread } from "@/components/assistant-ui/elements/thread.aui";

export default function Layout() {
  return (
    <SidebarProvider>
      <ThreadListSidebar />
      <SidebarInset>
        <Thread />
      </SidebarInset>
    </SidebarProvider>
  );
}
```

整个树的外层需要一个 `AssistantRuntimeProvider` 祖先。`SidebarProvider` 是侧边栏外壳自身的布局上下文，与运行时无关；两者都是必需的。

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

线程列表侧边栏没有独立形式：它会在内部渲染仅限运行时的线程列表，并且没有用于替换为静态线程列表的属性。对于非运行时侧边栏，请自行围绕[线程列表](/elements/thread-list)的独立区域组合 `Sidebar`。

</StandaloneMode>

## 结构

```tsx
<Sidebar {...props}>
  <SidebarHeader>{/* assistant-ui wordmark, links out */}</SidebarHeader>
  <SidebarContent>
    <ThreadList />
  </SidebarContent>
  {props.collapsible !== "none" && <SidebarRail />}
  <SidebarFooter>{/* GitHub link */}</SidebarFooter>
</Sidebar>
```

页眉链接到 assistant-ui.com，页脚链接到其 GitHub 仓库；两者都是占位内容， intended to be replaced with your own branding and support links. 折叠轨道仅在 `collapsible` 不为 `"none"` 时渲染，并遵循 `Sidebar` 自身接收到的设置。

## 示例

### 更改折叠行为

```tsx
<ThreadListSidebar collapsible="icon" />
```

每个 `Sidebar` 属性都会直接传递，包括 `collapsible`、`side` 和 `variant`，因为 `ThreadListSidebar` 只是在它们之间添加页眉、页脚和线程列表。

### 替换页眉和页脚品牌内容

`ThreadListSidebar` 不会将页眉或页脚内容作为属性公开。请将 `threadlist-sidebar.aui.tsx` 副本中的字面链接替换为你自己的产品名称和支持链接。

### 添加打开侧边栏的触发器

```tsx
import { SidebarTrigger } from "@/components/ui/sidebar";

<SidebarTrigger />;
```

将其放置在 `SidebarInset` 内、主面板一侧，即可从应用中的任意位置切换侧边栏。

## API 参考

<RuntimeMode>

### ThreadListSidebarProps

扩展 `React.ComponentProps<typeof Sidebar>`；所有属性都会被传递。

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `side` | `"left" \| "right"` | `"left"` | 侧边栏停靠在哪一侧。 |
| `variant` | `"sidebar" \| "floating" \| "inset"` | `"sidebar"` | 侧边栏外观样式。 |
| `collapsible` | `"offcanvas" \| "icon" \| "none"` | `"offcanvas"` | 侧边栏的折叠方式。`"none"` 还会移除轨道。 |

</RuntimeMode>
