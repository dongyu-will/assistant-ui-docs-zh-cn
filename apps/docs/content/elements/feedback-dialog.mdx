description: "一个会询问原因的点踩，让反馈信号附带具体理由。"

FeedbackDialog 会将点踩转换为简短表单：选择哪里出了问题，添加可选备注，然后发送。在运行时中，二元评分会通过 `submitFeedback` 传递到线程；单独使用时，选择、备注以及提交后的行为都由你负责。

## 快速开始

<RuntimeMode>

assistant-ui 自带的反馈信号是二元的：正面或负面，并记录在消息上。`ActionBarPrimitive.FeedbackNegative` 已经可以通过一次点击提交该信号。FeedbackDialog 会先询问原因，因此它位于该信号之前，而不是替代它：将二元评分保留给运行时，原因和备注则由你自行传递。

  <Step>

### 从触发器打开面板

打开状态由单独的触发器管理。`FeedbackDialog` 本身没有 `open` prop；挂载后，它始终会渲染表单（或确认信息）。

```tsx title="components/assistant-ui/elements/message-feedback.tsx"
"use client";

import { useState } from "react";
import { useAui } from "@assistant-ui/react";
import { FeedbackDialog } from "@/components/assistant-ui/elements/feedback-dialog";

const REASONS = [
  "Not factual",
  "Didn't follow instructions",
  "Too long",
  "Unsafe",
] as const;

export function MessageFeedback() {
  const aui = useAui();
  const [open, setOpen] = useState(false);
  const [selected, setSelected] = useState<string[]>([]);
  const [note, setNote] = useState("");
  const [sent, setSent] = useState(false);

  if (!open) {
    return (
      <button type="button" onClick={() => setOpen(true)}>
        Report an issue
      </button>
    );
  }

  return (
    <FeedbackDialog
      reasons={REASONS}
      selected={selected}
      note={note}
      sent={sent}
      onToggleReason={(reason) =>
        setSelected((current) =>
          current.includes(reason)
            ? current.filter((item) => item !== reason)
            : [...current, reason],
        )
      }
      onNoteChange={setNote}
      onSubmit={() => {
        aui.message.submitFeedback({ type: "negative" });
        setSent(true);
      }}
    />
  );
}
```

  </Step>
  <Step>

### 注册二元信号的接收位置

`submitFeedback` 会传递到你在运行时上注册的 `FeedbackAdapter`。它的 `submit` 只会接收消息和类型，不会接收原因或备注，因此如果你想保留这些信息，就需要为它们设置独立的传输层。

```tsx title="app/assistant.tsx"
import { useLocalRuntime } from "@assistant-ui/react";

const runtime = useLocalRuntime(adapter, {
  adapters: {
    feedback: {
      submit: ({ message, type }) => {
        fetch("/api/feedback", {
          method: "POST",
          body: JSON.stringify({ messageId: message.id, type }),
        });
      },
    },
  },
});
```

可以在同一个请求中从 `onSubmit` 发送 `selected` 和 `note`，也可以单独发送；适配器契约本身没有用于承载这些字段的位置。

  </Step>
</Steps>

</RuntimeMode>

单独使用时，FeedbackDialog 完全受控：你需要持有 `selected`、`note` 和 `sent`，并且 `onSubmit` 不接收任何参数，因此它会读取你自己的状态，而不是接收载荷。

### 保存表单状态

```tsx title="app/answer.tsx"
"use client";

import { useState } from "react";
import { FeedbackDialog } from "@/components/assistant-ui/elements/feedback-dialog";

const REASONS = ["Not factual", "Didn't follow instructions", "Too long", "Unsafe"];

export function AnswerFeedback() {
  const [selected, setSelected] = useState<string[]>([]);
  const [note, setNote] = useState("");
  const [sent, setSent] = useState(false);

  return (
    <FeedbackDialog
      reasons={REASONS}
      selected={selected}
      note={note}
      sent={sent}
      onToggleReason={(reason) =>
        setSelected((current) =>
          current.includes(reason)
            ? current.filter((item) => item !== reason)
            : [...current, reason],
        )
      }
      onNoteChange={setNote}
      onSubmit={() => sendFeedback({ selected, note })}
    />
  );
}
```

### 发送并切换 `sent`

```tsx
async function sendFeedback(payload: { selected: string[]; note: string }) {
  await fetch("/api/feedback", { method: "POST", body: JSON.stringify(payload) });
  setSent(true);
}
```

## 组成

```tsx
<div data-slot="feedback-dialog">
  <div role="status">{/* mounted in both states, so a screen reader catches "sent" the instant it flips */}</div>
  {/* not sent: a header, wrapped reason toggle pills, a note textarea, a submit button */}
  {/* sent: the form is gone; only the confirmation line remains */}
</div>
```

各个原因可以独立切换，构成多选项（`aria-pressed`，可以同时激活任意数量）；没有最低选择数量。`sent` 为 true 后，表单会完全消失，因此如果要再次打开并提交第二份反馈，就需要重新挂载，并将 `sent` 恢复为 `false`。live region 在变化前后都存在于树中，而不是随变化一起创建，这使辅助技术能够可靠地播报确认信息。

## 示例

### 发送后自动重置

在发送几秒后清除 `sent`、`selected` 和 `note`，可以让同一个触发器下次打开全新的表单，与确认信息本身较短的生命周期保持一致：

```tsx
useEffect(() => {
  if (!sent) return;
  const id = setTimeout(() => {
    setSent(false);
    setSelected([]);
    setNote("");
  }, 2600);
  return () => clearTimeout(id);
}, [sent]);
```

### 在服务器上接收反馈

<RuntimeMode>

外部状态存储运行时采用与 `useLocalRuntime` 相同的 `feedback` 适配器形式：

```tsx
import { useExternalStoreRuntime } from "@assistant-ui/react";

const runtime = useExternalStoreRuntime({
  // ...messages, onNew, isRunning, etc.
  adapters: {
    feedback: {
      submit: ({ message, type }) => api.rateMessage(message.id, type),
    },
  },
});
```

如果没有注册适配器，`submitFeedback` 仍会在本地更新 `message.metadata.submittedFeedback`，因此即使你完全没有接入服务器端，`ActionBarPrimitive.FeedbackNegative` 的按下状态仍然正确。

</RuntimeMode>

### 重新设置面板样式

两种方式都会在根元素上接收 `className`。胶囊按钮、文本区域和提交按钮会从 `surfaces.tsx` 读取共享的 `field`、`inkButton` 和 `mono` 表面样式，因此重新设置这些设计令牌的颜色后，所有使用它们的元素都会同步变色。

```tsx
<FeedbackDialog className="max-w-md" /* ... */ />
```

## API 参考

<RuntimeMode>

### 消息状态

| 选择器 | 类型 | 描述 |
|----------|------|-------------|
| `s.message.metadata.submittedFeedback` | `{ type: "positive" \| "negative" } \| undefined` | 此消息已经记录的评分（如果有）。 |
| `aui.message.submitFeedback(feedback)` | `(feedback: { type: "positive" \| "negative" }) => void` | 在消息上记录评分，并调用已注册的 `FeedbackAdapter`。 |

### FeedbackAdapter

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `submit` | `(feedback: { message: ThreadMessage; type: "positive" \| "negative" }) => void` | 每个 `submitFeedback` 调用一次。在 `useLocalRuntime` 或外部状态存储运行时上，将其注册到 `adapters.feedback` 下。只携带消息和二元类型。 |

</RuntimeMode>

<StandaloneMode>

### FeedbackDialog

| Prop | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `reasons` | `readonly string[]` | 必填 | 提供的原因胶囊按钮。 |
| `selected` | `readonly string[]` | 必填 | 当前处于按下状态的原因。 |
| `note` | `string` | 必填 | 文本区域的值。 |
| `sent` | `boolean` | 必填 | 为 true 时，将表单替换为确认信息。 |
| `onToggleReason` | `(reason: string) => void` | | 使用按下的原因调用；在 `selected` 中切换成员关系由调用方负责。 |
| `onNoteChange` | `(note: string) => void` | | 使用文本区域的下一个值调用。 |
| `onSubmit` | `() => void` | | 不接收参数调用。从你自己的状态中读取 `selected` 和 `note`。 |
| `className` | `string` | | 合并到根元素上。 |

所有其他 `div` props 都会转发到根元素。

</StandaloneMode>
