文件树会列出一次运行触及的所有内容：顶部显示包含净变更总量的“N 个文件已更改”标题，下面每个文件占一行，按文件夹标题缩进排列，并显示各自新增和删除的行数。在运行时环境中，你需要自行将工具返回的扁平结果映射到文件树；单独使用时，则直接提供这些行。

### 从扁平结果派生文件树

工具结果通常是一个扁平的已触及文件列表。将其分组为文件夹标题和缩进的文件行，然后再传递给该元素：

```tsx title="components/assistant-ui/elements/list-changes-tool-ui.tsx"
"use client";

import type { ToolCallMessagePartComponent } from "@assistant-ui/react";
import { FileTree, type FileTreeNode } from "@/components/assistant-ui/elements/file-tree";

type ChangedFile = { path: string; additions: number; deletions: number };
type ListChangesResult = { files: readonly ChangedFile[] };

function buildFileTree(files: readonly ChangedFile[]): FileTreeNode[] {
  const nodes: FileTreeNode[] = [];
  const seenDirs = new Set<string>();

  for (const file of files) {
    const slash = file.path.lastIndexOf("/");
    const dir = slash === -1 ? "" : file.path.slice(0, slash);
    const name = slash === -1 ? file.path : file.path.slice(slash + 1);

    if (dir && !seenDirs.has(dir)) {
      seenDirs.add(dir);
      nodes.push({ path: dir, name: dir, depth: 0, kind: "folder" });
    }

    nodes.push({
      path: file.path,
      name,
      depth: dir ? 1 : 0,
      kind: "file",
      additions: file.additions,
      deletions: file.deletions,
    });
  }

  return nodes;
}

export const ListChangesToolUI: ToolCallMessagePartComponent<
  Record<string, never>,
  ListChangesResult
> = ({ result }) => {
  if (!result) return null;
  const nodes = buildFileTree(result.files);
  return (
    <FileTree
      nodes={nodes}
      visibleCount={nodes.length}
      totalAdditions={result.files.reduce((n, f) => n + f.additions, 0)}
      totalDeletions={result.files.reduce((n, f) => n + f.deletions, 0)}
    />
  );
};
```

  </Step>

import { FileTree, type FileTreeNode } from "@/components/assistant-ui/elements/file-tree";

const NODES: readonly FileTreeNode[] = [

### 随时间显示行

按计时器逐步增加 `visibleCount`，让文件行逐渐淡入，就像一次运行仍在持续发现文件：

```tsx
const [visibleCount, setVisibleCount] = useState(0);

useEffect(() => {
  if (visibleCount >= NODES.length) return;
  const id = setTimeout(() => setVisibleCount((n) => n + 1), 420);
  return () => clearTimeout(id);
}, [visibleCount]);
```

## 结构

```tsx
<div data-slot="file-tree">
  <div>{/* "N files changed", total +additions and −deletions */}</div>
  <div>{/* one row per visible node, indented by depth × 0.85rem */}</div>
</div>
```

`path` 仅用作 React key；行的位置不会从中派生。`depth` 和 `kind` 是你需要自行分配给每个节点的独立字段，因此文件夹行是静态、不可交互的标题，从来不是真正的父节点，也不会折叠其下的行。“N 个文件已更改”的计数只统计 `kind: "file"` 节点，因此文件夹标题不会使计数虚高。当文件自身的新增或删除字段为 `undefined` 时，会省略相应徽标，而不是显示为零；标题中的总数始终会渲染，即使为零。

## 示例

### 重新设置文件树样式

两条轨道都会在根节点上使用 `className`。卡片表面和计数徽标来自 `surfaces.tsx` 中共享的 `paper` 和 `mono` 令牌。

```tsx
<FileTree className="max-w-none" /* ... */ />
```

### 没有文件夹的文件

由于 `depth` 和 `kind` 在每个节点上彼此独立，文件可以直接位于根节点下，上方没有文件夹标题。这就是目录自身的预览中显示类似 changeset 条目的独立文件时所采用的方式：

```tsx
{ path: "changeset", name: ".changeset/tidy-pans.md", depth: 0, kind: "file", additions: 5 }
```

### 工具已经返回文件树时

如果工具结果已经包含预先构造好的节点，可以完全跳过 `buildFileTree`：

```tsx
export const ListChangesToolUI: ToolCallMessagePartComponent<
  Record<string, never>,
  { files: readonly FileTreeNode[]; additions: number; deletions: number }
> = ({ result }) =>
  result ? (
    <FileTree
      nodes={result.files}
      visibleCount={result.files.length}
      totalAdditions={result.additions}
      totalDeletions={result.deletions}
    />
  ) : null;
```

## API 参考

<RuntimeMode>

### 工具调用渲染属性

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `result` | `{ files: readonly ChangedFile[] } \| undefined` | 调用完成后，已触及文件的扁平列表。 |

没有内置的路径到文件树辅助工具：请像上面的 `buildFileTree` 一样，自行将扁平列表映射为 `FileTreeNode[]`，或者让工具直接返回预先构造好的节点。完整的渲染属性说明请参阅 [工具 UI](/docs/tools/tool-ui)。

</RuntimeMode>

<StandaloneMode>

### FileTree

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `nodes` | `readonly FileTreeNode[]` | 必填 | 按顺序排列的完整行列表。 |
| `visibleCount` | `number` | 必填 | 要渲染的行数，从 `nodes` 的开头开始计算。 |
| `totalAdditions` | `number` | 必填 | 标题中的绿色计数。 |
| `totalDeletions` | `number` | 必填 | 标题中的红色计数。 |
| `className` | `string` | | 合并到根节点。 |

`FileTreeNode` 是 `{ path: string; name: string; depth: number; kind: "folder" | "file"; additions?: number; deletions?: number }`。其他所有 `div` 属性都会转发到根节点。

</StandaloneMode>
