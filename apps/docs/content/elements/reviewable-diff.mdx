---
title: "可审阅差异"
description: "相同的差异，但每个 hunk 都需要做出决定：保留、丢弃，或应用最终保留下来的内容。"
---

可审阅差异会将补丁拆分为多个 hunk，并要求对每个 hunk 做出决定：保留还是丢弃。同时显示实时计数，并提供一个应用按钮；只有每个 hunk 都得到答复后，该按钮才会启用。在运行时中，这是一个人在回路工具：模型提出各个 hunk，然后暂停等待决定。在独立使用时，则由你提供 hunk 并自行管理这些决定。

## 开始使用

<RuntimeMode>

补丁审阅没有自动结果，因此会注册为人工工具：不存在 `execute`，只有渲染器调用 `addResult` 后，工具调用才会解析。

### 渲染工具调用

```tsx title="components/assistant-ui/elements/review-patch-tool-ui.tsx"
"use client";

import { useState } from "react";
import type { ToolCallMessagePartComponent } from "@assistant-ui/react";
import {
  ReviewableDiff,
  type DiffHunk,
  type HunkDecision,
} from "@/components/assistant-ui/elements/reviewable-diff";

type ReviewPatchArgs = {
  filename: string;
  hunks: readonly Omit<DiffHunk, "decision">[];
};
type ReviewPatchResult = { kept: readonly string[] };

export const ReviewPatchToolUI: ToolCallMessagePartComponent<
  ReviewPatchArgs,
  ReviewPatchResult
> = ({ args, result, addResult }) => {
  const [decisions, setDecisions] = useState<Record<string, HunkDecision>>({});

  if (result) {
    return (
      <p>
        Applied {result.kept.length} of {args.hunks.length} hunks to {args.filename}.
      </p>
    );
  }

  const hunks: DiffHunk[] = args.hunks.map((hunk) => ({
    ...hunk,
    decision: decisions[hunk.id] ?? "pending",
  }));

  return (
    <ReviewableDiff
      filename={args.filename}
      hunks={hunks}
      onKeep={(id) => setDecisions((d) => ({ ...d, [id]: "kept" }))}
      onDiscard={(id) => setDecisions((d) => ({ ...d, [id]: "discarded" }))}
      onApply={() =>
        addResult({
          kept: hunks.filter((h) => h.decision === "kept").map((h) => h.id),
        })
      }
    />
  );
};
```

### 保存决定

```tsx title="app/patch-review.tsx"
"use client";

import { useState } from "react";
import {
  ReviewableDiff,
  type DiffHunk,
  type HunkDecision,
} from "@/components/assistant-ui/elements/reviewable-diff";

const HUNKS: readonly Omit<DiffHunk, "decision">[] = [
  {
    id: "h1",
    range: "@@ -12,6 +12,7",
    lines: [
      { kind: "context", text: "  const composer = useComposer();" },
      { kind: "removed", text: '  const [draft, setDraft] = useState("");' },
      { kind: "added", text: "  const draft = useDraft(threadId);" },
    ],
  },
];

export function PatchReview() {
  const [decisions, setDecisions] = useState<Record<string, HunkDecision>>({});
  const hunks: DiffHunk[] = HUNKS.map((hunk) => ({
    ...hunk,
    decision: decisions[hunk.id] ?? "pending",
  }));

  return (
    <ReviewableDiff
      filename="composer.tsx"
      hunks={hunks}
      onKeep={(id) => setDecisions((d) => ({ ...d, [id]: "kept" }))}
      onDiscard={(id) => setDecisions((d) => ({ ...d, [id]: "discarded" }))}
      onApply={() => applyPatch(hunks.filter((h) => h.decision === "kept"))}
    />
  );
}
```

  </Step>

### 应用保留的 hunk

`onApply` 只会调用一次，此时每个 hunk 仍可读取其当前的 `decision`。元素本身不会提交或清除状态，因此处理函数需要同时负责：

```tsx
async function applyPatch(kept: readonly DiffHunk[]) {
  await fetch("/api/patch", {
    method: "POST",
    body: JSON.stringify({ hunkIds: kept.map((h) => h.id) }),
  });
  setDecisions({});
}
```

## 结构

```tsx
<div data-slot="reviewable-diff">
  <div>{/* filename, "N of M kept" */}</div>
  <div>
    {/* one block per hunk: range, then Discard/Keep while pending, else the decision label; the diff lines dim once discarded but stay visible */}
  </div>
  <div>{/* "N left to review" or "All reviewed"; an Apply button disabled while any hunk is pending */}</div>
</div>
```

`kept` 和 `pending` 始终通过统计 `hunks` 得出，而不会单独存储，因此无论你传入哪些 `decision` 值，页眉和页脚都会保持同步。`onKeep`、`onDiscard` 和 `onApply` 都是可选的：只传入你需要的属性，相应控件仍会渲染，但按下时不会调用任何内容。

## 示例

### 重新设置审阅样式

两条通道都会在根元素上接收 `className`。卡片表面样式来自 `paper`，Apply 按钮样式来自 `inkButton`，二者都位于 `surfaces.tsx` 中。

```tsx
<ReviewableDiff className="max-w-none" /* ... */ />
```

### 无需审阅的内容

空的 `hunks` 数组也是有效的：页眉显示“已保留 0/0”，由于没有待处理项，页脚显示“全部已审阅”，Apply 显示“应用 0”且保持启用状态。

```tsx
<ReviewableDiff filename="composer.tsx" hunks={[]} />
```

### 一次性全部丢弃

两条通道都将 `decisions` 作为本地状态保存，因此无论该状态位于何处，全部拒绝控件都只需同样的一行代码：

```tsx
function discardAll() {
  setDecisions(Object.fromEntries(hunks.map((h) => [h.id, "discarded"])));
}
```

## API 参考

<RuntimeMode>

### 工具调用渲染属性

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `args` | `{ filename: string; hunks: readonly Omit<DiffHunk, "decision">[] }` | 模型正在提出的文件名和未审阅 hunk。 |
| `result` | `{ kept: readonly string[] } \| undefined` | `addResult` 调用后设置；用户保留的 hunk ID。 |
| `addResult` | `(result: ReviewPatchResult) => void` | 用户决定每个 hunk 后调用一次，以解析工具调用。 |

如需了解完整的渲染属性接口和人工工具注册方式，请参阅[工具 UI](/docs/tools/tool-ui)。

</RuntimeMode>

<StandaloneMode>

### ReviewableDiff

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `filename` | `string` | 必需 | 显示在页眉中。 |
| `hunks` | `readonly DiffHunk[]` | 必需 | 按顺序排列的 hunk，每个 hunk 都包含自己的 `decision`。 |
| `onKeep` | `(id: string) => void` | | 待处理 hunk 的 Keep 按钮按下时调用。 |
| `onDiscard` | `(id: string) => void` | | 待处理 hunk 的 Discard 按钮按下时调用。 |
| `onApply` | `() => void` | | Apply 按钮按下时调用。任何 hunk 仍为 `"pending"` 时禁用。 |
| `className` | `string` | | 合并到根元素上。 |

`DiffHunk` 是 `{ id: string; range: string; decision: HunkDecision; lines: readonly DiffLine[] }`，而 `HunkDecision` 是 `"pending" | "kept" | "discarded"`。所有其他 `div` 属性都会转发到根元素。

</StandaloneMode>
