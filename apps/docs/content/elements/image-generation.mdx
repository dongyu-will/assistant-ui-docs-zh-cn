图像生成会为尚未到达的图像固定画面：生成过程中显示覆盖在模糊渐变上的脉动点阵，完成后则稳定为清晰渐变。使用运行时（runtime）时，它会跟踪工具调用（tool call）的状态；独立使用时，则由你自行驱动 `prompt` 和 `generating`。

## 入门

<RuntimeMode>

图像工具通过其自身的工具包条目进行渲染：模型的提示词作为 `args` 传入，调用的生命周期则作为 `status` 传入。

<Steps>
  <Step>

### 定义图像工具包

```tsx title="app/toolkit.tsx"
"use generative";

import { defineToolkit, externalTool } from "@assistant-ui/react";
import { ImageGeneration } from "@/components/assistant-ui/elements/image-generation";

export default defineToolkit({
  generate_image: {
    execute: externalTool(),
    render: ({ args, status }) => (
      <ImageGeneration
        prompt={args.prompt ?? ""}
        generating={status.type === "running"}
      />
    ),
  },
});
```

`execute: externalTool()` 标记由后端路由或图像提供商运行的工具，而不是由浏览器运行的工具：编译器会将其从客户端 bundle 中移除，只保留 `render`。

  </Step>
  <Step>

### 注册工具包

```tsx title="app/MyRuntimeProvider.tsx"
"use client";

import { AssistantRuntimeProvider, AuiConfig, Tools } from "@assistant-ui/react";
import { useChatRuntime } from "@assistant-ui/ai-sdk";
import { Thread } from "@/components/assistant-ui/elements/thread.aui";
import toolkit from "./toolkit";

export function App() {
  const runtime = useChatRuntime();
  const config = AuiConfig({ tools: Tools({ toolkit }) });

  return (
    <AssistantRuntimeProvider runtime={runtime} config={config}>
      <Thread />
    </AssistantRuntimeProvider>
  );
}
```

线程中的每个 `generate_image` 工具调用现在都会渲染为此元素，无论 `MessagePrimitive.Parts` 将其放置在助手回复中的什么位置。

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

独立使用时，`ImageGeneration` 完全由你控制：提示词以及生成是否正在进行都由你管理。

<Steps>
  <Step>

### 保存生成状态

```tsx title="app/answer.tsx"
"use client";

import { useState } from "react";
import { ImageGeneration } from "@/components/assistant-ui/elements/image-generation";

export function Generation() {
  const [generating, setGenerating] = useState(true);

  return (
    <ImageGeneration
      prompt="A calm mountain lake at dawn"
      generating={generating}
    />
  );
}
```

  </Step>
  <Step>

### 生成完成后将其关闭

`ImageGeneration` 永远不会接收生成结果的 URL，因此请单独保存该 URL，并在其到达后替换为真正的图像渲染器：

```tsx
const [imageUrl, setImageUrl] = useState<string | null>(null);

useEffect(() => {
  generateImage(prompt).then((url) => {
    setGenerating(false);
    setImageUrl(url);
  });
}, [prompt]);

return imageUrl ? <img src={imageUrl} alt={prompt} /> : (
  <ImageGeneration prompt={prompt} generating={generating} />
);
```

  </Step>
</Steps>

</StandaloneMode>

## 结构

```tsx
<div data-slot="image-generation">
  <div>
    {/* the frame: an 8x8 pulsing dot grid, over a fixed decorative gradient */}
    <span>{/* "1024 × 1024" */}</span>
  </div>
  <div>
    <p>{/* prompt, or a shimmering "Generating" label while generating */}</p>
    <button aria-label="Regenerate image" />
  </div>
</div>
```

该画面永远不会渲染实际生成的图像：点阵背后的渐变是源代码中的固定装饰图形，在两种状态下都会显示，并且只会随着 `generating` 切换而改变模糊度和不透明度。此元素中的任何内容都不接受图像 URL。工具调用解析出真实 URL 后，请将其交给能够接受 URL 的渲染器；参见 [Image](/elements/image) 元素。当 `generating` 为 true 时，点阵中的 64 个点会以交错延迟脉动；变为 false 后，它们会淡出至完全透明。生成过程中，重新生成按钮会淡出并停止接收指针事件，但源代码中没有 `onClick`：直接编辑已安装的文件为其接入处理器，方式与其他由你维护源码的元素相同。

## 示例

### 为重新生成按钮接入处理器

该按钮存在于 DOM 中，但源代码没有为它设置处理器。安装元素时，在相应位置添加处理器：

```tsx
<button
  type="button"
  aria-label="Regenerate image"
  onClick={() => regenerate(prompt)}
  className={cn(ghostButton, "size-6 shrink-0", generating && "pointer-events-none opacity-0")}
>
  <RefreshCwIcon className="size-3" />
</button>
```

### 重新设置画面样式

两条布局轨道都会在根元素上接收 `className`。“1024 × 1024”标签和提示词行使用来自 `surfaces.tsx` 的 `mono` 和 `ShimmerLabel`。

```tsx
<ImageGeneration className="w-64" /* ... */ />
```

## API 参考

<RuntimeMode>

### 工具渲染属性

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `args` | `{ prompt?: string }` | 模型提供的参数。流式传输期间可能不完整。 |
| `status.type` | `"running" \| "complete" \| "incomplete" \| "requires-action"` | 调用的生命周期。只有 `"running"` 状态应显示生成中的点阵。 |

有关完整的工具调用部分结构，请参见 [工具 UI](/docs/tools/tool-ui)。

</RuntimeMode>

<StandaloneMode>

### ImageGeneration

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `prompt` | `string` | 必填 | 生成完成后显示在画面下方。 |
| `generating` | `boolean` | 必填 | 为 true 时显示脉动点阵、模糊渐变和闪烁的提示词标签。 |
| `className` | `string` | | 合并到根元素上。 |

所有其他 `div` 属性都会转发到根元素。

</StandaloneMode>
