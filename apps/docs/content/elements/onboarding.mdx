一个简短、可关闭的引导流程：一次显示一个步骤，每个步骤包含一行正文和一个完整示例；每个步骤对应一个进度圆点，并在“下一步”旁边提供“跳过”选项。使用运行时（runtime）时，唯一值得接入的是引导结束后要发生什么；单独使用时，每次转换都是由你控制的回调。

## 开始使用

<RuntimeMode>

步骤本身、步骤文案及其顺序都由你编写，是内容而不是运行时所持有的状态；这里无需从 `useAuiState` 读取任何内容。真正需要接入的地方只有“跳过”和最后一步的“下一步”实际执行的操作：将控制权交给线程。

### 引导结束后将控制权交给线程

```tsx title="components/assistant-ui/elements/first-run.tsx"
"use client";

import { useState } from "react";
import { useAui } from "@assistant-ui/react";
import {
  Onboarding,
  type OnboardingStep,
} from "@/components/assistant-ui/elements/onboarding";

const STEPS: OnboardingStep[] = [
  { title: "Ask anything", body: "Type a question, it answers in place.", example: "Summarize this PDF" },
  { title: "It can act, not just answer", body: "Grant a tool and it can search, run code, or call your API.", example: "Check the weather in Tokyo" },
  { title: "Every answer is a branch", body: "Regenerating never loses the original; step between versions.", example: "n / m stepper on any reply" },
];

export function FirstRun({ onFinish }: { onFinish: () => void }) {
  const aui = useAui();
  const [index, setIndex] = useState(0);
  const last = index >= STEPS.length - 1;

  const finish = () => {
    aui.threads.switchToNewThread();
    onFinish();
  };

  return (
    <Onboarding
      steps={STEPS}
      index={index}
      onNext={() => (last ? finish() : setIndex((i) => i + 1))}
      onSkip={finish}
    />
  );
}
```

只有当你的应用要等引导关闭后再创建线程时，`switchToNewThread()` 才有作用；如果线程和输入框已经存在于遮罩层后方，`finish` 只需调用 `onFinish()`，让它们接管即可。

  </Step>
</Steps>

</RuntimeMode>

### 保存步骤索引

```tsx title="app/tour.tsx"
"use client";

import { useState } from "react";
import {
  Onboarding,
  type OnboardingStep,
} from "@/components/assistant-ui/elements/onboarding";

const steps: OnboardingStep[] = [
  { title: "Welcome", body: "Three quick things before you start.", example: "…" },
  { title: "Ask in plain language", body: "No special syntax needed.", example: "What changed in v4?" },
];

export function Tour({ onDone }: { onDone: () => void }) {
  const [index, setIndex] = useState(0);
  const last = index >= steps.length - 1;

  return (
    <Onboarding
      steps={steps}
      index={index}
      onNext={() => (last ? onDone() : setIndex(index + 1))}
      onSkip={onDone}
    />
  );
}
```

## 组成

```tsx
<div data-slot="onboarding">
  <div>
    {/* keyed on the current step, so it fades in fresh every change */}
    <span>{/* "n of m" */}</span>
    <span>{/* step title */}</span>
    <p>{/* step body */}</p>
    <span>{/* step example */}</span>
  </div>
  <div>
    <span>{/* one dot per step, decorative only */}</span>
    <button>{/* Skip */}</button>
    <button>{/* Next, or Start on the last step */}</button>
  </div>
</div>
```

当步骤数为零时，该元素完全不渲染任何内容，而不是渲染一个空壳；它通过检查 `steps[0]` 是否为 undefined 来判断。使用前，`index` 会向下取整，并限制在 `0…steps.length - 1` 范围内，因此即使值超出该范围或是小数，也仍会解析为一个实际步骤，而不会渲染空白。该元素不负责推进流程：`onNext` 和 `onSkip` 只是纯信号，而不是状态变更，因此在调用方自行更新 `index` 之前，不会有任何推进，正如上面的两个示例所示。进度圆点是 `aria-hidden`，仅用于视觉展示；它们不是按钮，因此用户无法通过点击圆点跳回之前的步骤。

## 示例

### 添加返回方式

由于 `index` 是一个普通的受控属性，而该元素不会推进它，因此添加返回控件与 `onNext` 完全同样有效，尽管内置实现不会渲染返回控件：

```tsx
<button type="button" onClick={() => setIndex((i) => Math.max(0, i - 1))}>
  Back
</button>
```

### 重新设置引导流程样式

两个区域都会在根元素上使用 `className`。示例区块位于 `field` 表面上，最后一个按钮位于 `inkButton` 上，因此重新设置这两个令牌的主题，就能同时覆盖卡片的两个强调色表面。

```tsx
<Onboarding className="max-w-xs" /* ... */ />
```

## API 参考

<RuntimeMode>

该元素没有专用原语；其中唯一涉及的运行时调用是完成引导流程，具体如“开始使用”部分所示。

### 线程

| 方法 | 类型 | 描述 |
|--------|------|-------------|
| `aui.threads.switchToNewThread()` | `() => void` | 选择一个全新的、尚未发送消息的线程作为当前打开的线程。仅当线程创建延迟到入门引导完成后才需要。 |

</RuntimeMode>

<StandaloneMode>

### 入门引导

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `steps` | `readonly OnboardingStep[]` | 必填 | 引导流程中的步骤，按顺序排列。空数组不会渲染任何内容。 |
| `index` | `number` | 必填 | 要显示的步骤。会向下取整，并限制在 `0…steps.length - 1` 范围内。 |
| `onNext` | `() => void` | | 按下“下一步”（在最后一步时为“开始”）时调用。不会自行更改 `index`。 |
| `onSkip` | `() => void` | | 按下“跳过”时调用。 |
| `className` | `string` | | 合并到根元素上。 |

其余所有 `div` 属性都会转发到根元素。

### OnboardingStep

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `title` | `string` | 步骤标题。 |
| `body` | `string` | 一段说明文字。 |
| `example` | `string` | 在正文下方的独立字段中显示的完整示例。 |

</StandaloneMode>
