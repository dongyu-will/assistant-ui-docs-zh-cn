Flow graph 将工作绘制成小型依赖图，而不是扁平列表：节点排列在各列中，曲线边连接相互依赖的节点。在运行时中，你可以根据模型逐步写入的工具调用参数来布局；独立使用时，则由你自行维护节点和边数组。

## 开始使用

<RuntimeMode>

在运行时中，流程图通常对应一个工具调用，其参数描述完整计划：一个步骤列表，其中每个步骤都标明自身依赖的内容。一个小型布局函数会将该列表转换为 `FlowGraph` 所需的列、行和边。

### 根据工具调用布局计划

```tsx title="components/assistant-ui/elements/plan-graph-tool-ui.tsx"
"use client";

import type { ToolCallMessagePartComponent } from "@assistant-ui/react";
import {
  FlowGraph,
  type FlowEdge,
  type FlowNode,
} from "@/components/assistant-ui/elements/flow-graph";

type PlanStep = { id: string; label: string; dependsOn?: string[] };
type PlanArgs = { steps: PlanStep[] };

function layout(steps: PlanStep[], done: boolean) {
  const columnOf = new Map<string, number>();
  const rowsUsed = new Map<number, number>();
  const nodes: FlowNode[] = steps.map((step, index) => {
    const deps = step.dependsOn ?? [];
    const column = deps.length
      ? Math.max(...deps.map((id) => columnOf.get(id) ?? 0)) + 1
      : 0;
    columnOf.set(step.id, column);
    const row = rowsUsed.get(column) ?? 0;
    rowsUsed.set(column, row + 1);
    const state = done || index < steps.length - 1 ? "done" : "active";
    return { id: step.id, label: step.label, column, row, state };
  });
  const edges: FlowEdge[] = steps.flatMap((step) =>
    (step.dependsOn ?? []).map((from) => ({ from, to: step.id })),
  );
  return { nodes, edges };
}

export const PlanGraphToolUI: ToolCallMessagePartComponent<
  PlanArgs,
  unknown
> = ({ args, status }) => {
  const steps = args.steps ?? [];
  if (steps.length === 0) return null;
  const { nodes, edges } = layout(steps, status.type === "complete");
  return <FlowGraph nodes={nodes} edges={edges} visibleCount={nodes.length} />;
};
```

  </Step>

### 持有图

```tsx title="app/plan.tsx"
"use client";

import { useState } from "react";
import {
  FlowGraph,
  type FlowEdge,
  type FlowNode,
} from "@/components/assistant-ui/elements/flow-graph";

const NODES: readonly FlowNode[] = [
  { id: "intake", label: "intake", column: 0, row: 1, state: "done" },
  { id: "plan", label: "plan", column: 1, row: 1, state: "done" },
  { id: "search", label: "search", column: 2, row: 0, state: "done" },
  { id: "patch", label: "patch", column: 2, row: 2, state: "active" },
  { id: "verify", label: "verify", column: 3, row: 1, state: "pending" },
];

const EDGES: readonly FlowEdge[] = [
  { from: "intake", to: "plan" },
  { from: "plan", to: "search" },
  { from: "plan", to: "patch" },
  { from: "search", to: "verify" },
  { from: "patch", to: "verify" },
];

export function Plan() {
  const [visibleCount, setVisibleCount] = useState(NODES.length);
  return <FlowGraph nodes={NODES} edges={EDGES} visibleCount={visibleCount} />;
}
```

## 结构

```tsx
<div data-slot="flow-graph">
  <svg>{/* one curved path per edge */}</svg>
  <div>{/* one absolutely positioned node per visible node, fading and scaling in */}</div>
</div>
```

`visibleCount` 从数组开头截取 `nodes`。只有当边的 `from` 和 `to` id 都位于该切片中时，边才会以明亮描边绘制；否则会显示为较浅的描边。若边引用的 id 不在 `nodes` 中，则会完全跳过该边。`state` 控制每个节点的边框和填充：`"done"` 是低调的实心框，`"active"` 是蓝色轮廓，`"pending"` 是带虚线且颜色更暗的框。

## 示例

### 定位节点

`column` 和 `row` 是由你选择的网格坐标，而不是从 `edges` 推导出来的；两个节点可以位于同一列，图不会替你尝试避免重叠。

```tsx
{ id: "search", label: "search", column: 2, row: 0, state: "done" },
{ id: "patch", label: "patch", column: 2, row: 2, state: "active" },
```

### 重新设置图的样式

两个泳道都会在根元素上接收 `className`。节点标签读取共享的 `mono` 令牌，根元素读取 `paper`，二者都来自 `surfaces.tsx`。

```tsx
<FlowGraph className="max-w-none" /* ... */ />
```

## API 参考

<RuntimeMode>

### 工具调用渲染属性

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `args` | `TArgs` | 解析后的参数。模型仍在流式传输参数时，该值可能不完整。 |
| `argsText` | `string` | 模型流式传输的原始 JSON 参数文本。 |
| `result` | `TResult \| undefined` | 工具完成后返回的值。运行过程中为 `undefined`。 |
| `status` | `ToolCallMessagePartStatus` | `status.type` 为 `"running"`、`"requires-action"`、`"complete"` 或 `"incomplete"`。 |
| `toolName` | `string` | 模型调用的工具名称。 |
| `toolCallId` | `string` | 此次调用的稳定 id。 |
| `isError` | `boolean \| undefined` | `result` 是否表示工具执行错误。 |

没有专用的计划转图原语：上面的 `layout` 是由你编写的普通函数，用于将工具参数的任意形状转换为 `FlowGraph` 所需的 `FlowNode[]` 和 `FlowEdge[]`。在工具包条目的 `render` 字段上注册渲染器，并使用 `Tools({ toolkit })` 附加工具包。有关完整的渲染属性接口，请参阅[工具 UI](/docs/tools/tool-ui)。

</RuntimeMode>

<StandaloneMode>

### FlowGraph

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `nodes` | `readonly FlowNode[]` | 必需 | 图中的每个节点，以及各自的布局位置。 |
| `edges` | `readonly FlowEdge[]` | 必需 | 节点 id 之间的连接。 |
| `visibleCount` | `number` | 必需 | 要显示 `nodes` 开头的多少个节点。 |
| `className` | `string` | | 合并到根元素上。 |

`FlowNode` 是 `{ id: string; label: string; column: number; row: number; state: "done" | "active" | "pending" }`。`FlowEdge` 是 `{ from: string; to: string }`，引用节点 id。所有其他 `div` 属性都会转发到根元素。

</StandaloneMode>
