title: "恢复草稿"
description: "回到一个会话线程时，您从未发送的句子仍在等待发送。"
---

一个可关闭的横幅，用于将未发送的消息放回输入框，并在下方显示消息上次编辑的时间。使用运行时（runtime）时，您可以决定何时对输入框文本进行快照，以及何时重新显示它；单独使用时，则由您自行保存草稿和时间戳并传入。

## 开始使用

<RuntimeMode>

使用运行时时，重新加载默认不会保留未发送的输入框文本：如果会话线程的运行时不具备原地重新获取能力，重新加载时其 hook 会重新挂载，从而丢弃仍在输入的内容。跨越这一间隔恢复草稿属于应用层工作，并建立在输入框自身的文本状态之上。

  <Step>

### 随输入保存草稿

读取实时文本并将其写入您自己的存储中，以会话线程为键，并进行防抖处理，避免每次按键都写入磁盘。

```tsx title="components/assistant-ui/elements/use-draft-persistence.ts"
"use client";

import { useAuiState } from "@assistant-ui/react";
import { useEffect, useRef } from "react";

function saveDraft(threadId: string, text: string) {
  if (text) localStorage.setItem(`draft:${threadId}`, text);
  else localStorage.removeItem(`draft:${threadId}`);
}

export function useDraftPersistence(threadId: string) {
  const text = useAuiState((s) => s.composer.text);
  const timer = useRef<ReturnType<typeof setTimeout> | undefined>(undefined);

  useEffect(() => {
    clearTimeout(timer.current);
    timer.current = setTimeout(() => saveDraft(threadId, text), 400);
    return () => clearTimeout(timer.current);
  }, [threadId, text]);
}
```

  </Step>
  <Step>

### 恢复或丢弃草稿

挂载时，读取当前会话线程保存的草稿，并在输入框仍为空时显示横幅。恢复操作会将草稿写回实时输入框；丢弃操作只需清除存储，因为组件本身不持有任何状态。

```tsx title="components/assistant-ui/elements/draft-restore-banner.tsx"
"use client";

import { useAui } from "@assistant-ui/react";
import { DraftRestore } from "@/components/assistant-ui/elements/draft-restore";

export function DraftRestoreBanner({
  threadId,
  draft,
  savedAt,
  onDismiss,
}: {
  threadId: string;
  draft: string;
  savedAt: string;
  onDismiss: () => void;
}) {
  const aui = useAui();
  return (
    <DraftRestore
      draft={draft}
      savedAt={savedAt}
      onRestore={() => {
        aui.composer.setText(draft);
        localStorage.removeItem(`draft:${threadId}`);
        onDismiss();
      }}
      onDiscard={() => {
        localStorage.removeItem(`draft:${threadId}`);
        onDismiss();
      }}
    />
  );
}
```

  </Step>
</Steps>

单独使用时，`DraftRestore` 仅负责展示：它不会计算时间，也不会监听输入，因此 `savedAt` 需要传入预先格式化的值，而 `onRestore`/`onDiscard` 是触发任何操作的唯一方式。

### 保存草稿并连接回调

```tsx title="app/thread.tsx"
"use client";

import { useState } from "react";
import { DraftRestore } from "@/components/assistant-ui/elements/draft-restore";

export function ThreadDraftBanner({
  onRestore,
}: {
  onRestore: (text: string) => void;
}) {
  const [draft, setDraft] = useState<string | null>(
    "Add a regression test for draft restore",
  );

  if (!draft) return null;

  return (
    <DraftRestore
      draft={draft}
      savedAt="2 minutes ago"
      onRestore={() => {
        onRestore(draft);
        setDraft(null);
      }}
      onDiscard={() => setDraft(null)}
    />
  );
}
```

## 组成

```tsx
<div data-slot="draft-restore">
  <svg /* pencil icon */ />
  <div>
    <span>{/* draft, truncated to one line */}</span>
    <span>{/* unsent draft · savedAt */}</span>
  </div>
  <button>Restore</button>
  <button aria-label="Discard the draft">{/* x icon */}</button>
</div>
```

横幅本身没有可见性状态：只要挂载就会渲染，何时挂载由调用方决定。通常，调用方会在 `onRestore` 和 `onDiscard` 中清除保存的草稿，使横幅在任一选择后卸载。`draft` 使用 CSS 截断，不会进行测量或自动换行；`savedAt` 则会完全按照传入的内容显示。

## 示例

### 重新设置横幅样式

`className` 会合并到根元素上；Discard 按钮会复用共享的 `ghostButton` 表面，因此重新设置该令牌的样式，就会同时重新设置 kit 中所有仅包含图标的按钮。

```tsx
<DraftRestore className="max-w-md" draft={draft} savedAt={savedAt} onRestore={restore} onDiscard={discard} />
```

### 命名时间戳

该元素不会计算相对时间。使用您在其他位置已经采用的方式进行格式化，可以是原生的 `Intl.RelativeTimeFormat` 调用，也可以使用库。

```tsx
const savedAt = new Intl.RelativeTimeFormat("en", { numeric: "auto" }).format(-2, "minute");
```

## API 参考

<RuntimeMode>

### 输入框状态

| 选择器 | 类型 | 描述 |
|----------|------|-------------|
| `s.composer.text` | `string` | 当前输入框中的实时未发送文本。可以定时或在卸载时对其进行快照，以构建保存的草稿。 |
| `aui.composer.setText(text)` | `(text: string) => void` | 将文本写入输入框。通过 `onRestore` 调用，将保存的草稿放回输入框，并使用来自 `useAui()` 的客户端。 |

运行时没有保存草稿这一概念：持久化以及决定何时显示横幅，都由您负责。

</RuntimeMode>

<StandaloneMode>

### DraftRestore

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `draft` | `string` | 必填 | 未发送的文本，截断为一行。 |
| `savedAt` | `string` | 必填 | 上次编辑的时间，需预先格式化。 |
| `onRestore` | `() => void` | | 用于将草稿放回输入框时调用。 |
| `onDiscard` | `() => void` | | 用于丢弃草稿时调用。 |
| `className` | `string` | | 合并到根元素上。 |

所有其他 `div` 属性都会转发到根元素。

</StandaloneMode>
