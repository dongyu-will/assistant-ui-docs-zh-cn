---
title: "消息分支"
description: "在同一答案的重新生成版本之间导航，同时保持当前位置不变。"
---

重新生成的答案不会替换之前的答案，而是会成为一个同级分支。此元素会显示当前分支，并提供 `n / m` 步进器，用于在同级分支之间切换。在运行时中，分支来自线程；在独立模式下，则由你传入。

## 开始使用

<RuntimeMode>

每个 assistant-ui 运行时都会跟踪每条消息的分支。步进器从消息中读取 `branchNumber` 和 `branchCount`，并通过运行时切换分支，因此无需将任何状态存储在组件状态中。

<Steps>
  <Step>

### 组合分支选择器

使用 `BranchPickerPrimitive` 构建步进器。原语负责行为（包括当前活动分支、在两端禁用，以及只有一个分支时隐藏）；元素的 class 则负责呈现这种外观。

```tsx title="components/assistant-ui/elements/branch-picker.tsx"
"use client";

import { BranchPickerPrimitive } from "@assistant-ui/react";
import { ChevronLeftIcon, ChevronRightIcon } from "lucide-react";
import { cn } from "@/lib/utils";
import { ghostButton, mono } from "@/components/assistant-ui/elements/surfaces";

export function BranchPicker() {
  return (
    <BranchPickerPrimitive.Root
      hideWhenSingleBranch
      className="flex items-center gap-1"
    >
      <BranchPickerPrimitive.Previous
        aria-label="Show previous response"
        className={cn(ghostButton, "size-6")}
      >
        <ChevronLeftIcon className="size-3.5" />
      </BranchPickerPrimitive.Previous>
      <span className={cn(mono, "text-foreground/35 tabular-nums")}>
        <BranchPickerPrimitive.Number /> / <BranchPickerPrimitive.Count />
      </span>
      <BranchPickerPrimitive.Next
        aria-label="Show next response"
        className={cn(ghostButton, "size-6")}
      >
        <ChevronRightIcon className="size-3.5" />
      </BranchPickerPrimitive.Next>
    </BranchPickerPrimitive.Root>
  );
}
```

  </Step>
  <Step>

### 将其放置在消息中

选择器必须在消息作用域内渲染，这样它才能知道要显示哪个消息的分支。将其放在助手消息的操作行中，与复制和重新生成控件相邻。

```tsx title="components/assistant-ui/elements/thread.aui.tsx"
import { MessagePrimitive } from "@assistant-ui/react";
import { BranchPicker } from "./branch-picker";

function AssistantMessage() {
  return (
    <MessagePrimitive.Root>
      <MessagePrimitive.Parts />
      <div className="flex items-center gap-1">
        <BranchPicker />
        {/* copy, regenerate, ... */}
      </div>
    </MessagePrimitive.Root>
  );
}
```

`Thread` 元素已经为用户消息和助手消息提供了这种组合，因此安装 `@assistant-ui/thread` 后，无需进行上述操作即可获得分支导航。

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

在独立模式下，该元素是一个受控组件：由你管理变体列表和当前索引。它会渲染当前活动变体和步进器，并将索引变化回传给你。

<Steps>
  <Step>

### 保存分支状态

```tsx title="app/answer.tsx"
"use client";

import { useState } from "react";
import { MessageBranches } from "@/components/assistant-ui/elements/message-branches";

const variants = [
  "Paris is the capital of France.",
  "The capital of France is Paris, on the Seine.",
  "France's capital city is Paris.",
];

export function Answer() {
  const [index, setIndex] = useState(0);
  return (
    <MessageBranches variants={variants} index={index} onIndexChange={setIndex} />
  );
}
```

  </Step>
  <Step>

### 重新生成到新分支

追加新的答案，并将索引移动到该答案。步进器的计数会根据数组长度变化。

```tsx
async function regenerate() {
  const next = await fetchAnswer();
  setVariants((prev) => [...prev, next]);
  setIndex(variants.length);
}
```

  </Step>
</Steps>

</StandaloneMode>

## 结构

```tsx
<div data-slot="message-branches">
  <p>{/* the active variant, keyed on index so it fades in on change */}</p>
  <div>
    <button aria-label="Show previous response" />
    <span>{/* n / m */}</span>
    <button aria-label="Show next response" />
  </div>
</div>
```

在独立模式下，步进器会循环切换：在第一个变体上点击上一个会跳转到最后一个，在最后一个变体上点击下一个会跳转到第一个。只有一个变体时，两个按钮都会渲染为禁用状态，计数器显示 `1 / 1`；没有变体时显示 `0 / 0`。而运行时原语会在两端禁用按钮。

## 示例

### 仅显示步进器

<RuntimeMode>

当消息正文已经由 `MessagePrimitive.Parts` 渲染时，只需渲染步进器。`hideWhenSingleBranch` 会在第二个分支存在之前将其从布局中移除，从而保持操作行稳定。

```tsx
<BranchPickerPrimitive.Root hideWhenSingleBranch className="flex items-center gap-1">
  <BranchPickerPrimitive.Previous className={cn(ghostButton, "size-6")}>
    <ChevronLeftIcon className="size-3.5" />
  </BranchPickerPrimitive.Previous>
  <span className={cn(mono, "text-foreground/35 tabular-nums")}>
    <BranchPickerPrimitive.Number /> / <BranchPickerPrimitive.Count />
  </span>
  <BranchPickerPrimitive.Next className={cn(ghostButton, "size-6")}>
    <ChevronRightIcon className="size-3.5" />
  </BranchPickerPrimitive.Next>
</BranchPickerPrimitive.Root>
```

</RuntimeMode>

<StandaloneMode>

该元素始终会在步进器上方渲染当前活动变体。若要单独显示步进器，请传入变体，并根据 `variants[index]` 自行渲染正文：

```tsx
<div>
  <Markdown>{variants[index]}</Markdown>
  <MessageBranches
    className="[&>p]:hidden"
    variants={variants}
    index={index}
    onIndexChange={setIndex}
  />
</div>
```

</StandaloneMode>

### 分支的来源

<RuntimeMode>

重新加载助手消息会创建一个同级分支并切换到该分支；编辑用户消息则会从该位置开始创建对话分支。在选择器旁边放置一个重新生成按钮，步进器就会显示出来：

```tsx
import { useAui } from "@assistant-ui/react";
import { RefreshCwIcon } from "lucide-react";

function RegenerateButton() {
  const aui = useAui();
  return (
    <button
      type="button"
      aria-label="Regenerate"
      onClick={() => aui.message.reload()}
      className={cn(ghostButton, "size-6")}
    >
      <RefreshCwIcon className="size-3.5" />
    </button>
  );
}
```

对于需要直接操作分支的控件，如果你持有某个特定分支的消息 ID，`switchToBranch` 会通过 `{ position: "previous" | "next" }` 逐步切换，或通过 `{ branchId }` 直接跳转。

</RuntimeMode>

<StandaloneMode>

分支就是你追加到 `variants` 中的内容；重新生成意味着将新答案获取到该数组中。`onIndexChange` 是唯一的写入路径，因此任何使用有效索引调用它的控件都可以直接跳转：

```tsx
<select value={index} onChange={(e) => setIndex(Number(e.target.value))}>
  {variants.map((_, i) => (
    <option key={i} value={i}>
      Version {i + 1}
    </option>
  ))}
</select>
```

</StandaloneMode>

### 重新设置步进器样式

两种通道都在根元素上接收 `className`。按钮使用共享的 `ghostButton` surface，计数器使用来自 `surfaces.tsx` 的 `mono` surface，因此重新设置这两个 token 的样式，就能重新设置所有使用它们的元素。

```tsx
<MessageBranches className="max-w-none gap-3" /* ... */ />
```

## API 参考

<RuntimeMode>

### BranchPickerPrimitive

| 部件 | 渲染内容 | 说明 |
|------|---------|-------|
| `Root` | `div` | `hideWhenSingleBranch` 在 `branchCount <= 1` 时返回 `null`。必须位于消息作用域内。 |
| `Previous` | `button` | 在第一个分支上禁用。接受 `asChild`。 |
| `Next` | `button` | 在最后一个分支上禁用。接受 `asChild`。 |
| `Number` | text | 以 1 为起始的 `branchNumber`。 |
| `Count` | text | `branchCount`。 |

### 消息状态

| 选择器 | 类型 | 描述 |
|----------|------|-------------|
| `s.message.branchNumber` | `number` | 当前显示分支的从 1 开始计数的索引。 |
| `s.message.branchCount` | `number` | 此消息的同级分支数量。 |
| `aui.message.switchToBranch(options)` | `{ position?: "previous" \| "next"; branchId?: string }` | 切换当前显示的分支；`position` 用于逐步切换，`branchId` 用于跳转到你持有其消息 ID 的分支。 |

</RuntimeMode>

<StandaloneMode>

### MessageBranches

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `variants` | `readonly string[]` | 必填 | 按顺序排列的同级答案。 |
| `index` | `number` | 必填 | 要显示的变体索引。超出范围的索引会回退到第一个变体。 |
| `onIndexChange` | `(index: number) => void` | 必填 | 按下步进器按钮时，使用下一个索引调用。会在两端循环。 |
| `className` | `string` | | 合并到根元素上。 |

其他所有 `div` props 都会转发到根元素。

</StandaloneMode>
