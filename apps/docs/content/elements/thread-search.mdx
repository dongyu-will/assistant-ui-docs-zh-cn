用于跳转到过去会话的列表：输入文字进行筛选，置顶线程始终排在前面，其余线程则归入你提供的分组中。使用运行时时，列表来自线程列表；独立使用时，则由你自行提供线程和分组。

## 入门

<RuntimeMode>

运行时会在 `s.threads.threadItems` 中保存每个线程的标题、ID 和最近使用时间。将其映射到 `SearchableThread[]` 并基于它进行选择，就是完整的集成过程；没有专门的搜索原语可供组合。

### 将线程状态映射到列表

```tsx title="components/assistant-ui/elements/thread-search-panel.tsx"
"use client";

import { useMemo, useState } from "react";
import { useAui, useAuiState } from "@assistant-ui/react";
import {
  ThreadSearch,
  type SearchableThread,
} from "@/components/assistant-ui/elements/thread-search";

const DAY = 86_400_000;

function groupFor(date: Date | undefined, now: number) {
  if (!date) return "Earlier";
  if (date.getTime() >= now - DAY) return "Today";
  if (date.getTime() >= now - 2 * DAY) return "Yesterday";
  return "Earlier";
}

export function ThreadSearchPanel() {
  const aui = useAui();
  const items = useAuiState((s) => s.threads.threadItems);
  const activeId = useAuiState((s) => s.threads.mainThreadId);
  const [query, setQuery] = useState("");

  const threads = useMemo<SearchableThread[]>(() => {
    const now = Date.now();
    return items
      .filter((item) => item.status === "regular")
      .map((item) => ({
        id: item.id,
        title: item.title ?? "New chat",
        preview: item.isRunning ? "Running…" : "",
        group: groupFor(item.lastMessageAt, now),
        pinned: Boolean(item.custom?.["pinned"]),
      }));
  }, [items]);

  return (
    <ThreadSearch
      threads={threads}
      query={query}
      activeId={activeId}
      onQueryChange={setQuery}
      onSelect={(id) => aui.threads.item({ id }).switchTo()}
    />
  );
}
```

`status === "regular"` 会排除已归档、已删除的线程，以及新线程初始状态下的占位 `"new"` 条目，因此列表与用户所理解的历史记录一致。

  </Step>
</Steps>

</RuntimeMode>

### 保存搜索状态

```tsx title="app/history.tsx"
"use client";

import { useState } from "react";
import { ThreadSearch } from "@/components/assistant-ui/elements/thread-search";

const threads = [
  { id: "1", title: "Migration plan", group: "Today", preview: "Three tables, one rollback path", pinned: true },
  { id: "2", title: "Release notes draft", group: "Today", preview: "Bumped the changelog for 4.2" },
  { id: "3", title: "Onboarding copy", group: "Yesterday", preview: "First run, three moves" },
];

export function History() {
  const [query, setQuery] = useState("");
  const [activeId, setActiveId] = useState(threads[0]!.id);

  return (
    <ThreadSearch
      threads={threads}
      query={query}
      activeId={activeId}
      onQueryChange={setQuery}
      onSelect={setActiveId}
    />
  );
}
```

## 组成

```tsx
<div data-slot="thread-search">
  <div>
    <input aria-label="Search threads" placeholder="Search threads" />
  </div>
  {/* pinned matches, if any, under a "pinned" label */}
  <div>{/* pinned rows */}</div>
  {/* remaining matches, one block per group, in first-seen order */}
  <div>{/* group label */}</div>
  <div>{/* group rows */}</div>
  {/* or, when nothing matches */}
  <span>{/* No thread matches "{query}" */}</span>
</div>
```

匹配会对照查询内容检查 `${title} ${preview}`，且不区分大小写，因此空查询会匹配所有线程。匹配到的置顶线程始终作为单独区块优先渲染；其余线程则按照首次匹配出现的顺序分组，而不是按字母顺序或最近使用时间排序。在搜索输入框中按 Arrow Down 和 Arrow Up，会按照置顶后分组的顺序移动当前选择，并在两端循环；输入法编辑期间会忽略这些按键，因此组合查询时不会抢占按键。不存在区别于“没有匹配结果”的可见“完全没有线程”状态：空的 `threads` 数组与查询没有命中结果时会渲染相同的空状态消息。

## 示例

### 线程的来源

<RuntimeMode>

`group` 和 `pinned` 不是运行时概念。上面的按日期分组方式与已安装的线程列表内部使用的方式一致；你也可以根据应用所跟踪的任意字段，以相同方式创建自己的分组（例如按项目或标签分组）。置顶状态也需要存放在某处，而 `custom` 正是合适的位置：它是每个线程列表项都携带的自由格式数据包，可通过 `item.custom?.pinned` 读取，并通过 `aui.threads.item({ id }).updateCustom(...)` 写入。`updateCustom` 会替换整个数据包，而不是进行合并，因此切换单个字段时要展开现有值：

```tsx
function togglePinned(id: string) {
  const current = aui.threads.item({ id }).getState().custom;
  aui.threads.item({ id }).updateCustom({ ...current, pinned: !current?.["pinned"] });
}
```

</RuntimeMode>

<StandaloneMode>

独立使用时，`group` 和 `pinned` 只是你传入对象上的字段，因此当置顶控件触发时，置顶状态就是你写入 `setThreads` 的内容。该元素不会检查这些线程是如何生成的。

</StandaloneMode>

### 重新设置列表样式

两个区域的根元素都接收 `className`。行和字段的表面样式来自整个组件目录中通用的 `paper`、`field` 和 `mono` 令牌，因此重新设置这些令牌的主题即可同时覆盖搜索框、行悬停状态和分区标签。

```tsx
<ThreadSearch className="max-w-xs" /* ... */ />
```

## API 参考

<RuntimeMode>

此元素没有专用原语：它的内容来自 `useAuiState` 选择器，与“入门”中的方式相同。

### 线程状态

| 选择器 | 类型 | 描述 |
|----------|------|-------------|
| `s.threads.threadItems` | `readonly ThreadListItemState[]` | 每个已知的线程列表项，每项都包含 `id`、`title`、`lastMessageAt`、`status`、`custom` 和 `isRunning`。 |
| `s.threads.mainThreadId` | `string` | 当前打开线程的 ID。 |
| `aui.threads.item({ id }).switchTo(options)` | `{ unarchive?: boolean }` | 将指定线程设为打开状态。 |
| `aui.threads.item({ id }).updateCustom(custom)` | `Record<string, unknown> \| undefined` | 替换条目的自由格式元数据包，例如 `pinned` 标志。 |

</RuntimeMode>

<StandaloneMode>

### ThreadSearch

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `threads` | `readonly SearchableThread[]` | 必填 | 用于搜索和分组的完整列表。 |
| `query` | `string` | 必填 | 当前搜索文本。 |
| `activeId` | `string` | 必填 | 高亮线程的 ID。 |
| `onQueryChange` | `(query: string) => void` | | 用户输入时调用。 |
| `onSelect` | `(id: string) => void` | | 用户点击线程行时传入线程 ID 调用；在搜索输入框中每次按下 Arrow Down 或 Arrow Up 时也会立即调用。不存在单独的高亮步骤，因此移动即代表选择。 |
| `className` | `string` | | 合并到根元素上。 |

所有其他 `div` 属性都会转发到根元素。

### SearchableThread

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `id` | `string` | 唯一标识符，同时也是传递给 `onSelect` 的值。 |
| `title` | `string` | 行标题。 |
| `group` | `string` | 未置顶行的分区标签。自由格式文本；该元素不会解析其内容。 |
| `preview` | `string` | 显示在标题下方的辅助文本行。 |
| `pinned` | `boolean` | 可选。当值为 true 时，该行会渲染在置顶区块中，而不是所属分组中。 |

</StandaloneMode>
