---
title: "Orb"
description: "支持连接、静音和说话状态控制的实时语音 Orb。"
---

Orb 是实时语音界面：一个动画指示器，以及连接、静音和断开连接操作。在运行时中，它会直接读取实时的 `RealtimeVoiceAdapter` 会话；单独使用时，则由你自行管理的状态和回调来驱动相同的 Orb 和按钮。

## 快速开始

<RuntimeMode>

语音会话需要在运行时上配置 `RealtimeVoiceAdapter`，之后这些内容才能渲染。有关适配器设置，请参阅 [实时语音指南](/docs/guides/voice)。

<Steps>
  <Step>

### 配置语音适配器

```tsx
import { useChatRuntime } from "@assistant-ui/ai-sdk";

const runtime = useChatRuntime({
  adapters: {
    voice: myVoiceAdapter,
  },
});
```

  </Step>
  <Step>

### 渲染 Orb 和控制栏

```tsx title="app/page.tsx"
import { Thread } from "@/components/assistant-ui/elements/thread.aui";
import {
  VoiceControl,
  VoiceOrb,
} from "@/components/assistant-ui/elements/voice.aui";
import { AuiIf } from "@assistant-ui/react";

export default function Chat() {
  return (
    <div className="flex h-full flex-col">
      <AuiIf condition={(s) => s.thread.capabilities.voice}>
        <div className="flex items-center justify-center py-6">
          <VoiceOrb />
        </div>
        <VoiceControl />
      </AuiIf>
      <div className="min-h-0 flex-1">
        <Thread />
      </div>
    </div>
  );
}
```

`VoiceOrb` 在这里不需要任何必填属性：它会自行读取会话状态和实时音频电平。`VoiceControl` 是紧凑的状态点以及连接/静音/断开连接栏；可以将其放置在通话工具栏应处的位置，不受 Orb 自身位置影响。

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

单独使用时，`VoiceOrb` 是一个非受控视觉组件：状态和音量由你管理，而 WebGL 动画由它负责。

<Steps>
  <Step>

### 渲染 Orb

```tsx title="app/call.tsx"
"use client";

import { useState } from "react";
import {
  VoiceOrb,
  type VoiceOrbState,
} from "@/components/assistant-ui/elements/voice";

export function Call() {
  const [state, setState] = useState<VoiceOrbState>("idle");
  return <VoiceOrb state={state} volume={0} />;
}
```

  </Step>
  <Step>

### 提供实时音频电平

```tsx
<VoiceOrb state={state} volume={micLevel} />
```

`volume`（0 到 1）会在 `state` 已设置的效果之上调节 Orb 的速度、扭曲和光晕，使界面在说话过程中持续响应，而不是保持单一的静态外观。

  </Step>
</Steps>

</StandaloneMode>

## 结构

```tsx
<canvas className="aui-voice-orb" data-state={/* idle | connecting | listening | speaking | muted */} />

<div className="aui-voice-control">
  <span /> {/* status dot, colored by state */}
  {/* no session, or an ended one: */}
  <button>Connect</button>
  {/* starting: */}
  <span>Connecting...</span>
  {/* running: */}
  <button aria-label="Mute or Unmute" />
  <button aria-label="Disconnect" />
</div>
```

Orb 的五种状态按固定顺序解析：完全没有会话，或会话状态为 `"ended"` 时，状态为 `idle`；会话状态为 `"starting"` 时，无论是否静音，状态都为 `connecting`；否则，静音会话为 `muted`，即使模型正在说话也是如此；在其他情况下，会话的 `mode` 决定其为 `speaking` 还是 `listening`。`VoiceControl` 遵循更简单的划分：没有会话或会话已结束时显示连接按钮，正在启动的会话只显示“正在连接...”文本，运行中的会话显示静音和断开连接按钮。状态点在空闲时为灰色，连接时为脉动的琥珀色，聆听或说话时为绿色，静音时为红色。

## 示例

### 状态

<RuntimeMode>

运行时 `VoiceOrb` 接受显式的 `state`，它会覆盖原本根据实时会话派生的状态；即使在已连接的应用中，也可以利用这一点展示状态图库：

```tsx
{(["idle", "connecting", "listening", "speaking", "muted"] as const).map(
  (state) => (
    <VoiceOrb key={state} state={state} />
  ),
)}
```

它仍然需要运行时祖先：覆盖项只会替换派生的 `state`，而组件无论如何都会读取会话钩子。

</RuntimeMode>

<StandaloneMode>

```tsx
import { VoiceOrb } from "@/components/assistant-ui/elements/voice";

{(["idle", "connecting", "listening", "speaking", "muted"] as const).map(
  (state) => (
    <VoiceOrb key={state} state={state} />
  ),
)}
```

</StandaloneMode>

### 调色板

两条轨道都接受 `variant`，这是一个独立于 `state` 的颜色轴：`default`（灰色）、`blue`、`violet` 或 `emerald`。

```tsx
<VoiceOrb variant="violet" />
```

### 会话的来源

<RuntimeMode>

连接、静音和断开连接都会通过 `useVoiceControls()` 完成。输入框的紧凑切换按钮只需要它的 `status.type` 和以下两个调用：

```tsx
function ComposerVoiceToggle() {
  const voiceState = useVoiceState();
  const { connect, disconnect } = useVoiceControls();
  const isActive =
    voiceState?.status.type === "running" ||
    voiceState?.status.type === "starting";

  return (
    <AuiIf condition={(s) => s.thread.capabilities.voice}>
      <button
        type="button"
        onClick={() => (isActive ? disconnect() : connect())}
        aria-label={isActive ? "End voice" : "Start voice"}
      >
        {isActive ? <PhoneOffIcon /> : <PhoneIcon />}
      </button>
    </AuiIf>
  );
}
```

</RuntimeMode>

<StandaloneMode>

单独使用时，你需要端到端管理会话生命周期：接入自己的连接、静音和断开连接处理器，并根据会话报告的结果更新 `state` 和 `volume`。

```tsx
<VoiceOrb
  state={isMuted ? "muted" : isSpeaking ? "speaking" : "listening"}
  volume={micLevel}
/>
```

</StandaloneMode>

## API 参考

<RuntimeMode>

### 子组件

| 导出项 | 描述 |
|--------|-------------|
| `VoiceOrb` | 动画 Orb。除非你传入 `state` 和 `volume`，否则会从会话中派生它们；只有 `state` 可以被覆盖，而 `volume` 仍会跟踪实时音频。 |
| `VoiceControl` | 状态点，以及连接、“正在连接...”、静音和断开连接按钮，根据会话状态切换。 |
| `VoiceStatusDot` | 单独的彩色状态点。 |
| `VoiceConnectButton` | 调用 `connect()`。 |
| `VoiceMuteButton` | 在 `mute()` / `unmute()` 之间切换，并根据当前的 `isMuted` 设置标签。 |
| `VoiceDisconnectButton` | 调用 `disconnect()`。 |
| `deriveVoiceOrbState(voiceState)` | Anatomy 中的空闲/连接中/静音/说话/聆听状态解析结果，导出后可供自定义指示器复用。 |

所有子组件都会导出，可独立使用来创建自定义布局。

### 语音状态

| 选择器 | 类型 | 描述 |
|----------|------|-------------|
| `s.thread.capabilities.voice` | `boolean` | 是否配置了语音适配器。 |
| `s.thread.voice` | `VoiceSessionState \| undefined` | 不存在会话时为 `undefined`。 |
| `s.thread.voice?.status.type` | `"starting" \| "running" \| "ended"` | 会话阶段；已结束的会话还会携带 `reason`（`"finished" \| "cancelled" \| "error"`）。 |
| `s.thread.voice?.isMuted` | `boolean` | 麦克风静音状态。 |
| `s.thread.voice?.mode` | `"listening" \| "speaking"` | 当前处于活动状态的一方。 |
| `useVoiceVolume()` | `number` | 实时音频电平（0 到 1），在主状态订阅之外读取，以避免每个采样都触发重新渲染。 |
| `useVoiceControls()` | `{ connect, disconnect, mute, unmute }` | 每个都是一个 `() => void`，会调用匹配的运行时方法。 |

</RuntimeMode>

<StandaloneMode>

### VoiceOrb

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `state` | `"idle" \| "connecting" \| "listening" \| "speaking" \| "muted"` | `"idle"` | 要渲染的动画预设。 |
| `volume` | `number` | `0` | 0 到 1；叠加到状态的速度、扭曲和光晕之上。 |
| `variant` | `"default" \| "blue" \| "violet" \| "emerald"` | `"default"` | 调色板。 |
| `className` | `string` | | 合并到画布上。 |

</StandaloneMode>
