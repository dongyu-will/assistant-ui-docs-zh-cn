数据表列出模型希望展示在你面前的几行数据，每一行都会以短暂的交错动画逐一出现。在运行时中，这些行来自工具的结果；单独使用时，则由你直接传入。

## 入门

<RuntimeMode>

数据表用于渲染结果已经呈现为行数据的工具调用。注册一次后，所有匹配的调用都会使用同一个表格。

<Steps>
  <Step>

### 渲染工具调用

```tsx title="components/assistant-ui/elements/compare-models-tool-ui.tsx"
"use client";

import { useEffect, useState } from "react";
import type { ToolCallMessagePartComponent } from "@assistant-ui/react";
import {
  DataTable,
  type ModelUsage,
} from "@/components/assistant-ui/elements/data-table";

export const CompareModelsToolUI: ToolCallMessagePartComponent<
  { models: string[] },
  readonly ModelUsage[]
> = ({ result, toolCallId }) => {
  const [cycle, setCycle] = useState(0);
  useEffect(() => {
    setCycle((c) => c + 1);
  }, [toolCallId]);

  if (!result) return null;
  return <DataTable rows={result} cycle={cycle} />;
};
```

  </Step>
  <Step>

### 注册工具

```tsx title="app/toolkit.ts"
import { defineToolkit } from "@assistant-ui/react";
import { z } from "zod";
import { CompareModelsToolUI } from "@/components/assistant-ui/elements/compare-models-tool-ui";

export const toolkit = defineToolkit({
  compare_models: {
    type: "frontend",
    description: "Compare context window and price across a set of models.",
    parameters: z.object({ models: z.array(z.string()) }),
    execute: async ({ models }) => lookupModelUsage(models),
    render: CompareModelsToolUI,
  },
});
```

```tsx title="app/MyRuntimeProvider.tsx"
import { AssistantRuntimeProvider, AuiConfig, Tools } from "@assistant-ui/react";
import { useChatRuntime } from "@assistant-ui/ai-sdk";
import { toolkit } from "./toolkit";

export function MyRuntimeProvider({ children }: { children: React.ReactNode }) {
  const runtime = useChatRuntime();
  const config = AuiConfig({ tools: Tools({ toolkit }) });
  return (
    <AssistantRuntimeProvider runtime={runtime} config={config}>
      {children}
    </AssistantRuntimeProvider>
  );
}
```

有关后端定义的工具和审批门禁，请参阅[工具 UI](/docs/tools/tool-ui)。

### 保存行数据

```tsx title="app/comparison.tsx"
"use client";

import { DataTable, type ModelUsage } from "@/components/assistant-ui/elements/data-table";

const MODEL_USAGE = [
  { name: "Sonnet 4.5", context: "200k", cost: "$3.00" },
  { name: "GPT-5", context: "400k", cost: "$5.00" },
  { name: "Haiku 4.5", context: "200k", cost: "$0.80" },
] as const satisfies readonly ModelUsage[];

export function Comparison() {
  return <DataTable rows={MODEL_USAGE} cycle={0} />;
}
```

  </Step>
  <Step>

### 行数据变化时重播交错动画

`cycle` 是重新挂载键，而不是计数值。每当行数据发生变化时都将其递增，这样新数据集就会从顶部淡入，而不是在原位置突然出现。

```tsx
const [rows, setRows] = useState(MODEL_USAGE);
const [cycle, setCycle] = useState(0);

async function refresh(models: readonly string[]) {
  setRows(await fetchModelUsage(models));
  setCycle((c) => c + 1);
}
```

  </Step>
</Steps>

## 结构

```tsx
<div data-slot="data-table">
  <div>{/* header: Model / Context / Cost labels */}</div>
  <div />{/* hairline divider */}
  <div key={cycle}>
    {/* one row per item: initial-letter avatar, name, context, cost */}
  </div>
</div>
```

行列表以 `cycle` 作为键，因此更改它会重新挂载每一行，并从顶部重新播放每行 80ms 的交错动画。空的 `rows` 数组只会渲染表头，不会显示占位行或空状态消息。

## 示例

### 重新设置表格样式

两条通道都会在根元素上接收 `className`。标签、行头像和数字列都从 `surfaces.tsx` 中共享的 `mono` 和 `paper` 令牌读取，因此重新设置这些令牌的主题即可一次性调整所有表格的样式。

```tsx
<DataTable className="max-w-none" /* ... */ />
```

### 比较更少的模型

表头始终显示全部三列；`rows` 决定下方显示多少行数据，最少可以为零行。

```tsx
<DataTable
  rows={MODEL_USAGE.filter((row) => row.name.startsWith("Sonnet"))}
  cycle={cycle}
/>
```

## API 参考

<RuntimeMode>

### 工具调用渲染属性

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `args` | `TArgs` | 解析后的参数。模型仍在流式传输参数时，该值可能不完整。 |
| `argsText` | `string` | 模型流式传输的原始 JSON 参数文本。 |
| `result` | `TResult \| undefined` | 工具完成后返回的值。运行期间为 `undefined`。 |
| `status` | `ToolCallMessagePartStatus` | `status.type` 为 `"running"`、`"requires-action"`、`"complete"` 或 `"incomplete"`。 |
| `toolName` | `string` | 模型调用的工具名称。 |
| `toolCallId` | `string` | 此次调用的稳定 ID。 |
| `isError` | `boolean \| undefined` | `result` 是否表示工具执行错误。 |

在工具包条目的 `render` 字段上注册渲染器，并使用 `Tools({ toolkit })` 附加工具包。有关完整的渲染属性集合，请参阅[工具 UI](/docs/tools/tool-ui)，其中包括 `addResult`、人工工具和审批门禁。

</RuntimeMode>

<StandaloneMode>

### DataTable

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `rows` | `readonly ModelUsage[]` | 必填 | 要按顺序渲染的行。 |
| `cycle` | `number` | 必填 | 行列表的重新挂载键；更改它会重新播放交错进入动画。 |
| `className` | `string` | | 合并到根元素上。 |

`ModelUsage` 是 `{ name: string; context: string; cost: string }`。其他所有 `div` 属性都会转发到根元素。

</StandaloneMode>
