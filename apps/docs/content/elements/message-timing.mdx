---
title: "消息计时"
description: "当前消息的流式统计信息，包括首个令牌时间、总耗时和速度。"
---

消息计时会将流自身的遥测数据转换为一个小徽章：触发器上显示时长，悬停提示中显示首个令牌时间、总耗时、速度和分块数量。使用运行时（runtime）时，它会读取当前助手消息中记录的计时信息；这个精确徽章没有独立形式，因为没有可计时内容的徽章也就没有可显示的内容。它有两种设计：运行时版本将实时遥测数据显示在悬停提示中，而静态版本则将相同数字渲染为由 props 驱动的统计信息行（参见[计时页脚设计](#the-timing-footer-design)）。

## 开始使用

<RuntimeMode>

每个 assistant-ui 运行时都会记录响应的流式传输过程。徽章通过 `useMessageTiming()` 读取这份记录，并在有可报告的信息之前保持不可见。

<Steps>
  <Step>

### 读取消息计时

`useMessageTiming()` 返回当前助手消息的 `metadata.timing`；如果当前是用户消息，或尚不存在任何计时信息，则返回 `undefined`。在设置 `totalStreamTime` 之前，徽章不会渲染任何内容，因此它只会在响应完成流式传输后显示。

```tsx title="components/assistant-ui/elements/message-timing.aui.tsx"
"use client";

import { useMessageTiming } from "@assistant-ui/react";
import {
  Tooltip,
  TooltipContent,
  TooltipProvider,
  TooltipTrigger,
} from "@/components/ui/tooltip";
import type { FC } from "react";

const formatTimingMs = (ms: number | undefined): string => {
  if (ms === undefined) return "—";
  if (ms < 1000) return `${Math.round(ms)}ms`;
  return `${(ms / 1000).toFixed(2)}s`;
};

export const MessageTiming: FC<{
  className?: string;
  side?: "top" | "right" | "bottom" | "left";
}> = ({ className, side = "right" }) => {
  const timing = useMessageTiming();
  if (timing?.totalStreamTime === undefined) return null;

  return (
    <TooltipProvider>
      <Tooltip>
        <TooltipTrigger
          render={
            <button
              type="button"
              aria-label="Message timing"
              className={className}
            />
          }
        >
          {formatTimingMs(timing.totalStreamTime)}
        </TooltipTrigger>
        <TooltipContent side={side} sideOffset={8}>
          {/* first token, total, speed, chunks; see Anatomy below */}
        </TooltipContent>
      </Tooltip>
    </TooltipProvider>
  );
};
```

  </Step>
  <Step>

### 将其添加到消息操作栏

将 `MessageTiming` 放在复制和重新加载按钮旁边，这样它就会从 `ActionBarPrimitive.Root` 继承操作栏自身的悬停和自动隐藏行为。

```tsx title="components/assistant-ui/elements/thread.aui.tsx" {3,10}
import { ActionBarPrimitive } from "@assistant-ui/react";
import { TooltipIconButton } from "@/components/assistant-ui/elements/tooltip-icon-button";
import { MessageTiming } from "@/components/assistant-ui/elements/message-timing.aui";

function AssistantActionBar() {
  return (
    <ActionBarPrimitive.Root hideWhenRunning autohide="not-last">
      <ActionBarPrimitive.Copy asChild>
        <TooltipIconButton tooltip="Copy">{/* ... */}</TooltipIconButton>
      </ActionBarPrimitive.Copy>
      <MessageTiming />
    </ActionBarPrimitive.Root>
  );
}
```

`Thread` 提供的操作栏中不包含 `MessageTiming`；添加上面的代码行，即可为每条助手消息启用计时功能。

## 结构

<RuntimeMode>

```tsx
<button aria-label="Message timing">{/* e.g. "1.24s" */}</button>
<div>
  <div>First token   <span>{/* only when firstTokenTime is set */}</span></div>
  <div>Total         <span>{/* always, once the badge is visible */}</span></div>
  <div>Speed         <span>{/* only when tokensPerSecond is set */}</span></div>
  <div>Chunks        <span>{/* always, once the badge is visible */}</span></div>
</div>
```

触发器本身就是显示条件：当 `totalStreamTime` 未定义时，整个徽章都是 `null`，因此仍在流式传输的消息不会显示任何内容，而不是显示占位符。徽章可见后，“Total”和“Chunks”始终会显示；当底层值缺失时，“First token”和“Speed”会分别独立隐藏。

</RuntimeMode>

## 示例

<RuntimeMode>

### 悬停提示方向

传入 `side` 可以翻转悬停提示打开的边缘，使其与布局中操作栏所在的位置相匹配。

```tsx
<MessageTiming side="left" />
```

### 格式化规则

小于一秒的时长会渲染为整数毫秒（`420ms`）；一秒或更长的时长会渲染为两位小数（`1.24s`）。速度始终以每秒令牌数显示，并保留一位小数（`38.4 tok/s`）；触发器本身显示总耗时时，也使用相同的 `formatTimingMs` 规则。

</RuntimeMode>

## API 参考

<RuntimeMode>

### 消息状态

| 选择器 | 类型 | 描述 |
|----------|------|-------------|
| `s.message.metadata.timing` | `MessageTiming \| undefined` | 当前助手消息记录的计时信息；如果当前是用户消息，或尚不存在任何计时信息，则为 `undefined`。`useMessageTiming()` 对该选择器进行了完全封装。 |

`MessageTiming` 包含 `streamStartTime`、`firstTokenTime?`、`totalStreamTime?`、`tokenCount?`、`tokensPerSecond?`、`totalChunks` 和 `toolCallCount`。

### MessageTiming props

| Prop | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `className` | `string` | | 合并到触发器按钮上。 |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"right"` | 悬停提示打开的方向。 |

</RuntimeMode>

## 计时页脚设计

栏中的 Static 变体是同一遥测数据的第二种设计：`MessageTiming` 将数字布局为始终可见的普通 props 行，而不是将其收纳到徽章的悬停提示中。这是一个完全由 props 驱动、无运行时依赖的单一组件：

```sh
npx shadcn@latest add "@assistant-ui/elements-message-timing"
```

<RuntimeMode>

运行时已经通过 `useMessageTiming()` 暴露了相同的计时信息；如果希望显示信息行而不是徽章，请自行将其映射为统计信息：

```tsx title="components/assistant-ui/elements/thread.aui.tsx"
"use client";

import { useMessageTiming } from "@assistant-ui/react";
import {
  MessageTiming,
  type TimingStat,
} from "@/components/assistant-ui/elements/message-timing";

const formatMs = (ms: number) =>
  ms < 1000 ? `${Math.round(ms)}ms` : `${(ms / 1000).toFixed(2)}s`;

function TimingFooter() {
  const timing = useMessageTiming();
  if (!timing) return null;

  const stats: TimingStat[] = [
    timing.firstTokenTime !== undefined && {
      label: "ttft",
      value: formatMs(timing.firstTokenTime),
    },
    timing.totalStreamTime !== undefined && {
      label: "total",
      value: formatMs(timing.totalStreamTime),
    },
    timing.tokensPerSecond !== undefined && {
      label: "tok/s",
      value: timing.tokensPerSecond.toFixed(1),
    },
    { label: "chunks", value: String(timing.totalChunks) },
  ].filter((stat): stat is TimingStat => stat !== false);

  return <MessageTiming stats={stats} />;
}
```

</RuntimeMode>

<StandaloneMode>

单独使用时，`MessageTiming` 会渲染你提供的任意键值对；统计信息的内容没有固定限制：

```tsx title="app/answer.tsx"
import {
  MessageTiming,
  type TimingStat,
} from "@/components/assistant-ui/elements/message-timing";

const stats: TimingStat[] = [
  { label: "ttft", value: "0.4s" },
  { label: "total", value: "2.6s" },
  { label: "tok/s", value: "61" },
];

<MessageTiming stats={stats} />;
```

</StandaloneMode>

该行在挂载时淡入，并会在超过最大宽度后换为多行。传入 `streaming` 后，会将每个值高亮为蓝色，而不是使用稳定状态下的柔和色调；这在统计信息仍在实时更新时很有用。`stats` 可以是任意长度，包括空数组；传入空数组时，会渲染一个不包含任何内容的空行。

### MessageTiming

| Prop | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `stats` | `readonly TimingStat[]` | required | `{ label: string; value: string }[]`，按顺序渲染。 |
| `streaming` | `boolean` | | 为 true 时，将每个值高亮为蓝色。 |
| `className` | `string` | | 合并到根元素上。 |

其他所有 `div` props 都会转发到根元素。
