title: "检索分块"
description: "检索答案所依据的段落会先进行评分，然后答案才会到达。"
---

检索分块会显示查询、状态行，以及检索调用找到的段落；每个段落都包含其来源、定位信息、相关性评分和评分条。在运行时中，查询和段落来自模型发起的工具调用；独立使用时，你可以控制 `query`、`chunks` 以及可见分块的数量。

## 入门

<RuntimeMode>

检索工具会通过该工具自己的工具包条目进行渲染：模型的查询作为 `args` 传入，检索到的段落作为 `result` 传入，而调用的生命周期则作为 `status` 传入。

<Steps>
  <Step>

### 定义检索工具包

```tsx title="app/toolkit.tsx"
"use generative";

import { defineToolkit, externalTool } from "@assistant-ui/react";
import { RetrievalChunks } from "@/components/assistant-ui/elements/retrieval-chunks";

export default defineToolkit({
  search_docs: {
    execute: externalTool(),
    render: ({ args, result, status }) => (
      <RetrievalChunks
        query={args.query ?? ""}
        chunks={result?.chunks ?? []}
        visibleCount={result?.chunks.length ?? 0}
        searching={status.type === "running"}
      />
    ),
  },
});
```

`execute: externalTool()` 用于标记由后端路由或向量存储运行、而非在浏览器中运行的工具：编译器会将其从客户端构建包中移除，只保留 `render`。

  </Step>
  <Step>

### 注册工具包

```tsx title="app/MyRuntimeProvider.tsx"
"use client";

import { AssistantRuntimeProvider, AuiConfig, Tools } from "@assistant-ui/react";
import { useChatRuntime } from "@assistant-ui/ai-sdk";
import { Thread } from "@/components/assistant-ui/elements/thread.aui";
import toolkit from "./toolkit";

export function App() {
  const runtime = useChatRuntime();
  const config = AuiConfig({ tools: Tools({ toolkit }) });

  return (
    <AssistantRuntimeProvider runtime={runtime} config={config}>
      <Thread />
    </AssistantRuntimeProvider>
  );
}
```

现在，线程中的每个 `search_docs` 工具调用都会渲染为此元素，无论 `MessagePrimitive.Parts` 将其放置在助手回复中的什么位置。

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

独立使用时，`RetrievalChunks` 完全由你控制：你需要保存查询、完整的分块列表，以及其中可见的分块数量。

<Steps>
  <Step>

### 保存检索状态

```tsx title="app/answer.tsx"
"use client";

import { useState } from "react";
import {
  RetrievalChunks,
  type RetrievalChunk,
} from "@/components/assistant-ui/elements/retrieval-chunks";

const CHUNKS: readonly RetrievalChunk[] = [
  {
    id: "c1",
    source: "migration-0.14.md",
    locator: "§ 2",
    score: 0.91,
    text: "The composer owns its draft from 0.14 onward.",
  },
  {
    id: "c2",
    source: "composer.tsx",
    locator: "L12",
    score: 0.84,
    text: "useDraft(threadId) subscribes to the per-thread draft slot.",
  },
];

export function Retrieval() {
  const [searching, setSearching] = useState(true);
  const [visibleCount, setVisibleCount] = useState(0);

  return (
    <RetrievalChunks
      query="how does draft restore work"
      chunks={CHUNKS}
      visibleCount={visibleCount}
      searching={searching}
    />
  );
}
```

  </Step>
  <Step>

### 随检索完成逐步显示分块

段落准备好后，将 `searching` 关闭，并将 `visibleCount` 逐步增加，而不是直接跳转到完整列表：

```tsx
useEffect(() => {
  fetchChunks(query).then((found) => {
    setSearching(false);
    found.forEach((_, i) => {
      setTimeout(() => setVisibleCount((n) => Math.max(n, i + 1)), i * 250);
    });
  });
}, [query]);
```

  </Step>
</Steps>

</StandaloneMode>

## 组成

```tsx
<div data-slot="retrieval-chunks">
  <span>{/* query, in a rounded field with a database icon */}</span>
  <div>{/* "Retrieving" (shimmer) while searching, else "N passages above threshold" */}</div>
  <div>
    {/* the first `visibleCount` chunks: source, locator, score, snippet, score bar */}
  </div>
</div>
```

`visibleCount` 会限制在 `0…chunks.length` 范围内，因此超出范围的值不会抛出异常：负值或 `NaN` 不显示任何内容，超过末尾一个位置则显示全部内容。与网页搜索不同，检索完成后，状态行确实会显示 `chunks.length`。分块的评分条会按照 `1` 的百分比填充到 `score`；评分达到 `0.8` 或更高时，评分文本会变为翡翠绿色；低于该值时，则使用弱化的前景色显示。`text` 会限制为两行，且不会自动展开。

## 示例

### 渲染前按评分筛选

该元素不会强制执行相关性下限：传入更短的 `chunks` 数组，以移除低于你自定义阈值的段落，而不是尝试使用 `visibleCount` 将其隐藏。

```tsx
<RetrievalChunks
  query={query}
  chunks={chunks.filter((c) => c.score >= 0.5)}
  visibleCount={chunks.length}
  searching={searching}
/>
```

### 重新设置分块样式

两条轨道的根元素都接受 `className`。查询标签使用共享的 `field` 表面，分块卡片使用 `paper`，定位信息和评分使用 `mono`；这些样式都来自 `surfaces.tsx`。

```tsx
<RetrievalChunks className="max-w-none" /* ... */ />
```

## API 参考

<RuntimeMode>

### 工具渲染属性

| 属性 | 类型 | 描述 |
|------|------|-------------|
| `args` | `{ query?: string }` | 模型提供的参数。流式传输期间可能不完整。 |
| `result` | `{ chunks: RetrievalChunk[] } \| undefined` | 工具调用解析后设置。 |
| `status.type` | `"running" \| "complete" \| "incomplete" \| "requires-action"` | 调用的生命周期。只有 `"running"` 状态应显示检索中的闪烁效果。 |

`RetrievalChunk` 是 `{ id: string; source: string; locator: string; score: number; text: string }`。完整的工具调用部分结构请参阅[工具 UI](/docs/tools/tool-ui)。

</RuntimeMode>

<StandaloneMode>

### RetrievalChunks

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `query` | `string` | 必填 | 标签中显示的查询。 |
| `chunks` | `readonly RetrievalChunk[]` | 必填 | 完整的段落列表。 |
| `visibleCount` | `number` | 必填 | 从 `chunks` 开始渲染的分块数量。 |
| `searching` | `boolean` | 必填 | 为 true 时，在段落数量的位置显示带闪烁效果的“检索中”标签。 |
| `className` | `string` | | 合并到根元素上。 |

`RetrievalChunk` 是 `{ id: string; source: string; locator: string; score: number; text: string }`。其他所有 `div` 属性都会转发到根元素。

</StandaloneMode>
