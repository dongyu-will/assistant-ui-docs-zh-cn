---
title: "征询表单"
description: "服务器在工具调用进行到一半时暂停，以询问仍然需要的字段。"
---

当连接的服务器需要结构化输入才能完成操作时，就会显示征询表单：一条消息、每个请求字段对应一个控件，以及一对在回答后变为确认状态的“拒绝/发送”按钮。在运行时中，这来自 MCP 服务器实时发起的征询请求；单独使用时，则由你直接提供字段和状态。

## 快速开始

<RuntimeMode>

MCP 表单征询使用的是无样式原语，而不是工具包渲染器：`@assistant-ui/react-mcp` 暴露了 `McpElicitationPrimitive`，你可以直接使用其各个部分，构建与此元素相同的外观。

### 使用 `McpElicitationPrimitive` 组合表单

```tsx title="components/assistant-ui/elements/mcp-elicitation-form.tsx"
"use client";

import { PlugIcon } from "lucide-react";
import { McpElicitationPrimitive } from "@assistant-ui/react-mcp";
import { cn } from "@/lib/utils";
import { field, inkButton, mono, paper } from "@/components/assistant-ui/elements/surfaces";

function fieldKind(schema: unknown): "text" | "toggle" {
  return (schema as { type?: string } | undefined)?.type === "boolean"
    ? "toggle"
    : "text";
}

export function McpElicitationForm({ serverName }: { serverName: string }) {
  return (
    <McpElicitationPrimitive.Items>
      {() => (
        <McpElicitationPrimitive.Root
          className={cn(paper, "flex w-full max-w-sm flex-col gap-3.5 rounded-[20px] p-4")}
        >
          <div className="flex items-center gap-2.5">
            <span className="bg-foreground/[0.05] text-foreground/45 flex size-7 items-center justify-center rounded-lg">
              <PlugIcon className="size-3.5" />
            </span>
            <span className="min-w-0 flex-1 truncate text-[13.5px] font-medium">
              {serverName}
            </span>
          </div>

          <McpElicitationPrimitive.Message className="text-foreground/55 text-xs leading-relaxed" />
          <McpElicitationPrimitive.Error className="text-xs text-red-600 dark:text-red-400" />

          <div className="flex flex-col gap-2.5">
            <McpElicitationPrimitive.Fields>
              {({ name, schema, value, setValue }) => (
                <div className="flex flex-col gap-1">
                  <span className={cn(mono, "text-foreground/35")}>{name}</span>
                  {fieldKind(schema) === "toggle" ? (
                    <input
                      type="checkbox"
                      checked={value === true}
                      onChange={(e) => setValue(e.target.checked)}
                    />
                  ) : (
                    <input
                      className={cn(field, "rounded-lg px-2.5 py-1.5 text-xs")}
                      value={typeof value === "string" ? value : ""}
                      onChange={(e) => setValue(e.target.value)}
                    />
                  )}
                </div>
              )}
            </McpElicitationPrimitive.Fields>
          </div>

          <div className="flex h-8 items-center justify-end gap-2">
            <McpElicitationPrimitive.Decline className="text-foreground/55 h-8 rounded-full px-3.5 text-xs font-medium">
              Decline
            </McpElicitationPrimitive.Decline>
            <McpElicitationPrimitive.Accept
              className={cn(
                inkButton,
                "flex h-8 items-center rounded-full px-3.5 text-xs font-medium",
              )}
            >
              Send
            </McpElicitationPrimitive.Accept>
          </div>
        </McpElicitationPrimitive.Root>
      )}
    </McpElicitationPrimitive.Items>
  );
}
```

  </Step>
  <Step>

### 将其挂载到连接的服务器中

`MCPElicitation` 自身不携带服务器 ID；只有在列出连接的服务器时，处于已有的 `mcpServer` 作用域中，才能访问该请求。在同一作用域中渲染表单，例如将其放在服务器列表的每一行旁边：

```tsx
{servers.map((server) => (
  <McpElicitationForm key={server.id} serverName={server.name} />
))}
```

有关连接服务器并启用其 `elicitation` 能力，请参阅[用户管理的 MCP 服务器](/docs/tools/user-managed-mcp)。

### 保存字段和状态

```tsx title="app/publish-request.tsx"
"use client";

import { useState } from "react";
import {
  ElicitationForm,
  type ElicitationField,
  type ElicitationState,
} from "@/components/assistant-ui/elements/elicitation-form";

const FIELDS: readonly ElicitationField[] = [
  { name: "repo", label: "Repository", value: "assistant-ui/assistant-ui", kind: "text", required: true },
  { name: "notify", label: "Notify watchers", value: "true", kind: "toggle" },
];

export function PublishRequest() {
  const [state, setState] = useState<ElicitationState>("request");

  return (
    <ElicitationForm
      server="github-mcp"
      message="Confirm where the release notes should be published."
      fields={FIELDS}
      state={state}
      onAccept={() => setState("accepted")}
      onDecline={() => setState("declined")}
    />
  );
}
```

  </Step>
  <Step>

### 从自有 schema 映射字段类型

如果字段来自类似 JSON Schema 的数据源，而不是手动编写，请按照运行时流程从 `requestedSchema` 派生字段类型 `kind`：

```tsx
function toElicitationField(
  name: string,
  schema: { type?: string; enum?: readonly string[] },
  value: string,
): ElicitationField {
  if (schema.type === "boolean") return { name, label: name, value, kind: "toggle" };
  if (schema.enum) return { name, label: name, value, kind: "choice", options: schema.enum };
  return { name, label: name, value, kind: "text" };
}
```

  </Step>
</Steps>

## 构成

```tsx
<div data-slot="elicitation-form">
  <div>{/* plug icon, server name, "needs input" tag */}</div>
  <p>{/* message */}</p>
  <div>{/* one row per field: label (+ "*" when required), then a pill group, a switch, or a static value chip depending on kind */}</div>
  <div>{/* Decline / Send while state is "request"; a settled "Sent to {server}" or "Declined" row otherwise */}</div>
</div>
```

`state` 会完全替换页脚，而不是将其禁用：一旦离开 `"request"` 状态，“拒绝”和“发送”控件就会消失，而不仅仅是变为不可用。`"choice"` 字段会将 `options` 中的每个选项渲染为一个标签，并突出显示与 `value` 相等的选项，因此该元素要求你确保 `value` 是所列选项之一。`"toggle"` 字段会从字面字符串 `"true"` 读取真假值，而不是从布尔值读取。

## 示例

### 重新设置表单样式

两种流程都会在根元素上接收 `className`。面板表面、字段标签和“发送”按钮会读取 `surfaces.tsx` 中共享的 `paper`、`mono` 和 `inkButton` 设计令牌。

```tsx
<ElicitationForm className="max-w-none" /* ... */ />
```

### 标记必填字段

<RuntimeMode>

`requestedSchema.required` 是一个普通的 JSON Schema 数组；对每个字段检查其成员关系，即可添加与单独使用的元素相同的标记：

```tsx
const required = new Set(
  (elicitation.requestedSchema as { required?: string[] })?.required ?? [],
);
// required.has(name) inside the Fields render prop
```

</RuntimeMode>

<StandaloneMode>

```tsx
{ name: "repo", label: "Repository", value: "", kind: "text", required: true }
```

</StandaloneMode>

### 拒绝与取消

<RuntimeMode>

该协议有三个终止操作，而不是两个：`McpElicitationPrimitive.Cancel` 会提交 `{ action: "cancel" }`，以及 Accept 的 `"accept"` 和 Decline 的 `"decline"`。当宿主需要区分“明确拒绝”和“未作答即关闭”时，将其作为第三个控件添加：

```tsx
<McpElicitationPrimitive.Cancel className="text-foreground/45 h-8 rounded-full px-3.5 text-xs">
  Dismiss
</McpElicitationPrimitive.Cancel>
```

</RuntimeMode>

<StandaloneMode>

单独使用的元素只对两种已结束状态建模。如果应用不需要区分拒绝和关闭，请将两者都路由到 `onDecline`：

```tsx
<ElicitationForm onDecline={() => setState("declined")} /* ... */ />
```

</StandaloneMode>

## API 参考

<RuntimeMode>

### McpElicitationPrimitive

| 部件 | 渲染内容 | 说明 |
|------|---------|-------|
| `Items` | fragment | 读取 `state.mcpServer.pendingElicitations`；列表为空时不渲染任何内容。每个待处理请求对应一个 `Root` 子树。 |
| `Root` | `div` | 携带 `data-elicitation-id`。 |
| `Message` | `span` | 除非传入 children，否则渲染 `elicitation.message`。 |
| `Error` | `div` | 渲染当前的验证错误或服务器错误消息；没有错误时不渲染任何内容。 |
| `Fields` | render prop | 对 `requestedSchema.properties` 中的每个属性调用一次 children，并且每个 children 都已包装在该字段自己的 `{ name, schema, value, setValue }` 中。 |
| `Accept` | `button` | 必填字段缺失或输入值无效时处于禁用状态。提交 `{ action: "accept", content }`。 |
| `Decline` | `button` | 提交 `{ action: "decline" }`。 |
| `Cancel` | `button` | 提交 `{ action: "cancel" }`。单独使用的元素的双状态模型中没有对应项。 |

### MCP 服务器状态

| 选择器 | 类型 | 描述 |
|----------|------|-------------|
| `s.mcpServer.pendingElicitations` | `readonly MCPElicitation[]` | 当前在此服务器上等待的所有请求；由 `Items` 读取。 |
| `aui.mcpServer.answerElicitation(id, response)` | `(id: string, response: MCPElicitationResponse) => readonly { property: string; message: string }[] \| undefined` | `Accept`、`Decline` 和 `Cancel` 调用的内容；当 `response.action === "accept"` 且值无效时，返回验证错误而不是提交。 |

需要 `@assistant-ui/react-mcp`，并且连接的服务器不能将其 `elicitation` 能力设置为 `false`。请参阅[用户管理的 MCP 服务器](/docs/tools/user-managed-mcp)。

</RuntimeMode>

<StandaloneMode>

### ElicitationForm

| Prop | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `server` | `string` | 必填 | 标题栏中显示的服务器名称。 |
| `message` | `string` | 必填 | 请求文本。 |
| `fields` | `readonly ElicitationField[]` | 必填 | 按顺序排列的请求字段。 |
| `state` | `ElicitationState` | 必填 | `"request"` 显示表单；`"accepted"` 或 `"declined"` 会将页脚替换为已结束状态消息。 |
| `onAccept` | `() => void` | | 点击“发送”时调用。 |
| `onDecline` | `() => void` | | 点击“拒绝”时调用。 |
| `className` | `string` | | 合并到根元素上。 |

`ElicitationField` 是 `{ name: string; label: string; value: string; kind: "text" | "choice" | "toggle"; options?: readonly string[]; required?: boolean }`，`ElicitationState` 是 `"request" | "accepted" | "declined"`。所有其他 `div` props 都会转发到根元素。

</StandaloneMode>
