输入框是用于编写下一条消息的圆角栏：它包含一个会不断扩展的文本字段，下方工具栏用于处理附件、当前模型，以及在运行期间切换为停止按钮的发送按钮。在运行时中，该输入框会读写线程的实时输入框状态；独立使用时，则需要自行管理该状态。

## 开始使用

<RuntimeMode>

每个 assistant-ui 运行时都会为当前线程（或正在编辑的消息）提供一个输入框：用于保存草稿文本、暂存的附件，以及发送和取消操作。使用 `ComposerPrimitive` 中的原语构建输入框栏，这些原语正是 `Thread` 元素内部渲染的同一组原语；再配合 `surfaces.tsx` 中共享的界面样式令牌，即可匹配本目录的外观。

### 组合输入框栏

```tsx title="components/assistant-ui/elements/composer-bar.tsx"
"use client";

import { AuiIf, ComposerPrimitive } from "@assistant-ui/react";
import { ArrowUpIcon, PlusIcon, SquareIcon } from "lucide-react";
import { cn } from "@/lib/utils";
import { ghostButton, inkButton, paper } from "@/components/assistant-ui/elements/surfaces";

export function ComposerBar() {
  return (
    <ComposerPrimitive.Root className={cn(paper, "flex w-full max-w-lg flex-col gap-2 rounded-[24px] p-2.5")}>
      <ComposerPrimitive.Input
        placeholder="Message..."
        rows={1}
        className="placeholder:text-foreground/35 min-h-11 w-full resize-none bg-transparent px-3 text-[15px] outline-none"
      />
      <div className="flex items-center justify-between">
        <ComposerPrimitive.AddAttachment
          aria-label="Add attachment"
          className={cn(ghostButton, "size-8 disabled:pointer-events-none disabled:opacity-30")}
        >
          <PlusIcon className="size-4" />
        </ComposerPrimitive.AddAttachment>
        <AuiIf condition={(s) => !s.thread.isRunning}>
          <ComposerPrimitive.Send
            aria-label="Send message"
            className={cn(inkButton, "grid size-8 place-items-center rounded-full")}
          >
            <ArrowUpIcon className="size-4" />
          </ComposerPrimitive.Send>
        </AuiIf>
        <AuiIf condition={(s) => s.thread.isRunning}>
          <ComposerPrimitive.Cancel
            aria-label="Stop generating"
            className={cn(inkButton, "grid size-8 place-items-center rounded-full")}
          >
            <SquareIcon className="size-3 fill-current" />
          </ComposerPrimitive.Cancel>
        </AuiIf>
      </div>
    </ComposerPrimitive.Root>
  );
}
```

`ComposerPrimitive.Root` 会渲染一个 `<form>`，按 Enter 提交（Shift+Enter 换行），并发送已暂存的所有文本和附件。线程开始运行后，`AuiIf` 会立即将 `Send` 替换为 `Cancel`，这与 `Thread` 自带输入框所执行的切换相同。

  </Step>
  <Step>

### 按需添加其余功能

附件、`/` 和 `@` 菜单、模型触发器以及听写，都是叠加到同一输入框栏上的独立原语。有关各个部分的接线方式，请参阅[附件](/elements/composer-attachments)、[斜杠命令](/elements/composer-slash-commands)、[提及](/elements/composer-mentions)、[模型](/elements/composer-model-picker)和[听写](/elements/composer-voice)。`Thread` 元素提供了一个由这些原语构建的完整输入框，因此安装 [Thread](/elements/thread) 后即可获得可用的输入框栏，无需自行组装；该元素适合用于构建自定义输入框，或用于 `Thread` 未覆盖的界面，例如紧凑的内联输入框。

  </Step>
</Steps>

独立使用时，`Composer` 及其子元素仅负责呈现：它们渲染外形并为可见状态添加动画，但自身不保存文本、附件或运行状态。你需要自行管理这些状态，并通过 props 和事件处理器向下传递。

### 管理输入框状态

```tsx title="app/chat-box.tsx"
"use client";

import { useState } from "react";
import { Composer, ComposerBar, ComposerInput, ComposerToolbar, ComposerActions, ComposerAttachButton, ComposerSend } from "@/components/assistant-ui/elements/composer";

export function ChatBox() {
  const [text, setText] = useState("");
  const [sending, setSending] = useState(false);

  const send = () => {
    if (!text.trim()) return;
    setSending(true);
    submitMessage(text).finally(() => setSending(false));
    setText("");
  };

  return (
    <Composer>
      <ComposerBar>
        <ComposerInput
          value={text}
          onChange={(e) => setText(e.target.value)}
          onSubmit={send}
          placeholder="Message..."
        />
        <ComposerToolbar>
          <ComposerAttachButton onClick={() => addAttachment()} />
          <ComposerActions>
            <ComposerSend streaming={sending} idle={!sending && text.trim().length > 0} onClick={send} />
          </ComposerActions>
        </ComposerToolbar>
      </ComposerBar>
    </Composer>
  );
}
```

  </Step>
  <Step>

### 了解工具栏自身的行为

`ComposerAttachButton` 在未接收到 `onClick` 时会自动禁用，因此未接线的按钮不会呈现为可点击状态。`ComposerSend` 永远不会自行禁用；它只会在看起来不可用的填充色（`!idle`）、墨色发送按钮（`idle`）和墨色停止按钮（`streaming`）之间改变外观。因此，如果调用方希望发送按钮真正处于禁用状态，需要通过 `...props` 传入 `disabled`。

  </Step>
</Steps>

</StandaloneMode>

## 结构

```tsx
<div data-slot="composer">
  <div data-slot="composer-bar" data-drag-active={/* true while a file is dragged over */}>
    <div data-slot="composer-attachments">{/* staged files, when any */}</div>
    <input data-slot="composer-input" />
    <div data-slot="composer-toolbar">
      <button data-slot="composer-attach" />
      <div data-slot="composer-actions">
        {/* model trigger, voice button, context ring, ... */}
        <button data-slot="composer-send" />
      </div>
    </div>
  </div>
</div>
```

`ComposerBar` 是唯一拥有真实视觉状态的部分：`dragActive` 会为其着色，并将其边角变为圆角投放目标。这里的其他部分默认都是简单、无样式的构建块；具体组合方式（工具栏中放置哪些内容、是否显示模型触发器或语音按钮）由组装它们的页面决定。

## 示例

### 将发送按钮替换为取消按钮

<RuntimeMode>

`AuiIf` 只会挂载两个按钮中的一个，这与 `Thread` 自带输入框的切换方式一致；启用了队列能力的运行时在运行期间仍会允许发送操作进入队列，因此该组合会提前一拍卸载 `Send`，否则按钮自身的 `canSend` 逻辑会让它继续保持活动状态：

```tsx
<ComposerActions>
  <AuiIf condition={(s) => !s.thread.isRunning}>
    <ComposerPrimitive.Send className={cn(inkButton, "grid size-8 place-items-center rounded-full")}>
      <ArrowUpIcon className="size-4" />
    </ComposerPrimitive.Send>
  </AuiIf>
  <AuiIf condition={(s) => s.thread.isRunning}>
    <ComposerPrimitive.Cancel className={cn(inkButton, "grid size-8 place-items-center rounded-full")}>
      <SquareIcon className="size-3 fill-current" />
    </ComposerPrimitive.Cancel>
  </AuiIf>
</ComposerActions>
```

</RuntimeMode>

<StandaloneMode>

单个 `ComposerSend` 会切换自身的图标；根据你认为处于“进行中”的状态来驱动 `streaming`：

```tsx
<ComposerActions>
  <ComposerSend streaming={isSending} idle={!isSending} onClick={isSending ? cancel : send} />
</ComposerActions>
```

</StandaloneMode>

### 重新设置输入框栏样式

这里的每个部分都接受 `className`；圆角、边框和悬停状态都来自 `surfaces.tsx` 中共享的 `paper`、`ghostButton` 和 `inkButton` 令牌。重新设置这些令牌的样式，会影响目录中所有使用它们的元素，而不仅仅是输入框。

```tsx
<ComposerBar className="max-w-2xl rounded-2xl p-4" />
```

## API 参考

<RuntimeMode>

### ComposerPrimitive

| 部件 | 渲染内容 | 说明 |
|------|---------|-------|
| `Root` | `form` | 提交时发送；`Input` 会在按下 Enter 时触发提交；当文本最多只有一行，且没有附件、引用、排队消息或正在进行的听写时，`compact` 会将其收缩为单行。 |
| `Input` | 自动调整大小的 `textarea` | 由运行时控制；在线程被禁用或听写处于活动状态时禁用。`submitMode`（`"enter"` \| `"ctrlEnter"` \| `"none"`）控制 Enter 的行为。 |
| `Send` | `button` | 在 `!s.composer.canSend` 期间禁用；在线程运行期间也会禁用，除非线程具备队列能力。 |
| `Cancel` | `button` | 在 `!s.composer.canCancel` 期间禁用。 |
| `AddAttachment` | `button` | 打开由 `attachmentAccept` 过滤的原生文件选择器；仅在输入框不可编辑时禁用，因此在未配置适配器的情况下进行选择，会打开选择器，但不会提示添加文件失败。 |
| `AttachmentDropzone` | `div`（或 `asChild`） | 文件拖入时设置 `data-dragging="true"`；每个文件放下时都会调用 `addAttachment`。 |

### 输入框状态

| 选择器 | 类型 | 描述 |
|----------|------|-------------|
| `s.composer.text` | `string` | 当前草稿文本。 |
| `s.composer.isEmpty` | `boolean` | 输入框是否没有文本和附件。 |
| `s.composer.canSend` | `boolean` | `send()` 当前是否会执行任何操作。 |
| `s.composer.canCancel` | `boolean` | `cancel()` 当前是否会执行任何操作。 |
| `s.composer.attachments` | `readonly Attachment[]` | 此输入框中暂存的文件；请参阅[附件](/elements/composer-attachments)。 |
| `s.thread.isRunning` | `boolean` | 线程是否有正在进行的运行。 |
| `aui.composer.send(options?)` | `(options?: { startRun?: boolean; steer?: boolean }) => void` | 发送暂存的文本和附件。 |
| `aui.composer.cancel()` | `() => void` | 取消当前运行，或退出编辑模式。 |

</RuntimeMode>

### Composer

| Prop | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `className` | `string` | | 合并到根 `div` 上。 |

其他所有 `div` props 都会向下传递。

### ComposerBar

| Prop | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `dragActive` | `boolean` | `false` | 为输入框栏着色，并将其边框设置为虚线，使其成为投放目标。 |
| `className` | `string` | | 合并到根元素上。 |

### ComposerInput

| Prop | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `onSubmit` | `() => void` | | 在按下 Enter 时调用（Shift+Enter 以及输入法组合输入期间除外）。 |
| `className` | `string` | | 合并到 `input` 上。 |

其他所有 `input` props 都会向下传递。

### ComposerToolbar / ComposerActions

普通的 `div`（`data-slot="composer-toolbar"` 和 `data-slot="composer-actions"`），用于将子元素按行排列；二者都会向下传递所有 `div` prop。

### ComposerAttachButton

| Prop | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `onClick` | `() => void` | | 按钮要呈现为启用状态必须提供；省略时按钮会呈现为禁用状态。 |

### ComposerSend

| Prop | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `streaming` | `boolean` | 必填 | 显示停止图标和墨色填充。 |
| `idle` | `boolean` | 必填 | 非流式传输时显示墨色填充；否则显示较暗的填充。 |
