MemoryChips 会列出助手目前记住的关于你的信息：每条事实对应一个胶囊，新写入的内容会带有色 tint，并且每条都有独立的忘记按钮。在运行时中，这些胶囊来自当前回合中发起的 `remember` 工具调用；在独立使用时，则由你持有整个列表。

## 开始使用

<RuntimeMode>

assistant-ui 没有内置的记忆概念：消息中没有任何内容会跟踪助手了解到的用户事实。最接近的实际构建模块是工具调用，就像评分后的声明或比较表一样。为模型提供一个 `remember` 工具，并将它在当前消息中发起的每次调用收集到胶囊列表中。

<Steps>
  <Step>

### 从消息中读取 remember 调用

```tsx title="components/assistant-ui/elements/thread.aui.tsx"
"use client";

import { useAuiState } from "@assistant-ui/react";
import type { ToolCallMessagePart } from "@assistant-ui/react";
import {
  MemoryChips,
  type MemoryChip,
} from "@/components/assistant-ui/elements/memory-chips";

type RememberCall = ToolCallMessagePart<
  { text: string; change: "added" | "updated" },
  void
>;

function MemoryFromMessage() {
  const chips = useAuiState((s): MemoryChip[] =>
    s.message.role === "assistant"
      ? s.message.content
          .filter(
            (part): part is RememberCall =>
              part.type === "tool-call" && part.toolName === "remember",
          )
          .map((part) => ({
            id: part.toolCallId,
            text: part.args.text,
            change: part.args.change,
          }))
      : [],
  );

  if (chips.length === 0) return null;
  return <MemoryChips chips={chips} onForget={forgetMemory} />;
}
```

`remember` 及其 `{ text, change }` 参数是你自己的工具契约；`part.args` 则是实际的类型化底层管道，会在调用流式传输时将模型写回客户端的内容传递过去。

  </Step>
  <Step>

### 注册工具

上一步已经跨所有调用聚合并渲染了胶囊列表，因此工具自身的 `render` 已经没有需要显示的内容，会返回 `null`。

```tsx title="app/toolkit.ts"
import { defineToolkit } from "@assistant-ui/react";
import { z } from "zod";

export const toolkit = defineToolkit({
  remember: {
    type: "frontend",
    description: "Save a fact about the user for future turns.",
    parameters: z.object({
      text: z.string(),
      change: z.enum(["added", "updated"]),
    }),
    execute: async ({ text, change }) => {
      await saveMemory({ text, change });
    },
    render: () => null,
  },
});
```

在运行时配置中使用 `Tools({ toolkit })` 接入工具包，方式与其他工具包相同。请参阅 [工具 UI](/docs/tools/tool-ui)。

  </Step>
</Steps>

</RuntimeMode>

<Steps>
  <Step>

### 持有胶囊列表

```tsx title="app/memory.tsx"
"use client";

import { useState } from "react";
import {
  MemoryChips,
  type MemoryChip,
} from "@/components/assistant-ui/elements/memory-chips";

const INITIAL: MemoryChip[] = [
  { id: "1", text: "Prefers TypeScript", change: "existing" },
  { id: "2", text: "Works on assistant-ui", change: "existing" },
];

export function Memory() {
  const [chips, setChips] = useState(INITIAL);
  return (
    <MemoryChips
      chips={chips}
      onForget={(id) => setChips((c) => c.filter((chip) => chip.id !== id))}
    />
  );
}
```

  </Step>
  <Step>

### 标记新的记忆

使用 `change: "added"` 或 `"updated"` 添加胶囊后，标题会从 `memory` 变为 `remembered N`；请参阅“组成”。

```tsx
setChips((c) => [
  ...c,
  { id: crypto.randomUUID(), text: "Ships on Fridays", change: "added" },
]);
```

  </Step>
</Steps>

</StandaloneMode>

## 组成

```tsx
<div data-slot="memory-chips">
  <div>
    <svg aria-hidden />{/* brain icon */}
    <span>{/* "memory" or "remembered N" */}</span>
  </div>
  <div>
    <span>
      {/* one pill per chip */}
      <button aria-label={/* Forget "..." */} />
    </span>
  </div>
</div>
```

在至少一个胶囊的 `change` 为 `"added"` 或 `"updated"` 之前，标题显示为 `memory`；之后会切换为 `remembered N`，其中 N 只统计非 `existing` 胶囊。颜色表示两种状态，而不是三种：`existing` 胶囊使用中性的 `field` 表面，而 `added` 和 `updated` 胶囊共享完全相同的蓝色色调，因此调用方无法仅通过颜色区分这两者。每个胶囊以 `chip.id` 作为 key，并以 300ms 的淡入和缩放效果挂载，因此添加新胶囊时只有该胶囊会播放动画；屏幕上已有的胶囊会保留其 DOM 节点，且不会重新播放动画。空的 `chips` 数组只会渲染标题，显示为 `memory`，不会显示占位胶囊。

## 示例

### 合并本轮对话之前的记忆

<RuntimeMode>

`s.message.content` 只包含本条消息中发生的内容；三轮对话前记住的事实不会在此处有可读取的工具调用部分。将你自己持久化的列表放在上方选择器返回的新记忆之前进行合并：

```tsx
const chips = [...existingMemories, ...freshChipsFromMessage];
```

对 `existing` 胶囊中的 `onForget` 进行操作时，应直接调用你自己的移除端点：本条消息中没有需要更新的工具调用，因此裁剪本地状态是让胶囊立即消失的唯一方式。

</RuntimeMode>

<StandaloneMode>

这里的合并方式更简单：将你的持久化列表与上一轮对话新增的内容连接起来，然后将结果传递给 `chips`。

</StandaloneMode>

### 重新设置胶囊样式

两条通道的根元素都接受 `className`。标题标签使用共享的 `mono` token，`existing` 胶囊使用 `field`，忘记按钮使用 `ghostButton`，全部位于 `surfaces.tsx` 中。

```tsx
<MemoryChips className="gap-3" /* ... */ />
```

## API 参考

<RuntimeMode>

### 消息状态

| 选择器 / 字段 | 类型 | 描述 |
|--------------------|------|-------------|
| `s.message.content` | `readonly ThreadAssistantMessagePart[]` | 在此搜索 `tool-call` 部分，其 `toolName` 与你的 remember 工具匹配；assistant-ui 没有内置的 memory 字段。 |
| `ToolCallMessagePart.args` | `TArgs` | 模型对该调用提供的参数，其类型由你传递给 `ToolCallMessagePart<TArgs, TResult>` 的泛型指定。调用仍在流式传输时，该值可能是不完整的。 |
| `ToolCallMessagePart.toolCallId` | `string` | 该调用的稳定 ID；可自然作为 `MemoryChip.id`。 |

</RuntimeMode>

<StandaloneMode>

### MemoryChips

| Prop | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `chips` | `readonly MemoryChip[]` | 必填 | 要渲染的胶囊，按顺序排列。 |
| `onForget` | `(id: string) => void` | | 按下胶囊的忘记按钮时，会传入该胶囊的 `id` 进行调用。 |
| `className` | `string` | | 合并到根元素上。 |

### MemoryChip

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `id` | `string` | |
| `text` | `string` | |
| `change` | `"added" \| "updated" \| "existing"` | `existing` 会渲染为中性样式；`added` 和 `updated` 共享相同的高亮外观。 |

其他所有 `div` props 都会转发到根元素。

</StandaloneMode>
