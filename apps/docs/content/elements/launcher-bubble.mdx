title: "启动器"
description: "浮动入口，以及它打开的面板。"

一个浮动按钮，点击后打开一个小面板：包含问候语、几个起始提示，以及开始对话的方式。在运行时中，这些提示会填入真正的输入框，而启动对话的按钮就是实际的发送按钮；在独立模式下，每次交互都是由你自行接入的回调。

## 入门

<RuntimeMode>

除了用户在面板中按下某个控件后发生的事情外，面板本身没有任何运行时状态。使用 `ThreadPrimitive.Suggestion` 和 `ComposerPrimitive.Send` 重建面板中的两个交互部分，启动器会驱动与你的应用其余部分相同的输入框和会话线程。

### 将提示和开始按钮接入运行时

```tsx title="components/assistant-ui/elements/launcher.tsx"
"use client";

import { useState } from "react";
import { ComposerPrimitive, ThreadPrimitive, useAuiEvent } from "@assistant-ui/react";
import { MessageCircleIcon, XIcon } from "lucide-react";
import { cn } from "@/lib/utils";
import { field, floating, inkButton, mono } from "@/components/assistant-ui/elements/surfaces";

const PROMPTS = ["Summarize this page", "Find a teammate", "Report a bug"];

export function Launcher() {
  const [open, setOpen] = useState(false);

  // Surface the panel the moment a run starts, even if it was triggered elsewhere.
  useAuiEvent("thread.runStart", () => setOpen(true));

  return (
    <div className="flex w-full max-w-[19rem] flex-col items-end gap-2.5">
      {open && (
        <div className={cn(floating, "flex w-full flex-col gap-3 rounded-[20px] p-4")}>
          <div className="flex flex-col gap-1">
            <span className="text-[13.5px] font-medium">How can I help?</span>
            <span className={cn(mono, "text-foreground/30")}>typically replies in a minute</span>
          </div>

          <div className="flex flex-col gap-1.5">
            {PROMPTS.map((prompt) => (
              <ThreadPrimitive.Suggestion
                key={prompt}
                prompt={prompt}
                className={cn(
                  field,
                  "hover:bg-foreground/[0.07] text-foreground/70 rounded-xl px-3 py-2 text-start text-[13px] transition-colors",
                )}
              >
                {prompt}
              </ThreadPrimitive.Suggestion>
            ))}
          </div>

          <ComposerPrimitive.Send
            className={cn(inkButton, "flex h-8 items-center justify-center rounded-full text-xs font-medium")}
          >
            Start a conversation
          </ComposerPrimitive.Send>
        </div>
      )}

      <button
        type="button"
        aria-expanded={open}
        aria-label={open ? "Close the assistant" : "Open the assistant"}
        onClick={() => setOpen((o) => !o)}
        className={cn(inkButton, "flex size-12 items-center justify-center rounded-full")}
      >
        {open ? <XIcon className="size-5" /> : <MessageCircleIcon className="size-5" />}
      </button>
    </div>
  );
}
```

`ThreadPrimitive.Suggestion` 默认会替换输入框文本，而不是直接发送，因此选择提示后会将其载入输入框，供用户查看；之后由 `ComposerPrimitive.Send` 真正开始运行（输入框为空时，该按钮会自动禁用）。

### 保存打开状态和提示列表

```tsx title="app/support-launcher.tsx"
"use client";

import { useState } from "react";
import { LauncherBubble } from "@/components/assistant-ui/elements/launcher-bubble";

const prompts = ["Reset my password", "Talk to a person", "Where is my order?"];

export function SupportLauncher() {
  const [open, setOpen] = useState(false);
  const [unread, setUnread] = useState(2);

  return (
    <LauncherBubble
      open={open}
      unread={unread}
      greeting="Hey, need a hand?"
      prompts={prompts}
      onToggle={() => {
        setOpen((o) => !o);
        setUnread(0);
      }}
      onPick={(prompt) => console.log("picked", prompt)}
      onStart={() => console.log("start")}
    />
  );
}
```

## 结构

```tsx
<div data-slot="launcher-bubble">
  {/* only in the DOM while open; no closing transition, it just unmounts */}
  <div>
    <span>{/* greeting */}</span>
    <span>{/* "typically replies in a minute" */}</span>
    <div>{/* one button per prompt */}</div>
    <button>{/* "Start a conversation" */}</button>
  </div>
  <button aria-expanded aria-label="Open the assistant | Close the assistant">
    {/* message-circle and X layered in the same cell, cross-fading with a 90deg rotation */}
    <span>{/* unread count, only while closed and unread > 0 */}</span>
  </button>
</div>
```

切换按钮始终会渲染；它上方的面板仅在 `open` 为 true 时挂载，并带有进入动画（淡入、缩放和向上滑动），没有匹配的退出动画，因此关闭会立即生效。当 `open` 变为 true 时，未读徽标会立即消失，与 `unread` 的值无关。因此，宿主应用应在打开面板时清除自己的未读计数，而不要依赖徽标来完成这项工作。这里没有任何控件会被禁用：在独立模式下，提示按钮和开始按钮始终可以点击，因为没有输入框状态可以用来限制它们。

## 示例

### 重新设置面板和切换按钮的样式

两种模式都会在根元素上接收 `className`，它只影响布局（宽度、间距和对齐方式）；面板和切换按钮会从共享的 `floating` 和 `inkButton` 令牌中读取表面样式，因此重新设置这两个令牌的主题，就能覆盖此元素在各处的显示效果。

```tsx
<LauncherBubble className="max-w-xs" /* ... */ />
```

### 为关闭状态的切换按钮添加徽标

<StandaloneMode>

`unread` 是一个由你管理的普通数字。常见做法是在面板关闭期间每收到一条消息就将其递增，并像上面的示例一样在 `onToggle` 中将其重置，这样徽标始终表示“自我上次打开此面板以来”的消息数。

</StandaloneMode>

<RuntimeMode>

运行时没有未读消息的概念；它不会区分“用户已查看的消息”和“用户尚未查看的消息”。请自行跟踪，例如将 `s.thread.messages.length` 与面板打开时上次记录的数量进行比较，然后通过独立模式使用的同一个 `unread` 属性传入差值。

</RuntimeMode>

## API 参考

<RuntimeMode>

此元素没有专用原语；其中的两个交互部分是 `ThreadPrimitive.Suggestion` 和 `ComposerPrimitive.Send`，二者都属于 `@assistant-ui/react` 的原语集合。其余部分——打开、关闭和未读计数——都是由你管理的组件状态，具体如入门部分所示。

### 上文使用的线程事件

| 事件 | 负载 | 描述 |
|-------|---------|-------------|
| `thread.runStart` | `{ threadId: string }` | 任意来源启动运行时触发。使用 `useAuiEvent` 订阅后，即使消息是在应用的其他位置发送的，也能让面板显示出来。 |

</RuntimeMode>

<StandaloneMode>

### LauncherBubble

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `open` | `boolean` | 必填 | 面板是否显示。 |
| `unread` | `number` | 必填 | 面板关闭时显示在切换按钮上的计数。当 `open` 为 true 时完全隐藏。 |
| `greeting` | `string` | 必填 | 显示在面板顶部的标题。 |
| `prompts` | `readonly string[]` | 必填 | 起始提示，每条提示对应一个按钮。 |
| `onToggle` | `() => void` | | 按下切换按钮时调用。 |
| `onPick` | `(prompt: string) => void` | | 按下提示按钮时，以该提示的文本作为参数调用。 |
| `onStart` | `() => void` | | 按下“开始对话”时调用。 |
| `className` | `string` | | 合并到根元素上。 |

所有其他 `div` 属性都会转发到根元素。

</StandaloneMode>
