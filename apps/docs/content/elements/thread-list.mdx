线程列表是会话切换器：包含新线程按钮、在有内容可搜索后显示的搜索框，以及按日期分组的所有历史线程，并支持重命名、归档和删除。在运行时中，它会直接读取和写入线程列表；在独立模式下，你需要传入行数据，并报告当前活动的行。

## 开始使用

<RuntimeMode>

`ThreadList`不接收任何 props：将其挂载到运行时提供程序中的任意位置，它会自行读取和写入线程列表。

<Steps>
  <Step>

### 直接使用

```tsx title="app/sidebar.tsx"
import { ThreadList } from "@/components/assistant-ui/elements/thread-list.aui";

export function Sidebar() {
  return (
    <aside className="w-64 border-e p-2">
      <ThreadList />
    </aside>
  );
}
```

[线程列表侧边栏](/elements/thread-list-sidebar)已经将此组件与完整的可折叠侧边栏外壳配套使用；如果你需要的不是一个简单面板，可以使用它。

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

在独立模式下，该元素是一个受控的行列表：由你持有线程和活动索引，它负责渲染行并报告点击事件。元素本身没有内置的新线程按钮或搜索功能；两者都需要放在元素外部。

<Steps>
  <Step>

### 管理线程状态

```tsx title="app/sidebar.tsx"
"use client";

import { useState } from "react";
import {
  ThreadList,
  type ThreadItem,
} from "@/components/assistant-ui/elements/thread-list";

const threads: ThreadItem[] = [
  { title: "Renaming a component", time: "2m", unread: true },
  { title: "Deploy checklist", time: "1h" },
];

export function Sidebar() {
  const [activeIndex, setActiveIndex] = useState(0);
  return (
    <ThreadList
      threads={threads}
      activeIndex={activeIndex}
      onActiveIndexChange={setActiveIndex}
    />
  );
}
```

  </Step>
</Steps>

</StandaloneMode>

## 结构

```tsx
<div data-slot="aui_thread-list-root">
  <button data-slot="aui_thread-list-new">New Thread</button>
  <div data-slot="aui_thread-list-search" /> {/* runtime only, once a thread exists */}
  <div data-slot="aui_thread-list-items">
    <div data-slot="aui_thread-list-group-label">Today</div>
    <div data-slot="aui_thread-list-item">
      <button data-slot="aui_thread-list-item-trigger">
        {/* spinner while running, then the title */}
      </button>
      <button data-slot="aui_thread-list-item-more" aria-label="More options" />
    </div>
  </div>
</div>
```

在运行时中，只有至少存在一个线程时才会渲染搜索框；它会针对每个线程的标题执行不区分大小写的过滤。对于没有标题的线程，则会匹配 "New Chat"；没有匹配结果时，会显示 "No threads found"，而不是线程列表。行会根据`lastMessageAt`归入 Today、Yesterday 和 Earlier 分组，但只有当至少一个可见线程实际带有时间戳时才会分组；否则列表将以扁平形式渲染，不显示分组标签。活动线程带有`data-active`和`aria-current`。重命名时，行的触发器会原地替换为内联输入框（Enter 提交、Escape 取消、失去焦点提交）；它不会离开列表进行导航。

在独立模式下，由于没有可用于分组的时间戳，该元素会在每一行上方渲染一个固定的 "Today" 标签，而不考虑实际日期；它本身也没有新线程控件或搜索功能。它的重命名和删除图标仅用于展示：会在悬停时显示，但不带点击处理程序，因为该文件会被复制到你的项目中，由你自行添加处理逻辑。

## 示例

### 搜索

<RuntimeMode>

搜索功能内置，无需额外连接；线程列表非空后会显示搜索框，并随着输入内容缩小到匹配的标题。

</RuntimeMode>

<StandaloneMode>

该元素本身没有搜索输入框。在传入数组之前，先过滤你已经持有的数组：

```tsx
<ThreadList
  threads={threads.filter((t) =>
    t.title.toLowerCase().includes(query.toLowerCase()),
  )}
  activeIndex={activeIndex}
  onActiveIndexChange={setActiveIndex}
/>
```

</StandaloneMode>

### 重命名

<RuntimeMode>

更多菜单中的 Rename 项已经完成连接。若不通过菜单进行重命名，可以调用它使用的同一个方法：

```tsx
const aui = useAui();
aui.threads.item({ id: threadId }).rename("Q3 planning");
```

</RuntimeMode>

<StandaloneMode>

铅笔图标默认未连接。为它添加点击处理程序，使其像运行时实现那样将行切换为可编辑状态，因为复制该文件后，它就属于你的项目。

</StandaloneMode>

### 重新设置样式

两种模式都会在根元素上接收`className`。在独立模式下，活动行的填充色和末尾时间戳使用来自`surfaces.tsx`的共享`field`和`mono`令牌，因此重新设置这两个令牌的样式，就会重新设置所有使用它们的元素。

```tsx
<ThreadList className="max-w-[280px]" /* ... */ />
```

## API 参考

<RuntimeMode>

### ThreadListPrimitive

| 部件 | 渲染内容 | 说明 |
|------|---------|-------|
| `Root` | `div` | 提供线程列表的键盘焦点组。 |
| `New` | `button` | 切换到运行时的占位新线程。已处于该线程时会带有`data-active`。 |
| `ItemByIndex` | 无固定元素 | 通过你提供的`components.ThreadListItem`在`index`处渲染一个项目。`ThreadList`会自行按日期对这些项目分组，而不是使用更简单的`Items`原语；后者会在没有日期标题的列表中渲染所有未分组的项目。 |

### ThreadListItemPrimitive 和 ThreadListItemMorePrimitive

| 部件 | 渲染内容 | 说明 |
|------|---------|-------|
| `ThreadListItemPrimitive.Root` | `div` | 为主线程携带`data-active`/`aria-current`。 |
| `ThreadListItemPrimitive.Trigger` | `button` | 切换到此线程。 |
| `ThreadListItemPrimitive.Title` | 文本 | 线程标题；尚无标题时会渲染`fallback`。 |
| `ThreadListItemPrimitive.Archive` | `button` | 归档线程。接受`asChild`。 |
| `ThreadListItemPrimitive.Delete` | `button` | 删除线程。接受`asChild`。 |
| `ThreadListItemMorePrimitive.Root` | 无固定元素 | `sharedFocusGroup`会将菜单折叠到列表自身的键盘导航中，而不是使用独立的模态下拉菜单。 |
| `ThreadListItemMorePrimitive.Trigger` / `.Content` / `.Item` | `button` / 菜单 / 菜单项 | 溢出菜单外壳。 |

### 线程列表状态

| 选择器 | 类型 | 描述 |
|----------|------|--------------|
| `s.threads.threadIds` | `readonly string[]` | 按显示顺序排列的 ID。 |
| `s.threads.threadItems` | `readonly ThreadListItemState[]` | 每个 ID 对应一个状态对象，其中包括`title`和`lastMessageAt`。 |
| `s.threads.isLoading` | `boolean` | 列表本身仍在加载时为 true。 |
| `s.threadListItem.id` | `string` | `ItemByIndex`内部当前作用域中项目的 ID。 |
| `s.threadListItem.title` | `string \| undefined` | 在运行时为线程命名之前为 undefined。 |
| `s.threadListItem.isRunning` | `boolean` | 此线程是否正在执行 run，即使它不是当前打开的线程。 |
| `aui.threads.item({ id }).rename(title)` | `(title: string) => void` | 按 ID 重命名线程，无需经过更多菜单。 |

</RuntimeMode>

<StandaloneMode>

### ThreadList

| Prop | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `threads` | `readonly ThreadItem[]` | 必填 | 要按顺序渲染的行。 |
| `activeIndex` | `number` | 必填 | 高亮行的索引。 |
| `onActiveIndexChange` | `(index: number) => void` | | 使用点击行的索引调用。 |
| `className` | `string` | | 合并到根元素上。 |

其他所有`div` props 都会转发到根元素。

### ThreadItem

| 字段 | 类型 | 描述 |
|-------|------|--------------|
| `title` | `string` | 行标签。 |
| `time` | `string` | 末尾的时间戳文本，已经过格式化。 |
| `unread` | `boolean \| undefined` | 为 true 且该行不是活动行时，会在时间戳前显示一个圆点。 |

</StandaloneMode>
