---
title: "消息操作"
description: "复制、评价和重新生成。每个操作都会通过细微的状态变化确认自身结果。"
---

助手回复下方的操作栏：复制、点踩或点赞、重新生成，以及用于容纳其他操作的更多按钮。每个操作都会在原地确认结果，而不是显示 toast：复制按钮会切换为对勾，评价按钮会填充，重新生成时图标会旋转。使用运行时（runtime）时，每个按钮都会直接调用线程；独立使用时，则由你保存每个按钮所反映的状态和触发的回调。

## 入门

`ActionBarPrimitive` 为每个操作提供一个按钮；每个按钮都已连接到其所在消息，并会在对应操作不可用时立即禁用。

### 组合操作栏

```tsx title="components/assistant-ui/elements/message-actions.tsx"
"use client";

import { ActionBarPrimitive, AuiIf } from "@assistant-ui/react";
import {
  CheckIcon,
  CopyIcon,
  RefreshCwIcon,
  ThumbsDownIcon,
  ThumbsUpIcon,
} from "lucide-react";
import { cn } from "@/lib/utils";
import { ghostButton } from "@/components/assistant-ui/elements/surfaces";

export function MessageActions() {
  const buttonClassName = cn(ghostButton, "size-7");

  return (
    <ActionBarPrimitive.Root className="flex items-center gap-1">
      <ActionBarPrimitive.Copy aria-label="Copy response" className={buttonClassName}>
        <AuiIf condition={(s) => s.message.isCopied}>
          <CheckIcon className="size-3.5" />
        </AuiIf>
        <AuiIf condition={(s) => !s.message.isCopied}>
          <CopyIcon className="size-3.5" />
        </AuiIf>
      </ActionBarPrimitive.Copy>
      <ActionBarPrimitive.FeedbackPositive aria-label="Mark response helpful" className={buttonClassName}>
        <ThumbsUpIcon className="size-3.5" />
      </ActionBarPrimitive.FeedbackPositive>
      <ActionBarPrimitive.FeedbackNegative aria-label="Mark response unhelpful" className={buttonClassName}>
        <ThumbsDownIcon className="size-3.5" />
      </ActionBarPrimitive.FeedbackNegative>
      <ActionBarPrimitive.Reload aria-label="Regenerate response" className={buttonClassName}>
        <RefreshCwIcon className="size-3.5" />
      </ActionBarPrimitive.Reload>
    </ActionBarPrimitive.Root>
  );
}
```

`ActionBarPrimitive.Copy` 会在复制成功后将 `data-copied="true"` 设置三秒（可通过 `copiedDuration` 调整），而 `ActionBarPrimitive.FeedbackPositive`/`FeedbackNegative` 会在 `s.message.metadata.submittedFeedback` 匹配时设置 `data-submitted="true"`。请根据这些属性设置样式，而不是自行维护布尔值。

  </Step>
  <Step>

### 添加更多菜单

`ActionBarMorePrimitive` 是一个作用域限定在同一条消息上的 Radix 下拉菜单；`ActionBarPrimitive.ExportMarkdown` 是可直接使用的菜单项。

```tsx
import { ActionBarMorePrimitive, ActionBarPrimitive } from "@assistant-ui/react";
import { DownloadIcon, EllipsisIcon } from "lucide-react";

<ActionBarMorePrimitive.Root>
  <ActionBarMorePrimitive.Trigger aria-label="More response actions" className={buttonClassName}>
    <EllipsisIcon className="size-3.5" />
  </ActionBarMorePrimitive.Trigger>
  <ActionBarMorePrimitive.Content side="bottom" align="start" className="bg-popover rounded-xl border p-1.5">
    <ActionBarPrimitive.ExportMarkdown asChild>
      <ActionBarMorePrimitive.Item className="flex items-center gap-2 rounded-lg px-2.5 py-1.5 text-sm">
        <DownloadIcon className="size-4" />
        Export as Markdown
      </ActionBarMorePrimitive.Item>
    </ActionBarPrimitive.ExportMarkdown>
  </ActionBarMorePrimitive.Content>
</ActionBarMorePrimitive.Root>
```

`Thread` 元素会在每条助手消息上提供复制、重新加载和这个完全相同的更多菜单；它不包含上面的反馈按钮，因此如果需要评价，请将 `FeedbackPositive`/`FeedbackNegative` 添加到 `Thread` 的操作栏旁边。

  </Step>
</Steps>

独立使用时，`MessageActions` 完全受控：五个回调，以及决定每个按钮当前外观的各项状态。

### 保存操作栏状态

```tsx title="app/reply.tsx"
"use client";

import { useState } from "react";
import { MessageActions, type Reaction } from "@/components/assistant-ui/elements/message-actions";

export function Reply() {
  const [copied, setCopied] = useState(false);
  const [reaction, setReaction] = useState<Reaction>(null);
  const [regenerating, setRegenerating] = useState(false);

  return (
    <MessageActions
      copied={copied}
      reaction={reaction}
      regenerating={regenerating}
      onCopy={() => {
        navigator.clipboard.writeText("...");
        setCopied(true);
        setTimeout(() => setCopied(false), 2000);
      }}
      onReactionChange={setReaction}
      onRegenerate={async () => {
        setRegenerating(true);
        await regenerate();
        setRegenerating(false);
      }}
      onMore={() => {}}
    />
  );
}
```

  </Step>
  <Step>

### 从 `onMore` 打开自定义菜单

`onMore` 会在点击时触发，但不会附带内置菜单；调用它时，可以从自己的组件树中打开弹出层或下拉菜单。

  </Step>
</Steps>

</StandaloneMode>

## 构成

```tsx
<div data-slot="message-actions">
  <button aria-label="Copy response" />
  <button aria-label="Mark response helpful" aria-pressed={false} />
  <button aria-label="Mark response unhelpful" aria-pressed={false} />
  <button aria-label="Regenerate response" />
  <button aria-label="More response actions" />
</div>
```

独立使用时，两个评价按钮是 `aria-pressed` 切换按钮，并且互斥：再次按下当前激活的按钮会调用 `onReactionChange(null)` 将其清除，按下另一个按钮则会直接切换。复制按钮的图标会在（`iconSwap`/`iconSwapIn`/`iconSwapOut`）之间切换，并在 `copied` 为 true 时使用翠绿色调；`regenerating` 为 true 时，重新生成图标会旋转。在运行时中，`ActionBarPrimitive.FeedbackPositive`/`FeedbackNegative` 也互斥（提交其中一个会在 `s.message.metadata.submittedFeedback` 中替换另一个），但无法清除：`MessageMethods.submitFeedback` 只会写入反应，因此提交一个反应后，消息没有内置方式回到“无反应”状态，不像独立使用时的切换按钮那样。

### 重新设置操作栏样式

两种方式都会在根元素上接收 `className`，而来自 `surfaces.tsx` 的图标切换令牌（`iconSwap`、`iconSwapIn`、`iconSwapOut`）和 `ghostButton` 会覆盖复制过渡效果以及每个按钮的悬停状态。

```tsx
<MessageActions className="gap-2" /* ... */ />
```

## API 参考

<RuntimeMode>

### ActionBarPrimitive 和 ActionBarMorePrimitive

| 部件 | 渲染内容 | 说明 |
|------|---------|-------|
| `ActionBarPrimitive.Root` | `div` | `hideWhenRunning`、`autohide` 和 `autohideFloat` 控制可见性；未设置时，操作栏始终渲染。 |
| `ActionBarPrimitive.Copy` | `button` | 没有可复制的文本后禁用。`copiedDuration`（默认值为 `3000`）控制 `data-copied` 保持设置状态的时长。 |
| `ActionBarPrimitive.FeedbackPositive` | `button` | 调用 `aui.message.submitFeedback({ type: "positive" })`。 |
| `ActionBarPrimitive.FeedbackNegative` | `button` | 调用 `aui.message.submitFeedback({ type: "negative" })`。 |
| `ActionBarPrimitive.Reload` | `button` | 在线程运行、被禁用或消息并非来自助手时禁用。 |
| `ActionBarPrimitive.ExportMarkdown` | `button` | 将消息复制或下载为 Markdown；将其放入 `ActionBarMorePrimitive.Item` 内。 |
| `ActionBarMorePrimitive.Root` | 仅上下文 | 一个作用域限定在操作栏交互锁内的 Radix `DropdownMenu.Root`。 |
| `ActionBarMorePrimitive.Trigger` / `.Content` / `.Item` / `.Separator` | button / div / div / div | 标准下拉菜单部件。 |

### 消息状态

| 选择器 | 类型 | 描述 |
|----------|------|-------------|
| `s.message.isCopied` | `boolean` | `ActionBarPrimitive.Copy` 成功后，`copiedDuration` 为 true。 |
| `s.message.metadata.submittedFeedback?.type` | `"positive" \| "negative" \| undefined` | 这条消息最后提交的反馈（如果有）。 |
| `aui.message.submitFeedback({ type })` | `(feedback: { type: "positive" \| "negative" }) => void` | 记录一个反应。没有清除反应的方法。 |
| `aui.message.reload(config?)` | `(config?: { runConfig?: RunConfig }) => void` | 将这条助手消息重新生成为新的同级分支。 |

</RuntimeMode>

<StandaloneMode>

### MessageActions

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `copied` | `boolean` | 必填 | 在复制按钮上显示对勾并使用翠绿色调。 |
| `reaction` | `"up" \| "down" \| null` | 必填 | 哪个评价按钮（如果有）显示为按下状态。 |
| `regenerating` | `boolean` | 必填 | 使重新生成图标旋转。 |
| `onCopy` | `() => void` | 必填 | 按下复制按钮时调用。 |
| `onReactionChange` | `(reaction: "up" \| "down" \| null) => void` | 必填 | 使用下一个反应调用；再次按下当前激活的按钮时传入 `null`。 |
| `onRegenerate` | `() => void` | 必填 | 按下重新生成按钮时调用。 |
| `onMore` | `() => void` | 必填 | 按下更多按钮时调用。 |
| `className` | `string` | | 合并到根元素上。 |

其他所有 `div` 属性都会转发到根元素。

</StandaloneMode>
