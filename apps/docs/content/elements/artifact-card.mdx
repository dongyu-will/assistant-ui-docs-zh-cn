---
title: "Artifact 卡片"
description: "作为实体对象生成的文档，实时写入并进行版本管理。"
---

这是一个用于展示助手正在生成的文档的紧凑卡片：包含文件图标、截断的标题，以及在写入过程中显示为闪烁字数、完成后变为版本说明的标题行。在运行时中，这些字段来自工具调用；单独使用时，则由你自行维护。

## 快速开始

<RuntimeMode>

这样的文档本身就是工具调用的结果：调用的 `status` 表示文档是否仍在写入，而 `args` 则携带标题、实时字数以及完成后显示的标题行。

<Steps>
  <Step>

### 渲染工具调用

```tsx title="app/toolkit.tsx"
"use client";

import { defineToolkit } from "@assistant-ui/react";
import { ArtifactCard } from "@/components/assistant-ui/elements/artifact-card";

export const toolkit = defineToolkit({
  write_document: {
    type: "backend",
    render: ({ args, status }) => (
      <ArtifactCard
        title={args.title}
        meta={args.meta}
        generating={status.type === "running"}
        words={args.words ?? 0}
      />
    ),
  },
});
```

模型仍在输出调用时，`args` 会以部分 JSON 的形式到达，因此随着该字段的流式传输，`words` 会自动增加；无需连接单独的进度通道。当 `status` 不再是 `"running"` 时，`generating` 会关闭，`meta` 则会显示完成后的标题行。

  </Step>
  <Step>

### 注册工具包

```tsx title="app/MyRuntimeProvider.tsx"
import { AssistantRuntimeProvider, AuiConfig, Tools } from "@assistant-ui/react";
import { toolkit } from "./toolkit";

const config = AuiConfig({ tools: Tools({ toolkit }) });

export function MyRuntimeProvider({ children }: { children: React.ReactNode }) {
  return (
    <AssistantRuntimeProvider runtime={runtime} config={config}>
      {children}
    </AssistantRuntimeProvider>
  );
}
```

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

单独使用时，该元素是一个受控显示组件：由你管理 `generating` 和 `words`，并随着文档的进展切换它们。

<Steps>
  <Step>

### 保存 Artifact 状态

```tsx title="app/artifact.tsx"
"use client";

import { useState } from "react";
import { ArtifactCard } from "@/components/assistant-ui/elements/artifact-card";

export function Artifact() {
  const [generating, setGenerating] = useState(true);
  const [words, setWords] = useState(0);

  return (
    <ArtifactCard
      title="Draft persistence RFC"
      meta="Document · v3 · just now"
      generating={generating}
      words={words}
    />
  );
}
```

  </Step>
  <Step>

### 随文档写入推进状态

```tsx
useEffect(() => {
  if (!generating) return;
  const id = setInterval(() => setWords((w) => w + 4), 100);
  return () => clearInterval(id);
}, [generating]);

function finish() {
  setGenerating(false);
}
```

  </Step>
</Steps>

</StandaloneMode>

## 结构

```tsx
<div data-slot="artifact-card">
  <span>{/* file icon, pulses while generating */}</span>
  <div>
    <p>{/* title, truncated */}</p>
    <p>
      {/* generating: shimmering "Writing" · word count */}
      {/* otherwise: meta */}
    </p>
  </div>
  <span>{/* arrow, visible on hover */}</span>
</div>
```

元信息行和写入行不会同时显示：当 `generating` 为 true 时，卡片会显示带有闪烁效果的“正在写入”以及 `words`；当它为 false 时，卡片会改为显示 `meta`，并淡入显示。末尾箭头只有在鼠标悬停卡片时才会显示。整个卡片具有类似按钮的悬停和激活样式，但自身不会声明点击处理函数；可以通过转发到根元素的 props 来接入点击处理函数。

## 示例

### 重新设置卡片样式

两种显示状态都会在根元素上接收 `className`。字数和元信息标题行都使用 `mono` token，而写入标签使用 `ShimmerLabel`，这些都来自 `surfaces.tsx`。

```tsx
<ArtifactCard className="max-w-sm" /* ... */ />
```

### 让卡片可操作

`className`、`onClick` 以及除 `title`、`meta`、`generating` 和 `words` 之外的所有其他 `div` prop，都会传递到根元素，因此卡片在两种显示状态下都可以用相同方式变为可点击：

```tsx
<ArtifactCard
  title="Draft persistence RFC"
  meta="Document · v3 · just now"
  onClick={() => openDocument("draft-persistence-rfc")}
/>
```

## API 参考

<RuntimeMode>

### 渲染属性

| 来源 | 类型 | 描述 |
|--------|------|-------------|
| `args.title` | `string` | 卡片标题，截断为单行。 |
| `args.meta` | `string` | 调用不再运行后显示的标题行。 |
| `args.words` | `number \| undefined` | 运行期间显示的实时字数；缺失时显示为 `0`。 |
| `status.type` | `"running" \| "requires-action" \| "incomplete" \| "complete"` | `"running"` 映射为 `generating={true}`；其他值映射为 `false`。 |

</RuntimeMode>

<StandaloneMode>

### ArtifactCard

| 属性 | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `title` | `string` | required | 卡片标题，截断为单行。 |
| `meta` | `string` | required | 未生成时显示的标题行。 |
| `generating` | `boolean` | `false` | 将标题行切换为闪烁的字数。 |
| `words` | `number` | `0` | 当 `generating` 为 true 时显示的字数。 |
| `className` | `string` | | 合并到根元素上。 |

所有其他 `div` props（包括 `onClick`）都会转发到根元素。

</StandaloneMode>
