语音对话是在会话线程上叠加的一场实时通话：一个跟随说话者变化的轨道、一条标示当前回合的字幕，以及逐步填充的转录内容。在运行时中，轨道、字幕和转录内容都会直接读取会话线程的语音会话；独立使用时，则由你自行控制模式、振幅和对话回合。

## 入门

<RuntimeMode>

assistant-ui 将实时语音通话建模为 `s.thread.voice`；当你针对配置了实时语音适配器的运行时调用 `connectVoice()` 后，该对象会被填充。[`/elements/orb`](/elements/orb) 完整介绍了如何接入该适配器及其自身的状态；本页面介绍周边的通话界面。

### 读取通话模式和音量

```tsx title="components/assistant-ui/elements/voice.aui.tsx"
"use client";

import { useVoiceState, useVoiceVolume, useVoiceControls } from "@assistant-ui/react";
import { VoiceConversation, type VoiceMode } from "./voice-conversation";

function toMode(voice: ReturnType<typeof useVoiceState>): VoiceMode {
  if (!voice || voice.status.type === "starting") return "connecting";
  return voice.mode === "speaking" ? "speaking" : "listening";
}

function LiveCallScreen() {
  const voice = useVoiceState();
  const amplitude = useVoiceVolume();
  const { mute, unmute, disconnect } = useVoiceControls();

  return (
    <VoiceConversation
      mode={toMode(voice)}
      amplitude={amplitude}
      muted={voice?.isMuted ?? false}
      onToggleMute={() => (voice?.isMuted ? unmute() : mute())}
      onEnd={disconnect}
      transcript={[]}
    />
  );
}
```

对于 `mode`，适配器只会报告 `"listening"` 和 `"speaking"`；运行时中没有单独的 `"thinking"` 阶段，因此需要该阶段的界面必须自行推断，例如用户停止说话后、`mode` 切换为 `"speaking"` 之前的间隔。

  </Step>
  <Step>

### 从会话线程填充转录内容

语音回合会作为普通消息追加，因此转录内容与任何文本线程使用的 `s.thread.messages` 相同，而不是单独的语音专用日志：

```tsx
import { useAuiState, type TextMessagePart } from "@assistant-ui/react";

const transcript = useAuiState((s) =>
  s.thread.messages.map((message) => ({
    id: message.id,
    role: message.role === "user" ? ("user" as const) : ("assistant" as const),
    text: message.parts
      .filter((part): part is TextMessagePart => part.type === "text")
      .map((part) => part.text)
      .join(""),
  })),
);
```

  </Step>
</Steps>

### 从状态驱动通话

```tsx title="app/call.tsx"
"use client";

import { useState } from "react";
import { VoiceConversation, type VoiceMode, type VoiceTurn } from "@/components/assistant-ui/elements/voice-conversation";

export function Call() {
  const [mode, setMode] = useState<VoiceMode>("connecting");
  const [muted, setMuted] = useState(false);
  const [transcript, setTranscript] = useState<VoiceTurn[]>([]);

  return (
    <VoiceConversation
      mode={mode}
      amplitude={mode === "listening" ? 0.6 : 0}
      transcript={transcript}
      muted={muted}
      onToggleMute={() => setMuted((m) => !m)}
      onInterrupt={mode === "speaking" ? () => setMode("listening") : undefined}
      onEnd={() => setMode("connecting")}
    />
  );
}
```

  </Step>
  <Step>

### 仅在说话时显示中断操作

轨道的点击目标标记为“中断助手”，仅在 `mode === "speaking"` 且设置了 `onInterrupt` 时才会触发；其余时间传入 `undefined`，这样按钮会自行禁用，而不是点击后无任何反应。

  </Step>
</Steps>

</StandaloneMode>

## 组成

```tsx
<div data-slot="voice-conversation">
  <button aria-label="Interrupt the assistant">{/* orb rings, amplitude-scaled */}</button>
  <div>{/* caption plus hint */}</div>
  <div>{/* transcript, user or assistant tagged */}</div>
  <div>
    <button aria-pressed={/* muted */}>{/* mic */}</button>
    <button aria-label="End the call" />
  </div>
</div>
```

轨道的环会根据 `amplitude` 缩放（限制在 `0..1` 范围内），但仅当 `mode` 为 `"listening"` 或 `"speaking"` 时才会缩放；在 `"connecting"` 和 `"thinking"` 状态下，环保持较小的固定比例，而中心圆点会改为脉动。轨道下方的字幕在 `muted` 为 true 时显示“麦克风已关闭”，即使正在说话，也会优先显示该提示，而不是中断提示。

## 示例

### 所有模式

```tsx
<VoiceConversation mode="connecting" amplitude={0} transcript={[]} />
<VoiceConversation mode="listening" amplitude={0.4} transcript={[]} />
<VoiceConversation mode="thinking" amplitude={0} transcript={[]} />
<VoiceConversation mode="speaking" amplitude={0.7} transcript={[]} onInterrupt={() => {}} />
```

### 结束通话

<RuntimeMode>

`useVoiceControls().disconnect()` 是结束会话的唯一方式；不存在与断开连接不同的独立挂断操作，因此请直接将其连接到 `onEnd`：

```tsx
const { disconnect } = useVoiceControls();

<VoiceConversation onEnd={disconnect} /* ... */ />
```

</RuntimeMode>

<StandaloneMode>

独立使用时，`onEnd` 的具体行为由应用决定，可以表示结束通话、关闭界面、将 `mode` 重置为 `"connecting"` 以便重新拨号，或同时执行这些操作。

</StandaloneMode>

## API 参考

<RuntimeMode>

### 语音 hooks

| Hook | 返回值 | 描述 |
|------|---------|--------------|
| `useVoiceState()` | `VoiceSessionState \| undefined` | `{ status, isMuted, mode }`。在调用 `connectVoice()` 之前或会话结束后，`undefined`。 |
| `useVoiceVolume()` | `number` | 会话连接期间的实时输入振幅。 |
| `useVoiceControls()` | `{ connect, disconnect, mute, unmute }` | 每个方法都会调用对应的 `aui.thread.*Voice()` 方法。 |

### 语音会话状态

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `status.type` | `"starting" \| "running" \| "ended"` | `"starting"` 映射到此处显示的 `"connecting"` 模式。 |
| `mode` | `"listening" \| "speaking"` | 没有 `"thinking"` 值；如果希望显示该阶段，请自行推断这段间隔。 |
| `isMuted` | `boolean` | 反映 `mute()` 和 `unmute()`。 |

</RuntimeMode>

<StandaloneMode>

### VoiceConversation

| Prop | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `mode` | `"connecting" \| "listening" \| "thinking" \| "speaking"` | 必填 | 驱动轨道、字幕和提示文本。 |
| `amplitude` | `number` | 必填 | 限制在 `0..1` 范围内；在监听或说话时缩放轨道的环。 |
| `transcript` | `readonly VoiceTurn[]` (`{ id, role, text }`) | 必填 | 按顺序渲染在轨道下方。 |
| `muted` | `boolean` | | 显示麦克风静音图标和“麦克风已关闭”字幕。 |
| `onToggleMute` | `() => void` | | 由麦克风按钮调用；没有该属性时按钮会禁用。 |
| `onInterrupt` | `() => void` | | 启用轨道的点击目标；仅在 `mode === "speaking"` 时有意义。 |
| `onEnd` | `() => void` | | 由结束通话按钮调用；没有该属性时按钮会禁用。 |
| `className` | `string` | | 合并到根元素上。 |

其他所有 `div` props 都会转发到根元素。

</StandaloneMode>
