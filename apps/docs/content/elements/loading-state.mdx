title: "Loader"
description: "模型尚无内容可显示时，用于持续计时的像素矩阵。"

九个单元格组成的移动光带循环运行，下方的标签说明当前发生的事情，用于填补真实内容出现前的空档。在运行时中，你只需在这个空档期间挂载它，并自行驱动时钟；单独使用时，tick 和标签则完全由你管理。

## 入门

<RuntimeMode>

运行时不会替你驱动时钟，也没有任何 selector 会提供状态字符串。运行时能提供的，是决定它是否应该显示在屏幕上的唯一事实：一次运行处于活动状态，且最新消息尚未生成任何 part。

<Steps>
  <Step>

### 根据空消息运行进行控制

```tsx title="components/assistant-ui/elements/loading-state.tsx"
"use client";

import { useAuiState } from "@assistant-ui/react";

function useIsAwaitingFirstToken() {
  return useAuiState((s) => {
    if (!s.thread.isRunning) return false;
    const last = s.thread.messages.at(-1);
    return last?.role === "assistant" && last.parts.length === 0;
  });
}
```

`s.thread.messages` 是当前显示在屏幕上的分支，因此检查它的最后一项就足够了；你不需要 message scope 来询问“当前是否有人在等待模型”。

  </Step>
  <Step>

### 在本地驱动 tick

```tsx
import { useEffect, useState } from "react";
import { GenerationLoader } from "@/components/assistant-ui/elements/loading-state";

function useTick(active: boolean) {
  const [tick, setTick] = useState(0);
  useEffect(() => {
    if (!active) return;
    const id = setInterval(() => setTick((t) => t + 1), 120);
    return () => clearInterval(id);
  }, [active]);
  return tick;
}

function AwaitingFirstToken() {
  const waiting = useIsAwaitingFirstToken();
  const tick = useTick(waiting);
  if (!waiting) return null;
  return <GenerationLoader label="Generating" tick={tick} />;
}
```

将 `AwaitingFirstToken` 放置在助手下一条消息将要渲染的位置。part 到达后，`waiting` 会切换为 `false`，interval 会被清除，真实内容随即接管显示。

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

单独使用时，`label` 和 `tick` 都由你管理：该组件只会将 tick 数字转换为由点亮单元格组成的移动光带，并在下方显示标签。

<Steps>
  <Step>

### 在状态中保存 tick 和标签

```tsx title="app/loader.tsx"
"use client";

import { useEffect, useState } from "react";
import { GenerationLoader } from "@/components/assistant-ui/elements/loading-state";

export function Loader({ label }: { label: string }) {
  const [tick, setTick] = useState(0);

  useEffect(() => {
    const id = setInterval(() => setTick((t) => t + 1), 120);
    return () => clearInterval(id);
  }, []);

  return <GenerationLoader label={label} tick={tick} />;
}
```

  </Step>
  <Step>

### 稳定后停止计时器

在你自己的异步工作完成后卸载 `Loader`；它没有 `active` 或 `done` prop，只要组件保持挂载，interval 就会持续推进 `tick`。

  </Step>
</Steps>

</StandaloneMode>

## 示例

### 单元格形状

`variant` 只会改变九个单元格的圆角半径：`"dots"` 将它们变为圆形，`"squares"` 保持直角，`"rounded"` 则介于两者之间。

```tsx
<GenerationLoader label="Generating" tick={tick} variant="squares" />
```

### 重新设置网格样式

单元格使用纯色 `bg-foreground` 绘制，并具有两种不透明度级别（点亮和变暗）；由于没有 color prop，要重新着色网格，可以通过 `className` 覆盖该 utility，也可以将元素包裹在由自定义 CSS 读取的 `text-*`/color scope 中。标签本身使用来自 `surfaces.tsx` 的共享 `ShimmerLabel` 样式。

```tsx
<GenerationLoader
  label="Generating"
  tick={tick}
  className="[&_[aria-hidden]_span]:bg-blue-500"
/>
```

## API 参考

<RuntimeMode>

### 线程状态

| Selector | Type | Description |
|----------|------|-------------|
| `s.thread.isRunning` | `boolean` | 一次运行是否处于活动状态。 |
| `s.thread.messages` | `readonly MessageState[]` | 当前显示在屏幕上的分支；`.at(-1)` 是最新消息，其 `role` 和 `parts.length` 决定助手是否已经生成任何可见内容。 |

</RuntimeMode>

<StandaloneMode>

### GenerationLoader

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `label` | `string` | 必填 | 显示在网格下方的文本，以 shimmer 效果渲染。 |
| `tick` | `number` | 必填 | 推进由点亮单元格组成的移动光带；组件不会替你推进它。 |
| `variant` | `"dots" \| "squares" \| "rounded"` | `"dots"` | 九个单元格的圆角半径。 |
| `className` | `string` | | 合并到根元素上。 |

除 `children` 外，所有其他 `div` props 都会转发到根元素。

</StandaloneMode>
