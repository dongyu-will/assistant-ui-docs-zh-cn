---
title: "代码运行器"
description: "带有运行按钮的代码片段，以及附加在其下方的运行输出。"
---

代码块在用户按下运行按钮之前始终保持不变，按下后会将输出附加到下方。在运行时模式下，代码来自用户通过运行完成的工具调用；单独使用时，则由你保存运行状态，并自行将输出传入其中。

## 开始使用

<RuntimeMode>

用户通过按下按钮来完成的工具，而不是在模型调用它的瞬间执行的工具，是一个 `"human"` toolkit 条目：它没有 `execute`，因此调用会保持打开状态，直到渲染器调用 `addResult`。

<Steps>
  <Step>

### 注册人工工具包条目

```tsx title="app/run-code-toolkit.tsx"
"use client";

import { useState } from "react";
import { defineToolkit, type ToolCallMessagePartComponent } from "@assistant-ui/react";
import { CodeRunner, type RunState } from "@/components/assistant-ui/elements/code-runner";
import { z } from "zod";

type RunArgs = { language: string; code: string };
type RunResult = { output: string[]; durationMs: number };

const RunCodeUI: ToolCallMessagePartComponent<RunArgs, RunResult> = ({ args, result, addResult }) => {
  const [state, setState] = useState<RunState>("idle");
  const [output, setOutput] = useState<string[]>([]);

  return (
    <CodeRunner
      language={args.language}
      code={args.code}
      state={result ? "ok" : state}
      output={result?.output ?? output}
      durationMs={result?.durationMs}
      onRun={async () => {
        setState("running");
        const startedAt = Date.now();
        const lines = await runInSandbox(args.code);
        setOutput(lines);
        addResult({ output: lines, durationMs: Date.now() - startedAt });
      }}
    />
  );
};

const toolkit = defineToolkit({
  run_code: {
    type: "human",
    description: "Run a code snippet after the user presses run.",
    parameters: z.object({ language: z.string(), code: z.string() }),
    render: RunCodeUI,
  },
});
```

  </Step>
  <Step>

### 从按钮完成调用

`addResult(result)` 是完成此调用的唯一方式；运行时没有 `execute` 可以回退使用。只有在沙箱运行实际返回后，才能在 `onRun` 内调用它，并且必须严格调用一次。

```tsx title="app/providers.tsx"
const config = AuiConfig({ tools: Tools({ toolkit }) });
```

与其他 toolkit 一样，使用 `<AuiProvider extends={aui} config={config}>` 挂载 `config`。

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

单独使用时，该元素是一个受控组件：运行状态由你管理，并在运行产生输出时将输出推送给它。

<Steps>
  <Step>

### 保存运行状态

```tsx title="app/snippet.tsx"
"use client";

import { useState } from "react";
import { CodeRunner, type RunState } from "@/components/assistant-ui/elements/code-runner";

const code = `console.log("hello")`;

export function Snippet() {
  const [state, setState] = useState<RunState>("idle");
  const [output, setOutput] = useState<string[]>([]);
  return <CodeRunner language="js" code={code} state={state} output={output} onRun={run} />;
}
```

  </Step>
  <Step>

### 接入运行按钮

```tsx
async function run() {
  setState("running");
  const startedAt = Date.now();
  try {
    const lines = await runInSandbox(code);
    setOutput(lines);
    setState("ok");
  } catch (err) {
    setOutput([err instanceof Error ? err.message : String(err)]);
    setState("error");
  }
}
```

  </Step>
</Steps>

</StandaloneMode>

## 结构

```tsx
<div data-slot="code-runner">
  <div>{/* language, optional duration, run button (spinner while running) */}</div>
  <pre>{/* code, always visible */}</pre>
  {/* output block: only once state !== "idle" */}
</div>
```

代码块始终可见；只有当 `state` 离开 `"idle"` 后，输出块才会挂载。每一行输出都会按每行 `80ms` 的间隔依次淡入；当 `state` 为 `"error"` 时以红色显示，否则使用中性色。只有在 `state` 为 `"running"` 时，闪烁的光标才会渲染在目前已接收的行之后。运行按钮旁的时长徽章只有在已知运行时长且运行当前未进行时才会显示。

## 示例

### 读取模型发送的代码

<RuntimeMode>

`args.language` 和 `args.code` 正是上方 `RunCodeUI` 读取的内容；代码本身不会被推断，这些内容来自工具调用自身的参数。

```tsx
const RunCodeUI: ToolCallMessagePartComponent<RunArgs, RunResult> = ({ args }) => (
  <CodeRunner language={args.language} code={args.code} state="idle" output={[]} />
);
```

</RuntimeMode>

### 在完成调用前流式传输输出

<RuntimeMode>

`addResult` 只需在运行完全结束后调用一次；运行仍在进行时显示的输出属于普通本地状态，会随着各行到达而更新：

```tsx
onRun: async () => {
  setState("running");
  const lines: string[] = [];
  for await (const line of runInSandboxStreaming(args.code)) {
    lines.push(line);
    setOutput([...lines]);
  }
  addResult({ output: lines, durationMs: elapsedMs() });
};
```

</RuntimeMode>

### 重新设置运行器样式

两个区域都在根元素上接收 `className`。输出块通过 `surfaces.tsx` 提供的 `codeScroll`/`codeSurface` 配对进行水平滚动，使长行保持可访问而不会被裁剪；因此，重新指定这些 token 后，该元素以及其他以相同方式滚动预格式化输出的元素都会应用新的样式。

## API 参考

<RuntimeMode>

### run_code toolkit 条目

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `type` | `"human"` | 没有 `execute`；调用会保持打开状态，直到 `render` 调用 `addResult`。 |
| `parameters` | Zod schema | 声明参数形状，即上方的 `{ language, code }`。 |
| `render` | `ToolCallMessagePartComponent<RunArgs, RunResult>` | 此调用结果的唯一来源。 |

### 使用的渲染 props

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `args` | `RunArgs` | 模型发送的语言和代码。 |
| `result` | `RunResult \| undefined` | 在调用 `addResult` 后设置；等待按钮期间为 `undefined`。 |
| `addResult(result)` | `(result: RunResult) => void` | 完成调用。调用一次即可。 |

</RuntimeMode>

<StandaloneMode>

### CodeRunner

| Prop | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `language` | `string` | 必需 | 显示在标题栏中。 |
| `code` | `string` | 必需 | 代码片段，按原样渲染。 |
| `state` | `RunState` | 必需 | `"idle" \| "running" \| "ok" \| "error"`。 |
| `output` | `readonly string[]` | 必需 | 输出行；当 `state` 为 `"idle"` 时忽略。 |
| `durationMs` | `number` | | 已知后显示在运行按钮旁。 |
| `onRun` | `() => void` | | 按下运行按钮时调用。 |
| `className` | `string` | | 合并到根元素上。 |

其他所有 `div` props 都会转发到根元素。

</StandaloneMode>
