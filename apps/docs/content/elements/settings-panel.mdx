这是一个集中设置用户可自行调整选项的卡片：由哪个模型回答、告知模型应如何表现、回答的灵活程度，以及一组可开关的能力。在运行时中，这些值会提供给已注册的模型上下文，从而传递到每个请求；单独使用时，它们只是由你自行读取的受控输入。

## 入门

<RuntimeMode>

默认情况下，面板的值不会存储在运行时中；你需要将它们保存为组件状态，并将其注册为模型上下文提供者，这与 `useAssistantInstructions` 和模型选择器内部使用的机制相同。此后，每个请求都会携带面板当前持有的值。

  <Step>

### 将面板的值注册为模型上下文

```tsx title="components/assistant-ui/elements/model-settings.tsx"
"use client";

import { useEffect, useState } from "react";
import { useAui } from "@assistant-ui/react";
import {
  SettingsPanel,
  type SettingToggle,
} from "@/components/assistant-ui/elements/settings-panel";

const MODELS = ["gpt-5.6-terra", "gpt-5.6-sol"];

export function ModelSettings() {
  const aui = useAui();
  const [model, setModel] = useState(MODELS[0]!);
  const [systemPrompt, setSystemPrompt] = useState("You are a concise assistant.");
  const [temperature, setTemperature] = useState(0.7);
  const [webSearch, setWebSearch] = useState(false);

  useEffect(() => {
    return aui.modelContext.register({
      getModelContext: () => ({
        system: systemPrompt,
        callSettings: { temperature },
        config: { modelName: model },
      }),
    });
  }, [aui, model, systemPrompt, temperature]);

  const toggles: SettingToggle[] = [
    {
      key: "web-search",
      label: "Web search",
      detail: "Look things up before answering",
      on: webSearch,
    },
  ];

  return (
    <SettingsPanel
      model={model}
      models={MODELS}
      systemPrompt={systemPrompt}
      temperature={temperature}
      toggles={toggles}
      onModelChange={setModel}
      onSystemPromptChange={setSystemPrompt}
      onTemperatureChange={setTemperature}
      onToggle={(key) => key === "web-search" && setWebSearch((w) => !w)}
    />
  );
}
```

每当 `model`、`systemPrompt` 或 `temperature` 发生变化时，注册都会重新执行，因此 effect 的清理函数会在新提供者接管之前注销过期的提供者；在下一次请求之前，不会发送任何内容。

  </Step>
</Steps>

</RuntimeMode>

单独使用时，每个值都是一个 prop，每次变更都通过回调通知；除将 temperature 限制在显示范围内之外，面板不会进行其他计算。

### 保存设置状态

```tsx title="app/settings.tsx"
"use client";

import { useState } from "react";
import {
  SettingsPanel,
  type SettingToggle,
} from "@/components/assistant-ui/elements/settings-panel";

export function Settings() {
  const [model, setModel] = useState("balanced");
  const [systemPrompt, setSystemPrompt] = useState("You are a helpful assistant.");
  const [temperature, setTemperature] = useState(1);
  const [toggles, setToggles] = useState<SettingToggle[]>([
    { key: "code", label: "Code execution", detail: "Run snippets in a sandbox", on: true },
    { key: "memory", label: "Memory", detail: "Remember facts across chats", on: false },
  ]);

  return (
    <SettingsPanel
      model={model}
      models={["fast", "balanced", "careful"]}
      systemPrompt={systemPrompt}
      temperature={temperature}
      toggles={toggles}
      onModelChange={setModel}
      onSystemPromptChange={setSystemPrompt}
      onTemperatureChange={setTemperature}
      onToggle={(key) =>
        setToggles((prev) => prev.map((t) => (t.key === key ? { ...t, on: !t.on } : t)))
      }
    />
  );
}
```

  </Step>
</Steps>

</StandaloneMode>

## 组成

```tsx
<div data-slot="settings-panel">
  <div>
    <span>{/* "model" */}</span>
    <div>{/* one segmented button per model in `models` */}</div>
  </div>
  <div>
    <span>{/* "system prompt" */}</span>
    <textarea aria-label="System prompt" />
  </div>
  <div>
    <span>{/* "temperature" */}</span>
    <span>{/* the clamped value, one decimal */}</span>
    <input type="range" aria-label="Temperature" />
  </div>
  <div>{/* one row per toggle: label, detail, switch */}</div>
</div>
```

`temperature` 会在显示或传递给范围输入框之前被限制到 `0…2`，而 `NaN` 会将值限制到 `0`，因此错误值不会以无效属性的形式到达 DOM。此元素中的任何控件都不会自行禁用：无论其他字段的值如何，模型按钮、文本区域、滑块和每个开关都保持可交互状态；如果 `models` 或 `toggles` 数组为空，该部分只会渲染为空，而不会显示占位消息。模型控件会在普通按钮上使用 `aria-pressed`，而不是采用单选框语义；每个切换项都是带有 `aria-checked` 的真实 `role="switch"`，而不是经过样式处理的复选框。

## 示例

### 值的去向

<RuntimeMode>

已注册的提供者到达后端的方式与手动选择 `ModelSelector` 相同：`AssistantChatTransport` 会将 `config`、`system` 和 `callSettings` 作为同级字段放入每个聊天请求的请求体中，因此你的路由可以直接从解析后的 JSON 中读取这三个字段。

```tsx title="app/api/chat/route.ts"
export async function POST(req: Request) {
  const { messages, config, system, callSettings } = await req.json();
  const result = streamText({
    model: openai(config?.modelName ?? "gpt-5.6-terra"),
    temperature: callSettings?.temperature,
    system,
    messages: await convertToModelMessages(messages),
  });
  return result.toUIMessageStreamResponse();
}
```

切换项可以控制的不只是 `config` 中的值：你可以根据切换项的 `on` 值，在同一提供者的 `tools` 中包含或省略某个条目，并使用应用在其他位置注册的工具定义；开关切换的瞬间，模型就不会再获得该工具。

</RuntimeMode>

<StandaloneMode>

单独使用时，没有任何内容会离开组件：`onModelChange`、`onSystemPromptChange`、`onTemperatureChange` 和 `onToggle` 是值传出的唯一方式，因此要将它们持久化（保存到数据库或 `localStorage`）完全取决于你传入的回调。

</StandaloneMode>

### 重新设置面板样式

两种布局都会在根元素上接收 `className`。分段控件、文本区域和滑块都位于 `field` 表面上，分区标签使用共享的 `mono` 设计令牌，因此只需重新设置这两个令牌的主题，就能一次覆盖所有行。

```tsx
<SettingsPanel className="max-w-xs" /* ... */ />
```

## API 参考

<RuntimeMode>

此元素没有专用原语；它会注册一个普通的 `ModelContextProvider`，与入门部分中的方式相同。

### 模型上下文

| 选择器 / 方法 | 类型 | 描述 |
|--------------------|------|-------------|
| `aui.modelContext.register(provider)` | `(provider: ModelContextProvider) => Unsubscribe` | 注册一个提供者，其 `getModelContext()` 会合并到每个发出的请求中。调用返回的函数（或让 `useEffect` 清理函数调用它）即可注销。 |
| `s.modelContext.modelName` | `string \| undefined` | 合并所有已注册提供者后当前生效的 `config.modelName`。 |
| `s.modelContext.toolNames` | `readonly string[]` | 当前在所有提供者中注册的工具名称。 |

`ModelContext` 本身接受 `system`（附加到发出请求的系统提示词末尾的字符串）、`callSettings`（一个 `LanguageModelV1CallSettings`，包括 `temperature`）、`config`（一个 `LanguageModelConfig`，包括 `modelName`）以及 `tools`。

</RuntimeMode>

<StandaloneMode>

### SettingsPanel

| Prop | 类型 | 默认值 | 描述 |
|------|------|---------|-------------|
| `model` | `string` | 必填 | 从 `models` 中选中的值。 |
| `models` | `readonly string[]` | 必填 | 分段控件中显示的选项。 |
| `systemPrompt` | `string` | 必填 | 文本区域的值。 |
| `temperature` | `number` | 必填 | 滑块的值。显示时会限制到 `0…2`；`NaN` 会将值限制到 `0`。 |
| `toggles` | `readonly SettingToggle[]` | 必填 | 滑块下方显示的行。 |
| `onModelChange` | `(model: string) => void` | | 使用按下的模型值调用。 |
| `onSystemPromptChange` | `(prompt: string) => void` | | 每次文本区域发生变化时调用。 |
| `onTemperatureChange` | `(temperature: number) => void` | | 使用滑块的原始值（未限制范围）调用。 |
| `onToggle` | `(key: string) => void` | | 按下开关时，使用切换项的 `key` 调用。 |
| `className` | `string` | | 合并到根元素上。 |

所有其他 `div` props 都会转发到根元素。

### SettingToggle

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `key` | `string` | 传回 `onToggle` 的标识符。 |
| `label` | `string` | 行标题。 |
| `detail` | `string` | 标题下方的辅助文本。 |
| `on` | `boolean` | 开关位置。 |

</StandaloneMode>
